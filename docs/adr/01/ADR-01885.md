# ADR-01885: the shadow comparison's checker warmed before a rewrite

- **Relations**: `Implements TDD-00230` (P3.3: the shadow report)
- **Date**: 2026-10-21

## Context

- A rewrite after binding (staticPrivateBrand) changes the code the checker reads; codegen's checker types the affected bodies first (warmFront), since its memo drops an answer reached inside a cycle (a static member read while its class's value is built). The shadow comparison runs its own checker over the same program, never warmed: it left such reads unanswered and fell back to the declared type, the largest bucket of the report (a static getter's `return this.#gen`), none of it a disagreement codegen has.

## Decision

- warmFront warms the shadow oracle's checker over the same nodes.

## Consequences

- The report's largest bucket, about 318 rows, leaves it; emission is unchanged.
- Verified on Apple Silicon.
