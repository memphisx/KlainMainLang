# ADR-01570: A block's class initializes its statics where it is declared

- **Relations**: Extends ADR-00375, Implements TDD-00230
- **Date**: 2026-10-11

## Context

Test262's class-field files left invalid IR, plus one wrong result:

- A field initialized by a call that only throws (`static f =
  initThrows()`, `x = f()`) took the call's type. That type is `void` (a
  `never` function, or an unannotated one that ends in `throw`), so the
  emitted field was a `void` global (`global void zeroinitializer`) or a
  `{ i64, void }` instance layout.
- A class declared inside a block (here a `try`) is hoisted to the program
  level, and its declaration site already re-runs its static
  initialization (`markClassReeval`). Its statics also ran once before the
  program's first statement, outside the `try`. A static initializer that
  throws then escaped as an uncaught error before any code ran, and every
  static initializer ran one time too many.

- A static setter assigned a nullable value (`static set a(_ = null)`,
  `C.a = null`) received it through a synthesized local holding the
  `{ i1, payload }` pair. The local was not marked as holding one, so it
  read back as the bare payload: invalid IR, and before that `0` where
  Node passes `null`.

## Decision

- A field whose initializer has no value type (`void`, or none) is laid
  out as `any`, the slot later assignments write. This applies to static
  and instance fields alike.
- `reevaluatedClass` excludes a class whose declaration site initializes
  its statics from the program-start static initialization. Its statics
  run once, where the class is declared, as in JavaScript.

- `emitStaticFieldAssign` marks its argument local `NullableBoxed` for a
  nullable scalar, so the setter receives `null`.

## Verification

`static f = initThrows()` in a `try`, an instance and a subclass field
initializer that throws, a block-scoped class with interdependent statics,
and a function's class whose statics restart per call all print Node's
output, and so does `C.a = null` through a static setter
(`TestE2EStaticSetterNullAndBlockStatics`). Mac: the class/static E2E suites. Linux (DeskMini and Node304
kmlbox) full gates.
