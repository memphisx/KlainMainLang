# ADR-00399: `net` completion — `isIP` family, options-object connect, socket options

- **Relations**: Implements TDD-00131 (per-module Node API fidelity); Extends ADR-00324, ADR-00358, ADR-00397 (net runtime)
- **Date**: 2026-08-27

## Context

A completeness pass over `net`, closing the remaining high-use gaps a corpus
tally over `test-net-*.js` surfaced: `.isIP` family (38+14+14 uses), `.resume`
(51), `.destroy` (27), `.setNoDelay` (19), `.setKeepAlive` (15), and the
`net.connect({ port, host })` options-object form (16 files in the compile-error
histogram).

## Decision

- **`net.isIP(s)` / `isIPv4(s)` / `isIPv6(s)`** — a runtime helper
  `__kml_net_is_ip` runs `inet_pton` for `AF_INET` then `AF_INET6` (the platform's
  value — macOS 30 / Linux 10), returning 0/4/6. `isIP` yields a `number`;
  `isIPv4`/`isIPv6` yield booleans.
- **`net.connect` / `createConnection` options-object form** — `net.connect({
  port, host }, cb?)` alongside the positional `(port, host, cb?)`. `host`
  defaults to `"localhost"`. The IPC `{ path }` form stays unsupported (TCP only).
- **`socket.setNoDelay(bool?)` / `setKeepAlive(bool?, ms?)`** — real `setsockopt`
  (`TCP_NODELAY` / `SO_KEEPALIVE`); the boolean defaults to `true`, and
  `setKeepAlive`'s initial-delay argument is accepted but not threaded.
- **`socket.destroy()`** — forcibly closes the socket (no error argument in V1).
- **`socket.setEncoding` / `ref` / `unref` / `pause` / `resume` / `setTimeout`**
  — accepted but **no-ops**, documented as such: a socket's chunk type already
  follows the listener's declared parameter type; the program runs to completion
  regardless of event-loop keep-alive; and the blocking read model has no
  separately-schedulable flow or idle timer. Arguments are still evaluated for
  their side effects.

## Deliberately still out (documented in the status row)

Async `'error'`/`'close'`/`'connect'` events, back-pressure (`.write` returning
`false` + `'drain'`), a `host`/options object on `server.listen`, and
constructible `net.Server`/`net.Socket` classes — these need the non-blocking /
event-model changes the current blocking `connect()` + synchronous-listener
design intentionally avoids.

## Verification

`net.isIP` family, the options-object connect, and `setNoDelay`/`setKeepAlive`/
`destroy` verified byte-identical to Node v26 (Mac), including a full
options-form `listen(0) → address().port → connect({ port, host })` round-trip.
E2E tests added; net + TLS suites green.
