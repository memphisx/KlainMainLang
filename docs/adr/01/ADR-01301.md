# ADR-01301: `http2` as Node's lib/internal/http2 over an nghttp2 event queue

- **Relations**: `Implements part of TDD-00230` (P3.1), `Supersedes ADR-00414`, `Supersedes ADR-00415`
- **Date**: 2026-09-30

## Context

The `http2` module was compiled directly. `http2.createServer` was the
codegen HTTP server with an h2c preface check. `.on('stream')` built a
codegen `Http2ServerStream` record whose response went out after the
handler returned. `http2.connect` was a separate codegen client that sent
requests without a body. There were no push streams, RST, settings, ping or
goaway, no flow of request data per frame, and no TLS client.

## Investigation

Node's lib/internal/http2/core.js keeps the protocol logic in JavaScript
around one native `Http2Session`. The native side feeds bytes to nghttp2,
calls back per frame event, and takes requests, responses, data, RST,
settings, ping and goaway. compat.js builds `Http2ServerRequest` and
`Http2ServerResponse` on top of the stream API. util.js holds header
mapping, settings packing and validation. The same split works here, with
one change: nghttp2's callbacks cannot call into TypeScript directly, so
the native session queues events and the TypeScript side drains them.

## Decision

**Natives** (`http2src/h2node.c`, the `h2node` unit, linked by `@link
http2`): one nghttp2 session per `Http2Session`, addressed by handle:
`h2New`, `h2Feed` (bytes in), `h2Flush`/`h2Take` (bytes out), `h2Next`/
`h2Event` (the queued frame events), `h2Request`, `h2Respond`,
`h2Headers`, `h2Push`, `h2Write`, `h2Rst`, `h2Settings`, `h2Ping`,
`h2Goaway` and `h2State`. A client stream is tracked natively until its
HEADERS frame is sent, because nghttp2 attaches stream user data only then.

**Library** (`lib/node/http2.ts`): Node's core.js, compat.js and util.js
over those natives and `net`/`tls` sockets. It covers `createServer`,
`createSecureServer` (ALPN `h2`, `allowHTTP1` handing HTTP/1.1 to `http`'s
connection listener), `connect` over h2c and TLS, `ClientHttp2Session`,
`ServerHttp2Session`, `ServerHttp2Stream`, `ClientHttp2Stream`, push
streams, trailers, `'unknownProtocol'`, timeouts, `constants`,
`getDefaultSettings`, `getPackedSettings`, `getUnpackedSettings` and
`sensitiveHeaders`.

Writes are coalesced into one flush per loop turn through `setImmediate`,
as Node's `MaybeScheduleWrite` does. Microtasks are drained after each
frame event (`runMicrotasks`, `@lower __kml_drain_microtasks`), matching
the order Node's `MakeCallback` gives.

A session or stream timeout re-arms the timer (clear, then set again) in
place of `timeout.refresh()`. It unrefs the handle while it is still typed
`Timeout`: timer handles are numeric ids here (the timers status row).

**Deleted**: the codegen `http2` module (its marker, `emit_http2_settings.go`,
the client session and stream types and emitters,
`emitHTTP2CreateSecureServer`), and the codegen server's
`.on('stream')` path (`emitHTTPStreamHandlerCore`, `emitH2StreamMethod`,
`Http2ServerStreamType`, the dispatcher's stream mode). Node's `http.Server`
has no `'stream'` event. Kept: `klain:http`'s `http.listen` serving h2c
prior-knowledge through `http2src/http2.c` (ADR-00357).

## Implementation notes

Compiler fixes the port needed:
- a top-level `new Set([...])` read inside functions (third-pass promotion);
- `x ?? []` with an `any` array on the left narrows to non-null;
- timers take an `any` callback, with Node's `ERR_INVALID_ARG_TYPE`;
- `Array.isArray(v) ? v.join() : …` on a narrowed union;
- `URL` as a host cell: reads through `any`, `instanceof URL`, and Node's
  inspect and `toString` format, depth included;
- host-box inspect honours `util.inspect`'s run-time depth;
- a union box converts to an object layout (`emitAnyToLayout`);
- a dict boxes into `any` as a dynamic-object bag;
- object spread: of a `null`/`undefined` source, skipping absent optional
  fields, and of a foreign layout's own keys (`__kml_shape_spread`);
- `Partial<T>` makes fields optional;
- `(F)[] | null` and `Array<T> | null` keep their nullability;
- a failed dynamic get names the property.

## Side effects discovered

- A dict boxed into `any` is a copy (BACKLOG 127).
- `const x: T[] = null as any` does not compile (BACKLOG 128).
- TypedArray `.buffer`/`.byteOffset` are missing (BACKLOG 129); the library
  avoids them.
- Timer handles through `any` have no methods (timers status row).
- Programs importing `http2` compile in about 15 s (BACKLOG 113).

## Verification

`tests/http2_port_test.go` has 7 programs: sync API, compat server with
client, stream API, push and reset, settings, TLS with `allowHTTP1`, and
stream timeouts. Each one's output matches Node 24's. The `http2` tests in
`tests/http_test.go` now use the Node API and pass. The `examples/http2`
programs were updated. Verified on the Mac.
