# ADR-01673: Builtin-name switches give way to declarations and tables

- **Relations**: Implements TDD-00230, Extends ADR-01664
- **Date**: 2026-10-17

## Context

Phase 3's exit criterion allows no `case "<builtin name>"` dispatch outside the intrinsic table. `TestStringCaseArmsOnlyShrink` counts string-literal case values in codegen. It stood at 913 after ADR-01668. Three different kinds of switch remained:

- some re-asked a question the declarations already answer;
- some re-dispatched by name inside an entry the intrinsic table had already chosen by name;
- the rest mapped names to behaviour or data, one `case` per name.

## Decision

- **Declarations answer.**
  - `funcOwnPropCall` no longer lists `call`/`apply`/`bind`/`toString`. lib's `Function` interface declares them, and the checker's `MemberDecl` already reports a declared member.
  - The inference special case typing `process.stdin/stdout/stderr.isTTY` as boolean is deleted. Those streams are the stdio module's TypeScript objects, which declare `isTTY`.
- **One intrinsic, one entry point.** `String.fromCharCode`/`fromCodePoint`, `Symbol.for`/`keyFor` and `Response.json`/`redirect`/`error` register their own emitters. The emitters that switched on the method name (`emitStringStaticCall`, `emitSymbolStatic`, `emitResponseStatic`) are split or deleted.
- **Tables.**
  - `generatorMethods`: a generator's `next`/`throw`/`return`, each with its async form and its sync step.
  - `combinators`: Promise `all`/`allSettled`/`race`/`any`. For each: the element type it collects, whether its result is that array, how it finishes, and its fulfilled and rejected reactions.
  - `execMembers`: an `exec()` result's `index`/`input`/`groups`, with each one's type, header offset and how a global match's plain array lacks it.
  - `bufferAccessorShapes` and `bufferEncodingNames`: the element types a Buffer `read*`/`write*` name spells, and the encoding names a literal may use.
  - `collIterMethods` (keys/values/entries, also behind `mapEagerIter`), `processStdioGetters`, `processConstMembers` and `builtinCountNames`.
- **Smaller changes.**
  - `literalMembers` picks a stream source's or sink's members by name list.
  - `emitStaticIntegrityTest` takes the integrity level that `integrityLevel` already carries, not the method name.

The allowance drops from 913 to 798 (`errorOptionalNumbers` too). Whether a member on a function value is an expando asks the lib's `Function` and `Object` interfaces, not an eight-name list. `Function` gains `prototype: any`, as TypeScript's own lib declares it. `NaN` and `Infinity` read their IR constants from `globalNumberConsts`.

## Side effects discovered

None.

## Verification

- Emitted IR is byte-identical over the 68-file IR list plus the examples using each touched feature: call/apply/bind, generators, Promise combinators, Buffer, process, streams, RegExp, Object integrity, collection iterators and stdio.
- Targeted tests for each feature pass on Mac.
