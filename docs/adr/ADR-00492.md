# ADR-00492: Typed Object.values/entries for homogeneous shapes

- **Date**: 2026-08-29

## Context

`Object.values`/`Object.entries` on a fixed-shape object always
stringified the values — even when every field was the same type, so a
numeric sum over `Object.values(scores)` was impossible.

## Decision

`homogeneousFieldType` checks whether every visible field shares one
storage type (IR + the behavior-changing flags). If so, `values` returns
a real `V[]` and `entries` a real `[string, V][]` — raw field loads, no
stringification. Mixed shapes keep the stringified fallback: the union
those would need is only representable as `any`, whose operators aren't
dispatched yet. Inference mirrors the same rule so downstream arithmetic
type-checks. Dynamic (Map-backed) objects already returned typed values
and are unchanged.
