# ADR-01906: TS2741 for a builtin declaration's value

- **Relations**: `Implements TDD-00230` (strict lane is tsc)
- **Date**: 2026-10-21

## Context

- A builtin declaration lists only the members this compiler implements, so the missing-property check (TS2741, TS2739) skipped every source typed by one: `const d: EchoResp = r.json()` assigned a `Promise<any>` to an interface it lacks every property of, and compiled. tsc rejects it.

## Decision

- A required target property a builtin source lacks is missing when TypeScript's own declaration of the source (lib/tsmembers.txt) lacks it too; a member only TypeScript's declaration has still leaves the check undecided.

## Consequences

- The strict lane rejects a builtin value assigned where it lacks required members, as tsc does. Tests that assigned an un-awaited `json()` to its parsed type now await it.
