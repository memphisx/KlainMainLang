# ADR-01481: Shadow agreement by node kind; dictionary reads

- **Relations**: Extends ADR-01480
- **Date**: 2026-10-09

## Context

TDD-00230 P3.3 replaces `inferExprType` with `reprOf` of the checker's
type. The shadow report ranked disagreements but did not say how often the
two answers agree, so it could not tell which node kinds are ready to
switch.

## Investigation

- Recording how many nodes of each kind were asked about (per compile run)
  showed, over 60 examples, `inferExprType` agreeing on 99% of its answers:
  every literal, `this`, unary, `new` and template node, and 99.5% of
  20,129 identifiers.
- The recorder keeps the first answer for a node. An analysis pre-pass
  (escape and purity checks, empty-container and widened-binding
  inference) asks before the bindings it reads are in scope, so a node
  first asked there was recorded with a pre-pass answer, not the one code
  is emitted by: `first` in `{ showHidden: first }` after `typeof first ===
  'boolean'` read `any` in `crossTypeWidenedBindings` and `boolean` when
  emitted (where both sides agree). About a quarter of the sample's
  disagreements were such pre-pass answers.
- `spawn(...)` returns `ChildProcessWithoutNullStreams`, an interface
  extending the `ChildProcess` class: codegen holds the class instance, the
  oracle answered the interface's members as a structural object. The
  interface's base is named as written (`ChildProcess`) while module
  symbols carry the module's suffix.
- `util.inspect.colors` (a function's own property holding a string-keyed
  dictionary) read as `any`, and so did every index into it.
- A function declared `: never` returned codegen's `i64` default (no
  case for the name), where a block-bodied arrow that only throws is
  already `TypeNever` (ADR-00869).
- `x` held as `any` and narrowed to a class instance (`if (!(x instanceof
  C)) return;`) was read as `any`, its members dynamically, though codegen
  already read it through C's layout inside the same condition.
- `encoding: BufferEncoding | 'buffer' | null | undefined` resolved to a
  boxed union of strings instead of a three-state string (ADR-01314): the
  "one primitive kind" collapse looked only at literal members, and
  `BufferEncoding` is an alias.
- The oracle disagreed with codegen where codegen is right: `ArrayBufferLike`
  (`dv.buffer`) is held as an ArrayBuffer; `n as number` with `n: number |
  undefined` keeps the absent value (the assertion is erased); a
  conditional over a typed array read or a string read (`c ? arr[i] :
  str`) keeps the read's undefined; a call picked for an `any` argument
  returning void is void.
- `err && ok` (`err: Error | null | undefined`, `ok: boolean`) was a
  boxed union; its values are exactly `null`, `undefined`, `true` and
  `false`, the three-state boolean ADR-01314 gives such an annotation.
- `list.slice()` on a `T[] | undefined` was typed possibly absent; a
  fresh copy never is (the call throws on an absent receiver).
- `Promise.resolve(1).then(() => pn)` (pn a `Promise<number>`) was
  `Promise<any>` in the checker: inference into `TResult1 |
  PromiseLike<TResult1>` gave up on a union with two generic members.
- A missing key of a dictionary of arrays (`r["zz"]`, `r.zz`,
  `map.get("zz")` with `Map<string, number[]>`) printed `null`; Node prints
  `undefined`. The read was marked nullable but not undefined, kept so
  (a comment said) because `toBool` folded an undefined-flagged array to
  false; it no longer does (`if (m.get("zz"))`, `x ? 1 : 0` checked).

## Decision

- Shadow mode writes one tally record per decider and node kind (nodes
  asked about, each once per run); `go run ./tools/shadow` prints an
  "Agreement by node kind" table. A kind that agrees everywhere can switch
  to `reprOf`.
- An analysis pre-pass runs under `analysisPass`; `inferExprType` answers
  given there are not compared.
- `reprOf` gives an interface that extends one class, and adds no
  representation of its own, that class's instance (`interfaceClassBase`,
  resolving the base by its module-suffixed name).
- A function's own property the checker types as a string-keyed
  dictionary reads as that dictionary (`checkerDictType`), in emission and
  inference.
- A missing key of a dictionary or `Map` of arrays is `T[] | undefined`.
- `never` resolves to `TypeNever`.
- `a && b` with a an object that may be absent (truthy whenever present)
  and b a plain scalar is b's type with a's absence: three-state, undefined
  or null (`andAbsentScalar`, `emitAndAbsentScalar`), in emission and
  inference.
- `slice()`'s result type is the receiver's without its absence
  (`presentCopy`).
- The checker infers into a union of several generic members as tsc's
  inferToMultipleTypes: each source member to a non-bare member it
  matches, else to the bare type parameter (checker/generics.go `unify`);
  `reprOf` maps `never` to `TypeNever`.
- A union whose members all resolve to exactly a string's representation
  (string literals, a literal-union alias) is a string (and so, with null
  and undefined, a three-state string); a stream or other host handle is a
  pointer too and keeps the union (`body: string | ReadableStream` lost its
  stream when `isStringTy` was the test, which the examples' fixture
  server caught).
- The oracle: `ArrayBufferLike` is an ArrayBuffer handle; an asserted
  nullable scalar stays nullable; the conditional element-read rule covers
  typed arrays and a branch of the element's own type; an `any`-argument
  overload's void result stays void; a class instance an `any` narrows to
  reads as the instance (`narrowableClass`).
- An `any` the checker narrows to an instance of a plain class (no host
  body, not an Error subclass) reads as that instance (`checkerNarrowed`),
  so its members read through the class's layout; the oracle keeps such a
  receiver's named member reads static. A number codegen holds as an
  integer in a binding it proved integral is not counted as a
  disagreement (`intPromoted`).

## Side effects discovered

- BACKLOG 160: a generic call returned by a callback (`p.then((n) =>
  sleep(1).then(() => n))`) is still `any` in the checker.

- BACKLOG 161: `instanceof ReadableStream` on a union member holding a
  stream is false.
