# ADR-01603: net.connect tries every address (autoSelectFamily)

- **Relations**: Extends ADR-01601
- **Date**: 2026-10-13

## Context

With the test servers bound to `127.0.0.1` (ADR-01601), every client that
connected by name failed with `ECONNREFUSED ::1:<port>`:
`http.request({ port })` and `net.connect(port)` default to `localhost`,
which resolves to `::1` first, and the socket tried that address only. They
had passed because the servers listened on `::` (dual-stack).

## Investigation

Node 24 on the same machine, server on `127.0.0.1` only: `http.get({ port })`
answers, and `net.connect(port)` connects with `remoteAddress` `127.0.0.1`.
Since Node 20, `net.connect` resolves every address and tries them in turn
(`autoSelectFamily`, on by default; `lib/net.js` `lookupAndConnectMultiple`
and `internalConnectMultiple`), each attempt bounded by
`autoSelectFamilyAttemptTimeout` (250 ms, at least 10). `net.ts` looked up
one address.

## Decision

`Socket.connect` follows Node when `autoSelectFamily` (option, else
`net.getDefaultAutoSelectFamily()`) is on and no `family` is given:

- every address from `getaddrinfo`, deduplicated and interleaved by family
  starting with the first address's family; a `'lookup'` event per address;
- one attempt at a time, each emitting `'connectionAttempt'`; a failure
  emits `'connectionAttemptFailed'` and the next address is tried; an
  attempt still pending after the timeout emits `'connectionAttemptTimeout'`,
  is closed, and the next is tried;
- when every address fails, the socket is destroyed with the one error, or
  an `AggregateError` of them all whose `code` is the last one's;
- a lookup failure is the `getaddrinfo` `DNSException` (`ENOTFOUND`).

`net.getDefaultAutoSelectFamily`, `setDefaultAutoSelectFamily`,
`getDefaultAutoSelectFamilyAttemptTimeout` and
`setDefaultAutoSelectFamilyAttemptTimeout` are added, with Node's defaults
(true, 250 ms).

## Verification

Windows 11: the HTTP client tests, `TestCompatJSProgramUsingHTTP`, the
`net.connect` tests and `TestE2ENetConnectDNSFailureEmitsError` pass with
servers on `127.0.0.1`. Linux: owed.
