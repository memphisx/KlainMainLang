# ADR-01702: Functions as constructors

- **Relations**: `Implements TDD-00230`; `Extends TDD-00155`
- **Date**: 2026-10-18

## Context

The constructor functions of TDD-00155 Stage 4 (`function F(v) { this.v = v }` with `new F(…)`) existed only under `-compat=js`, and there:
- `x instanceof F` was a compile error;
- `F.prototype` had no `constructor`, so `x.constructor === F` was false and Node's `F { v: 3 }` printed as `{ v: 3 }`;
- a plain call `F(…)` was rejected;
- an object the constructor returned was ignored.

Under strict TypeScript, a function is constructed through a cast, `new (F as any)(…)`. It threw "F is not a constructor".

## Decision

1. **Recognition in both lanes.** A top-level function that a `new` expression names is a constructor function, in either lane. A name under `as` or `!` counts too (`protoCtorCallee`). Under `-compat=js` a `.prototype` write also marks one.
   - A function declared with a `this: T` parameter (the strict form) takes the new object there, with no hidden receiver (`protoCtorOwnThis`).
   - A constructor function's non-void return type is `any`.
2. **`x instanceof F`** tests whether F's prototype object is on x's chain (`emitProtoCtorInstanceOf`).
3. **`F.prototype.constructor`.** At program start, each prototype object gets a non-enumerable `constructor` that is F itself (`seedProtoCtorConstructors`, `__kml_dynobj_set_hidden`).
4. **Inspection.** A dynamic object is named by util.inspect's rule (`ctor_name`, `dynjson.c`): the name of the `constructor` owned by the nearest prototype on its chain, with no prefix for Object. The object's own `constructor` property is skipped, since Node only uses a constructor the object is an instance of.
5. **A plain call `F(…)`** passes globalThis as `this`, as a sloppy-mode call does. The resolver links the global-object module for a program that both constructs and plainly calls one of its functions (`ctorFunctionCall`). Without that module, the receiver is `undefined`.
6. **`new F(…)` whose body returns an object** gives that object as the result.

## Verification

macOS (Apple Silicon): the probes match Node's output in both lanes. `TestE2EJSFunctionConstructors`, which uses Node as the oracle, and `TestE2EFunctionConstructorTS` both pass. So do the existing Stage 4 tests, except the plain-call rejection test, which is replaced by the oracle test.
