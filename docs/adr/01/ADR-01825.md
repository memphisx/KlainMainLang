# ADR-01825: A destructured key or array member a type lacks is TS2339

- **Relations**: `Implements TDD-00230`, follows ADR-01824
- **Date**: 2026-10-20

## Context

- ADR-01824 routes a named member of a static array through its box, so codegen no longer rejects `arr.qq` on a `number[]`. The checker never reported it: `checkProperty` modelled only object, interface and instance types.
- The checker never checked an object destructuring pattern's keys against its source type. `const {zz} = o` and `function f(...{x}: number[])` compiled, where tsc reports TS2339.

## Decision

- `arrayLacks` reports a named member of an array or tuple type that neither TypeScript's own `Array` (lib/tsmembers.txt) nor any declaration of the global `Array` (the builtin declarations, a `declare global` augmentation) has. Index names are exempt.
- `checkPatternProps` checks each named key of an object pattern against its source type, as `checkProperty` checks a member read, through nested patterns: a destructuring declaration against its initializer's type (an object literal initializer excepted), a destructured parameter against its annotation.

## Consequences

- `TestE2EPatternMissingPropertyRejected` covers both, and `TestE2ERestDestructuredParamRejected` passes again.
- A destructuring *assignment* (`({ zz } = o)`) and an object-literal initializer are not checked yet.
