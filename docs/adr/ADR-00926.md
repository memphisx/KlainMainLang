# ADR-00926: `--run` — compile and execute immediately

- **Date**: 2026-09-13

## Context

During development the compile → locate-binary → execute loop is repetitive.
Other native-via-toolchain tools (`go run`, `deno run`) offer a one-shot
compile-and-run. A `--run` flag gives the same ergonomics here, and is the
foundation for a future watch mode (recompile+rerun on `.ts` change).

## Decision

`--run`: after a successful host build, execute the freshly-built binary,
forwarding the arguments given after the filename, propagate its exit code, then
delete the temporary build artifacts.

- The binary is built into a fresh `os.MkdirTemp("klainrun-*")` directory (an
  explicit `-o` is ignored in this mode), so the source tree is never littered;
  the directory is `RemoveAll`'d after the run.
- Program arguments are `flag.Args()[1:]` (everything after the filename); a
  single leading `--` separator is dropped. Flags still precede the filename
  (Go's flag parser stops at the first non-flag argument).
- stdin/stdout/stderr are inherited. The child's exit code becomes klainmain's
  exit code (via `*exec.ExitError`).
- Rejected combinations: `--target` (a cross-built binary can't run on this
  host) and `-emit-llvm` (stops before an executable exists).
- The run happens before the lazy-island / packaging / `.d.ts` steps, which
  `--run` does not use.

Watch mode (monitor the entry and its imports, recompile+rerun on change) is a
deliberate follow-up, layering on this same execute path.

## Verification

- `tests/run_flag_test.go` (new): a program run via `--run` emits its stdout and
  propagates exit code 4, with no binary left in the source dir; `--run
  --target` is cleanly rejected.
- Manual: argument forwarding and temp cleanup confirmed; macOS arm64.

## Note (discovered in passing → fixed)

`process.argv` on a compiled binary was `[exePath, ...userArgs]` — one entry
short of Node's `[execPath, execPath, ...userArgs]`, so `process.argv.slice(2)`
dropped the first user argument. Found via `--run` argument forwarding; fixed in
ADR-00927 (not deferred).
