# ADR-01892: a static generator method's destructured parameter

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

- A static generator method's body moves to a lifted generator declaration and the method becomes a forwarder. The oracle's check for a leaf of a generator's destructured parameter (read as its boxed storage) resolved the name to the rewritten method, no longer a generator, so it typed `x[0]` from the checker as a number while codegen stored a box: `typeof x[0]` printed `undefined`, and the shadow report's largest bucket disagreed on the element type.

## Decision

- The lift records each method's generator, and the leaf check resolves a lifted method to it.

## Consequences

- Static generator methods with patterned parameters read their elements correctly; about 440 shadow rows go away.
- Verified on Apple Silicon against Node.
