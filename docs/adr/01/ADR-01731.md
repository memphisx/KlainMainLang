# ADR-01731: A namespace import read as a value

- **Relations**: `Implements TDD-00230`, Extends [ADR-00135](../00/ADR-00135.md)
- **Date**: 2026-10-18

## Context

A namespace import (`import * as ns from "./m"`) existed only at compile time: `ns.member` was rewritten to the member's declaration. Reading `ns` any other way failed:

- `typeof ns`, `const p = ns` and `ns["x"]` were "cannot find name 'ns'";
- `typeof ns` in a type position failed the same way;
- `typeof crypto` worked only because a global `crypto` exists.

In Node, `ns` is the module namespace object.

## Decision

- **The object:** the resolver declares, at the top of the importing file, one `const` per namespace import that is read as a value. It holds `Object.freeze({ … })` of the module's value exports, keyed in sorted order as Node's namespace object is. Interfaces and type aliases are not members.
  - The checker types the call as written.
  - Codegen builds it (`ModuleNamespaceIntrinsic`, `moduleNamespaceRule`) as a dynamic object marked a module namespace (header bit 36): null prototype, sealed, its properties writable but every write rejected, `[object Module]` to `Object.prototype.toString`, printed `[Module: null prototype] { … }`.
- **Reads:**
  - `ns.member` still resolves to the member's declaration directly;
  - any other read of `ns`, and `typeof ns` in a type, name that object;
  - an import whose namespace is never read as a value declares nothing.
- **Positions:** the declaration's nodes carry the import statement's position.

- **Rejected writes, found on the way:** a rejected write or delete on any dynamic or static object now throws V8's message, built at run time from the object (`__kml_dyn_set_throw`, `__kml_static_set_throw`). The forms are `Cannot assign to read only property 'a' of object '#<Foo>'`, `Cannot add property z, object is not extensible` (the key unquoted) and `Cannot delete property 'a' of [object Object]`. Before, every object read `#<Object>`, and deleting a property of a frozen or sealed static object succeeded.

## Verification

macOS (Apple Silicon), against Node:

- **`tests/namespace_value_test.go` TestE2ENamespaceImportValue:** `typeof`, `Object.keys` order, a value copy, `Object.isFrozen`, `ns["b"]`, `in`, a `typeof ns` parameter and variable, a program module and `path`.
- **`tests/namespace_value_test.go` TestE2ENamespaceImportObject:** `console.log`, the tag, `isFrozen`/`isSealed`, the prototype, the three rejected writes and the property descriptor, as Node prints them.
- **`tests/builtin_prototype_test.go` TestE2EReadOnlyMessages:** writes, additions and deletes on a frozen literal, a frozen null-prototype object and a frozen class instance; a getter-only property; a sealed object.
- **Removed:** `TestE2ENamespaceImportBareUseRejected`, which expected the old rejection.
- **Import, re-export and resolver tests** pass.
