# ADR-01789: A generator's value type joins its returns; boxed element calls are dynamic

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- An unannotated generator's value type was the join of its yields. A return value was consulted only when there were no yields, and then only top-level returns. `function* g() { yield 1; return g; }` converted `g` to a number, and the final `next()` gave NaN.
- `[function* () {}][0]()` inferred as a number, so `.next()` on it failed to compile ("a number has no method 'next'"). The element is held boxed, and a call through it is a dynamic call.

## Decision

- `inferGeneratorElemType` joins every return value in the body (`returnExprs`) with the yields. A type of another representation makes the value type `any`.
- `structuralCallType` types a call whose callee is an index expression holding a dynamic value as `any`.

## Consequences

- `TestE2EJSFileGeneratorReturnValues` compares mixed yield and return values, spread and `Array.from` over such a generator against Node.
