# ADR-01453: Absent elements in a scalar array literal stay absent

- **Relations**: none
- **Date**: 2026-10-07

## Context

`const c = [1, null, undefined]` was built as a `number[]`: the null and
undefined elements read back as `0`. TypeScript types it
`(number | null | undefined)[]`, and Node prints `[ 1, null, undefined ]`.

## Investigation

`inferArrayType` made a literal's element type nullable only for a pointer
element; a scalar kind kept its plain representation and the absent
elements were coerced to its zero.

## Decision

A literal of one kind mixed with null and undefined has that kind's
absent-holding form: `T | null` (nullable), `T | undefined`
(`undefinedableElem`), or both (`withNullAndUndef`) for a scalar, and for a
string or object the three-state pointer when both appear.

## Verification

- `TestE2EArrayNullishElementsJoin` (against Node).
