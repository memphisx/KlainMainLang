# ADR-01779: Generators take destructured parameters

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- A generator function or method with a destructured parameter was rejected at compile time. Its `__paramN` slots hold plain values only.
- In the spec, a destructured parameter is bound at the call (FunctionDeclarationInstantiation). A bad argument throws from the call, and an iterable argument is iterated before the generator first resumes.

## Decision

- `desugarGeneratorPatternParams` renames each destructured parameter to a hidden plain one, keeping its type (`any` when unannotated) and default. It records a `let <pattern> = <hidden>` statement per declaration (`genPatternInits`).
- The body's start runs those statements after the parameter defaults and before the eager start suspension (ADR-01774). So the destructuring happens at the call.
- The yield-type pre-pass binds the pattern's names as `any`.

## Consequences

- `TestE2EJSFileGeneratorDestructuredParams` and `TestE2EGeneratorTypedDestructuredParams` cover array and object patterns, defaults, rest elements, async generators, a throw at the call, and evaluation order.
- A yield of a destructured name makes an unannotated generator's element type `any`.
