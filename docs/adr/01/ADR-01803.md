# ADR-01803: A bare `yield` yields undefined

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- Generator element inference (`inferGeneratorElemType`) skipped a `yield` with no operand. A generator whose only yields were bare got the default number element, so `next()` gave `{ value: 0 }`, and `yield 1; yield;` yielded 0 for the second. Node yields undefined. Test262's `yield-newline` and `yield-as-statement` hit this.

## Decision

- A bare, non-delegating `yield` makes an unannotated generator's element any, which carries undefined.

## Consequences

- `TestE2EJSFileBareYieldUndefined` compares a line-break-ended `yield`, mixed bare and valued yields, and spreading against Node.
