# ADR-01414: Class fields keyed by a declared symbol

- **Relations**: Implements TDD-00246; Extends ADR-01411, ADR-01410
- **Date**: 2026-10-05

## Context

TDD-00246: `class T { [kRefed]: boolean = true }` with `const kRefed =
Symbol('refed')` was rejected, so the timers port (ADR-01411) kept its
symbol-keyed state as per-object expando properties.

## Decision

- **Parsing and binding.** A class field whose computed key is an identifier
  keeps it (`AnnotField.Key`); the binder binds it where the class is
  declared, the resolver renames it with the rest of the program, and the
  generated AST walker visits it. A method keyed by an identifier stays a
  rejection.
- **Naming.** Before code generation (`lowerSymbolFields`) such a field is
  named `"\x01@@symf:" + description + "\x02" + binding`: the leading \x01
  makes every string enumeration skip it as a symbol's key, the binding
  keeps two symbols of one description apart, and the description is the
  const's `Symbol('…')` literal.
- **Access.** Each `obj[k]` whose key is such a const and whose receiver the
  checker types as an instance of a class with that field, or a subclass of
  one, becomes the field's member access, so reads, writes and compound
  assignments take the static paths. Through `any`, the class's shape
  `get`/`set` match the field also by the symbol's own run-time key
  (`__kml_key_is_sym`, comparing against the const's module global).
- **Reflection.** `Object.keys`, `for…in` and `JSON.stringify` leave the
  field out (`VisibleFields`; the boxed key array now skips every symbol
  key, a run-time symbol property's included); `util.inspect` lists it as
  `Symbol(description)` after the string keys, on the static and the
  dynamic path.
- `lib/node/internal_timers.ts` declares its five (`Timeout`) and four
  (`Immediate`) symbol-keyed fields.

## Consequences

Arming and clearing 200,000 timeouts on the Mac (M4) peaks at 103 MB instead
of 235 MB under the default memory mode. Still open in TDD-00246: methods keyed by a declared
symbol, the checker's `unique symbol` identity, `Object.getOwnPropertySymbols`,
and spread copying such a field.
