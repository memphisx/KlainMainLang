# ADR-01839: IndexExpression switched to the checker

- **Relations**: `Implements TDD-00230` (P3.3: the checker answers what inferExprType did)
- **Date**: 2026-10-20

## Context

Ahead of switching IndexExpression, its disagreements came down to four shapes:

- `[,,,1,2][0]`: the literal with holes is held with boxed elements, but the oracle read a bare `number`.
- `[22, 33]?.[i]`: the receiver can never be nullish, so the read is a plain element read, yet the oracle gave no answer for any optional index.
- `A.prototype[1]`: a class method read through a literal key is its boxed function record, as a `.m` read already was.
- `process.env[k]`: a string or undefined, as `process.env.K` already was.

`a || b` on a three-state pointer left also kept the left side's null/undefined marker, which emission keeps only for `&&`.

## Decision

- An index read off an array whose held element type is a box is that box.
- An optional index on a receiver that cannot be nullish is answered like a plain index.
- A literal key (a string, or a plain decimal integer) that names a program class's method reads a boxed method value.
- `process.env[k]` is a string-or-undefined slot.
- The three-state rule applies to `&&` only.
- A record whose index signature declares tuples (`{ [k: string]: [number, number][] }`) is held with those tuples, as with any other annotation that declares one. Its value read is the declared tuple array, or undefined for a missing key.
- IndexExpression joins the switched kinds: emission takes the checker's answer. A node the checker never saw falls back to `structuralIndexType`, which is the old index case moved out of the old inference (from the receiver's representation and the dispatch emitIndex runs), the same way Member and Call already fall back.

## Consequences

- All 37 IndexExpression rows from the previous full shadow run are gone, and outputs match Node.
- Before the record rule, switching segfaulted `TestE2EAnyIntoTuplesAndNestedArrays`, because a function-local record of tuples was read as nested arrays.
- Verified on Apple Silicon (targeted index/optional/tuple/record/typed-array/buffer/any tests). The gate runs on Linux x86-64 (DeskMini).
