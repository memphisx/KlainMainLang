# ADR-01331: Builtin statics dispatch through their declarations

- **Relations**: Implements TDD-00230 (P3.2), Extends ADR-01315, ADR-01307
- **Date**: 2026-10-02

## Context

[TDD-00230](../tdd/TDD-00230.md) P3.2 routes builtin calls through their
declarations. [ADR-01315](ADR-01315.md) did Map, Set and Date with
`@intrinsic` keys naming their existing emitters. The `Object` statics were
still a by-name switch in `emitCall` and a second one in `inferExprType`,
and `ObjectConstructor` in `lib/es.d.ts` declared 15 of the 21 statics the
switch handled: `groupBy`, `hasOwn`, `defineProperty`, `defineProperties`,
`getOwnPropertyDescriptor`, `preventExtensions` and `isExtensible` had no
declaration. The checker's open-member rule for library globals let a call of
an undeclared one through untyped: `const x: number = Object.groupBy(…)`
compiled, where TypeScript reports TS2322.

## Investigation

Probes against Node 24.19 while moving the statics:

- `Object.groupBy` returned its own representation (`IsGroupMap`, a C bucket
  map): `console.log` printed an empty line, `g.odd` was a compile error, a
  number-keyed selector was rejected, and a nested-array element was rejected
  ([ADR-00152](ADR-00152.md)). Node returns a null-prototype object of
  arrays.
- `Object.getOwnPropertyDescriptor` and `Object.getOwnPropertyNames` of a
  statically typed object, or of one boxed in `any`, were a compile error or
  a TypeError.
- `Object.isFrozen`/`isSealed`/`isExtensible`/`preventExtensions` of a
  primitive were a compile error; Node answers `true`/`true`/`false` and
  returns the value.
- Codegen synthesizes two `Object` calls itself
  (`Object.prototype.hasOwnProperty.call` and `propertyIsEnumerable.call`).
  A synthesized node has no checker declaration.

## Decision

1. `ObjectConstructor` declares every static TypeScript's library does,
   with TypeScript's signatures, plus `PropertyKey`, `PropertyDescriptor`
   and `PropertyDescriptorMap`. Each static except `is` (already `@lower`)
   carries `/** @intrinsic Object.<name> */`.
2. The by-name blocks are deleted. `emitObjectStatic` and
   `objectStaticType` are the one emitter and the one type answer behind the
   `Object.*` intrinsics. The two synthesized calls call `emitObjectStatic`
   directly (`propertyIsEnumerable` binds the keys it reads with
   `bindValue`).
3. An intrinsic call ignores explicit type arguments
   (`Object.freeze<C>(o)`): `loweredCall` rejects them only for `@lower`
   targets, whose marshalling reads the signature.
4. `Object.groupBy` builds a null-prototype dynamic object whose values are
   dynamic arrays of the boxed elements, keys in first-seen order, a
   non-string key converted with ToString. The group map, its C runtime
   and every `IsGroupMap` branch are deleted.
5. A static object boxed or not answers `getOwnPropertyDescriptor` through
   its layout (`__kml_shape_own_desc`, `shapesrc/shape.c`): a data
   descriptor of an own field, `writable`/`configurable` from the integrity
   level `Object.freeze`/`seal` recorded; a class method is not own.
   `getOwnPropertyNames` reads the layout's keys.
6. The integrity statics answer a primitive's constants.
7. `JSON.parse` and `JSON.stringify` carry `@intrinsic` keys too. An
   overloaded method whose overloads all name one intrinsic takes it
   without resolving the overload (`methodIntrinsic`); `Response.json`
   stringifies its data directly instead of through a synthesized call.
8. `Reflect` is declared as TypeScript's `declare namespace Reflect`, plus
   the reflect-metadata functions decorator metadata uses, each with an
   `@intrinsic` key naming `emitReflectCall`. The parser now reads
   `@intrinsic` on an ambient namespace's function, and the checker records
   the declarations of a builtin global namespace's member (it did so only
   through `globalThis`).
9. `Symbol.for`/`keyFor`, `Date.now`/`parse`/`UTC`, `ArrayBuffer.isView`,
   `BigInt.asIntN`/`asUintN`, the `Buffer` statics and `Atomics` carry
   `@intrinsic` keys. `Atomics` and `BigInt` are declared with TypeScript's
   signatures, so the checker now reports their argument errors as tsc
   does (`Atomics.wait(ta, "1", …)` is a strict-lane error, as in tsc).
10. The `console` methods carry `@intrinsic console.<name>` keys, reached
    through `Console`'s declaration whatever names the receiver.
11. `fetch`, the timers, `process.nextTick`, `crypto.getRandomValues`,
    `crypto.randomUUID`, `queueMicrotask` and `structuredClone` (now
    declared, with TypeScript's signature) carry `@intrinsic` keys. `gc`
    stays by name: Node declares it as a variable, not a function.
12. `Array.isArray`/`of`/`from`, `ReadableStream.from` and
    `Response.error`/`json`/`redirect` carry `@intrinsic` keys. A call the
    compiler synthesizes itself (spread lowering's `Array.from`) has no
    checker declaration, so `ast.CallExpression.Intrinsic` names its
    builtin directly and `loweredCall` honours it first.
13. Any builtin method with an `@intrinsic` key is a function value
    (`[1, 2].forEach(console.log)`, `p.then(console.log)`,
    `const f = console.log`). The objects whose members may be one are no
    longer a hand-kept list: the intrinsic keys name their owners.
14. `String`, `Number`, `Boolean`, `Symbol` and `BigInt` called as
    functions carry `@intrinsic` keys on their interfaces' call signatures
    (`ast.CallSignature.Intrinsic`); `loweredCall` takes the key every call
    signature of a builtin global's type names. Each is a function value
    (`.map(Number)`, `const s = String`), which retires the callback-only
    conversion kind. A constant bound to a builtin (`const n = Number`)
    reads and calls the builtin's own members through the bound global
    identifier. Calls codegen synthesizes (`String(key)`) name the
    intrinsic directly.
15. The `Promise` statics stay by name for now. Their declarations lean
    on `Awaited` and mapped tuple types the checker does not model yet;
    they move once it does.

## Side effects discovered

- A member of a function value was read as an expando property unless a
  merged namespace declared it, so `String.fromCharCode(c)` became a
  dynamic call once `String` was a function value. A member the checker
  finds on the value's declared interface is not an expando.
- A builtin function value's return type was unknown to a higher-order
  call's inference (`const r = [4, 9].map(Math.sqrt)` typed `r` as the
  receiver's element type), and `Array.of` used as a value forwarded a
  spread its emitter rejected and returned an aggregate where the array
  return ABI is a header.

- `Object.freeze`, `seal` and `preventExtensions` of an array were a
  compile error. An array's level is now recorded in the frozen set keyed
  by its shared header (`collectionssrc/arrayguard.c`). Every mutation
  checks it: `push`, `pop`, `shift`, `unshift`, `splice`, `length` writes,
  indexed and compound element writes, `sort`, `reverse`, `fill` and
  `copyWithin`, and an `any`-held array's indexed write and method view.
  Each rejection is the strict-mode TypeError V8 throws. The check is one
  load of a flag that only the first array level sets, so the text of
  library code does not depend on whether the program freezes arrays. A
  typed array with elements cannot be frozen or sealed, as in V8;
  `isFrozen`/`isSealed`/`isExtensible` answer from the level and length.
- A type literal with one member the checker cannot answer (`Response`'s
  `HeadersInit` reaches `Record`) was unanswered whole, so the value typed
  `any` and `Response.json(...)` dispatched on a number. A type literal
  now keeps its answered members; an unanswered call or construct
  signature marks it partial instead.

## Verification

- macOS (Apple Silicon): `TestE2EDescStaticObjectDescriptor`,
  `TestE2EObjectGroupByNullPrototype`, `TestE2EArrayIntegrity`,
  `TestE2EArrayIntegrityAliases`, the `Object`, descriptor, array, assert,
  util, JSON and HTTP client tests; probes matching Node 24.19 output (the
  array integrity probes against `node --input-type=module`, strict mode);
  `examples/objects/group_by.ts` matches Node. A probe that panicked on the
  old by-name path found it reached only from the two synthesized calls.
- Linux (Node304): `make test-par` green, 3,781 tests (before the JSON and
  Reflect steps).
- Linux (DeskMini): `make examples` 379/379 after each step through
  `console`; `make conformance` strict
  7,992/53,578 (from 7,945), js 9,492/53,578 (from 9,449).
