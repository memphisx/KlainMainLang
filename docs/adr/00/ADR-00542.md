# ADR-00542: `klain:sync` Stage 2 — cooperative preemption (sysmon + safepoints)

- **Relations**: `Implements TDD-00143`, `Extends ADR-00541`
- **Date**: 2026-09-01

## Context

Stage 1 ([ADR-00541](ADR-00541.md)) delivered the GMP scheduler, `go`, and
channels, but a goroutine that never blocks on a channel could monopolise its M
indefinitely — with `GOMAXPROCS=1`, a single tight `while (true)` loop starved
every other goroutine. TDD-00143 Stage 2 closes this with Go's tier-1
(cooperative) preemption: a `sysmon` thread that flags a long-running goroutine,
plus compiler-inserted safepoints at function entry and loop back-edges that
honour the flag. (Tier-2 signal-based async preemption for safepoint-free code
is Stage 4.)

## Investigation

The Stage-1 runtime already had the hook: `klainsync_safepoint` checks a
per-G `preempt` flag and yields via `gosched`. Two pieces were missing — the
thread that sets the flag, and the compiler emitting the checks.

A standalone repro (`GOMAXPROCS=1`, a spinner goroutine calling the safepoint in
a loop plus a sender goroutine) exposed a scheduler bug that had to be fixed
before preemption could work: `gosched` re-enqueued the yielding G onto its P's
**local** run queue, which `ks_findrunnable` drains before the global queue — so
the just-yielded spinner was immediately re-picked and the sender (sitting in the
global queue) never ran. The yield must return the G to the **global** queue.

## Decision

- **sysmon** (`klainsyncsrc/klainsync.c`): a background thread (not a P/M, runs
  no managed code, not GC-registered) that wakes every ~2ms and, for each M
  whose current G has been running longer than a 10ms budget, sets that G's
  `preempt` flag. Each M records its current G and a monotonic start timestamp
  in `ks_execute`; these plus `preempt` are `_Atomic` (sysmon reads them cross-
  thread — a stale read costs at most one spurious, harmless yield).
- **Safepoint-insertion pass** (codegen): `emitSafepoint` emits
  `call void @klainsync_safepoint()` at **function entry** (named functions,
  arrows, function expressions) and at every **loop back-edge** (the `cond`
  label of `for`/`while`/`do-while`, hit each iteration). Gated on
  `usesSyncProgram`: a program that does not import `klain:sync` emits nothing
  and links nothing.
- **Exact upfront gating**: the resolver records `Program.UsesKlainSync` when
  any file imports `klain:sync` (a shallow top-level import scan, like
  `WorkerModules`), so codegen decides before emitting any body — and forces
  `ensureSyncRuntime` so the `call @klainsync_safepoint` sites always resolve.
- **Scheduler fairness**: a yielding G goes to the global run queue, and
  `ks_findrunnable` polls the global queue first every 61st schedule (Go's
  heuristic) so a P with steady local work can't starve the global queue.

## Implementation notes

- Placing the safepoint at the loop's `cond` label makes it the true back-edge
  check (the back-edge branches to `cond`), covering `for (;;)` and
  `while (true)` with no test expression.
- `emitSafepoint` is a no-op when `blockDone` (after a terminator), so it never
  produces dropped-dead-code or a double-terminator.
- The 10ms budget / 2ms sysmon tick mirror Go's defaults closely enough for the
  starvation guarantee without measurable overhead.

## Side effects discovered

- The gosched-to-local-queue starvation bug (above) was latent in Stage 1 —
  `gosched` was unreachable there (preempt was never set) — and would have
  surfaced the moment any yield path ran. Fixed as part of this stage.

## Verification

- Standalone C repro: a `GOMAXPROCS=1` spinner + sender now completes
  (`received 42`); the scheduler stays clean under ThreadSanitizer with sysmon
  running.
- E2E `TestE2EGoroutinePreemption`: a TS goroutine in an infinite `while (true)`
  tight loop is preempted so the sibling's channel send completes, under
  `GOMAXPROCS=1` with a hang-catching timeout. A non-`klain` program's IR
  contains zero safepoint references (isolation verified).
- Stages 3–5 (`select`, blocking-syscall P-handoff, async signal preemption,
  growable stacks) remain.
