# ADR-01419: Element access by a const symbol or literal key in the checker

- **Relations**: Implements TDD-00246; Extends ADR-01414
- **Date**: 2026-10-05

## Context

A class field keyed by a declared symbol (`[kRefed]: boolean`) compiled,
but the checker typed `this[kRefed]` as nothing it could check:
`const s: string = this[kRefed]` passed the checker and failed later in code
generation ("initializer's type is incompatible"), and `t[kOther]` for a
symbol the class does not key passed both, where tsc reports TS2322 and
TS7053. A string key naming no member (`t['nope']`) was likewise left to code
generation.

## Decision

- `accessKey` (the checker's constant key of an element access) reads a
  const initialized by `Symbol(<string literal>)` or `Symbol()` as the
  member name `ast.SymbolMemberName` gives its member, so `this[kRefed]`
  is that member and its declared type.
- TS7053: an element access by a constant key (a string or number literal, a
  const holding one, a const symbol) on an object literal type, interface or
  class instance the checker models whole, that names no member and is not
  covered by an index signature (a symbol key by none), is reported with the
  key's type (`"nope"`, `unique symbol`), as tsc reports it under `strict`.
  The types `checkProperty` leaves alone (library types, callable and merged
  declarations) are left alone here too.

## Side effects discovered

- `lib/node/internal_timers.ts` declared `Timeout`'s `[kRefed]` as
  `boolean | null` and returned it from `hasRef(): boolean`, now a type
  error. Node's constructor always assigns a boolean: the field is `boolean`.
- A key read by a numeric literal was compared by its text (`0x10`, not
  `16`), which TS7053 would misreport: ADR-01420.

## Verification

Mac (M4): `TestE2ETypeErrorElementAccessKey` (TS2322 through a symbol
member, TS7053 for a symbol and a const string key, and index-signature,
numeric, literal and `Object.prototype` accesses accepted); the checker's
tests under the guard; `go test ./lib/... ./resolver ./sema ./binder`.
