# ADR-01941: The dynamic object's header joins the shared scheme and reserves a shape word

- **Relations**: Implements TDD-00230, Extends ADR-01939
- **Date**: 2026-10-28

## Context

TDD-00230 Phase 5 asks that:

- a dynamic object's flags (null prototype, frozen, sealed, Proxy) live in the one header word every boxable object starts with;
- a dynamic object reserve a shape word for hidden classes (TDD-00220);
- a string's header carry its encoding.

Before this change, a dynamic object's first word held its own magic, "KMLD", in the low 32 bits and six flags in bits 32–37, so it could not be told apart by the header scheme's magic. `shape.c` and two generated tests found a bag by those low 32 bits alone.

## Investigation

- **Who reads the Bag word:**
  - Only `dynobj.c` makes a bag; `emitNewProxy` makes a Proxy header in Go.
  - The flags are read in `dynobj.c` (through `F_*`), in `dynjson.c` (literal `1LL << 33`–`36` tests) and in `shape.c` (`is_bag`).
  - On the Go side, `emitIsBagPtr` and the foreign-layout test in `emit_record_view.go` read it.
- **Type id 1:** no header uses it today (per-program ids start at 2^16). An Error header of kind 1 has the same low bits under its own flag, so a bag test masks the kind flags as well.
- **`__kml_shape_of` on a bag** looks up shape id 1, which is never registered, so it still answers "no shape".
- **The other header tests** decide on the magic only for tag-6 payloads. A bag reaches one only through a structural type, where it now reads as headered rather than as a headerless dictionary.
- **Strings:** a string's header keeps bit 32 clear, which no object header has (the magic sets it), so it is already told apart exactly. Its UTF-16 count (bits 33–62) equals its byte length exactly when the text is one-byte, so the encoding is already exact too.
- **Side effect:** a Proxy over an array target (ADR-01939) was followed to a NULL target bag by `JSON.stringify` and util.inspect.

## Decision

- **The header word:**
  - A bag's header word is `kmlBagHdr`, the header magic with type id 1 (`kmlTypeIDBag`).
  - Its flags move above the shared bits: non-extensible 55, Proxy 56, null prototype 57, array exotic 58, module namespace 59, a function's bag 60. `kml_heap.h` names them `KML_BAG_*`, and `objheader.go` documents the bits.
  - A bag test is `KML_IS_BAG_WORD` / `emitIsBagPtr`: the word masked with the magic, the id and the kind flags.
- **The shape word:** the Bag grows a reserved `shape` word at offset 48, zero until hidden classes use it.
- **Readers:**
  - `dynjson.c` names the flags instead of spelling bits.
  - The foreign-layout test drops its separate bag clause, since a bag's header carries the magic.
- **Strings:** the string header is unchanged. Its kind and encoding are exact as described above, and `kml_heap.h` documents both.
- **Array-target Proxy:** `JSON.stringify` and util.inspect render a Proxy whose target is no dynamic object as the target itself, as Node's `IsArray` and inspect see through it.

## Implementation notes

- **Header bits and Bag layout:** `kmlheapsrc/kml_heap.h`, `objheader.go`, `dynobjsrc/dynobj.c`, `runtime_dynobj.go`.
- **Bag readers:** `shapesrc/shape.c`, `dynjsonsrc/dynjson.c`, `emit_reflect.go`, `emit_record_view.go`.
- **Test:** `tests/dynstage67_test.go`.

## Side effects discovered

The array-target Proxy rendering above.

## Verification

- A probe covering a Proxy over an array (reads, a write, `in`, `JSON.stringify`, inspect), a null-prototype object, `Object.preventExtensions` and `Object.freeze` matches Node.
- `TestE2EProxyArrayTarget` covers the rendering.
- The Proxy, dynamic-object, freeze, null-prototype and structural-view E2E suites pass, as do the `codegen/llvm` unit tests. Verified on the Mac.
