# ADR-01318: Classes and builtin constructors are values; `new` takes any constructor expression

- **Relations**: Implements TDD-00230 (P3.2), Extends ADR-01317
- **Date**: 2026-10-01

## Context

BACKLOG 81: `new K()` with `K` a class held in a `let`, a parameter or `any`
was "unknown class", and a builtin constructor (`Map`) was not a value at
all. ADR-01317 covered only a constant alias (`const K = C`). Probing the
rest turned up a cluster of gaps around the same thing, a constructor used as
a value:

- `let K: typeof A = A` stored a number: the checker had no case for a
  `typeof` type query in an annotation (it answered `any`), and the resolver
  never renamed a bare `typeof X` annotation's name, so codegen missed the
  class.
- `new ctors[0]()` parsed as `(new ctors)[0]()`: the parser took only a name
  or a dotted name after `new`.
- `new this.K()` and `new obj.K()` with `obj` a value were rejected.
- Statics through a class value (`K.make()`, `K.count = 5`) read undefined or
  threw.
- A generic `function mk<T>(c: new () => T)` could not infer `T`, and a
  generic's type argument could not be a Map, Set, function or promise.
- A class expression used as a value (an argument, a return value, a nested
  binding) was rejected, and a named one bound at top level lost its own
  name and its self-references.
- Pre-existing, found on the way: assigning an inherited static through a
  subclass (`B.n = 5`) overwrote the base's value, where JavaScript gives
  `B` an own property; a class's `length` counted an inherited or implicit
  constructor's parameters; `Object.keys` of a class was empty.

## Investigation

- A class in value position was already a boxed constructor reference: tag
  `kmlTagFuncRef`, the payload a per-class string constant
  (`emit_classref.go`), used by `instanceof` and util.inspect. A builtin
  Error kind used the same tag with its interned name as the payload.
- `emitNewExpression` (`emit_classes.go`) dispatched only on a class name.
  The `instanceof` precedent (`__kml_dyn_instanceof`) is a generated function
  that compares the payload against every class used as a value and runs the
  static test of the matching one. Construction can do the same.
- Representing `typeof C` as its own codegen type was considered and
  rejected: a constructor reference is already `any`-shaped (a NaN-boxed
  word), and the checker supplies the instance type at each `new` site.
- tsc types `new x()` with `x: any` as `any`, and `typeof base` with
  `const base = 42` as the literal `42`.

## Decision

1. **Construction through a value.** `new X(args)` where `X` is not a class
   name (a local, a parameter, `any`, a member, an index, a call) boxes its
   arguments into an array and calls the generated
   `i64 __kml_dyn_construct(i64 ctor, ptr argv, i64 argc, ptr msg)`. Per
   class used as a value it emits `new <Class>(…)` over the boxed arguments
   (a missing one is `undefined`). Per builtin used as a value it emits one
   arm per argument count, lowered through sema's builtin table; `Promise`'s
   executor is called through its boxed value. Anything else throws
   `TypeError: <expr> is not a constructor`, with the expression's source
   text as Node prints it. The result converts to the checker's instance
   type when that is a class, and is otherwise `any`. The dispatcher is
   emitted before main's event-loop epilogue, so the runtime flags its arms
   set (a Promise's microtasks) are seen.
2. **`new` takes a member expression.** `NewExpression.Callee` holds the
   constructor when it is not a name or a dotted name (`new this.K()`,
   `new a[i]()`, `new (f())()`); `ClassName` is then empty. A dotted name
   whose qualifier is a value (`new obj.K()`) takes the same path.
3. **Builtin constructors are values.** A name sema lowers as a builtin
   `new` (`Map`, `Set`, `Date`, `URL`, the Error kinds, …) and `Promise`
   box as constructor references carrying their name. Sema follows
   `const M = Map` to the builtin, so `new M<K, V>()` is still the static
   construction.
4. **`typeof` in type position.** The binder records the scope each
   `typeof x` in an annotation (variable, parameter, result, field) is
   written in. The checker answers the query from that scope, so a local
   shadows the top level, a `const` gives its literal type and an unknown
   name is TS2304, as in tsc. The resolver renames a top-level query's name
   with the module's other names. Codegen's own fallback for types reprOf
   does not cover yet takes a local in scope before the top level. A
   `typeof Class` binding is stored as the constructor reference.
5. **Statics through a class value.** Generated
   `__kml_classref_get(ptr, ptr key)` and `__kml_classref_set(ptr, ptr key,
   i64 v)` read and write a class's statics (fields, methods as values,
   accessors, `length`) through its reference. `Object.keys` of a class lists
   its own static fields.
6. **Inherited statics.** A class inheriting a static field gets its own
   storage and an "own" flag. A read takes the nearest class in the chain
   that has assigned the field, else the declaring class. A write goes to
   the class written through and marks the field its own. `B.n ||= x` is
   `B.n || (B.n = x)`. util.inspect and `Object.keys` list an inherited
   field once it is the class's own.
7. **A class's `length`** is its own constructor's parameters before the
   first defaulted or rest one; an implicit constructor's is 0.
8. **Generics.** A parameter typed `new (…) => T` infers `T` as the instance
   type of the class or builtin the argument names. A constructor type is a
   constructor reference in codegen. Any type may be a type argument; types
   outside the old named set mangle by a hash of their shape.
9. **Class expressions as values.** A class expression whose body names no
   binding of an enclosing function is hoisted to a top-level class under a
   name of its own (`<name>__kml_cxN`), and the expression becomes its
   constructor reference. An anonymous one takes its binding's name
   (`const K = class {}` is `K`; JavaScript's NamedEvaluation). A named one
   bound at top level keeps its own name for `.name` and inspect, and its
   self-references are renamed to the binding's class. A class expression
   that reads a local of its enclosing function is a clean rejection naming
   the local.
10. **`Error` subclasses** may redeclare one of this compiler's system-error
    slots (`code`, `errno`, `syscall`, …: properties Node's `Error` does
    not have) with their own type. The system slot steps aside under an
    internal name (BACKLOG 110, first half).

## Implementation notes

- `codegen/llvm/emit_classref.go`: `dynNewInstanceType`, `emitDynNew`,
  `emitDynConstructDispatch`, `emitHostConstructArms`, `constructedType`,
  `emitClassRefGetDispatch`/`emitClassRefSetDispatch`, the run-time
  static-key table (`__kml_classref_nstatic`/`skey`/`sget`/`keys`),
  `ctorLength`, `isClassName`.
- `codegen/llvm/emit_classexpr.go` (new): `hoistClassExpressions`,
  `classCaptures`, `classDisplayName`.
- `parser/parser_literals.go`: `newTargetIsExpression`,
  `parseNewOfExpression`, `parseNewTail`. `ast.NewExpression.Callee`;
  `ast.TypeAnnotation.IsCtorType`; `go generate ./ast`.
- `checker/symbols.go`: `typeQueryType`. `checker/checker.go`: `new` through
  any callee expression, and `new` of an `any` is `any`.
- `sema/sema.go`: per-scope `const M = Map` aliases; `BuiltinNew`,
  `IsBuiltinConstructor`.
- `resolver/rename.go`: bare `typeof X` annotations rename; `Callee`
  renames; `RenameInClass`.
- `codegen/llvm/emit_classes.go`: `staticFieldReadPtr`/`staticFieldWritePtr`
  and the inherited-static globals; `ImplicitCtor`; `errorSystemSlot`.
- `codegen/llvm/emit_generics.go`: `genericParamPos.Ctor`, `hashedTypeArg`.
- A class identifier infers as `any` (its value), except as the base of a
  member read, whose statics resolve statically (`isClassName`).

## Side effects discovered

- The unit packages (`codegen/llvm`, `sema`, `cmd/statusgen`, …) were not in
  the local gate: `make test-par` ran only `tests/`, while CI runs
  `go test ./...`, so part 2 reached CI with failing unit tests. `make
  test-par` now runs a new `make test-unit` first, and CI's POSIX lanes run
  `make test`, the same target as the local serial run. The
  `codegen/llvm` sidecar test's extern list gained the classref accessors
  dynjson.c declares.

- `sema_test`'s `new Worker(path)` row expected a sema rejection that moved
  out with `worker_threads` (ADR-01303), and Node accepts the call. The row
  was deleted.
- `TestE2ETypeofScalarInline` relied on `typeof` of a `const 42` being
  `number`; tsc gives the literal `42` and rejects `= 100`. The test now uses
  `let`.
- A class expression is hoisted, so evaluating it twice yields one class,
  not two. Identity between two evaluations, and statics written through
  one, differ from Node.
- An `Error` subclass instance with its own fields renders and enumerates
  as a plain object, listing the system slots (BACKLOG 69); extending an
  `Error` subclass is rejected; `(err as any).x = v` on a builtin error is a
  compile error. All three predate this ADR and are the next item.
