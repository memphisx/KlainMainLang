# ADR-00363: Union response bodies (`string | ReadableStream`) for `http.listen`

- **Relations**: Implements [TDD-00119](../tdd/TDD-00119.md). Extends [ADR-00300](ADR-00300.md) (streaming response body), builds on [TDD-00043](../tdd/TDD-00043.md)/[TDD-00115](../tdd/TDD-00115.md) (constrained unions).
- **Date**: 2026-08-25

## Context

An `http.listen` handler's response `body` had a single static type per program:
`streamingBody := bodyTy.IsReadableStream` chose the chunked vs buffered writer
at compile time (`emit_http.go`). A handler couldn't return a `string` on one
branch and a `ReadableStream` on another — the last caveat on the `req.stream()`
HTTP-Server row. Chosen approach (from TDD-00119): extend the general union
subsystem so `body: string | ReadableStream<...>` is an ordinary union, branched
on its runtime tag — over an HTTP-local bespoke box.

## Investigation

Two blockers in the union machinery (`emit_dynamic.go`):
1. `emitBoxValue` tagged every `IR=="ptr"` non-object as `kmlTagString`, so a
   `ReadableStream` (`{IR:"ptr", IsReadableStream:true}`, not `IsObject`) boxed
   *identically to a string* — indistinguishable in a union box.
2. `validateUnionMembers` rejected a `ReadableStream` member (`isUnionObjectMember`
   requires a plain object).

And `containsDynamicElement` (`emit_func.go` return-type guard) rejected *any*
union nested in an object — a deliberate TDD-00043 cut, because union member
checking/boxing wasn't wired at object-literal field construction.

Finally, a latent bug once a struct actually carried a union field:
`StructFieldSize` counted a dynamic field as 8 bytes (`ty.Align()`) instead of
the 16-byte `{ i8, i64 }` box, so the response object `calloc`'d too small and
the body-box store overflowed — observed as a corrupted `status` (read back as 0).

## Decision

- **Distinct boxing**: `kmlTagStream` (9); `emitBoxValue` boxes a
  `ReadableStream` to it (ptrtoint payload) ahead of the string fallthrough.
- **Union membership**: `validateUnionMembers` accepts a `ReadableStream`
  member; being tag-distinguishable it doesn't count toward the "2+ object
  members need a discriminant" rule. `unionAllowsAssignmentFrom` accepts a
  stream value into a stream-member union.
- **Object-field unions (general)**: `containsDynamicElement` allows a
  *constrained* union as an object field (still rejects bare any/unknown and any
  union as an array element — element-level checking stays unwired).
  `storeScalarOrNullableField[Expr]` boxes + member-checks a union field at
  construction. This completes constrained-union object fields end-to-end
  (construction, read, `typeof` narrowing), not just the HTTP body.
- **StructFieldSize**: a dynamic/union field is 16 bytes.
- **Response writer** (`buildHTTPDispatcher`): when the `body` field is a union,
  load the `{i8,i64}` box and branch on the tag — `kmlTagStream` → the existing
  chunked tail (unbox the stream ptr), otherwise → the buffered
  `__kml_http_send_response` tail (unbox the string ptr, `strlen`).

## Implementation notes

- Files: `emit_dynamic.go` (tag, boxing, membership, assignment,
  `containsDynamicElement`), `emit_nullable_scalar.go` (field-store boxing +
  check), `types.go` (`StructFieldSize`), `emit_http.go` (union response tail).
- V1 union body targets `string | ReadableStream`; `ArrayBuffer` as a third
  member is a possible follow-up.

## Side effects discovered

- Fixed the `StructFieldSize` union-field under-count (above) — latent until the
  first struct with a union field existed.
- `TestE2EUnionInterfaceFieldRejected` asserted the now-obsolete rejection;
  replaced with `TestE2EUnionObjectField` (works) +
  `TestE2EUnionObjectFieldInvalidMemberRejected` (member-set still enforced).
  The array-element rejection (`TestE2EUnionArrayElementRejected`) stays.

## Verification

- `TestE2EHTTPUnionResponseBodyString` / `...Stream` (new): one handler returns a
  `string` on `/plain` (buffered, status preserved) and `req.stream()` on
  `/stream` (chunked echo of a 3 MiB upload).
- `TestE2EUnionObjectField` + invalid-member rejection (new).
- Broad type-system suite (Union/Object/Dynamic/Narrow/Discriminated/
  Intersection/Tuple/Class/Stream/HTTP) passes; `go build`/`go vet` clean.
- Test262 run gates delivery (union boxing is a common JS-language path).
