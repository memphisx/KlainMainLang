# ADR-00420: diagnostics_channel V1 — named pub/sub with string messages

- **Relations**: Extends [ADR-00412](ADR-00412.md) (wrapper contextual typing)
- **Date**: 2026-08-28

## Context

Next item from the gap analysis's ranked list: `diagnostics_channel`, a
28-file oracle block and a genuinely small module — a name-keyed pub/sub
with no I/O. The corpus splits between the plain channel surface and
`tracingChannel` (the traceSync/tracePromise/store-binding half).

## Decision

- **Surface**: `dc.channel(name)` (create-or-get), `dc.subscribe(name, fn)`/
  `dc.unsubscribe(name, fn)` (also as Channel methods), `dc.hasSubscribers
  (name)`, and the Channel's `hasSubscribers`/`name` properties.
  `tracingChannel` and the store bindings (`bindStore`/`runStores`, which
  ride AsyncLocalStorage) are clean rejections naming the gap.
- **String messages (V1)**: `publish` takes a string; a non-string message
  is a clean rejection pointing at `JSON.stringify`. A typed subset cannot
  hand an arbitrary object shape to statically-unknown subscribers — the
  string constraint is the honest boundary, and JSON covers the structured
  case.
- **Subscriber typing**: `(message, name)` contextually typed as strings at
  the subscribe site (through `mustCall` wrappers); 0/1/2-arity subscribers
  supported, the declared arity stored per subscriber so publish calls each
  correctly. A subscriber whose params are *not* string-typed — the
  pre-wrapped-then-bound case, where the wrapper's number-defaulted
  signature is already fixed — is a **clean rejection**: during development
  it silently reinterpreted published pointers as doubles (`got NaN on
  6e-323`), and silent corruption is never an acceptable V1 behavior.
- **Runtime**: a linear name→channel registry (few channels by nature);
  per-channel parallel closure/arity arrays; pointer-identity unsubscribe
  with tail-swap compaction; `hasSubscribers` as a count check.

## Implementation notes

`runtime_diagch.go`, `emit_diagch.go`, plus the usual wiring
(`types.go` `IsDCChannel`, `emit_call.go`/`emit_exprs_member.go`/
`emit_exprs_types.go`, resolver members, oracle supported-set).

## Side effects discovered

- A Channel handle is not in the module-global promotion set (ADR-00342), so
  a named top-level function can't capture one — closure capture works;
  disclosed on the status row and in the example.

## Verification

New E2E tests `TestE2EDiagnosticsChannelPubSub` (full flow: hasSubscribers
transitions, 2-arg + 1-arg subscribers, unsubscribe semantics) and
`TestE2EDiagnosticsChannelUntypedSubscriberRejected`; new example
`examples/process/diagnostics_channel.ts` compiled and run; Node oracle +
full `make test-par` re-run (Mac).
