# ADR-01710: `new Worker(new URL(import.meta.url))` is a self-worker

- **Relations**: `Implements TDD-00230`; `Fixes ADR-01605`
- **Date**: 2026-10-18

## Context

The resolver recognized a self-worker only in the CommonJS form, `new Worker(__filename)`. The ES-module form that Node documents, `new Worker(new URL(import.meta.url))`, failed with "Cannot find module".

## Decision

`rewriteSelfWorker` also rewrites a `new URL(import.meta.url)` first argument to the file's own specifier.

## Verification

macOS (Apple Silicon): `TestE2EWorkerSelfImportMetaURL` and `TestE2EWorkerSelfFilename` pass.
