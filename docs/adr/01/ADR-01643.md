# ADR-01643: ADR records in one folder per thousand

- **Date**: 2026-10-16

## Context

`docs/adr/` held 1,642 files, and GitHub stops listing a directory's
contents past a fixed number of entries. At the current rate the folder
would pass that limit within months, and the web view would stop showing
the records.

## Investigation

References to ADR files came in four forms: same-folder links between
ADRs (`ADR-00047.md`), `../adr/ADR-…` from `docs/tdd/` and `docs/status/`
(including the status JSON, whose links are relative to the generated
pages), `adr/ADR-…` from `docs/`, and repository-root paths
(`docs/adr/ADR-….md`) in source comments. `cmd/statusgen` lists the records,
writes the index, and writes the TDD index's Related ADRs column. The index
copied each title and Relations bullet verbatim. That was correct only
because the records and the index shared a folder.

## Decision

- `docs/adr/NN/ADR-NNNNN.md`, where `NN` is the number divided by 1000, two
  digits: `00/` holds ADR-00001 to ADR-00999, `01/` holds ADR-01000 to
  ADR-01999. `README.md` and `TEMPLATE.md` stay at the top.
- Files moved with `git mv`, so history follows them.
- Every reference was rewritten by resolving it against its own file (the
  status JSON against `docs/status/`), and every relative link inside a
  moved record was rebased one level down.
- `cmd/statusgen` lists records across the thousand folders (`adrNums`),
  builds paths with `adrRel`, and rebases the links of each title and
  Relations bullet from the record's folder to the index's.

## Implementation notes

`cmd/statusgen/records.go`, `cmd/statusgen/records_test.go`,
`docs/adr/README.md` (naming and linking rules). A link text that the
rewrite also changed (ADR-01020's Relations, already garbled before) was
fixed by hand.

## Side effects discovered

ADR-01020's index row was garbled at HEAD; it is clean now.

## Verification

A link checker over every markdown link in the repository: no file has
more broken links than before the move. `go test ./cmd/statusgen`,
`make status-check`, `make reference-check`.
