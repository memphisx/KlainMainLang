# ADR-01717: Response stream bodies of any chunk type

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-18

## Context

`new Response(stream)` compiled only for a `ReadableStream<Uint8Array>`. A stream of `any` chunks, the only kind `-compat=js` builds, was rejected at compile time (BACKLOG #78). Node takes any `ReadableStream`. A body method reads it, and a chunk that is not a `Uint8Array` rejects the read with `TypeError: Received non-Uint8Array chunk`. Also, a program whose only wait was this collector's `await` was classified as never waiting. The build then failed with an internal error, for typed streams too.

## Decision

- A stream body of any other chunk type sets a new body flag bit, `responseStreamAny`. The collector reads that stream as `ReadableStream<any>` and checks each chunk with `instanceof Uint8Array`, throwing Node's TypeError otherwise. A `Uint8Array` stream keeps the typed read. `.body` stays the stream itself.
- `programMayWait` counts `new Response(<body>)` as a possible wait.

## Verification

macOS (Apple Silicon): `TestE2EResponseStreamOfAnyChunks` and `TestE2EJSResponseStreamOfAnyChunks` match Node. The Response, fetch, body and stream E2E tests pass.
