# ADR-01820: Class static initialization runs at the declaration

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- A program class's static fields and `static {}` blocks ran once at the very start of `main`, before any top-level statement. JS runs them when the class declaration is evaluated, so `console.log("a"); class C { static { console.log("b"); } }` printed `b` first.
- A generator function expression printed `function g() { [native code] }`: the declaration it lowers to dropped its source text.

## Decision

- A program class's static initializer is called where its declaration runs. A generic class's statics, held by a synthesized companion class, initialize at the generic declaration's site. A builtin module's classes still initialize before program code.
- Both lowerings of a generator function expression keep its source text.

## Consequences

- Static initializers interleave with top-level code in source order, as in Node.
- `String(function* g() {})` prints the generator's source.
