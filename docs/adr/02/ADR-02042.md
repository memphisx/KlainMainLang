# ADR-02042: %ArrayIteratorPrototype% and %IteratorPrototype%

- **Date**: 2026-11-22

## Context

- `Object.getPrototypeOf([].values())` was Object.prototype, shared with
  the Map and Set iterators. Its `next` could be neither read nor
  patched.

## Decision

- Each builtin iterator class (`Array Iterator`, `Map Iterator`,
  `Set Iterator`, `RegExp String Iterator`) gets a prototype object: its
  `next` and `[Symbol.toStringTag]`, no constructor. Its parent is one
  %IteratorPrototype%, which holds `[Symbol.iterator]` (returning this)
  and the linked iterator helpers.
- An iterator made through a boxed array's `[Symbol.iterator]` has the
  same prototype, and answers that prototype's `next`.
- %ArrayIteratorPrototype%'s bag records its `next` when it is made
  (dynobj.c). A replaced `next` is what a read of `it.next` returns.
  `it.next()` on a static array iterator checks it when the program reads
  a prototype and writes a `next` property, and then holds its result
  boxed. Array iteration then takes the protocol path
  (`__kml_array_iter_patched`), as it does for a replaced
  `Array.prototype[Symbol.iterator]`.

## Consequences

- A boxed iterator's `next` read costs one C call, which returns at once
  while the prototype was never made.
- Tests: `TestE2EArrayIteratorPrototypeTS`.
