# ADR-01162: Compiler fixes found by the TypeScript `stream` port

- **Relations**: `Implements TDD-00231` (stages 2–3); `Implements TDD-00230` (P3.3: `convert` between object layouts and function types); `Extends ADR-01014`, `ADR-01016`, `ADR-00477`, `ADR-00619`, `ADR-00093`
- **Date**: 2026-09-25

## Context

`lib/node/stream.ts` (ADR-01161) is ordinary TypeScript, compiled like a
user module. Each construct it used that the compiler mishandled is a bug
user code hits too, so each is fixed at its origin rather than avoided in
the module. This records them.

## Decision

- **A closure may call a closure declared after it.** `const a = () =>
  b(); const b = () => 1;` compiled to "undefined function or closure".
  A body's `const`/`let` closures that an earlier closure names are found
  when the body starts (`setForwardClosures`). The first capture of one
  allocates its cell in the entry block (`forwardClosureSym`), which
  dominates both the capture and the declaration, and the declaration
  stores into that cell. Mutual recursion works, in functions, methods
  and at top level. A call through the cell before the declaration has
  run throws JavaScript's `ReferenceError: Cannot access 'b' before
  initialization`.
- **An object of one layout where another is expected is converted.**
  `useB(a)` with `a: A` and `useB(b: B)`, where `A` and `B` list the same
  properties in different orders, passed the pointer and misread every
  field (garbage, or a crash at `-O2`). A plain object (an interface,
  type literal or object literal, not a class or host object) is copied
  into the target's layout by property name (`emitObjectRelayout`), in
  `coerce` and in `emitExprWithObjectHint`. Arguments, initializers,
  returns, assignments and field stores all take one of those. A property
  the source lacks is absent. The copy is a new object, so a mutation
  through one alias is not seen through the other.
- **`typeof x === 'function'` narrows a union** to its function member,
  and the narrowed binding can be called. A union's function member
  unboxes through the any-to-closure thunk. An object or function
  literal passed into a union slot is built as the union's member of its
  kind (`unionLiteralMember`).
- **Overrides with another parameter representation.** TypeScript's
  method parameters are bivariant, so `_write(chunk: Buffer, …)` may
  override `_write(chunk: any, …)`. Such an override takes the base's
  parameter and converts it to its declared type at entry
  (`adaptOverrideParams`), so both share one vtable signature.
- **Closures against a function-typed slot** go through the ADR-00477
  adapter when a parameter's representation differs, as `coerce` already
  did (`emitClosureAgainstHint`). A rest `any[]` tail now spreads into an
  array parameter (`(d: Buffer) => …` where `(...args: any[]) => void` is
  expected).
- **Namespace imports qualify `new`, `extends` and types.** `new m.C()`,
  `class D extends m.C` and the annotations `m.C`, `m.I[]` through
  `import * as m` did not resolve: the parser dropped `new`'s and
  `extends`' qualifier, the resolver never looked a qualified type up in
  the namespace, and the annotation of `ns.T[]` lost its qualifier.
  `NewExpression.Qualifier` and `ClassDeclaration.BaseQualifier` keep
  it, a name-spelled array annotation keeps its element's, and the
  resolver maps `m.X` through the namespace's export table. A qualifier
  that is not a namespace import (a TypeScript `namespace`) keeps the
  earlier lookup.
- **A top-level object literal with methods is a module global** when its
  methods read only module globals, top-level functions and classes, and
  builtins, so a named function or another module can read it. Such a
  declaration is promoted after the others, so a method may read a global
  declared after it.
- **A subclass may redeclare an inherited field** of the same type
  (`code: string` over `Error`'s): the inherited slot is kept.
- **EventEmitter**: `addListener`, `prependListener` and
  `prependOnceListener`. A dynamic emitter's object-literal argument is
  built as a dynamic object, so a listener can read it through `any`.
- **`Buffer.prototype.subarray` returns a `Buffer`**, not a
  `Uint8Array`.
- **Bitwise operators take each operand through `ToInt32` on its own.**
  A typed-array element (`u8`) `|` a double truncated the double to a
  byte first: `b[0] | (b[1] << 8)` lost the high byte.
- **`buf.toString('utf8')` is the WHATWG decoder.** An invalid sequence
  becomes U+FFFD instead of passing through as raw bytes
  (`__kml_buf_utf8_str`); valid input is a plain copy.
- **An `any` element into an array-of-arrays or `Buffer[]`** unboxes to
  the array (`storeArrayElem`), sharing the boxed array's header.
- **Captures:**
  - a method's captured parameter is boxed at entry, as a function's is,
    not at its first capture, which may sit in one branch;
  - the capture pre-scan walks every expression kind (a method shorthand
    in a `new` argument's object literal was skipped).
- **Earlier in the port** (before ADR-01161's rewrite):
  - an untyped `let` with no initializer is evolving `any`, in both
    lanes;
  - a generic method erases to its simple constraint, else `any`, with
    the result typed at the call (`genericMethodResult`);
  - an `any` into a closure-typed slot converts through a thunk
    (`emitAnyToClosure`) instead of reinterpreting the box;
  - `super(...)` arguments are built against the base constructor's
    parameter types, and omitted optional ones are filled;
  - `c ? null : obj` keeps the object (`ternaryNullablePointerType`);
  - `.length` of an object with its own `length` field reads the field;
  - the free-variable scan walks every expression kind;
  - `Buffer.concat` of a list built at run time (`__kml_buf_concat`);
  - `this` captured by an arrow in a method is boxed at entry.

## Side effects discovered

- A method call on a primitive, array or Buffer held in `any`
  (`anyBuf.slice(1)`) is BACKLOG's primitive-member dispatch item.
- An omitted `Error | null` argument reads `null` where Node reads
  `undefined` (ADR-01161).
- A class instance passed as an interface, or an object literal as a
  class, still misreads (BACKLOG 64): a class's layout begins with hidden
  words, and copying it would lose the mutations made through the
  interface. It needs P3.3's object representations.

## Verification

- **Tests:** `tests/stream_port_fixes_test.go`, one E2E test per fix
  above (17), each program's expected output Node v24's. The Node-stream
  tests (ADR-01161) cover the rest.
- **Example:** `examples/function_expressions/forward_reference.ts`
  (mutual recursion and a tokenizer whose helpers call forward), same
  output as Node.
- **tsdiag:** 3,157 diagnostics, 0 false positives.
- **Gates:** `make examples`, `make test-par` and `make conformance` on
  the Mac (see ADR-01161).
