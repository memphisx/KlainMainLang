# ADR-01757: A module binding of a builtin function is a module global

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

`var gopd = Object.getOwnPropertyDescriptor; function f(o, n) { return gopd(o, n); }` failed to compile in both lanes ("undefined function or closure 'gopd'"), and `typeof g` read inside a function printed `undefined` for `var g = parseInt`, `Math.max` or `JSON.stringify`. A top-level binding becomes a module global, readable from a named function, only when its type is decided before the bodies are emitted (`decideGlobalType`). Its identifier case knew program functions and earlier globals, not a builtin function, so the binding stayed a local of `main()`. Test262's `propertyHelper.js` binds `__getOwnPropertyDescriptor` this way, so every test that includes it failed to compile.

## Decision

An unannotated binding whose initializer is a builtin function (`builtinRef`) is promoted with the type of the closure codegen builds for that value (`funcTypeFromSig` of the builtin's signature), the same type the declaration's store has.

## Consequences

- `TestE2EModuleGlobalBuiltinFunctionValue` and `TestE2ECompatJSModuleGlobalBuiltinFunctionValue` cover reads and calls from functions.
