# ADR-00590: crypto.randomBytes callback form

- **Relations**: Extends [ADR-00340](ADR-00340.md) (the fs async-shape posture)
- **Date**: 2026-09-01

## Context

Node `crypto.randomBytes(size)` returned a Buffer, but the `randomBytes(size,
callback)` form — `cb(err, buf)` — was a clean rejection.

## Decision

Accept an optional callback. The bytes are generated synchronously (the same
CSPRNG the sync form uses), then `cb(null, buf)` is fired inline — async-shaped
but not offloaded, matching the fs callback posture (ADR-00340). The callback is
contextually typed `(err: Error | null, buf: Buffer)`; `err` is always `null`
since generation never fails. The no-callback form still returns the Buffer.

## Verification

`TestE2ECryptoRandomBytesCallback` (callback fires with `err === null` and a
correctly-sized buffer; the sync form still returns a Buffer). Built and verified
on Mac (Apple Silicon).
