# ADR-01495: `console.countReset` of an unknown label warns

- **Relations**: Extends ADR-00347
- **Date**: 2026-10-09

## Context

`console.countReset("zz")` for a label never counted set a counter of 0
silently. Node emits a process warning, "Count for 'zz' does not exist",
and resets nothing.

## Investigation

- Node's `countReset` (lib/internal/console/constructor.js) calls
  `process.emitWarning` when the label has no count.
- `process.emitWarning` is a library module (internal_process_warning.ts)
  the resolver links when a program names `emitWarning`; a program using
  only `countReset` did not link it.

## Decision

- `countReset` of an unknown label calls the library's `emitWarning` with
  Node's message, and leaves the counts as they are. Node looks the label
  up as given, so a non-string label (counted under its string form)
  never matches: it warns too (`consoleLabelArgKind`).
- The resolver links the warning module when a program names
  `countReset`. A program compiled without the library (some tests)
  prints the default listener's line directly.

## Side effects discovered

None.

## Divergences

- Node's one-time "(Use `node --trace-warnings ...`)" hint stays out, as
  for every process warning (internal_process_warning.ts).

## Implementation notes

resolver/resolver.go; BACKLOG 158 deleted.
