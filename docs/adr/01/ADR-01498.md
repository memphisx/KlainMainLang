# ADR-01498: `implements` is checked by the checker (TS2420)

- **Relations**: Supersedes the conformance check of ADR-01475 and TDD-00009 Stage 4
- **Date**: 2026-10-09

## Context

The checker ignored a class's `implements` clause. Codegen checked a
non-generic class against the interface by comparing its own field and
method tables, and rejected a generic interface outright: `class D
implements G<number>` failed with "implements unknown type 'G'", where
Node runs it.

## Investigation

- `implements` has no run-time effect. Codegen's check compared IR types
  (a field's `ptr` against an interface's), not TypeScript's
  assignability, and could not see a generic interface's instantiation
  (the clause keeps the name only).
- tsc reports TS2420 when the class's instance type is not assignable to
  the implemented type.

## Decision

- The checker checks each non-generic implemented interface, class or
  object type alias: the class's instance type must be assignable to it,
  else TS2420 "class 'C' incorrectly implements interface 'I'"
  (`checkImplements`). A generic target is not checked (its arguments
  are not kept on the clause).
- Codegen's conformance check is deleted.
