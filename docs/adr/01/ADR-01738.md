# ADR-01738: `new.target`, and an abstract class constructed through `any`

- **Relations**: `Implements TDD-00230`, Extends [ADR-01737](ADR-01737.md)
- **Date**: 2026-10-19

## Context

- `new.target` was a parse error.
- `new` on an abstract class through `any` (`new (Shape as any)()`) threw "Shape is not a constructor". `abstract` exists only in TypeScript, so JavaScript runs the constructor.

## Decision

- **Parsing:** `new.target` is a `NewTargetExpression`. Its child is a `ThisExpression` flagged `NewTarget`: the value is read from the receiver, so the walkers that capture `this` for closures capture it too.
- **Context:** a pass after parsing (`newTargetContexts`) records what the enclosing function is.
  - Constructor: a class constructor.
  - Undefined: a method, accessor, field initializer or static block.
  - Function: a function declaration or expression.
  - An arrow keeps its enclosing function's context. Outside any function, `new.target` is the early SyntaxError V8 and tsc report.
- **The checker** types it `undefined` in the Undefined context and `any` otherwise.
- **Codegen** (`emitNewTarget`):
  - In a constructor it is `this.constructor`: the class `new` named, a derived class's included, since `super()` runs on the derived instance.
  - In a `-compat=js` prototype constructor it is `Object.getPrototypeOf(this) === F.prototype ? F : undefined`. `Base.call(this)` gives `undefined`. The declaration and its `new.target` nodes share an id (`NewTargetID`/`FnID`), so a nested function expression or declaration has its own `new.target`.
  - Anywhere else it is `undefined`.
  - The static-`this` rewrite leaves it alone.
- **An abstract class constructs through `any`:**
  - the dynamic construct dispatch includes abstract classes;
  - an abstract class gets a vtable, with a null slot for an abstract method that nothing in its chain implements, as an unimplemented optional method gets;
  - the dynamic member table leaves such a method out, so it reads as `undefined`.
  - A static `new Abstract()` is still rejected, as tsc rejects it.

## Verification

macOS (Apple Silicon), against Node:

- `tests/classes_test.go`:
  - TestE2ENewTarget: constructors, a derived class, before `super()`, an arrow, a method, a static method, a plain call;
  - TestE2ENewTargetPrototypeConstructor (`-compat=js`): through `new`, through `Base.call(this)`, an arrow, a nested function expression and declaration;
  - TestE2ENewTargetAtTopLevelRejected;
  - TestE2EAbstractClassConstructedThroughAny.
- `examples/classes/new_target.ts` matches Node.
- The class, static, prototype, closure, arrow, decorator and `-compat=js` families pass, as do the parser and ast unit tests.
