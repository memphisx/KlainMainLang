# ADR-00354: Flow-based narrowing of union types

- **Relations**: Implements [TDD-00114](../tdd/TDD-00114.md); extends [TDD-00043](../tdd/TDD-00043.md) (union types), [TDD-00064](../tdd/TDD-00064.md) (nullable narrowing seam)
- **Date**: 2026-08-25

## Context

Union types shipped ([TDD-00043](../tdd/TDD-00043.md)) as a boxed `{ i8, i64 }`
value but with no flow narrowing — inside `if (typeof x === "string")`, `x`
stayed a union and couldn't be used as a `string`. This adds narrowing, the last
major core-language type-system gap.

## Decision

Generalize the nullable-scalar branch-narrowing seam ([TDD-00064](../tdd/TDD-00064.md)
Stage 2, `emit_nullable_scalar.go`) from a `NarrowedNonNull bool` to a
`Symbol.NarrowedTo *Type`:

- **Guard recognition** (`emit_narrowing.go`): `typeof x === "T"` / `!==`,
  bare truthiness `if (x)` on a nullable union. For `typeof`, both the matching
  branch (→ member `T`) and the complement branch (→ union minus `T`, concrete if
  one member remains) narrow.
- **Branch wiring**: `applyUnionBranchNarrowing` runs alongside the existing
  `applyBranchNarrowing` in both `if` branches (`emit_stmts.go`); the shadow is
  defined in the branch scope and discarded by `popScope`. It also runs in the
  existing **early-exit** block, so `if (typeof x === "string") return;` narrows
  the rest of the enclosing scope to the complement.
- **Nested composition**: `unionLocal` returns the *effective* union (the
  already-narrowed type if a prior guard narrowed to a smaller union), so nested
  `else if` refines the remaining members rather than the original set.
- **Use sites**: `emitIdent` and `inferExprType`, on a binding with `NarrowedTo`
  set, unbox the `{ i8, i64 }` box to the concrete narrowed type
  (`emitUnboxBoxToType`: inttoptr for a string, bitcast for a double, trunc for a
  bool, raw i64 for an integer), so downstream method dispatch / arithmetic /
  printing see a real concrete value.

## Side effects discovered

`isNumberTy` reports true for `i1` (it only excludes pointers/dates), so an
initial member classifier that checked number before boolean folded `boolean`
into `number` — removing `boolean` from `string | number | boolean` also dropped
`number`. Fixed with `unionMemberTag`, which checks `i1` (boolean) before number
and is the single source of truth for member identity/`typeof` matching.

## Scope

- **In:** `typeof`/truthiness/`== null` narrowing of a union **local** in `if`/
  `else` branches and after an early return/throw/break/continue; nested
  composition; narrowing to a single member makes the value fully usable.
- **Out (deferred):** narrowing a field/element or arbitrary expression (locals
  only, matching the nullable precedent); discriminated-union narrowing on an
  object tag; `switch (typeof x)`; `&&`/`||` guard algebra beyond the first
  conjunct; `as` casts.
