# ADR-01781: Methods returned by getters are called through their value

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- `C.f(x)` with `static get f()` returning a function failed with "class has no static method". The static call site only knew methods and function-valued fields.
- A static private generator method's body was named with its `#`, which is invalid IR.
- `obj.g(x)`, with a getter `g` returning a generator method that has no `yield`, inferred the call as a number. The checker-refined call type won over the dynamic call codegen emits. So `.next()` on the result failed with "a number has no method".

## Decision

- `emitStaticMethodCall` reads a static getter's value and calls it: directly for a typed function, through the dynamic call ABI otherwise.
- The generator body name goes through `llvmSafeSymbol`.
- `structuralCallType` types a call of a class instance's non-method member whose value is an `any` as `any`, ahead of the checker refinement.

## Consequences

- `TestE2EJSFileGetterReturnedMethodsCalled` covers static and instance getters returning functions and private generator methods.
