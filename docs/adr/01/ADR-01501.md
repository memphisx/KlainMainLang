# ADR-01501: An array's element type is part of its host layout key

- **Relations**: Extends TDD-00247, TDD-00230
- **Date**: 2026-10-09

## Context

A program that boxed iterators over two arrays with different element
types misread the second one:

```ts
const anys: any[] = [1, "s", {}];
console.log(anys.values().reduce((m: any, v: any) => v, {}));
console.log([1, 2, 3].values().reduce((a, b) => a + b, 10)); // 15.5625, not 16
```

## Investigation

- Both iterators shared one host layout and its method wrappers
  (`__kml_host_m_<id>_*`).
- `hostKey` adds a Map's key and value storage and an iterator's
  source, but not an array's element type. So the `number[]` iterator
  reused the `any[]` iterator's `next`, which reads elements as boxes.

## Decision

`hostKey` includes an array's element layout key, so each element type
gets its own host layout, header word and wrappers.
