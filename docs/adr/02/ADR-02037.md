# ADR-02037: A class at an object-typed parameter

- **Date**: 2026-11-22

## Context

- `f(K)` with `f(o: { x: number })` passed a copy of `K`'s statics in the
  parameter's layout. The callee's writes never reached `K`.

## Decision

- The any-argument check (emit_anyarg.go) marks a class value at a plain
  object-typed parameter (`classAtObjectParam`). Such an argument never
  fits the layout, so the call takes the any-argument entry, whose
  parameter holds the class's box. Reads and writes there reach the
  class's statics.

## Consequences

- Only a call passing a class itself pays for the second entry.
- Tests: `TestE2EClassAtObjectParamTS`.

## Addendum: an `any` at a class-typed parameter

- The same check marks an `any` argument at a program class's parameter
  (no error or host base). It fits when the box holds an instance of the
  class or a subclass (`emitBoxIsInstanceOf`, `__kml_class_is` over its
  header). Any other box, such as a plain object, takes the entry where
  the parameter is a box and is read as itself.
- Tests: `TestE2EAnyAtClassParamTS`.
