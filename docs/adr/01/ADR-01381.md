# ADR-01381: A renamed function keeps its namespace; unconvertible arguments are rejected, not emitted

- **Relations**: Extends ADR-01376, TDD-00095, TDD-00230 P2.7
- **Date**: 2026-10-03

## Context

Conformance of the tree through ADR-01380 measured 34 strict-lane files of
invalid IR and none in the js lane: 30 DataView files
(`getInt8("")`, `getFloat32(0, {})`, `setInt16(0, 1, obj)`), `indexOf` and
`lastIndexOf` with an object needle against a `number[]`
(`15.4.4.14-2-2.js`), `ArrayBuffer.prototype.resize` and
`SharedArrayBuffer.prototype.grow` with an object length, and
`[].concat(fn)`. Every one is a program tsc rejects; the strict lane
compiled it.

## Investigation

- The strict lane type-checks before emitting, yet these files reached the
  emitter. Reduced: after `assert.sameValue(sample.getInt8(1), 39, "a")`,
  the argument error in `assert.sameValue(sample.getInt8("q"), 0, "x")` was
  not reported; without the harness both lines were. The harness's `assert`
  is a function merged with a namespace.
- `function a(m: any) {} namespace a { export function s(x: any) {} }`,
  then `a.s(dv.getInt8(1)); a.s(dv.getInt8("r"));`: tsc reports line 2's
  argument, this checker did not. The resolver's per-file rename suffixes the
  function (`a__kml_mod0`) and leaves namespace names global, so the binder
  declared two symbols: the function, and a namespace `a` with no function
  behind it. `a.s` read the function, which has no member `s`, and was
  unanswered. A call whose arguments mention `dv` may assert it, so after a
  call to an unanswered callee `dv`'s type is unanswered too
  (`narrowByAssertion`, `unknownGuard`), and every later use of `dv` went
  unchecked.
- Unchecked, the strict emitter passed the argument with no conversion:
  ToNumber/ToBoolean of a string, object or function is `-compat=js` only
  (ADR-01376), and the class-method, constructor, `super(...)` and setter
  argument paths used `coerce` without checking that the result had the
  parameter's representation. `emitBufferGrow` and `emitArrayConcat` did
  the same into `i64` and the element type.
- `indexOf`/`lastIndexOf`/`includes` converted the needle to the element
  type. Under `-compat=js` that made `[1, 2].indexOf("1")` 0 and
  `[1, 0].indexOf(true)` 0, where strict equality gives -1.

## Decision

- The binder merges a namespace with the one function, class or enum in the
  same scope whose name is the namespace's plus the resolver's rename suffix
  (`renamedPartner`), as it merges them under one name. The namespace scope
  belongs to that symbol, so `a.s` reads the namespace member.
- Every class call path (method, static method, constructor, `super(...)`)
  rejects an argument whose converted value does not have its parameter's
  IR type (`argReprMismatch`), and so does a setter: tsc's "not
  assignable", never a mismatched call.
- `resize`/`grow`'s length and a non-array `concat` argument go through
  `coerceChecked`.
- A search value of another kind than the elements (number, boolean, string,
  object) is boxed and compared boxed, so it matches no element.

## Implementation notes

`binder/binder.go` (`inNamespace`, `renamedPartner`),
`codegen/llvm/emit_classes.go`, `emit_arraybuffer.go`,
`emit_arrays_transform.go`, `emit_arrays_search.go` (`searchNeedle`,
`searchKind`). A namespace that comes before its function, or two files
each merging the same name, find no single partner and bind as before.

## Side effects discovered

- `Array.prototype[2] = …` is unsupported, so `15.4.4.14-2-2.js` and
  `15.4.4.15-2-2.js` still fail at run time in the js lane.
- With `assert.sameValue` no longer hiding later errors, more strict-lane
  Test262 files are rejected as tsc rejects them.

## Verification

Mac (Apple Silicon): the reduced program reports the same two errors as
`tsc --strict` (TS2345 at 5:7 and 8:16); the search cases match Node; the 34
files, assembled as the conformance runner assembles them, give valid IR or
a type error in both lanes. Tests: `TestE2EFunctionNamespaceMergeKeepsChecking`,
`TestE2EArraySearchOtherKind`, `TestE2EStrictEmitterRejectsUnconvertibleArgs`;
binder, resolver, parser and checker unit tests.
