# ADR-01745: A parameter default is a branch in flow

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-19

## Context

`async function f(_ = (function () { throw new Error() })()) { … }` was inferred as returning `Promise<never>`, where tsc infers `Promise<void>`. The binder visited a parameter's default as unconditional code. A default that always throws, such as an IIFE flowing inline (TS 5.4), then left the function body unreachable, and the return type became `never`.

## Decision

- A parameter's default and a binding element's default (`{ a = f() }`, `[b = g()]`) run only when the value is `undefined`. The binder visits each one between the flow before it and a join with that flow (`initializer`), as tsc's binder does.

## Consequences

- A default that always throws no longer makes the body unreachable. The return type and narrowing after it match tsc.
- The shadow report's `Promise<never>` disagreements on async functions with throwing defaults are gone.
