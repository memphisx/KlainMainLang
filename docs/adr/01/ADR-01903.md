# ADR-01903: dictionary boxes, `ReadonlyArray` and `Array.isArray` in the oracle

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

- A generic dictionary's string index (`NodeJS.Dict<T>`'s `T | undefined`) holds its value without the `undefined`, a union's box included (`ParsedUrlQuery`); a box keeps the union's `null`. An interface writing its own index (`OutgoingHttpHeaders`), or naming members beside it (`IncomingHttpHeaders`), keeps a box's `undefined`. The oracle dropped the `undefined` only from a non-box value, and so disagreed on every inherited dictionary of a union.
- resolveType holds the library's `ReadonlyArray<T>` as an array, as it does `readonly T[]`. The oracle mapped it as an object, so a union naming it beside a string (`ParsedUrlQueryInput`) had no representation.
- `Array.isArray(v)` narrows a union to `any[]` (tsc's answer, a `ReadonlyArray` member included); emission reads the box's one array member there. The oracle compared `any[]` with each member and found none.

## Decision

- The oracle drops an inherited dictionary value's `undefined` whatever its representation, keeping a box's `null`; maps `ReadonlyArray<T>` as `T[]`; and answers a box narrowed to an array type with its one plain array member.

## Consequences

- The querystring module's rows go away (every program linking it); no emission change.
