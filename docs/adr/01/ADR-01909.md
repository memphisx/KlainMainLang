# ADR-01909: a declaration file's annotation in resolveType; an optional union in the oracle

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

- A declaration file's annotation is wrapped without conversion: only its type node describes it (P3.1). resolveType still ran the converted-field decider on it, which found no name and fell to the numeric default: `type DOMHighResTimeStamp = number` resolved as an integer and `RequestDuplex` as a box.
- resolveType marks an optional parameter's union box absent (`options?: AddEventListenerOptions | boolean`); the oracle mapped the bare node.

## Decision

- resolveType answers a declaration file's annotation with the checker's type for its node.
- The oracle marks an optional parameter's union box absent.

## Consequences

- Builtin aliases resolve as their declarations say; the fetch and event declaration rows go away.
