# ADR-00484: synchronous Readable.read()

- **Relations**: Completes the [ADR-00483](ADR-00483.md) stream-method caveat sweep
- **Date**: 2026-08-29

## Context

The last method in the streams row's "No `.read()`/`.unshift()`" caveat
with a clean semantic story: Node's non-flowing consumption API.

## Decision

`read([size])` pops one queued chunk synchronously via a new
`__kml_rs_tryread` runtime helper ({has, v0, v1} — reuses `__kml_rs_qpop`
with an emptiness guard); an empty queue yields `null` for pointer-chunk
streams and the zero stand-in for scalar chunks (the usual convention,
disclosed). The `size` argument is evaluated and ignored — chunks are
whole pushes here, not a byte buffer. `.unshift()` remains the caveat's
only survivor.

## Verification

Mac. `tests/streams_test.go` E2E (two pops in order, then `null`); full
stream batch green. Oracles unchanged (Node 41, TS 57.2%).
