# ADR-01074: `-mm=gc` — coroutine stacks live outside the collected heap

- **Relations**: Extends ADR-01048, ADR-01049 (GC roots), ADR-01050 (the 8 MiB module task)
- **Date**: 2026-09-22

## Context

BACKLOG §0 item 12: under `-mm=gc` a task's stack block came from the shimmed `malloc`, i.e. `GC_malloc` — zeroed
on allocation (so the module task's 8 MiB was resident from the first instruction, ADR-01050) and scanned as one
enormous heap object on every collection, on top of being scanned as the running stack through `GC_stackbottom`.

## Investigation

`@__kml_spawn_task_ex` mallocs the block; `@__kml_task_reclaim` frees it. On POSIX the parked task's frames
genuinely live in that block, so it must stay visible to the collector while parked; on Windows a context is a
Win32 fiber on an OS stack and `win32io.c` registers the parked fiber stack as a root itself (`park_lo`/
`park_hi`, ADR-01048) — the block there is only the size hint `makecontext` reads. `klainsync.c` already keeps
goroutine stacks outside the heap and registers each whole block with `GC_add_roots`.

## Decision

Two shim entry points in `gcsrc/gcshim.c`, used by the task runtime only in gc mode
(`@__kml_task_stack_alloc(n)` / `@__kml_task_stack_free(p, n)`):

- POSIX: an anonymous private `mmap` (pages exist only once touched), registered as a root for the block's
  lifetime with `GC_add_roots`; `GC_remove_roots` + `munmap` on free.
- Windows: `VirtualAlloc(MEM_RESERVE | MEM_COMMIT)` / `VirtualFree` — no root, the fiber shim owns that.

Manual/auto mode keeps libc `malloc` (lazily committed, never zeroed). The whole-block root is scanned in
full on POSIX; registering only the live `[sp, high)` slice per park would scan less, but the block is already
strictly cheaper than before (no zeroing, no residency until touched, no double scan of a heap object) and
matches the goroutine runtime's shape.

## Implementation notes

`codegen/llvm/gcsrc/gcshim.c`, `codegen/llvm/runtime_task.go` (`stackAllocCall`/`stackFreeCall`, the reclaim
site reads the stack size from the task struct).

## Side effects discovered

None.

## Verification

Windows `-mm=gc`: the ADR-01073 probe (3,000 coroutines + race/any losers) runs to the same output as manual
mode. Linux (Docker) — the POSIX `mmap` + root path — in the session's full pass (`tests/task_reclaim_gc_tls_test.go`).
