# TDD-00102: Blob — immutable binary data with a MIME type

- **Status**: Implemented (see ADR-00314)
- **Date**: 2026-08-23

## Context

`Blob` is the last WHATWG binary primitive missing from the ArrayBuffer/TypedArray/DataView family. It matters less on its own than as glue: fetch/File-ish APIs and conformance tests construct Blobs from mixed string/binary parts, and its absence compile-fails whole test files.

## Design

**Representation.** `Type{IR:"ptr", IsBlob:true}` — a ptr to a hidden heap header `{ i64 size, ptr data, ptr type }`, the same hidden-struct convention ArrayBuffer (`{i64, ptr}`) and DataView already use. Data is materialized eagerly at construction into one contiguous malloc'd buffer (a Blob is immutable, so no rope/segment list is ever needed); the type string is stored as-is (no spec lowercasing — disclosed caveat).

**Construction.** `new Blob(parts?, { type }?)` is a dedicated AST node (`NewBlobExpression`), a general expression like `new ArrayBuffer`/`new DataView`. `parts` must be an inline array literal (the same array-literal-position restriction TypedArray construction has); each element dispatches on its inferred type — string (strlen bytes, UTF-8 already), TypedArray (byteLength bytes via `resolveArrayForHOF`), ArrayBuffer (header), Blob (header). Two passes: sum sizes → malloc → memcpy each part.

**Surface.** `.size`/`.type` (dedicated member reads); `.slice(start?, end?, contentType?)` — a copied sub-range Blob with the array-slice normalization rules, contentType defaulting to `""` per spec (not inherited); `.arrayBuffer()`, `.bytes()` (Uint8Array), `.text()` — all return already-resolved values (the same synchronous-under-`await` shape `Response.arrayBuffer()` uses; `await` of a non-promise is identity + tick). Copies, not views — the Blob is immutable, its consumers' results are mutable. **Cut for v1** (disclosed caveats): `.stream()` (needs a from-memory ReadableStream source kind), type lowercasing, `endings` option.

## Prerequisites

| Dependency | Status | Notes |
|---|---|---|
| ArrayBuffer header convention | Done | `.arrayBuffer()` hand-builds one, like fetch's Response does |
| TypedArray `{ptr,i64}` aggregate | Done | `.bytes()` returns one |
| await pass-through for non-promises | Done | verified in emit_async.go's identity guard |
