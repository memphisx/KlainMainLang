# ADR-00649: `accessor` auto-field decorators — the TC39 `{get,set,init}` protocol

- **Relations**: `Implements TDD-00161` (Stage 5, completes the standard dialect), `Extends ADR-00648`
- **Date**: 2026-09-02

## Context

The last standard-dialect placement: a decorator on a TC39 `accessor x`
auto-field. Its protocol is distinct from a getter/setter decorator — the
decorator receives one `{ get, set }` object and may return `{ get, set, init }`
(a returned get/set replaces the accessor's getter/setter; a returned `init`
transforms the backing field's initial value per-instance).

## Decision

### Desugar (parser)

A *decorated* `accessor x: T = init` is desugared in `parseClassDecl` to a
private backing field `__kml_acc_x: T = init` plus generated `get x()` /
`set x(value)` methods over it, and the accessor decorators are recorded as an
`ast.AutoAccessorSpec{ Name, Backing, Decorators }` on the class (tracked as a
unit rather than split across the two methods). A *non-decorated* `accessor x`
stays a plain field (observably identical). The resolver rewrites the accessor
decorators like every other decorator. Under the experimental dialect a class
carrying `AutoAccessors` is a clean rejection (`accessor` decorators are TC39).

### Application (codegen)

`registerDecoratedMethodSlots` (standard) registers per-accessor `get`/`set`
routing slots (keyed by the accessor dispatch name, so
`emitClassCall`/`emitClassSetterCall` pick them up) and a field-init slot on the
backing field. `emitStandardDecoratorApplications` then, per accessor:

1. boxes the generated get/set (`emitMethodBoxAdapter`), holding a running
   `{get, set, init}` trio (init defaults to `undefined`);
2. per decorator (bottom-up), builds a `{ get, set }` object from the current
   trio, calls the decorator with `(accessorObj, { kind: "accessor", … })`, and
   — when the return is an object — adopts its `get` / `set` / `init` members
   (each kept if the returned member is `undefined`);
3. stores the final get/set into the accessor slots and the final init into the
   backing field's init slot (applied per-instance in the constructor tail).

This reuses the getter/setter slot routing (ADR-00648) and the field-init /
constructor-tail machinery (ADR-00647) — the accessor protocol is the object
wrapper `{get,set}` in / `{get,set,init}` out around them.

## Side effects discovered

- A returned replacement `get`/`set` that reads typed `this.field` hits the
  general replacement-`this` boundary (ADR-00648) — observe/`init` decorators
  and non-`this` replacements are unaffected.
