# ADR-01811: `new` on a generator function throws a TypeError

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- `new g()` on a generator function failed to compile with "unknown class". In JavaScript a generator function is not a constructor, and `new` on one throws `TypeError: g is not a constructor` once its arguments are evaluated.

## Decision

- In the js lane, `new` on a name bound to a generator evaluates the arguments, then throws that TypeError. The strict lane keeps the checker's rejection.

## Consequences

- `TestE2EJSFileGeneratorPrototypes` covers the throw and its message.
