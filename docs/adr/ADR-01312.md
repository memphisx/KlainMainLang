# ADR-01312: Symbols and bigints keep their kind in unions

- **Relations**: `Implements part of TDD-00230` (P3.3), `Extends ADR-01059`
- **Date**: 2026-09-30

## Context

A symbol in a `string | symbol` union lost itself (BACKLOG 22):

- Narrowed with `typeof x === "symbol"`, its `description` read `null` and
  `String(x)` gave `Symbol(null)`.
- `cond ? 'q' : Symbol('w')` was a string, so `typeof` read `"string"`.
- `['s', Symbol('t')]` typed `(string | symbol)[]` was rejected as a symbol
  converted to a number.
- `cond ? 1n : 'a'` was a string too.

## Investigation

A symbol is a struct (SymbolType: a flagged header word and a description),
and a bigint an opaque pointer. Both are pointers, and three places took a
pointer to mean a string or a plain record:

- `scalarTypeKind` returned `""` for any object (a symbol) and `"string"` for
  any pointer (a bigint). `nullCoalesceUnion`, and with it `ternaryUnion`,
  refused a non-string pointer. So the two arms merged as one string.
- `plainRecordType` counted a symbol as a plain record. A narrowed union
  member was therefore read through the record view (`__kml_any_to_layout`),
  whose header check fails for a symbol, and then through the layout table,
  which has no `description`.
- `coerce`/`coerceChecked`'s "a Symbol cannot become a number" guard fired
  for a union target, whose word is an `i64`.

## Decision

- `scalarTypeKind` answers `"symbol"` for a symbol and `"bigint"` for a
  bigint, and `nullCoalesceUnion` admits both. A conditional or `??` mixing
  them with other kinds is the union.
- `plainRecordType` excludes a symbol, so a narrowed symbol is read as a
  symbol.
- `coerce` unboxes a box into a symbol slot as the box's object, not its
  ToString. The numeric guard skips a dynamic (union) target.
- `unionMemberTag` classifies symbol and bigint members, so
  `typeof x === "symbol"` / `"bigint"` narrow a union local.

## Implementation notes

The box of a symbol is already an object box whose field 0 carries
`symbolTypeIDFlag` (ADR-01059); `typeof` and ToString on it were right. Only
the static side lost the kind.

## Side effects discovered

None beyond those fixed here.
