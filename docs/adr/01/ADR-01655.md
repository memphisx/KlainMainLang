# ADR-01655: An array value is the pointer to its header

- **Relations**: Implements [TDD-00230](../../tdd/TDD-00230.md) (P3.3, one array shape); builds on [TDD-00213](../../tdd/TDD-00213.md), [TDD-00127](../../tdd/TDD-00127.md), [ADR-01653](ADR-01653.md)
- **Date**: 2026-10-16

## Context

Storage already held an array as a pointer to its shared `{data, len}`
header (fields, globals, locals, elements, the return ABI). A value in a
register was still the `{data, len}` aggregate, with the header carried
beside it in `Value.ArrayHeader` only where one was in hand. Every path
that moved only the aggregate (a generator's yielded value, a phi, a
merge slot, `Promise.allSettled`'s values, a method returning its receiver
through a member access) rebuilt a second header over the same data. That
copy shared element writes but not a `push`, and `===` was false. Absence
had two encodings: a null header, or a null data pointer, which an empty
array also has.

## Decision

An array value's `Ref` is its header pointer; `Value.ArrayHeader` is
removed.

- `arrayParts`/`arrayData`/`arrayLen` read the current data pointer and
  length from the header. A null header reads as empty through a shared
  read-only cell.
- `mkArray` builds a value over a data pointer and length. `arrayFromAgg`
  wraps a runtime routine's `{data, len}` result; `arrayAggOf` builds one
  for a C routine that takes it by value. Runtime routines keep their
  aggregate ABI.
- Phis, merge slots and result buffers of array type are `ptr`.
  Absence is only the null header: an optional-chain miss, `pop()`/`shift()`
  on an empty array, an out-of-bounds `at()`, a generator's finished value.
- `sort`, `reverse`, `fill` and `copyWithin` return the receiver's header
  (`resolveArrayHOF`), for any receiver expression.
- A field read of a non-nullable array whose slot is null makes a fresh
  empty array. A nullable one is absent.
- Producers whose miss used to be a null data pointer give the null header:
  `Map.get` on a missing key and a RegExp `exec`/`match` with no match.
  JSON serialization, `typeof` and `Array.isArray` of a `T[] | undefined`
  test the header, so an empty array with no storage is never absent.
- A stream queue carries an array chunk as its header and its length, so
  the chunk read is the chunk enqueued. A chunk the runtime makes (a fetch
  body, an HTTP request body, a zlib output block) gets its header from
  `__kml_rs_chunk_hdr`; the zlib transform and the HTTP response writer read
  the data through it.
- A Response body collected from a stream reads the Uint8Array the
  collector resolves with through its header.
- `fill` of a numeric array with an array value no longer stores the
  header pointer as an element: a Buffer filled with a typed array repeats
  its bytes (an empty one is `ERR_INVALID_ARG_VALUE`), and any other fill
  takes the value's ToNumber, as Node does.

## Consequences

- A yielded array, `Promise.allSettled`'s values and `o.arr.sort()` keep
  identity, matching Node.
- Reading data and length at each use sees a mutation made through another
  alias since the value was produced.
- Each new array value allocates its 24-byte header (with its type word),
  which the aggregate form avoided for temporaries. An escape analysis
  that keeps a non-escaping temporary's header on the stack is the
  recorded follow-up.
