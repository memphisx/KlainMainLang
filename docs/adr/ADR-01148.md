# ADR-01148: Node's timers, `os` and synchronous `fs` declared; intersections, generic bases and overload picks in the checker

- **Relations**: `Implements TDD-00230` (Phase 3, P3.1); `Extends ADR-01144`, `ADR-01145`
- **Date**: 2026-09-25

## Context

P3.1 continues with the next Node surfaces to declare in `lib/node.d.ts`:
the timer globals, `os`, and the synchronous `fs` functions. A misuse
tsc reports through @types/node was unchecked here:
`let id: number = setTimeout(…)`, `os.cpus(1)`,
`const s: string = fs.readdirSync(".")`.

## Investigation

- **Timers.** @types/node types a handle as `NodeJS.Timeout` (an object
  with `ref`/`unref`/`hasRef`/`refresh`/`close`). Here a handle is the
  timer's id, an `i64` (`inferExprType`), and none of those members
  exist. `typeof t` reads `"number"`, where Node's is `"object"`. The
  timers status page did not disclose this.
- **`fs` stayed unchecked after its declaration**, for five reasons:
  - `PathLike` is `string | Buffer | URL`, and neither `Buffer` nor `URL`
    was declared. An unresolved member leaves the union, and so the whole
    signature, unanswered.
  - `Stats extends StatsBase<number>`: `interfaceOf` gave up on a generic
    base.
  - The option types are intersections (`StatSyncOptions & { bigint?:
    false }`), which `typeFromNode` did not model.
  - One unanswered overload (`readdirSync`'s `NonSharedBuffer[]` form)
    left the whole overload set unanswered.
  - `readFileSync(p, "utf8")` picked the `Buffer` overload. `"utf8"` came
    out as "maybe" against the all-optional `{ encoding?; flag? }`.
- **Wider object leniency.** An object against any union was "maybe"
  (the discriminated-union rule), so an argument to an optional
  parameter (`o?: { … }`, which adds `| undefined`) was never checked.
  With that narrowed to unions of two or more object members, tsdiag
  showed four more gaps:
  - An array literal in a tuple context (`pair?: [number, number]` given
    `[1, 2]`) was `number[]`.
  - An object-literal argument's properties were widened before an
    overload's pick (`{ encoding: "utf8" }` against `BufferEncoding`).
  - A missing property on an intersection was TS2741 where tsc reports
    TS2322.
  - An intersection of DOM-named interfaces lost their open members
    (TS2339 against tsc's TS2812).
- **`existsSync(42)` is still accepted.** A primitive against an
  interface stays "maybe": the checker cannot rule out the primitive's
  apparent members (BACKLOG).

## Decision

- **`lib/node.d.ts`**:
  - **Timers**, in @types/node's overloads: `setTimeout`, `setInterval`,
    `setImmediate`, `clearTimeout`, `clearInterval`, `clearImmediate`,
    `queueMicrotask`.
  - **`NodeJS.Timeout` and `NodeJS.Immediate`** are declared with no
    members, since none are implemented.
  - **`os`**: every implemented function and constant, with `CpuInfo`,
    `NetworkInterfaceInfo`, `UserInfo<T>` and `UserInfoOptions`. Left out:
    `constants`, `getPriority`/`setPriority` and the Buffer-encoded
    `userInfo`.
  - **`fs`**: the synchronous functions this compiler implements, each
    in @types/node's shape, plus their helper types. `Stats` has no
    Date-valued times and `Dirent` no `path`, since neither exists here.
  - **`Buffer` and `URL`** are declared as types only (their
    constructors are not yet), with `NonSharedBuffer = Buffer`, plus
    `BufferEncoding`.
- **Checker**:
  - **Intersections.** An intersection of object types is one object
    with every member's properties. A property two members declare takes
    the narrower type, when one is assignable to the other. The result
    is partial if any member is open, and is marked `intersection`, so a
    missing property is reported as TS2322.
  - **Generic bases.** An interface's generic base is typed with its
    arguments (`interfaceOf(base, args)`).
  - **Object against a union.** It stays "maybe" only when the union has
    two or more object members.
  - **Weak types.** Picking an overload uses TypeScript's weak-type
    rule: a primitive does not fit an all-optional object type unless
    its apparent type shares a property. Ordinary assignment leaves this
    unreported, since tsc reports it as TS2559.
  - **Object-literal arguments** keep their literal property types while
    an overload is picked (`overloadArgType`), both for the pick and for
    TS2769.
  - **Tuple context.** An array literal whose context, `null` and
    `undefined` aside, is one tuple of its length is typed as that tuple.
  - **Elaboration through a nullable union.** A literal is elaborated
    against a `T | undefined` target's only object member.
- **Codegen** maps `NodeJS.Timeout` and `NodeJS.Immediate` to the id
  (`i64`).
- **libconform** skips member comparison for an interface only
  @types/node declares (`Buffer`), since those files do not parse whole.
  The name is still checked.
- **Two examples** read `readFileSync(path)` into a `string`, which tsc
  rejects. They now pass `'utf8'`: `examples/fs/fs.ts` and
  `examples/webview/spa_server.ts`.
- **The conformance shims** (`tools/conformance`: the Node suite's
  `common/fixtures`, the WPT fetch shim) read `readFileSync(path)` into a
  `string`. That rejected 303 Node-suite files once the `Buffer` overload
  was declared. They now pass `"utf8"`.
- **`TestE2ESetIntervalSelfCancelsViaAssignment`** typed its handle
  `number`, which tsc rejects (TS2322). It is now
  `NodeJS.Timeout | undefined`.

## Side effects discovered

- **`JSON.stringify`'s function-replacer overload was missing** from
  `lib/es.d.ts`. With the tightened union rule, a function replacer was
  TS2345 where tsc accepts it. The overload is now declared. A probe of
  the other members with fewer signatures than TypeScript's (libconform's
  review list), through their other overloads' common forms, found no
  more false positives.
- **A timer handle is a number, not a `Timeout` object.** Now a timers
  status caveat.
- **A primitive against an interface is not checked**
  (`fs.existsSync(42)`, BACKLOG).
- **A file-descriptor path gave invalid IR in every fs function.** Fixed
  in ADR-01150.
- **A closure did not narrow a captured binding along its own flow.**
  Fixed in ADR-01149.
- **A captured `number | undefined` gave invalid IR.** Fixed in
  ADR-01150.

  - `TestE2ENodeModulesDeclared` runs timers, `os` and `fs` with Node's
    output. It also checks seven misuses that tsc rejects.
  - `TestCheck` has cases for the tuple context, a generic base, an
    intersection, an optional parameter's object and a literal
    object-literal overload, each with tsc 5.6's code.
- **tsdiag:** 12 more matches (TS2322 +2, TS2345 +1, TS2353 +9) and no
  new false positives. The project's programs have 0 diagnostics.
- **libconform:** 0 divergences.
- **Gates (with ADR-01148–01153):**
  - Test262: strict 7,032 and js 7,832 (the handover's were 7,034 and
    7,825), no clang failures in either lane. The two strict files lost
    call `str.slice(obj, obj2)` with objects for `number` parameters,
    which tsc rejects (TS2345).
  - Node suite: strict 61, js 63, unchanged.
  - `make examples`: 360 pass. `chained_listen` timed out once, its
    known intermittent hang, and passes 3 of 3 runs alone.
  - `make test-par`: only the four macOS `-mm=gc` failures.
