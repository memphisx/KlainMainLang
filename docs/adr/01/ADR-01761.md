# ADR-01761: A non-callable array callback throws at run time

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

`arr.reduce(null)`, `arr.filter(undefined)` or `arr.some(5)` failed to compile under `-compat=js` ("callback must be an arrow function or function identifier"). Node throws a TypeError (`object null is not a function`) before it reads any element, even on an empty array. A callback held in `any` already takes a path that checks it is callable first. Test262 has a test of this for each Array method.

## Decision

When an array method's callback has a static type that is not a function (`nonCallableCallback`), it is passed as `any`, so the call takes the checked dynamic path. This covers `map`, `filter`, `find`, `findIndex`, `findLast`, `findLastIndex`, `some`, `every`, `forEach`, `flatMap`, `reduce` and `reduceRight`. The strict lane rejects these calls as tsc does.

## Consequences

- `TestE2ECompatJSNonCallableArrayCallback` covers it.
