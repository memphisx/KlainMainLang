# ADR-01518: A function read inside its own return is itself

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-09

## Context

While a function's return type is inferred, a read of the function in its
own body (`return inner.caller`) is circular. tsc gives the circular
return type `any` (TS7023) but keeps the read a function: `typeof inner`
with an `any` result. The checker typed the read plain `any`. The lib's
`Function` interface also lacked `arguments` and `caller`, which tsc's
lib declares, so `f.caller` had no type. The shadow oracle had no
representation for `Function`, which codegen holds as a dynamic value.
Shadow buckets 4 and 8 (240 rows) came from this.

## Decision

- The checker types such a read as the function's own signature with an
  `any` result, built from its parameters without its body.
- `Function` declares `arguments: any` and `caller: Function`.
- The oracle maps `Function` to `any`, as `resolveType` does.
- The shadow hook skips a read of a function whose return type is being
  inferred: codegen answers its recursion guard's `void` placeholder
  there, which no emission uses.
