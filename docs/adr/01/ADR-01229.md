# ADR-01229: Overload selection and contextual typing follow tsc more closely

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-09-29

## Context

`child_process` in TypeScript (TDD-00234) declares @types/node's overloads,
and its callers went through overload selection and contextual typing
paths the checker had not modelled:

- `exec(cmd, (err, stdout) => …)`: the callback's parameters were
  untyped, because the chosen overload's `callback?: F` context was
  `F | undefined`, which is no function type.
- `readonly string[]` was unanswered, so every overload set mentioning it
  (`spawn`, `spawnSync`) was unanswered, and so were their calls.
- `spawn(file, [], opts)`: an empty `[]` is unanswered alone, which aborted
  overload selection.
- `{ stdio: ["pipe", "inherit"] }` was typed `string[]` while fitting an
  overload, so no overload matched.
- `execFileSync("printf", ["ab"])` picked the `(file, options)` overload:
  an array was assignable to an interface with a required `encoding`
  (`maybe`), and to an all-optional options type (tsc's weak type check).

## Decision

- An argument's contextual type drops its nullish members when a function
  type remains (tsc's contextual signature).
- `readonly T[]` is `ReadonlyArray<T>` (lib/es.d.ts declares its
  `readonly [n: number]: T`). A readonly tuple is the tuple.
- For overload fitting, `[]` fits a parameter that takes an array
  (array, tuple, `ReadonlyArray`, or a union with one). An object
  literal's array-valued properties keep their elements' literal types.
- An array is not assignable to an object type with a required property
  its apparent type (`Array<T>`) lacks. A weak type (all properties
  optional) takes no array or primitive (TS2559) during overload fitting.

## Implementation notes

`checker/generics.go`, `checker/overloads.go`, `checker/relate.go`,
`checker/symbols.go`, `lib/es.d.ts`.

## Side effects discovered

- Test programs that tsc rejects were accepted before, because the
  context was missing: `sort((p, q) => { if (p !== q) return p - q })`,
  `res.setHeader(k, req.method)` with `string | undefined`,
  `process.kill(child.pid)`. They are made valid TypeScript.
