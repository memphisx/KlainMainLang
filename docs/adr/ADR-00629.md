# ADR-00629: D1 Stage 5 — property descriptors, accessors, real freeze/seal

- **Relations**: `Implements TDD-00155 (Stage 5)`, `Completes TDD-00022`, `Extends ADR-00628`
- **Date**: 2026-09-02

## Context

The attrs word every bag entry has carried since Stage 1 becomes live: the
descriptor tier of the object model — the surface the conformance corpus's
object-model probes exercise, and the last D1 stage before the static
bridge. Semantics are module-strict JS (Node ESM): rejected writes and
refused deletes throw, verified against `node` on `.mjs` sources.

## Decision

**Runtime** (`runtime_dynobj.go`; attr bits WRITABLE 1 / ENUMERABLE 2 /
CONFIGURABLE 4 / ACCESSOR 8; header non-extensible bit 1<<32):

- An ACCESSOR entry's payload is a `{getterRec, setterRec}` pair of raw
  Stage-4 dynamic-function records. `get` invokes the getter through the
  dynamic ABI with the **original receiver** boxed as `this` (inherited
  getters via the proto walk see the object the read started from);
  a getter-less accessor reads undefined.
- `setv` is the checked assignment (status: read-only / not-extensible /
  getter-only): inherited accessors run their setter against the receiver,
  an inherited read-only data property blocks, an inherited writable one
  shadows own, a miss defines own iff extensible. The member/bracket
  assignment glue surfaces each status as its JS TypeError (`Cannot assign
  to read only property 'x' of object`, …).
- `delete` refuses non-configurable (glue throws, strict-JS); the raw
  `set`/`get_at` stay the unchecked construction/JSON primitives.
- `keys_enum` (Object.keys / for...in / JSON) filters ENUMERABLE;
  `keys` keeps all own keys (getOwnPropertyNames). `merge` (spread) copies
  own enumerables *through the checked get*, so spread invokes getters and
  lands data properties — JS's `{...src}`.
- `defacc`/`patch` install/merge accessor pairs; `prevent` (mode:
  preventExtensions/seal/freeze) sets the header bit and sweeps attrs;
  `flags_test` answers isExtensible/isSealed/isFrozen by scan.

**Glue/statics** (`emit_dyndesc.go`): `Object.defineProperty` (spec create
defaults — absent attributes are *false*; redefinition merges present
fields; non-configurable rejects everything except a value write while
still writable; non-extensible rejects new keys), `getOwnPropertyDescriptor`
(data and accessor forms, built as a dynamic object), `getOwnPropertyNames`,
and dynamic-object branches for `freeze`/`seal`/`preventExtensions`/
`isFrozen`/`isSealed`/`isExtensible` (statically-typed objects keep the
frozen-pointer-set path). Object-literal `get x()`/`set x(v)` compile under
the dynamic ABI and install as enumerable+configurable accessor entries; a
function-valued property (a descriptor literal's `get:`/`set:` field)
compiles the same way. `dynjson.c` skips non-enumerable entries and calls
getters through the record (a small `nb_decode` mirror of the NaN-box
rules, kept in sync by comment).

**TDD-00022 completes**: under `-compat=js` an untyped object-literal
binding is now a D1 dynamic object — ad-hoc property add/delete on plain
literals (break shape 4's last edge) works, with field arithmetic riding
the ADR-00628 dispatch. `strict` keeps literals as native-speed static
structs.

## Consequences

- The descriptor verification program — hidden properties, read-only
  throws, accessor descriptors, inherited getters, freeze/seal/
  preventExtensions probes, getter-only assignment, spread-over-accessors
  — is diff-identical to Node (ESM). 9 new E2E tests.
- Disclosed: `Object.defineProperties`/`Object.assign` descriptor forms,
  `Object.entries/values` on dynamic objects, per-entry `Cannot delete`
  message detail, and sloppy-mode silent failures (compiled code is
  module-strict) remain out; the static-object `freeze` keeps its
  pointer-set mechanism.
- Verified on the Mac (arm64); batteries green.
