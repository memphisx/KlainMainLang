# ADR-01259: `const self = this`

- **Date**: 2026-09-29

## Context

`const self = this` in a method failed with "initializer's type is
incompatible with the variable's type". The declaration's type switch had
no case for `this`, so the binding took the scalar default.

## Decision

A `this` initializer takes the receiver's inferred type.

## Verification

Mac (Apple Silicon): `TestE2EThisAliasLocal` matches Node.
