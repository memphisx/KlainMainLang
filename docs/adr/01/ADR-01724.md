# ADR-01724: Per-evaluation class records are collectable under `-mm=gc`

- **Relations**: `Implements TDD-00230`, Extends [ADR-01338](ADR-01338.md)
- **Date**: 2026-10-18

## Context

A class declared in a function and used as a value gets a record per evaluation ([ADR-01336](ADR-01336.md), [ADR-01338](ADR-01338.md)). The runtime kept every record in four strong places:

- the set telling a record from a static reference;
- the map from each instance to its record;
- the map from each record to its static area;
- an alias of its constructor row in the constructor table.

Under `-mm=gc` none of them was ever collected. A loop that makes a class per iteration grew without bound: 400,000 evaluations reached 223 MB resident.

## Decision

- **Weak keys:** the three maps are weak in their key.
  - Under `-mm=gc` a key is held through a Boehm disappearing link, so a record or instance nothing else reaches is collected.
  - The entry, and the value it kept (an instance's record, a record's static area), goes at the next sweep of its table. Each lookup purges its bucket, and an insert sweeps the whole table once the inserts since the last sweep pass half the live count.
- **Constructor-row aliases:** a collected record's alias is removed from the constructor table, by backward-shift deletion so the other rows' probe chains stay whole. The alias row holds no managed pointer of its own (it is atomic memory), so it does not keep its record alive.
- **Static keys:** a class's own static reference is not a heap object, so its static area is kept for the program's life.
- **Manual mode:** the same tables apply. Nothing is collected there, so their links are never cleared, as before.

## Verification

macOS (Apple Silicon): `TestE2EGCModeClassRecordsCollected` builds under `-mm=gc` a class with statics and instances per call. Its peak RSS stays within 2× from 20,000 to 400,000 evaluations: about 5 MB at 2,000,000. Without the weak tables the same test reached 223 MB at 400,000 evaluations. The class-record, local-class, statics and `-mm=gc` suites pass.
