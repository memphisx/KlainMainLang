# ADR-01716: Sloppy-mode `this` is globalThis

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-18

## Context

Node runs a `.js` file without ES module syntax or a `"use strict"` directive as sloppy-mode CommonJS. There, a function called without a receiver (`f()`, or `f.call(null)`) sees `globalThis` as `this`. In `-compat=js`, `this` was `undefined`, so `this.x = …` in a plain call threw (BACKLOG #75). The js lane compiles a top-level function that reads its own `this` as a dynamic function expression. That rewrite also dropped the declaration's file, which stack frames name.

## Decision

- `sloppyFiles` records the program's own sloppy-mode files: `.js` or `.cjs`, not in the resolver's ES-module set, no `"use strict"` directive.
- A dynamic function expression from one of these files replaces an undefined or null receiver with `globalThis` on entry, as the language does for a sloppy function.
- The rewrite keeps the declaration's file.

## Verification

macOS (Apple Silicon): `TestE2EJSSloppyThisIsGlobal` passes against Node, and a `"use strict"` `.js` file and both `.mjs` forms keep `undefined`. The js-lane `this` and prototype E2E tests pass.
