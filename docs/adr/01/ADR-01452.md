# ADR-01452: `join` renders null and undefined as empty; Array `toString`

- **Relations**: none
- **Date**: 2026-10-07

## Context

`[1, undefined, null].join('-')` gave `1-undefined-null`; Node gives
`1--`. `String(arr)`, a template literal and `arr + ''` share the same join.
`arr.toString()` failed to compile ("an array has no method 'toString'").

## Investigation

- `emitArrayJoinCore` rendered a null pointer element as "", but converted a
  boxed `any` element and a nullable scalar through `emitValueToString`,
  which spells their absence out, and tested a three-state pointer only
  for the null pointer.
- `toString` had no array intrinsic.

## Decision

- An element whose box tags null or undefined, an absent nullable scalar,
  and either absence of a three-state pointer (`isAbsentPtr`) join as "".
- `Array.prototype.toString` is `join()`.

## Verification

- `TestE2EArrayNullishElementsJoin` and `TestE2EDynamicArrayJoinAbsent`
  (against Node, strict and `-compat=js`).
