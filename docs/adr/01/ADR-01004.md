# ADR-01004: `AbortSignal.reason` as `any` + fetch rejects with the reason

- **Relations**: Extends ADR-01003 (applies the TDD-00222 type-id to the next lying slot), Implements TDD-00081 (follow-on), Extends ADR-00240
- **Date**: 2026-09-18

## Context

`AbortSignal.reason` was the remaining "lying slot" noted in TDD-00169 §Context:
typed `errorObjType` yet holding whatever raw pointer `abort(reason)` coerced in.
A custom `abort("stop it")` stored the string pointer and read it back through
the error-object shape; `abort(42)` was worse (a small integer as a pointer). A
never-aborted signal's reason was a null pointer, not `undefined`. And the fetch
abort path ignored the slot entirely, always throwing a freshly built
`AbortError`/`TimeoutError` DOMException — Node rejects the fetch with
`signal.reason` itself, whatever value that is. Both were recorded as the
"custom `abort(reason)` still throws `AbortError`" caveat.

ADR-01003 removed the blocker: an Error boxed as a `kmlTagObject` `any` is now
recoverable at every render/member/instanceof site via its field-0 type-id, so
the slot can hold a faithful NaN-boxed `any`.

## Investigation

- All reason writes live in `emit_abort.go` (construction ×3, `abort(reason?)`
  ×2, the timeout dispatcher, and `AbortSignal.any`'s copy); the only runtime
  readers are the fetch await loop's `doabort` block (`runtime_fetch.go`) and
  the pipe abort helper (`runtime_streams_pipe.go`).
- The pipe helper already loads the slot as a raw `i64` and forwards it to
  `__kml_rs_cancel`/`__kml_ws_abort`/`__kml_prom_reject` — whose reason words
  everywhere else are NaN-boxed anys (`emit_streams.go:660`). The old raw
  pointer in the slot was a latent encoding mismatch; the flip fixes it.
- Layout: `errorObjType` (ptr) → `TypeAny` (i64) is the same 8-byte slot, so
  `deadlineNs` keeps the fixed field-3 offset `__kml_signal_aborted` and the
  hand-written signal GEPs rely on. The two hardcoded `{ i1, ptr, ptr, i64 }`
  struct literals (fetch/http) were updated to `{ i1, i64, ptr, i64 }` for
  accuracy (offsets were already identical).
- Making fetch throw the stored reason surfaced a **pre-existing bug**: a
  user-level `throw x` where `x: any` holds a boxed Error lost the Error shape
  at the catch site (`e.name`/`e.message` empty, `instanceof Error` false) —
  the throw carried tag `kmlTagObject` and no catch path restored tag 13.

## Decision

1. `AbortSignalType().reason` becomes `TypeAny`. Writes box: a user
   `abort(reason)` via `emitBoxValue`, the default/timeout DOMExceptions via
   `emitNbTagPtr(err, kmlTagObject)` (their field-0 type-id makes them
   recoverable), and construction stores boxed `undefined` — so a never-aborted
   signal reads `undefined`, per spec. `AbortSignal.any` copies the slot as
   `i64`. Reads need no work: the generic member path returns `any`, and the
   dynamic member/render/instanceof paths recover an Error via the type-id.
2. The fetch `doabort` block loads the slot and, when it is not `undefined`,
   unboxes (`__kml_nb_tag`/`__kml_nb_pay`) and throws it via
   `__kml_throw_any` — the same path a user-level throw of an `any` takes, so
   the awaited fetch rejects with `signal.reason` exactly as Node does. The
   `undefined` fallback (build the deadline-matched DOMException as before)
   stays load-bearing: `__kml_signal_aborted` latches a timeout signal's
   aborted flag without storing the reason, so the slot can legitimately still
   be `undefined` at the throw.
3. `__kml_throw_any` gains the type-id probe at entry: a `kmlTagObject` payload
   whose field 0 has the flag bit set and low bits below `errorSubclassTagBase`
   is a built-in Error — the throw is restored to tag 13 so catch handlers see
   the full Error shape. This fixes the pre-existing boxed-Error-rethrow bug
   for every throw site, not just fetch. Subclass instances (different layout)
   stay boxed, as elsewhere.

## Implementation notes

- `codegen/llvm/types.go` — the field flip.
- `codegen/llvm/emit_abort.go` — all reason stores box; `buildDefaultAbortReason`
  now returns the boxed i64.
- `codegen/llvm/runtime_fetch.go` — `doabort` split into `abreason`/`abdefault`;
  `ensureFetchAsync` gains `ensureNanBox`.
- `codegen/llvm/runtime_exceptions.go` — the `__kml_throw_any` probe; the
  uncaught printer and `@__kml_thrown` now key off the restored tag.
- `codegen/llvm/runtime_http.go` — signal struct literal accuracy fix only.
- Gotcha: comments inside the runtime IR raw strings must avoid backticks and
  stray `%` once the literal becomes a `fmt.Sprintf` format string.

## Side effects discovered

- The pipe-abort encoding mismatch (raw pointer where a NaN-box was expected)
  fixed in passing, above.
- Boxed error-*subclass* instances still render as `[object Object]` with no
  member recovery — needs class field metadata (TDD-00155 Stage 6), tracked as
  the remaining reason caveat.
