# ADR-01831: The integrity level lives in the header word

- **Relations**: `Implements TDD-00230` (phase 5: object identity never depends on the address; the header carries object state and an immortal bit)
- **Date**: 2026-10-20

## Context

- `Object.freeze`, `seal` and `preventExtensions` recorded a level in a set keyed by `ptrtoint(obj)`, for static objects and for arrays (keyed by the array header). Every write to an object field looked it up.
- That had three problems:
  - **The set was `_Thread_local`.** An object frozen on one thread was writable on another: a goroutine on another M thread, or a Worker's shared state.
  - **Its key was an address.** Under `-mm=manual`/`auto`, a frozen object freed and its address reused made the new object frozen.
  - **It cost a hash lookup on every object-field write,** frozen or not.
- Phase 5 rules out identity tables keyed by address. It gives the header word room for object state and an immortal bit.

## Decision

- **Bits 51..52 of the header word hold the level:** 0 none, 1 frozen, 2 sealed, 3 non-extensible.
  - A static object's word is its first. An array's precedes its `{data, len}` header.
  - A level only tightens.
  - Bit 53 marks an immortal header: the shared empty and absent array cells. No level is ever written to one. The absent cell is a read-only constant.
- **The runtime is C** (collections.c, arrayguard.c): `__kml_obj_level`, `__kml_obj_set_level`, `__kml_obj_extensible`, `__kml_array_level`, `__kml_array_set_level`. The frozen set is deleted. So is the IR-text definition of `__kml_obj_extensible`, which lowers `emit_record_view.go`'s IR-text allowance from 19 to 17.
- **A type test compares the header without its state bits.** On the Go side that is `headerIdentity`, at every whole-word comparison of a header with a type id: class tests and virtual dispatch, Error kinds, host shapes and map views, arrays and `arguments`, record views, promises and thenables. On the C side it is `KML_HDR_STATE_MASK`: `__kml_class_is`, the host-row lookup, the AggregateError test and the `arguments` test.
- The state constants, and the `static inline` helpers that read and tighten a level, are generated from Go into every runtime member's prelude (`hdrStateDefines`), not copied by hand. The array guard links without the collections unit, so the helpers cannot live in one member.
- A layout without a header word (none reaches these operations today) is treated as never frozen, statically.

## Consequences

- Freezing works the same on every thread and never outlives the object. A write to an unfrozen object costs one load and one compare instead of a hash lookup.
- A frozen class instance still passes `instanceof`, dispatches virtually, inspects and stringifies as before. A probe of class, literal, array and Error freezing matched Node in strict mode, and the freeze/seal/integrity E2E tests pass (Apple Silicon); the full gate runs on Linux x86-64 (DeskMini).
- Left open: `Object.freeze` and its family reject a `Map`, `Set`, `Date` or function value at compile time (status caveat).
