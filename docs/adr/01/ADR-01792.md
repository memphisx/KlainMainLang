# ADR-01792: A class's own static name or length member replaces the built-in one

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- `class C { static name() {} }` defines an own `name` property on C that replaces the class's name string. `C.name` still read the name string, directly and through a class held as a value. A static `length` method lost to the constructor length the same way.

## Decision

- `emitStaticFieldRead` checks the class's static methods before its built-in `name` and `length`.
- Through a class reference, `name` reads the class-reference get first and uses the class name only when that is undefined. The get rows drop their built-in `length` key when the class has a static `length`.

## Consequences

- `TestE2EJSFileStaticNameMember` compares direct, variable-held and array-held classes against Node.
