# ADR-00937: Boxed arrays render the util.inspect bracket form in console.log (TDD-00212 Stage 2)

- **Relations**: Implements TDD-00212; Relates to ADR-00936, ADR-00478, TDD-00062
- **Date**: 2026-09-14

## Context

Stage 1 (ADR-00936) taught an `any`-boxed array to render its contents in string
contexts (`String([1,2,3]) === "1,2,3"`). But `console.log(a)` on the same boxed
value routed through the ToString path too, so it printed `1,2,3` where Node
prints the `util.inspect` bracket form `[ 1, 2, 3 ]` (and `[ 'x', 'y' ]` with
single-quoted string elements). A statically-typed array already renders the
bracket form via `emitInspectArray`; the boxed case did not, because the dynamic
console.log arm shared one renderer (`emitDynamicToString`) with String().

## Decision

Give the dynamic render path an inspect mode, selected by `console.log` only:

- **Split the renderer.** `emitDynamicToString` and the new `emitDynamicInspect`
  are thin wrappers over a shared `emitDynamicRender(v, inspect)`. All scalar tags
  (int/float/string/bool/null/undefined) render identically in both modes — at the
  top level Node prints them bare, exactly as ToString does. Only the array tags
  differ. Inspect mode also skips the ToString-only `ToPrimitive` step
  (console.log inspects; it does not call an object's `toString`).
- **Flat any-array box** (`kmlTagArray`) → `__kml_array_inspect(data, len, kind)`,
  the bracket sibling of `__kml_array_join`: `[ ` / ` ]` padding, `, ` separators,
  single-quoted strings, `[]` when empty, and the `[Array]` placeholder when the
  element kind is the `-1` sentinel (matching `util.inspect`'s depth behaviour).
- **Dynamic array box** (`kmlTagDynArray`, the heterogeneous / empty-literal /
  nested case) → `__kml_dynarr_inspect`, the bracket sibling of
  `__kml_dynarr_join`. It walks the same D1 tag tree with inspect punctuation:
  quoted strings, `null`/`undefined` printed literally (not the empty join form),
  nested arrays recursing into the bracket form, `[Object]` for object elements.
  Without this, `console.log([])` on an `any` binding printed a blank line and a
  heterogeneous `[1,'hi',true]` printed `1,hi,true` — both now match Node.

`console.log`'s dynamic arm calls `emitDynamicInspect`; every other caller of the
dynamic renderer (template literals, `String()`, JSON, Map/dynobj value rendering)
keeps the ToString wrapper unchanged.

## Implementation notes

Files: `codegen/llvm/emit_dynamic.go` (`emitDynamicRender` split; array +
dynarr arms pick the helper by mode), `codegen/llvm/emit_call_console.go` (the
`IsDynamic` arm calls `emitDynamicInspect`), `codegen/llvm/dynjson_c.go`
(declare the two `_inspect` helpers), `codegen/llvm/dynjsonsrc/dynjson.c`
(`__kml_array_inspect`, `__kml_dynarr_inspect` + `inspect_arr`/`inspect_val`).
The `KJ_*` enum stays shared between join and inspect.

Live mutation through the box (Stage 3) is still out of scope: the box holds a
`{data,len}` snapshot, unchanged by this ADR.

## Verification

- `console.log` matches Node for number/float/string/boolean/nested/empty and
  heterogeneous boxed arrays; String()/interpolation still produce the flat comma
  join (unchanged from Stage 1).
- Full dynamic/collections/JSON/array/coerce/nullish suites pass.
- `make examples`. macOS arm64.
