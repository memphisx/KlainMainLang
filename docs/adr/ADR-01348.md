# ADR-01348: `TextEncoder` and `TextDecoder` are TypeScript

- **Relations**: Implements TDD-00230 (P3.4), TDD-00034 (Stages 0–3, Stage 4 single-byte), Extends ADR-01320, ADR-00112, Supersedes ADR-00567
- **Date**: 2026-10-03

## Context

TDD-00230 phase 3 ends with no `Is*` flags in codegen's `Type`: each host
type becomes a declaration the generic paths reach. `TextEncoder` and
`TextDecoder` were stateless codegen markers (`IsTextEncoder`,
`IsTextDecoder`) with sema `new` nodes, intrinsics for
`encode`/`encodeInto`/`decode`, and hand-written inspect strings.
`TextDecoder` decoded UTF-8 only, rejected every other label, and had no
`stream` option (backlog 86).

## Investigation

- Node's `lib/internal/encoding.js` is the model: WHATWG label
  normalization, `fatal`, `ignoreBOM`, `stream`, and the inspect forms.
  `TextEncoder`'s form prints no class name. Node was run as the oracle
  for each case, including two quirks: an invalid input's message names
  the `"list"` argument, and `latin1`/`ascii` decode as `windows-1252`.
- The URL migration (ADR-01320) is the template: a global module, then
  delete the `new` nodes, the sema mapping, the flags and the emitters.
- Buffer's UTF-8 decoder already replaces invalid sequences as WHATWG
  does. So the module only needs a validator, for `fatal` and for finding
  an incomplete tail when streaming.
- Strings are byte-indexed (backlog 25), so a decoded string cannot be
  checked for U+FEFF by code point. The BOM is stripped from the bytes.

## Decision

1. **`lib/node/kml_encoding.ts`** is a global module with `TextEncoder`
   and `TextDecoder`.
   - It decodes UTF-8 through Buffer, with a WHATWG validator.
   - It decodes UTF-16LE and UTF-16BE itself: a surrogate pair is
     combined, a lone surrogate or an odd byte is U+FFFD.
   - It decodes every single-byte encoding of the WHATWG list (28
     tables, the ISO-8859 and windows code pages, KOI8, IBM866,
     macintosh) and x-user-defined. The tables and the full label list in
     `internal_encoding_tables.ts` are generated from Node's own
     `internal/encoding` label table and its ICU decoders, with -1 where
     Node's fatal decoder rejects a byte.
   - It holds `fatal`, `ignoreBOM`, `stream` (a pending incomplete
     sequence) and the BOM-once state, with Node's `ERR_ENCODING_*`
     errors and inspect output.
   - `encodeInto` writes whole code points and counts UTF-16 units read.
   - `util.TextEncoder`/`util.TextDecoder` are the same classes, as in
     Node.
2. **Deleted:**
   - the `NewTextEncoderExpression`/`NewTextDecoderExpression` nodes, and
     their sema, checker and walker entries;
   - the `IsTextEncoder`/`IsTextDecoder` flags, `TextEncoderType`,
     `TextDecoderType` and `EncodeIntoResultType`;
   - the three intrinsics and `@intrinsic` annotations, the codegen
     `encode`/`encodeInto`/`decode` emitters (including the `any`
     ArrayBuffer path ADR-01347 had just added), the `.encoding` and
     inspect hooks, and the instanceof row.

## Implementation notes

- **Libraries:** `lib/node/kml_encoding.ts`,
  `lib/node/internal_encoding_tables.ts` (generated) and `lib/node.d.ts`.
- **Front end:** `ast/nodes.go` (the walker regenerated with
  `go generate`), `checker/checker.go`, `sema/builtin_new.go` and
  `resolver/rename.go`.
- **Codegen:** `codegen/llvm/emit_call_encoding.go`, `emit_exprs.go`,
  `emit_exprs_types.go`, `emit_exprs_member.go`, `emit_exprs_vardecl.go`,
  `emit_inspect.go`, `emit_inspect_host.go`, `emit_intrinsics.go`,
  `emit_lowered.go` and `types.go`.

## Side effects discovered

- `'﻿h'.length` is 4 here: strings are byte-indexed (backlog 25). The
  decoded string is right.
- The CJK encodings (GBK, GB18030, Big5, EUC-JP, EUC-KR, ISO-2022-JP,
  Shift_JIS), which Node decodes through ICU, throw
  `ERR_ENCODING_NOT_SUPPORTED` (TDD-00034 Stage 4).

## Verification

Mac (Apple Silicon), against Node v24.19:
- the encoding probe: encode, `encodeInto`, every decoder, `fatal`,
  `stream` with flush, BOM handling, labels, errors, a DataView, an
  ArrayBuffer and inspect. Everything matches except the length line
  above;
- every single-byte encoding and x-user-defined over all 256 bytes, with
  `fatal`, and the Greek labels, all byte for byte as Node;
- new test `TestE2ETextEncoderDecoderNodeEncoding`;
- the encoding, inspect, Web Crypto, fetch, stream and Blob groups.
