# ADR-01900: a base class's default type arguments for an inherited constructor

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

- A class without its own constructor extending a generic base without type arguments (`class FSWatcher extends EventEmitter`, with `EventEmitter<T = DefaultEventMap>`) constructs through the base's constructor with the base's defaults, as tsc instantiates it. The checker matched the clause's arguments to the base's parameters one to one, so a missing one left the constructor, and every `new` of the class, unanswered.

## Decision

- Missing base type arguments come from the parameters' defaults, each instantiated with the arguments before it; one without a default still leaves the constructor unmodelled.

## Consequences

- `new` of such a class is answered (the fs module's watcher, in every program linking fs).
