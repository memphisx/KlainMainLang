# ADR-01991: Two conformance-process crashes: a cyclic AST walk and unit-compile waiters

- **Relations**: Implements TDD-00230
- **Date**: 2026-11-20

## Context

The WPT conformance run (Linux x86-64, js lane) died with a Go stack
overflow inside `memplan.collectFinRegNames`. That scan walks the AST by
reflection, following every pointer field, and never remembered what it had
visited: an AST that reaches a node a second time (a back-reference closing a
loop) recursed until the 1 GB goroutine stack ran out, taking the whole
conformance process, and every result of the run, with it. No single
generated WPT program reproduces it through the CLI; the loop forms inside
the long-running conformance process, which compiles many programs.

## Decision

The walk keeps a set of the pointers it has entered, keyed by address and
type (a struct and its first field share an address), and enters each once.
A node reached twice is the same node, so the candidates and disqualified
names it records are unchanged.

## A second crash: unit-compile waiters

With the walk fixed, the same run died again in `cachedUnitObject`, the
library unit object cache. A caller that found another caller compiling the
same unit waited for it and, when no object appeared (the compile failed),
called itself again: it waited on the next compile, which failed the same
way, and in a process that keeps compiling programs the recursion had no
end. A waiter now takes the compile's own outcome (`unitJob`, its error
set before its channel closes): a failed compile hands its error to every
waiter once, and the program that needed the unit fails with it.

## Verification

`TestCollectFinRegNamesCyclicAST` builds a statement whose class's
constructor body holds that same statement, and checks the scan ends and
still finds the registry declared inside the loop.
`TestCachedUnitObjectFailedCompileWaiters` has sixteen callers compile one
invalid unit at once: each gets the compile error, and the unit is compiled
once. The WPT suite re-run on Node304 and in the arm64 container.
