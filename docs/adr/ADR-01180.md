# ADR-01180: A method returning `this` returns its receiver; the js lane's top-level bindings a function reads; `createConnection`

- **Relations**: `Extends [ADR-01171](ADR-01171.md)`, [ADR-01175](ADR-01175.md)
- **Date**: 2026-09-26

## Context

`const server = http.createServer(h).listen(0, client)`, with `server` read
in `function client()`, is how Node's own tests start a server. Under
`-compat=js` the function could not see `server` (`undefined variable
'server__kml_mod0'`, 16 files): the top-level binding was not promoted to a
module global. Promoting it needed its type, and code generation typed
`listen(…)`, which `net.Server` declares as returning `this`, as a
`net.Server` where tsc's polymorphic `this` gives the `http.Server`.

## Investigation

- The type converter replaced a class body's `this` type with the class's
  own name, so a method's `this` return became its declaring class.
- The promotion of an unannotated top-level binding a function reads
  (ADR-01171) compared codegen's inferred type with the checker's, and was
  off in the js lane.

## Decision

- The converter marks the polymorphic `this` (`TypeAnnotation.IsThis`); a
  method returning it (`FuncSig.RetThis`) returns its receiver's class when
  the receiver is a subclass of the declaring class, in the call's inferred
  type and in the emitted value's.
- The promotion runs in the js lane too (not for a binding the js lane
  widens across kinds), and accepts a class the checker and codegen agree
  on up to derivation, taking the more specific one.
- `http.request`'s `createConnection` option makes the socket: no agent,
  `Connection: close`, as `_http_client.js` does. Its declared result
  `net.Socket | undefined | void` needed `void` beside other union members
  to read as undefined, which the type converter now does.

## Implementation notes

`ast/nodes.go`, `ast/type_convert.go`; `codegen/llvm/types.go` (`RetThis`),
`emit_classes.go` (`thisRetType`), `emit_exprs_types.go`,
`emit_exprs_vardecl.go` (`classDerives`, `checkerClassType`);
`lib/node/internal_http.ts` (`ClientRequest`).

## Side effects discovered

None.
