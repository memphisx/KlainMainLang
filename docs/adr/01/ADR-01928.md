# ADR-01928: oracle rows — element joins, settled results, skipped `var`s, capture cells, dictionaries

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

The oracle disagreed with codegen, or left a node unanswered, on:

- an array literal whose elements the checker gives no layout for: generator objects (`[g()]`), or settled promises mixing `Promise.resolve(1)` with `Promise.reject(e)` (`Promise<never>`);
- an element read of such an array (`results[0]` of `Promise.allSettled`), whose `PromiseSettledResult` union has no mapping;
- a `var` declared in a `do` body, which the oracle treated as skippable like any nested block, although the body runs up to its first jump;
- a js-lane array literal that a store of another kind turns into `any[]` (`temps.source` defined with a string on a number array), which codegen holds as boxes;
- an object literal property bound to an identifier codegen holds boxed while its type maps to a scalar, and the binding of such a literal;
- a field holding `[...] as [string, string][]` in an object literal, and the literal's binding, which codegen builds as tuples;
- a closure-converted class's capture read (`this.#__kml_cap_x`), built after binding, which the checker never saw;
- a static member read through a module-level `let` holding a class, which codegen reads dynamically because the binding may hold a subclass;
- `FinalizationRegistry<T>` and `NodeJS.Dict<T>` themselves, which had no mapping, and `x!` over a dictionary's box;
- a `var` bound to a function expression that calls itself through the variable: the checker left it unanswered, where tsc types it `(arg) => any` and reports TS7023;
- a `var` bound to a function literal reading `arguments`, read by name, which carries the synthetic rest parameter;
- a js-lane function declaration's defaulted parameter, which codegen always holds boxed;
- the checker's answer for a callee depending on query order: inferring a js-lane function's parameters from its call sites types an argument whose contextual type reads the callee back, and the cycle's `any` was memoized on that callee node.

## Decision

- An array literal the checker leaves unanswered is the array of its elements' common representation. A `Promise<never>` element takes a sibling promise's layout.
- An unanswered element read of a static array is that array's element, read as an index read.
- A `do` body is scanned like a function body: a `var` in it is skippable only after a jump, and only if the `do` statement itself is reached.
- Codegen records the js-lane filled literals it makes `any[]`. The oracle reads that record through a hook, as it does widened bindings.
- An object literal's identifier-valued properties held boxed decide the literal's layout. Its binding holds the literal's storage, tuple-asserted fields included.
- A capture read stands for the identifier it replaced (`originate`). Its cell, which stands for nothing in the source, is marked lowered and is not a checker gap.
- A member read through a reassignable module-level binding of a class goes through the dynamic-receiver rule.
- `FinalizationRegistry<T>` maps to its handle over `T`. A generic dictionary interface maps as a dictionary view, and a non-null assertion of a dictionary's box is that box.
- The checker types a recursive `var` function expression read inside its own inference as itself with an `any` result, and reports TS7023 at the variable when it is called there, as for a declaration.
- A never-reassigned `var` of a function literal reading `arguments` carries the literal's synthetic rest, both read by name and as the global's type.
- A js-lane declaration's defaulted unannotated parameters map to the box.
- A symbol whose type is resolving is an open computation, as an open assignment is: an answer reached through its cycle is provisional and is not memoized past the resolution.

## Consequences

- The seven `examples/` files these buckets named compile with no shadow rows, except `finalization_registry.ts`'s reads of the `memory` module's marker, which the `klain:`-era module port replaces.
- The rest of the remaining rows are in Test262's js-lane files.
