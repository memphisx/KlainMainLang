# ADR-01580: Library code compiles the same whatever the program declares

- **Relations**: Extends ADR-01579, ADR-01326
- **Date**: 2026-10-11

## Context

`make drift` (CI's `examples + drift` job) found 172 of 4,429 builtin
library functions compiled differently between the examples. Three
program-wide facts reached library code:

- **`arguments` reads:** a class anywhere in the program reading
  `arguments` (`methodsReadArgs`) made every method and constructor call,
  library calls included, store its argument count.
- **Own-property assignments:** a method name the program assigns
  (`obj.m = fn`, `jsMemberWritten`) made every call of that method,
  library calls included, look for an own property shadowing it first.
- **AsyncLocalStorage:** a program using it (`programUsesALS`) made
  library timer, `nextTick` and promise-reaction callbacks capture the
  async context.

Before ADR-01579 the library's function literals were compiled with the
program, so the test did not see most of this.

## Decision

In program-independent code (`programIndependent`):

- **Argument counts:** method and constructor calls always store the
  argument count (`methodsMayReadArgs`).
- **AsyncLocalStorage:** callbacks go through `__kml_als_wrap`
  (asynchooks.c). It binds the context as `__kml_als_timer_tramp` does
  while one is current, and returns the callback itself otherwise. A
  program without AsyncLocalStorage has no context, so nothing is wrapped.
- **Own-property shadowing:** library calls of a class's methods take the
  class's method, as before the shadowing check existed. The program's own
  calls still check.

## Consequences

`make drift` reports 0 of 4,429 functions differing.

A method the program assigns on a library object (`socket.write = fn`) is
honoured when the program calls it, but not when library code calls it.
Doing that needs the own-property call path to handle every method kind:
`emitOwnOrClassMethodCall` fails on, for example, an iterator helper's
`some`.

## Verification

Linux: `make drift` on the DeskMini box. Mac: the AsyncLocalStorage,
timer, nextTick and emitWarning E2E tests and the shared-unit tests, run
with targeted `-run` filters.
