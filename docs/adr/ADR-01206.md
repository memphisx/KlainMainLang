# ADR-01206: console.log of Blob, Headers, ArrayBuffer and the text codecs

- **Date**: 2026-09-28

## Context

Found with ADR-01204: with static types, `console.log` printed a `Blob`
and an `ArrayBuffer` as empty lines, `Headers` as `Map(1) {…}`, and a
`TextEncoder` as `null`; inside an object a Blob printed as `''`.

## Investigation

`emitConsolePrintValueToken` (`emit_call_console.go`) and
`emitInspectField` (`emit_inspect.go`) had no cases for these types: a
Blob and an ArrayBuffer fell to the string path, Headers (a Map with
`IsHeaders`) to the Map path. Node prints `Blob { size: 2, type: '' }`,
`Headers { x: '1' }`,
`ArrayBuffer { [Uint8Contents]: <00 00>, [byteLength]: 2 }` (at most 100
bytes, then `... N more bytes`), `{ encoding: 'utf-8' }` for a
TextEncoder and
`TextDecoder { encoding: 'utf-8', fatal: false, ignoreBOM: false }`.

## Decision

`emitInspectHost` renders those five plus URLSearchParams, through the
same entry list and line layout as objects (`__kml_inspect_end`), both at
the top level and as a nested value, with `[Blob]`-style placeholders past
the depth limit and the keyword for an absent nullable one. Two C
helpers: `__kml_inspect_key` (a key bare when it is an identifier, quoted
otherwise) and `__kml_inspect_hex`.

## Implementation notes

`codegen/llvm/emit_inspect_host.go` (new), `emit_inspect.go`,
`emit_call_console.go`, `inspectsrc/inspect_reduce.c`, `inspect_c.go`.

## Side effects discovered

`Headers` stores names lowercased, so it prints `'content-type'` where
Node keeps the case it was given (BACKLOG).

## Verification

Mac (Apple Silicon): `TestE2EHostClassInspect` matches Node v24.19.
