# ADR-01592: `new a.b.C()` rooted at a value

- **Date**: 2026-10-11

## Context

`new dns.promises.Resolver()` failed with "unknown class 'Resolver'". So
did `new o.k.C()` for an object holding a class. One qualifier level
(`new promises.Resolver()`) worked.

## Investigation

`parseNew` (`parser/parser_literals.go`) kept only the last qualifier
segment. The resolver (`resolver/rename.go`) then saw
`Qualifier = "promises"`, which is neither a namespace member it knows nor
a value it can bind.

## Decision

- The parser records every qualifier segment (`QualifierPath`).
- When the path has more than one segment and its root is a value, the
  resolver turns the `new` into `new <a.b.C>()` with the member
  expression as the callee. A value root is one of:
  - a local;
  - a file binding;
  - an import namespace whose next segment it exports.
- A namespace root keeps the class-declaration path. Nested TypeScript
  namespaces still resolve as before.

## Verification

`TestE2ENewThroughValuePath` matches Node for the default-import and
namespace-import `dns` forms and for an object holding a class. The
namespace tests pass.
