# ADR-01668: emitCall as ordered rule lists over receiver owners

- **Relations**: Implements TDD-00230, Extends ADR-01664
- **Date**: 2026-10-17

## Context

`emitCall` (`codegen/llvm/emit_call.go`) was one function of about 730 lines: a chain of `if` blocks, each recognizing one shape of call and returning. Its largest block, about 250 lines, dispatched member calls on the receiver's type, interleaved with checks on property names. Which path a call took depended on where its block sat in the chain, and that ordering was written down only in comments. Phase 3 asks for one call path plus the intrinsic table.

## Decision

The chain becomes data, keeping its order, so the emitted code is unchanged:

- **Rules.** A `callRule` is `func(e, ex) (Value, done bool, error)`; each former block is a named rule. Its `return`s are wrapped in `handled`, and it ends with `done = false`.
- **Two rule lists.**
  - `callRewrites` run first: calls recognized by their shape, and desugarings that emit the call they rewrite to.
  - `callTargets` run after the method call's receiver guard. In order: the builtin's `@lower` declaration, plain-object function fields, namespaces and class statics, the receiver's owner, then the value fallbacks and diagnostics.
  - The guard stays in `emitCall` between the two lists, so its `defer undo()` still covers every target.
- **Receiver owners.** The member-call block is `receiverOwners`, an ordered list of one function per owner: flat array, request, builtin namespace, class, BigInt arrays, `any` arrays, ArrayBuffer/Buffer/number, dictionary `hasOwnProperty`, Map/Set/Weak collections, collection iterators, generators, function fields.
  - A class comes before the owners that match by name, so a class method sharing a builtin's name wins.
  - The dictionary owner comes before the Map owner, because a dictionary also answers to `IsMap`.
- **Name tables.** The request's methods (`requestMethods`) and the builtin namespace markers (`namespaceMethods`: `process`, `Memory`, `http`, `klain:http`) are tables keyed by name.

## Implementation notes

- Rule and owner tables are assigned in `init`. As package-level initializers, they form an initialization cycle through `emitExpr`.
- The conversion was mechanical. A script split the body at its top-level `if` statements, checked the block count against the list of rule names, and joined `return` expressions spanning several lines before wrapping them.
- The ArrayBuffer and Buffer owner merges what were separate checks on property names. The two host kinds are disjoint (`hostBuffer` derives from `hostTypedArray`, not `hostArrayBuffer`), so a single `switch` on the receiver keeps the old precedence.

## Side effects discovered

None.

## Verification

- Emitted IR is byte-identical for the 68-file IR list plus the buffer, streams and classes examples (99 files).
- Targeted tests pass on Mac: class, generator, flat-array, BigInt-array, collection, request and klain:http.
- test-par on Linux (Node304) and `make examples` on Linux (DeskMini) were run on this state.
