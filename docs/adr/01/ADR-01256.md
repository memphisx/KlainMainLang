# ADR-01256: A return's type sees the locals of the blocks around it

- **Date**: 2026-09-29

## Context

An arrow whose `return` sits inside `try { … }` and reads a local declared
there emitted invalid IR (`ret ptr` in a function returning `i64`).
For example, `() => { try { const p: any = …; return (p as Promise<any>).then(f) } finally { … } }`.
The return-type inference (`inferBlockReturnExpr`) bound only the body's
top-level locals, so the local was unknown and the inferred type fell back
to a scalar.

## Decision

Before inferring the first return's type, the declarations of every block
on the way from the body to that return are bound, outermost first. The
walk does not descend into nested functions.

## Verification

Mac (Apple Silicon): a `try`/`finally` return of a promise and of a string
from an `any`-returning closure matches Node; `TracingChannel.tracePromise`
(ADR-01254) relies on it.
