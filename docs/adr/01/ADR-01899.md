# ADR-01899: an annotation's literal-typed member in the oracle

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

- resolveType resolves an annotation's member typed by a string literal (`{ encoding: 'buffer' }`) as the literal, as it does a bare literal annotation or a union's literal member. The oracle kept the literal only for those two, so an object type's literal member disagreed in every annotation naming it (the fs module's `BufferEncodingOption`, in every program linking fs).

## Decision

- In annotation context the oracle maps an object type's literal-typed member as the literal.

## Consequences

- About 160 shadow rows go away; no emission change.
