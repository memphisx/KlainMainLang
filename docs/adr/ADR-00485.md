# ADR-00485: Readable.unshift(); Record<string, V> bracket parity

- **Relations**: Completes [ADR-00484](ADR-00484.md)'s stream-method sweep; clears TDD-00130's last deferral
- **Date**: 2026-08-29

## Context

Two remaining caveats: streams' `.unshift()` (the last survivor of the
"No `.read()`/`.unshift()`/…" line) and `Record<string, V>`'s missing
bracket parity (a `Record`-typed binding resolved to a plain `Map`,
whose value has none of the object-style surface — bracket assignment
errored "'r' is not an array").

## Decision

- **`unshift(chunk)`**: a new `__kml_rs_qunshift` runtime pushes onto the
  *front* of the chunk queue — reusing the free head slot when one
  exists, otherwise growing (qpush's doubling) and `memmove`ing the live
  region forward one slot. The read()/unshift() peek-then-put-back
  pairing round-trips. Inference rows for the whole new method family
  (`read`/`unshift`/`destroy`/`setEncoding`) added — an untyped
  `const c = r.read()` binds the chunk type.
- **`Record<string, V>`** (the open-key form) now resolves to the
  index-signature dict type (`IsDynamicObject`) instead of a plain
  `MapType`, so bracket read/write, `Object.keys/values/entries`,
  `for…of`, and `JSON.stringify` all ride the existing map-backed
  machinery — identical to `{ [k: string]: V }`. String-literal-union
  keys keep the fixed-shape object.

## Verification

Mac. `tests/streams_test.go` (unshift ordering + put-back round-trip)
and `tests/type_features_test.go`-adjacent Record E2E pass; full stream
+ Record/utility/mapped batches green. Oracles: Node 41, TS 57.2%
(unchanged — caveat clears).
