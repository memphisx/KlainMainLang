# ADR-01983: Array and function members of an intersection

- **Relations**: Implements TDD-00230 (P2.7); follows [ADR-01982](ADR-01982.md)
- **Date**: 2026-11-07

## Context

- `((x: number) => number) & { id: string }` had no checker type. The
  object merge accepted only object and interface members, so a function
  member made the whole intersection unanswered.
- `string[] & { tag: string }` merged into a plain object of the array's
  members. Its array storage was gone, and codegen had no type for the
  annotation.
- `b ? x : true`, `x` a `number | undefined`, stored the nullable
  aggregate into a `double` result: invalid IR.
- An identity `TransformStream<I, O>` (no transform callback) whose chunk
  types differ in representation was refused.
- Codegen's own intersection validation (`IntersectionMembers`,
  `mergeIntersectionFields`) had no remaining writer. Every intersection's
  type comes from the checker.

## Decision

- The merge takes a function member as an object with its signatures as
  call signatures, as tsc does.
- The merged type's `Intersects` lists the members as written. Codegen
  holds an intersection with an array member boxed, as it does one with a
  host or class member. That is the representation `Object.assign` on an
  array already gets.
- The dead intersection validation and its type field are deleted.
- A ternary of a nullable scalar and a scalar of another kind is boxed,
  as their union.
- An identity `TransformStream` with differing chunk types runs a
  generated pass-through that boxes each chunk and converts it to the
  output type, as `chunk as unknown as O` converts.

## Consequences

- Covered by `TestE2EArrayAndFunctionIntersections` and
  `TestE2ETernaryNullableScalarMixedKind`, both matching Node, and
  `TestE2EIdentityTransformStreamConverts`.
- A chunk of another kind converts (a string read as a number is `NaN`),
  where Node passes the value through. A typed slot can't hold it. The
  same divergence applies to `x as unknown as T`.
