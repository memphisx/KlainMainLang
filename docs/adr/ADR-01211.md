# ADR-01211: Objects built outside their type's layout, and three emitter slips

- **Relations**: `Extends ADR-01210`
- **Date**: 2026-09-28

## Context

The checked view (ADR-01210) compares an object's header with its static
type's layout id on every member read. The first full run failed about 40
tests. Each failure was an object whose memory did not match its static
type, or an emitter slip that the view's new code paths reached for the
first time. Before the view, the mismatched objects were read at the wrong
offsets without any check.

## Investigation

- **Mapped types.** `{ [K in keyof User]: boolean }` mapped every field of
  `User`, including the hidden header field. The result laid the header out
  as `i1`, so an object of that type was a 3-byte allocation that took an
  8-byte header store: a heap overflow.
- **`opts ?? {}`.** The right operand was built with no type hint, as an
  object with no fields, and then typed as the left's interface. Its
  members were read past the end of the allocation. `stream/promises`'
  `finished` did this on every call, and so did `http.createServer`'s
  options path.
- **An empty literal into an optional-only type** was not copied into the
  target layout (`objectRelayoutNeeded` required a source with fields).
- **An array-returning dynamic-to-static thunk** (a generic method read
  through `any`) returned the `{ptr, i64}` aggregate where the ABI returns
  the header pointer: invalid IR.
- **`strcmp`** was declared by hand in the SQLite and UTF-8 label runtimes
  instead of through `ensureStrcmp`, which gave a duplicate declaration
  when the layout table's key compare was also used.
- **Test build paths.** Four test helpers link a fixed list of C runtime
  files, not the program's `EmbeddedCSources`. They are unchanged: the
  view no longer pulls in the layout table when the program has no rows.

## Decision

- `resolveMappedType` maps the source's own fields (`UserFields`).
- A `??` whose left operand is a plain object type builds its right
  operand with that type as the hint and converts it to that type.
- `objectRelayoutNeeded` accepts an empty plain object as the source
  (`emptyRecordType`); every target field is absent in the copy.
- `finishDynToStaticThunk` returns an array result's header pointer
  (`arrayReturnHeader`).
- Both runtimes call `ensureStrcmp`.

## Implementation notes

`codegen/llvm/emit_mapped_types.go`, `emit_exprs_operators.go`,
`emit_exprs_coerce.go`, `emit_dynfunc.go`, `runtime_sqlite.go`,
`runtime_encoding.go`.

## Side effects discovered

None.
