# ADR-01585: Array search compares a null string slot by identity

- **Date**: 2026-10-11

## Context

Test262's `Array/prototype/indexOf/15.4.4.14-9-b-ii-3.js` and its
`lastIndexOf` twin, `[null].indexOf(null)`, passed before ADR-01583 and
segfaulted after it.

## Investigation

`[null]` is typed as a string array, and the element comparison
`emitElemEq` (`codegen/llvm/emit_arrays_core.go`) called
`strcmp(element, needle)` with both null. That is undefined behaviour. With
an ordinary call, LLVM's library-call folding removed it; ADR-01583 makes
every call `notail`, the call stayed, and strcmp read address 0 (macOS).

## Decision

A string element compares equal when the two pointers are the same. When
they differ and either one is null, they are not equal. Only two different
non-null strings reach strcmp. This covers `indexOf`, `lastIndexOf` and
`includes`, which all use `emitElemEq`.

## Verification

- New test `TestE2EArraySearchNullString`, whose expected output was taken
  from Node: macOS.
- The two Test262 files pass again (Linux x64).
