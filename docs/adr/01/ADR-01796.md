# ADR-01796: Object patterns over non-object array elements; dynamic element defaults

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- `[{ x }]` over an array whose elements are not static objects (`[null]`, strings, a union) failed to compile ("cannot object-destructure a non-object element"). JS reads the property off the element's object and throws a TypeError for null and undefined.
- In the js lane, `var [h = { q: 7 }] = []` printed NaN. An object literal infers as dynamic there, and `defaultFitsElem` let a dynamic default share the number element's slot. The default was converted to a number.

## Decision

- `unpackNestedArrayElem` binds such an element under a hidden name, as it already did for a defaulted element, and destructures that name as a value. Non-object sources box (ADR-01791), and null or undefined throw.
- `defaultFitsElem` no longer counts a dynamic default as fitting a static element type. The binding then holds either value as `any`.

## Consequences

- `TestE2EJSFileNonObjectElementPatterns` compares null, undefined, missing, object and string elements, and nested and plain defaults over an empty array, against Node.
