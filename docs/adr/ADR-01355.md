# ADR-01355: Construct-signature arguments are checked, and named as tsc names them

- **Relations**: Extends ADR-01350
- **Date**: 2026-10-03

## Context

`new DataView(buffer, Symbol("x"))` is TS2345 in tsc. After DataView moved
to TypeScript (ADR-01352), the program compiled, and the JS lane then emitted
invalid IR (ADR-01356). Codegen's own operand check had been the only thing
rejecting it.

## Investigation

- A `new X(…)` through a value's construct signatures (`declare var
  DataView: DataViewConstructor`) had its arguments typed but never checked.
- A generic signature (`new <T extends ArrayBufferLike>(buffer: T,
  byteOffset?: number)`) skipped every argument except the constraint check
  of the type parameters an argument infers. A parameter whose type names
  no type parameter was never checked.
- tsc names the target as the non-nullable type when a source that is
  neither null nor undefined misses a union of one type plus null or
  undefined. `x?: number` says `number`; `x?: string | number` says
  `string | number | undefined`.
- tsc reports an argument at its start. The checker used the argument
  node's own position, which for a call is its `(`.

## Decision

- `checkSignatureCall` is `checkCall`'s signature half. A `new X(…)` through
  a value's construct signatures runs it as a call.
- In a generic signature, each argument whose parameter type names no type
  parameter is checked as in a plain call.
- `displayTarget` names the target in TS2322/TS2345 as tsc does.
- Argument errors are reported at `startOf(argument)`.

## Implementation notes

`checker/check.go`; `tests/arraybuffer_test.go` now expects tsc's message for
the constructor case; `examples/classes/class_values.ts`.

## Side effects discovered

`examples/classes/class_values.ts` assigned `typeof Square` (constructor
`(side: number)`) to `typeof Shape` (constructor `(name?: string)`). tsc
rejects that with TS2322 and the calls with TS2345. The example now gives
both classes a numeric constructor, keeping every feature it shows.

## Verification

Mac (Apple Silicon), against tsc 5.9:
- the DataView constructor case, `f(x?: number)`, `number | undefined`,
  `number | null` and `string | number | undefined` targets, all with tsc's
  text and column;
- the checker binary under the memory guard and the unit packages;
- test-par on Node304.
