# ADR-00777: `os.tmpdir()` POSIX fidelity — empty-`TMPDIR` fallback and trailing-slash strip

- **Relations**: Extends [ADR-00739](ADR-00739.md) (Windows `os.tmpdir()` algorithm)
- **Date**: 2026-09-08

## Context

On POSIX hosts `os.tmpdir()` (`emitOSTmpdir`, `emit_os.go`) was
`getenv("TMPDIR") ? TMPDIR : "/tmp"` with no post-processing, diverging from
real Node in two ways the status page recorded as a caveat:

- **Trailing slash kept.** Node's `lib/os.js` `tmpdir()` strips a single
  trailing separator unless the path is the root — `TMPDIR=/foo/` → `'/foo'`.
  The port returned `'/foo/'`.
- **Empty `TMPDIR` not treated as absent.** Node computes
  `process.env.TMPDIR || '/tmp'`, so an empty string (falsy) falls back to
  `/tmp`. The port returned `''` because its fallback tested only the null
  pointer, not emptiness.

The third clause of the old caveat — "consults only `$TMPDIR`, not `$TMP`/
`$TEMP`" — was never a real gap: POSIX Node consults only `TMPDIR`; `TMP`/`TEMP`
are the Windows variables (already handled, ADR-00739). It was a mis-stated
caveat, removed here rather than "fixed."

## Investigation

`emit_os.go`'s POSIX branch built the result with a single `select` on
`icmp eq ptr null` — no length inspection, so neither the empty-string fallback
nor the trailing-slash strip was expressible without reading the string's
bytes. The header-string runtime already exposes everything needed:
`__kml_str_len` (length) and `emitStringExtract(src, start, len)` (the substring
primitive `String.prototype.slice` uses, `emit_strings.go:221`), with a
Value.Ref pointing at the NUL-terminated data so the last byte is a plain
`getelementptr i8 … , len-1` + `load i8`.

## Decision

Replace the `select` with a small branch:

1. `TMPDIR` null → `/tmp`.
2. else `len == 0` → `/tmp` (Node's `||` empty-is-falsy).
3. else strip iff `len > 1 && lastByte == '/'`: `newLen = select strip, len-1,
   len`, then `emitStringExtract(val, 0, newLen)`.

A `phi` merges the extracted path with the `/tmp` fallback. The Windows branch
(ADR-00739) is untouched. `os.tmpdir()`'s only caveat is gone, so it becomes
Strict-eligible (the status/reference strict counts move accordingly).

## Verification

- `go build`, `go vet ./codegen/...` — clean.
- Manual matrix (compiled binary, `TMPDIR` varied on the child run): unset →
  `/tmp`, `""` → `/tmp`, `/foo/` → `/foo`, `/foo` → `/foo`, `/` → `/`,
  `/a/b/` → `/a/b` — all match Node.
- 4 new E2E tests (`tests/os_test.go`) via a new `assertOutputImportsEnv`
  helper that overrides the environment for the child run only (a global
  `t.Setenv("TMPDIR", …)` would break `t.TempDir()`, which reads `TMPDIR`
  itself at build time): trailing-slash stripped, no-trailing unchanged, root
  not stripped, empty → `/tmp`. All pass.
- Verified on macOS (Apple Silicon).
