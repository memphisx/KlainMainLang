# ADR-01115: The checker types enums, `this`, and `any` as a dynamic type

- **Relations**: `Implements TDD-00230` (Phase 2, P2.3 and P2.6); `Extends ADR-01111`, `ADR-01113`
- **Date**: 2026-09-24

## Context

After [ADR-01111](ADR-01111.md) and [ADR-01113](ADR-01113.md), three
common constructs were still unanswered by the checker:
- an enum's members and its name as a type;
- `this` in a class;
- any member, element or call of an `any` value.

[TDD-00230](../tdd/TDD-00230.md) P2.6 makes `any` a real type with dynamic
semantics, distinct from the checker's "unanswered" marker.

## Investigation

- **tsc 5.6.3 `--strict`** confirms the enum expectations:
  - `Dir.E` is `Dir.E`, and so is a read of `let d = Dir.E` (declared
    `Dir`, narrowed by the assignment);
  - `let d: Dir = Dir.N` reads as `Dir.N`;
  - after `d !== Dir.N`, `d` is `Dir.E | Dir.S | Dir.W`;
  - a `switch`'s `default` past `Dir.N` and `Dir.E` is `Dir.S | Dir.W`;
  - a declared `Dir` prints `Dir`, and a string enum member `Col.Red`.
- **TypeScript's enum literal types** are number or string literal types
  that also name their enum and member. An enum type is the union of its
  members. A member widens to its enum type, not to `number`.

## Decision

- **Enums** (`checker/enums.go`):
  - each member is a number or string literal carrying its enum symbol and
    member name. Numeric members auto-increment from the previous value,
    from 0, and a string member needs its literal;
  - the enum's name as a type is the union of its members (printed by the
    enum's name when whole);
  - the enum's value is an object with a property per member;
  - widening a member gives the enum type, so narrowing and `switch` work
    on enums unchanged;
  - a computed member value, and a merged enum, leave the enum unanswered.
- **`this`** in a class's instance method, constructor or field
  initializer (through arrows, which keep it) is the class's instance, and
  in a generic class the instance over its own type parameters
  (`this.items` is `T[]` in `class B<T>`). In a static member, a function
  expression, an object literal's method or module code it is unanswered.
  The class comes from the parent table, and its symbol from a
  declaration-to-symbol table built on first use.
- **`any`**: a member, element, optional member or call of an `any` is
  `any`.

## Implementation notes

- **New:** `checker/enums.go`.
- **Changed:**
  - `checker/types.go`: an enum member's `Member` and `EnumSize`, and
    printing;
  - `checker/checker.go`: `this`, `any`'s members, elements and calls, and
    enum widening;
  - `checker/symbols.go`: an enum's value and type;
  - `checker/generics.go`: `thisType`, `classInstance`, `symbolOf`.
- The tests are in `checker/generics_test.go` and
  `checker/checker_test.go`.

## Verification

All on macOS arm64 (M4):

- `go test ./checker`: enums (numeric with explicit and auto values,
  string, a computed member, narrowing, `switch`), `this` (methods,
  arrows, static members, generic classes, object literals), and `any`'s
  members, optional members, elements and calls. The enum expectations
  were checked against tsc 5.6.3 `--strict`.
- Shadow report over the examples and apps (404 compile runs): 473
  disagreements, five more than ADR-01113's 468. All five are newly
  answered sites in the integer-as-`i64` representation bucket (ADR-01111):
  four numeric enum members (`Direction.East`, `StatusCode.OK`), which
  codegen holds as `i64`, and `this.radius * 2` in a field initializer in
  `examples/classes/classes.ts`.
- `make examples`: 357/358 on the first run. The failure was
  `examples/http/async_handler_inproc_client.ts` hanging, the intermittent
  hang BACKLOG §0 item 1 records. Its IR is byte-identical to the previous
  build's, and it passed three runs on its own.
- `make test-par`: the first run timed out in `TestE2EHTTPAgentInert`,
  another intermittent HTTP hang, added to the same BACKLOG item; it passed
  three runs on its own. The rerun passed apart from the four `-mm=gc`
  macOS segfaults (BACKLOG §0 item 1d), identical at HEAD.
