# ADR-01807: a string binding assigned null keeps the null

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- In the js lane, `var k = "y"; k = null; console.log(k)` printed `undefined`. The cross-type widening rule did not widen a string binding that is also assigned a nullish value, so the binding stayed a string slot, which cannot tell null from undefined.
- The widening walk did not look into nested functions. `var g = "s"; function f() { g = null; }` kept `g` a plain string slot, and so did a nested function assigning `g` a number.

## Decision

- `widenedKinds` widens a binding when "nullish" sits beside "string".
- In the js lane, the walk also visits nested functions. A nested function's assignment of a literal (null, number, string, boolean) to one of the scope's untyped bindings counts toward that binding's kinds, when the binding is free in the function. Only literals count: any other value's type belongs to the nested function's own inference.

## Consequences

- `TestE2EJSFileStringBindingAssignedNull` covers the local case, a function expression, a function declaration, and an arrow assigning a number.
