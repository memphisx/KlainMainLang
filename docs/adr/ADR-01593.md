# ADR-01593: Unannotated destructuring parameters

- **Date**: 2026-10-11

## Context

A function declaration's destructuring parameter required a type
annotation ("a destructured parameter requires an explicit type
annotation"). That message, raised by this compiler and not by tsc,
compile-failed:
- 7 node-suite files;
- 44 WPT files;
- 31 ts-suite cases;
- a Test262 file.

A destructuring parameter on a dynamic function (a `-compat=js` function
value) was a codegen error as well.

## Investigation

tsc types an unannotated pattern parameter the way it types an arrow's:
from its contextual type, then its default, and otherwise each binding
element is an implicit `any` (TS7031 under noImplicitAny).

The checker's `paramType` looked only at a parameter's own name. Pattern
leaves were never bound to a type, so the checker answered "unanswered"
for them.

## Decision

- **Parser**: accepts the unannotated pattern and gives the parameter the
  pattern's position.
- **Checker**:
  - `paramType` types a pattern leaf through `patternParamLeafType`:
    annotation, else contextual parameter type, else the default's type,
    else `any`, then `bindingType`.
  - `checkParams` reports TS7031 (`BindingImplicitAny`) for each leaf
    without a default, outside `-compat=js` and outside a contextually
    typed function.
- **Codegen**:
  - a dynamic pattern type gives every leaf `any`
    (`definePatternParamForInference`);
  - an array pattern over a dynamic argument unpacks with
    `unpackDynArrayParam`;
  - `resolveObjectPtr` reads a dynamic identifier through the dynamic
    unpack.
  - On a dynamic function, the argument is boxed into its own slot and
    unpacked with `unpackDynObjectPatternInto`/`unpackDynArrayPatternInto`.
  - `capturedLocalNames` sees the pattern's leaf names (`paramBindingNames`).
- The retired diagnostic is deleted.

## Verification

- checker, parser, diag and binder unit tests pass;
- E2E destructuring, pattern, closure, dynamic, js-mode, arrow, capture,
  callback, module and import suites pass on the Mac.
