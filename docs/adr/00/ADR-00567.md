# ADR-00567: TextDecoder validates its encoding label

- **Relations**: Extends ADR-00112
- **Date**: 2026-09-01

## Context

`new TextDecoder(label?)` evaluated the `label` argument for side effects and
then discarded it — every decoder was UTF-8 regardless of the label, and an
unrecognized label was accepted silently. Real `TextDecoder` throws a
`RangeError` for a label that maps to no encoding, and this compiler decodes
only UTF-8, so a `latin1`/`utf-16` label was silently mis-decoding (returning
UTF-8-interpreted bytes) rather than surfacing the unsupported encoding.

## Decision

Add `__kml_is_utf8_label(ptr) -> i1`: the WHATWG "get an encoding"
normalization (trim leading/trailing ASCII whitespace `0x09/0x0A/0x0C/0x0D/0x20`,
then ASCII-lowercase) into a stack buffer, compared against the six UTF-8
aliases (`utf-8`, `utf8`, `unicode-1-1-utf-8`, `unicode11utf8`, `unicode20utf8`,
`x-unicode20utf8`). `emitNewTextDecoderExpression` calls it and, when the label
is not a UTF-8 alias, throws a catchable `RangeError`.

This is faithful for two of the three cases and honest for the third:

- A **UTF-8 alias** (any case, surrounding whitespace tolerated) is accepted and
  decodes — matching real JS.
- An **unrecognized label** (`"bogus"`) throws `RangeError` — matching real JS.
- A **recognized non-UTF-8 label** (`latin1`/`utf-16`/…) throws `RangeError`
  rather than decoding. Real JS decodes these; this compiler cannot transcode
  them (UTF-8-only, TDD-00034), so throwing is the honest response — surfacing
  the unsupported encoding instead of silently mis-decoding. This is disclosed
  as the row's UTF-8-only caveat.

## Side effects discovered

None. The no-argument form (`new TextDecoder()`) is unchanged (defaults to
UTF-8), and a `"utf-8"` label continues to decode exactly as before.

## Verification

Rewritten `TestE2ETextDecoderLabelValidation` (UTF-8 aliases across case and
whitespace decode; `latin1` and `bogus` throw `RangeError`) plus the existing
TextEncoder/TextDecoder round-trip and unsupported-argument tests pass. Built
and verified on Mac (Apple Silicon).
