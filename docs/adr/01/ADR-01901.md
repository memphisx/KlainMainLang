# ADR-01901: an object literal's method reading `arguments` in the oracle

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets); follows ADR-01893
- **Date**: 2026-10-21

## Context

- An object literal's method that reads `arguments` takes the implicit rest parameter emission appends for it, so the literal's layout holds that method as a variadic function. The oracle mapped the literal from the checker's object type, which leaves the parameter out, at the literal, its binding's declaration and every read of the binding (the Test262 arguments-object method tests).

## Decision

- Wherever the oracle answers such a literal's layout, a method field reading `arguments` carries the implicit rest parameter, whether or not emission has already appended it to the method's declaration.

## Consequences

- The shadow rows for such literals go away; no emission change.
