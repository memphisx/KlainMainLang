# ADR-01511: A contextually typed arrow parameter takes any represented type

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-09

## Context

`checkerContextualParam` gave an unannotated arrow parameter its
contextual type only for a primitive, an `any`, or a builtin with a
native layout. A union (`flags: number | string`), a callback
(`cb: (err, fd) => void`) or an object fell back to an implicit `any`.
So an arrow stored in a typed field (`{ open: (path, flags, mode, cb) => … }`
returned as an interface) was compiled with boxed parameters while the
field's own type had typed ones. Shadow bucket 2 (526 rows).

## Decision

After the existing cases, and for a union, the parameter takes the
representation the checker's type maps to (`e.repr().of`), when it has
one. The strict lane
only, as before: in the js lane any caller can pass anything.

## Divergences

None.
