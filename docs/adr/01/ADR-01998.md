# ADR-01998: util.inspect marks cycles in dynamic values

- **Date**: 2026-11-21

## Context

On the Mac js lane the Node test `es-module/test-esm-path-posix.mjs`, six
lines long, went over 1.2 GB and the runner's reaper killed it. On Linux
(Node304) the same program reached 4 GB. HEAD does the same.

## Investigation

- The test calls `assert.strictEqual(pathPosix, posix)`. That assertion
  fails here ([ADR-01999](ADR-01999.md)), so the AssertionError builds its message with
  `inspectWith(val, 1000, …)`, which is Node's `inspectValue` at depth 1000.
- `path.posix` refers to itself (`posix.posix`) and to `win32`, which refers
  back. The dynamic inspector (dynjson.c `inspect_obj`, `inspect_arr`,
  `inspect_static`) had no record of the values it was in the middle of
  rendering. A cycle therefore recursed to the depth limit, and at depth
  1000 the output grows exponentially.
- `console.log` of a self-referencing object printed
  `{ a: 1, self: { a: 1, self: { a: 1, self: [Object] } } }`. Node prints
  `<ref *1> { a: 1, self: [Circular *1] }`.

## Decision

The inspector keeps util.inspect's `ctx.seen`: a per-thread stack of the
objects and arrays being rendered. A value met again inside itself prints
`[Circular *N]`, and the outer value gets `<ref *N> ` in front of its opening
brace. Refs are numbered in the order cycles are found, and the count
restarts with each top-level inspect. As in util.inspect, the check runs
before the depth limit, and the prefix counts toward the 80-column
single-line budget.

## Implementation notes

- codegen/llvm/dynjsonsrc/dynjson.c: `ins_circular`, `ins_enter`,
  `ins_leave`; used by `inspect_obj`, `inspect_arr`, `inspect_static`.

## Verification

- Linux x86 (Node304): `TestE2EInspectCircularRefs` matches Node (js lane)
  for a self-reference, two nested refs, a shared value that is not a cycle,
  and the assert message for two cyclic objects. The
  `Inspect|Assert|Console|Util|Circular|JSON` E2E tests pass.
- An array whose static type is inspected by compiled code
  (`const arr = [1]; arr.push(arr)`) still nests to the depth limit
  (`[ 1, [ 1, [ 1, [Array] ] ] ]`). That output is bounded, but it is not
  Node's `<ref *1> [ 1, [Circular *1] ]`.
