# ADR-02012: process.version's native in C

- **Relations**: Implements TDD-00230
- **Date**: 2026-11-21

## Context

TDD-00230 Phase 4 moves the runtime the compiler writes as IR from Go into
C. `__kml_native_process_version` (process.version, versions.node,
versions.v8 and the compiler's own version) was still a function emitted
as IR by `ensureNativeProcessVersion`. The compiler's version is set when
the compiler is built (`-ldflags -X`), so a cached runtime object cannot
hold it.

Separately, four entries of the lowering tables (`runtimeUnits`,
`runtimeSymbols`) were empty functions: units the link already takes by
symbol.

## Decision

- loop.c defines `__kml_native_process_version`. It reads the four strings
  from `__kml_process_versions`, a constant array that the program defines
  as data.
- The empty table entries are `linkedBySymbol`.

## Implementation notes

- codegen/llvm/loopsrc/loop.c, codegen/llvm/runtime_process_native.go,
  codegen/llvm/emit_lowered.go.

## Verification

- `process.version`, `process.versions.node` and `process.versions.v8`
  print the same as HEAD; the process-version tests and
  `TestIRTextOnlyShrinks` pass on Linux x86 (Node304).
