# ADR-01949: Computed `keyof` reads on objects; nested generic functions

- **Relations**: Implements TDD-00230
- **Date**: 2026-10-28

## Context

Three gaps, found while checking three-state values against Node:

- `o[k]`, with `k` a `keyof O` that is not one literal (a parameter, a loop variable), failed on a static-shape object with "'o' is not an array". Only a class instance could be indexed by a run-time key.
- A generic `T[K]`, `K extends keyof T`, resolved to `i64` in each specialization whenever the key was not a single literal. `get(o, "name")` returned `0` for a string field.
- A generic function or generator declared inside a function or a block was rejected ("a generic nested function declaration is not supported").

## Decision

- **Run-time key reads and writes:** a static-shape object indexed by a string-typed key that is not a constant takes the class-instance path. The object is boxed, the property is read or written by name at run time, and the result converts to the checker's type for the expression when that type is a primitive. Arrays, tuples, Maps, Sets, dictionary objects, dates, functions and typed arrays keep their own paths.
- **`T[K]` with a non-literal key** is the union of the fields the key can name: all of them, or the ones a literal union lists. It is their shared type when they have one representation, and the box otherwise.
- **Nested generic declarations:** before code generation, a generic function declaration inside a block has its type parameters erased to `any` in its annotations, as a generic function expression's are, and is then compiled as a plain nested function. A nested function is compiled once, closing over its enclosing locals, so it cannot be specialized per instantiation as a top-level generic is. The checker has already typed every call. The declaration keeps its hoisting, name and length.

## Consequences

- Tests: `TestE2EKeyofIndexStaticObject`, `TestE2EThreeStateInRecordsAndSpreads`, `TestE2ENestedGenericFunction` (which replaces the test that asserted the rejection). Example: `examples/generics/nested_generic_functions.ts`. Each output is compared against Node, on macOS (Apple Silicon).
- A nested generic function's values pass through boxes where a top-level one would be specialized. That is a speed difference, not a behavioural one.
