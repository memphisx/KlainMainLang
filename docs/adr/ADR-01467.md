# ADR-01467: Linear provisional types for mutually dependent locals; `Array()` as a call

- **Relations**: Extends ADR-01121
- **Date**: 2026-10-08

## Context

The TypeScript conformance suite's js lane ran out of memory (past 50 GB)
on `controlFlowSelfReferentialLoop.ts`: an md5 round, where untyped locals
`a`, `b`, `c`, `d` are assigned from calls on each other inside a loop. The
same case then failed to compile because `Array()` was called without
`new`.

## Investigation

- The checker answers a type that reads a binding whose assignment is still
  being computed provisionally (`TypeOf`'s `provisional` map), recording the
  open assignments it depended on in `c.cuts`. A reused provisional answer
  appends its dependency list to `cuts` again, and each new dependency list
  was copied from `cuts` without removing duplicates. With four bindings
  each depending on the other three, the lists doubled at every level: the
  crash was a 4 GB `append` with 19 GB already in use.
- A reduced input (16 rounds of the four assignments) exhausts a 6 GB cap
  in 8 seconds on the unfixed checker.
- `Array(n)` is `new Array(n)` (ECMA-262 §23.1.1.1). Only the `new` form was
  lowered (`sema/builtin_new.go`); the call reached codegen as a call of an
  undefined function.

## Decision

- A query's dependency list holds each open assignment once, and `cuts`
  past the query's mark is replaced by that list: an assignment closed
  inside the query stays closed for every enclosing one, so nothing an
  enclosing query needs is dropped. `cuts` is now bounded by the number of
  open assignments.
- `sema` lowers a call of the global `Array` (no local binding of that
  name) as `new Array` with the same arguments and type arguments.

## Implementation notes

`checker/checker.go` (`TypeOf`), `sema/sema.go` (the walker's call case).

## Verification

Mac: `TestE2EMutuallyDependentUntypedLocals` (fails with out-of-memory on
the unfixed checker, verified on Linux under a 6 GB cap),
`TestE2EArrayCalledAsFunction` (same output as Node, including a parameter
named `Array`). Linux: the full TS-suite js lane.
