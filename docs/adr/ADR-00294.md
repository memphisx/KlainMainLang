# ADR-00294: `DataView` over `ArrayBuffer`

- **Relations**: Extends [TDD-00018](../tdd/TDD-00018.md)'s ArrayBuffer/TypedArray family; picked from the [ADR-00288](ADR-00288.md) histogram (264 files gated) and the roadmap's Binary/`Blob` enabler tier
- **Date**: 2026-08-22

## Decision

`new DataView(buffer, byteOffset?, byteLength?)` with the full accessor set
— `get/set` × `Int8/Uint8/Int16/Uint16/Int32/Uint32/Float32/Float64` with
the spec's per-call `littleEndian` flag (default **false**, big-endian) —
plus `.byteLength`/`.byteOffset`/`.buffer`.

- **Representation**: TDD-00018's hidden-heap-struct convention — a ptr to
  `{ ptr data, i64 byteLength, i64 byteOffset, ptr bufHdr }`, with `data`
  the buffer base already advanced by the offset and `bufHdr` the owning
  ArrayBuffer's own header, so `.buffer` returns the aliasing-identical
  ArrayBuffer.
- **Endianness**: the hosts are little-endian, so a big-endian access
  byte-swaps through the `llvm.bswap.i16/32/64` intrinsics; the runtime
  flag folds with a `select`. Float accessors bitcast through the matching
  integer width (`Float32` via `fptrunc`/`fpext`).
- **Bounds**: both construction (`offset+length ≤ buffer.byteLength`) and
  every access (`offset+width ≤ byteLength`, negative rejected) throw the
  spec's RangeError as a catchable error.
- No `BigInt64`/`BigUint64` accessors (same scope line the TypedArray set
  drew) and no `getFloat16`.

A general expression (like ArrayBuffer, unlike the TypedArray constructors'
vardecl-only restriction). The resolver's reference-rewrite walker gained
the new node — without it, a module-renamed `buf` argument went stale
(caught during verification).

## Verification

Node-diff (byte-identical): default/explicit endianness on every width,
signed/unsigned re-reads, `Float32`/`Float64` round-trips, sub-range views
with `.buffer` aliasing both directions, access + construction RangeErrors.
E2E: `TestE2EDataViewBasics`, `TestE2EDataViewSubRangeAndBounds`; example
`examples/basics/dataview.ts`. Full suite + `make conformance` at delivery.
