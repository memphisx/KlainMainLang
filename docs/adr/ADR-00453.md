# ADR-00453: namespaces V3 — nesting, dotted names, relative references

- **Relations**: Implements [TDD-00148](../tdd/TDD-00148.md) (extends its shipped scope); Extends [ADR-00450](ADR-00450.md)
- **Date**: 2026-08-29

## Context

After V2 shipped, the refreshed TS-oracle histogram put the two scopes V2
had deferred at the top of the namespace cluster: nested namespace members
(155 "unsupported namespace member" false-rejects) and dotted declarations
(`module A.B.C {}`, 37).

## Decision

Flatten nesting into dotted namespace names, reusing every V2 mechanism:

- `ast.NamespaceMangle` flattens dots through the same `__kmlns_` infix
  (`A.B` member `f` → `A__kmlns_B__kmlns_f`).
- Parser: `parseNamespaceDecl` splits into `parseNamespaceName` (dotted
  names allowed — `module A.B {}` is the nested shorthand) and a recursive
  `parseNamespaceBody`; a nested `namespace`/`module` member recurses with
  the extended dotted name and its desugared declarations flatten into the
  parent's list. The V2 dotted-name rejection is gone.
- Codegen: `emitFunctionDeclAs` reconstructs the dotted namespace from the
  *last* `__kmlns_` infix; a new `namespaceByChain` resolves outside
  `A.B.member` chains (member-expression chains of pure identifiers,
  including the resolver's `__kml_modN` root suffix) at the call, value,
  and both inference sites; `namespaceMembers` gains relative resolution —
  `B.f()` written inside namespace `A` walks enclosing scopes innermost-
  outward to find `A.B`, matching TS lookup order.

## Implementation notes

`ast/nodes.go`, `parser/parser_stmts.go`, `codegen/llvm/emit_call.go`
(chain + relative helpers), `emit_exprs_member.go`, `emit_exprs_types.go`,
`emit_func.go`. Non-exported enforcement carries over to chains.

## Verification

Mac. `tests/namespaces_test.go` V3 test (nesting, dotted declaration,
relative sibling-namespace reference, non-exported member used by an
exported sibling, outside chains) replaces the V2 dotted-rejection test;
`examples/language/namespaces_v2.ts` extended; parser + namespace suites
green. TS oracle: **54.9% → 55.2%**. Node oracle unchanged (37).
