# ADR-01412: A primitive is never assignable to a generic function parameter

- **Relations**: Extends ADR-01217
- **Date**: 2026-10-05

## Context

The checker checks a generic call's arguments only against constraints it
infers, and a generic overload whose type parameters stay unanswered "may
fit" any argument. `setTimeout(5, 10)` therefore type-checked: both of its
overloads take a function first, one of them generic. tsc rejects it
(TS2769). The intrinsic `setTimeout` had rejected it in code generation;
once `setTimeout` lowered to a library function (ADR-01411), nothing did.

## Decision

An argument whose type is a primitive (a string, number, boolean or bigint,
or a literal of one; not a union, `any` or an object) passed for a
parameter whose type is a function fails under every instantiation, so it
is reported as not assignable: in a generic call (TS2345) and in overload
resolution, where it makes that overload a misfit (TS2769 when none fits).

## Consequences

Test262's strict lane loses one file it passed wrongly:
`built-ins/Reflect/apply/target-is-not-callable-throws.js` calls
`Reflect.apply(1, 1, [])`, which tsc rejects (TS2769: neither overload's
first parameter, a function or `Function`, takes a number); the strict lane
rejects what tsc rejects. Verified with tsc 5 against the same call.

## Verification

- Mac (M4): `setTimeout(5, 10)` and a generic `f<T extends any[]>(cb: (...a:
  T) => void)` called with `5` are rejected as tsc rejects them; the
  checker's tests (under the guard) and `TestE2ESetTimeoutNonFunctionCallbackRejected`.
- Linux (x86-64, Ubuntu 24.04 container), with ADR-01410 to ADR-01415: the
  full test suite, the 394 examples, and Test262 in both lanes (strict 8,497,
  the one file of ADR-01412 fewer; js 10,506; no invalid IR).
