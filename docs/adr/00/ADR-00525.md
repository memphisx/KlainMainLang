# ADR-00525: Binary-safe `fs.copyFileSync`

- **Relations**: Extends ADR-00027, ADR-00094
- **Date**: 2026-08-31

## Context

`fs.copyFileSync(src, dest)` was implemented (ADR-00027) as a compose of the
string-based `readFileSync`/`writeFileSync` runtime helpers. Both of those go
through the text path — `__kml_fs_read_file` copies the raw buffer into a
length-prefixed string but hands back a bare `ptr`, and `__kml_fs_write_file`
recovers the length via `strlen`. The upshot: a source file containing an
embedded null byte copied back truncated at the first null, so a binary file
(image, gzip, etc.) could not be copied faithfully. This was tracked as a
Fidelity Gap on the status index.

The binary-safe primitives ADR-00094 added for `readFileSyncBytes` /
`writeFileSync(path, ArrayBuffer)` already carry an explicit byte count, so no
new C-level I/O was needed — only a rewire.

## Investigation

`codegen/llvm/runtime_fs.go` already exposes `__kml_fs_read_file_raw(path) ->
{ptr, i64}` (buffer + true byte count from `ftell`) and
`__kml_fs_write_file_bytes(path, data, len)` (writes exactly `len` bytes via
`fwrite`, no `strlen`). `emitFsCopyFileSync` in `codegen/llvm/emit_fs.go` just
had to call the raw reader, `extractvalue` the `{ptr, i64}` pair, and pass both
to the bytes writer.

## Decision

Route `copyFileSync` through `__kml_fs_read_file_raw` +
`__kml_fs_write_file_bytes`, threading the exact byte count end-to-end. The two
`ensure*` calls swap from `ensureFsReadFile`/`ensureFsWriteFile` to
`ensureFsReadFileRaw`/`ensureFsWriteFileBytes`.

## Implementation notes

Single function rewrite in `emit_fs.go`; no runtime helper changes. The
existing wrong-arg-count compile error is untouched.

## Side effects discovered

None.

## Verification

`TestE2EFsCopyFileSyncPreservesEmbeddedNullByte` (new) writes a fixture with an
embedded null via real Go `os.WriteFile`, copies it via KML, and confirms the
destination bytes are exactly equal via real Go `os.ReadFile`. The existing
`TestE2EFsCopyFileSyncCopiesContent` still passes. Verified on Mac (Apple
Silicon).
