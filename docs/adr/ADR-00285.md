# ADR-00285: `console.log` prints Node-faithfully — space-joined arguments, bare-newline no-arg call, unprefixed `warn`, `-0` display

- **Relations**: Extends [ADR-00183](ADR-00183.md) (the "deferred shortcuts get fixed on sight" precedent — boolean printing) and TDD-00080's float formatter
- **Date**: 2026-08-22

## Context

Three long-standing `console` divergences from real Node, hit while
node-diffing the ADR-00284 battery:

1. `console.log(a, b)` printed each argument on its own line (a documented
   internal convention) — Node joins them with a single space on one line.
2. `console.warn` prepended an undocumented `"Warning: "` prefix — Node's
   `warn` is identical to `error`: the arguments, unprefixed, to stderr
   (one of the 2026-08-11 audit findings).
3. `console.log(-0)` printed `0` — Node's util.inspect displays `-0`
   (`String(-0)` is `"0"`, and stays so here; only the console display
   special-cases it).

Also fixed in passing: `console.log()` with no arguments now prints a bare
newline (it printed nothing).

## Decision

- `emitConsolePrint`'s per-argument terminator becomes `" "` for every
  argument but the last, `"\n"` for the last — threaded through every
  argument-type branch and the nullable-scalar helpers
  (`emitConsoleNullableScalar`/`...Agg`/`emitConsolePresenceBranch`/
  `emitConsoleScalarValue` gain a `term` parameter). `console.group()`'s
  indent is now applied once per call, since a call is one line.
- The `warn` dispatch passes an empty prefix; `trace` keeps `"Trace: "`
  (Node prints that prefix too — the missing stack trace remains a caveat).
- The console float branch checks the exact `-0.0` bit pattern (`bitcast` to
  i64, compare against the sign-bit-only value) and selects an interned
  `"-0"` over the formatter's output. Template literals and `String()` are
  untouched.

## Verification

- Node-diff (node v26.3.0, byte-identical): `console.log(1, "two", true,
  [3, 4])`, `console.log()`, `console.log(-0.0)`, `Math.round(-0.5)` display,
  mixed strings/numbers/arrays across one line.
- Existing E2E expectations updated wherever they asserted the old
  one-line-per-argument output; full `go test ./tests/` green.
