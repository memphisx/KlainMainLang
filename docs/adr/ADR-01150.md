# ADR-01150: Invalid IR: captured and module-level nullable scalars, a non-string fs path, an array in a scalar slot

- **Relations**: `Extends ADR-01148`
- **Date**: 2026-09-25

## Context

Three kinds of invalid IR came up while testing the declarations in
ADR-01148. HEAD has all three.

- **A captured nullable scalar.**
  `let id: number | undefined; const f = () => console.log(id)`. The
  same idiom with a timer handle is
  `let t: NodeJS.Timeout | undefined; t = setInterval(() => clearInterval(t), 5)`.
- **A top-level `let c: boolean | undefined` read by a named function**
  was `undefined variable`.
- **A number or boolean fs path.** `fs.unlinkSync(42)`,
  `fs.readFile(4, cb)` and `fs.copyFileSync(1, 2)` stored a `double` as a
  `ptr`.
- **An array in a scalar slot.** `const s: string = xs` in `-compat=js`
  stored a `{ ptr, i64 }` as a `ptr`.

## Investigation

- **Captured and module-level nullable scalars.** A nullable scalar
  local's slot is the `{ i1, T }` aggregate (`NullableBoxed`, TDD-00064).
  Several paths treated it as a bare scalar:
  - `promoteCaptureToCell` sized its cell with `ty.IR` and dropped
    `NullableBoxed`. Both sides then read an 8-byte `double`.
  - The per-iteration loop cells (ADR-01147) did the same.
  - `emitNullableScalarVarDecl` never consulted `hoistedCaptures` or
    `promotedGlobalDecls`, since the nullable branch returns before them.
  - `isSimpleGlobalType` excluded nullable scalars from module-global
    promotion.
- **A non-string fs path.** Every fs path argument went through
  `coerce(v, TypePtr)`, which leaves a number untouched. Node reads a
  number as a file descriptor for `readFileSync`/`writeFileSync`/
  `appendFileSync`, and throws `ERR_INVALID_ARG_TYPE` elsewhere.
  `existsSync` answers `false`.
- **An array in a scalar slot.** `coerciblePure` passed arrays by IR
  equality, but an array value is its aggregate.

## Decision

- **Capture cells** hold the `{ i1, T }` aggregate: 16 bytes, loaded and
  stored as the aggregate, and still `NullableBoxed`. This covers
  `promoteCaptureToCell`, `boxHoistedNullableCapture` (the eager box) and
  the per-iteration loop cells. A closure's view of a captured cell keeps
  the enclosing symbol's `NullableBoxed`.
- **Module globals.** A top-level nullable scalar with a declared type is
  promoted to a module global with the aggregate's type,
  `zeroinitializer` (absent). `emitVarDecl`'s nullable branch stores into
  that global or into the eager box.
- **fs paths.** `fsPath` guards every fs path coercion. A number or a
  boolean is the clean error "a path must be a string; a file descriptor
  path is not supported". `existsSync` answers `false` for one, as Node
  does.
- **`coerciblePure`** rejects an array going into a string, number or
  boolean slot.

## Side effects discovered

- **File-descriptor paths** (`readFileSync(fd)`, `writeFileSync(fd, …)`,
  `appendFileSync(fd, …)`) are not implemented. Now a file-system status
  caveat.
- **A narrowed `RegExpExecArray | null` can't be indexed** (BACKLOG).

## Verification

- **New tests, with Node's output:**
  - `TestE2ENullableScalarCaptured` covers lazy, eager and per-iteration
    captures, a hoisted function reading a nullable global, and the
    self-cancelling interval.
  - `TestE2EFsNonStringPath` covers `existsSync(42)` and four clean
    rejections.
- **Targeted E2E runs** pass: fs, os, timers, paths, closures, captures,
  nullables, narrowing and module globals.
- **Gates (with ADR-01148–01153):**
  - Test262: strict 7,032 and js 7,832 (the handover's were 7,034 and
    7,825), no clang failures in either lane. The two strict files lost
    call `str.slice(obj, obj2)` with objects for `number` parameters,
    which tsc rejects (TS2345).
  - Node suite: strict 61, js 63, unchanged.
  - `make examples`: 360 pass. `chained_listen` timed out once, its
    known intermittent hang, and passes 3 of 3 runs alone.
  - `make test-par`: only the four macOS `-mm=gc` failures.
