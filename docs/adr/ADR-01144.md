# ADR-01144: Node's modules declared: `declare module` in the builtin library (path first)

- **Relations**: `Implements TDD-00230` (Phase 3, P3.1); `Extends ADR-01134`, `ADR-01139`
- **Date**: 2026-09-25

## Context

P3.1 declares "each supported `node:*` module" in `lib/*.d.ts`. Until now
only globals were declared, so a call through an import of a Node module
(`path.join("a", 1)`) was unchecked. tsc rejects that call (TS2345).

The merged program has no import statements to read. The resolver drops
them, and rewrites a builtin module import's uses through the module's
marker identifier: `path.join(…)` and `join(…)` both become
`path__kml_builtin.join(…)`.

## Investigation

- **The parser erased `declare module "x" { … }`** with its balanced-token
  skip.
  - Parsing the bodies of `@types/node` instead fails 54 of its 71 files.
    The forms that fail include ambient `const`s, class overload
    signatures, `import x = require(…)` and generic heritage clauses.
  - That full parse belongs with a signature-level `@types/node`
    comparison. The builtin library needs only its own modules parsed.
- **The marker names** are a fixed table in the resolver
  (`virtualBuiltinMarkers`). The checker can type a marker as the module's
  exports once it knows which module a marker stands for.
- **Two receivers the lowering must not take.**
  - The `ffi` module's marker: `ffi.toString(ptr)` became a Number method
    call on the marker, and `examples/ffi/ffi.ts` failed.
  - A possibly-absent number, such as a typed-array element read
    (`view[i].toString(16)`), was declined, so it was left without its
    radix path (`examples/crypto/crypto.ts` failed). Both examples caught
    this.

## Decision

- **Parser.**
  - `parser.ParseLibrary` (used by `lib.Programs`) keeps a declaration
    file's `declare module "name" { … }` as an `ast.AmbientModuleDeclaration`
    of its body statements. `ParseDeclarations` still erases the block, so
    TypeScript's and Node's own libraries keep parsing whole.
  - In a declaration file a `const` needs no initializer (it is ambient).
  - A declared module's `export`s are that module's top level.
- **Binder.** A module declaration is bound into its own scope under the
  globals (`Binding.AmbientModules`).
- **Resolver.** It records the marker-to-specifier table on the merged
  program (`Program.BuiltinMarkers`).
- **Checker.**
  - A marker identifier has its module's type (`moduleType`): an object
    whose properties are the module's value exports, each with its
    declarations. It is partial, so an undeclared member is not reported.
  - A type declared inside a module counts as the library's, and is
    partial (`inLibrary`).
- **`lib/node.d.ts`** declares `path` in @types/node's shapes:
  - `normalize`, `join`, `resolve`, `isAbsolute`, `relative`, `dirname`,
    `basename`, `extname`, `parse`, `format`, `toNamespacedPath`;
  - `sep`, `delimiter`;
  - `ParsedPath`, `FormatInputPathObject`.
- **Lowering receivers.**
  - A builtin module's marker is never a receiver.
  - A possibly-absent number is one: the receiver guard throws on an
    absent value, as a method call on `undefined` does.

## Side effects discovered

- **`path.format({ dir, base })`** is rejected by codegen, which wants
  every field `path.parse` returns. This happens in the previous build too.
  Node accepts it. Fixed in ADR-01145.
- **HTTP hangs under load.** `examples/http/chained_listen.ts` and
  `TestE2EHTTPChainedListenBinding` hung while the machine ran other heavy
  jobs. Run quietly, 12 runs of each build pass (BACKLOG: HTTP examples
  hang on the M4).

## Verification

- **`TestE2EPathModuleDeclared`:** named, default and `path.parse` uses
  run, and `path.join("a", 1)` is TS2345.
- **Examples:** `make examples` passes apart from the load-dependent HTTP
  hang above; the crypto and FFI examples pass.
- **Unit tests:** the `lib`, `parser`, `binder` and `checker` tests pass.
  `parser.ParseDeclarations` still reads all of `@types/node` and
  TypeScript's `src/lib`.
- **Test262 (both lanes, together with ADR-01142–01144):** strict 7,031
  (+7), js 7,793 (+9).
- **`make test-par`:** only the four known `-mm=gc` failures and the
  load-dependent HTTP hang (`TestE2EHTTPChainedListenBinding`).
