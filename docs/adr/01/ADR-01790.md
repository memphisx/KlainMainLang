# ADR-01790: propertyIsEnumerable reads a dynamic object's own attributes

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- `o.propertyIsEnumerable(k)` on a dynamic object threw "is not a function".
- `Object.prototype.propertyIsEnumerable.call(o, k)` answered with `Object.keys(o).includes(String(k))`, which is false for every symbol key.

## Decision

- `__kml_dynobj_prop_enumerable(v, key)` (dynobj.c) answers 1 or 0 from a dynamic object's own property attributes. The key is the property key as a dynamic get computes it, so symbols use their synthetic key. It returns -1 for any other value.
- `emitPropertyIsEnumerable` serves both forms. It falls back to the `Object.keys` check when the receiver is not a dynamic object.

## Consequences

- `TestE2EJSFilePropertyIsEnumerable` compares string, symbol, non-enumerable, inherited and array keys against Node.
