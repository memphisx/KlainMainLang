# ADR-01747: structuredClone as a value and with options

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-19

## Context

`const sc = structuredClone` failed to compile. The builtin's value closure takes the declaration's two parameters (`value, options?`), and the emitter accepted exactly one argument. A direct call with `options` was rejected the same way.

## Decision

- `structuredClone` takes a value and an optional options argument. The options are evaluated after the value and before the clone, as in Node. The run-time clone (`structuredCloneAny`) takes them too.
- `options.transfer` is accepted, but an `ArrayBuffer` in it is copied, not detached. This matches the existing `Worker` transfer caveat; nothing in the runtime detaches a buffer yet.

## Consequences

- `structuredClone` read as a value is a function that clones.
- The transfer caveat is recorded on the `structuredClone` status row.
