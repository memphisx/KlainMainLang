# ADR-00670: Legacy `url.format` — the inverse of `url.parse` (TDD-00165 Stage 4)

- **Relations**: Implements TDD-00165 (Stage 4); Extends [ADR-00669](ADR-00669.md)
- **Date**: 2026-09-03

## Context

ADR-00669 added `url.parse` as the first module-only function of the hybrid `url`
module. Its natural pair is `url.format(urlObject)` — the inverse, which
serializes a URL object back to a string.

## Decision

Register `format` alongside `parse` in `moduleFunctionMembers["url"]` (so it is
importable named, via namespace, and via the module default, through the same
hybrid-module machinery), dispatch `<url marker>.format(...)` in codegen, and
infer its result as `string`.

`emitUrlFormat`:

- A **WHATWG `URL`** argument (`objTy.IsURL`) serializes to its already-computed
  `href` field.
- Any other object is treated as a **legacy/plain Url object** and reconstructed
  as `protocol · "//"(if host) · auth"@"(if auth) · host · pathname ·
  (search | "?"+query) · hash`. Components are read **by field name** off the
  argument's inferred type, so it works on a `LegacyUrlType` (round-tripping a
  `url.parse` result), a hand-built object literal with a subset of the legacy
  fields, alike — matching Node's leniency about partial input objects. A field
  the object doesn't define, or an empty one, contributes nothing.

## Implementation notes

- Reuses `emitStringConcat`, `emitStrBranch`, and `emitStrNonEmpty` (the same
  helpers `url.parse`/`new URL()` use); the three conditional segments (the
  leading `//`, the `auth@`, and the `search`-or-`?query`) are computed with
  `emitStrBranch`, then the parts are concatenated in order.
- Reading components by `FieldIndex` name (rather than a fixed layout) is what
  lets one code path serve both the `LegacyUrlType` and an arbitrary object
  literal.

## Verification

E2E tests in `tests/node_core_modules_test.go`: a `parse`→`format` round-trip that
reproduces the exact original string, a WHATWG `URL` → `href`, a plain-object
input, and a `query`-without-`search` case (the `?` is re-added). The
now-obsolete "url.format rejected" case was repointed to a still-unbuilt extra
(`fileURLToPath`). `go test` over the import/module/url suites green (Mac);
`go vet ./...` clean.
