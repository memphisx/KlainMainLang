# ADR-01876: On-demand instance members; an iterator method's result

- **Relations**: `Implements TDD-00230` (P3.3: the shadow report's CallExpression bucket), follows ADR-01874
- **Date**: 2026-10-21

## Context

- A class's instance type types its fields before its methods. A field initializer calling a method (`#b = this.#m()`, Test262's private-method initialization order) read the half-built type, found no member, and stayed unanswered. tsc resolves each member on demand.
- ADR-01874 rejected an iterator key that is no method. A method whose result is no iterator (`[Symbol.iterator]() { return true }`, `{ next: 1 }`, `null`, a body that only throws) is TS2504/TS2488 to tsc as well, the rest of Test262's `yield-star-*` family; the checker left those unanswered.

- A leaf of a generator's destructured parameter is bound by the destructuring codegen runs over the hidden boxed parameter (desugarGeneratorPatternParams): `[...x]` holds boxes, while the checker types it as tsc does (`number[]`), about 500 shadow rows.

## Decision

- A member read on a class instance still being built types the named method from its declaration first.
- An iterator method must return an object with a callable `next`, or a type the checker cannot rule out (any, unanswered, a member list not modelled whole); otherwise the object is not iterable, as in ADR-01874.
- An iterator whose `next()` returns a primitive is TS2490, reported once per iterable and protocol, as tsc's cached iteration types report it.

- The shadow oracle reads such a leaf as the storage codegen binds it to, as it reads a name bound to a box.

## Consequences

- `TestClassFieldInitializerMethod` covers both lanes; `TestCheck`'s new case holds tsc 5.6's codes.
- Verified on Apple Silicon.
