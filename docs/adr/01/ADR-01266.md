# ADR-01266: `structuredClone` of an `any` clones by run-time shape

- **Relations**: `Extends ADR-00574`
- **Date**: 2026-09-29

## Context

`structuredClone(x)` with `x: any` (or `x as any`) was a compile error:
the compiler clones by static type. `perf_hooks` clones a mark's
`detail`, typed `unknown`.

## Decision

When the argument's type is any/unknown, or asserted to be, the call
goes to `structuredCloneAny` in `lib/node/internal_structured_clone.ts`.
It follows V8's serializer:
- primitives are themselves;
- errors, ArrayBuffers, TypedArrays, Maps, Sets, arrays and objects are
  copied once each, so a cycle clones to its copy;
- a class instance becomes a plain object of its own properties;
- a function or a symbol throws `DataCloneError`.

The resolver includes the module when a file names `structuredClone`.
Statically typed values keep the compiler's clone.

## Verification

Mac (Apple Silicon): objects, cycles, arrays, errors, TypedArrays, class
instances and functions clone as in Node.
