# ADR-01657: A union narrowed to a host member reads as it, and BYTES_PER_ELEMENT

- **Relations**: Implements [TDD-00230](../../tdd/TDD-00230.md) (P3.3, found while ranking `reprOf`'s unanswered types)
- **Date**: 2026-10-16

## Context

`function f(x: string | Buffer) { … typeof x === "string" ? … : x.byteLength }`
failed to compile with "field access on non-object". `x.length` and `x[0]`
worked. The same program with a `string | Map` parameter failed on `x.size`
("can't be read on an un-narrowed union") and then on `x.get(k)` ("'x' is
not a Map or Set"), and `x.buffer.byteLength` produced invalid IR.
`BYTES_PER_ELEMENT` compiled only through a box: `u.BYTES_PER_ELEMENT` on a
typed view and `Uint16Array.BYTES_PER_ELEMENT` were "field access on
non-object".

## Investigation

- `emitIdent` unboxes a union binding the checker narrows
  (`checkerNarrowed`), and `identStorageType` gives inference the same type.
  But several member paths take an identifier receiver's binding type
  directly: the `byteLength` fast path (`emit_exprs_member.go`) and
  `resolveMapOrSetForCall` (`emit_collections.go`). For them the receiver
  was still the boxed union.
- `checkerNarrowedUnion` matched a narrowed object type against the union's
  object members by name, but a Map, Set or Date member is not an object
  member to `unionMemberTag` (`isUnionObjectMember` excludes Map and Set),
  so a `string | Map` narrowed to Map found no member.
- The oracle's `typedArrayView` (`shadow_binder.go`) asked the receiver's
  storage type, so `x.buffer` on a narrowed binding was typed as the
  checker's `ArrayBuffer` rather than the box `emitTypedArrayViewProp`
  returns, and `.byteLength` loaded the box as a pointer.

## Decision

- `.byteLength` and `.BYTES_PER_ELEMENT` dispatch on a union binding's
  narrowed member when the checker narrows it to a buffer or a view.
- `resolveMapOrSetForCall` takes an identifier's binding only when it is a
  Map or Set; any other receiver is emitted, which narrows.
- `checkerNarrowedUnion` matches a narrowed named type against the union's
  host members by `hostClassName`, after its object members.
- `typedArrayView` also accepts the checker's narrowed type of the receiver.
- `BYTES_PER_ELEMENT` on a view evaluates the receiver and is its element
  size; on a typed array constructor it is that constructor's constant.

## Implementation notes

`emit_exprs_member.go` (`byteLengthReceiverType`, `typedArrayBytesPerElement`),
`emit_collections.go`, `emit_lowered.go`, `shadow_binder.go`.

## Side effects discovered

None.

## Verification

`TestE2EUnionNarrowedToHostMember` compares a Buffer, Uint8Array, Map, Set,
Date and ArrayBuffer member of a narrowed union, and both forms of
`BYTES_PER_ELEMENT`, with Node. The union, narrowing, Buffer, typed array,
Map and Set suites pass (Mac).
