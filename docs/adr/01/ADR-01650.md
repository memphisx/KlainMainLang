# ADR-01650: Symbol.species on classes extending Array, typed arrays and Promise

- **Relations**: Implements [TDD-00230](../../tdd/TDD-00230.md) (P3 remainder of [TDD-00247](../../tdd/TDD-00247.md))
- **Date**: 2026-10-16

## Context

A class extending Array, a typed array or Promise makes its derived results
(`map`, `filter`, `slice`, `subarray`, `then`, `catch`, `finally`) through a
species construction ([ADR-01466](ADR-01466.md), [ADR-01469](ADR-01469.md)),
but always with the receiver's own class. A `static get [Symbol.species]()`
override, which Node consults, did not parse: the parser took no
`Symbol.species` computed member key.

## Investigation

The parser maps a computed `[Symbol.x]` member key to an `@@x` name for the
well-known symbols it knows (`wellKnownSymbolMemberName`); `species` was
not one. Codegen picks the derived constructor in three places: the array
fill (`emitArrayClassFill`), Promise's `then`/`catch` (`emitPromiseSpecies`)
and `finally` (`emitPromiseSpeciesFinally`). The derived value's static type
does not come from those emitters but from the checker's oracle
(`shadow_binder.go`), whose rule typed every `then`/`catch`/`finally` on a
Promise subclass as that class. With the emitters changed alone, a plain
promise was stored under the class type, and `instanceof` and later reads
went wrong.

The species getter is code: Node runs it on every derived construction.
The getters written in practice are a single `return` of `this`, a class or
the builtin; a constructor computed at run time would need a class value
codegen can construct from, which a statically laid out class does not have.

## Decision

`species` joins the well-known symbol keys (`@@species`). `speciesOf`
resolves a class's species at compile time, walking the class and its
ancestors for a static `@@species` getter whose body is one `return` of
`this` (the receiver's class), a class name, the builtin's own name or
`null`/`undefined` (the builtin); any other body is a compile error naming
the class. The array fill, `then`/`catch` and `finally` construct with that
class, or, for the builtin, take the builtin's own method on the instance's
body. The oracle asks codegen for the species through a new `species` hook
on `reprCtx`, so the derived value's type matches what was constructed.

## Consequences

- `instanceof`, `Array.isArray` and element and settled values match Node
  for each species form (`tests/classes_test.go`, `TestE2EClassSpecies`;
  `examples/classes/species.ts`).
- A getter with a computed body, and a `Symbol.species` defined other than
  as a static getter (`Object.defineProperty`, a static field), remain
  unsupported; the status caveat says so.
