# ADR-01887: an undeclared name in JavaScript is any

- **Relations**: `Implements TDD-00230` (P3.3: the shadow report's unanswered bucket)
- **Date**: 2026-10-21

## Context

- In a JavaScript program a name nothing declares is read at run time: a ReferenceError unless the host defines it. tsc types it, and what is built from it, as its error type `any`. The checker left it unanswered, and everything derived from it with it (`let realm = $262.createRealm(); new (realm.global.Function)(…)`), so codegen's own inference decided those expressions.

## Decision

- In the js lane, an unresolved name in the program's own code that is no global the compiler knows is `any`. A name a rewrite built (a namespace member's mangled name) and names in the library's code stay unanswered, codegen's to type; the strict lane keeps TS2304.

## Consequences

- The rows of every Test262 file that reads the host's `$262` leave the report's unanswered buckets; programs run as in Node.
- Verified on Apple Silicon.
