# ADR-00621: D1 dynamic object model, Stage 1 — the runtime property bag behind `any`

- **Relations**: `Implements TDD-00155 (Stage 1)`, `Extends ADR-00008, ADR-00478`
- **Date**: 2026-09-01

## Context

[TDD-00155](../tdd/TDD-00155.md) designed the native dynamic object model (D1):
a per-instance property bag + prototype pointer + descriptors behind a new any-
box tag, staged in seven shippable steps. Stage 1 is the core bag: creation
from an object literal in an `any` context, member/bracket get/set with
runtime keys, `delete`/`in`/`Object.keys`/`for...in`, spread, and identity.

## Decision

**Runtime** (`codegen/llvm/runtime_dynobj.go`, `@__kml_dynobj_*`): a 40-byte
header `{flags/magic, proto (null in Stage 1), props, count, cap}` over a
realloc-doubled array of 32-byte entries `{key, tag, payload, attrs}`. Values
are the existing `{i8,i64}` any box verbatim; keys are owned, length-prefixed
heap strings (the TDD-00120 header at `key-8` — a plain C-string copy broke
every length-reading consumer, caught by `Object.keys` printing garbage).
Lookup is an insertion-ordered linear `strcmp` scan — enumeration order falls
out, and the hash/hidden-class ladder stays a caller-invisible later
optimization. Helpers: `new`, `find`, `get`, `set` (update-or-append, attrs=7),
`has`, `delete` (memmove compaction; a miss still returns `true` — JS reserves
`false` for non-configurable, which arrives with Stage-5 descriptors), `count`,
`key_at`, `get_at`, `keys`, `merge` (spread).

**Box tag 10** (`kmlTagDynObject`): payload is the bag pointer. `typeof` →
`"object"` and `String()` → `"[object Object]"` fall out of the existing
remaining-tag arms; `__kml_any_eq` compares tag-10 by pointer (reference
equality); the interned-key/`dtoa`/`%lld` stringification of bracket keys
reuses the tag-dispatch printer for `any`-typed keys.

**Codegen glue** (`emit_dynobj.go`) and hook points:

- `emitExprWithObjectHint`: an object literal bound into a bare `any` slot
  builds a bag (`emitDynObjLiteral`) — nested literals recurse, static-object
  spreads copy visible fields boxed, an `any` spread merges at runtime (a
  non-object spread is JS's silent no-op). Getter/setter properties are
  rejected until Stage 5.
- Member/bracket read & write, `delete`, `in`/`hasOwnProperty`, `Object.keys`,
  and `for...in` on a bare `any` base each emit a runtime tag dispatch:
  tag 10 → bag op; null/undefined → Node-matching TypeErrors (`Cannot read
  properties of null (reading 'x')`, `(setting 'x')`); primitive reads →
  `undefined` (`Object.keys` → `[]`); statically-shaped refs (tags 6-9) →
  TypeError, the honest rejection until Stage-6 allocation-site widening.

## Consequences

- The `any`-has-no-shape caveat family is closed for values *created* dynamic;
  a static struct boxed into `any` still rejects member access (Stage 6).
- `console.log` shows `[object Object]` (no inspect form), `JSON.stringify`/
  `JSON.parse` of dynamic values are Stage 2, `Object.values`/`entries` need
  `any[]` elements, and primitive members through `any` (`.length`) read as
  `undefined` — all disclosed on the status pages.
- Verified on the Mac (arm64); nine E2E tests (`tests/dynobj_test.go`) +
  `examples/dynamic/dynamic_object.ts`, outputs cross-checked against Node.
  Node oracle unchanged at 45 passes (most corpus files fail on earlier gaps).
