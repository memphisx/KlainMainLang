# ADR-00934: `Array.isArray` on a dynamic value consults the runtime box tag

- **Relations**: Extends ADR-00933
- **Date**: 2026-09-14

## Context

`Array.isArray(x)` where `x` is `any` (or `unknown`) always returned `false`,
even when `x` genuinely held an array at runtime:

```ts
let a: any = [1, 2, 3];
Array.isArray(a);   // was false, should be true
```

Found while writing the `-compat=js` regression for ADR-00933, where a widened
binding reassigned to `[]` still reported non-array.

## Investigation

The `isArray` case in `emit_call.go` was a pure compile-time check —
`inferExprType(arg).IsArray`. A dynamic argument's static type is `any`, whose
`IsArray` is always `false`, so the runtime array-ness was never consulted. A
boxed array carries its kind in the NaN-box tag: a static-array box is
`kmlTagArray`, a D1 dynamic array `kmlTagDynArray` (`emit_dynamic.go`), decoded
by `__kml_nb_tag` — the same tag `emitDynamicTypeof`/`emitDynamicToString`
already switch on.

## Decision

When the argument's static type is dynamic, emit the value, box it
(`emitBoxValue` is a no-op if already boxed), read its tag with
`emitUnboxTagPayload`, and return `tag == kmlTagArray || tag == kmlTagDynArray`.
Non-dynamic arguments keep the exact compile-time answer (an array-typed value is
statically `true`, everything else `false`).

## Implementation notes

`codegen/llvm/emit_call.go`, the `Array.isArray` case. Both array tags are
covered so a `JSON.parse`-sourced D1 array counts too. No runtime change.

## Verification

- `TestE2EArrayIsArrayOnAny`: boxed array → true, boxed object → false, and
  false again after cross-type reassignment.
- Array/collection/dynamic suites pass; `make examples` 303/303. macOS arm64.
