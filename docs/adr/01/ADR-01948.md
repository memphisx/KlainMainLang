# ADR-01948: Top-level pattern globals; null and undefined kept apart

- **Relations**: Implements TDD-00230
- **Date**: 2026-10-28

## Context

A sweep of nullable and three-state scalars outside locals, compared against Node, found seven bugs. All predate this change.

- A name bound by a top-level destructuring (`const { x } = …`, `const [a] = …`) failed to compile when a function declaration read it ("undefined variable 'x'"). Arrow functions worked, because they capture; a function declaration has its own scope, and only plain declarations were promoted to module globals.
- `null | undefined` lowered to plain `undefined`, so `[undefined, null]` printed `[ undefined, undefined ]` and its destructured `null` read `undefined`.
- A box holding `null` unboxed into a three-state `number | null | undefined` slot read `undefined`. Both unbox paths (`convert` and the narrowing unbox) left the payload 0, which is undefined's encoding, and `convert` sent boxes to `toThreeState`, which unboxes through the plain `T | undefined` type.
- `Promise.all` over `Promise<number | null>` produced invalid IR.
- `[...gen()]` and `Array.from(gen())` of a `Generator<number | null>` produced garbage (`[ undefined, 0.9375, undefined ]`).
- `JSON.parse(…) as (number | null)[]` was rejected as "a union type".
- An array typed `T[] | null | undefined` stored a plain null header for `null`, so it read back as `undefined`. Declarations, returns, assignments and ternaries all did this; `c ? null : undefined` typed both branches as null.
- `f(null)` for a `T[] | null | undefined` parameter, and `m.set(k, null)` on a Map whose values are three-state (strings, objects, numbers or arrays), stored undefined. So did a constructor, method or static method argument.
- `xs ??= ys` (and `||=`, `&&=`) on an array variable was rejected.
- The definite-assignment check (TS2454) decided its exemption from the annotation's spelling. It missed an alias of a type holding `undefined` (`type A = T | undefined; let x: A;` was rejected), and it exempted `T | null`, which tsc rejects.
- `join` and `toString` on an array of nullable arrays rendered `null` and `undefined` instead of empty strings.
- `const [p = 5] = [null] as (number | null | undefined)[]` bound 5: an element typed as a boxed union that may be undefined was taken for an element that is always undefined, so the default applied without reading it.

## Decision

- **Pattern globals:** `registerPatternGlobals` promotes each name a top-level destructuring binds and a named function reads. The global has the checker's declared (storage) type of the name, taken from a reference that resolves to that declaration; library statements are skipped. After `main` runs the destructuring, `bindPatternGlobals` stores each bound value into its global and rebinds the name to it, so `main` and every function share one slot.
- **`null | undefined`** lowers to `any`: a box keeps which one it holds.
- **Three-state unbox:** both unbox paths put the null marker in a three-state scalar when the box's tag is null. A box flowing into a three-state scalar goes to the tag-aware unbox, not to `toThreeState`.
- **Boxed arrays:** an array of a nullable scalar stores boxes (`arrayElemType`). `Promise.all`'s result store converts each value to that representation. `emitUnboxAnyArray` returns a boxed source array as is when the target element is stored boxed.
- **Three-state arrays:** a declaration, return, assignment or ternary branch of `null` stores the null cell, as three-state strings and objects already do; `undefined` stays the null header. A ternary with null on one side and undefined on the other is the three-state array, or the box when neither branch is an array.
- **One absent-array helper:** `emitAbsentArrayValue` takes the absent value's type, so every site (function, constructor and method arguments, `convert`, assignments, `??`/`||` results and ternary branches) picks the null cell for a three-state array's null. A Map value is converted to its slot's three-state type before it is stored.
- **Logical assignment on an array variable** lowers to `xs ?? (xs = ys)` (and `||`, `&&`); the name reads twice without side effects.
- **TS2454** is skipped exactly when the declared type holds `undefined`: `any`, `unknown`, `void`, `undefined`, or a union with `undefined`. The check follows a non-generic type alias from the declaring scope. Checked against tsc 5.9.3.
- **Destructuring defaults:** the shortcut that binds the default without reading the element applies only to the type `undefined` itself.
- **Join** treats an absent array element (the null header or the null cell) as empty, as it already did for other absent elements.
- **JSON.parse** into a union of primitives (numbers, booleans and strings, with null and undefined) builds the box the JSON value converts to, which is that union's representation. A union with an object member is still rejected.
