# ADR-01924: codegen — Partial's header word, a nested generator's value type, a template object's callee

- **Relations**: `Implements TDD-00230` (codegen/oracle agreement)
- **Date**: 2026-10-21

## Context

- `Partial<T>` marked every field of `T`'s layout optional, including the object's hidden header word, which is no property.
- A nested generator declaration read as a value was inferred through the function registry, where it has no callable signature: a function type with no parameters and an empty result. Emission builds its constructor closure.
- A tagged template's template object is an intrinsic call with no callee. The receiverless-`this` check asked for that callee's type, which inferred a type for nothing.
- An array annotation spelled with a type parameter (`T[]`) resolved its element through a copy that still pointed at the whole array's node.

## Decision

- `Partial` leaves the header word alone.
- Inference of a value read finds a generator before the function registry, so the inferred type is the constructor closure that emission builds.
- An intrinsic call skips the receiverless-`this` check.
- The peeled copy points at the element's node.

## Consequences

- Inference and emission agree for nested generators. `Partial` objects keep their header layout.
