# TDD-00156: Single-word NaN-boxed dynamic values (the substrate for real `any` operators)

- **Status**: Implemented
- **Date**: 2026-09-02

## Context

Every dynamic value — `any`/`unknown`, unions, the D1 object model's
property/element slots ([TDD-00155](TDD-00155.md)) — rides the two-word
`{ i8 tag, i64 payload }` box from [ADR-00008](../adr/ADR-00008.md).
[TDD-00076](TDD-00076.md) (implicit-`any` + operator dispatch, the
`-compat=js` half of real JS semantics) now needs arithmetic on these
values, and the two-word aggregate makes every operation a two-slot
shuffle with no fast path. The direction settled here: collapse the box to
**one 64-bit word** using the JSC-style encoding — the design sketched when
the idea first came up, with the GC constraint worked out.

## Design

### Encoding (JSC "reverse" NaN-boxing, Boehm-safe)

A dynamic value is one `i64`:

- **Numbers** — every JS number is a double (int/float tags merge, which is
  *more* faithful than today's exact-`i64` int tag: precision past 2^53
  rounds exactly as JS does). Encoded as `double_bits + (1 << 49)`
  (`DoubleEncodeOffset`), after canonicalizing NaN — so every encoded
  number is `≥ 2^49` and can never collide with a pointer or immediate.
  The number test is a single unsigned compare; arithmetic is
  decode → `fadd` → encode.
- **Immediates** (JSC's constants): `undefined = 0x0A`, `null = 0x02`,
  `false = 0x06`, `true = 0x07`. All `< 0x10`.
- **Heap references** — the raw pointer with a **low-3-bit kind tag**
  (allocations are ≥8-aligned): string, static object, array header,
  funcRef, stream, dynamic object, dynamic array, dynamic function —
  exactly the eight pointer kinds the tag model has. High 16 bits zero,
  value ≥ 0x10000 distinguishes them from immediates.

**Why pointers stay low-tagged rather than high-tagged (the GC
constraint):** classic NaN-boxing hides pointers under high tag bits, which
Boehm's conservative scan cannot see — collected out from under the
program. A low-bit-tagged pointer is an *interior* pointer
(`GC_all_interior_pointers`, on by default), which Boehm treats as a live
reference to the enclosing allocation. This is the load-bearing decision;
everything else is convention.

### The logical tag model survives

`kmlTag*` remains the compiler's dispatch vocabulary. Two runtime IR
helpers decode a word into the familiar pair — `@__kml_nb_tag(i64) → i8`
and `@__kml_nb_pay(i64) → i64` (payload = decoded double bits / masked
pointer / 0|1 for booleans) — and `@__kml_nb_pack(i8, i64) → i64` is the
inverse. `emitBoxValue`/`emitUnboxTagPayload`/`emitTagCheck` keep their
signatures, so the entire dispatch glue (typeof, toString, equality, the
D1 member/method paths, union narrowing) survives with its structure
intact; the migration is the aggregate's IR type (`{ i8, i64 }` → `i64`)
plus routing the pack/unpack sites through the helpers. Number values
always decode to the float tag; the int tag becomes unreachable (arms stay
until a cleanup pass).

### Storage stays put in stage one

The D1 bag/array slot layouts (and dynjson.c's read-only walkers over
them) keep their `(i64 tag, i64 payload)` pair slots: the runtime
get/set entry points convert at the boundary. The single word is the
SSA/ABI representation — what operators, calls, and returns move around.
Collapsing the storage slots to single words is a follow-on optimization,
deliberately excluded so stage one changes no C code and no heap layout.

### What this unlocks (implemented as TDD-00076 A2/A1, same delivery)

- **Operator dispatch** (`emitAnyBinary`, TDD-00076's recommended inline
  Option 1): the both-numbers fast path is two compares + decode/op/encode.
  V1 semantics matrix: numbers ⊕ numbers (all arithmetic/relational);
  `+` with a string side → ToString concat; null/undefined/boolean coerce
  numerically (`null+1 === 1`, `undefined+1 → NaN`, `true+1 === 2`);
  string relational compare (lexicographic); reference operands in
  arithmetic → runtime TypeError (the full ToPrimitive ladder stays a
  later stage, per TDD-00076).
- **Truthiness**: `if (x)` / `!x` / `&&`/`||` on a dynamic value via
  ToBoolean (empty string reads its length header; 0/-0/NaN false).
- **Implicit-`any` (A1, `-compat=js`)**: precedence becomes annotation →
  call-site-inferred concrete type ([ADR-00625](../adr/ADR-00625.md) —
  built and kept, superseding TDD-00076's "not worth building" verdict) →
  boxed `any`. Conflicting call sites stop being a hard error under `js`
  (both callers are valid JS — the parameter is genuinely polymorphic and
  now *works* as `any`); `strict` keeps every current rejection.

## Open questions

- Whether the follow-on storage collapse (single-word bag/array slots,
  half the D1 memory) lands before or after D1 Stage 5 descriptors.
- Whether the unreachable int-tag arms are excised immediately after the
  migration proves out or kept one release as a safety net.
- `-compat=strict`'s unannotated-parameter future (TDD-00076's open
  question — today's number default vs. a `noImplicitAny` error) stays
  open; nothing here forces it.
