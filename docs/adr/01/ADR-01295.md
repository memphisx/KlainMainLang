# ADR-01295: Array element kinds across `any[]`, ternary types, promoted callables, and Number predicates

- **Relations**: `Extends ADR-00887`, `Extends TDD-00213`, `Implements part of TDD-00230`
- **Date**: 2026-09-30

## Context

The dns port (ADR-01294) ran into these. Most gave wrong values silently.

- **`number[]` read as `any[]`.** Assignment (`ys = xs`), a variable
  declaration, a return from an `any[]` function, or a variable argument to
  an `any[]` parameter reinterpreted the raw doubles as box words. `[1, 2]`
  read back as `[0.9375, 1.875]`.
- **Ternaries.** `c ? [] : s.split(':')` took the empty literal's element
  type, and its elements then failed to compile. `c ? 'x' : undefined` was
  typed `string | null`, so JSON printed `"type":null`.
- **Promotion to module globals.** A top-level object holding functions or
  classes by name (`{ lookup, Resolver }`), or a `const g = f` alias, was
  not promoted. A named function reading it failed to compile.
- **Overloads.** A call whose context-sensitive callback had an annotated
  parameter that no overload accepts (`dns.lookup(h, (err, address:
  number) => {})`) was not reported. tsc says TS2345/TS2769.
- **Rest callbacks.** A rest-parameter function passed to `.then`/`.catch`
  (`p.then((...a) => …)`) segfaulted.
- **Number predicates.** `Number.isInteger`, `Number.isSafeInteger`,
  `Number.isNaN` and `Number.isFinite` answered `true` (or converted) for
  any non-float operand. An `any` holding `1.5` was an integer, and
  `Number.isNaN('x')` was true.

## Decision

- **Element conversion.** `coerceArrayElems`/`arrayElemsConvert`
  (emit_exprs_coerce.go) copy a concrete-element array into an `any[]` with
  each element boxed, and unbox for the reverse. They apply at `coerce`,
  the array variable declaration, array assignment, the array return and
  both argument paths. A spread of box elements into a concrete array
  unboxes each one (`emitSpreadUnboxLoop`). The two representations differ
  per element, so the copy does not alias the source.
- **Ternaries.** `conditionalArrayType` gives an empty `[]` branch the other
  branch's type. `ternaryNullablePointerType` keeps the absent branch's
  `undefined`.
- **Promotion.**
  - `initRefsCallable` promotes an object literal that names a top-level
    function or class (`topLevelCallables`).
  - The pre-pass accepts those names as stable.
  - A `const g = f` of a top-level non-generic function promotes with the
    function's type.
- **Overloads.** `argMisfit` checks a context-sensitive function literal's
  annotated parameters against the callback parameter each overload passes,
  contravariantly (`literalParamsMisfit`).
- **Rest callbacks.** A `.then`/`.catch` callback whose only parameter is a
  rest goes through the boxed closure, which packs the value into its rest.
- **Number predicates.** `numberOperand` answers "is it a number": the tag
  test for an `any`, the static type otherwise. `Number.isInteger`,
  `isSafeInteger`, `isNaN` and `isFinite` answer for numbers only. The
  global `isNaN`/`isFinite` keep converting.

## Verification

On the Mac (Apple Silicon), outputs match Node v24.19.0:
- `tests/iterable_spread_test.go`;
- `TestE2ENumberPredicatesOnAny`;
- `TestE2EDnsZlibDeclared` (the TS2345);
- the dns port tests;
- the repros above.

The same programs match Node 26.10 on Linux (Docker, glibc/arm64).
