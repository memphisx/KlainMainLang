# ADR-01762: Under `-compat=js`, a Symbol where a number is taken throws at run time

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

`[1].includes(1, Symbol())` and `"abc".charAt(Symbol())` were compile errors in both lanes ("a Symbol cannot be converted to a number"), raised by `convertChecked`. That is right for the strict lane, where tsc rejects the call. Under `-compat=js`, Node throws `TypeError: Cannot convert a Symbol value to a number` when the call runs. `coerce` already emits that throw for sites with no compile-time check.

## Decision

Under `-compat=js`, `convertChecked` leaves a Symbol in a numeric position to `coerce`'s run-time TypeError.

## Consequences

- `TestE2ECompatJSSymbolToNumberThrows` covers it.
