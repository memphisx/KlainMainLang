# ADR-00605: `instanceof Object` by negating the primitive set

- **Relations**: Extends [ADR-00162](ADR-00162.md) (built-in `instanceof` as a static constant)
- **Date**: 2026-09-01

## Context

`x instanceof Object` was a clean rejection. [ADR-00162](ADR-00162.md)
deliberately left it out: real JS's "true for anything non-primitive" was thought
to need an exhaustive, drift-prone enumeration of every object-shaped `Type` flag
(and every new one added later).

## Decision

Answer it by **negating the primitive set** instead of enumerating objects. The
JS primitive types are a *closed* set — number, string, boolean, bigint, symbol,
null, undefined — that never grows, so negating it is drift-safe: every remaining
typed value is a JS object and every future object type is covered automatically.

In `emitInstanceOf`, for a right-hand `Object`, evaluate the left (for side
effects) and fold to a compile-time constant from its static type:

- **Undecidable static type** (`any`/`IsDynamic`, a union, or nullable `T | null`)
  → clean rejection: the runtime primitive-vs-object identity isn't statically
  known, and a wrong constant is worse than a clear error.
- **Non-`ptr` object type caught first**: `Date` is a plain `i64` timestamp yet a
  JS object, so it is matched before the scalar rule (which would otherwise read
  any non-`ptr` value as a primitive). Every *ptr* object type falls through to
  the default `true`, so only such non-`ptr` object types need explicit listing.
- **Primitive** → `false`: a non-`ptr` scalar (number/boolean), `bigint`,
  `symbol`, `null`/`undefined`, or a genuine string (`isForOfStringTy`).
- **Otherwise** → `true`: every remaining typed `ptr` value is an object (class
  instance, plain object, array, function, `Map`/`Set`/`RegExp`, streams, …).

Soundness rests on the primitive set being closed and on the ambiguous cases
(any/union/nullable) rejecting rather than guessing.

## Verification

`TestE2EInstanceOfObject` (class instance / array / object / `Date` / `Map` /
`Set` / `RegExp` / function → true; string / number / boolean / bigint → false),
matching Node v26, and `TestE2EInstanceOfObjectUndecidableRejected` (an
`any`-typed value is a clean rejection). Replaces the old
`…BuiltinObjectStillRejected` test. Built and verified on Mac (Apple Silicon).
