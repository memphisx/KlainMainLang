# ADR-00366: Node-core conformance track — full test/parallel corpus runner

- **Relations**: `Implements TDD-00121`
- **Date**: 2026-08-25

## Context

TDD-00121 Track B implements the Node behavioral oracle TDD-00082 designed but
deferred: run Node's own pure-module tests (`path`/`querystring`/`url`) through
this compiler and report a Node-parity number. The async model that blocked it
(timers, microtasks, Promise chaining) has since shipped.

## Investigation

A pinned sparse checkout of `nodejs/node@v22.11.0` (`test/parallel/test-{path,
querystring,url}*` + `test/common`, blobless) yielded 33 files. Direct sampling
established the transform surface and the scope reality:

- Node tests are untyped CommonJS: `'use strict';`, `require('../common')`,
  `const x = require('mod')`, Node globals (`__filename`). A snippet test
  confirmed this compiler compiles the ESM equivalent (`import path from 'path'`,
  `assert.strictEqual/throws/ok`), so a mechanical CJS→ESM transform is viable.
- `require` targets across the 33 files: `../common` (33), `assert`/`node:assert`
  (33), `path` (16), `node:url`/`url` (12), `node:test` (7, a whole different
  harness), plus `internal/url`, `child_process`, `vm`, `fixtures` — the last
  group structurally out of scope.
- **The decisive finding:** 13 of 16 `path` files test the `path.win32` /
  `path.posix` platform namespaces (`path.win32.basename(...)`) and `.call`, API
  surface this compiler deliberately does not expose. After excluding those, the
  remaining in-scope files *still* fail to compile — not on module behavior but
  on the untyped-dynamic idioms the tests are written in: `Object.entries` over
  object test-tables, `instanceof RegExp`, `.call`/`.apply`. This is exactly the
  "coupled and side-effectful, poor cost/return" outcome TDD-00082 predicted.

The bare `parser.Parse` + `EmitProgram` path first tried in the runner failed on
`import` with "unknown statement type ImportDeclaration" — imports are merged by
`resolver.ResolveProgram` (the pipeline step the klainmain binary runs), not the
parser. The runner was switched to write the transformed source to a scratch
entry file and drive `resolver.ResolveProgram` over it, mirroring the real
pipeline.

**Corpus scope — corrected from pure-modules to the full suite.** The first cut
fetched only `test-path*`/`test-querystring*`/`test-url-*` (33 files) — TDD-00082's
"pure modules only" scoping. That measured against a denominator so small it was
meaningless (33 of the ~4,159 `test-*.js` files Node ships; `test/parallel` alone
holds ~3,478). The fetch was widened to the whole `test/parallel` suite (+ `common`
+ `fixtures`), so the number is reported against the real corpus. It also exposed
that the supported-module allow-list had been far too narrow (only
`assert`/`path`/`url`/…), which mislabeled every `fs`/`http`/`net`/`crypto` test —
modules this compiler *does* implement — as "unsupported module" and hid them as
skips; the list was expanded to the full set of implemented Node core modules.

## Decision

- `fetch.sh` sparse-checks out the whole `test/parallel` + `test/common` +
  `test/fixtures` into gitignored `.node-tests/` (the test262 early-exit was
  refactored to a flag so the Node/TS blocks always run).
- `tools/conformance/node.go`: a `-suite=node` runner over a worker pool (the full
  ~3,478-file corpus needs parallelism). Per file, `transformNodeSource` coalesces
  physical lines into logical statements (bracket/string-aware —
  `coalesceLogicalLines`), strips `'use strict'`, rewrites `require`→`import`
  (default namespace + destructured, `node:` prefix normalized), and injects
  concrete `__filename`/`__dirname`.
- **`common` harness handling.** `require('../common')` in bare or binding form is
  dropped and a shim object is bound in its place — but the shim provides only the
  pure environment probes (`isWindows`/`isLinux`/`hasCrypto`/…). A file that uses a
  *behavioral* helper (`common.mustCall`/`mustNotCall`/`skip`/`expectsError`/…) is
  skipped with the accurate reason "requires Node common harness (common.X)",
  because those need Node's call-count-tracking semantics this compiler can't
  reproduce (a `common.mustCall(fn)` result comes back as `any` and isn't
  callable). This replaced an earlier mislabel where such files read as
  "unsupported module require('../common')".
- **Platform path namespaces (`.win32`/`.posix`)** are dropped at statement
  granularity, not whole-file — a path test interleaves default-namespace
  assertions this compiler targets with platform ones it doesn't, so dropping only
  the platform statements keeps the runnable default half (per-file "Default-only"
  mark); a file with no assertions left is skipped. `.call`/`.apply`, an
  unsupported `require` target (`vm`/`inspector`/`internal/*`/`node:test`/…), or a
  residual dynamic `require(` skip the whole file. The rest compile through
  `resolver.ResolveProgram` + codegen and run; nonzero exit is a fail.
- Shared front-end helpers (`frontEnd`/`frontEndSource`/`compileAndRun`) added
  for reuse by Track C.
- Report `docs/testing/CONFORMANCE-RESULTS-NODE.md`: overall against the real
  denominator, per-module histogram, and **failure-reason + skip-reason
  histograms** (the skip histogram makes the harness-coupling honest and visible),
  plus the passing-file list.

## Implementation notes

Go's RE2 has no backreferences, so the `require('X')` patterns use a plain quote
class (`['"] … ['"]`) rather than a `\1` match — mismatched-quote require lines
are vanishingly rare in the corpus and not worth a two-pass parse.

The transform is line-oriented and deliberately conservative: anything it can't
confidently rewrite is left in the body, and a residual `require(` there trips
the out-of-scope classification rather than producing a broken compile.

## Side effects discovered

Surfaced (not fixed here — each is a compiler limitation exposed by untyped test
code, not an in-scope regression; noted for follow-up):

- `Object.entries` over an object whose field is read into a template literal
  fails codegen ("cannot convert type ptr to string in template literal") —
  `test-path-glob.js`.
- `instanceof` against a builtin (`RegExp`) rather than a user class is rejected
  — `test-querystring-multichar-separator.js`.

The broader finding is now quantified against the real corpus: of 3,478
`test/parallel` files, ~3,130 are skipped and the skip histogram shows why —
**~2,150 need Node's behavioral `common` harness** (`mustCall` 1,028, `skip` 841,
`mustNotCall` 224, …), plus fixtures/tmpdir infra, `vm`/`inspector`/`internal`
modules, and dynamic `require`. A high headline pass rate on this corpus is only
reachable by *adapting* Node's harness (a differential runner plus a full `common`
shim that reproduces `mustCall`/`skip` semantics); ~90% of the suite is
harness/fixture-coupled in ways a typed AOT subset can't reproduce, so this track
reports the honest floor instead. Hand-mined typed value-semantics cases remain the
productive complement.

## Verification

`go vet` + `go build ./...` clean; `go test ./tools/conformance/` (transform smoke
tests) green. `-suite=node` over the full `test/parallel` corpus runs end-to-end:
**3,478 files — 21 passed, 1,174 failed, 2,283 skipped**; of the ~1,195 that
compiled far enough to run, 21 passed. Wiring the transform's `common.mustCall`/
`skip` to the native `test` builtin ([ADR-00370](ADR-00370.md)) moved ~1,000 files
from skipped-as-harness-coupled to actually attempted. The failures are now cleanly
attributed to *real* language/API gaps (a module-classification bug — `events`/
`crypto` are ambient globals not importable modules, `http2`/`https` aren't
importable at all — was fixed, dropping the "bare/package import" bucket from 188
to 0): the top buckets are untyped method calls on unknown-typed objects (`only
simple function calls`, ~288), missing exported members (~95), Node globals we
don't provide (~92), non-arrow callbacks (~60), and `new obj.Member()`
member-constructor syntax. These are the untyped-dynamic-JS and unimplemented-API
surface a typed AOT subset legitimately rejects — not tooling artifacts. The
report's skip/failure histograms attribute every bucket.
`test-path-basename` passes after the binary-safe basename fix
([ADR-00368](ADR-00368.md), found by this track). Verified on macOS (arm64).
