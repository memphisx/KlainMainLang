# ADR-01333: Builtin values, local classes, JSON's replacer and reviver, and builtin names a program declares

- **Relations**: Extends ADR-01331, ADR-01332, ADR-01327
- **Date**: 2026-10-02

## Context

The open items left after [ADR-01332](ADR-01332.md) were a class declared
in a function body ("unknown class"), `Math`/`JSON`/`console`/`globalThis`
read as values (`undefined variable`), `crypto.getRandomValues` taken by
value (a compile error), and the reserved-name check that rejected a local
`const String = …` tsc and Node accept. Each repro was run against Node
v24.19, and working through them turned up the further divergences
recorded below.

## Investigation

- A class declaration nested in a block was never registered: only
  `prog.Body` classes are, and the resolver's rename pass did not walk a
  nested class at all (`resolver/rename.go` `rewriteStmt` had no case for
  it), so a class body inside a function also kept unrenamed module
  references. Class expressions that capture nothing were already hoisted
  (`codegen/llvm/emit_classexpr.go`); their statics, and those of a hoisted
  declaration, were shared across evaluations, where Node gives every
  evaluation a fresh class (`function f() { class C { static n = 0 } … }`
  printed `1 2` for two calls; Node `1 1`).
- `const m = Math` reached `emitIdent` with no binding. `process` already
  had the shape needed: an object made once by a TypeScript module
  (`lib/node/internal_process.ts`).
- Taking `JSON.stringify` by value failed because its adapter forwards
  every declared parameter and the emitter rejected any replacer but a
  literal `null` and any space but a literal. `JSON.parse` likewise
  rejected a reviver. The native `any` serializer reported a cycle as the
  bare "Converting circular structure to JSON", skipped user `toJSON`
  methods on objects held in `any`, and never cycle-checked a boxed static
  array, so `const a: any = [1]; a.push(a); JSON.stringify(a)` overflowed
  the stack.
- `const a: any = [1]` boxed a `number[]` (element kind F64); `a.push(o)`
  stored `o` converted to a number, so `a[1] === o` was false and
  `a[1].x` undefined.
- `.constructor` read through `any` was `undefined` for plain objects,
  arrays, typed arrays and host objects (Map, Date, …).
- `Date.prototype.toTimeString`, `toLocaleTimeString`, `toLocaleString`
  and `toJSON` were declared without an implementation; `typeof` of a
  string slot holding null said "string"; `typeof f()` never called `f`;
  `new Date(v)` with `v: any` holding an ISO string gave the epoch.
- `Symbol.toStringTag` on a dynamic object was ignored by inspect,
  `String()` and `Object.prototype.toString`, partly because
  `p[Symbol.toStringTag]` was keyed by the symbol's pointer while classes
  key it `@@toStringTag`.
- `Reflect.construct` and `Reflect.getOwnPropertyDescriptor` were
  declared but not emitted; the generic, overloaded `Reflect` functions
  could not be taken by value (the checker gives them no single type).
  `Math.SQRT1_2` was missing. `DOMException.code` read `undefined` for
  every name; `DOMException` itself was undeclared.
- `fetch(url, init)` and `new Request(url, init)` rejected an `init` held
  in `any`.
- `crypto.getRandomValues` filled an `ArrayBuffer` and a `number[]` (a
  legacy path), rejected a Float typed array at compile time, and returned
  a rebuilt array that was not `===` its argument; Node throws
  TypeMismatchError (code 17) for every non-integer view and returns the
  argument. Node's `crypto` global is a `Crypto` whose methods check their
  receiver (`ERR_INVALID_THIS`).
- `this instanceof K` in a method of `K` folded to `true`, wrong for a
  method called without a receiver; and the dynamic adapter of a class
  method (`__kml_shape_m_*`) dispatched through the receiver's class,
  dereferencing a null `this`.
- `console.dir(x, opts)` required a literal options object.
- The reserved-name tiers (`resolver/reserved_names.go`) assumed the
  parser commits `new Map()` to the builtin before scopes exist; sema now
  builds the builtin `new` nodes with scope tracking (`builtinBehind`), so
  shadowing works once the check is gone.
- Converting a boxed value to a `double` bitcast the payload, so a missing
  argument of a dynamically called function read `0` and a string read
  garbage bits.

## Decision

1. **Local classes.** A block-level class declaration that names no local
   of its enclosing function is hoisted to the top level under
   `<name>__kml_cxN`, with the block's references renamed
   (`resolver.RenameInBlock`, scope-aware). Its place in the block keeps a
   copy whose evaluation re-runs the class's static initialization, and so
   does each evaluation of a hoisted class expression
   (`markClassReeval`/`emitClassReeval`). The resolver walks a nested class
   in its block's scope (`rewriteClassDeclIn`).
2. **Namespace values.** `lib/node/internal_namespaces.ts` makes `Math`,
   `JSON`, `Reflect`, `Atomics` (non-enumerable members, tagged as Node's
   are), `console` and the global object once each;
   `lib/node/internal_crypto_global.ts` makes `crypto` as a `Crypto` whose
   methods check `this`. The resolver links a module only when the source
   reads the name as a value (`namespaceValueUse`, `globalObjectUse`,
   `cryptoValueUse`); codegen calls the maker from `emitIdent`
   (`namespaceValueExport`). `globalThis.X` stays the declared global when
   one declares X, and is the global object's property otherwise; a
   builtin namespace is a builtin global object for by-value member reads,
   and a generic namespace function the checker cannot type is taken by
   value from its declaration's parameters. `Atomics`' by-value members
   dispatch on the array's kind in TypeScript.
3. **JSON.** A replacer, a run-time space, a reviver, or either function
   by value compiles to `lib/node/internal_json.ts` (ECMA-262
   SerializeJSONProperty / InternalizeJSONProperty, V8's cycle message);
   other calls keep the compiled serializer. The native `any` serializer
   calls `toJSON` itself (a tag-12 record, `fn(env, this, argc, argv)`),
   cycle-checks boxed static arrays, and builds V8's message from the walk's
   path. An `any` field holding undefined is omitted by the static
   serializer.
4. **Representation.** An array literal stored where `any` is expected is
   built as `any[]`. Unboxing to `double` is ToNumber. `.constructor`
   through `any` falls back to Object/Array/the typed-array kind/the host
   class. `typeof` tests a non-literal string slot for null, and evaluates
   an operand with effects even when the answer is static. A dynamic
   object's `Symbol.toStringTag` drives inspect (unless it is an own
   enumerable property), `String()` and `Object.prototype.toString`;
   `toStringTag` joins the canonical well-known keys (mirrored in
   `dynobjsrc/dynobj.c`).
5. **Builtins.** The four Date methods, `Math.SQRT1_2`,
   `Reflect.construct` (a `newTarget` other than the target throws a
   TypeError), `Reflect.getOwnPropertyDescriptor`, `Object` and `Function`
   as values (`FunctionConstructor` declared), `DOMException` declared with
   its legacy `code` (`__kml_domexc_code`, coresrc) and code constants,
   `new Date(v)` with `v` held in `any` (a Date's time value, a string
   parsed, anything else ToNumber'd), `Symbol(x)` with a
   ToString'd description (undefined: none, read as `undefined`), symbols
   rendered by inspect at any depth, `structuredClone`'s options argument
   through the global object (a non-empty `transfer` throws), and
   `console.dir` with run-time options through util's inspect.
6. **Requests.** `fetch` and `Request` read an `init` held in `any` member
   by member; undefined or null is no init.
7. **getRandomValues.** Integer typed arrays (and Buffer) are filled
   inline and the argument itself returned; anything else goes through
   `__kml_crypto_fill_any` (cryptorandsrc, behind `KML_CRYPTO_FILL_ANY`),
   which fills an integer view held in `any` and otherwise reports Node's
   TypeMismatchError or QuotaExceededError. The `number[]` path is
   deleted.
8. **Methods called without a receiver.** `this instanceof K` checks
   `this` at run time; a class method's dynamic adapter calls the method
   directly.
9. **Builtin names.** `resolver/reserved_names.go` and its checks are
   deleted: a program's declaration of a builtin's name is its own
   binding, in every lane. `new globalThis.Map()` is always the builtin.

## Implementation notes

- No routine was added as IR text: an earlier draft of the `toJSON` step
  as a generated IR helper was replaced by the C walker calling the
  record, and `TestIRTextOnlyShrinks` ([ADR-01327](ADR-01327.md)) holds.
- `emitVarDeclBody`'s identifier-initializer arm fell back to no type for
  any name it did not list (`const m = Math` stored a number); it now
  takes `inferExprType`.
- The resolver's module hooks skip lib files, whose sources name
  `console` and `crypto` freely; otherwise the namespace module includes
  itself recursively through util's inspect.
- `Math.SQRT1_2`'s absence made `Math.SQRT1_2` inside the namespace module
  evaluate `Math` as a value, which called `_kmlMath` again: a missing
  member through the value path recurses rather than failing, so each
  maker's members must all compile.

## Side effects discovered

- A class declared in a function that names a local of the function is
  still "unknown class": hoisting cannot express a per-evaluation
  environment.
- A required `number` parameter passed `undefined` reads NaN (ToNumber)
  where Node keeps `undefined`; a plain `double` slot cannot hold it.
- `.bind` on a rest-parameter function (and on array or nullable-scalar
  parameters) is still a compile error: the bind trampoline assumes one
  8-byte slot per parameter.
- `crypto.subtle` is not a value, so the `Crypto` object has no `subtle`.
- Primitive wrapper objects (`new Number(3)`) do not exist.
- A builtin method called through `any` on a host object
  (`(d as any).toJSON()` on a Date) throws "can't be called through a
  dynamic value" (TDD-00230 P3.3).

## Verification

`tests/any_json_date_fidelity_test.go` holds each repro with Node's output
as its expectation (TZ=UTC, en-US), and `TestE2EFetchDynamicInit` the
request cases; the Symbol, JSON-error and getRandomValues tests that
asserted the old behavior now assert Node's. Examples
`examples/json/replacer_reviver.ts`, `examples/globals/namespace_values.ts`
and `examples/globals/shadowed_globals.ts` (replacing
`reserved_globals.ts`) match Node. Linux x86-64 (Node304/DeskMini): before
the reserved-name removal, examples 379/379 and conformance strict 8,159 /
js 9,767 (from 8,063 / 9,586).
