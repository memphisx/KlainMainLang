# ADR-01357: A shared view crosses a worker boundary as a view

- **Relations**: Completes TDD-00243; builds on ADR-01351
- **Date**: 2026-10-03

## Context

A typed array over a SharedArrayBuffer, sent as `workerData` or by
`postMessage`, arrived as a copy at offset 0. Writes on either side were
invisible to the other. Node shares the memory. This was a caveat on the
SharedArrayBuffer and Worker rows.

## Investigation

- The worker module (`lib/node/worker_threads.ts`) already rebuilds a
  shared view from `value.buffer` and `value.byteOffset`, through `any`.
  Since ADR-01351 both read correctly.
- `isSharedView` then tests `value.buffer instanceof SharedArrayBuffer`.
  The registry boxed every root as an ArrayBuffer, so the test was false
  and the view was cloned.
- Statically, `.buffer` was typed `ArrayBuffer`. `v.buffer instanceof
  SharedArrayBuffer` folded to false, and inspect printed `ArrayBuffer`
  where Node prints `SharedArrayBuffer`. Whether a typed array's buffer is
  shared is known only at run time.

## Decision

- The registry marks a root as shared when the view made over it is a
  SharedArrayBuffer's (`__kml_view_register`'s fourth argument).
- `__kml_view_buffer_any` boxes a shared root with the SharedArrayBuffer
  host type. The compiler exports its header word too
  (`__kml_view_sab_header`).
- A typed array's static `.buffer` is that boxed host value (`any`), of its
  run-time class. The `ArrayBuffer` and `DataView` constructors unbox it as
  they unbox any buffer held in `any`.

## Implementation notes

`codegen/llvm/viewsrc/views.c`, `runtime_views.go`, `emit_arraybuffer.go`
and `emit_exprs_types.go`.

## Verification

Mac (Apple Silicon):
- a view as `workerData` and by `postMessage` in both directions, a
  subarray sent back included: writes visible on both sides at the right
  offsets, `byteOffset` preserved;
- static and `any` `.buffer` of shared and unshared views match Node's
  `instanceof`, `===` and inspect output.

Tests: new `TestE2ESharedViewAcrossWorker`; the view, DataView,
SharedArrayBuffer, worker and Atomics groups.
