# ADR-01908: `for await` over an array of boxed promises

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-21

## Context

- `for await (const x of [p, 2])` holds its elements boxed, a promise among them. The loop awaited only elements typed as promises, so a boxed promise was converted to a number (`NaN`) instead of awaited.

## Decision

- A boxed element is awaited as `await` awaits any value: a promise's value, else the value itself after the tick.

## Consequences

- Mixed arrays of promises and values iterate as in Node.
