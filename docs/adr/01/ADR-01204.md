# ADR-01204: A host handle boxed into `any` is an object

- **Relations**: `Extends ADR-01199`
- **Date**: 2026-09-28

## Context

Writing the WebSocket client in TypeScript (TDD-00232 Stage 2) needed
`data instanceof Blob` on an `any` parameter, and it did not compile. A
probe showed the wider bug: a `Map`, `Set`, `Blob`, `Headers`,
`URLSearchParams` or `ArrayBuffer` stored into `any` reported `typeof`
"string", printed as an empty line, and `TextEncoder` reported
"undefined". Node says "object" and prints each one. The global modules
take `any` parameters, so host values pass through `any` there all the
time.

## Investigation

- `emitBoxValue` (`emit_dynamic.go`) boxed any `ptr` without an earlier
  case as a string: the pointer itself, kind bits 0. A host handle is a
  bare pointer to runtime state with no header word, so nothing could tell
  it apart afterwards.
- The layout table (`emit_shape.go`, `shape.c`) finds a layout from an
  object's header word, and `emitDynamicRenderAt` already probes object
  boxes for a bigint cell, an Error and a Symbol by their headers.
- Giving each host struct its own header word (TDD-00230 P3.3's "opaque
  host handle whose first word is a type id") would change every host
  runtime's layout. A cell wrapping the handle needs no host code changed.

## Decision

- A host handle (`isHostHandle`: a `ptr` with a host `Is*` flag that no
  earlier boxing case takes) boxes as a cell `{ i64 header, ptr handle }`
  under the object tag. The header is the magic, a new `hostTypeIDFlag`
  (bit 49) and a per-program id interned per host type (`hostKey`: the
  class, plus a collection's key and value storage).
- Unboxing to a host type (`coerce`, `emitUnboxBoxToType`) loads the
  handle from a host cell; null and undefined give a null handle.
- `__kml_any_eq` compares two host cells by handle, and
  `__kml_map_any_hash` hashes one by handle, so one handle boxed twice is
  one value (`===`, Set and Map keys).
- console.log of a boxed host value calls `__kml_host_inspect(cell,
  depth)`, and `String()` calls `__kml_host_tag` (`[object Map]`). Both
  are defined at finalize and dispatch on the header id to a routine
  generated from the static type's own inspection.
- `x instanceof C` for a host class `C` (Map, Set, Blob, Headers, …)
  answers from the static type, or for a boxed `x` from
  `__kml_host_is_<C>`, which is defined at finalize over every id of that
  class. `new Headers() instanceof Map` is false now.
- Each host type gets a layout-table row with its class name and no keys,
  so a property read through `any` reads `undefined` instead of throwing
  "no shape".
- With `ArrayBuffer` recognisable in `any`, `Buffer.from(x)` and
  `new XArray(x)` for an `any` `x` dispatch at run time as Node does: a
  string decodes, an ArrayBuffer is copied (Buffer) or viewed (TypedArray),
  any other object is an array-like, and a primitive is a TypedArray length.

## Implementation notes

`codegen/llvm/emit_hostbox.go` (new), `emit_dynamic.go`,
`emit_exprs_coerce.go`, `emit_narrowing.go`, `runtime_dynamic.go`,
`runtime_collections.go`, `emit_classes.go`, `emit_shape.go`,
`emitter.go` (finalize order: inspect routines, the layout table, then the
dispatchers), `emit_buffer.go` (`emitBufferFromDynamic`),
`emit_arraybuffer.go` (`emitTypedArrayFromDynamic`). Rendering a host
value can box another (a Map of Blobs), so inspect routines are generated
until no new host type appears.

## Side effects discovered

- A host type first boxed while the layout table is generated gets no
  inspect routine and prints `[Object]`.
- Reading a host value's properties or calling its methods through `any`
  (`(m as any).get("k")`) still reads `undefined`: the layout rows carry no
  members (BACKLOG).
- A class instance nested in a dynamic container prints `[Object]`
  (dynjson.c does not consult the layout table); a host cell nested there
  prints the same.

## Verification

Mac (Apple Silicon), against Node v24.19: `TestE2EHostValuesThroughAny`
(typeof, console.log, instanceof, `===`, Set membership, `String()`,
unboxing back) and `TestE2EBufferAndTypedArrayFromAny` print what Node
prints.
