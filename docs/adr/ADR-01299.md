# ADR-01299: Fixes found porting `fs`

- **Relations**: `Extends ADR-01298`
- **Date**: 2026-09-30

## Context

Porting `fs` to TypeScript (ADR-01298) ran the lib and its tests through
paths no earlier program had exercised. Each item below failed a probe
that Node passes.

## Investigation and decisions

1. **`type`/`interface` as variable names.** `type = undefined;` (Node's
   symlink argument juggling) parsed as a type alias
   (parser_stmts.go's contextual-keyword switch). TypeScript starts a
   declaration only when a name follows. Both keywords now require an
   identifier next.

2. **An array literal holding an `any`.** `[s.mtimeMs, x.toISOString()]`
   with `x` held in `any` skipped the dynamic element in
   `inferMixedArrayElem` and fell back to the first element's `number[]`.
   The string then stored as NaN. TypeScript types a literal with an `any`
   element as `any[]`, so `inferArrayType` now does too.

3. **An Error held in `any` through a rejection.**
   `Promise.reject(err as any).catch((e: any) => e.message)` read
   `undefined`, and `e instanceof Error` was false. This was already so at
   HEAD. The rejection split the box into (object tag, pointer). The catch
   record's Error fields exist only under tag 13. `throw` already mapped
   an object box whose field 0 carries the built-in Error type-id back to
   tag 13, inside `__kml_throw_any`. That probe is now
   `__kml_caught_tag`, which `emitValueToCaughtParts` (every rejection)
   calls too.

4. **`message`/`name` on a caught non-Error.** A caught plain object's
   `message` read `undefined`. The typed-field path returned undefined for
   every non-Error tag. It now reads the property dynamically: a string,
   or undefined for any other value.

5. **A primitive into an object type.** The checker related `'buffer'` to
   `{ encoding: BufferEncoding | null; … }` as maybe. So
   `readdirSync(p, 'buffer')` resolved to the `string[]` overload. The
   required-member check (`primitiveLacksLibraryMember`) ran only for
   library types. Its member table is TypeScript's full apparent set, so it
   now runs for every object type, anonymous ones included. Symbol-keyed
   members are skipped.

6. **`s.toString()` on a narrowed string.** Inference had `toString`
   cases for Buffers and numbers only. An `any` narrowed to string
   inferred as `i64` while emission produced the string. An arrow
   returning it defined `i64` and returned a pointer (invalid IR).

7. **Overload picks: excess properties and union members.** A pick
   related an object literal to a parameter without tsc's excess property
   check, and ran the weak type check on the parameter's union as a whole.
   So `readFileSync(p, { mode })` and `readFileSync(p, 'nope')` compiled.
   `argMismatch` now runs `literalExcess` (TS2353: a key no object member of
   the union has) and relates to each union member with its own weak type
   check. The pick (`argFits`) and the report (`argMisfit`) both use it.

8. **A Buffer or number method on a value held in `any`.**
   `xs[0].toString('hex')` on a Buffer from an overloaded function with an
   `any` implementation (the lib's `readdirSync`) failed: dynamic dispatch
   had no Buffer methods. A call on a box now branches on a Buffer: it
   runs the static Buffer method (`dynBufferMethods`), else the dynamic
   call. A number's `toString(radix)` honours the radix
   (`emitDynNumberToString`). Unboxing the result to the checker's type
   instead was rejected: with an `any` argument the checker picks the
   first overload, and the result changed meaning.

9. **An `any[]` box unboxed into a typed array.** It was reinterpreted in
   place, reading NaN-boxed words as the target's elements. An array box
   records its element kind, so a `KJ_ANY` box now converts element by
   element into a new array, as a dynamic array already did.

10. **`undefined` in a binding typed as an array.** A callback's `data` on
    error, reaching `(err, data: Buffer) => …` through an `any` adapter,
    left a null header. Reading it dereferenced null: printing it looped
    forever (the same at HEAD), and `.length` segfaulted. The identifier
    read now loads through a shared empty header when the header is null,
    and carries the null header. `console.log` prints `undefined` for it,
    and `.length`/`for…of` throw Node's TypeError (`Cannot read properties
    of undefined (reading 'length')`, `xs is not iterable`). A direct call
    passing undefined into such a parameter is ADR-01300's.

11. **`super(message, options)` in an Error subclass** was rejected
    ("takes at most one message argument"). The options bag's own `cause`
    is now stored, as `new Error(message, { cause })` stores it, and stays
    absent when there is none.

12. **A class type read inside a subclass constructor.** A class
    narrowed by the checker (`NarrowedTo`) kept a stale field layout when
    read inside a callable subclass's constructor, so a field read gave
    another field's value. `emitIdent` and inference now canonicalize the
    class type.

## Verification

- Each item's probe prints what Node prints: items 3 and 4 against Node
  v24.19.0, and item 5 against tsc's TS2322.
- `go test ./checker ./binder ./parser` passes.
- tests/fs_port_test.go covers items 1, 2, 3 and 6 through the fs lib.
- **Mac (Apple Silicon).**
