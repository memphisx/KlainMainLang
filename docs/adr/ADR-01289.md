# ADR-01289: `util` as Node's lib/util.js in TypeScript

- **Relations**: `Implements part of TDD-00230` (P3.1), `Supersedes ADR-00325`, `Extends ADR-01288`
- **Date**: 2026-09-30

## Context

`util` was compiled directly (emit_util.go):

- **`util.format`** was walked at compile time, so its format had to be a
  string literal.
- **`util.inspect`** ignored its options.
- **The module** exposed only those two functions, plus `promisify` from a
  TypeScript companion. `util/types` did not exist.

## Decision

**Modules.**
- `lib/node/util.ts` ports lib/util.js.
- `lib/node/internal_util_inspect.ts` holds `inspect` itself, from
  lib/internal/util/inspect.js. It is separate from `util` because
  `events`, `readline` and `test` import it, and `util` reaches `process`,
  which is an `EventEmitter`: a cycle.
- `lib/node/util_types.ts` is `util/types`, and `util.types` is the same
  functions.
- `internal_util.ts` stays as lib/internal/util.js (`promisify`).
- emit_util.go is deleted. console.log's own specifiers keep their
  converter (emit_console_format.go).

**`util` exports:**
- `format` and `formatWithOptions`: Node's `formatWithOptionsInternal`, run
  at run time. `%s` inspects an object whose `toString` is built in and
  calls a program's own. `-0` keeps its sign, and `numericSeparator`
  applies.
- `inspect(value, options)` and its legacy `(value, showHidden, depth)`
  form. `depth`, `compact`, `sorted`, `breakLength` and `maxArrayLength`
  reach `__kml_native.inspectWith`, which now takes the last two as well.
  Node's `depth: -1` shows only the type, and Infinity is unlimited. The
  export also carries `inspect.custom`, `inspect.colors` (with Node's
  aliases), `inspect.styles` and `inspect.defaultOptions`.
- `isDeepStrictEqual` (internal/util/comparisons), `callbackify` (with
  `ERR_FALSY_VALUE_REJECTION`), `deprecate` (once per code) and
  `debuglog`/`debug` (`NODE_DEBUG` sections, `*` patterns).
- `stripVTControlCharacters`, `toUSVString`, and
  `getSystemErrorName`/`getSystemErrorMessage`/`getSystemErrorMap`.
- `styleText`, which is plain unless the stream shows colours.
- `types`, `aborted`, and the deprecated `isArray`.

**Codegen, found by the port.** An async arrow whose contextual signature
returns `Promise<any>` stored its value unboxed while its consumers read a
box: `callbackify(async (a) => a * 2)` gave 38 for 42. Its promise now
holds the value boxed.

## Verification

On the Mac (Apple Silicon), outputs match Node v24.19.0:
`tests/util_port_test.go` and the existing tests that use `util`.
