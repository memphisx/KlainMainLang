# ADR-01440: `ArrayBuffer.byteLength` is a number

- **Relations**: Implements TDD-00230 (P2.2)
- **Date**: 2026-10-07

## Context

A shadow bucket after ADR-01439 (911 rows, `kml_dataview.ts`,
`internal_fs.ts`) was `buffer.byteLength` on an `ArrayBuffer`, which codegen
inferred as `i64` and the checker types `number`.

## Investigation

- Emission already converted the byte length to a double for a typed array
  and for an `ArrayBuffer` expression, but returned the raw `i64` for an
  `ArrayBuffer` named by a variable.
- Inference had no `byteLength` rule and fell to the integer default.

## Decision

`.byteLength` of an `ArrayBuffer` or typed array is a `double`, in
emission (every receiver form) and in inference.

## Verification

- `TestE2EArrayBufferByteLengthIsNumber` (against Node) and the
  `ArrayBuffer`, `DataView`, typed-array and `Buffer` tests pass on the Mac.
- The probe's shadow row is gone.
