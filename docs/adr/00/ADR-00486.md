# ADR-00486: HTTP status reason phrases

- **Date**: 2026-08-29

## Context

The http-server status caveat: every response's status line carried a
hardcoded `OK` (`writeHead(201)` → `201 OK`), a visible-on-the-wire
deviation.

## Decision

A `__kml_http_reason(status)` runtime switch over the standard registry
(36 common codes, 1xx–5xx) feeds a `%s` slot in the response format;
unknown codes fall back to `OK` (clients key off the number anyway).
Shared by every response path through `__kml_http_send_response`.

## Verification

Mac. `curl -i` shows `HTTP/1.1 201 Created`; new
`TestE2EHTTPReasonPhrase` asserts `404 Not Found` end-to-end via Go's
http client; full HTTP/fetch server batch green.
