# ADR-01661: Catch frames, throws and fiber switches through single primitives

- **Relations**: Implements [TDD-00230](../../tdd/TDD-00230.md) (P3.3b)
- **Date**: 2026-10-16

## Context

TDD-00230 P3.3b asks that `throw`/`catch` be lowered through one primitive
and `await`/`yield` suspension through another, so that a WebAssembly
target (exception handling instead of setjmp/longjmp; a stackless state
machine or Asyncify instead of `ucontext`) replaces two functions rather
than every site. Codegen opened catch frames in seven places (try, a
protected catch, an async body, a generator body, a dynamic promise
executor, a fetch body promise), each spelling out the jmpbuf push,
`setjmp`, compare and branch; it threw in 36 places and switched fibers in
seven.

## Investigation

- Every catch frame was the same four instructions; only the labels
  differed. Every close on a non-throwing path was one `__kml_pop_jmpbuf`
  call (a throw pops in `__kml_throw`).
- Register and label counters are separate (`freshReg`, `freshLabel`), so
  allocating the frame's registers inside a helper leaves the IR
  byte-identical whatever order a site created its labels in.
- Fiber switches were `swapcontext` calls, two of them discarding the
  result.

## Decision

`exc_prims.go` holds the primitives:

- `excEnter(catchL, tryL)` opens a catch frame and branches to `catchL`
  when a throw unwinds to it, to `tryL` now; `excLeave()` closes it.
- `excThrow(err)` throws an error object; `excThrowAny(tag, pay)` throws a
  value of any kind.
- `fiberSwitch(from, to)` suspends the running fiber into `from` and
  resumes `to`, returning the switch's result register.

`TestExceptionLoweringIsOnePrimitive` rejects the raw calls in any
`emit_*.go` file.

## Implementation notes

Sites rewritten in `emit_exceptions.go`, `emit_async.go`,
`emit_anyprom.go`, `emit_fetch.go`, `emit_generators.go`, `emit_stmts.go`
(the pending-finally handler pop), `emit_http.go`,
`emit_http_upgrade.go`, and the 15 files that threw. The typed-error
helpers (`__kml_throw_nullderef`, `__kml_throw_range_error`) build their
error and throw through `__kml_throw`, so they are not separate
lowerings. The `runtime_*.go` IR-text helpers keep their own switches and
leave as the IR-text ratchet moves them to C.

## Side effects discovered

None.

## Verification

- IR byte-identical on the 68-file corpus except the two programs with a
  fiber switch whose result was discarded: it now names a register, which
  renumbers the registers after it.
- `go test ./codegen/llvm`; targeted E2E suites for try/throw/catch/
  finally, generators, async/await, errors, and the HTTP servers (Mac).
