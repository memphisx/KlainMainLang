# ADR-01291: `os` as Node's lib/os.js in TypeScript

- **Relations**: `Implements part of TDD-00230` (P3.1), `Supersedes ADR-00090`, `Supersedes ADR-00777`, `Extends ADR-01077`
- **Date**: 2026-09-30

## Context

`os` was compiled directly: a codegen case per function (emit_os.go), the
CPU readers written as IR per platform (runtime_os.go, runtime_os_win.go),
and a passwd shim for `homedir`. `getPriority`, `setPriority` and
`os.constants` did not exist. `EOL`, `arch()` and `endianness()` were
compile-time constants, and `tmpdir()` read only `TMPDIR`.

## Decision

- **Module.** `lib/node/os.ts` is Node's lib/os.js. The natives it calls
  stand in for `internalBinding('os')`. They live in osinfo.c, beside the
  host reads it already had, and are linked through `@link osinfo`:
  - `osString(which)`: type, version, release, machine, hostname, homedir.
  - `osNumber(which)`: uptime, total and free memory, available
    parallelism, load averages, and whether the host is big-endian.
  - Snapshot readers with indexed getters: `osCpus()` (libuv's
    `uv_cpu_info` per platform), `osNetifs()` and `osUserInfo()`.
  - `osGetPriority`/`osSetPriority`, and `osErrno()` for the last failure.
  - `osConstant*`: the four `os.constants` groups, generated from
    node_constants.cc in its order, each name behind its `#ifdef`.
- **Faithful details:**
  - `homedir` is libuv's `uv_os_homedir`: a set `HOME` wins, an empty one
    included.
  - `tmpdir` is `getTempDir`: `TMPDIR`, then `TMP`, then `TEMP`.
  - Free memory on Linux is `MemAvailable`.
  - `cidr` is Node's own `getCIDR`.
  - A failed call throws `ERR_SYSTEM_ERROR`, a `SystemError` carrying the
    call's `info`.
  - `userInfo({ encoding })` gives Buffers for `'buffer'` and re-encodes
    the strings for any other encoding.
  - The functions Node gives a `Symbol.toPrimitive` have one here too, so
    `${os.hostname}` is the hostname (ADR-01292 makes that conversion work).
- **libuv descriptions.** The errno table gains libuv's text for `ESRCH`,
  `ETIMEDOUT`, `EHOSTUNREACH`, `ENETUNREACH`, `ECONNABORTED` and `ENOBUFS`.
  These previously fell back to `strerror`.
- **Compiled path deleted.** emit_os.go, runtime_os_win.go, the IR CPU
  readers, the passwd shim, the `os` virtual marker and its `declare module`
  are gone.

`SystemError`'s `errno` and `syscall` are copies of `info`'s, where Node
has accessors over it: a class accessor cannot take the name of the error
layout's own `errno` slot. The Windows priority-class mapping is
compile-checked only (mingw).

## Verification

Outputs match Node v24.19.0 in `tests/os_port_test.go` and the examples:
- the Mac (Apple Silicon);
- Linux (Docker, glibc/arm64): `cpus`, `userInfo`, interfaces, priority
  and `constants`, against Node 26.10 in its own container.

osinfo.c compiles for Windows with x86_64-w64-mingw32-gcc.
