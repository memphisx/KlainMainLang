# ADR-01249: A stream handle on a device `poll()` rejects

- **Relations**: `Extends ADR-01239`
- **Date**: 2026-09-29

## Context

With stdin from `/dev/null`, `make examples` hung two examples for their
300 s limit (`process_stdin/stream.ts`, `readline/readline.ts`); Node ends
at once. `/dev/null` is a FILE (a character device, as libuv classifies
it), so stdin is a stream handle over fd 0. On macOS, `poll()` reports
POLLNVAL for `/dev/null`, while `select()` reports it readable. The
reactor's per-handle readiness check read only POLLIN/POLLHUP/POLLERR, so
the handle was never readable.

## Decision

POLLNVAL counts as readable and writable: the operation itself answers,
with EOF for `/dev/null` and EBADF for a closed descriptor.

## Verification

Mac (Apple Silicon): `TestE2EStdinDevNullEnds`; both examples under
`make examples`.
