# ADR-01198: Blob's readers return promises; Blob is declared

- **Relations**: `Extends ADR-00314`, `Implements TDD-00230`
- **Date**: 2026-09-28

## Context

`blob.text().then(…)` did not compile ("a string has no method 'then'"):
`text()`, `arrayBuffer()` and `bytes()` returned the value itself, which
`await` passes through. And `(await blob.text()).length` was 0, with
concatenation dropping the text.

## Investigation

- `emitBlobCall` (`codegen/llvm/emit_blob.go`) built `text()`'s result with
  a bare `malloc`; strings carry their length in the 8 bytes before the
  characters (`__kml_str_alloc`, `runtime_strheader.go`), so `.length` read
  the heap word before the buffer.
- Node's `Blob.arrayBuffer()` (lib/internal/blob.js) pulls the blob through
  its reader, queueing a microtask between pulls; `text()` and `bytes()`
  are `.then`s of it. Measured against Node v24.19 with a `.then` chain as
  a clock: an empty Blob's `arrayBuffer()` settles at once, a one-part
  Blob's after one microtask hop, `text()`/`bytes()` one hop later; each
  further part adds two hops (2n − 1 for n parts).

## Decision

- The three readers return a task promise of the copy
  (`emitBlobReadPromise`): settled at once for an empty Blob's
  `arrayBuffer()`, else through `@__kml_promise_defer_settle` after one hop
  (`arrayBuffer()`) or two (`text()`, `bytes()`), as for a one-part Blob.
  `inferExprType` types them as promises.
- `text()` allocates its string with `__kml_str_alloc`.
- `lib/node.d.ts` declares `Blob` (lib.dom.d.ts shapes; no `endings`
  option, which is not implemented).

## Implementation notes

`codegen/llvm/emit_blob.go`, `emit_exprs_types.go`, `lib/node.d.ts`.

## Side effects discovered

- A Blob keeps one buffer, not its parts, so a several-part Blob's readers
  settle as a one-part Blob's do (status caveat).

## Verification

Mac (Apple Silicon), against Node v24.19: `TestE2EBlobReadersArePromises`
(length, `.then`, the settle order of empty and one-part Blobs against a
`.then` chain); the Blob and Response tests; `tools/libconform`; the
example sweep reports no type error.
