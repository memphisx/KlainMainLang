# ADR-01855: `for await` loop variables, contextual pattern parameters and computed keys are typed

- **Relations**: `Implements TDD-00230` (P3.3: the checker answers what inferExprType did)
- **Date**: 2026-10-21

## Context

- The checker typed a `for await` loop variable only over an array or a string. Over an async generator (`for await (const line of readFile())`) it was unanswered, and so was every async generator yielding it, every call of that generator, and the `.next().then(...)` chains on its result. Test262's async-generator tests are built this way, and the pattern led the shadow report's largest bucket.
- In the strict lane, an unannotated destructured parameter without a default (`({ done, value }) => …`) was unanswered even with a contextual type, so the literal fell back, and a `.then` taking it degraded to `Promise<any>`.
- When such a parameter's type has no representation (a union of two object types), the oracle could not answer the literal, though emission types the parameter as a box.

- An element read through a string- or number-typed key on an object type without an index signature (`c[String(1.1)]` on a class instance) was unanswered. tsc types it `any`, and reports TS7053 under `--strict`; the strict lane reported nothing and compiled the program.

## Decision

- A `for await` loop variable is the awaited element of what it iterates (`Awaited<T>`, tsc's async use of getIteratedTypeOrElementType), through the existing `iteratedType`.
- An unannotated destructured parameter takes its contextual type, else the type its pattern implies (tsc's getTypeFromBindingPattern): an object of its keys, a tuple of its positions, each `any` unless nested, a key with a default optional.
- `literalFromReturns` covers arrows as well as function expressions, and maps a destructured parameter whose type has no representation to a box, as emission does. The checker exports `AnyType` for it.

- Such a read is `any`, and the strict lane reports TS7053 for it (`checkComputedIndexKey`), as tsc does; a literal key naming a property, an index signature and an `any` receiver report nothing.

## Consequences

- `TestForAwaitLoopVariable` and `TestPatternParameterContextual` cover async generator, promise-array and set iteration, contextual and implied pattern types, and nested patterns.
- `TestImplicitAnyElementAccess` and `TestComputedKeyImplicitAny` cover the type and the diagnostic.
- Verified on Apple Silicon (checker package; the Test262 file named in the report reports no rows).
