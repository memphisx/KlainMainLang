# ADR-02046: An Error's given prototype, a class extending Error by alias

- **Date**: 2026-11-22

## Context

- `Object.setPrototypeOf(err, p)` recorded `p` (`getPrototypeOf` saw it),
  but a read of `p`'s member on `err` was undefined: an Error has no
  shape, and `__kml_shape_get` returned before the given prototype was
  consulted. A call of a member the Error type does not declare threw at
  compile time.
- In the JavaScript lane, `class E extends Err` with `Err = Error` (or
  `globalThis.Error`) was left to the run-time base path, whose instance
  is a plain Error: `E`'s methods were missing.

## Decision

- `__kml_shape_get`: an Error given a prototype reads a key it does not
  own (`__kml_error_own_names`) through that prototype's chain; a key the
  chain lacks falls through to the error's own reads.
- `Object.setPrototypeOf` of an Error box (tag 13) sets it as a class
  instance's (`__kml_shape_set_proto`).
- A call of a member an Error does not declare is a run-time read
  (`memberBoxedMethod`), throwing the same TypeError when nothing has it.
- `checker.DynamicBase` in the JavaScript lane specializes over host
  constructors too, when every member of the variable's stored type is a
  candidate class or one of them.

## Consequences

- Tests: `TestE2EErrorGivenPrototypeJS`.
