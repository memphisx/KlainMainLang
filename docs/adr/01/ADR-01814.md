# ADR-01814: a Proxy's own keys and own property descriptors run its traps

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- A Proxy ran its `get`, `set`, `has` and `deleteProperty` traps, and its `ownKeys` trap only for `Object.getOwnPropertySymbols`.
  - `Object.keys`, `Object.getOwnPropertyNames` and object rest (`{ ...r } = proxy`) read the proxy's own empty header, so they found no keys at all. A proxy without traps did not forward to its target.
  - `Object.getOwnPropertyDescriptor` ignored the `getOwnPropertyDescriptor` trap.
  - `Reflect.ownKeys` ran the `ownKeys` trap twice, once for strings and once for symbols.
- Test262's `object-rest-proxy-*` tests failed.

## Decision

- `shape.c` holds a Proxy's `[[OwnPropertyKeys]]` (`__kml_proxy_own_keys`): the `ownKeys` trap's checked result, in the trap's order, else its target's own keys. It also holds `[[GetOwnProperty]]` (`__kml_proxy_own_desc`): the `getOwnPropertyDescriptor` trap's result, completed into a new descriptor object, else its target's. A trap returning neither an object nor undefined is a TypeError.
- `dynobj.c` routes a Proxy through them:
  - The key list behind `Object.keys` and `getOwnPropertyNames` takes the string keys in trap order. `Object.keys` filters them through `[[GetOwnProperty]]`.
  - `__kml_dynobj_own_desc` builds every bag's descriptor in C, replacing the inline IR in `getOwnPropertyDescriptor`.
  - Weak defaults keep a program without a Proxy linking. `new Proxy` links `shape.c`.
- `Reflect.ownKeys` of a Proxy takes `[[OwnPropertyKeys]]` once, boxed.
- `JSON.stringify` of a Proxy serializes its enumerable own keys through those internal methods, each value through `[[Get]]`. It had serialized the target.
- Keys that C code passes to a trap, or stores in a bag the program can see (a descriptor's `value`, `enumerable`, …; `toJSON`), are length-prefixed JS strings. A bare C literal crashed a trap that read the key's `length`.
- Object rest of a Proxy source follows CopyDataProperties (`__kml_proxy_obj_rest`): the keys once, then per key outside the excluded ones, `[[GetOwnProperty]]` and, when enumerable, `[[Get]]`.

## Consequences

- `TestE2EProxyOwnKeysAndDescriptors` checks the trap order against Node: keys, descriptors, rest, `JSON.stringify`, forwarding through nested proxies, and both TypeErrors.
- A trap receives a string key as its string, and a symbol key as the symbol only in the `getOwnPropertyDescriptor` trap. The `get` trap's key for a symbol is still its internal key string, as before.
