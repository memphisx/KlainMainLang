# ADR-00474: type predicates, bare class fields, ambient namespaces

- **Relations**: Extends [ADR-00471](ADR-00471.md), [ADR-00450](ADR-00450.md); the field default follows ADR-00042's unannotated-parameter convention
- **Date**: 2026-08-29

## Context

Second pass over the three largest remaining TS-oracle buckets after the
ambient-stub work, none of which need the deferred dynamic-semantics TDDs:

- `expected {, got IDENT` (72) — type predicates (`x is number`) and
  assertion signatures (`asserts x is T`) as return types.
- `class field '%s' requires a type annotation or an initializer` (168) —
  bare fields (`class C { x; }`).
- The `undefined variable` residue — identifier-named ambient namespaces
  (`declare module Foo.Bar { export var foo; }`) whose members are then
  used as values.

## Decision

- **Type predicates**: `x is T` parses in `parseTypeAnnotation` and
  resolves to `boolean` (the function *is* an ordinary boolean predicate
  at runtime); `asserts x [is T]` resolves to `void`. The flow-narrowing
  itself is not modeled — a disclosed narrowing.
- **Bare class fields** default to `number`, the same convention an
  unannotated parameter and an untyped variable already follow; JSDoc
  `@type` still overrides. TS infers implicit `any` here, so a later
  non-numeric assignment is a shifted typed error, not accepted.
- **Ambient namespaces**: identifier-named `declare namespace/module X`
  (dotted included) routes through the real namespace parser with an
  `ambient` flag — var members are zero-initialized vars, function
  members get the ADR-00471 throwing stub; the string-named external-
  module and `declare global` forms keep the token-skipper erasure.
  `export declare …` passes through `parseExportDeclaration` unwrapped.
- **Namespace-member assignment**: `X.member = v` / `A.B.member = v`
  rewrites to the desugared flat binding in `emitAssign`, completing the
  read/call/assign triad the namespace dispatch needed anyway (found
  because ambient members are typically *assigned* right after
  declaration).
