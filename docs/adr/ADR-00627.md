# ADR-00627: D1 Stage 4 — vanilla-JS prototype classes (`-compat=js`)

- **Relations**: `Implements TDD-00155 (Stage 4), TDD-00022 (break shape 3)`, `Extends ADR-00623, ADR-00625`
- **Date**: 2026-09-02

## Context

The last piece of TDD-00022's untyped-JS surface with a runtime
representation waiting for it: pre-ES6 prototype "classes". D1 Stages 1–3
supplied the bags, prototype chains, and `__proto__`; Stage 4 adds the two
missing kinds — functions as constructors, and function values as
prototype methods — gated on `-compat=js` (strict mode byte-identical).

## Decision

**Dynamic functions, box tag 12** (`emit_dynfunc.go`): a function expression
compiled in a dynamic position (`F.prototype.m = function() {...}`, a
dynamic-object property) gets the uniform dynamic ABI
`{i8,i64} @fn(ptr env, {i8,i64} this, i64 argc, ptr argv)` — every call site
can invoke it signature-blind. Parameters bind as boxed values (a missing
argument reads undefined), `this` is the boxed receiver, a fall-off end
returns undefined. The value is a `{fnptr, env, arity}` record; identity is
per-evaluation, like a JS closure. `typeof` → "function"; stringify skips it
like tag 8. Boxing a *statically-typed* closure into `any` is now a clean
error (previously a silent mis-box as a string — a real latent bug).

**Method dispatch**: `obj.m(args)` on a bare `any` receiver does the Stage-3
chain-walking read then an indirect dynamic-ABI call with the receiver as
`this` — inherited and overridden methods fall out of the proto walk. A
non-function property throws the JS TypeError.

**Constructor functions** (`emit_protoclass.go`): a top-level function
declaration used with `new` or whose `.prototype` is written is recognized
as a prototype constructor (`jsCollectProtoCtors`, before any body emission).
It is emitted with a hidden boxed `this` first parameter (its `this.x = v`
writes are Stage-1 dynamic member sets); its prototype bag is a lazily
initialized module global (`F.prototype` reads/writes route to it; a plain
data-segment global — Boehm scans it, no TLS treatment needed). `new F(args)`
builds a fresh bag linked to the prototype and runs the body against it;
`Base.call(this, args)` passes the receiver through — the pre-ES6
inheritance chain — while the generic `.call` path keeps discarding thisArg
(ADR-00398). A direct `F()` call is rejected with guidance.

**Inference reach** (three fixes forced by the classic pattern):
- `.call` sites feed call-site parameter inference (`F.call(this, name)` is
  often a base constructor's only call site).
- An identifier argument that is the *enclosing function's parameter*
  becomes a propagation edge, resolved to a fixed point after collection —
  `new Dog("Rex")` types Dog's `name`, the edge carries it to Animal's. The
  `new`-site slot map is consulted as an edge source too.
- An unresolvable identifier argument now contributes *nothing* — it was
  answering the number default through `inferExprType`, silently mistyping
  chain arguments (caught as pointer-garbage output, fixed before landing).

**String concatenation with a dynamic operand**: `+` with one string side
and one `any` side goes through the runtime ToString dispatch (exactly what
template literals already did) — `this.name + " barks"` is the beating heart
of every prototype method. Arithmetic between dynamic operands stays
rejected (TDD-00076's NaN-box territory).

## Consequences

- The full pre-ES6 shape — constructors, prototype methods, `Object.create`
  inheritance, override, chain calls — compiles natively and byte-identical
  to Node on the verification programs. TDD-00022's break shapes 1–3 are
  now all covered; what remains of it is dynamic property add on *static*
  literals (D1 Stage 6) and the implicit-`any` operator half (TDD-00076).
- Disclosed limits: no captures of enclosing locals in prototype methods; no
  rest/destructured/async method params; `instanceof` on dynamic values
  stays rejected; the not-a-function TypeError names the property without
  the receiver text; arithmetic on boxed fields waits for TDD-00076.
- Verified on the Mac (arm64): 6 new E2E tests (19 in `tests/jsmode_test.go`),
  the 4-minute wide regression suite green, example extended and
  diff-identical to Node.
