# ADR-00509: Generate the ADR & TDD index READMEs and the status backlog from the record files

- **Relations**: Implements [TDD-00149](../tdd/TDD-00149.md)
- **Date**: 2026-08-30

## Context

`docs/adr/README.md`, `docs/tdd/README.md`, and the "Design Documents (TDDs)"
backlog in `docs/status/README.md` were three hand-maintained tables restating
facts that already live in the record files (each ADR/TDD's title, status,
relations). Keeping the same fact in two hand-edited places drifted, as
[TDD-00149](../tdd/TDD-00149.md) documents: the status backlog listed shipped
TDDs its own preamble promised to omit, TDD-00046's index status contradicted
its file, TDD-00032 was mislabeled `Superseded` in both indexes while its file
said `Not Started`, and ~347 ADR index Relations cells diverged from the ADR
files (one, ADR-00406, citing different ADR numbers entirely).

## Investigation

A three-part corpus analysis established recoverability per column: TDD `#`
heading + bare Status parse cleanly in all 148 files; ADR titles in all 508;
ADR→TDD links live canonically in ADR `Relations` bullets (238 carry them), not
in the TDDs; TDD Notes and the status-backlog's shorter titles are editorial
with no machine source. The existing `cmd/statusgen` already renders
`docs/status/*.md` from `docs/status/data/*.json` via ordered segments, giving a
natural home.

## Decision

Extend `cmd/statusgen` to generate the two index READMEs and the backlog as
projections of the record files (`records.go`):

- **`docs/tdd/README.md`** — a table-splice generator preserving the hand-edited
  preamble and regenerating only the Index rows. `#`/Title/Status/Notes come
  from each TDD file (Status = leading enum word only); **Related ADRs is
  derived** by scanning every ADR's Relations bullet for `TDD-NNNNN` tokens.
- **`docs/adr/README.md`** — same splice; Title from the heading, Relations from
  the file's own Relations bullet, normalized (wraps joined, every ADR/TDD
  reference rewritten to one canonical link form, pipes escaped).
- **Status backlog** — a new `tddBacklog` index segment. Which rows render and
  their Status derive from the TDD files (not-yet-done only, so a shipped TDD
  drops automatically); the segment's editorial map supplies each row's
  status-page-specific title/notes. A not-yet-done TDD missing an editorial
  entry is a hard error.
- **`make reference-sync`** — `check-reference.mjs --sync` rewrites each website
  surface's coverage counts/percentages from its status page via a surgical
  text edit (preserving the file's compact hand-formatting), ending the stale
  hand-edited numbers.

`generate`/`check` (i.e. `make status`/`status-check`) now emit and guard both
READMEs, so CI fails if either drifts from the record files.

## Implementation notes

- The record files gained the one format field they lacked: an optional
  `- **Notes**:` header line on TDDs (migrated one-time from the old index).
- One-time reconciliation: 122 TDD Notes + 36 TDD titles folded into the files;
  10 ADR files enriched with a Relations reference the index had but the file
  lacked. Regeneration otherwise *restores* detail the index had curated away
  (parentheticals, "Part 1 only"), which is why ~299 ADR rows change with no
  information lost.
- The `tddBacklog` segment round-trips through `importIndex` (a header-keyed
  parser rebuilds the editorial map from a rendered table; Status is re-derived,
  never stored).

## Side effects discovered

- **ADR-00406 had a mis-numbered relation**: its file cited `ADR-00357` (the
  HTTP/2 ADR) where its own parenthetical said "chained createServer" — that is
  `ADR-00391`. The old index had the right number; the file was corrected to
  `ADR-00391` so the generated relation is right at the source.
- `statusgen roundtrip` on the status pages fails on a pre-existing, unrelated
  issue (a `TYPE-SYSTEM.md` caveat containing an unescaped `-1 | 0 | 1` literal
  breaks the importer's row split). The routine generate/check path is
  unaffected; noted for a later importer fix.

## Verification

- `make status` idempotent (0 regenerated on re-run); `make status-check` green
  (35 pages match source); `make reference-check` green; `reference-sync`
  verified to correct a deliberately-broken count while preserving formatting.
- `go build ./...` and `go vet ./cmd/statusgen` clean.
- Verified on macOS (Apple Silicon M4).
