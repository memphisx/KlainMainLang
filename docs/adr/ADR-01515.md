# ADR-01515: Return inference reads a catch binding as the caught value

- **Relations**: Extends TDD-00229, TDD-00230
- **Date**: 2026-10-09

## Context

Return-type inference defined a catch binding as `any`, so that
`catch (e) { return e }` returned a box. Emission binds it as the
caught-value record (`emitCatchBody`), so every read of `e` in a catch
body (`e.x`, `e instanceof C`) was inferred one way and emitted another
(shadow bucket 11, 119 rows).

## Decision

Inference defines the binding as the caught-value record, as emission
does. A return candidate of that type is widened to `any` where it
becomes the function's result (`inferCandidateReturnExpr`), which keeps
`return e` boxed.

None.
