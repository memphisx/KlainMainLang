# ADR-00967: EventTarget/AbortSignal accept a zero-argument listener

- **Relations**: Implements TDD-00081
- **Date**: 2026-09-15

## Context

`addEventListener` rejected a listener that declared no parameter:

```ts
new EventTarget().addEventListener("x", () => { /* ignores the event */ })
// codegen error: an event listener must take exactly 1 argument (the event)
```

A zero-arg listener is valid WHATWG/JS — the event is passed as the sole
argument and a handler that declares no parameter simply ignores it. `() => …`
is common (WPT `dom/abort`, everyday `.addEventListener("click", () => …)`).
The 1-arg-only rule blocked those files from compiling (BACKLOG WPT gaps).

## Investigation

`resolveEventTargetListenerArg` (`emit_eventtarget.go`) required
`len(FuncParams) == 1`. Dispatch (`emitDispatchToMap`) already invokes every
listener through a uniform 1-arg call site
(`Callback{ty: FuncType([]Type{eventTy}, TypeVoid)}` + `emitCBCall`), and the
listener list is type-erased, so dispatch does not know each listener's arity.
`emitCBCall` reconciles the call to the callback's declared arity, and a 0-param
function invoked with one extra pointer argument leaves it in an ignored
register (benign on SysV/Win64, void return) — confirmed at runtime, including
captured-variable, `once`, and AbortSignal listeners.

## Decision

Accept 0 or 1 parameter; a declared parameter must still be the `ptr` the event
box arrives as; two-or-more parameters stay a clean rejection (dispatch can never
satisfy them). AbortSignal listeners share this resolver, so they gain the same
tolerance.

## Side effects discovered

`removeEventListener`/`EventEmitter.off` by a **named-function reference** does
not match at any arity — `emitNamedFuncValue` mallocs a fresh closure header per
reference, and remove compares header pointers. A const-bound listener (one
stored header) removes correctly, so this feature's removable path works; the
named-reference gap is pre-existing, orthogonal to arity, and now recorded in
BACKLOG for a stable-header follow-up.

## Verification

- `TestE2EEventTargetZeroArgListener` (new): 0-arg arrow, `once`, const-bound
  remove, and an AbortSignal 0-arg listener — all match Node.
- `examples/events/eventtarget.ts` gains a 0-arg listener line.
- `EventTarget|AbortSignal|Abort` suites green; `go build`/`go vet` clean;
  `make examples`. macOS arm64 (M4).
