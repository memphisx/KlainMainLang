# ADR-00744: Windows console — enable VT output processing at startup

- **Relations**: Implements a [TDD-00180](../tdd/TDD-00180.md) §2 row; extends [ADR-00719](ADR-00719.md) (the Win32 platform layer), [ADR-00727](ADR-00727.md) (the pseudo-console test harness), builds on the VT-input handling in the `klain:tty` raw-mode path
- **Date**: 2026-09-07

## Context

`ENABLE_VIRTUAL_TERMINAL_PROCESSING` was turned on only inside `setRawMode(true)` (`emit_tty.go`). So a program that just did `console.log('\x1b[31m…')` on a legacy Windows console — without entering raw mode — had the escape printed literally instead of rendered as colour. Node turns VT output processing on for stdout/stderr at startup, so ANSI colour works in an ordinary `console.log` on Windows 10+ the same as on a POSIX terminal.

## Decision

The shim's startup constructor (`kml_win_shim_init`, `win32shim.c`) now enables `ENABLE_VIRTUAL_TERMINAL_PROCESSING` (0x0004) on both `STD_OUTPUT_HANDLE` and `STD_ERROR_HANDLE`, guarded by `GetConsoleMode` so it is a no-op when the stream is a pipe or file (the common case under a test harness or a shell redirect). This runs once, before `main`, and is independent of the raw-mode path, which still sets/restores its own input and output modes around `setRawMode`.

## Consequences

- `tests/tty_vt_startup_windows_test.go`: a plain `console.log` colour sequence reaches the pseudo-console as a real VT sequence around the text (verified on Windows 11 under the ConPTY harness). The pseudo-console is VT-native, so it cannot demonstrate the legacy-conhost difference directly; the test guards that startup does not mangle or double the sequence, and that colour works without raw mode. The full `klain:tty`/`klain:tui` raw-mode suite still passes, so the startup enable does not disturb raw-mode save/restore.
- Still open in §2: `WriteConsoleW` for non-ASCII output (mojibake off code page 65001), `ReadConsoleW` for non-ASCII console input, `CommandLineToArgvW` for non-ASCII `process.argv`, and a `'resize'`/`SIGWINCH` console-resize watcher.
