# ADR-01472: `new C(…)` checked against the class's constructor

- **Relations**: Extends ADR-01470
- **Date**: 2026-10-08

## Context

Porting `klain:webview` to TypeScript (ADR-01471) moved `bindings: { x: 5 }`
from a codegen check to the type checker, and the test expecting its
rejection passed the program. tsc rejects it: `number` is not assignable to
the binding's function type.

## Investigation

- `new W(5)` against `constructor(o: string)`, `new W(1)` of a class with no
  constructor and `new B("s")` through an inherited `constructor(x: number)`
  all compiled under the strict lane, caught only by codegen's own
  representation checks with messages that are not tsc's.
- checker/check.go's `NewExpression` case sent a `new` through
  `checkSignatureCall` only when its target was a value with construct
  signatures (`declare var DataView: DataViewConstructor`); a class target
  was never checked.
- `constructorType` (checker/symbols.go) built a class's construct signature
  from the implementation's parameters, ignoring the overload signatures the
  parser keeps on the constructor (`Overloads`), so an overloaded
  constructor accepted anything its implementation took.

## Decision

- A `new` of a class is checked as the call it is, through the same
  `checkSignatureCall` as a construct-signature value: arity (TS2554),
  argument assignability (TS2345, elaborated per property), overloads
  (TS2769), generics as for a call.
- An overloaded constructor's construct type is its overload signatures,
  each returning the instance, not the implementation's.

## Implementation notes

checker/check.go (the `NewExpression` case), checker/symbols.go
(`constructorType`), checker/check_test.go (five cases).

## Side effects discovered

None.

## Verification

- `TestCheck`: a class argument mismatch (TS2345), an extra argument to a
  class without a constructor (TS2554), an inherited constructor's
  parameter, an overloaded constructor matching no overload (TS2769) and one
  matching.
- The TypeScript suite on the Linux boxes (ADR-01474's verification).
