# ADR-01008: Dynamic-object console.log inspect form

- **Relations**: Extends TDD-00212 (boxed-array inspect), TDD-00155 (D1 dynamic objects)
- **Date**: 2026-09-18

## Context

The stale-caveat sweep confirmed "`console.log` renders a dynamic object
`[object Object]`" — Node prints the util.inspect form `{ a: 1, b: 'x' }`.
Boxed arrays already had inspect rendering (TDD-00212 Stage 2:
`__kml_dynarr_inspect`), but `kmlTagDynObject` had no branch in
`emitDynamicRender` and fell through to the `[object Object]` default.

## Investigation

The dynobj record layout (props table: key/tag/pay/attrs ×32 bytes) and the ES
enumeration-order walker (`es_order`) already live in `dynjsonsrc/dynjson.c`
for `JSON.stringify`; the inspect value formatter (`inspect_val`) exists for
arrays. So the whole feature is one more C walker plus a tag branch.

## Decision

- `dynjson.c`: `__kml_dynobj_inspect(obj)` → `inspect_obj`: `{ a: 1, b: 'x' }`
  with keys in ES enumeration order; `{}` when empty; keys unquoted when
  identifier-like (`key_is_ident`), single-quoted otherwise; non-enumerable
  entries skipped; accessors shown as `[Getter]`/`[Setter]`/`[Getter/Setter]`
  without invoking them; a Proxy header forwards to its target; and — Node's
  default `util.inspect` depth — anything nested deeper than two object levels
  collapses to `[Object]`.
- `inspect_val` gains tag 10 (nested dynobj → `inspect_obj`) and tag 12
  (dynamic function → `[Function (anonymous)]`).
- `emitDynamicRender` (inspect mode only) dispatches `kmlTagDynObject` to the
  new helper. `String()`/interpolation is untouched: `emitAnyToPrimitive`
  already resolves a plain object to its own `toString` or the JS-faithful
  `[object Object]` primitive before the tag dispatch.

## Implementation notes

`codegen/llvm/dynjsonsrc/dynjson.c` (walker), `codegen/llvm/emit_dynamic.go`
(tag branch), `codegen/llvm/dynjson_c.go` (declaration). Depth accounting is
shared with `inspect_arr` (an array level consumes a depth step, as in Node).

## Side effects discovered

- The existing `inspect_arr` has no Node depth-2 collapse for deeply nested
  pure arrays (renders fully) — pre-existing, left as is.
- Strings inside inspect output are single-quoted without escape handling
  (pre-existing convention from the array inspect walker).

## Verification

New `TestE2EDynObjConsoleInspect` (flat/empty/nested-collapse/quoted-key/
`String()` unchanged) — byte-exact vs Node. `Dyn|Any|Console|JSON|Inspect|
Proxy|Reflect` groups pass; `make examples` + `make conformance-node` green
(macOS arm64). Caveat deleted from `docs/status/data/type-system.json`.
