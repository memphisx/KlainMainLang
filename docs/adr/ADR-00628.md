# ADR-00628: NaN-boxed dynamic values + real `any` operators under `-compat=js`

- **Relations**: `Implements TDD-00156, TDD-00076 (A2 + A1)`, `Supersedes the ADR-00008 two-word box representation`, `Extends ADR-00627`
- **Date**: 2026-09-02

## Context

[TDD-00156](../tdd/TDD-00156.md) designed the single-word dynamic value; this
ADR ships it, plus the operator semantics it exists for ([TDD-00076](../tdd/TDD-00076.md)):
`function add(a, b) { return a + b }` — untyped, polymorphic, coercing JS —
now compiles and runs natively under `-compat=js`.

## Decision

**Representation (both modes)** — the `{i8,i64}` box became one i64
(`runtime_nanbox.go`): numbers are offset-encoded doubles (the int/float
tags merged — a JS number IS a double, so >2^53 rounds exactly as JS),
undefined/null/true/false are JSC's small immediates, heap references are
raw pointers with low-3-bit kinds (GC-safe: a low-tagged pointer is an
interior pointer Boehm's scan keeps alive; strings take kind 0 so their
data needs no alignment; interned literals were already 8-aligned with the
length header). The logical `kmlTag*` dispatch model survives —
`__kml_nb_tag/pay/pack` decode/encode it — so every consumer
(typeof/toString/equality/D1 member+method paths/union narrowing) kept its
structure; ~150 aggregate IR sites became word ops. The D1 bag/array slot
layouts deliberately kept their (tag, payload) pairs with boundary
conversion, so dynjson.c and the JSON tree walkers changed only where a
real bug surfaced: the stringify C boundary took the tag as `char`, and
arm64 expects the *caller* to extend sub-32-bit args — junk high bits that
the old aggregate extract had masked by luck. The tag is now an i64
parameter. Equality re-derives from the word (bitwise fast path; two
numbers via fcmp so NaN≠NaN and -0===0; strings by content).

**Operators (`-compat=js`; strict keeps every rejection)** —
`emit_anyops.go`: a ToNumber/ToBoolean runtime over words plus inline
dispatch (`emitAnyBinary`). The V1 matrix: number⊕number fast path
(two compares + decode/op/encode); `+` with a runtime string side →
ToString concat; null/undefined/boolean coerce numerically (`null+1===1`,
`true+1===2`, `undefined+1→NaN`); numeric strings coerce in arithmetic
(`"6"*7===42`); relational — two strings lexicographic, else numeric
(JS's own string↔number rule); heap references in arithmetic → NaN
(ToPrimitive is a later stage). Wired through: binary/unary(-,+)
dispatch, mixed *concrete* pairs (`n * "4"`, `null + 1` — routed before
the typed-subset rejection/concat mishandling), compound assignment on
identifiers and dynamic members (`this.x *= k`), and `coerce`'s
dynamic→numeric/boolean path (so `Math.sqrt(anyVal)` converts instead of
reinterpreting the word). ToBoolean truthiness (`if (x)`, `!x`) runs in
both modes — it has one correct answer.

**Implicit-`any` (A1)** — an unannotated parameter's precedence under
`-compat=js` is now: annotation → call-site-inferred concrete type
(ADR-00625, kept — superseding this TDD's "option 2 not worth building"
verdict, since it preserves native-speed typed paths when sites agree) →
**boxed `any`**. Disagreeing call sites and dynamic arguments stop being
errors: the parameter is genuinely polymorphic and now works. An untyped,
uninitialized `let` is a dynamic `undefined` (so `u + 1` is NaN, not 1).
Inference mirrors the dispatch (dynamic/mixed arithmetic → `any`;
`string +` anything → string; relational → bool).

## Consequences

- The full `make test-par` suite is green on the new representation, and
  the operator smoke program — coercion, NaN, polymorphism, truthiness,
  compound ops, prototype-method arithmetic (`Point.dist` via
  `Math.sqrt` on boxed fields) — is diff-identical to Node.
- Two latent bugs fixed by construction: the i8-across-C-ABI junk (above)
  and big-int-through-`any` exactness (now rounds like JS, which is the
  faithful behavior).
- Disclosed: ToPrimitive on objects, `==` loose-equality coercion beyond
  the strict set, unary `+` *parsing*, and whitespace-only-string
  ToNumber (`"  " * 1` → NaN here, 0 in JS) remain; strict-mode `any`
  keeps all its rejections by design.
- Follow-ons per the TDD: collapsing the D1 slot pairs to single words,
  excising the now-unreachable int-tag arms.
