# ADR-00878: Node oracle — every behavioral suite, not just test/parallel

- **Relations**: `Implements TDD-00204`, `Extends ADR-00453`
- **Date**: 2026-09-11

## Context

The Node-core track fetched and ran only `test/parallel`. Upstream's other
behavioral suites — `es-module` (175 files; an ESM compiler skipping the ESM
suite), `sequential` (121), `message` (11), `internet` (38), `pummel` (52),
`known_issues` (17) — were absent from the denominator entirely (TDD-00204
audit).

## Decision

- **fetch.sh** sparse-checks out all seven suite dirs (marker bumped to
  `<tag>+suites-v2` so existing checkouts refetch).
- **Runner** (`tools/conformance/node.go`) walks all suites; `nodeResult`
  gains a `Suite` field and the report a per-suite table. Per-suite handling:
  - `sequential`: serialized behind a mutex — upstream runs the dir one file
    at a time (fixed ports, process-global state); racing it would
    manufacture failures.
  - `es-module`: simple ESM import forms (`import x from`, `import {a}`,
    `import * as`, bare `import 'm'`, `../common/index.mjs`) are rewritten to
    the require form up front so the existing module classifier applies;
    dynamic `import()` and `import.meta` fail with counted reasons.
  - `message`: expected-output suite — pass criterion is the combined
    stdout+stderr matching the sibling `.out` baseline (line-wise, `*`
    wildcards honored), not the exit code, which is often nonzero by design.
  - `internet`: run normally (this environment has real network).
  - `pummel` / `known_issues`: fetched and counted as named SKIP buckets
    (stress-scale runs; upstream-documented expected failures) — in the
    denominator, visibly, not executed.
- `compileAndRunInDir` now returns stderr too and takes the entry
  subdirectory (the suite name) so `../common/*` shim resolution works from
  every suite dir, not just `parallel/`.

## Consequences

The denominator grows by ~400 files across six previously invisible suites.
`message`'s `.out` comparison is the strictest criterion in the track (exact
output shape); early false-negatives there are expected and diagnosable from
the report. Regenerate with `make conformance-node`.
