# ADR-01070: `-compat=js` — an absent `T | undefined` operand is NaN, and a fall-off `reduce` accumulator is `undefined`

- **Relations**: Extends ADR-01065 (fall-off callbacks return `T | undefined`), TDD-00064 (nullable scalars), TDD-00076 (js-lane operator dispatch)
- **Date**: 2026-09-22

## Context

BACKLOG §0 item 2a: under `-compat=js`, `undefined + 2` was `2` (Node `NaN`) whenever the `undefined` came from a
`T | undefined` scalar — a call result, a local, or the accumulator of
`[1,2,3].reduce((a, x) => { if (x > 1) return a + x }, 0)`, which printed `5` where Node prints `NaN`.
Strict mode rejects the expression as tsc does, so only the js lane saw it.

## Investigation

- `emitBinary` (`emit_exprs_operators.go`) collapses a nullable-scalar aggregate to its payload
  (`nullableScalarPayloadOf`) before dispatch: a `null` reads as its zero — which is *correct* JS for `null`
  (`ToNumber(null)` is 0: `null + 1 === 1`, `null * 2 === 0`) but wrong for `undefined` (`ToNumber(undefined)` is
  NaN). A `T | undefined` *local* is unwrapped even earlier, by `emitIdent`, so its absence never reached the
  operator at all.
- `emitArrayReduce` (`emit_arrays_hof.go`) typed the accumulator from the initial value and, in the js lane, let
  the callback's `{ i1, T }` result collapse into it (the strict lane rejects that call, ADR-01065). In Node the
  accumulator on the next step *is* `undefined`, so `a + x` inside the callback is NaN, and the reduce result is
  `undefined` when every step falls off.
- `emitCBCall` (`emit_func.go`) spelled a callback's parameter ABI with `p.IR`, but a closure with a
  nullable-scalar parameter takes the `{ i1, T }` aggregate (`nullableScalarParamDecl`) — invalid IR the moment a
  HOF handed such a callback a nullable value. `emitConsoleScalarValue` printed a present nullable payload with
  a raw `printf %g`, so a NaN payload came out as `nan`.

## Decision

1. `nullableScalarOperand(v, op)` replaces the collapse in `emitBinary`: strict mode and `T | null` keep the
   payload; under `-compat=js` a numeric `T | undefined` operand of `+ - * / % ** < > <= >=` becomes a double
   that is NaN when absent. Bitwise/shift operators keep the zero collapse — `ToInt32(NaN)` is 0. String
   concatenation is untouched (`"s" + undefined` renders `sundefined` as before).
2. `jsUndefinedLocalOperand`: a `T | undefined` local identifier operand is re-read from its slot as the
   aggregate (a side-effect-free lvalue reload, the same trick `emitConcatOperandString` uses) and demoted the
   same way.
3. `reduce`/`reduceRight` under `-compat=js`: when the callback's return type is `T | undefined` and the
   accumulator is a plain scalar or pointer (`reduceAccWidenable`), the accumulator is widened to
   `T | undefined`, the callback is re-resolved with that parameter hint, and the fold stores the nullable
   result as is; `inferExprType` mirrors the widening so `const r = arr.reduce(…)` declares the right type.
4. `emitCBCall` spells every parameter with `storageIR(p)` in both the closure and the named-function branch.
5. `emitConsoleScalarValue` renders every scalar through `emitValueToString` (NaN → `NaN`, Infinity, JS number
   formatting), not `printf`.

## Implementation notes

`emit_exprs_operators.go`, `emit_nullable_scalar.go` (the two helpers, `emitConsoleScalarValue`),
`emit_arrays_hof.go`, `emit_exprs_types.go` (reduce inference), `emit_undefined.go` (`reduceAccWidenable`),
`emit_func.go` (`emitCBCall`). The re-resolution of the callback emits the closure a second time under a fresh
name; the first is unreferenced dead code — acceptable for the js lane's rare fall-off shape.

## Side effects discovered

A `(T | undefined)[]` element type still has no storage of its own (`flatMap` with a fall-off callback) — the
remaining half of BACKLOG §0 item 2a.

## Verification

Windows, `-compat=js`, all equal to Node 24: `f(-1) + 2` → `NaN`, `f(3) + 2` → `5`, `f(-1) < 1` → `false`,
`f(-1) | 0` → `0`, a `number | undefined` local in `+`/`*`/`>`, `g(-1) + 2` → `2` for `number | null`, the
backlog `reduce` → `NaN`, an all-fall-off `reduce` → `undefined` (`typeof` `undefined`, `=== undefined`
true), `reduceRight`, a string accumulator → `undefined`, an annotated `(a: number | undefined, x) => (a ?? 10)
+ x` → `3`. E2E: `tests/js_undefined_arith_test.go`.
