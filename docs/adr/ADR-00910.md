# ADR-00910: str.replace() ToStrings a non-string replacement

- **Date**: 2026-09-12

## Context

Invalid-IR sweep. `String.prototype.replace` with a number replacement emitted
invalid IR:

```ts
"a77b".replace(/77/, 1)   // clang: strlen(ptr 0x3FF0000000000000)  (1.0 as a ptr)
```

From `built-ins/String/prototype/replace/S15.5.4.11_A1_T14.js`.

## Investigation

`resolveRegexReplacer` (`emit_regexp_replace.go`) coerced the replacement
argument with `coerce(templateVal, TypePtr)`. For a number that reinterprets the
double bits as a pointer, which `strlen` then dereferences. Per spec a non-
function replacement is ToString'd (`1` → "1").

## Decision

ToString the replacement (`emitArgToString`) when it is not already a string,
before coercing to `ptr`.

## Implementation notes

`emitArgToString` is the same any→string conversion `parseInt`/template literals
use; a real string passes through unchanged.

## Side effects discovered

None.

## Verification

- `"a77b".replace(/77/, 1)` → "a1b", matching Node.
- The Test262 file compiles clean.
- `make examples` 296/296 (re-run at delivery).
