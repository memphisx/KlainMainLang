# TDD-00242: Class objects carrying their evaluation's bindings

- **Status**: Implemented
- **Date**: 2026-10-02

## Context

[ADR-01334](../adr/ADR-01334.md) closure-converts a class declared in a
function that reads the function's locals. Each instance holds the
evaluation's bindings in hidden fields, which every `new` fills. That
conversion cannot express a class whose *class object* needs the bindings:

- the class used as a value (`return D`, `register(D)`, `new k()`), whose
  `new` happens where the locals are out of scope;
- a static member, static block or static field initializer that reads a
  local;
- a class expression that reads a local (`return class extends Base { … }`,
  the mixin pattern).

In each case Node gives every evaluation its own class: a distinct
constructor (`f() !== f()`), its own statics, and its own bindings. Today
these report "class 'D' names 'b', a local of its function, and …; not
supported yet".

## Design

**An evaluation record per class evaluation.** Evaluating the declaration
(or expression) allocates a record:

```
{ ptr classref   ; the class's static constructor reference
  ptr cap_0 …    ; each captured local (or its cell, ADR-01334)
  i64 static_0 … ; the class's static fields }
```

The class's static initialization runs against the record, so each
evaluation's statics start from their initializers. This replaces the
statics re-run of [ADR-01333](../adr/ADR-01333.md), which shares one storage
across evaluations.

**The class value is the record.** Inside the function, the class's name in
value position reads the local holding the record. Boxed, the record is a
constructor reference (tag 8) whose payload is the record. The payload is
told apart from a static reference by its first word, which points at the
static constant; a static reference's payload is the name's characters.
`__kml_classref_unwrap(pay)` gives the static reference for the existing
dispatchers (`__kml_dyn_construct`, `__kml_dyn_instanceof`, `.name`,
inspect), so they keep their per-class arms.

**Instances point at their record.** The ADR-01334 hidden fields become one
field, `#__kml_rec`, which every construction stores: the local record at a
direct `new D()`, the record the value carries in `__kml_dyn_construct`'s
arm. Methods read a capture as `this.#__kml_rec.cap_i`. Static methods take
the record as their receiver, so a static reads `rec.cap_i` and
`rec.static_j`.

**Identity.** `===` on two class values compares records, so classes from
two calls differ. `instanceof` compares an instance's record with the
value's record, so a class from one call does not claim instances of
another. A class without captures keeps the static reference, with no
behavior change.

**Escaping into types.** A function returning a local class has a return
type naming that class. The checker already types it as the class's
constructor type. Codegen types the value as `any` and constructs through
the dispatcher, the ADR-01318 path for any class value.

## Open questions

- A subclass declared at top level cannot extend a local class (the base is
  out of scope), but a local subclass of a local base needs the base's
  record in its own. It is likely a `base` pointer in the record, mirroring
  the prototype chain.
