# ADR-01119: One options struct for every compile mode

- **Relations**: `Implements TDD-00230` (Phase 2, P2.6); `Extends ADR-01116`
- **Date**: 2026-09-24

## Context

[TDD-00230](../tdd/TDD-00230.md) P2.6: one options struct carries every
mode to the checker, `reprOf` and `@lower`. [ADR-01116](ADR-01116.md)
seeded it as `checker.Options{CompatJS}`. Codegen held each mode in its own
emitter field, and `main.go` set each through its own setter, once for the
program and again for every lazy dynamic-import island.

## Investigation

- **`main.go`** repeated the setter list for the island emitter, and the
  copy had drifted: it never called `SetNoAny`. With `--no-any
  -dynamic-import=lazy`, an `any` in an imported module compiled and ran
  (`let x: any = 1` in the island printed `island 1`), while the same
  declaration in the entry file was rejected.
- **`--strict-modifiers` and `--stack-traces`**, named in the TDD, do not
  exist yet. The cross-compilation target is a package-level setting in
  `codegen/llvm` (`SetCrossTarget`), read by the runtime-emission sites.
- **The binder** takes one Annex B rule derived from the compat lane. The
  TDD names the checker, `reprOf` and `@lower` as the struct's readers.

## Decision

- **A leaf package `options`** holds `Options`:
  - `Compat`, `NoAny`, `Decorators`, `EmitDecoratorMetadata`;
  - `MemMode`, `DynamicImport`, `Regex`;
  - `BigInt`, `Crypto`, `Webview`;
  - `OptimizeMemory`, `Finalizers`.

  The zero value is every default. `CompatJS()` reports the js lane.
- **The CLI builds it once.** `--no-any` under `-compat=js` is dropped there,
  with the existing warning. The program's emitter and each island's
  receive the same value through `Emitter.SetOptions`. An island keeps its
  own `import()` eager, as before, by clearing `DynamicImport` on its copy.
- **The emitter** reads `e.opts` instead of twelve fields. The single-mode
  setters stay, as one-line writes into `e.opts`, for the tests that set
  one mode.
- **The checker** takes `options.Options` (`checker.NewWith`), replacing
  `checker.Options`. The shadow oracle receives the emitter's options.
- **Not in this step:**
  - the target, which moves into the struct when the runtime-emission
    sites read it from the emitter;
  - `--strict-modifiers` and `--stack-traces`, which arrive as fields with
    their flags;
  - the binder, which keeps its Annex B option.

## Implementation notes

- **New:** `options/options.go`.
- **Changed:**
  - `main.go`;
  - `codegen/llvm/emitter.go`: `SetOptions`, `Options`, the setters,
    `compatJS`, and the resolved backend names;
  - `codegen/llvm/*.go`: the field reads;
  - `codegen/llvm/shadow.go` and `shadow_binder.go`;
  - `checker/checker.go`, `checker/symbols.go`, `checker/jsmode_test.go`.
- `tests/dynamic_import_test.go`: `TestE2EDynamicImportLazyIslandNoAny`.

## Side effects discovered

- The island `--no-any` bypass above. It is fixed here by construction.

## Verification

All on macOS arm64 (M4):

- `TestE2EDynamicImportLazyIslandNoAny`: the island's `any` is rejected
  under `--no-any`, with the island's file named. Without the flag, the
  same program compiles and prints `island 1` and `42`.
- The other lazy dynamic-import tests, and the `--no-any`, decorator (both
  dialects), finalizer, `-compat=js`, `-optimize-memory`, RegExp-mode and
  crypto-backend E2E tests.
- `go vet ./...`, and `go test` over every package but `tests`.
- `make examples`: 358/358, run on the tree with ADR-01117, ADR-01118 and
  this step.
- `make test-par`: pass apart from the four `-mm=gc` macOS segfaults
  (BACKLOG §0 item 1d), identical at HEAD.
