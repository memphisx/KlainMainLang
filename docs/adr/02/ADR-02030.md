# ADR-02030: A mapped type over `any` for an array-constrained parameter

- **Date**: 2026-11-22

## Context

- `Promise.all(5)` and the other combinators over a non-iterable already
  return a rejected promise in both lanes. In the strict lane, though,
  `Promise.all(x)` with `x: any` was typed
  `Promise<{ [x: string]: any; [x: number]: any }>`. tsc types it
  `Promise<any[]>`, so assigning the result to a `Promise<unknown[]>` was a
  false rejection.
- tsc's instantiateMappedType maps `any` to an array of the template when
  the mapped type parameter's constraint is array-like
  (`T extends readonly unknown[] | []`). Here the constraint was not
  available where the mapped type was evaluated: a deferred type's
  instantiation binds the parameter by name to its argument alone.

## Decision

- `instantiateDeferred` records the constraints of the type parameters it
  binds (`deferBounds`).
- A homomorphic mapped type over `any` whose parameter's constraint has
  only array, tuple or ReadonlyArray members is an array of its template at
  a number key (`arrayConstrained`).

## Consequences

- Tests: `TestE2EPromiseCombinatorNonIterableTS`.
