# ADR-01549: AggregateError's `errors` is `any[]`; SharedArrayBuffer's constructor

- **Relations**: Extends TDD-00083, TDD-00230
- **Date**: 2026-10-10

## Context

- `new AggregateError([1, "s"])` stored the argument array's elements
  as they were (raw doubles for a number[]), and `.errors` read them back
  as error objects: `2` printed as `2.0000000000000004`, `"s"` as
  `[Object]`. Promise.any stored each rejection reason as a raw pointer,
  and the fetch runtime built its AggregateError from raw error
  pointers; util.inspect read every element as an object. `errors` is
  `any[]`.
- A typed `.errors` read (`e.errors.slice()`) had no inferred type.
- The library declared the SharedArrayBuffer interface but no
  constructor, so `new SharedArrayBuffer(n)` had no checker type.
- An AggregateError had no representation in the checker mapping: it is
  held as the shared Error layout.

## Decision

- An AggregateError's errors array holds boxed values: construction
  boxes a concrete-element argument, Promise.any boxes each reason (as
  allSettled does), and the fetch runtime boxes each error with the
  error tag. Every `.errors` read (typed, through `any`, caught) is
  `any[]`, and util.inspect decodes each element.
- `aggregateerror` maps to the Error layout.
- SharedArrayBufferConstructor is declared as tsc declares it, with the
  growable `maxByteLength` overload.
