# ADR-02035: The uncaught report shows an error's own properties

- **Date**: 2026-11-22

## Context

- Node's uncaught-exception report prints the error as util.inspect does:
  the stack, then a `{ code: 'ENOENT', … }` block of its own properties and
  `[cause]`. The report printed the stack only.

## Decision

- `__kml_print_uncaught` renders an Error through the program's inspector
  (`__kml_any_inspect_at`, the error's box `pay | 1`). It falls back to the
  stack when the inspector is absent or renders the error short of its
  stack (a program linking only part of it).

## Consequences

- The source excerpt and the version line Node adds are still not printed.
- Tests: `TestE2EUncaughtReportOwnPropertiesTS`.
