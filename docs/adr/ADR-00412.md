# ADR-00412: The Node test idiom end-to-end — wrapper typing, options-object client, post-loop flush

- **Relations**: Extends ADR-00406, [TDD-00138](../tdd/TDD-00138.md), [TDD-00122](../tdd/TDD-00122.md)
- **Date**: 2026-08-27

## Context

After ADR-00406/00408 the Node oracle's largest non-module bucket was handle
type-decay (~145 files: `a number has no method 'address'/'writeHead'/'end'/
'close'/'on'`). Sampling showed one dominant idiom behind most of it —
Node's own test shape:

```js
const server = http.createServer(common.mustCall((req, res) => { … }));
server.listen(0, common.mustCall(() => {
  http.get({ port: server.address().port, path: '/x' },
           common.mustCall((res) => { res.on('data', …) }));
}));
```

Three separate gaps broke it: the counting wrapper hid the handler arrow from
contextual typing (decaying every later `res.`/`server.` method), the http
client had no options-object form, and a `server.close()` from inside the
handler could strand the client's response reaction when the event loop wound
down before the transfer's completion was drained.

## Decision

1. **Contextual typing sees through `test` wrappers** —
   `contextTypeArrowParams(expr, names…)` + `unwrapTestWrapper`
   (emit_http.go): an inline arrow, possibly inside
   `mustCall`/`mustCallAtLeast`/`mustSucceed` (whose value carries the wrapped
   callback's own function type), gets its un-annotated simple params typed
   from the API signature — `(req, res)` for createServer, the response param
   for `http.get`. The client response uses the internal-only annotation name
   `__kml_client_response` → `IncomingMessageType()` (types.go): Node names
   both the server request and the client response `IncomingMessage`, but this
   compiler models them as distinct types and the public name is taken by the
   server side. The name is synthesized only, never written by user code.
2. **Options-object client form** — `http.get({ port, path?, host?/hostname? },
   cb)` composes `<scheme>://<host>:<port><path>` at runtime (host defaults to
   `127.0.0.1`, path to `/`); any other option key is a clean rejection rather
   than a silent ignore. The scheme threads through
   `emitHTTPClientGetScheme` so the `https` module's dispatch composes
   `https://` (fixing what would have been a silently-plaintext https options
   call under ADR-00410).
3. **Post-loop client-reaction flush** — a `@__kml_httpc_flush_hook` global
   (defined once via `ensureHTTPCFlushHook`, null by default) that each
   `http.get` site points at `@__kml_httpc_flush` (pump curl + fire until
   every registered reaction has fired). Every `@__kml_event_loop_run` call
   site is followed by a null-guarded indirect call through the hook
   (`emitPostLoopFlush`). Server-only programs keep a null hook and no curl
   dependency; client-only programs already busy-drive.

## Implementation notes

`codegen/llvm/emit_http.go` (helpers + hook calls after all three loop-run
sites), `emit_http_client.go` (options form, scheme variant, flush IR + hook),
`emit_call.go` (https dispatch → scheme variant), `types.go` (internal name).
The wrapper-unwrap matches on the post-resolver `test__kml_builtin` member
shape, so it composes with both the `import { mustCall } from 'test'` and the
oracle's `common.mustCall` → `mustCall` rewrite.

## Side effects discovered

- Two oracle files (`test-http-client-unescaped-path`,
  `test-http-request-invalid-method-error`) flipped from PASS to FAIL: they
  `assert.throws` on invalid options and previously passed **by accident** —
  the options object slipped through the old `IR == "ptr"` URL check into
  curl, whose runtime error satisfied the assertion. They now fail as honest
  compile-time rejections (the typed-compiler-rejects-dynamic-misuse class the
  gap analysis already documents).

- `server.close()` captured inside a wrapped handler closure already worked
  (the handle promotes like other module-global values) — the decay was purely
  the typing gap, not capture.
- The remaining decay tail is `function()`-expression handlers using dynamic
  `this` (`this.address()`), and net/tls variants — tracked in the gap
  analysis.

Two same-day follow-ons landed with this change, each clearing the next
surfaced bucket: the `*Sync` child_process options object now supports
`{ cwd, encoding: 'utf8' }` (child `chdir`; other keys stay clean rejections —
extends ADR-00411, ~15 files), and `str.toString()` is the identity (~20
files — Node calls it on values that are Buffers there but strings here;
new zero-caveat row in STRING-METHODS.md).

## Verification

New E2E `TestE2EHTTPCreateServerNodeTestIdiom` — the exact corpus shape,
mustCall counts verified at process exit, response delivered through the
post-loop flush — passes; full HTTP/fetch suite re-run green; Node oracle
re-run (see regenerated results). Mac.
