# ADR-01277: split on empty RegExp matches, two-digit Date years

- **Relations**: `Supersedes part of ADR-00119`, `Supersedes part of ADR-00039`
- **Date**: 2026-09-29

## Context

Both behaviours were set aside as not worth the effort. Neither is
impossible:

- ADR-00119 skipped zero-length matches in `str.split(regexp)`. So
  `'ab'.split(/(?:)/)` gave `["ab"]`, where Node gives `["a","b"]`.
- ADR-00039 left out MakeFullYear. So `new Date(99, 0)` was year 99, where
  Node gives 1999.

## Decision

- The split loop follows `RegExp.prototype[@@split]` for empty matches:
  - an empty match splits, except where it ends where the previous piece
    ended, or at the end of the string;
  - the search then advances one code point under `/u`, otherwise one
    unit;
  - the empty string splits into no pieces when the separator matches it.
- `new Date(y, m, …)` maps a year of 0–99 to 1900+year. The setters do not,
  as in the specification.
- Still open (BACKLOG): capture groups in `split`, and local time in `Date`.

## Verification

Mac (Apple Silicon): `TestE2ERegexSplitEmptyMatches` and
`TestE2EDateTwoDigitYear` print what Node v24.19.0 prints; the regex and
Date suites pass.
