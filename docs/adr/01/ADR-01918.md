# ADR-01918: a typed array's set() from an asserted view

- **Relations**: `Implements TDD-00230` (Node fidelity)
- **Date**: 2026-10-21

## Context

`data.set(v as Uint8Array)` with `v: NodeJS.ArrayBufferView` holding a DataView threw `TypeError: the value is not an array`. `as` asserts and never converts; Node reads the DataView as an array-like with no length and copies nothing.

## Decision

A `set()` source that is an `as` assertion over a value held boxed is read as that box, through the array-like path `set(x as any)` already takes.

## Consequences

- The HTTP/2 module's `goaway(…, opaqueData)` accepts a DataView as Node does.
