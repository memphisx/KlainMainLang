# ADR-00503: createServer({requireHostHeader: false})

- **Date**: 2026-08-29

## Context

Node-corpus http files call `createServer({ requireHostHeader: false },
cb)` (8 files); any non-empty options literal was rejected.

## Decision

Accept exactly `{requireHostHeader: false}` — this dispatcher never
enforced a Host header, so the flag states existing behavior instead of
silently changing any (which is why it is safe where a generic
ignore-the-options policy would not be). The literal `true` and every
other option (timeouts, h2 settings) stay clean rejections.

## Verification

Mac. `tests/http_test.go` `TestE2EHTTPCreateServerRequireHostHeaderFalse`
passes; createServer batch green.
