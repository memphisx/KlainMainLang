# ADR-01730: A primitive's constructor, method values' `this`, inferred method results

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-18

## Context

- **Calling a primitive's constructor:** comparing `n.constructor` with `Number`, or reading its `.name`, matched Node. Calling it did not: `s.constructor(42)` was rejected ("a string has no method 'constructor'").
- **A bigint's constructor:** `(5n).constructor` failed to compile ("field access on non-object").
- **Method values:** a class method read as a value (`const f = k.greet`) kept its name and identity. But `f.call(k)`, `f.apply(k, …)` and `f.bind(k)` dropped `thisArg`, so the method read `this` as undefined. `k.greet.call(k)` was rejected outright (".call requires a function value").
- **Method order:** a class method without a declared result had its result inferred while the class's members were being built. A generator `*[Symbol.iterator]()` declared before the `next(): number | null` it calls therefore yielded `unknown`, and `Array.from(new CountUp(4))` was `unknown[]`. TypeScript resolves members lazily, in any order.

## Decision

- **Bigint:** a statically typed bigint's `constructor` is the `BigInt` value, the one the identifier `BigInt` yields.
- **Calls:** `x.constructor(args)` on a number, string, boolean or bigint reads `x.constructor` and calls that function value (`primitiveCtorCallRule`).
- **Method values:**
  - `call`/`apply`/`bind` on a class method read (`k.greet`), or on a `const` initialized with one, pass `thisArg` to the method's dynamic adapter, which binds it as the receiver.
  - A bound method value takes the method's signature, less the bound arguments.
  - A function value whose `this` is never read keeps the direct typed call.
- **Method order:** the checker types a class's methods with declared results (and overloaded methods) first, then the rest. An inferred result sees every declared one, whatever the declaration order.

## Verification

macOS (Apple Silicon), against Node and tsc:

- **`tests/builtin_prototype_test.go` TestE2EPrimitiveConstructorValue:** comparison, `.name`, the value, and calls for all four primitives.
- **`tests/builtin_prototype_test.go` TestE2EMethodValueThis:** identity, `call`/`apply`/`bind` with the instance and with another object, through `const f` and directly on `k.greet`.
- **`examples/arrays/array_methods.ts`:** its `CountUp` iterator compiles again.
