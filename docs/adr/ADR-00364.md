# ADR-00364: Binary-safe string consumers — length/compare/search switch

- **Relations**: `Implements TDD-00120`
- **Date**: 2026-08-25

## Context

TDD-00120 gave every heap string a `{i64 len, [N x i8]}` header (Stage 1) and
headered every producer (Stage 2), but left the *consumers* on `strlen`/`strcmp`/
`strstr`. That kept strings correct only up to the first embedded NUL: a `req.body`
of `"ab\0cd"` stored all 5 bytes but every operation on it — length, comparison,
substring search, split — stopped at byte 2. The representation was done; the
behavioral payoff was not yet wired.

## Investigation

The first consumer-switch attempt failed ~40 tests. Rather than read them as a
reason to revert, each failure named a specific subsystem-local producer still
emitting a headerless string (a header read on which is silent garbage). The
failures were the coverage map. A separate ~30-failure cluster was a duplicate
`memcmp` declaration emitted by the new primitives, not a missing header — LLVM
rejects the redeclare at link (`ensureMemcmp()` in `emit_buffer.go` already owns
that decl).

The hand-written runtime search functions (`__kml_replace`/`__kml_replace_all`/
`__kml_split`, `runtime_strings.go`) were the non-mechanical part: their loops
track a `%cur` pointer and rely on `strstr` returning NULL at the terminator and
`strlen` for the tail — both NUL-bounded. A binary-safe rewrite needs a
remaining-length counter threaded through the phi chain and `memmem(cur, rem,
needle, needlelen)` in place of `strstr`.

## Decision

Flip the consumers and fix producers to green rather than revert:

- **Length/core** (`.length`, concat, methods) → `__kml_str_len`.
- **Compare** (`==`/`===`/`!=`/`!==`/`<`/`>`/`<=`/`>=`, `switch` on a string
  discriminant, `localeCompare`) → `__kml_str_cmp` (memcmp over the shorter
  header length, then a length tiebreak).
- **Search** (`indexOf`/`includes`) → `__kml_str_indexof` (memmem), returning the
  byte index / a `>= 0` test directly instead of `strstr` + pointer arithmetic.
- **Runtime search** (`__kml_replace`/`__kml_replace_all`/`__kml_split`) rewritten
  to carry a remaining-byte counter (`%rem`, seeded from `__kml_str_len(%s)`,
  decremented by `(match - cur) + needle_len` each step) and search with `memmem`;
  the tail copy uses `%rem` instead of `strlen(%cur)`.
- **Producers** surfaced by the failing tests, all headered: `req.method`/
  `req.path`/query values, `__kml_split_first` (both halves), `path.*`
  dirname/basename/extname, URL parts (via `__kml_str_from_cstr`), regexp capture
  substrings, WebSocket server + client payloads, the HTTP bind-error message, and
  the h2c dispatch bridge's method/path/body.

`console.log` is deliberately left on `printf` `"%s"` — see Side effects.

## Implementation notes

- `emit_strings.go` (compare/indexOf/includes/localeCompare), `emit_stmts.go`
  (switch), `runtime_strings.go` (the three runtime functions). The primitives
  themselves live in `runtime_strheader.go` (ADR from TDD-00120 Stage 2) and are
  reached via `ensureStrHeaderRuntime()`, which also owns the `memmem` decl and
  routes `memcmp` through the shared `ensureMemcmp()`.
- `memmem` with a zero-length needle returns the haystack on current glibc/macOS,
  matching the old `strstr(s, "")` behavior; the split char-mode and replaceAll
  empty-search guards already special-case that path before any `memmem` call, so
  only single `replace("", …)` relies on it — an accepted edge.
- The runtime rewrites drop their `ensureStrstr`/`ensureStrlen` calls; those decls
  are still emitted by other users, so nothing dangles.

## Producers surfaced by the test + example suites

Switching the consumers turned the suites into a coverage map for headerless
producers (a header read on a raw C string is garbage — an intermittent SIGBUS
on misaligned/unmapped `ptr-8`, or a silent truncation when the garbage length
is small). Fixed in place, no reverts:

- **`os.cpus()[].model`** (`runtime_os.go`, Linux + Darwin) — `malloc`+`sscanf`/
  `sysctlbyname`; headered via `__kml_str_from_cstr` before the field store. A
  `cpus[0].model === cpus[1].model` compare SIGBUS'd before.
- **`XMLHttpRequest.responseText`/`response`** (`emit_xhr.go`) — the raw curl
  body; copied into a header string of the exact `bodyLen` (tuple field 4).
- **child-process `stdout`/`stderr`** (`runtime_childprocess.go`,
  `__kml_cp_accum_str`) — returned the raw accumulator buffer; now a headered
  copy of its `len` field. A `.split("\n")` returned 0 lines before.
- **Error `.message`, a whole class** — messages are built raw (`strerror`/
  `curl_easy_strerror` + `sprintf` into `malloc`), then commonly used as
  `'prefix: ' + e.message`, so the concat reads `message-8`. Headered at every
  producer: `fs` throw, `process` exec/kill/signal throws (×3), child-process
  exec errmsg, RegExp compile (`pcre2_get_error_message`), `JSON.parse`, and the
  `fetch`/fetch-stream transport-failure messages (`curl_easy_strerror`). Foreign
  static strings go through `__kml_str_from_cstr`; `sprintf` buffers switch
  `malloc`→`__kml_str_alloc` + `__kml_str_finalize`. The HTTP bind message was
  already headered (TDD-00119 work).

## Side effects discovered

- **`console.log` stays NUL-truncating on display.** The print path bakes its
  trailing terminator into the `printf` format string (`"%s"`, `"%s\n"`), so a
  binary-safe `fwrite` needs the terminator threaded separately through ~8 call
  sites. Left as display-only (the stored string is intact; `process.stdout.write`
  is the binary output channel). Tracked as the sole remaining string-consumer
  caveat in TDD-00120 and [STRING-METHODS.md](../status/STRING-METHODS.md).
- **`.length` on an indexed `split()` element** (`s.split(x)[3].length`) is a
  pre-existing element-type inference gap, unrelated to this work — annotate the
  binding (`const p: string = …`) as a workaround.

## Verification

- `TestE2EStringBinarySafePrimitives` (compare/switch/indexOf/includes through an
  embedded NUL), `TestE2EStringBinarySafeSplitReplace` (split → 4 parts,
  replaceAll → length 12, both reaching a separator past the NUL),
  `TestE2EHTTPListenStringBodySurvivesEmbeddedNull` (plain string `req.body`
  round-trips an 8-byte body with two NULs), and `TestE2EFsErrorMessageConcatBinarySafe`
  (`'prefix: ' + e.message` keeps its full length; `includes` finds the path) added.
- Full `go test ./...` green on Apple Silicon (M4). `make examples` 183/183 green
  (fs and fetch-then crashes both traced to headerless `.message` producers).
- Manual repro: `"ab\0cd" === "ab\0ce"` → false, `.indexOf("cd")` → 3, `switch`
  matches the full 5-byte label; `"aXbXc\0dXe".split("X").length` → 4; an
  `"ab\0cd"` HTTP body reports length 5 and echoes 5 bytes.
