# ADR-01806: `yield` early errors in generator parameters and after a line break

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- Two programs the spec rejects compiled:
- `function* g(x = yield) {}`: a YieldExpression in a generator's formal parameters is an early error.
- `yield` + newline + `* 1`: `yield` followed by a line break is a complete yield, and `* 1` on the next line then has no left operand. `parseYield` consumed the `*` before checking for the line break.

## Decision

- The parser sets `inGenParams` while parsing a generator's parameter list. A nested function's body resets it, and it is restored on return. `parseYield` reports tsc's TS2523 ("'yield' expressions cannot be used in a parameter initializer") there.
- `parseYield` takes a `*` only when no line break precedes it. A delegating `yield *` may still take its operand on the next line.

## Consequences

- `TestYieldEarlyErrors` covers both rejections, a nested generator yielding in a parameter default, and `yield *` with the operand on the next line.
