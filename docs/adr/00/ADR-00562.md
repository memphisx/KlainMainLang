# ADR-00562: String.raw (raw template quasis)

- **Relations**: Extends TDD-00059
- **Date**: 2026-09-01

## Context

`String.raw` was unsupported — it needs the *raw* (undecoded) text of each
template quasi, but the lexer only kept the cooked form (escapes decoded), and
`TaggedTemplateExpression` carried only cooked quasis. TDD-00059 had explicitly
deferred `.raw` for that reason.

## Investigation

`String.raw`a${x}b`` is `raw0 + String(x) + raw1` — the raw quasis interleaved
with the string-coerced interpolations, escapes verbatim. The lexer's
`readTemplateSegment` (lexer.go) already walks the source char-by-char and knows
the segment's start/end rune positions, so the raw slice
(`string(l.src[start:end])`) is available at no extra cost; it just wasn't
returned. The cooked template *value* path is unaffected — only tagged
templates need raw.

## Decision

Thread raw quasis from lexer to codegen:

- `Token` gains a `Raw` field; `readTemplateSegment` returns the raw slice and
  `readTemplateHead`/`readTemplatePart` store it on the template token.
- `TaggedTemplateExpression` gains `RawQuasis` (parallel to `Quasis`);
  `parseTemplateRestRaw` collects them, and both tagged-template parse sites
  pass them through.
- codegen: `emitExpr`/`inferExprType` special-case a `String.raw` tag
  (`isStringRawTag`, guarded against a shadowing local `String`) and emit
  `emitStringRaw`, which concatenates the RAW quasis with the string-coerced
  interpolations — mirroring `emitTemplateLiteral` but using raw text. Every
  other tag desugars unchanged.

## Implementation notes

- `Token.Raw` is populated only for template tokens; it is inert everywhere
  else, so no other token consumer is affected.
- `parseTemplateRest` is kept as a thin wrapper over the new
  `parseTemplateRestRaw` for the untagged path, which discards the raw quasis.

## Side effects discovered

None. The cooked-quasi tagged-template and template-value paths are unchanged.

## Verification

`TestE2EStringRaw` (`` `a\nb` ``, `` `\t\\` ``, an interpolation, a Windows
path, and a plain quasi) is byte-for-byte identical to Node v26. The lexer,
parser, and existing template/tagged-template suites pass. Built and verified
on Mac (Apple Silicon).
