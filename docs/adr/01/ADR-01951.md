# ADR-01951: `x?.[i]` short-circuits on a boxed receiver

- **Relations**: Implements TDD-00230
- **Date**: 2026-10-28

## Context

`a?.[0]` threw "Cannot read properties of undefined" when `a` was an `any` holding undefined or null. A longer chain (`a?.[0].x`) and a member link (`a?.k`) were guarded; a single optional index on a box was not. The optional-index path guarded only pointer and array receivers, so it read through a boxed one unguarded. The same applied to every value the compiler boxes, such as an element of a record array whose layout is boxed (`rs[0].t?.[1]`).

## Decision

When the receiver of an optional index is a box, the index is guarded on its null or undefined tag. An absent receiver gives `undefined` without evaluating the index read. A present one is indexed as before.

## Consequences

- Tests: `TestE2EOptionalIndexOnBoxedValue` and `TestE2EThreeStateOptionalRecordFields`. Outputs were compared against Node on macOS (Apple Silicon).
