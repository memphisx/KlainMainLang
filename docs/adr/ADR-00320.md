# ADR-00320: `crypto.subtle.deriveBits`/`deriveKey` — PBKDF2 and HKDF

- **Relations**: Implements [TDD-00104](../tdd/TDD-00104.md) (Phase 4, completing it); extends [ADR-00316](ADR-00316.md), [ADR-00318](ADR-00318.md)
- **Date**: 2026-08-23

## Context

The last unimplemented Web Crypto row. PBKDF2 and HKDF derive raw bits
(`deriveBits`) or a ready-to-use AES/HMAC CryptoKey (`deriveKey`) from
imported base key material.

## Investigation

- OpenSSL: `PKCS5_PBKDF2_HMAC` (non-deprecated) and the `EVP_KDF` "HKDF"
  provider. CommonCrypto: `CCKeyDerivationPBKDF`; HKDF is absent from the
  public API, so the shim implements RFC 5869 over `CCHmac` (~40 lines,
  extract + counter-expand).
- Both implementations were vector-checked standalone before wiring: RFC
  6070 PBKDF2 cases (SHA-1 and the SHA-256 variant) and RFC 5869 HKDF case
  1, identical across backends.

## Decision

- `importKey("raw", material, "PBKDF2"|"HKDF", …)` produces a secret
  CryptoKey holding the raw password/IKM (algId 7/8, no hash bound — the
  hash arrives per derive call, per spec).
- `deriveBits(algorithm, baseKey, lengthBits)` → Promise<ArrayBuffer>;
  `deriveKey(algorithm, baseKey, derivedKeyType, extractable, usages)` →
  Promise<CryptoKey> for AES-GCM/AES-CBC (`length:`) and HMAC (`hash:`,
  spec-default length) targets, reusing generateKey's derived-length
  logic and the standard CryptoKey constructor. Usage bits deriveBits/
  deriveKey enforced (`InvalidAccessError`).
- Parameters: PBKDF2 `{salt, iterations, literal hash}`; HKDF
  `{salt, optional info, literal hash}` — salt/info as runtime
  BufferSources, iterations/length as runtime i64.

## Implementation notes

`cryptosrc/crypto_openssl.c` / `crypto_commoncrypto.c` (`__kml_crypto_pbkdf2`,
`__kml_crypto_hkdf`), `runtime_crypto_subtle.go` (`ensureCryptoDerive`),
`emit_call_crypto.go` (`emitSubtleDeriveBits/DeriveKey` + shared
`emitSubtleDeriveBytes`), type inference rows. The spec's
`extractable=false` requirement on PBKDF2/HKDF base keys is not enforced
(status caveat).

## Side effects discovered

None.

## Verification

Mac: `TestE2ESubtleDerive` — RFC 6070 PBKDF2 and RFC 5869 HKDF known
answers plus a deriveKey→AES-GCM encrypt/decrypt roundtrip, matrix-run on
**both** backends with identical output; standalone C vector drivers; the
crypto example's new derive section. Full `go test ./...`,
`make examples`, and `make conformance` run at delivery end.
