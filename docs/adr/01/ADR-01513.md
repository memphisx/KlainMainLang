# ADR-01513: A js-lane object-literal binding read before its declaration is `any`

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-09

## Context

In the js lane an unannotated object-literal binding is a dynamic object
held in an `any` (emitVarDecl, decideGlobalType). A read inferred before
the declaration is emitted (a module-global pre-pass inferring
`var ref = obj.method`) fell through every identifier rule to the integer
default, because the checker fallback does not map object types. Output
was right; the inferred type was a plain signed integer (shadow bucket 5,
303 rows).

## Decision

That read is `any`: in the identifier inference fallback, and in
`resolveValueType`.

## Divergences

None.

## Files

codegen/llvm/emit_exprs_types.go, codegen/llvm/emitter.go

## Verification

- Mac (Apple Silicon): a probe of an object literal with an async
  generator method read through `var ref = obj.method` prints the same
  as Node; its shadow rows are gone.
