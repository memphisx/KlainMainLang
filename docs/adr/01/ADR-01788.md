# ADR-01788: A function expression's own name is an immutable binding to itself

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- `function B() { B = 1; return B; }` as an expression failed to compile with a type error. In JS the name binding inside is immutable: sloppy code ignores the assignment, strict code throws TypeError.
- A top-level `let ref = function* B() {}` is rewritten to a declaration named `ref`. The rewrite renamed `B` in the body only, not in parameter defaults, and `B = 1` became an assignment to a function declaration ("undefined variable").
- A named generator expression nested in a function had no binding for its own name at all.
- Inside a capturing nested generator, each read of its name built a new closure, so `g().next().value === g` was false. A non-capturing one read itself as a number while its signature was built, an internal compiler error.

## Decision

- `Symbol.SelfName` marks a function expression's self-capture. `emitAssign` sends an assignment to it, or to an assignment node recorded by `renameGeneratorSelfName`, to `emitSelfNameAssign`. That evaluates the right side, leaves the binding unchanged, and throws "Assignment to constant variable." in strict files.
- `renameGeneratorSelfName` renames the self name in the body and parameter defaults, after recording assignments to it. It serves both the top-level rewrite and nested generator expressions, whose declaration name is now stable per expression (`genExprNames`).
- A generator whose body reads its own name as a value gets one function object per run of the enclosing code (`emitSelfReferencingGenerator`): a cell under its name, captured by the body and filled with the constructor closure.
- `inferGeneratorElemType` binds the generator's own name as `any` while it is not yet registered.

## Consequences

- Strictness is per file. A function-level `"use strict"` directive does not make the assignment throw.
- `TestE2EJSFileFunctionSelfName` and `TestE2EJSFileFunctionSelfNameStrict` compare plain, generator, nested, capturing and array-held cases against Node.
