# ADR-01771: yield* over any iterable, spread in any-typed array literals, and a nested function's own arguments

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

Test262's yield* tests delegate to plain objects with `[Symbol.iterator]` or `[Symbol.asyncIterator]` (often through getters) and log every protocol step. Three gaps blocked them:

- `yield*` accepted only a generator, a builtin collection in a sync generator, or a class with `[Symbol.asyncIterator]` in an async generator. Anything else was a compile error.
- A spread inside an array literal in an `any` context (`args: [...arguments]` in an object literal) was "spread in a dynamic (any-typed) array literal is not supported yet".
- A function expression reading `arguments`, nested inside another function, read the enclosing function's `arguments`. The free-variable scan treated `arguments` as a capture across a non-arrow function boundary. So a function returned from an object-literal method or getter always reported the outer call's arguments.

## Decision

- `emitYieldStarAny` follows the spec's yield* on boxed values:
  - GetIterator: in an async generator `@@asyncIterator`, falling back to `@@iterator` with each value awaited.
  - `next` is read once.
  - Each resumption of the outer generator is forwarded to the iterator's `next`, `throw` or `return` through `.call(it, received)`. An async generator awaits each result, and each result must be an object.
  - A done next or throw result is the expression's value. A done return result returns from the outer generator.
  - Without `throw`, the iterator is closed and a TypeError thrown. Without `return`, the return goes through.
- A `yield*` over such an operand makes the generator's element type and the expression's type `any` (`yieldStarIsDynamic`).
- `pushSpreadIntoDynArr` collects the spread operand as `[...src]` and pushes each element boxed.
- `scanExprFV` and `capScanExpr` bind `arguments` inside a function expression or nested function declaration (not an arrow).

## Consequences

- `TestE2EJSFileYieldStarProtocol` and `TestE2EJSFileSpreadInAnyArrayAndOwnArguments` cover them.
- In a sync generator, yield* yields each inner result's value through the outer generator's own `{value, done}` object. The spec passes the inner result object through unchanged, so a getter on the inner result's `value` runs at a different time.
