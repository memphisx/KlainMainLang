# ADR-01082: A present `T | undefined` pointer boxes into `any` as itself

- **Relations**: `Extends ADR-00958, ADR-01059`
- **Date**: 2026-09-23

## Context

`let s: string | undefined = 'q'; const w: any = s; console.log(w)` printed `undefined`. Node prints `q`. The same happened with:
- an in-range array read boxed into `any` (`const v: any = a[0]`);
- a present optional object (`let p: P | undefined = new P()`);
- a ternary whose union result boxes a `string | undefined` branch.

Found while making a `spawnSync` stream usable in a ternary (ADR-01081).

## Investigation

`emitBoxValue` (`codegen/llvm/emit_dynamic.go`) switched on `case v.Ty.IsUndefined:` first. That arm was meant for the literal `undefined` type, but every `T | undefined` pointer also carries `IsUndefined` (TDD-00187). So every such value boxed as the `undefined` sentinel, present or not. The pointer and object arms below it already handled a null pointer as `nbNull`, but never saw these values. They also used `nbNull` for the absent case even when the flavour was `undefined`.

## Decision

- The literal arm matches only `IsUndefined && !Nullable`.
- The string-pointer and object arms box a null pointer as that flavour's sentinel: `nbUndefined` for `T | undefined`, `nbNull` for `T | null`. A present pointer boxes as itself, exactly as before.

## Implementation notes

`codegen/llvm/emit_dynamic.go` only. Nullable scalars (`{ i1, T }`) and arrays have their own earlier arms and are unchanged.

## Side effects discovered

None beyond ADR-01081's.

## Verification

- Windows x64: a hand probe is identical to Node 24, covering a present/absent `string | undefined`, `string | null`, array reads in and out of range, a ternary union, `a[i].toString()`, and a present/absent optional class instance.
- Tests added in `tests/dynamic_test.go`:
  - `TestE2EAnyBoxNullablePointer`, a fixed expectation;
  - `TestE2EAnyBoxNullablePointerSameAsNode`.
- Linux x86-64 (Docker): the full suite passes.
