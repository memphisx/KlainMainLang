# ADR-02021: A Map's or Set's `void` type argument

- **Date**: 2026-11-21

## Context

`new Map<string, void>()` set with a `v(): void` call read back `0` from
`get`: the value type was `void`, which holds nothing, so the slot's raw
word showed. Arrays and object literals of void values already held
undefined.

## Decision

A Map's key or value type, or a Set's element type, that is `void` is
held as `any`, whose one value there is undefined (`voidHeld`, in
`MapType` and `SetType`).
