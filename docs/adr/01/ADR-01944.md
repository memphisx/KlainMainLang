# ADR-01944: JSON.stringify's walk path grows with the walk

- **Relations**: Implements TDD-00230
- **Date**: 2026-10-28

## Context

`JSON.stringify` on a value 512 or more levels deep threw `TypeError: Converting circular structure to JSON`, though the value has no cycle. Found while churning a 1,000-node linked list under `-mm=gc` (ADR-01943). Every memory mode failed the same way, and so did the compiler from before this session.

## Investigation

- The dynamic walker (`dynjson.c`) kept its path in fixed arrays of `KML_DYN_MAX_DEPTH` (512) entries:
  - `parents`, on the C stack of `__kml_dynjson_stringify_at`;
  - the key, index and kind of each level, in thread-local arrays.
- Past 512 levels, `kj_enter` reported a cycle with no message.
- Node walks until the stack runs out, then throws `RangeError: Maximum call stack size exceeded`. The stack guard already gives the same `RangeError` here, at 20,000 levels.
- A `toJSON` may itself call `JSON.stringify`. The key, index and kind arrays were already shared between the two walks, so an inner walk overwrote the outer one's path, which only the cycle message reads.

## Decision

- The path is one thread-local growable record (`kjp`: object, kind, key, index), always indexed through `kjp`, so growing it never leaves a stale pointer. The `parents` parameter is gone.
- A walk takes the slots past those of the walk it runs within (`kj_base`, `kj_used`) and restores both on return.
- A walk entered from no deeper in the stack than the last recorded walk's frame finds that walk gone, because a throwing `toJSON` skipped its restore. It then starts the path at 0.

## Consequences

- A deep chain is no longer a cycle. A real cycle still names its path, and only the stack limits the depth, as in Node.
- The other dynamic walkers (`join`, inspect of boxed static arrays) keep their 512 limit.

## Verification

`TestE2EJSONStringifyDeepNesting` matches Node: a 3,000-deep chain, a cycle's message, a `toJSON` that calls `JSON.stringify`, a throwing `toJSON` followed by more walks, and a self-cycle. A 20,000-deep chain gives Node's `RangeError` (Mac).
