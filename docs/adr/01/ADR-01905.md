# ADR-01905: `typeof C` before C is registered; a parameter's tuple storage in the oracle

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

- `typeof C` of a class is its boxed constructor reference. resolveType recognized the class only once it was registered, so an interface naming a class declared after it (http2's `ServerOptions.Http2ServerRequest?: typeof Http2ServerRequest`) held the field as the numeric default.
- The oracle's rule for a parameter whose declared type involves a tuple read the type the read narrows it to, not the parameter's storage: inside `Array.isArray(headers)` it answered `[string, string][]` for a parameter stored as its union's box (`addTrailers`).

## Decision

- resolveType recognizes the class through the program's scope when it is not registered yet.
- The oracle's parameter rule maps the parameter's storage type.

## Consequences

- The constructor field holds the reference it is given; the http2 module's rows for both go away.
