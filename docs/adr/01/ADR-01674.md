# ADR-01674: The function builder is one swappable object

- **Relations**: Implements TDD-00230
- **Date**: 2026-10-17

## Context

P3.5 splits the Emitter by lifetime: per-function state apart from per-module state. The function being emitted owned five Emitter fields: the entry-block allocas, the body, the register and label counters, and whether the current block has its terminator. Each place that emits a function while another is under way saved these by hand, reset them, and restored them at the end: about fifteen sites. Some reset only four of the five. Some left the label counter running from the enclosing function, or did not restore the enclosing block's terminator state. Copying a `strings.Builder` by value also only worked because the copy was never written.

## Decision

- **One object.** The five fields become `funcBuilder` (funcstate.go). The Emitter embeds `*funcBuilder`, so `e.allocas`, `e.regCtr` and the rest read as before.
- **One swap.** `beginThunkEmit` installs a fresh builder and returns the function that puts the enclosing one back. Every save/reset/restore site goes through it: classes, functions, generators, workers, the HTTP dispatcher, collections, fetch's body runners and the import() settle functions. `beginDetachedFunc` drops its own counter save, which the swap makes redundant.
- **One numbering rule.** A nested function now always numbers its registers and labels from zero. The fetch body runners and import() settle functions had kept the enclosing label counter. Their IR differs from before in label numbers only.

- **Language context too.** The 24 function-context fields go into `funcContext`, also embedded: scopes, return and promise types, async, generator and constructor state, and the loop, label, cleanup and finally stacks. `beginDetachedFunc` is now two swaps: a fresh builder, and a fresh context whose return type is `any`. The 23 saves it did field by field are gone.

- **Declared functions swap too.** The function, closure, arrow, generator, class-member and static-initializer emitters each install a fresh context, restored by one defer. Each copies the few fields it inherits on purpose. The function emitters copy the enclosing scopes, which their pre-passes read before the body resets them, and the return type. All of them copy the module-task and HTTP-handler flags, and class members copy the constructor class their caller set. About 150 lines of per-field saves, resets and restores are gone. The defer now also restores the async fields on an error return, which used to leak into the enclosing function.

- **Checker behind an interface.** Codegen reaches the checker only through `frontView` (frontview.go), the 28 query methods it calls. `front()` and every helper that took a `*checker.Checker` now take the interface, so emission code cannot call into checker state beyond those queries. A compile-time assertion keeps `*checker.Checker` implementing it. `front()` returns a plain nil when the checker failed to build, never a typed nil, which would be a non-nil interface.

- **One emission point.** A finished function goes out through `writeFunc(header, body)` (funcstate.go): the `define` line, the entry block, the allocas, then the body. 52 sites wrote that text themselves, each its own copy of the prologue and epilogue; they all go through it now. 23 `define` texts are left: the coroutine definitions (`writeAsyncDefinition`), the hook routines and the class-reference rows whose bodies are hand-written dispatch text, which TDD-00240 moves to C. The IR-text allowances drop with it (`emit_classref_rows.go` 18→12, among 26 files).

## Side effects discovered

None.

## Verification

- Emitted IR is byte-identical over 162 files: the IR list and the examples for functions, generators, classes, workers, HTTP, collections, streams, Buffer and Promise combinators. The exception is 16 files whose fetch-runner labels are renumbered, and those are identical once label numbers are normalized.
- Fetch, dynamic-import, worker, generator, class, closure, adapter, async and promise tests pass on Mac.
