# ADR-01559: A module-level `var` nested in a block is a module binding

- **Relations**: Extends ADR-01057
- **Date**: 2026-10-10

## Context

A `var` declared inside a top-level block (`if`, a loop body, a
`do … while`) is scoped to the module, exactly like one declared at its top
level. A function reading it failed to compile:

```ts
if (Math.random() > 2) { var x = 1; }
function f() { return x; }   // error: undefined variable 'x'
```

Node prints `undefined` for `f()`. Top-level reads worked: the main body
held the binding as a local of the module's entry function, and only
top-level-statement `var`s were registered as module globals.

## Investigation

`registerModuleGlobals` (codegen/llvm/emit_exprs_vardecl.go) promotes a
top-level declaration to a module global when a function reads it, walking
only the module's own statements. A nested `var` never reached it, so the
function body's lookup of the name found nothing.

## Decision

`registerModuleGlobals` also walks each top-level statement
(`nestedVarDecls`, stopping at function and class boundaries) for `var`
declarations a function reads. Each becomes a module global
stored as its skippable form (`indexReadType`, ADR-01057), since a path can
reach the read without the declaration running. Every declaration of the
name is marked in `promotedGlobalDecls`, so each stores to the global.
A top-level `for` statement's own initializer declarations are not walked:
each iteration's binding stays a loop local, as a closure capturing it
expects (`TestE2ENestedFunctionCapturingForLoopVar`).

## Implementation notes

codegen/llvm/emit_exprs_vardecl.go. The global keeps `UncheckedIndex`, so
the representation agrees with the checker-side mapping's
`hoistSkippable` answer.

## Side effects discovered

None.

## Verification

- Mac (Apple Silicon): `TestE2ENestedTopLevelVarReadFromFunction`,
  `TestE2EConditionalTypedVarReadsUndefined`,
  `TestE2EHoistedVarLoopAndSwitchShapes`; each prints what Node prints.
- `examples/basics/var_hoisting.ts` gains the module-level case; output
  matches Node.
