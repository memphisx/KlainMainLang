# ADR-01274: A generic call takes a type parameter's default

- **Relations**: `Extends TDD-00010`
- **Date**: 2026-09-29

## Context

A generic call with nothing at the call site to infer a type parameter
from was rejected. An example is `setImmediate<T = void>(value?: T)`
called as `setImmediate()`. tsc uses the parameter's default.

## Decision

`inferGenericCallConcreteTypes` substitutes the declared default when no
argument infers a type parameter. Without a default, the call is still
rejected.

## Verification

Mac (Apple Silicon): `TestE2EGenericDefaultVoidAndTypeof`; the
`timers/promises` tests (`sleep(20)`, `scheduler.yield()`).
