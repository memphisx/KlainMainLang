# ADR-01775: Generator and async methods run on a foreign receiver

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- A class method called on a receiver that is not an instance runs its body on that receiver as an `any` (`emitForeignReceiverCall`). An example is `C.prototype.m()` or `C.prototype.m.call(o)`.
- Generator and async methods were excluded. A `this`-reading one threw "called on incompatible receiver" where Node runs it.

## Decision

- `emitForeignReceiverCall` also compiles generator and async methods, as a function expression of the same kind taking `this: any`.
- A generator function's value is dynamic, so it is called through the dynamic call ABI.

## Consequences

- `TestE2EJSFileGeneratorMethodsOnForeignReceiver` covers `C.prototype.method()` for async generator, generator and async methods, and `.call` with a plain object.
