# ADR-01936: The program declares what it calls from its call sites

- **Relations**: Implements TDD-00230, Extends ADR-01935
- **Date**: 2026-10-28

## Context

Before a runtime entry point could be called, an `ensure*` declarator had to run to emit its `declare` line. There were 301 `ensure*` methods. Once ADR-01935 linked runtime files by the symbols a program names, most declarators did nothing except declare: a forgotten call was an invalid-IR error, and a redundant one cost nothing.

## Decision

- **`declareCalled` (`declare_calls.go`) runs on the final IR.**
  - For each function the IR calls but neither defines nor declares, it appends a `declare` built from the first call site. An LLVM call spells the return type and argument types, and the pass keeps the return and parameter attributes (`zeroext`, `signext`, `noundef`, `inreg`, `noalias`). A variadic call already names its function type.
  - A function the IR only takes the address of is declared `void ()`. With opaque pointers that type is never read.
- **It runs after `renameHooks`,** so a hook the program defines is declared under its final name, never twice.
- **`runtimeGlobals` is the runtime's one header for globals.** A use of a global does not show whether it is thread-local, so 35 runtime globals have their lines in a table. The pass emits a line when the IR names that global without defining it; the program's own internal globals are defined the same way.
- **The plain `__kml_` declare lines are removed from the Go sources** (about 190). A declare with function attributes after its parameter list stays.
- **192 declarators are deleted**, along with about 850 call sites.
  - A declarator stays when its flag or `fnDecls` key is read by something other than a declarator being deleted, when it emits a global or a definition, or when its work depends on the target or options.
  - A deleted declarator that called a kept one leaves that call in its place.
  - In the `@lower` and intrinsic tables, an entry whose declarator is gone becomes `linkedBySymbol`, which does nothing, or a closure that runs the kept declarators it used to call.
- `UsesProcessRuntime` and its list of `fnDecls` keys had no callers left and are deleted.
- **`ensureRuntimeDeps` keeps only gated files' dependencies.** The entries whose two ends are both in the pool are gone, since the resolver follows those references.
- 109 `ensure*` methods remain. They emit globals or definitions, depend on the target, or set a flag that gates a library unit or a finalize step.

## Verification

- To check the pass, every `declare` the emitter wrote (except `llvm.*` intrinsics) was stripped before it ran, under a temporary switch since removed. All 172 saved probes built, and their output matched Node v24 except for the known differences listed in ADR-01935.
- The same probes, after the deletions, match Node v24.
- Unit packages pass on the Mac (Apple Silicon).
