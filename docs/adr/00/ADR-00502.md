# ADR-00502: http.Server 'listening' event

- **Date**: 2026-08-29

## Context

`server.on('listening', cb)` is the corpus's most-registered http.Server
event (31 files); only `'request'`/`'stream'` were accepted.

## Decision

The server handle grows 8→16 bytes: slot 1 stashes a pending
`'listening'` closure. `.listen()` fires-and-clears it right after
binding (so `server.address()` already works inside it), and a
registration on an already-listening server fires immediately — the
same semantics net.Server's `'listening'` already has. Other events
(`'clientError'`, `'connection'`, `'upgrade'`, …) stay rejections.

## Verification

Mac. `tests/http_test.go` `TestE2EHTTPServerListeningEvent` passes;
HTTP server/listen batch green; `examples/http/create_server_handle.ts`
extended and re-run.
