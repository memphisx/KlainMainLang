# ADR-01401: The codegen TLS server path deleted

- **Relations**: Implements TDD-00244; Extends ADR-01400
- **Date**: 2026-10-05

## Context

Mapping the HTTP server's IR for the move to C ([ADR-01400](ADR-01400.md))
showed that its TLS branches no longer run. `https.createServer` and
`http2.createSecureServer` are TypeScript over the pool's handle table
(`lib/node/internal_https.ts`, [ADR-01396](ADR-01396.md)), but codegen kept
the paths that preceded them:

- **The h2-over-TLS accept** (`usedH2TLSServer`): a blocking handshake and
  an nghttp2 session driven inline in the accept, which blocks the whole
  reactor for that client's lifetime. Nothing sets the flag.
- **The HTTPS/1.1 accept** (`usedHTTPS1Server`): a pre-scan for
  `https.createServer(...)` set the flag. Every connection fiber's read and
  write then went through an fd→SSL lookup. Nothing ever stored a TLS
  context into `@__kml_http_tls_ctx`, so the accept never took the TLS
  branch and the lookup always missed.
- **`tlssrc/tls.c`** (a blocking client connect, server context and accept,
  non-blocking SSL shims) and the net socket's SSL branches. They were
  reached only through the two paths above.

## Decision

- The flags, the pre-scan and the accept heads are deleted, along with the
  connection shims (`__kml_http_conn_recv/send/send_nb/close/ssl_get/
  ssl_set`) and every call site's TLS variant. A connection fiber reads and
  writes its socket directly.
- `tls.c`, `emit_tls.go`, `emitTLSNetSymbols` and its stubs, and
  `netsock.c`'s SSL branches are deleted. The `tls` module's native side is
  `tlshandle.c` alone.
- The IR-text ratchet drops: `runtime_http.go` from 23 to 17, and
  `tls.go` from 5 to none.

## Verification

- Mac (M4): with only the pre-scan removed, the HTTPS, TLS, HTTP/2 and
  secure-server tests pass. After the deletion: the HTTP, HTTPS, TLS,
  upgrade, WebSocket, clientError, connection and net tests, and the
  codegen unit tests.
- Linux (x86-64, Ubuntu 24.04 container), with [ADR-01400](ADR-01400.md):
  the full test suite (3,922 tests), the 393 examples, and Test262 in both
  lanes (strict 8,498, js 10,506, unchanged, no invalid IR).
