# ADR-01268: `arr.length = n`

- **Relations**: `Extends ADR-00939`
- **Date**: 2026-09-29

## Context

Assigning an array's `length` was "field assignment on non-object", so
the common `arr.length = 0` did not compile.

## Decision

A length write on a mutable array location truncates, or grows through
the shared header so every alias sees it:
- new slots read as undefined in a boxed-element array;
- in a typed-element array they hold their kind's zero value.

A negative, fractional or ≥ 2^32 length throws `RangeError: Invalid
array length`; the range check runs before the conversion to an integer.

## Verification

Mac (Apple Silicon): truncation, growth, aliasing and the RangeError
match Node.
