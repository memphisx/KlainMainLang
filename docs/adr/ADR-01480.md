# ADR-01480: A defaulted parameter is an optional one, filled by the body

- **Relations**: Extends ADR-01479
- **Date**: 2026-10-09

## Context

Second pass over the P3.3 shadow comparison (TDD-00230): 8,969
`inferExprType` disagreements over the examples after ADR-01479, from
10,349.

## Investigation

- Bucket "ArrowFunction FuncParams" (364): a parameter with a default is
  `T | undefined` in the checker's function type, `T` in codegen's, whose
  caller evaluates the default (`FuncParamDefaults`) or passes a presence
  mask (`FuncHasDefaultMask`). A caller that holds the function through a
  function type with no defaults does neither: `const g: (a: string, b?:
  string) => string = (a, b = "dflt") => a + b; g("p")` printed `pnull`,
  and `const hh: (n?: number) => number = h` (with `function h(n = 5)`)
  returned 0 for `hh()`; Node gives `pdflt` and 5.
- Through the box, a default whose parameter the target type makes
  optional (`(x?: number) => number` holding `(x = 3) => …`) was built as
  the `{i1, double}` it is passed as but stored as a `double` (invalid IR;
  the staged tree printed NaN for `cbs[0]()`).
- A callback taking more parameters than an Array method passes
  (`forEach((v, i, a, extra = 7) => …)`) had its defaulted extra
  parameter padded with zero; Node binds undefined and so the default.
- An annotated parameter of a nested function read as `any`: the
  empty-array element pre-pass (`inferEmptyArrayElemTypes`) bound every
  nested parameter as `any`, so a `[]` filled from it took `any` elements,
  and the shadow comparison recorded `(error: Error | null) => …`'s
  parameter as dynamic (buckets of "Identifier … IsDynamic,IsError").
- `err && ok` with `err: Error | null | undefined` holding null printed
  `[Object]` (Node: `null`): the short-circuit's boxing split a nullable
  pointer into "null pointer is undefined, else the value", which boxed a
  three-state value's null marker cell as an object.
- `n > 1 ? s : n` (a string and a number) and `n > 1 ? [n] : n` were
  compile errors ("a union-typed ternary is not supported"), and `[s, n]`
  with `s: string | null | undefined` was one too: the literal's kind
  count skipped the three-state element as if it were an `undefined`
  literal; `k ?? 0` (a class instance or a number) was "type mismatch in
  ?? operands". TypeScript accepts all four as unions.
- `err as StreamError` (an Error to a class extending Error): codegen keeps
  the error object's layout, the oracle answered the class; an assertion
  between two static object types does not convert.

## Decision

- A plain parameter with a default (`bodyDefaulted`: not rest, not
  destructured) is passed as an optional one: its slot is `T | undefined`
  (`optionalParamType`) in every signature (functions, methods,
  constructors, generic instantiations, closures' function types), and no
  caller evaluates its default (`callSiteDefault`; the closure's
  `FuncParamDefaults` and presence mask keep only destructured
  parameters'). The function itself, after binding its parameters, declares
  over each one `let p = arg ?? default` (`emitParamDefaultPrologue`;
  `arg === undefined ? default : arg` when T itself admits null), with the
  earlier parameters in scope: an absent or undefined argument takes the
  default whoever calls, as in JavaScript. This is the representation the
  checker's function type already has, so a function value keeps its
  defaults through any function type it is stored as.
- `Function.prototype.length` stops at the first defaulted parameter
  (`FuncSig.HasDefault`), and a parameter is in its dead zone while an
  earlier (or its own) default is evaluated: the prologue binds those names
  as dead (`Symbol.TDZ`, `laterParamRefs`) and reading one throws
  ReferenceError, as `(x = y, y) => …` does in JavaScript.
- A present argument of another kind into an optional scalar slot (a
  string where a defaulted number parameter is, in a `.js` file's strict
  lane, which the checker does not check) is the typed-subset rejection a
  plain parameter makes (`emitNullableScalarBoxedValue`,
  `coerceChecked`), not invalid IR (Test262's
  `dflt-params-arg-val-not-undefined`); the js lane converts it.
- An unannotated parameter whose default is not a literal (`s = "x" + n`)
  takes the checker's primitive type of the default (`paramDefaultType`),
  as TypeScript types it; it was the number default.
- `emitCBCall` converts an argument for an optional slot to its payload
  type before wrapping it (an `i64` index into `number | undefined`), and
  fills a parameter the method does not pass from a destructured
  parameter's call-site default (`spillValue`).
- A function value whose type still fills defaults through the call (a
  destructured parameter's) converted to a function type without them goes
  through its box (`funcAdapterPlan`, `hasParamDefaults`); the boxed
  call's default slot takes the parameter's storage form.
- A three-state operand of `&&`/`||` with a boxed result is boxed as a
  whole (its null, undefined or value); a ternary whose branches have no
  common slot (`ternaryMixed`: an array and a non-array, a reference and a
  scalar) is the boxed union, in emission and inference, and so is a
  `??` of a reference and a scalar (`nullCoalesceMixed`); an array
  literal's kind count skips only null and undefined literals.
- The pre-pass binds an annotated parameter with its declared type
  (`optionalParamType`); an unannotated one stays `any`.
- The oracle keeps an object operand's representation across an
  assertion to another static object type.
