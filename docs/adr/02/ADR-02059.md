# ADR-02059: A subject with a lone surrogate is matched around it

- **Date**: 2026-11-22

## Context

- Strings hold a lone surrogate as WTF-8 (`ED A0 BD` for U+D83D), which is
  not valid UTF-8. The UTF-mode dialects compile with `PCRE2_UTF`, so
  PCRE2 rejected such a subject: every match on it failed, and
  `"a\uD83Db".replace(/b/, "X")` returned the string unchanged.

## Decision

- The UTF dialects (es-unicode, es-utf16, ecmascript) also compile with
  `PCRE2_MATCH_INVALID_UTF` (PCRE2 10.34+). Matching then runs around an
  invalid sequence, which no pattern item matches.

## Consequences

- `TestE2ERegExpSubjectWithLoneSurrogate` matches Node: replace, split,
  exec, match and an anchor on such a subject.
- Left: `.` and classes never match the surrogate itself, and an escaped
  lone surrogate in a pattern is a `SyntaxError`. Both need the surrogate
  as a code point PCRE2 can match.
- A platform whose PCRE2 is older than 10.34 rejects the option.
- Verified on Node304 (Linux x86-64, PCRE2 10.42).
