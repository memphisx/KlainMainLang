# ADR-01337: Host-object methods through declarations, and the checker's type operators

- **Relations**: Implements TDD-00230 (P2.3, P3.2), Extends ADR-01331, ADR-01315
- **Date**: 2026-10-02

## Context

[TDD-00230](../tdd/TDD-00230.md) P3.2 moves builtin calls from by-name
blocks in `emitCall` to their declarations. After [ADR-01331](ADR-01331.md)
the open blocks were: the timer handle's methods, the TypedArray/Buffer/
DataView methods, XMLHttpRequest, the Response/Request body readers, the
`Promise` statics, and `hasOwnProperty`/`toString` on objects.

The `Promise` statics could not move: TypeScript declares them with mapped
and conditional types (`Promise.all<T extends readonly unknown[] | []>(values:
T): Promise<{ -readonly [P in keyof T]: Awaited<T[P]> }>`), and the checker
modelled no type operator. It typed `keyof`, `T[K]`, mapped and conditional
types as unanswered, so `Record`, `Partial`, `Pick`, `Omit`, `Exclude`,
`ReturnType` and `Awaited` were undeclared and every value of those types
went unchecked.

## Investigation

- Moving the body readers found `new Response("hi")` typed `any` by the
  checker: `BodyInit` names `FormData`, which was not declared, so the
  constructor's parameter, and the whole `Response` constructor type,
  were unanswered. The by-name block had hidden this.
- Moving the timer handles: Node's `refresh()` re-arms a one-shot that
  already fired and leaves a cleared one cleared (Node 24 probe). The
  timer queue kept no delay for a one-shot (`interval` is 0 for it, -1 once
  fired or cleared), so it could not restart one.
- `const q = m.clear()` at top level emitted `internal global void 0`
  (invalid IR): a module global took a void call's type. The DataView
  setters' move exposed it.
- `h.link` on a `Record<string, string>` or `{ [k: string]: string }`
  emitted invalid IR (a `ptr` stored as `i64`) at HEAD: inference read the
  dictionary's dot-read as the default `i64`, while emission returned the
  map get's pointer.
- `({ a: 1 }).toString()` was a compile error at HEAD; Node prints
  `[object Object]`. The checker did not reach Object.prototype's members
  through an object type's member access, so `o.hasOwnProperty` and
  `o.toString` had no declaration.
- `TestE2EDnsPromisesLookup` expected `127.0.0.1`; Node on macOS answers
  `::1` (the resolver's order), as this compiler does.

## Decision

1. **Type operators in the checker** (`checker/typeops.go`):
   - `keyof T`: the property names as string literals, `string | number`
     for a string index, `number` for a number index; over a union, the
     keys every member has.
   - `T[K]`: per member of K, a property's type, a tuple element, an array
     element, or an index signature's value.
   - Mapped types: over `keyof T` homomorphic (an array maps its element, a
     tuple each element, an object each property keeping its `?` and
     `readonly` unless `+`/`-` changes them); over a key union, one
     property per literal and an index signature for `string`/`number`.
     The parser now records the modifiers' signs (`ast.MappedType.
     ReadonlyMod`, `OptionalMod`).
   - Conditional types: `infer` placeholders inferred by unifying the
     extends type with the checked type; a naked type parameter
     distributes over a union; `any` takes both branches.
   - An operand that reads a type parameter makes a **deferred** type (a
     new `Deferred` flag) holding its node, scope and the bindings in
     scope. `instantiate` evaluates it with the parameters bound. Relating
     a deferred type is "maybe", as for any type the checker leaves open.
   - Intersections with `object` or `{}` reduce (`object & {…}` is the
     object member; `T & {}` is T without null and undefined).
   - Function signatures with a rest parameter relate position by position
     (they were all "maybe").
   - A generic source signature infers with its own type parameters
     unknown (TypeScript's erased signature).
   - An array literal passed where a type parameter is constrained by a
     tuple type infers a tuple (`Promise.all([a, b])` is `[A, B]`).
   - A conditional the relation leaves open takes the true branch when
     every `infer` matched, and the false branch when the checked type
     lacks a property the extends type requires or is an object against a
     primitive.
2. **lib.es5's utility types** are declared with TypeScript's own
   definitions (`Partial`, `Required`, `Readonly`, `Pick`, `Record`,
   `Exclude`, `Extract`, `Omit`, `NonNullable`, `Parameters`,
   `ConstructorParameters`, `ReturnType`, `InstanceType`), and `Awaited` with
   its real recursive definition. Codegen keeps evaluating the utility types
   itself (`resolveUtilityType`): the ambient alias registry skips them.
3. **The `Promise` statics** (`all`, `allSettled`, `any`, `race`,
   `resolve`, `reject`) carry TypeScript's signatures and `@intrinsic`
   keys; `PromiseSettledResult` and its two members are declared. The
   by-name block is deleted.
4. **Timer handles**: `NodeJS.Timeout` and `Immediate` declare `ref`,
   `unref`, `hasRef` (and `refresh`, `close` on Timeout) with intrinsic keys.
   `refresh()` is new: `timers.c` keeps each entry's delay
   (`__kml_timer_refresh`), re-arming a fired one-shot and ignoring a
   cleared one. The by-name block and `isTimerHandle` are deleted.
5. **TypedArray, Buffer, DataView**: `set`/`subarray` carry
   `TypedArray.prototype.*` keys on every typed array and Buffer; the Buffer
   instance methods `Buffer.prototype.*`; the DataView accessors
   `DataView.prototype.*`, with `getFloat16`/`setFloat16` declared
   (lib.esnext.float16). Their by-name blocks are deleted. The Response
   stream reader's synthesized `out.set(…)` names its intrinsic directly.
6. **XMLHttpRequest** is declared (lib.dom's members this compiler
   implements, `onload`/`onerror` on `XMLHttpRequestEventTarget`), its
   methods carrying intrinsic keys. The by-name block is deleted.
7. **Body readers** (`text`, `json`, `arrayBuffer`) carry `Body.prototype.*`
   keys; `FormData` is declared as a type (no constructor, no
   implementation). The by-name block and `isResponseMethodName` are
   deleted.
8. **Object.prototype**: the checker reads Object's members through any
   object type that does not declare them (and `BigInt`'s apparent type is
   `BigInt`). `toString` (Object, String, Symbol) and `hasOwnProperty`
   carry `Object.prototype.*` keys, BigInt's `toString` its own, and
   Array's `toString` is `Array.prototype.join`. An object's or class
   instance's `toString()` is `"[object Object]"`. The Symbol/BigInt/Error
   `toString` and `hasOwnProperty` by-name blocks are deleted.
9. A void call's result held in a module global is `undefined`; a
   dictionary's dot-read is typed as its map get's result.
10. **WHATWG streams**: the ReadableStream, reader, controller (and
    TransformStreamDefaultController), WritableStream, writer and writable
    controller methods carry `<Owner>.prototype.*` keys on
    `emitStreamMethodCall`/`emitWStreamMethodCall`; `streamCallType` is the
    one result-type answer for both. The by-name block is deleted.
11. **A receiver the checker cannot type** (a callback parameter typed from
    an overloaded generic context, `new ReadableStream<number>({ start:
    (c) => … })`; synthesized code) takes the intrinsic its codegen
    representation's owner declares (`reprIntrinsic`): one lookup keyed by
    representation, not a name switch, consulted only when the checker
    has no declaration for the member.
12. An intrinsic whose type hook has no answer leaves the call to the
    per-kind inference.
13. An array literal for an array of literal types (`["sign"]` for
    `KeyUsage[]`) keeps its literal elements in overload resolution.
14. **TextEncoder, TextDecoder, WeakRef, FinalizationRegistry** carry
    intrinsic keys; `ownerReprs` names the representation each owner's
    intrinsics take (one table, consulted by `intrinsicApplies` and
    `reprIntrinsic`). Their by-name blocks are deleted.
15. **The native ChildProcess representation is deleted**
    (`emit_childprocess.go`, `ChildProcessType`/`CPStreamType`/
    `CPStdinType` and the `IsChildProcess`/`IsCPStream`/`IsCPStdin` flags):
    `lib/node/child_process.ts` implements ChildProcess, and the only
    producer left was an undeclared bare `ChildProcess` annotation, which
    tsc rejects. The spawn runtime the TypeScript module and the fork IPC
    use stays.

## Implementation notes

- `checker/typeops.go` (new), `checker/symbols.go` (the operators'
  dispatch, intersection reduction, substitution of function type
  parameters during a deferred evaluation), `checker/generics.go`
  (instantiate, erased generic sources), `checker/relate.go` (rest
  signatures, deferred), `checker/overloads.go` (tuple inference),
  `checker/checker.go` (Object members, BigInt apparent type).
- The `infer` placeholders being matched are tracked
  (`inferPlaceholders`) so they do not make the extends type deferred.
- `codegen/llvm`: `emit_timers.go`, `emit_intrinsics.go`, `emit_lowered.go`
  (each new owner's `intrinsicApplies` receiver check), `emit_buffer.go`,
  `emit_xhr.go`, `emit_fetch.go`, `emit_promise_combinators.go`,
  `emit_response_new.go`, `emit_ambient.go`, `emit_exprs_vardecl.go`,
  `emit_exprs_types.go`, `emit_call.go` (blocks deleted).
- `codegen/llvm/timerssrc/timers.c`: a per-entry delay array beside the
  queue (the queue's 32-byte entry layout is read by generated code, so it
  is unchanged).

## Side effects discovered

- [ADR-01336](ADR-01336.md)'s rule that `new obj.K()` never renames K broke
  a namespace's class (`new Geometry.Point()`): a namespace's class is a
  bare top-level declaration (ADR-00408), so its member is renamed; only
  a qualifier that is a value (a top-level binding, or a local) keeps the
  member as a property name.
- `TestE2EZlibPortHandlesASan` crashed Apple clang 21's AddressSanitizer
  pass: `llvm.global_ctors` listed `__kml_perf_init`, a C function only
  declared in the IR, and once a second constructor joined it
  (`__kml_unit_init`) ASan's initializer poisoning dereferenced the
  declaration's missing entry block. `__kml_perf_init` is a C
  `__attribute__((constructor))` now; the IR list holds only IR
  definitions.
- `zlibstream.c` names the constructor-name constant `Error` by symbol;
  the IR's copy is `linkonce_odr`, which LLVM drops when no IR uses it,
  so a program using only the zlib streams failed to link once the
  by-name paths that used it were gone. `zlibstream.c` defines it weakly
  itself (same layout, coalesced with the IR's copy).
- The Linux test-par found `n.toString(8)` printing decimal: a number the
  checker reaches Object.prototype's `toString` for took the Object
  intrinsic, which has no radix. Numbers keep `Number.prototype.toString`'s
  lowering.
- Test262 strict went from 8,201 to 8,180 passes and js from 9,842 to
  9,827. The strict lane rejects 23 more files with TS2345 now that
  `PropertyKey`, `Exclude` and the utility types resolve: a `valueOf`
  object, a symbol, `null` or a `Number` wrapper where tsc also rejects
  them (sampled against tsc 5.9.3). One cluster was a declaration bug:
  FinalizationRegistry took `object` where TypeScript's lib takes
  `WeakKey`; it is declared with TypeScript's definition, and a registered
  symbol passed to it is Node's TypeError.
- `TestE2EReplaceCallbackNumericReturn` asserted the strict lane accepts a
  replacer returning a number; tsc rejects it (TS2769). It asserts the
  rejection and the `-compat=js` output.
- `examples/strings/replace_capture_groups.ts` passed a replacer returning
  a number, which tsc rejects (TS2769); it is typed `(): any` now, keeping
  the stringification it shows.

- `TestE2EUtilityPickDropsField` now fails in the checker with tsc's
  excess-property error instead of a codegen error.
- `TestE2EPromiseAllSettledArrayBufferPreservesEmbeddedNullByte` read
  `res.value` on a `PromiseSettledResult` without narrowing, which tsc
  rejects; it narrows on `status` now.
- The DNS test compares against Node.
- A rest parameter's `infer` binds one position, not the rest's tuple;
  `Awaited` and `Parameters` of a fixed-arity function are unaffected.
- `Promise.withResolvers` and `Promise.try` stay undeclared: codegen has no
  implementation.
