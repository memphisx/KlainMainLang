# ADR-01287: Dates, collections and weak collections held in `any`

- **Relations**: `Extends ADR-01285`, `Implements part of TDD-00230` (P3.3)
- **Date**: 2026-09-29

## Context

A host value boxed into `any` is a host cell: a header word naming its
layout, and the handle. Several kinds were still missing or broken:

- **`Date`** boxed as its time value, so `typeof` read `"number"` and
  `instanceof Date` was false. Typed Dates had no `toString`, and
  `console.log(date)` printed the number.
- **A boxed Map, Set, Headers or URLSearchParams** could not be iterated:
  `for…of` and spread threw "is not iterable". Typed `[...map]` crashed,
  and `[...headers]` was empty.
- **`const m: any = new Map()`** (or Set, WeakMap, WeakSet, WeakRef) was
  a compile error.
- **Weak collections**:
  - a boxed WeakMap called its members with a primitive-typed key;
  - an `any` key was rejected at compile time;
  - an `any` value was stored as raw box bits;
  - `console.log` of a WeakMap, WeakSet or WeakRef failed to compile or
    printed garbage.
- **Typed `console.log`** of a RegExp or a DataView printed garbage.
- **`structuredClone`** of a boxed `Map<string, number>` read its values
  as boxes, because the clone cast the box to `Map<any, any>`.

## Decision

- **A Date is a host cell** whose second word is the i64 time value
  (`hostHandleIR`). Every load or store of the handle goes through
  `emitHostCellLoad`.
  - Unboxing to Date reads the cell; a number held in the slot converts.
  - `__kml_toprimitive` takes an i8 hint: number, string or default.
    Operators pass "default" for `+` and "number" for everything else.
    A host box goes to `__kml_host_toprim`, which gives a Date's time
    value for the number hint and its `toString` otherwise.
  - `JSON.stringify` asks `__kml_host_tojson`, which gives a Date's ISO
    string.
- **`Date.prototype.toString`**, `String(d)` and template literals give
  `Thu Jan 01 1970 00:00:00 GMT+0000 (Coordinated Universal Time)`. It is
  UTC, like every other Date accessor here (BACKLOG 124).
- **Inspect**: `console.log` and util.inspect show a Date as its
  toISOString, a RegExp as its source form, a WeakMap or WeakSet as
  `WeakMap { <items unknown> }`, and a WeakRef as `WeakRef {}`. A DataView
  shows its byteLength, byteOffset and buffer.
- **Spread**: a typed Map, Set, Headers or URLSearchParams spreads through
  its default iterator, `entries()` (a Set's `values()`).
- **`any` iteration**: `for…of` and spread over an `any` call
  `__kml_host_iter`. An iterable host box becomes its `[...handle]`,
  boxed; anything else passes through unchanged.
- **Declarations**: a collection under an `any`, `unknown` or union
  annotation is boxed like any other value. The module-global pre-pass
  agrees and types it `any`.
- **Weak keys**: a WeakMap or WeakSet key typed `any` (including
  `x as any`) is checked at run time. A primitive throws Node's
  TypeError: "Invalid value used as weak map key", or "Invalid value
  used in weak set". A boxed weak collection's adapters keep the key
  boxed, and a value is converted to the declared value type.
- `instanceof` knows WeakMap, WeakSet and WeakRef.
- `lib/node/internal_structured_clone.ts` walks a Map or Set with
  `value.forEach`, which dispatches on the box's own layout.
