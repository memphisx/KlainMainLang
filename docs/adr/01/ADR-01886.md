# ADR-01886: an iterator's next() result without a value (TS2490, TS2547)

- **Relations**: `Implements TDD-00230` (the strict lane is tsc; P3.3's unanswered bucket)
- **Date**: 2026-10-21

## Context

- tsc reports TS2490 when an iterator's `next()` returns a type without a `value` property, TS2547 for an async iterator's (its awaited result), and types the iterated element `any` after either. The checker reported TS2490 for both protocols, and for a `next()` that only throws (`never`) reported nothing and left the delegating generator unanswered: `yield* obj` with `obj`'s `next() { throw reason }` (a Test262 shape) gave no type to the generator, its calls or anything read from them.

## Decision

- A `next()` result of never is one without a value: TS2490, or TS2547 when the async protocol is the one read, and the element is `any`.

## Consequences

- The strict lane rejects what tsc rejects, with tsc's code for each protocol; the js lane types the generator and runs as Node does.
- Verified on Apple Silicon against tsc 5.6.3.
