# ADR-01768: Unannotated async methods return a Promise

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

`class C { async foo() { return 1; } }` registered `foo`'s signature with the inferred result (`number`) and an async flag, but never wrapped it. Expression inference said `Promise<number>`, so `o.foo().then(…)` failed with ".then is only supported on a Promise" and `await o.foo()` with "await requires a Promise value", in both lanes. An annotated `async foo(): Promise<number>` worked. Test coverage only had annotated async methods.

Separately, a detached async method (`var am = C.prototype.am; am().then(…)`) is `any` in codegen, while the front end types the call as a Promise. So `.then` took the static Promise path on an `any` value and failed the same way.

## Decision

- An unannotated, non-generator async method's signature returns `PromiseOf(inferred)`, as the annotation would.
- `emitPromiseThenInto` calls `then`/`catch`/`finally` dynamically (`emitDynAnyMethodCall`) when the receiver turns out to be `any`.

## Consequences

- `TestE2EUnannotatedAsyncMethodPromise` and `TestE2EJSFileDetachedAsyncMethodThen` cover both.
