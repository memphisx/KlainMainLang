# ADR-01970: Promise.try, Awaited<T> in generic bodies, instance spreads and other shadow-unit gaps

- **Relations**: Implements TDD-00230 (P3.3); follows [ADR-01969](ADR-01969.md)
- **Date**: 2026-10-30

## Context

Three shadow units from the E2E suite were still open after ADR-01969:

- A program printing `typeof Promise.try` needed an answer for a static the lib did not declare.
- A JavaScript file called a method `ArrayBuffer` does not have (`transferToImmutable`).
- A hoisted `var acc = (acc ?? 0) + j` read itself in its own initializer.

Probing nearby shapes turned up more bugs:

- `const f = () => f` overflowed the stack, first in the checker and then in codegen.
- `const g = () => g()` crashed the checker with a nil result.
- `Promise.try` compiled to a call that threw "is not a function" at run time.
- Adding it exposed `Awaited<T>` resolving to an array inside a generic body.

## Investigation

- **`Promise.try`.** Node 24 has `Promise.try` (ES2025), with `typeof` `"function"` and `length` 1. The lib's `PromiseConstructor` did not declare it. The status row for `typeof` cited it as a runtime-absent static, which was wrong.
- **`Awaited<T>` in a generic body.** `function r<T>(v: T): Awaited<T>` failed with "the value is not an array" for every instantiation. The checker types `Awaited<T>` over an unbound type parameter as a deferred conditional, which the oracle declines. Codegen's fallback (`decideAnnotationType`) then reached the generic single-type-argument arm, which reads `Name<X>` as an array of X. Codegen's conditional-type evaluator is never reached for the lib alias.
- **The first `Promise.try` body.** It resolved with `callbackFn(...args) as any` inside a generic `<T, U extends unknown[]>`, which then read a promise returned by the callback as a number (`NaN`). Codegen infers T from `() => T | PromiseLike<T>` as the callback's whole return type, and `reprCtx.union` drops a `PromiseLike` member (deliberately, so resolvers take the value). So a declared `() => number | PromiseLike<number>` that returns a promise reads it as a number. That drop is a cross-cutting representation question and is tracked in the backlog rather than changed here.
- **`const f = () => f`.** tsc types it `() => ...`: the type contains itself, with no TS7023, because no call asks for the result. The checker's interned type is the same, and three walkers recursed without end on it: `Type.String`, the oracle's `hasTuple`, and `reprCtx.function`.
- **`const g = () => g()`.** tsc reports TS7023 at `g` and types it `() => any`. The checker's deferred result (`interner.deferred`, read through `Type.Ret`) was asked for while it was being computed and returned nil.
- **`var acc = (acc ?? 0) + j`.** tsc reports TS7022 and types `acc` as `any`. `typeOfSymbol` returned unanswered for the cycle.
- **TS2454 for `var`.** The binder's definite-assignment check (`FlowDiagnostics`) exempted `var`, as hoisted and undefined-initialized. tsc 5.9.3 reports a `var` read that some path reaches before a store, whether the `var` is annotated or typed by its initializer (`while (c) { var w = "w"; break } w`), unless its type holds `undefined`. The strict lane compiled `TestE2EHoistedVarLoopAndSwitchShapes` and `TestE2EDefiniteAssignConditionalVarAllowed`, which tsc rejects. tsc's binder makes the false branch of `if (true)` unreachable, so `if (true) { var z = 7 } var z = z + 1` is accepted.
- **`ab.transferToImmutable()` in JavaScript.** tsc in a JavaScript file types a member the lib type lacks as `any`. The checker did so only for arrays and primitives.
- **`new assert.Assert({ diff: 'full' })`.** The binder records a qualified `new` callee (`binder.go`, `qualifiedCallees`) only when its root is a variable or a namespace. A function's expando (`ok.Assert = Assert`), an import alias or a class's static member was never typed, so the construction was unanswered. Through a `const d = ok` alias it already worked.
- **`{ ...p }` over a class instance.** The checker's `spreadable` admitted only anonymous and interface types. tsc's `getSpreadType` spreads an instance's public data properties and leaves out methods, accessors, private and protected members, and `#` names. At run time, though, a TypeScript-private field is an own property, and Node copies it (`{"a":"a","b":1}`). So the representation has to hold fields that tsc's type leaves out.
- **`this.k` in an object literal's method.** Codegen holds that `this` as a box (`funcExprThisType`), and its member read on a plain box unboxes to the checker's primitive (`emitMember`, `checkerPrimitive`). The oracle answered the box.
- **`this.tag` in a static generator method called through a subclass.** `staticThisToClass` gives the method a leading `this: any` parameter, which `liftStaticGenerators` copies into the generator function, and codegen keeps that read a box. The oracle answered the static field's string.
- **`new O((res) => res(9))` for a Promise subclass with an own `then` and no constructor.** Codegen passes the executor to Promise's constructor, so `res` is a resolver. The oracle collected executors only for subclasses with no instance methods.

## Decision

- `lib/es.d.ts` declares `PromiseConstructor.try` with tsc's signature, lowered (`@lower`) to `__kml_Promise_try` in `lib/node/kml_promise.ts`. That body is typed with `any`: it calls the callback with the arguments inside a promise executor, resolves with the result (so a thenable is adopted) and rejects with a synchronous throw. Typed `any`, the callback's result is held boxed whatever it is, which the generic form could not do.
- `decideAnnotationType` resolves the lib's `Awaited<X>` (no program type of that name) before the array fallback: X resolved, with promises unwrapped recursively. The oracle binds a generic body's type parameter that is instantiated with `number` or `boolean` to that checker type (`TypeFromNodeWithBindings`, `primitiveBindings`), so the checker evaluates a conditional over it.
- `Type.String` prints a type met again while being printed as `...`, as tsc does. `hasTuple` and `reprCtx.function` stop at a type they are already inside, and the oracle holds a self-containing function type (`selfContaining`) boxed, as no closure signature can spell it.
- A deferred result asked for during its own computation is `any`, and TS7023 is reported at the binding's name (`reportArrowReturnCycle`). The check pass resolves each function literal's result (`resolveResult`), as tsc does while checking it, so the cycle is found even when nothing calls the function.
- An unannotated variable read inside its own initializer, outside any nested function or class, is `any` (`ownInitializerRead`), and TS7022 is reported at its name (`reportOwnInit`).
- The check pass reports TS2454 for a `var` read (`unassignedVar`) when its type holds no `undefined`, `any`, `unknown` or `void`, and the binder finds a path from the declaring function's start with no store (`UnassignedVarRead`, `walkBackStop`). That holds for the strict lane only, in the declaring function only. Two kinds of condition end a path as a store does, so a program tsc accepts is never rejected. One is a condition or switch that may narrow the variable, since tsc's narrowing may remove the `undefined` there. The other is the unreachable branch of a literal `true`/`false` condition. The message is now a TypeScript error.
- In the JavaScript lane, a member that a library interface or instance type lacks is `any`.
- The binder records a qualified `new` callee rooted in a function, an import alias or a class as well as in a variable or a namespace.
- `spreadable` admits a class instance, and the spread copies what tsc's `isSpreadableProperty` does (`instanceSpreads`). A literal spreading an instance that has a private or protected field (not a `#` name) is laid out by the oracle as `inferObjectType` lays it out (`hiddenFieldsLiteral`): each spread's runtime fields, then the literal's properties. An unannotated binding of one is laid out the same way.
- A named member read off a boxed `this` that the checker types as a primitive is that primitive. Inside a lifted static generator that takes its receiver as a parameter (`liftedGenReceiver`), it is the box.
- A Promise subclass with no constructor and no fields of its own (`promiseSubclassImplicitCtor`; methods allowed) has its executor's parameters typed as Promise's resolve and reject. One with a field (`examples/classes/extends_promise.ts`'s `Timed`) keeps a plain function there, as codegen does.
- ADR-01969's rule for a const binding of a boxed member read now applies only to a member the checker types as a function (`functionTyped`): a method read as a value. A data read off a box (`const type = options.type` in `lib/node/crypto.ts`) is narrowed at its reads as codegen narrows it.

- The checker follows tsc in more places:
  - A tuple read at a `number` index is the union of its elements, plus `undefined` when an element is optional.
  - An object pattern's rest is the source's other properties (`getRestType`).
  - An `@@` key on an array or tuple reads its apparent type's member.
  - `instanceof Map` keeps `Map<string, number>` when the guard's instantiation is all-`any`.
  - The JavaScript lane's empty `[]` is `any[]`, or its array context.
  - `URLSearchParams` and `Headers` are iterable, as in `lib.dom.iterable`.
  - An object literal's getter reads `this` as the literal's snapshot, accessors left out as methods are.
  - An assignment narrows a declared union of objects by the full relation, type arguments included (`Set<number>` out of `Set<string> | Set<number>`; tsc's `getAssignmentReducedType`).
  - A catch clause is entered from every assignment inside its `try` block as well as from the state before it (tsc's catch exception target).
  - A rest in an unannotated pattern's implied type adds a string index of `any`, and an object rest keeps the source's index signatures.
- The oracle matches codegen in more cases:
  - A library global's member (`JSON.stringify` read as a value) is the builtin's closure, not a boxed receiver's read.
  - A generator declaration a literal holds by name (`{ seq }`) is a box, whichever receiver reads it.
  - A step of a generator or of any other iterator that codegen builds as `{value, done}` reads its own fields.
  - An object-typed read off a binding held as a plain box is a box.
  - A `for (const [a, b] of rows)` binding over arrays may be absent.
  - A binding of a typed-array element read is present after a store that is.
  - `singleVarDecl` ignores a type alias or interface merged with the value.
  - `const f = counter.describe` and `const q = a` (a's literal layout) keep the methods that take their `this`.
  - A builtin read with a string key (`Date["UTC"]`) is the builtin's closure.
  - `...{ length }` on a rest parameter binds a number.
  - A member read off a non-identifier receiver held as a plain box is a box when the member is an object or a function.
  - A `for (var k of …)`/`for (var k in …)` binding read after its loop, or in a closure, may be undefined, unless the loop runs over a non-empty literal and the read is in the same function.
  - A member of `globalThis.X`, X a library global, reads as the bare `X.member` (`globalThis.crypto.subtle`).
  - A call (or its `await`) of a non-generic function declared to return a tuple keeps the tuple.
  - A call of an object literal's `return this` method (`o.self()`, `o.inc().inc()`) is the box the method returns.
  - `new K()` of a `const K = class {…}` binding is that class's instance, inside its own static method too. A `new` of a class value the checker cannot follow (a class a call returns, an aliased member such as `events.EventEmitter`, `new c.B()` of a class-valued field of an instance) is a box.
  - A property that only one object member of the receiver's union has (`server.address().port`) is that member's property, for a scalar.
  - A spread literal whose checker type has no representation is the dynamic object codegen builds.
  - A property of `this` in a static method of a class expression, which codegen binds as a box, is a dynamic read.
  - A parameter annotated with one string literal and null or undefined (`y: 'p' | null`) keeps the literal kind.
  - A library `PromiseSettledResult<T>` is the settlement record. An inferred tuple whose elements differ only in their absent states (`[number | null, number | null | undefined]`, or settlements of them) is an array of the joined element. A `then` callback over an allSettled array, and an element callback over one, take its records.
  - A conditional whose branches have one layout is that layout (two object literals with a tuple field).
  - A builtin function read as the receiver of its `length` or `name` is the closure codegen builds for it. A function member of a library global that codegen holds as a box, with no intrinsic (`Promise.try`), is a read off that box.
  - An array of object literals whose methods read `this`, its unannotated binding and an element callback's parameter over it keep those methods' `this` parameter.
  - An element callback on an evolving JavaScript array, which the checker leaves unanswered, takes and returns boxes. `map` and `flatMap` of it are `any[]`, and `filter` is the receiver's kind.
  - A nested generator that captures and reads its own value (a declaration, or an expression's own name) is held in a cell as a function, as codegen binds it.
  - `super(…)` is the class's instance, and so are the `(super(…), …, this)` sequence that inlined field initializers make and an arrow returning either. `super` in a subclass of `Array<T>` is a `T[]`.
  - A generic function declaration read as a value is its erased instantiation's value (`funcRef`, `erasedGenericValueType`).
  - A match result's `groups` is the dictionary codegen reads it as (`execMembers`). A member of a value that is only `undefined`, `null` or `void` is a dynamic read, which throws.
  - A rest parameter annotated with a tuple of several element kinds is the boxed array its arguments are collected into.
  - A function declaration whose every return is its own name returns itself boxed (below).
- The checker prints a function type inside a union in parentheses (`(() => number) | undefined`), as tsc does.
- The checker reports TS2558 for `new C<…>(…)` of a program class given fewer type arguments than its type parameters without defaults, or more than all of them; codegen used to reject `new Pair<number>(1)` with its own message. A method whose inferred result reads a static of its own class, where that static's result builds the instance (`meth() { return K.s() }` with `static s() { return new K().e }`), is typed on first read rather than left `any`: a read of a static not yet typed off the class's partial snapshot of its statics counts as a cycle, the snapshot is never cached as a node's type, and the method's result is deferred (`methodType`). Test: `TestE2EClassMethodThroughStaticCycle`. It reports TS2304 for `arguments` that no function binds (an arrow at the top level) on the strict lane; codegen used to fail with `undefined variable`. tsdiag: 4 more TS2558 agreements and 4 more TS2304 agreements, no new false positives.
- Codegen:
  - `eraseTypeParams` also erases value-held annotations, so `new Q<string>((r) => r("hi"))` compiles.
  - A function field's object parameter or result keys its layout as `{}`, so self-returning literals cut at different depths share one layout.
  - A non-pointer callee is called dynamically (`f()()` of `const f = () => f`).
  - An unannotated literal that reads its own binding is typed from the checker.
  - The prototype-reach walk (`buildProtoReach`) reads every body outside its scope, so it runs as an analysis pass.
  - The `u` flag's escapes follow V8, checked as a regular expression is compiled (`regexp.c`):
    - `\u{…}` and a surrogate-pair escape are one code point, written for PCRE2 as `\xHH` (ASCII, so a metacharacter stays literal) or the code point's UTF-8 bytes. `PCRE2_ALT_BSUX`'s `\x` takes two hex digits, so `\x{…}` would not do.
    - An escape the `u` grammar has no production for, and a class range with a class escape at either end, are a SyntaxError with V8's message.
    - `.unicode`, `.unicodeSets` and `.hasIndices` are fields set from the flags. A read of `.unicode` used to call the prototype getter, which read `.unicode` again until the stack overflowed.
    - Tests: `TestE2ERegExpUnicodeCodePointEscapes`, `TestE2ERegExpUnicodeFlagGetters`, `TestE2ERegExpUnicodeEscapeValidation`.
  - A spread into fixed parameters follows TypeScript and JavaScript instead of failing to compile:
    - A fixed tuple spreads by position whether codegen holds it as a tuple or an array (`[4, 5, 6] as const`), in a call and in `f.apply(t, tuple)` (`spreadArity`, `spreadOnce`).
    - On the strict lane, an array spread over optional parameters (`f(...arr)`, `f(...arr, 9)` of `f(a?, b?, c?)`, which tsc accepts) collects the arguments from that spread on into one array. Each remaining parameter takes its element, undefined past the end; a rest takes the remainder. An element of another kind than its parameter is converted from its box (`optionalSpreadRule`).
    - An array spread into required parameters is TS2556, reported by the checker as tsc does (`checkSpreadArity`); it was a codegen error.
    - Under `-compat=js`, a spread of no static arity that reaches a fixed parameter calls through `apply`, so any iterable spreads and `arguments` counts every element (`applySpreadRule`).
    - Tests: `TestE2ESpreadConstTupleIntoFixedArity`, `TestE2ESpreadOverOptionalParams`, `TestE2ESpreadIntoFixedArityJS`.
  - A nested generator declaration may capture an enclosing array: the capture is the cell holding the array's shared header, as for any other closure (the compile error that refused it is gone). Test: `TestE2ENestedGeneratorCapturesArray`.
  - The new oracle rules dispatch a library method's or interface's name through a table (`evolvingElemResult`) or a structural test (the settled records' `value`/`reason`), keeping the string-case ratchet where it stood.
  - `function F() { return F }` returns itself boxed (`returnsOwnName`). Its type has no finite form, and the cut at a fixed depth handed a raw function pointer to a dynamic call, so `F()()()()()` threw `is not a function`. Test: `TestE2EFunctionReturnsItself`.
  - A function's own unannotated local declaration whose initializer is not a literal takes the checker's type (`LocalType`, `localDeclType`). That type is the initializer's expression type, or an element read widened to a number. Codegen keeps only the storage refinements that come from flow: a `var` its scope may skip. A literal initializer is still typed by its syntax, and a node the checker never saw is still typed from its parts. The shadow harness compares every local declaration (`localDeclType`).
  - A typed array's iteration callback got a fresh plain array over its data as its third argument (`a === t` was false, and `a` printed as an array). It now gets the typed array itself, typed as the receiver (`hofSelf`, `codegen/llvm/emit_arrays_hof.go`). Test: `TestE2ETypedArrayCallbackGetsReceiver`.

## Implementation notes

- `checker/types.go`: `str(seen)` behind `String`; `cycleResult`/`computing` on `Type`, and `interner.deferred` takes the cycle result.
- `checker/checker.go`: `ownInitializerRead`, `reportArrowReturnCycle`, and the JavaScript lib-member rule.
- `checker/check.go`: `resolveResult`, `unassignedVar`.
- `binder/flow.go`: `walkBackStop`, `UnassignedVarRead`.
- `diag/messages.go`: TS2454 is a TypeScript error.
- Tests: `TestE2EHoistedVarLoopAndSwitchShapes` and `TestE2EDefiniteAssignConditionalVarAllowed` assert tsc's rejection and run their programs under `-compat=js`.
- Instantiating a generic over a type that contains itself (`let x = { foo: <T2>(t2: T2) => x, bar: (t1: T1) => x }` returned from `example<T1>()`) recursed without end. Each outermost `instantiate` now memoizes its function types (`instState`): a function type met again inside its own instantiation gets a deferred result, the finished instantiation's, read when asked. Met inside its own result, it is a reference rather than a call, so it is instantiated without its own type parameters and stays generic, as tsc prints it. `occurs` searches each type once. Tests: `TestSelfReferentialGenericLiteral`, `TestE2ESelfReferentialGenericLiteral`.
- TS2454 follows tsc's flow containers: a namespace body is one (a read there of a variable declared outside it is not checked), a var's read in its own initializer is the circular any (TS7022) instead, and a name in an object literal method's or accessor's computed key has no flow node.
- A call's effects (a `never` result, an `asserts` predicate) come only from annotations, as tsc's getEffectsSignature: `inferredResultCallee` skips a callee whose result is inferred, so `function f(x) { var z = f(x); return x }` and `function self() { self() }` are no cycle.
- `callsItself` (tsc skipping a bare self-call among return expressions) also unwraps `await` in an async function and accepts an arrow or function expression held by a `const`.
- TS7023 is reported only when the cycle closes while the function's result is inferred: one through parameter defaults alone (`function foo(a = bar())`, `function bar(a = foo())`) tsc never meets.
- An `as T` expression is typed from `T` without typing its operand first; the check pass types the operand, as tsc's checkAssertionDeferred.
- Inferring from one signature to another reads the argument's result only when the parameter's result could hold an inference (tsc's applyToReturnTypes): `Parameters<typeof bar>` in `foo`'s parameter, `bar` returning `foo(…)`, is no cycle.
- A `typeof` query inside a type literal's member closes no TS7023 cycle: tsc resolves those members when read (`var y: { y2: typeof z }` with `z` the function's own call).
- `typeof f` of a plain function declaration not yet typed is its signature with the result deferred (`lazyResultDecl`), and a deferred result is not read to decide whether a type is generic, nor when the target signature's result is `void` or `any` (tsc's compareSignaturesRelated). A cycle report names only the function's own symbol, never one of its parameters. Test: `TestNoReturnCycle`.
- The front end's `T | PromiseLike<T>` outside a signature's own parameters holds a `PromiseLike` member as any, so the union is boxed, as codegen's annotation decider has it; a parameter's (a resolver's value) stays T, codegen's resolvers adopting a thenable at run time. Dropping the member read a promise returned through `() => number | PromiseLike<number>` as a number. Test: `TestE2EValueOrPromiseLike`.
- Example `examples/basics/var_hoisting.ts` reads `var`s that tsc reports (TS2454 at 13 reads). It moved to `examples/jsmode/var_hoisting.js`, the JavaScript lane, with the same output.
- `checker/symbols.go`: `TypeFromNodeWithBindings`, `PrimitiveType`.
- `codegen/llvm/frontview.go`: the two new methods.
- `codegen/llvm/shadow_binder.go`: `hasTupleIn`, `selfContaining`, `reprCtx.fnBusy`, `primitiveBindings`.
- `codegen/llvm/emitter.go`: the `Awaited` arm.
- `binder/binder.go`: qualified callee roots.
- `checker/checker.go` also: `instanceSpreads` and `spreadable`.
- `codegen/llvm/shadow_binder.go` also: `spreadsHiddenFields`, `hiddenFieldsLiteral`, `liftedGenReceiver`, `promiseSubclassImplicitCtor`, and the boxed-`this` member rule.

- `checker/checker.go`, `checker/symbols.go`, `checker/narrow.go`, `checker/generics.go`, `checker/jsmode.go`, `lib/node.d.ts`, `codegen/llvm/phantom_generics.go`, `codegen/llvm/objheader.go`, `codegen/llvm/emit_call.go`, `codegen/llvm/emit_exprs_vardecl.go`, `codegen/llvm/emit_func.go`, `codegen/llvm/shadow_binder.go`, `binder/binder.go`: the rules above.

## Side effects discovered

- A declared `T | PromiseLike<T>` return is held as T (backlog).
- A closure reading a `let`/`const` declared after it failed to compile; fixed in [ADR-01971](ADR-01971.md).
- A destructured `x = d` over an `x?: T | null` string or array field kept `undefined` in its type after the default replaced it. It is now `T | null` (`defaultedBindingType`, `codegen/llvm/emit_objects.go`).
- `Promise.all`/`allSettled` over promises of `T | null` and `T | null | undefined` failed to compile (a union of two nullable scalars). The array literal now takes one promise type that holds both absences (`joinedPromiseElems`, `awaitedUnion`), a `T | null` promise stores its null with the three-state null payload, and the oracle maps `PromiseSettledResult<T>` to the settlement record and joins such inferred tuple elements (`settledResult`, `joinedElems`). Test: `TestE2ECombinatorMixedNullableScalars`.
- The checker builds a class's instance type eagerly, so a static method's inferred result that constructs the class can leave an instance method's inferred result `any` (backlog).
- A JavaScript loop of bindings reassigned from calls that read each other (`a = F(a, b); b = F(b, a); …`) ran out of the checker's flow budget, so the sum it returned was untyped. Now an assigned call to a plain function declaration (one signature, no type parameters, no predicate) takes the signature's result without typing its arguments (`plainCallResult`, in `assignedType` and the evolving binding's storage type). That function, asked while it is itself being typed, is a cycle. A flow label's answer is cached unless a recursion cut still open was met under it (`openCutSince`), instead of after any cut at all. Test: `TestJSChainedCallReassignmentsInLoop`, `TestE2EJSRedeclaredFunctionAndChainedCalls`.
- A JavaScript function declared twice was typed by its first declaration; it is now the last, as hoisting leaves it. Test: `TestJSRedeclaredFunctionIsLast`.
- The oracle now matches codegen on four more shapes:
  - an array-pattern binding past the end of a literal source reads undefined;
  - a JavaScript alias of an array binding holds what its source holds;
  - an object rest binding with no properties left is the empty residual object;
  - a binding of `x[Symbol.iterator]()` is the builtin iterator.
  It also sees the by-value tuple return ABI that `-optimize-memory` gives a function.
- A function expression written as an object literal property's value (`f: function () { return this; }`) failed to compile in TypeScript ("'this' is only valid inside a method"), though tsc types its `this` as the literal. It now takes its receiver as a method shorthand does (`literalMethod`, the parser's `PropValue`). In JavaScript such a function keeps its own call-time `this`. Test: `TestE2ELiteralPropertyFunctionThis`.
- An object literal whose field's type asks for the literal's own class (a method returning `this`) registered one class per nesting level. An async `yield*` over it then failed to link, because only the last class had its accessor bodies. The nested registration is now the literal's one class. Test: `TestE2EJSAsyncYieldStarOverLiteralWithReturnGetter`.
- In JavaScript, `new` of a constructor function a variable holds, and `this` in a function expression, are `any` (they were unanswered). Tests: `TestJSNewOfFunctionExpressionValue`, `TestJSFunctionExpressionThisIsAny`.
- The oracle now also:
  - finds Promise executors in a worker module's top level;
  - no longer answers a function's local from a same-named module binding (`heldIdent`);
  - types a JavaScript literal function returning `this` as returning `any`.
- The shadow harness keeps a unit's source when its entry file was removed after parsing.
- A JavaScript function that reads its own `arguments` gets an implicit `any[]` rest in its checker signature, so extra call arguments are no error and every argument reaches it. Test: `TestJSArgumentsImplicitRest`.
- In JavaScript, a function expression read a name declared only by an earlier, closed block's `let` as that dead binding ("Cannot access before initialization"). It now reads the global ("is not defined"), as Node does. Test: `TestE2EJSClosedBlockLetUnseenByLaterFunction`.
- A top-level `let x = await []` read by a function failed to compile (the `never[]` element was unmapped, so the binding stayed a `main()` local). It is now the module's global array. Test: `TestE2ETopLevelAwaitEmptyArrayReadByFunction`.
- Strict-lane diagnostics tsc gives that were missed: TS2683 for `this` in a returned function expression no context types, and TS2554 for a tagged template whose tag takes fewer parameters than the template passes. Test: `TestCheck` cases.
- A JavaScript Map seeded with pairs whose values are pointers of different kinds (`[[1, [1, 2]], [2, "x"]]`) crashed: the seed's value type was compared by IR only, so the string was read as an array. Keys and values are now compared by their whole representation, and a seed or Set of rows of different layouts holds boxed rows. Test: `TestE2EJSMapSeedMixedValueKinds`.
- The checker overflowed its stack on an overloaded call with two object-literal arguments holding methods (`s.replace({ toString: function () {…} }, { toString: function () {…} })`): each argument's context typed the other. A call fitting its overloads gives a nested fit of itself no context.

An interface member typed with its polymorphic `this` (`self(): this`), read where no receiver binds it, holds the object as a box, generic interface or not. A type literal's accessor (`{ get done(): boolean; set done(v: boolean) }`) is a field to its readers, answered by an accessor object's own getter and setter, and boxed when its setter takes other values than its getter gives; such a type had no representation. An element access by a key of type parameter type (`src[k]` for `k: K`, `K extends keyof typeof src`) is the deferred indexed access `S[K]`, evaluated once K is bound, where it had no type; a generic arrow's type-parameter constraints and defaults name the file's own declarations (`typeof src` reported TS2304 there); an `any` key on an object with no index signature is TS7053, as tsc reports it. In codegen, a static object read by a key known only at run time (an erased `K`) reads through its box, and a deferred type over a type parameter an erased or monomorphized body binds is held boxed. Contextual typing and inference gained tsc's rules for callbacks: an object literal's member without a property of its context takes the context's index signature (through a type parameter's constraint too, instantiated with what the other arguments inferred); a context-sensitive literal's other properties infer first (intra-expression inference), also from an arrow's returned literal, which is itself context-sensitive (hasContextSensitiveReturnExpression); and a template expression is a possible discriminant value of type string. A call whose callback returns an object or array literal, whose result fits its context only with the context's literals, stays undecided; any other mismatch is reported, where every such call was left without a type. A generic function's instantiation takes the checker's inferred object type argument as its layout, where it fell back to `any` and read the argument's foreign layout at run time. A function-valued property beside a context-sensitive callback infers its type parameter only when no other property does, as tsc prefers covariant candidates over contravariant ones. A discriminant an object literal omits reads as undefined, which excludes a union member requiring it. A property of a literal whose context is a mapped type over keys not yet known takes the template at that key, and an intersection with a type parameter among its parts is deferred until bound. A spread of a union of object types types the literal once per member and joins the results, as tsc's getSpreadType does. A function-valued property's result and type predicate infer covariantly, and a type parameter occurring only in a predicate (`n is T`) counts as inferable from it. A computed key the checker can name (`[Symbol.unscopables]`) takes its member's context. A `return` in an unannotated function expression takes its contextual signature's result, a generator's the `TReturn` of that result's `next()`. An unannotated object pattern's defaulted function members are its initializer's context (tsc's getTypeFromBindingPattern). A type parameter's default that names an earlier type parameter is instantiated with that one's argument, after explicit type arguments too. A generic callable interface's instance (`Make<T>`) is its instantiated signature in codegen, and a generic interface's type parameters and its methods' own are erased where a member is read outside an instantiation. A type parameter with no inference whose constraint does not admit `unknown` takes the constraint (tsc's getInferredType). A deferred type counts the type parameters its node names through scope as free, so a conditional over a deferred mapped argument (`U<Pick<S, C>>`) waits for them. An `infer` inside a mapped pattern or an index signature is collected, a mapped type over `any` keys has string and number index signatures, and the resolver keeps an `infer` name and a mapped key name from being renamed to a top-level type of the same name. An interface may extend a type alias of an object type (`extends Record<string, Q>`, itself among the arguments), and codegen lays out a base with type arguments ahead of the interface's own fields. An optional property's `undefined` is not related to a target's index signature, as tsc's getNonMissingTypeOfSymbol drops it without exactOptionalPropertyTypes. A `typeof` of an unannotated variable written in its own initializer, an assertion's type included and a nested function's not, reports TS7022 and reads as any. An anonymous type with a string index signature and named members (a mapped type over a widened key intersected with an object) is a dictionary with those members. A type alias whose every self-reference is inside an interface's or class's type arguments (`type R<T> = T | Box<R<T>>`) is built with a stand-in, as tsc resolves those arguments lazily; instantiating a union met inside its own instantiation gives a stand-in too, the type-parameter walk stops on re-entering such a self-containing type, and codegen holds one as a box. Two generic signatures with as many type parameters relate with the source's taken as the target's, and two deferred conditional types relate by tsc's rule (check types related either way, extends types identical, branches related), so the `Equals` idiom evaluates; a conditional whose instantiated extends type reads only its signatures' own type parameters is decided, not deferred. A function-local type alias's body is renamed as a top-level one's. A `typeof x` reads x as flow narrowed where written. A narrowing by a type guard between two unrelated object types is their intersection; one class instance refined by different literals of one property is never, and a refined instance relates structurally, not as every instance of its class. `typeof N` of a namespace is an object of the members its run-time object holds, a member of its own namespace's type any inside it, and `typeof N.Sub.x` walks the namespaces; codegen holds `typeof` of a namespace or enum boxed, as their values are. `static g(t: typeof C.g)` reads the member, still being built, as any, as tsc resolves it lazily. An assertion's type (`x as T`, `<T>x`, `satisfies T`) resolves in the scope it is written in, so a type parameter it names is found. A type parameter as the source of a relation to a concrete target goes only where its constraint goes, unknown when it has none, so `T` to `string` is TS2322. The `this` type in a class field's function names the class; in a static member, or outside a class or interface, it is TS2526 with tsc's text, replacing the former unsupported-feature message. A generator function contextually typed by a union returns to the union's generator members. A union of callables intersects object parameters at one position. A deferred conditional bound to another deferred one reads that one's type parameters, so inference reaches through nested distributive conditionals. Element access by a constant key reads a primitive's member through its apparent interface, then Object's (codegen emits `x["charAt"]` on a primitive as the member it names), a property every member of a union of objects has, an empty enum's reverse mapping, and a function's expando member a constant-key assignment declared; a generic receiver read by a generic key is the deferred indexed access. `object` read by a computed key is TS7053, and TS7053 is reported at the receiver's position, as tsc's is. A class method or getter whose inferred result reads the member itself is TS7023 at its name, each member on the cycle reported, its result any; a getter read before the instance build reaches it is typed on demand. A function returned from a function with neither a return annotation nor a contextual result, or from an object literal's accessor, has implicitly-any parameters (TS7006). A spread of `[]` contributes no element (`[...[]]` is never[]), and a class whose `[Symbol.iterator]()` returns `this` iterates the values of its own `next`. An object type with call signatures and properties (`F & { foo: string }`) is a function object: codegen holds it boxed, `typeof` narrows it as "function", and `Object.assign` onto a function writes the sources' properties as its expandos through that box. A program's interface with required members beside a string or number index signature is an open object, read through a box. A bracketed string or number literal member name (`["a b"]: T`, `[0]: T`) is the plain name it spells, and a type literal's well-known symbol member (`[Symbol.toPrimitive]`) is that member, as an interface's is. A function-local type alias is typed only where an annotation names it, in its own scope, so codegen no longer evaluates one whose type reads a contextual signature's type parameter. A computed member name naming a const string or number literal (`[keywordA]: number`) is that literal's key. An alias reached again inside an array or tuple element is resolved lazily, as tsc defers it. A tuple with a trailing rest element (`[string, ...number[]]`) is an array of the union of its elements that also records its leading elements and its rest: a literal index, a destructured element and a rest binding read the position's own type, a union of such tuples destructures member by member, and assignment requires the leading positions (an empty literal against one is the tuple `[]`). A checker site that knows only arrays reads it as the array of that union. An array type parameter infers from a `ReadonlyArray<X>` context as X. A source conditional whose branches both relate to the target relates to it (tsc's default constraint of a conditional), and `never` relates to a deferred target. A call's context-sensitive arguments are typed left to right, each one's context inferring from the ones before it, as tsc's. A call with a callback whose inferred result does not fit the call's context, beyond its literals, is that result, its context filling only the type parameters nothing else infers, and the mismatch is reported. A union context's members with no call signature (a primitive, `PromiseLike<F>`) give the function literal none, so the callable member is its signature. An async function's body meets its contextual result awaited, keeping its literals by it, and `await` of a `PromiseLike<T>` is T. An object literal's member context reads `this` as the literal's context. A tuple spread inside a tuple type (`[...A, ...B]`, `[string, ...[number]]`) is spliced in place. Codegen no longer evaluates a non-generic alias the checker leaves without a type; an annotation naming one is typed where it is written. A call signature beside other members, in a type literal or an interface, is no longer rejected (90017, 90018 removed): the value is a function object carrying them, held boxed by codegen; a library callable with members (`process.memoryUsage`) keeps its host function. An argument inferring to a mapped type over a type parameter's keys (`Record<K, V>`, `{ [P in K]: X }`) infers K as the object's keys, kept literal, and the template from its property types (tsc's inferToMappedType). An object rest pattern over a type parameter (`const { a, ...rest } = obj` for `obj: T`) is `Omit<T, "a">`. A function literal's contextual parameter may read the type parameters of a function enclosing it (`keys.forEach(key => …)` inside `function S<K>(keys: K[])` types key as K); only the callee's own uninstantiated type parameters leave it untyped. A tagged template whose tag is overloaded or generic resolves as tsc's call over its `TemplateStringsArray` and substitutions: the first signature they fit, a generic one instantiated by the template's type arguments or by what the substitutions infer. An ambient class's computed member key (`declare class D { [k]: number }`) is resolved but never evaluated, so it is no read before the binding's declaration. A callable interface reached again from its own result (`interface A { (): B }`, `interface B { (): A }`) is held boxed at that occurrence. A class extending a namespace-qualified class (`extends M.C1`, `extends M.In.C3`) resolves its base through the namespaces, the qualifier now keeping every segment. A constructor type with members (`{ foo: number } & { new(): T }`) is held boxed like a callable one. A class value gains properties that are none of its statics (`K.extra = 7`, `Object.assign(K, { foo })`): the runtime keeps them per class reference after its static fields, so reads, `Object.keys` and `util.inspect` see them. A conditional type whose check type is the polymorphic `this` (`m(): this extends C ? undefined : null`) is deferred and decided per receiver, as `this` is instantiated on each member read. `x instanceof G` for a generic class G compiles (it was a clean rejection): each instantiation records an id G owns as its parent, so the class-chain walk answers it for every `G<T>` and for a class extending one. An instance intersected with a union of object types (`N & ({ a?: string } | { b?: number })`) distributes, each member refining the instance. An object literal spreading a generic value (`{ ...from, ...p }`) is the intersection of the spread types and its other properties, deferred until the type parameters are bound. A generic function argument meeting a non-generic function parameter, in a call returning a non-generic function (`createTransform(<I>(from: I) => …)`), keeps its own type parameters through inference and passes them to the result, as tsc's higher-order function type inference. A property destructured from a type-parameter value is `T["a"]`; an arithmetic operand of a deferred type is left unchecked rather than read as unknown. A signature whose result reads the value it types (`var b: () => typeof b`, `function foo(): typeof foo`) resolves that result when read, as tsc resolves a signature's return type apart. `typeof globalThis.isNaN` in a type position is the global's type. A function value whose rest elements differ in shape from the slot it is stored in (a builtin's `any[]` rest held as `(...v: number[]) => number`) converts through the box; it was passed through raw, so `Math.min` read doubles as boxed values. `typeof globalThis` is the global object's type, and indexing it by a name (`(typeof globalThis)["isNaN"]`) is that global's. An intersection of function types is their overload list, held boxed. An object type may declare several call signatures (90015 is removed). A function expression whose context has several signatures takes one combining them, each parameter the union of theirs (tsc's getIntersectedSignatures). A union of generic signatures with as many type parameters each is called through one signature over the first member's parameters. A type or interface may declare a string and a number index signature both (90013 and 90014 are removed): a key reads as its string, so the string index holds every entry at run time. `import.meta.dirname` and `import.meta.filename` are the module's own directory and path, and `import.meta` alone is an object holding them with `url` (90008 is removed). A namespace member declaration may bind several names (`export const a = 1, b = 2`) or destructure (`export const { p, q: [r] } = o`), each bound name a member. An object literal's `this` snapshot holds its methods too, each result resolved when read, so a method may read a later one (`a() { return this.b(); }`); one whose result reads itself is TS7023. A conditional whose branches are a tuple and a non-tuple (`c ? pair : "x"`) holds the boxed union, as one of an array and a non-array does. The library declares `Uppercase`, `Lowercase`, `Capitalize` and `Uncapitalize` as tsc does: each maps a string literal (a union member by member, a non-literal string to string), and defers on a type parameter until it is known. An indexed access with a concrete key of an object type that mentions a type parameter (`{ h(e: T): any }["h"]`) is read at once, as tsc reads it; an `any` index gives any. A deferred conditional source relates to a concrete target through the union of its branches (tsc's default constraint) when neither branch mentions a type parameter. In codegen, a receiver typed by a type parameter constrained to string or number, or by a union of literals of one kind, calls that primitive's methods, and one generic function's instantiations whose type arguments share a layout but give different signatures are separate instances. A class's static array is mutated in place through its value (`C.xs.push(v)`, `pop`, `unshift`, `splice`), which codegen rejected before. A generic class's instantiation lays out only its instance fields: a static field (`static instance: Bar<string>[]`, typed by the class's own instantiation) is the class's. A `super(…)` call's arguments take the base constructor's parameters as their contextual types (`super({ method(p) {…} })`), the base's type arguments applied. An interface method's result naming both its own type parameter and `this` (`extend<T>(p: T): this & T`) is mapped with both bound. `IterableIterator` is declared as tsc declares it (`<T, TReturn = any, TNext = any>`, with its `[Symbol.iterator]()`). A generator's `[Symbol.iterator]()` is the generator itself, and an iteration-protocol interface other than a generator's in a function's result (`(): Iterator<number>`) is held boxed, as a top-level annotation of one is. A homomorphic mapped type parameter (`x: { [K in keyof A]: X<A[K]> }`) infers A from an object argument as tsc's reverse mapped type: each property infers A's property from the template with that property the inference target, a primitive argument held as itself; a property's literal is kept where A's constraint types it with a primitive (the property's contextual type is `A["v"]`, read through the constraint, and through a conditional's branches), and widens elsewhere. A homomorphic mapped type over a type variable, once bound, distributes over a union and is a primitive, null or undefined itself (`Partial<string>` is string), as tsc's instantiateMappedType.

**Reverse mapped lists, deferred intersections, generic `for…in` keys.**
A homomorphic mapped parameter makes an array literal argument a tuple
(tsc decides by the parameter, before its type variable is fixed), and a
tuple or array argument reverse-maps element by element. Inference's first
pass reads an object or array literal argument without its
context-sensitive functions, so a callback beside data is typed from the
data. An intersection of mapped types infers to each member and gives a
property the merge of their templates. Tuples of one fixed length
intersect element by element. A `for…in` over a generic object whose keys
are one type variable's types its variable `Extract<keyof X, string>`,
else string, which indexes an intersection with a type parameter only as
TS7053. A generic deferred source relates through its base constraint
(`keyof` is `string | number | symbol`, an unconstrained `T[K]` unknown).
A `for…in` over a static layout under an `any` type boxes it first.

**Implicit-any parameters are any.** A parameter with no annotation,
default or context is the `any` its TS7006 reports, as in tsc, instead
of an unanswered type: the function and its uses stay checked (a later
TS2322 against it is reported). A member of an object literal whose
context is an unconstrained type parameter has no context of its own.

**Union calls with mixed generic members, singleton display.** A union of
call signatures where only some members are generic combines with the
generic members' type parameters, as tsc's
combineSignaturesOfUnionMembers keeps whichever side has them, and a
callback argument of a union callee takes its context from that combined
signature. Inference to an intersection of function types infers to each
member; to a type literal of call signatures, pairs signatures from the
end. A TS2322 message names a literal source as itself against a target
that could hold a singleton (a literal, null, undefined, void), judged on
the target the message names, as tsc's
typeCouldHaveTopLevelSingletonTypes.

**No contextual signature from `any`.** A function whose contextual type
is `any`, `unknown` or an unconstrained type parameter, or that is an
argument of a call through `any`, has no contextual signature: its
untyped parameters are implicitly any and reported (TS7006), as in tsc.
Return-type inference ignores an `unknown` call context and infers `any`
from an `any` one.

**Variadic tuple types; deferred types print.** A tuple type spreading a
type variable (`[...A, L]`, `[X, ...A]`, `[...A]`) is a deferred type,
evaluated once its variables are bound; `[...any]` is `any[]`. A rest
parameter of one infers from the tuple of the arguments it collects
(each widened, as tsc's spread arguments are), its fixed elements from
either end and its one spread from what lies between; an array literal
against one is a tuple. A fixed element before the spread reads as its
own type, any other index as the deferred indexed access. Code
generation lays a type parameter spread in a parameter's tuple type out
as the tuple it is bound to, splices such spreads in an instance's tuple
annotations, and names a tuple binding to the checker as a tuple type.
A deferred type prints as tsc prints a generic one: its type node with
each bound name shown as its binding, an alias instance by its alias
(`Extract<keyof T, string>`).

**Ambient constructor overloads; qualified names through a fundule.** An
ambient class's several bodiless constructors are overload signatures,
not a duplicate constructor (TS2392 is for implementations). A qualified
type name whose namespace is merged with a function the resolver made
file-private (`declare function B(): B.C`) finds that namespace by its
source name.

**Auto-typed bindings assigned `[]`.** `let x; x = [];` makes `x` an
evolving array from that assignment on, as a binding declared `[]` is:
the empty literal stores `never[]` (not a type taken from `x` itself),
push, unshift and element stores add their element types along the flow,
a mutation's own receiver reads as `any[]`, and a read finalizes the
array (`any[]` with TS7034/TS7005 where no element reached it). A
mutation's receiver is its reference candidate: a comma expression's
last operand, an assignment's target (`(x = [], x).push(5)`).

**Array and object intersections.** An array intersected with object
types (`Thing & string[]`) merges its `Array<E>` members, index
signature included, with the objects' members, so the intersection, an
alias of it and an interface extending that alias all type their
members and elements.

**Recursive generic object aliases; inference from the return context.**
A generic alias of a type literal that names itself (`type Thing<T> = {
pipe(a: T): Thing<T> }`) is one instance per argument list, as a generic
interface's is: printed by its alias, re-instantiated through its
arguments, and bounded in depth like interface instances. Code generation
holds such an instance boxed where it reaches itself, its object read by
its header. A generic call infers a type parameter no argument infers
from its return type against the call's contextual type (tsc's
ReturnType-priority inference, which also types its context-sensitive
arguments), candidates naming an enclosing call's type variables
dropped. An argument typed while its call's inference runs takes the
parameter instantiated with what the arguments before it inferred.

**Library-typed `any` contexts.** A callback passed where this compiler's
library declares the parameter `any`, or through a value that library
gives as `any` (an untyped listener's parameter), is not reported
implicitly any: Node's own declarations type those callbacks, and tsc
over them reports nothing. A program's own `any` (an annotated binding or
parameter, or a value initialized from one) still gives no contextual
signature (TS7006). An error message's source literal is widened unless
the target has literal members (null and undefined do not count until
object-literal freshness is modelled).

**`Function.prototype[Symbol.hasInstance]`; generic instance
intersections.** `Function.prototype` has `[Symbol.hasInstance]`, which
is OrdinaryHasInstance: the per-class `instanceof` rows the run-time
dispatch reads no longer call a class's own `@@hasInstance` (the
dispatch calls it first), so one that defers to
`Function.prototype[Symbol.hasInstance].call(this, v)` ends. A key known
only at run time reads `Function.prototype`'s methods on a function
value that has none of its own (`f[k]` with `k = "call"`). An
intersection with a generic interface's instance (`Set<number> &
Promise<any>`, `instanceof` an unrelated class) merges that instance's
members.

**`ThisType` over a generic instance; shorthand discriminants.** An
intersection of one object type, a generic interface's instance
included, with `ThisType<T>` is that type with `this` T in its methods. A
binding of a unit type written as a property (`{ kind, … }` with `const
kind = "a"`) discriminates a union context, as tsc's
isPossiblyDiscriminantValue counts an entity name.

**Method tuples, constrained elements, erased rest parameters.** A
class method annotated to return a tuple (`m(): [T, string]`) returns
the tuple, as a function does. An element read of a type parameter
constrained to an array or tuple (`o[0]`, `O extends Opt<any>[]`) is its
constraint's element. A `new` of a generic class whose argument infers
`any` (`new Opt(x as any)`) takes the type arguments of the instance its
context expects (`(): Opt<[number, string]>`), bound by the enclosing
instantiation and capped in depth, so the instance has the layout its
reader expects. A type parameter an instantiation leaves unbound (a
generic method's own) is laid out as its array constraint, and a rest
parameter typed by one erased is the boxed array its arguments fill. A
literal against a target that is only null or undefined is named as
itself, and against one with other members, widened (tsc's
typeCouldHaveTopLevelSingletonTypes, as reported per member).

**Class index signatures; index-key diagnostics.** A class body's index
signature (`[n: number]: T`) types its instances, and an object literal
built against the class's layout stores the keys the layout lacks on the
object itself. A string key that names a number (`o["3"]`) reads the
number index; a key of one literal type (an enum member) reads the
member it names. An element access tsc would suggest a `get`/`set`
method for reports TS7052; one keyed by no number on an object with only
a number index signature, TS7015; a missing key read off an object
literal itself, TS2339. A numeric property key too large for an integer
(`0b111…`) names the double it spells, `Infinity` past the largest. A
member keyed by a const (`[k]() {}`) is named as the resolver names it
in the corpus harness too.

**Type parameters under guards.** A read of a type parameter with a
union constraint (`x: T`, `T extends A | B`, or `keyof S`) narrows as
its constraint where its context mentions no type parameter or it is
read for a member, as tsc's getNarrowableTypeForReference substitutes
it. `typeof` and `instanceof` (a class's, a constructor value's, a
`[Symbol.hasInstance]` predicate's) narrow a type parameter to `T & K`,
K what of its constraint the guard admits: the parameter, constrained
to K, related to T as itself. The false branch drops a parameter whose
constraint is all the class's. A `switch (typeof x)` covering every
type of x's base constraint is exhaustive, its case labels plain or
template strings. In codegen, an instantiation that binds the
parameter to a primitive decides such a guard, and only the branch that
runs is emitted; a `.length` read of a number or boolean is read off its
box, `undefined`.

**Relations, calls and inference.** A distributive conditional
(`IsArray<T>`) relates through itself of its check type's constraint
before its branches (tsc's getConstraintOfDistributiveConditionalType).
An intersection of constructor types applies tsc's mixin rule: a
mixin's (`new (...args: any[]) => X`) instance is intersected into every
other member's construct signatures, and a class instance intersected
with plain interfaces keeps its own identity. An `instanceof` against a
constructor value narrows to the union of its construct signatures'
instances, generic ones erased. A union of signatures keeps a rest
parameter only where its longest member has one (on a tie, both). An
ambient class's constructor overloads, and a signature parameter with an
initializer, are what tsc reads. A spread argument counts the tuple
elements before it; a source signature's fixed tuple rest is spread
into one parameter per element when inferring. A call reports only its
first argument that does not fit, an object literal's properties widened
outside a literal context of their kind. A tuple pattern's leaves
(`const [ok, v] = r()`) narrow together, as an object pattern's do. A
tagged template's substitution is contextually typed by the tag's
parameter, and a generic tag keeps its substitutions' literal freshness.

**Const enums, suggestions, fresh literal reads.** A const enum object
has no reverse mapping: a key it lacks is TS2339, and a key that is not
a string literal TS2476. A property a type lacks, read or keyed by a
literal, names the closest property it has (TS2551, tsc's spelling
rule). An object literal read by a string or number key is the union of
its properties' types and undefined, with no implicit-any report. A
class member keyed by a `symbol`-typed expression gives the class tsc's
implicit symbol index. Overloaded method signatures in a type literal
are one overload list, as an interface's are. A function type's result
reads its parameters (`(x: F) => typeof x`). An empty destructuring
pattern checks only that its initializer is not nullish.

**Narrowing.** A non-null assertion of a type parameter whose constraint
admits null or undefined is `T & K`, K the constraint without them; a
truthy `T & K` keeps the truthy part of K. `o?.p instanceof C` makes `o`
non-nullish when true. A type with no string index narrowed by a guard
to one with (`{}` by `x is Record<string, unknown>`) becomes the guard's
type, as tsc's strict subtype rule picks it. A generic tag's signature
types its substitutions where they read none of its type parameters; a
class expression's static field is typed in its context's property,
keeping the literals it names. A message names an optional chain
without its `?.`.

**Tuple spreads.** In a tuple context an array literal with spreads is
a tuple: each spread tuple's elements in place, a spread array's or
rest tuple's rest its rest, the elements after joining it. Codegen
builds a fixed tuple from them, each spread tuple and each element
before it evaluated once, in order.

**`instanceof` of an absent reference.** A reference that may hold no
value (`o?.d`, an optional field) is no instance of Error, an Error
subclass, a builtin (Date, Map) or a host class; the statically decided
cases tested it as always present.

**Every clashing declaration.** A redeclaration reports at each of the
clashing declarations, the first one included, as tsc does (not a catch
variable's or an import's, which it reports otherwise); a duplicate
function implementation at every implementation. A block-scoped
variable's redeclaration is TS2451 alone, never also TS2403. An array
type intersected with a tuple of its elements (`number[] & [number,
...number[]]`) is that tuple.
A function's inferred result of one literal widens only where a return
makes it fresh (`return "b" as const` stays `"b"`). An object literal's
property against a type parameter's context is in its constraint's
property or string index, whose literals it keeps.
A tuple relates to an object type of numeric members (`{ 0: A; 1: B }`)
element by element. Codegen builds such an object from the tuple's
elements, and a spread literal in its context as a tuple first. `u ===
v` with v declared as an intersection does not narrow unknown, as tsc's
narrowing reads an intersection as no object type.
An array literal's element in a union context (`string | [string,
...H[]]`) is each array or tuple member's element at its index, and a
rest tuple's element is the one at its index, not the union of all.

A class may extend ArrayBuffer or SharedArrayBuffer. A class may extend the global Function. The resolver lowers it after the type check (so TypeScript sees the class as written): each `new C(…)` becomes a call of helpers emitted beside the class, which build the function with `new Function(…)` from the construction's (or the super call's) arguments where they are written, so constant source strings compile as any Function call's do, then give it C's prototype and define C's instance fields on it. An explicit constructor's body runs in its helper with `this` reading the instance and V8's ReferenceError before the super call; when its one super call only forwards its parameters (or constant strings) and the construction passes constant strings, the construction hands the helper a thunk making that function from them, called at the super call. To support this at run time, `Object.setPrototypeOf` on a function stores the prototype on the function's own-property bag (a function, as a prototype, standing as its bag), which property reads, `Object.getPrototypeOf`, and `instanceof` against a class, a constructor function or Function follow.

A typed array over a resizable ArrayBuffer tracks the buffer's length. Each view made over a growable buffer registers its header with the view registry (views.c), and `resize`/`grow` recompute every registered header's length word: a length-tracking view (no length argument) spans from its offset to the buffer's end, a fixed-length one keeps its length, and either reads length 0 while the buffer is too short for it. Bytes a buffer grows back into read zero. A view out of bounds this way throws V8's TypeError ("Cannot perform %TypedArray%.prototype.<method> on a detached ArrayBuffer") from the methods that validate their receiver and from its iteration (for-of, spread, destructuring, including through `any`), and its `byteOffset` reads 0. A global counter of out-of-bounds views keeps the check to one load while there are none. A typed array built as a general expression, or as the body of a class extending a typed array, is now built in its header's own fields, so that header is the one tracked.

Around this, several gaps on classes extending builtins closed. A class's static reads fall back to the builtin it extends (`MyU8.BYTES_PER_ELEMENT`, also through `any`). `new K(…)` through `any`, for a class with no constructor of its own up to a builtin, passes the arguments by count, as the builtin takes them. An element write through `any` on an instance of a class extending Array or a typed array writes the instance's elements, not a side property. `v instanceof Uint8Array` through `any` is true for an instance of a class extending it. A union of a typed array and a class instance is held as `any`. `new Function(…)` whose source a function builds from its own string parameters gets one constant-source arm per argument tuple its call sites pass as string literals, so the Test262 harness's `subClass(type)` compiles. The checker types an array pattern over a non-array iterable (a string, a Map, a typed array) as what the iterable yields, as tsc does. A closure that can fall off the end (`T | undefined`) in a slot whose function type returns T calls through an adapter that hands back T's undefined, instead of being rejected.

A callback that resizes a view's buffer mid-walk is now seen. In a program that may resize a buffer (one that names `resize` or `grow`, or passes `maxByteLength`), a typed array's callback methods read its header's length at each step, as the specification's `Get` does: an element past a shrunk length is `undefined`, and a grown tail is not visited. The `BigInt64Array`/`BigUint64Array` methods, written in TypeScript, capture the length once and do the same. `indexOf`, `lastIndexOf` and `includes` re-read the length after coercing `fromIndex` (whose `valueOf` may resize): the first two skip an element past it, `includes` reads it as `undefined`. `Array.prototype` methods called on a typed array (`Array.prototype.reduce.call(ta, …)`) run their array-like algorithm on the view itself rather than on a copy. `Object.defineProperty` on a typed array element past its length throws "Invalid typed array index", and a descriptor that would make an element an accessor, non-writable, non-enumerable or non-configurable throws "Cannot redefine property", as V8 does.

Several bugs found along the way were fixed. `includes` on a float typed array matches `NaN` (SameValueZero), and a `Float32Array` search no longer emits an integer compare on floats. `Array.prototype.keys` and `entries` called through `.call` no longer recurse into themselves. `Array.prototype.concat` has an array-like algorithm (`Symbol.isConcatSpreadable`), and a typed array passed to `concat` is appended whole rather than spread. `xs?.forEach(cb)` on an absent optional array short-circuits, and the checker gives the callback the context of the call's non-nullish callee. In JavaScript, a callback passed to a callee the checker cannot type (a method only one member of a union has) gets `any` parameters. An array pattern binding a `Map`'s entry (`const [e] = m`) holds the entry's tuple.
