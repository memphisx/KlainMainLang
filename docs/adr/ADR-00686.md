# ADR-00686: HOF callback with an untyped array parameter emitted invalid IR

- **Date**: 2026-09-03

## Context

The invalid-IR (CLANG_ERROR) backlog's largest concrete cluster was a value
`defined with type '{ ptr, i64 }' but expected 'i64'`. Repro:
`[11, 9].forEach(callbackfn)` where `function callbackfn(val, idx, obj) {}` — a
**named** function with untyped parameters. Its third parameter `obj` (the
array) defaults to `i64`, but `forEach` passes the array as a `{ptr,i64}`
aggregate, so the emitted call put an aggregate into a scalar slot: invalid IR,
clang failure.

## Investigation

`resolveCallbackWithHints` contextually types an *arrow*/function-expression
callback's parameters (so `(val, idx, obj) => …` gets `obj: number[]`), but a
**named** function's signature is fixed at its declaration, before the `forEach`
call is seen — the array hint can't reach it, so `obj` stays `i64`. `emitCBCall`
already reconciles arity (truncate extras, zero-pad missing params) to keep the
call well-typed, and coerces each argument to the callback's parameter type —
but `coerce(arrayValue, i64)` can't convert an aggregate to a scalar and returns
the array unchanged, so the mismatched operand reached the emitted call.

## Decision

Extend `emitCBCall`'s "always emit a well-typed call" rule: after coercing an
argument, if the parameter is a scalar but the coerced argument is still an
array (the coercion was impossible), substitute the parameter's zero value. The
callback sees a `0`/empty stand-in for a parameter it never typed as an array —
the honest outcome for untyped code that couldn't hold an array anyway — instead
of a hard clang-stage crash. A *typed* callback (`obj: number[]`) is unaffected:
its parameter is already an array, so the aggregate passes through normally.

## Verification

Mac. `[11, 9].forEach(callbackfn)` (named, untyped 3-arg) compiles and runs. In
`built-ins/Array` Test262 alone this cleared 8 invalid-IR files and lifted
passes 142→149; the fix is general across every array HOF (`map`/`filter`/
`some`/`every`/`reduce`/…). Full array-HOF regression green.
