# ADR-01493: `(a, b)` is the comma operator unless an arrow follows

- **Relations**: Supersedes the lookahead in ADR-00179
- **Date**: 2026-10-09

## Context

`const c = (a, b)` was a parse error ("expected =>"). An open parenthesis
followed by a name and a comma was taken as an arrow function's parameter
list, whatever followed the group.

## Investigation

- The defaulted-parameter case (`(p = 1) => …`) already scanned to the
  group's `)` and looked for `=>` or a return-type `:`.
- A `:` after the group is also a conditional's alternative: `c ? (a, b)
  : 0`. Taking every `:` as a return type turned that into an arrow.

## Decision

- `(name, …` starts an arrow only when the group is followed by `=>`, or
  by `:` and a return type that `=>` follows at its own depth before the
  expression could end (`returnTypeThenArrowAt`): `;`, `,` or a closing
  bracket of the enclosing expression.
- The defaulted-parameter case uses the same test.
