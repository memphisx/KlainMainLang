# ADR-01651: A class iterates only through Symbol.iterator

- **Relations**: Implements [TDD-00230](../../tdd/TDD-00230.md) (P3.3, values and representation)
- **Date**: 2026-10-16

## Context

A class declaring a zero-argument `next(): T | null` iterated in `for…of`
and `Array.from` with no `[Symbol.iterator]` ([TDD-00009](../../tdd/TDD-00009.md)
Stage 1a, [ADR-00063](../00/ADR-00063.md)): a compile-time structural check
matching no standard. tsc rejects both uses (TS2488); Node throws
`TypeError: c is not iterable` from `for…of` and reads the object as an
array-like (`[]`) in `Array.from`.

## Investigation

The checker had no TS2488. Codegen dispatched the `next()` shape in
`emitForOf` (`emitForOfClassIterator`), `emitArrayFrom` and its inference.

Rewriting the tests and examples that relied on the shape to drain `next()`
through a generator `[Symbol.iterator]` exposed four defects on that path:

- A for…of over an iterator object bound its variable to the result's
  `value` type, `T | undefined`, and stored the `{ i1, T }` aggregate into a
  bare `T` slot (invalid IR).
- An unannotated generator yielding `null` beside another type was rejected
  as having element types that do not join.
- A nullable scalar element was stored with its bare type in the
  generator's yielded slot, its absent zero, and the loop variable's slot.
- A generator method's yields were inferred with `this` unbound, and a
  later-declared annotated sibling (`this.next()` above `next(): Nd | null`)
  had no forward result, so the element type fell back to `i64`.

## Decision

- The checker reports TS2488 for a for…of over a class instance with no
  `[Symbol.iterator]` of its own or a base's (`checkIterable`).
- Codegen deletes the structural shape: for…of over such an instance throws
  Node's TypeError; `Array.from` reads it as an array-like with no `length`
  (an empty `any[]`), and so does its inference.
- A for…of over a generator binds what the generator yields when that is
  not itself nullable.
- `yield null` joins as `T | null`; the yielded slot, its absent value and
  the loop variable use the nullable storage type.
- A generator method's element type is inferred with `this` bound, and
  `inferForwardMethodResults` records each annotated sibling's declared
  result.

## Consequences

- `TestE2EForOfClassNextOnlyNotIterable` covers both lanes; the former
  structural tests and `examples/classes/classes.ts`,
  `examples/arrays/array_methods.ts` and
  `examples/nullable_scalars/nullable_scalars.ts` drain `next()` through
  `[Symbol.iterator]`.
