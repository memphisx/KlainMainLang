# ADR-01460: Narrowed nullable property reads

- **Relations**: Implements TDD-00230 (P2.5); extends ADR-01442
- **Date**: 2026-10-07

## Context

A shadow bucket (170 rows, `kml_event_target.ts`) was
`this.#dispatching && this.#currentTarget !== null ? [this.#currentTarget]
: []`: codegen typed the array's element as a possibly-null
`EventTarget`, the checker as `EventTarget`. ADR-01442 had applied the
checker's narrowing to variables only.

## Decision

`checkerPresentRef` takes a property read as well as a variable: a nullable
instance, function, promise or object property the checker's flow type
proves present reads as present, in `inferExprType` and in `emitExpr`'s
member read alike, and the oracle mirrors it.

## Verification

- `TestE2ENarrowedNullableMembers` (against Node); the discriminant,
  literal, union and narrowing E2E tests pass on the Mac.
