# ADR-01526: Date's calendar fields compose as ECMAScript's MakeDate

- **Relations**: Extends TDD-00240
- **Date**: 2026-10-10

## Context

`Date.UTC` and `new Date(y, m, …)` composed their fields as integers:
`Date.UTC(NaN)` and `new Date(2020, NaN)` were valid times, a fractional
or out-of-range field wrapped, and `Date.UTC()` was year 0. Called
through its value (`const f = Date.UTC; f(2020)`), every omitted field
arrived as `undefined` and read as 0, so the day was the 0th.

## Decision

- `__kml_date_fields` (C) is MakeDate(MakeDay, MakeTime) over each
  field's ToIntegerOrInfinity, in doubles: NaN when one is not finite, a
  year 0-99 as 1900+year, a month overflowing into the year.
  `__kml_date_timeclip` is TimeClip. `Date.UTC` returns the clipped
  number; the constructor stores NaN as Invalid Date.
- A present field is ToNumber'd; an absent one takes its default (none
  for the year).
- `Date.UTC` as a value takes its arguments as a rest and counts them,
  so an absent field defaults and an `undefined` one is NaN; its
  `length` is 7.
