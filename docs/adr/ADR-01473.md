# ADR-01473: A generic class instantiated where a type names it

- **Relations**: Extends ADR-01471
- **Date**: 2026-10-08

## Context

With `klain:sync`'s `Channel<T>` a generic TypeScript class (ADR-01471),
apps/loadtest's engine.ts failed to compile: `class
'Channel__…__num' has no method 'recvCase'`. Its functions take
`stop: Channel<number>` and call methods on it; the channels are made in
main.ts.

## Investigation

- Reduced to one file: a function `show(b: Box<number>)` calling `b.get()`,
  declared before the program's `new Box<number>(…)`, fails the same way;
  with the `new` first it compiles.
- A generic class is instantiated (its methods registered and emitted) only
  at a `new` site (`instantiateGenericClass`, codegen/llvm/emit_generics.go).
  An annotation resolves to the instantiation's type through
  `genericClassInstanceType`, which builds the type without registering the
  class, so a method call through it found no class and fell to the generic
  "has no method" error (emit_call.go). The existing on-demand path covered
  only a receiver that is itself the `new` expression.
- Type inference cannot instantiate, since inferring never emits: a method's
  result through such an annotation inferred as the default number
  (`b.get().toUpperCase()` on a `Box<string>` failed).

## Decision

- `genericClassInstanceType` records each instantiation's class and type
  arguments (`genericInstSrc`); `ensureGenericInstance` instantiates a
  recorded one on its first method call (`emitCall`'s class dispatch and
  `emitClassCall`).
- Inference of a method call on a recorded, not yet instantiated class
  substitutes the method's declared result type
  (`genericInstMethodRet`), without emitting.

## Implementation notes

codegen/llvm/emit_generics.go, emitter.go, emit_call.go, emit_classes.go,
emit_exprs_types.go; tests/generics_test.go.

## Side effects discovered

None.

## Verification

`TestE2EGenericClassAnnotatedBeforeConstruction` (a method, a getter, a
method returning the instantiation and a `Box<string>` result, output as
Node's); the generic-class E2E tests; apps/loadtest compiles.
