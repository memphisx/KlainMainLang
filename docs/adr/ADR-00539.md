# ADR-00539: optional chaining `arr?.prop` on an array no longer miscompiles

- **Relations**: Extends ADR-00061
- **Date**: 2026-08-31

## Context

`a?.length` where `a` is an array (`const a: number[] = [1,2,3]`) produced
invalid LLVM IR — a clang-stage type error, `'%t' defined with type '{ ptr, i64
}' but expected 'ptr'`. Optional chaining worked on objects, strings, and array
*method* calls (`a?.map(...)`), so the miscompile was specific to a property
access (`?.length`) on an array receiver.

## Investigation

`emitOptionalMember` (`emit_exprs_member.go`) falls back to a plain member
access for a non-`ptr` receiver ("cannot be null"), then otherwise emits an
`icmp eq ptr %obj, null` null check. An array's `Ty.IR` is `"ptr"`, so it passed
the guard — but an array *value* is a `{ ptr, i64 }` aggregate, not a bare
pointer, so the `icmp eq ptr` against it was ill-typed. Arrays are never a null
pointer in this model: a non-nullable array is always a valid aggregate, and a
nullable array (e.g. a `RegExp.exec` result) uses the `{ null, 0 }` *value*
sentinel, whose own `.length` is already `0`.

## Decision

Extend the plain-access fallback guard to also cover arrays
(`objVal.Ty.IR != "ptr" || objVal.Ty.IsArray`). `arr?.prop` becomes `arr.prop`,
which handles `.length` (and every other array member) correctly. For a nullable
array the `{ null, 0 }` sentinel's `.length` is `0` — consistent with this
compiler's existing zero-for-absent convention (ADR-00157).

## Implementation notes

`emit_exprs_member.go` only — one condition. Array *method* calls
(`a?.map(...)`) already took a different, working path, so they are unaffected.

## Side effects discovered

Optional *index* access on an array (`a?.[0]`) is a separate, still-unsupported
form — it fails at parse time (`?.[` is not lexed), a clean error rather than a
miscompile, and out of scope here.

## Verification

`TestE2EOptionalChainingArray` (new): `a?.length`, an empty array's `?.length`,
and `a?.map(...).join(",")`, cross-checked against real Node. The existing
optional-chaining suites pass. Verified on Mac (Apple Silicon).
