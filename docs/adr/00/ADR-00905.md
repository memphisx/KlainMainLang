# ADR-00905: `return <value>` inside a constructor

- **Date**: 2026-09-12

## Context

Invalid-IR sweep. A constructor returning a value emitted invalid IR:

```ts
class Derived extends Base { constructor() { super(); return 0; } }
// clang: ret double 0x0 — in a void function
```

From `language/statements/class/subclass/derived-class-return-override-with-{boolean,null,number,string,symbol}.js`.

## Investigation

A constructor's LLVM result type is `void` — the caller holds the allocated
`this` and the constructor fills it. `emitReturn` (`emit_stmts.go`) had no
constructor-specific handling, so a `return <expr>` evaluated the value and
emitted `ret <value>` against the void signature.

JS semantics: returning `undefined` is a normal return (yields `this`); returning
an object overrides the instance (return-override); returning a primitive is
*ignored* in a base class but a **TypeError** in a derived class (spec step 13.c).

## Decision

Intercept `return <expr>` when `e.currentCtorClass != ""`. Evaluate the operand
for side effects, then by its inferred type:

- `undefined`/`void` → ordinary `ret void` (yields `this`).
- Symbol (a primitive that reuses the object IR) → derived: throw TypeError;
  base: ignore.
- object/array/dynamic → **reject at compile time**: return-override of the
  instance is not expressible under the void constructor ABI (a documented
  limitation; it was already invalid IR, so a clean error is strictly better).
- any other primitive → derived class (`info.BaseClass != ""`): emit a runtime
  TypeError; base class: ignore, normal return.

## Implementation notes

- `e.classes[currentCtorClass].BaseClass` distinguishes derived from base.
- `emitThrowTypeError` emits the throw + `unreachable` (sets `blockDone`).
- The Symbol case is tested before the object branch because a Symbol is
  `IsObject` in this type system.

## Side effects discovered

Object return-override (`constructor() { return someObj; }`) is now a clean
rejection rather than invalid IR — a genuine ABI limitation, deferred.
