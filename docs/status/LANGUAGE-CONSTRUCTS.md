# Language Constructs

> Part of the [Implementation Status](README.md) index. Covers control flow, operators, variable declarations, functions/closures, async/Promise, enums, interfaces, and classes/OOP.

**Coverage**: 64/65 rows on this page, ~98% (see the index's Coverage Summary for the breakdown by sub-category).

**Strict Coverage**: 35/65, ~54% — a row only counts here if it was independently repro-verified with zero known caveats or bugs, of any severity. See the 2026-08-11 audit ([ADR-00166](../adr/ADR-00166.md)) that produced the baseline 34/65; the nullish coalescing `??` row cleared its last caveat when nullable non-pointer scalars gained a real presence bit ([TDD-00064](../tdd/TDD-00064.md)/[ADR-00199](../adr/ADR-00199.md)). Every remaining caveat still excludes its row from this count even though the row stays ✅ in the Coverage column above.

**Caveats**: TDD-00009 is now fully implemented (Stages 0-4) — `class` has real single inheritance (`extends`/`super`), `static` members/`static {}` blocks, `private`/`protected` visibility (compile-time-only, matching real TypeScript's own erasure), `abstract` classes/methods, and `implements` (a compile-time-only structural self-check, not polymorphic dispatch through an interface type) — see [ADR-00083](../adr/ADR-00083.md) (Stage 3) and [ADR-00084](../adr/ADR-00084.md) (Stage 4). Real JS/TS `#x` runtime-private field syntax — a *different* mechanism from the `private` keyword modifier, with a real observable difference (genuine reflection-hiding, not just type-level erasure) — is now done too, see [TDD-00021](../tdd/TDD-00021.md)/[ADR-00155](../adr/ADR-00155.md). Class-field-initializer syntax (`x = 1;`, `n: number = 1;`, `#x = 0;` inline, private or public — [TDD-00063](../tdd/TDD-00063.md) Stage 1 / [ADR-00180](../adr/ADR-00180.md)) is now done for **instance** fields: initializers run at construction time in declaration order, right after super() in a derived class, and a class whose every field initializes itself no longer needs an explicit constructor. Static field initializers (`static x = 1`) stay a clean rejection (they'd run in the class's `staticinit`, a separate mechanism — use a `static {}` block); an initializer that lowers into the constructor body can currently see the constructor's own parameters, which real JS's separate initializer scope forbids; an unannotated initializer of an expression shape the compiler doesn't specifically recognize falls back to `i64`. Async methods (`async m(): Promise<T>`, instance or static, including one awaiting another via `this`) are now done too — [TDD-00063](../tdd/TDD-00063.md) Stage 2a / [ADR-00181](../adr/ADR-00181.md) — reusing the top-level async coroutine path unchanged. Instance generator methods (`*m()`, driven by `for...of` or `.next()`, yielding from `this` fields, in derived classes) are now done as well — Stage 2b / [ADR-00182](../adr/ADR-00182.md) — the generator fiber captures the receiver in a `__this` slot; static generator methods and async generators (`async *m()`) stay a clean rejection. Computed member names are now done for a compile-time-constant string/number key (`['foo']() {}`, `[0]() {}`, `['x']: T = v`, `get ['y']()`), desugared to the equivalent named member — Stage 3 / [ADR-00184](../adr/ADR-00184.md); a dynamic key (identifier, call, `Symbol.*`, interpolation) is a clean rejection, so well-known-symbol keys like `[Symbol.iterator]` stay out of scope. Class expressions are now done too — Stage 4 / [ADR-00185](../adr/ADR-00185.md): a top-level `const/let/var X = class {...}` binds a nominal class under the LHS name (usable as `new X()` and as a type annotation, inheriting every Stage 1–3 member), since classes are compile-time nominal types here, not first-class runtime values. A class expression used as a runtime value (an argument, a return, a nested binding) or a named self-reference (`class D {...}` where the body references `D`) is a clean rejection, and `extends <expression>` stays out of scope. No early-error validation for a `#name` colliding across static/instance in the same class, or `#constructor` specifically banned as a name (both real, narrow gaps found running the Test262 conformance harness against real-world `#`-using code, deferred rather than fixed). `async`/`await` is a synchronous resolved-slot read for everything except `await fetch(...)`, which is genuinely non-blocking (yields via a fiber inside an `http.listen` handler) — see [TDD-00006](../tdd/TDD-00006.md). Numeric separators, optional catch binding, and logical assignment operators are now done — see [ADR-00085](../adr/ADR-00085.md)/[ADR-00086](../adr/ADR-00086.md)/[ADR-00087](../adr/ADR-00087.md). Destructured function parameters are now done too — see [ADR-00109](../adr/ADR-00109.md). Getters/setters on classes are now done too — see [TDD-00030](../tdd/TDD-00030.md)/[ADR-00110](../adr/ADR-00110.md); object-literal getters/setters remain out of scope (an object literal's `Type` is pure structural value-equality with no name to hang an accessor table off). Nested function declarations are now done too, V1-scoped — see [TDD-00057](../tdd/TDD-00057.md)/[ADR-00149](../adr/ADR-00149.md). An unannotated function forward-referencing another unannotated, later-declared function's non-scalar return type ([ADR-00041](../adr/ADR-00041.md)'s originally-accepted boundary) is also now resolved by a bounded fixed-point re-inference sweep — see [TDD-00058](../tdd/TDD-00058.md)/[ADR-00150](../adr/ADR-00150.md); a genuinely circular pair of mutually-recursive unannotated functions still can't converge and keeps the old scalar-default fallback, not a new failure mode. Tagged template literals are now done too (desugared to a plain call; no `.raw` property on the `strings` array) — see [TDD-00059](../tdd/TDD-00059.md)/[ADR-00151](../adr/ADR-00151.md). Array-typed arrow-function/closure parameters (including rest params, and by extension an arrow function as a tagged-template tag) are also now fully supported, closing the gap ADR-00151 itself had only narrowed to a cleaner rejection — see [ADR-00152](../adr/ADR-00152.md). Function expressions support both the anonymous and named forms; a named function expression binds its own name inside its body for self-reference/recursion (a name shadowing a top-level function of the same name is the one remaining clean-error case) — see [TDD-00060](../tdd/TDD-00060.md)/[ADR-00168](../adr/ADR-00168.md)/[ADR-00178](../adr/ADR-00178.md). This compiler still has no general strict-mode parser context or block-scope (`let`/`const`-vs-`var`) redeclaration tracking, so 7 Test262 early-error cases around a literal `"use strict"` directive (reserved words as object-literal shorthand properties, a legacy octal escape in a directive prologue, block redeclaration, and one case with no literal `"use strict"` marker the harness can detect at all) stay unrejected; a narrower, unconditional-where-safe subset — duplicate parameter names, and a non-simple parameter list or `eval`/`arguments` as a parameter name specifically under a literal `"use strict"` directive — is caught. Adding class field initializers ([ADR-00180](../adr/ADR-00180.md)) and async methods ([ADR-00181](../adr/ADR-00181.md)) surfaced the same class of early-error gaps function expressions did (a construct that used to be rejected wholesale now parses, so its own early-error rules start to matter): a `static` member named `prototype` and `eval`/`arguments` as a class-method parameter name are now rejected, but a field initializer containing `arguments` or a `super()` call, a `super()` call in a method parameter default, field-definition ASI on the same line (`field = 1 method(){}`), and the `#constructor` private-name ban all still compile instead of raising the spec's `SyntaxError` (each needs an initializer-expression "Contains" walk or line-terminator tracking, not just a name check) — deferred, no valid program miscompiles.

## Known Limitations

| Limitation | Notes |
|---|---|
| A logical compound assignment (`??=` / `&&=` / `||=`) on a nullable-scalar *field* is not presence-aware | The presence-flagged `number \| null` representation ([TDD-00064](../tdd/TDD-00064.md)/[ADR-00199](../adr/ADR-00199.md)) routes every other form — bare `??`, `??=`/`&&=`/`||=` on a *local*, `=== null`, reads, printing, JSON — through the real presence bit, but a logical compound assignment targeting a nullable-scalar object/class *field* (`obj.n ??= 5`) still goes through the generic pointer-null path, so it reads the field's `{ i1, T }` slot as a bare scalar. Niche (the common case is a local); a plain `obj.n = ...` assignment on such a field is correct. |
