# ADR-00851: Optional chaining on a nullable-scalar receiver (`map.get(k)?.m()`)

- **Relations**: Follows the `Map.get` → `V | undefined` flip (ADR-00794 family), extends optional-call ([ADR-00834](ADR-00834.md))
- **Date**: 2026-09-10

## Context

Once `Map<K, number>.get()` began returning a `{ i1, T }` nullable scalar
(`number | undefined`) rather than a bare `number`, `map.get(k)?.toFixed(1)`
broke two ways:

- **Codegen**: `emitOptionalCall` classified a non-`ptr`, non-array receiver as
  "can never be null" and ran the method directly on the `{ i1, double }`
  aggregate — `'%t' defined with type '{ i1, double }' but expected 'double'`.
- **Inference**: `inferExprType` for `?.` (both member and call) only widened the
  result to `T | undefined` when the receiver's IR was `ptr`, so a nullable-scalar
  receiver produced a plain `T`. `map.get(k)?.toFixed(1) === undefined` then
  folded to a compile-time `false`.

A nullable-*pointer* receiver (`Map<K, string>`) was unaffected — its null *is*
the pointer, so it already flowed through the pointer path.

## Decision

- `emitOptionalCall` gains a nullable-scalar branch (`emitOptionalCallNullableScalar`):
  unwrap the `{ i1, T }` into its presence bit and payload, bind the bare payload
  as the receiver, and guard the call on the presence bit — the `absent` state
  short-circuits to a real `undefined`, mirroring the pointer path's merge shape.
- `inferExprType` widens a `?.` member read and `?.` call to `T | undefined` when
  the receiver is a nullable scalar, not only when it is a `ptr`.

## Implementation notes

`emit_call.go` (`emitOptionalCall` dispatch + `emitOptionalCallNullableScalar`);
`emit_exprs_types.go` (both `?.` inference sites gain `|| isNullableScalar(objTy)`).
The optional member *read* (`map.get(k)?.length`) already worked; only the call
path and the inference needed the fix.

## Verification

macOS (Apple Silicon M4): matches Node — `Map<string, number>` `get("a")?.toFixed(1)`
→ `1.0`, `get("z")?.toFixed(1)` → `undefined` and `=== undefined` → `true`; the
string-valued map (`get()?.toUpperCase()`) unchanged. `TestE2EOptionalCallUndefinedResult`
extended with the scalar case + the optional-chaining/map/nullable/undefined
suites green.
