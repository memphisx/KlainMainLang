# ADR-00589: process.execFileSync cwd option

- **Relations**: Extends [ADR-00025](ADR-00025.md)
- **Date**: 2026-09-01

## Context

`process.execFileSync(file, args?)` took no options object, so a caller couldn't
run the child in a different working directory — a common need.

## Decision

Accept a trailing options object with `{ cwd, encoding }`:

- `__kml_exec_file_sync` gains a `cwd` pointer parameter (null = no change); in
  the forked child, when non-null, it `chdir(cwd)`s before `execvp`.
- The emit side accepts `execFileSync(file, options)`, `execFileSync(file, args,
  options)`, and the existing `(file, args?)` forms — the 2nd argument is the
  options object when it is an object literal, otherwise the args array (matching
  Node's overload). An empty `[]` args array is handled directly (no element
  type to infer). `encoding` accepts only `'utf8'` (the default string result);
  any other option key is a clean rejection.

## Verification

`TestE2EProcessExecFileSyncCwd` runs `pwd` with `{ cwd: "/" }` and asserts `/`,
plus the plain no-options form still works. Built and verified on Mac (Apple
Silicon).
