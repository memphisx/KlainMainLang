# ADR-00907: parseInt ToNumbers a string radix

- **Date**: 2026-09-12

## Context

Invalid-IR sweep. `parseInt` with a string radix emitted invalid IR:

```ts
parseInt("11", "2")   // clang: strtoll(ptr, ptr, i32 <string ptr>)
```

From `built-ins/parseInt/S15.1.2.2_A3.1_T2.js`.

## Investigation

`emitParseInt` (`emit_call_number.go`) coerced the radix with `coerce(rv,
TypeI32)`. For a string operand `coerce` has no ToNumber, so the string pointer
reached `strtoll`'s `i32` base argument unchanged. Per spec the radix is
`ToInt32(ToNumber(radix))`.

## Decision

When the radix is a string, run the real ToNumber (`__kml_to_number`) to a double
then `coerce` to `i32`; when dynamic, ToNumber via `emitAnyToNum`; otherwise
coerce directly as before. `ToNumber("2")`→2, `ToNumber("0")`/`ToNumber("")`→0,
and base 0 lets strtoll parse "11" as decimal — matching
`parseInt("11","0") === parseInt("11",10)`.

## Implementation notes

`__kml_to_number` (the same helper `Number(str)` uses) gives JS ToNumber(string).

## Side effects discovered

None.
