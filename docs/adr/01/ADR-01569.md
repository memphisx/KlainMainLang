# ADR-01569: A property of a boxed value takes the dynamic dispatch's type

- **Relations**: Extends ADR-01562, Implements TDD-00230
- **Date**: 2026-10-11

## Context

ADR-01562 makes a method call on a value held boxed take the type its
dynamic dispatch returns. The callee of that call is a member read, and
the call's emission picks its path from the callee's type. In the
`-compat=js` lane the checker types an unannotated parameter from its call
sites (`function f(s) { … }` called with a string types `s` as `string`),
while codegen stores the parameter as `any`. The checker then typed
`s.substring` as a string method, and emission called the boxed property
word as a typed closure pointer: `'%t' defined with type 'i64' but
expected 'ptr'` from clang. Test262's js lane hit it in 578 files, and
the strict lane in 33.

## Decision

`inferExprType` types a non-optional member read whose receiver is an
unconstrained `any` (no `DynPropTy`) with `structuralMemberType`, the
dispatch's own type, before asking the checker. This is the member-read
counterpart of the call rule in `codegenCallRepr`.

A member read directly on a name with no binding is excluded
(`unboundName`): a builtin namespace or global (`[4, 9].map(Math.sqrt)`,
`console.log` passed as a callback) types as `any` too, but its member is a
builtin function value that emission builds itself. A first version without
the exclusion failed four E2E tests on those. A second version applied the
rule only to receivers rooted at a bound name, which still left
`Array.prototype.entries.call(…)` reading a boxed word as a closure (548
Test262 files).

Two more receivers read a property off a box, and take the dispatch's
type the same way:

- a field whose slot the object's layout holds boxed (`{ normalize:
  String.prototype.normalize }`, whose initializer was itself a dynamic
  read), so `myobj.normalize()` calls the box;
- a property of a function value other than its own (`g.toString`), read
  off the boxed function. `toString()` on a statically-typed function
  stays the compile error the status page lists; before this rule it was
  invalid IR.

## Verification

A js-lane program reading `.length` and calling `.substring` on a
call-site-typed parameter prints Node's output. Test262
`annexB/built-ins/String` js lane: no CLANG_ERROR. Linux (DeskMini and
Node304 kmlbox) full gates.
