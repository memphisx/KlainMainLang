# ADR-02044: An unsound cast to a primitive keeps the value

- **Date**: 2026-11-22

## Context

- `f("s" as unknown as number)` passed NaN, and
  `const v = "x" as unknown as number` held NaN. The asserted type's
  representation (an f64) cannot hold the string Node keeps.

## Decision

- Over the checked program, `x as unknown as T` (or through `any`), T
  `number`, `string`, `boolean` or `bigint` and x's type not T's, becomes
  `x as any` (`boxUnsoundScalarCasts`).
- A parameter it is passed to takes the any-argument check, whose
  alternate entry binds the parameter as the box. An unannotated binding
  of it holds the box (`anyHeldDecl`).

## Consequences

- Tests: `TestE2EUnsoundScalarCastTS`.
