# ADR-01219: A union of object types needs no discriminant

- **Relations**: `Extends TDD-00116`, `Extends ADR-01215`
- **Date**: 2026-09-28

## Context

A union with two or more object members had to be a discriminated union
(TDD-00116): each member needed a shared first-position string-literal
tag. `string | URL | RequestOptions` did not qualify, so the builtin
`http.request` could not take a URL, and `res.setHeaders(new Headers(…))`
was refused (BACKLOG 71). A union of two classes (`A | B`) narrowed by
`instanceof` was rejected outright.

## Investigation

- The union box holds an object as it is, and since the header word
  (TDD-00230 phase 5) each object identifies itself:
  - a class instance by its TagID;
  - a plain object by its layout id, read through the checked view
    (ADR-01215);
  - a host handle by its host box.
- A headerless host object (`URL`, a struct of fields) has no header, so
  it is the union's one object whose first word lacks the header magic.
- Codegen narrowed a union local by `typeof`, truthiness and a
  discriminant only. The checker's narrowed type for an `instanceof` guard
  on a class union is not readable from codegen: `TypeOf` answers an empty
  anonymous object type.
- `hostClassName` answered `Object` for a URL: `IsObject` comes before
  `IsURL` among the type's flags.

## Decision

- `validateUnionMembers` accepts several object members when each
  identifies itself (`selfIdentifyingObjects`): classes, plain object types
  with a header, host handles, and at most one headerless host object.
- Codegen narrows a union local in if/else branches and after an early
  exit by:
  - `x instanceof C`: the members that are C or derive from it, or the
    host class C;
  - `"k" in x`: the members declaring k;
  - a call to a type guard `g(x)` declared `p is T`: the members T names
    (`guardUnionNarrowing`).
- A conditional expression whose test narrows a union local emits and
  infers each branch in its narrowed scope (`emitNarrowedConditional`,
  `narrowedCondBranchTypes`). The result keeps the branches' type when they
  share one representation, and is boxed otherwise.
- `x instanceof URL` on a union tests the box for an object without a
  header (`emitBoxIsHeaderless`). `"k" in x` on a union tests the box at
  run time.
- A member every object member declares reads by name before narrowing
  (`unionCommonMember`).
- The checker's narrowed type selects an object member by name
  (`objectMemberNamed`) when it names one.
- `http.request`/`get` and `https.request`/`get` take
  `string | URL | RequestOptions`, converting a URL as Node's
  `urlToHttpOptions` does.
- The checker types a type literal's method, call and construct
  signatures, as it does an interface's (`withSignatures`). `declare var
  URL: { prototype: URL; new (…): URL; … }` was unanswered, so
  `x instanceof URL` narrowed nothing. `URL.createObjectURL` takes a `Blob`,
  as @types/node declares it; the lib.dom `MediaSource` is undeclared here.
- The conditional-expression path is taken for the object guards
  (`instanceof`, `in`, a type guard); a `typeof` test keeps the general
  path, which narrows through the checker.
