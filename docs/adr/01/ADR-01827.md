# ADR-01827: localeCompare collates by ICU root order

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- `localeCompare` compared bytes. `'apple'.localeCompare('Banana')` was 1 (Node: -1), `'é'` sorted after `'z'`, and `options` was a compile error.
- Node's default locale (`en`) collates by ICU's root order, CLDR's tailoring of the Unicode Collation Algorithm (UCA). Embedding ICU would add tens of megabytes to every binary that compares strings.

## Decision

- **Weights generated from Node.** `tools/gencollate/gen.cjs` writes `collatesrc/collate_tables.h` from the running Node's `Intl.Collator`, reading each level off a sensitivity:
  - **Primary:** the order of the characters compared at `base` sensitivity, with equal characters sharing a weight. A letter equal to two letters (`ß`/`ss`, `æ`/`ae`, `ĳ`/`ij`) expands to their elements.
  - **Secondary:** a decomposable character is its NFD base followed by its combining marks. Each mark is a secondary-only element, ordered by `accent` comparison. An accent variant without a decomposition (`ø`) gets its rank within its primary group. An expansion that differs at `accent` sensitivity (`ß`) takes a secondary above every accent.
  - **Tertiary:** the rank by `variant` comparison within a secondary class, so lowercase comes first. A compatibility ligature (`ﬁ`) falls between lowercase and uppercase.
  - **Case bit:** whether the character is uppercase.
- **Coverage:** every BMP script, symbol and presentation form, mathematical letters and emoji. Characters ICU ignores map to no element.
  - BMP Han ideographs (Extension A, the unified block, and the compatibility ideographs as their canonical equivalents) get a radical-stroke rank table, also read off ICU.
  - A Hangul syllable decomposes to its jamo at run time, as the UCA defines it.
  - Any other character sorts after all of these, by code point.
- **Comparison (`collate.c`):** compare primaries, then secondaries, then tertiaries, skipping zero weights at each level. The result is exactly -1, 0 or 1, as V8 returns.
- **Options:** the options value is read at run time, through a compiled snippet over it boxed as `any`.
  - `sensitivity` selects the levels: `base` primary only; `accent` adds secondary; `case` is primary plus the case bit; `variant` (the default) uses all three.
  - `numeric: true` makes a run of ASCII digits one element: a digit against anything else, and by value against another run.
  - `locales` is evaluated and ignored.
- Each table is compiled only into programs that call `localeCompare`.

## Consequences

- Probed against Node 24 (ICU 78.3): a 55-word matrix across scripts, cases, ligatures and expansions, plus 20,000-pair seeded random runs over a mixed pool at every sensitivity, numeric included, all match exactly. `TestE2EStringLocaleCompareCollation` covers it, and `examples/strings/locale_compare.ts` shows it.
- What is left:
  - a locale's tailoring (Swedish `å` after `z`, Turkish `i`);
  - the `caseFirst`, `ignorePunctuation` and `usage` options;
  - radical-stroke order for supplementary-plane Han (Extension B and later), which sorts by code point.
- Regenerating the tables with a newer Node picks up ICU's newer root order.
