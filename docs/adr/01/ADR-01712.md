# ADR-01712: A generator's mixed yields are a union

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-18

## Context

When a generator had no element-type annotation and its yields had different representations (`yield 1; yield [2]`), compilation failed with "requires an explicit return type annotation". TypeScript infers `Generator<number | number[]>`, and Node runs the program.

## Decision

When the yields don't join into one representation, the element type is `any`: each value is held boxed, which is how a union of those types is held everywhere else.

## Verification

macOS (Apple Silicon): `TestE2EGeneratorUnionYields` and the `Generator` E2E tests pass; numbers, arrays, strings, objects and a boolean return match Node.
