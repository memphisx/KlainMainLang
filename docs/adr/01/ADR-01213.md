# ADR-01213: A static object in a union or `any` renders and enumerates from its row

- **Relations**: `Implements TDD-00230`, `Extends ADR-01210`
- **Date**: 2026-09-28

## Context

- An array or field of a union with an object member (`(P | number)[]`)
  printed a class instance as `[object Object]`; Node prints `P { x: 1 }`.
- A plain object in `any` listed an omitted optional field
  (`{ a: 1, b: undefined }`, `Object.keys` → `['a', 'b']`), where its
  statically typed binding and Node list `a` only.
- `Object.values`/`entries` of a static object in `any` returned `[]`.
- A `Headers` whose one-line form fits Node's width printed on several
  lines.

## Investigation

- `emitInspectField` rendered a union from its box only when every member
  was a scalar or an array (`isSelfDescribingBox`). An object member was
  stringified, because a boxed object had no shape before the layout table.
- The layout row's getter reported every declared field as found.
- The dynamic `Object.values`/`entries` handled bags and arrays only.

## Decision

- A union whose members are scalars, arrays, `null`/`undefined` and
  objects with a header word (a class instance or a plain object, not an
  Error or a host object) renders from its box (`inspectsByTag`).
- A row's getter reports an omitted optional field as absent (found 0), so
  `in` and every key walk skip it: dynjson.c's render and serialize
  (through the new `__kml_obj_has` hook), `__kml_shape_keys_array` and
  `emitShapeValuesArray`.
- The dynamic `Object.values`/`entries` walk a static object's row.
- `Headers` prints as undici formats it: the entries as an object, then
  the `Headers ` prefix, which does not count toward the 80-column break
  (a 79-column line wrapped).

## Implementation notes

`codegen/llvm/emit_inspect.go`, `emit_inspect_host.go`, `emit_shape.go`, `emit_record_view.go`,
`emit_dynobj.go`, `dynjsonsrc/dynjson.c`.

## Side effects discovered

- An optional field set to `undefined` explicitly is indistinguishable from
  an omitted one, on the static path and through the row alike (Node lists
  `b: undefined`).

## Verification

Mac (Apple Silicon), against Node v24.19: `TestE2EHeaderedObjectInUnionAndAny`,
`TestE2EHostClassInspect`.
