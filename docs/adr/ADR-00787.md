# ADR-00787: `Dirent.parentPath` and the device kind predicates

- **Relations**: extends the `Dirent` object from `fs.readdirSync(path, { withFileTypes: true })` ([ADR-00752](ADR-00752.md)); addresses the "`Dirent` missing `.parentPath`/device predicates" gap in BACKLOG §3
- **Date**: 2026-09-08

## Context

`Dirent` exposed `.name` and three kind predicates (`isFile`/`isDirectory`/
`isSymbolicLink`). Node's `Dirent` also carries `.parentPath` (the directory the
entry was read from — the `.path` alias too) and four more predicates
(`isFIFO`/`isCharacterDevice`/`isBlockDevice`/`isSocket`). These are the last of
the `Dirent` surface.

## Decision

- **`Dirent.parentPath`.** `DirentType` gains a `parentPath` `ptr` field, placed
  **before** the hidden `mode` word so the enumeration/JSON strip keeps the two
  leading real properties (`name`, `parentPath`) and still hides `mode`
  (`fields[:2]`). `__kml_fs_readdir` stores the `path` argument into each Dirent
  — all entries of one call share the directory string, as Node returns it.
  `.parentPath` resolves as a plain struct field (no interception).
- **Device predicates.** `emitStatsKindCall` (shared by Stats and Dirent) grows
  a full S_IFMT → predicate table: `isFIFO` `S_IFIFO` (0x1000),
  `isCharacterDevice` `S_IFCHR` (0x2000), `isBlockDevice` `S_IFBLK` (0x6000),
  `isSocket` `S_IFSOCK` (0xC000), alongside the existing reg/dir/lnk. The
  `mode` word a Dirent carries is synthesized from the entry's `d_type`, so
  `__kml_fs_readdir`'s `d_type → mode` map is extended to the same seven kinds
  (`DT_FIFO`/`DT_CHR`/`DT_BLK`/`DT_SOCK` in addition to dir/reg/lnk). A shared
  `isStatsKindPredicate` helper drives both the call dispatch and the inference
  site so they can't drift.

Both predicate sets work on Stats (from a real `stat` mode) and Dirent (from the
synthesized `d_type` mode) through the same masking, since the S_IF* encoding is
identical.

## Caveat (unchanged)

A filesystem that returns `DT_UNKNOWN` (rare — some network/FUSE mounts) yields
a `mode` of 0, so every kind predicate reports `false` (no `lstat` fallback),
exactly as before this change; `.path` (the `.parentPath` alias) is not added.

## Verification

Verified on macOS/Apple Silicon against `node` on a directory holding a
subdirectory, a regular file, and a real FIFO (`mkfifo`): `.parentPath`, the
kind of each entry (including `isFIFO() === true`), and
`JSON.stringify(dirent)` (`{ name, parentPath }`, `mode` hidden) all match.
`TestE2EFsReaddirSyncDirentParentPathAndDevicePredicates`, the updated
`examples/fs/fs.ts`, full `make test-par`, Node oracle.
