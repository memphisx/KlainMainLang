# ADR-01537: A plain function's `this` is `any`

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-10

## Context

The checker left `this` unanswered in a function declaration outside a
class and in a function expression with no `this` type from anywhere,
and a body returning `this` was unanswered. The old inference, asked
for `this` before it was bound (a pre-pass over a function value), gave
its integer default: `function f() { return this }` typed its call as an
integer, and a bare `f()` printed `0` (Node: `undefined`).

## Decision

- The checker types such a `this` as `any` (tsc's type for it, with
  TS2683 where it is checked): a function declaration outside a class,
  and a function expression for which tsc reports TS2683.
- `return this` is the polymorphic `this` type only where `this` is not
  `any`.
- The old inference types a `this` not bound yet as `any`, as it is
  bound when the function is emitted.
