# ADR-02016: Array.prototype's added properties

- **Date**: 2026-11-21

## Context

An array read a non-index key it did not own through
`__kml_array_proto_get`. That function was generated only for builtin
methods read as values; otherwise its weak default gave undefined. A data
property or an accessor added to Array.prototype (`Array.prototype.x = 5`,
`Object.defineProperty(Array.prototype, …)`) therefore read as undefined.
Calls to added methods went through another path and worked.

## Decision

- `__kml_array_proto_get(key, recv)` takes the array as its receiver.
- It is generated whenever the program builds Array.prototype's object.
  It looks first in that object, running an accessor with the array as
  `this`, then in the builtin methods.

## Implementation notes

- codegen/llvm/emit_builtin_proto.go (`emitValueProtoGetFinalize`).
- codegen/llvm/dynobjsrc/dynarr.c, codegen/llvm/dynjsonsrc/dynjson.c (the
  callers pass the receiver).

## Verification

- `TestE2EArrayProtoPropertiesJS` matches Node on Linux x86 (Node304).
