# ADR-01269: A local initialized from a call takes the call's return type

- **Relations**: `Extends ADR-00538`
- **Date**: 2026-09-29

## Context

Inside a function, `const t = g()` with `g(): number` returning 2.5 gave
2: the declaration's slot kept only pointer-like return types (arrays,
objects, strings, nullable scalars). A `double` or `boolean` result fell
to the integer default and was truncated. The same held for a
closure-typed callee.

## Decision

An un-annotated declaration initialized from a named function or
closure call takes the callee's return type whenever it is not void.

## Verification

Mac (Apple Silicon): doubles, booleans and a `super(t)` argument computed
before `super` keep their values.
