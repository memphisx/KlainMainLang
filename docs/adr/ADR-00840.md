# ADR-00840: optional call `a?.m()` yields `RetType | undefined`

- **Relations**: Extends [ADR-00682](ADR-00682.md) (optional-chaining calls) and [ADR-00834](ADR-00834.md) (optional member reads as `T | undefined`)
- **Date**: 2026-09-10

## Context

`ADR-00834` made an optional member read `o?.x` a real `PropType | undefined`,
but the parallel optional *call* `a?.m()` still short-circuited to the return
type's zero — so `m.get("z")?.toUpperCase()` on a missing key printed `null`
(the null-pointer zero of a string result) and `=== undefined` was `false`,
where Node yields `undefined` / `true`.

## Investigation

`emitOptionalCall` (`emit_call.go`) mirrored the pre-834 `emitOptionalMember`:
its null branch stored `zeroRef(retTy)` and it returned the bare `retTy`, with no
`undefined`. The `inferExprType` `CallExpression` case likewise returned the
bare call type for an optional callee.

## Decision

Apply the same `undefinedableElem` shape as `o?.x`:

- `emitOptionalCall`: the result type is `undefinedableElem(retTy)`. The null
  branch stores the absent value (a `{present=false}` optional for a scalar
  return, the null pointer for a pointer return, `{null,0}` for an array
  return); the non-null branch wraps a scalar result `{present=true, value}`. It
  returns `RetType | undefined` for scalar/pointer returns, the bare type for
  array/tuple/dynamic and `void`.
- `inferExprType`'s `CallExpression` case mirrors it for an optional callee off a
  pointer (non-array) receiver.

## Implementation notes

`emit_call.go` (`emitOptionalCall`); `emit_exprs_types.go` (`CallExpression`
optional wrap). A non-pointer/array receiver still falls back to the plain
(non-optional) call.

## Side effects discovered

`TestE2EOptionalChainCallShortCircuits` asserted the old `a?.m()` on null → `0`;
corrected to `undefined`. Single-test blast radius (same as ADR-00834).

## Verification

macOS (Apple Silicon M4): `m.get("z")?.toUpperCase()` → `undefined`,
`=== undefined` true; a present receiver still invokes (`HELLO`); a null
class-method receiver `a?.m()` → `undefined`. New
`TestE2EOptionalCallUndefinedResult` + the optional/call/method/class/map suites
green; `make examples` clean.
