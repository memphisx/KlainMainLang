# ADR-01442: Narrowed nullable references and absent-reference strings

- **Relations**: Implements TDD-00230 (P2.2)
- **Date**: 2026-10-07

## Context

The largest shadow bucket (1508 rows; `kml_url.ts`, `stream.ts`, `net.ts`,
`internal_http.ts`) was a nullable instance or function reference that the
checker narrows to present: `const base = this.base` under
`this.base !== null`. TypeScript types `base` as `URLRecord`; codegen kept
the unnarrowed `URLRecord | null`.

Probing it turned up two older bugs:

- Array destructuring accepted only an identifier, a call or an array
  literal as its source: `const [a, b] = xs as R[]` failed to compile.
- An absent instance or function reference converted to a string
  (`String(b)`, a template literal, `b + ''`) gave `[object Object]`;
  `console.log` already printed `null`/`undefined`.

## Investigation

- Nullable scalars already read their payload where the checker narrows
  them (`checkerPresent`, ADR-01439). That rule requires the declared type
  to hold the absence, which a `const` initialized from a narrowed read
  does not.
- A position an array pattern reads past the source's end is `T` to the
  checker (no `noUncheckedIndexedAccess`) yet absent at run time, so such a
  binding must keep its nullability.
- `emitValueToString` handled a nullable string and a nullable scalar, but
  sent a nullable object straight to its object rendering.

## Decision

- `checkerPresentRef`: a nullable class, object, function or promise
  reference reads as present (the same `ptr`, `Nullable` cleared) where the
  checker's flow type has no null or undefined. This applies in both
  inference and `emitIdent`. A binding declared by an array pattern, and an
  element read (`UncheckedIndex`), are excluded.
- Array destructuring's source falls back to any expression whose value is
  an array.
- A nullable object or function reference converts to `"null"` or
  `"undefined"` when absent. Otherwise it converts as its non-null type
  (a user `toString`, a tag, `[object Object]`).

## Verification

- `TestE2ENarrowedNullableRefs` (against Node) passes on the Mac.
- The probe's shadow rows are gone.
