# ADR-01433: Shadow rows name their module; narrowed, typed-array reprs

- **Relations**: Implements TDD-00230 (P2.2, P3.3), Extends ADR-01432
- **Date**: 2026-10-06

## Context

After ADR-01432 the shadow report's remaining large buckets sat in the
builtin library's modules, and a row recorded only a line and column,
attributed to the compile run's entry file. Positions from different
modules collided, so a bucket's example could not be traced to its source.

## Investigation

- With the module recorded, the top buckets were representations the
  oracle did not model rather than type disagreements:
  - an `any` local a `typeof` test narrows reads unboxed for a boolean,
    number or string (a bigint stays boxed): `inspect`'s `typeof first ===
    'boolean'`, `kill`'s `typeof p !== 'number'`;
  - a typed array's element read is its native width (`i8` for a
    `Uint8Array`), and a local initialized from one holds the number it
    converts to, undefined-able but without the unchecked-index mark;
  - `symbol` had no representation;
  - a builtin global function as a value (`parseInt`, or `const f =
    parseInt`) is held with every parameter `any` and its declared
    result: `["10","10","10"].map(parseInt)` prints what Node prints;
  - an object with only a string index signature (`{ [k: string]: T }`,
    `Record<string, T>`) is a string-keyed map held as a dynamic object;
  - an optional parameter's annotation (`error?: Error | null`) carries the
    `undefined` the parse recorded on it, which `resolveType` applied after
    its decider and the oracle did not.

## Decision

- A shadow row records the library module its node belongs to (the
  emitter's current module, set per declaration for the top-level
  variable rows), and the report names it.
- The oracle models the four representations above; the annotation
  post-processing is one function (`annotationNullish`) both sides call.

## Verification

Gates on this tree (Linux, kmlbox DeskMini; Node304 unreachable): test-par,
examples 396/396, Test262 strict 8409 and js 10833 (the previous run's
files exactly), neither with invalid IR. The builtin-function, index
signature and per-declaration module changes came after the gates; they
are confined to the shadow oracle and to code that runs only under it.
