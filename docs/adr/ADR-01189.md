# ADR-01189: A web stream of typed chunks read as `ReadableStream<any>` is converted

- **Relations**: `Extends ADR-01182`, `Implements TDD-00230` (P3.3 convert)
- **Date**: 2026-09-28

## Context

A `ReadableStream<T>` keeps each chunk in T's representation (a
`Uint8Array` is a data pointer and a length). Passed where a
`ReadableStream<any>` is declared — `Readable.fromWeb(blob.stream())`, an
annotated binding — its chunks were read as boxes: garbage bytes (BACKLOG).
ADR-01182 converted promises the same way; streams had no conversion.

## Investigation

The conversion a program would write by hand compiles and runs: a
`ReadableStream<any>` whose `pull` awaits the source reader's `read()` and
enqueues the value (the chunk is boxed at `enqueue`, where the controller's
chunk type is `any`), with `cancel` forwarding to the reader.

## Decision

`coerce` converts `ReadableStream<T>` to `ReadableStream<any>` by that
program: the source's reader is taken, and the new stream is built from a
parsed snippet (run through `sema.Prepare` so its `new ReadableStream` is the
builtin, as the `events.on` helper's snippet is). The reverse direction
(`any` chunks read as T) is not needed by any caller yet.

## Implementation notes

`codegen/llvm/emit_streamconv.go` (new), `emit_exprs_coerce.go`.

## Side effects discovered

- `new Response(body)` is not constructible (only fetch builds a Response):
  BACKLOG.
