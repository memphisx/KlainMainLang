# ADR-00956: Omitted optional `any` argument is boxed `undefined`, not raw zero

- **Date**: 2026-09-15

## Context

The conformance async lane's reproducer for the long-standing "then-handler gets
`5e-324`" bug (recorded as the lead async-lane defect) turned out to be a general
call-lowering bug, not a Promise bug at all.

The Test262 async protocol reporter (`tools/conformance/harness-shim/
doneprintHandle.js`) is an ordinary top-level function:

```ts
function $DONE(error?: any): void {
    if (error !== undefined && error !== null) { /* failure */ }
    else { /* Test262:AsyncTestComplete */ }
}
```

A passing async test calls `$DONE()` with no argument, expecting the "complete"
branch. Instead the compiler took the failure branch and printed
`Test262:AsyncTestFailure:Test262Error: undefined`, failing seven otherwise-passing
`built-ins/Promise/**` files (e.g. `prototype/then/rxn-handler-identity.js`).

Minimal repro — no promises involved:

```ts
function g(error?: any): void {
  console.log(error !== undefined); // printed `true` (wrong; should be false)
}
g();
```

## Investigation

`emitPromiseThen`/`emitThenRunner` (`codegen/llvm/emit_promise_then.go`) all
proved correct — a resolved-object identity chain (`Promise.resolve(obj).then()
.then(a => a === obj)`) returned `true`, and boxed-number/any values round-tripped
fine. The failure only appeared when the callback declared an **optional `any`
parameter and was called with fewer arguments**.

The direct-call arg-lowering path fills omitted optional parameters at
`codegen/llvm/emit_call.go` (the `i < len(sig.Optional) && sig.Optional[i]` branch
of `emitCBCall`). It emitted `paramTy.zeroLiteral()` for every non-array,
non-nullable-scalar parameter. For a dynamic (`any`) parameter `zeroLiteral()` is
the i64 `0`. But an `any` slot is a NaN-boxed word (TDD-00076), and the boxed
`undefined` sentinel is `nbUndefined` (10, `runtime_nanbox.go:27`), not `0`. A
zero word decodes as the *boxed integer 0* — which, reinterpreted as a `double`,
is the denormal `5e-324` (the reported symptom). So `x === undefined` and
`x === null` both compared false, and any numeric read of the slot was corrupt.

The closure/indirect-call path (`emitClosureCallByPtr`) was already correct — it
fills omitted trailing parameters from the callee's stored defaults and boxes
`undefined` properly — so only the direct-call path was affected. `ADR-00164`
introduced the zero-value stand-in before the NaN-box `any` model existed, so it
never accounted for a dynamic slot.

## Decision

In the omitted-optional branch of `emitCBCall`, special-case a dynamic parameter:
emit the boxed `undefined` sentinel (`nbUndefined`) as the `i64` argument instead
of `zeroLiteral()`. Array and nullable-scalar params keep their existing
absent-value shapes; all other scalars keep `zeroLiteral()`.

## Implementation notes

Single site, `codegen/llvm/emit_call.go`: a new `else if paramTy.IsDynamic`
clause between the nullable-scalar and the default-scalar branches, appending
`i64 <nbUndefined>` and recording it as the materialized scalar so a later
parameter's default can reference it by name. No ABI change — the slot was always
`i64`; only the literal changed.

## Side effects discovered

- Optional parameters in **arrow-function** parameter lists (`(x?: any) => …`) and
  in **function-type annotations** (`(x?: any) => void`) still fail to parse
  (`unexpected token :` / `expected type name, got ?`). Pre-existing parser gap,
  unrelated to this fix; not addressed here.
- The remaining four `built-ins/Promise/**` async failures are thenable
  assimilation / poisoned-`then` semantics (`resolve/arg-non-thenable.js`,
  `resolve/resolve-poisoned-then.js`, `prototype/then/S25.4.5.3_A4.{1,2}_T1.js`),
  a separate and deeper feature, not this bug.
