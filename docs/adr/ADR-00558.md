# ADR-00558: Buffer string-form indexOf/includes/lastIndexOf

- **Relations**: Extends TDD-00103
- **Date**: 2026-09-01

## Context

`Buffer.indexOf`/`.includes`/`.lastIndexOf` worked only with a numeric
(single-byte) argument — they rode the shared TypedArray/array machinery. The
string forms (`buf.indexOf("world")`), which search a needle's bytes over the
buffer, were unsupported. This was a disclosed caveat on the Node `Buffer`
status row.

## Investigation

A Buffer is a `Uint8Array` (`IsBuffer`), so `indexOf`/`includes` already
dispatch to `emitArrayIndexOf`/`emitArrayIncludes` for numeric args in
emit_call.go. A string argument needs a distinct byte-substring search:
`memmem` (already declared by `ensureStrHeaderRuntime`) gives a forward search;
the needle length comes from the string header via `emitStrLenHeader`.

## Decision

Add `emitBufferStringSearch(mem, method, args, pos)`:

- **indexOf / includes**: `memmem(bufPtr, bufLen, needle, needleLen)` → byte
  index or `-1`; `includes` returns `idx >= 0`. An empty needle is index `0`
  (Node), selected explicitly because macOS `memmem` returns NULL for a
  zero-length needle while glibc returns the haystack.
- **lastIndexOf**: a reverse scan from `bufLen - needleLen` down to `0` using
  `memcmp`; an empty needle returns `bufLen` (Node).

emit_call.go intercepts `indexOf`/`includes`/`lastIndexOf` on an `IsBuffer`
receiver when `args[0]` is a string, before the generic array dispatch. Numeric
args are unchanged.

## Implementation notes

- Single-argument form only; a `byteOffset`/`encoding` second argument is a
  clean compile error (documented in the status caveat).
- `ensureMemcmp` already existed in emit_buffer.go; reused it.

## Side effects discovered

None. Numeric `indexOf`/`includes` and the rest of the Buffer surface are
untouched.

## Verification

`TestE2EBufferStringSearch` cross-checks `indexOf`/`lastIndexOf`/`includes`
(including the empty-needle 0 / length edges and a not-found `-1`) against Node
on `Buffer.from("hello world hello")`, and the existing numeric
`TestE2EBufferSharedArrayMachinery` still passes. Built and verified on Mac
(Apple Silicon).
