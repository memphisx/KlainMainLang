# ADR-02034: Empty-search replaceAll substitution over astral text

- **Date**: 2026-11-22

## Context

- `"a😀b".replaceAll("", "[$`]")` matched at whole characters. JavaScript
  matches an empty search at every UTF-16 unit, so `$`` and `$'` may end or
  start between a pair's two halves (lone surrogates in the result).

## Decision

- `__kml_replace_all_subst`, for an empty search over text that holds a
  four-byte character, substitutes over the string's units (each pair as
  its two WTF-8 halves). It then joins every high/low half pair the result
  holds into its four-byte character (`__kml_wtf8_join`), so equal text
  stays equal bytes.

## Consequences

- A non-`u` regex's empty matches still step whole characters (PCRE2's
  UTF-8 subject). That is a BACKLOG item.
- Tests: `TestE2EReplaceAllEmptyAstralSubstTS`.
