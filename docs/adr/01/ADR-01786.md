# ADR-01786: An empty object pattern requires an object-coercible value

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- `function f({}) {}` accepted `f(null)` and `f()`. The parser gave `{}` a nil pattern, so the parameter was not destructured. Even with a pattern, the dynamic unpack reads nothing for zero properties, so nothing threw. Destructuring runs RequireObjectCoercible first, so both calls throw a TypeError in Node.

## Decision

- `parseObjectPatternProps` returns a non-nil empty slice for `{}`.
- `unpackDynObjectPatternInto` checks an empty pattern's value with `emitRequireDestructurable`. It throws Node's "Cannot destructure 'object null' as it is null." (or the `undefined` form). A non-empty pattern already throws on its first property read.

## Consequences

- `TestE2EJSFileEmptyObjectPatternCoercible` compares methods, functions and arrows against Node.
