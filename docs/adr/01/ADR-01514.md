# ADR-01514: A named-element array annotation keeps its nullability

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-09

## Context

The parser hands `User[]` (a named interface or enum element) to codegen
as one `"User[]"` name, which `decideAnnotationType` resolves through its
own branch. That branch dropped the annotation's `| null` / `| undefined`,
so `c: H[] | null` was a plain array while `number[] | null` (resolved
through `ElemType`) was a nullable one. Output was right; the two shapes
disagreed (shadow bucket 14, 111 rows).

## Decision

The named-element branch applies the annotation's nullability, as the
`ElemType` branch does.

## Divergences

None.
