# ADR-00496: mustCall for any fixed callback signature

- **Date**: 2026-08-29

## Context

`mustCall` only accepted callbacks of 0–3 scalar/pointer parameters —
array params, nullable scalars, and wider arities were compile
rejections, though the counting trampoline was already
signature-parametric.

## Decision

Drop the artificial bounds: the trampoline forwards whatever ABI slots
each parameter expands to via `paramABITypes` — split `(ptr, i64)`
arrays and `{i1, T}` nullable aggregates included — so every
fixed-signature callback wraps. Only rest-parameter callbacks stay
rejected (a rest tail is a different calling convention, not a fixed
slot list).

## Verification

param, 5-arg, nullable scalar) and `TestE2EMustCallArrayParamUnmetFails`
(unmet count still exits 1) pass; test-module/node-test batch green;
