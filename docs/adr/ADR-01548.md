# ADR-01548: Settled expression kinds: the old inference deleted

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-10

## Context

inferExprType takes thirteen expression kinds from the checker
(switchedExprKind): the literals, template literals, and `new` of
RegExp, typed arrays, Date, Array, the three web streams, and Request.
Over the whole shadow corpus none of them fell back to the old
inference (no switchFallback row), so the old arms only duplicated the
checker's answer.

Two kinds stayed partial:

- `this` fell back on 10,515 rows. The checker answered, but while a
  class registers its layout is not built yet, so classRepr had no
  answer; and a `this` codegen synthesizes for a field initializer
  (`this.f = …`) is no node the checker typed.
- `await` and `!` derive their representation from their operand. The
  checker's answer for them disagreed whenever the operand's own kind
  was still on the old inference (`await subtle.exportKey("jwk", k)`
  bound a struct of the JsonWebKey interface while emission held the
  library's dynamic object, and printed its keys sorted).

## Decision

- The thirteen kinds are settled (settledExprKind): their old arms are
  deleted. A node the checker has no answer for is typed from its syntax
  alone (syntacticExprType): code built after parsing (the Response
  stream drain, a static eval's text), which the checker never sees; and
  a checker gap on a node of the program, which also records a
  switchFallback shadow row (Checker.InProgram tells the two apart).
- On overload failure, a builtin `new` whose overloads all construct the
  same interface is that interface (`new BigInt64Array([1, 2])`, a type
  error, is still a BigInt64Array), as tsc types a failed call from its
  candidates.
- `SharedArrayBufferConstructor` gives `new SharedArrayBuffer(n)` its type
  (ADR-01549).
- classRepr answers a class still registering with the type `this` is
  bound to there (the provisional layout); a synthesized `this` is that
  binding.
- `await` and `!` are no longer switched: each composes its operand's
  representation, and switches with the kinds it wraps.

## Divergences

None.

- Mac (Apple Silicon): targeted literal/typed-array/stream/Request/

- Shadow corpus (DeskMini, Linux x86-64): no switchFallback row on the
  settled kinds.
