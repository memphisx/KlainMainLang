# ADR-01525: A literal key on a builtin global reads as its member

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-10

## Context

`Date["parse"]`, `Number["parseFloat"]` and `Math["PI"]` name the same
property `Date.parse`, `Number.parseFloat` and `Math.PI` do. The bracket
form went through the dynamic index read instead: `typeof Date["parse"]`
printed `undefined`, `typeof Number["parseFloat"]` printed `number`.

## Decision

An index read of a builtin global object (`Date`, `Math`, `Number`, …)
with a string-literal key that is an identifier name is emitted and
inferred as the member read (`builtinLiteralMember`, one node per index
expression).
