# ADR-00610: Default parameter referencing an earlier array parameter

- **Relations**: Extends [ADR-00598](ADR-00598.md)/[ADR-00599](ADR-00599.md) (default referencing an earlier scalar/string param)
- **Date**: 2026-09-01

## Context

A parameter default could reference an earlier **scalar/string** parameter
(`function f(a: number, b = a * 2)`) via the scratch-symbol mechanism of
[ADR-00598](ADR-00598.md) — the earlier param's final value is materialized into
a temp and made visible only while a later default is emitted. An earlier
**array** parameter stayed a clean rejection (`undefined variable 'a'`): the arg
loops never materialized an array param, so `function f(a: number[], b = a.length)`
couldn't see `a`.

## Decision

Materialize an array parameter into the same scratch scope, via a slot holding
its **header pointer** (`arrayDataLenSlots` derives the data/len from it) — so a
later default can read `a.length`, `a[i]`, and any other array operation.

- Free functions (`emit_call.go`): capture the array arg's header (in the
  identifier, transient-expression, and array-default branches) and, at the end
  of each parameter's iteration, store it into a fresh `alloca ptr` scratch
  symbol keyed by the parameter name.
- Class methods / static methods / constructors (`emit_classes.go`): a new
  `paramDefaultScratch.bindArray(i, header, arrTy)` mirrors the scalar `bind`,
  called from each loop's array-argument branch.

The scratch symbol carries the array's own `Type`, so `a[i]`, `a.length`,
`a.map(...)` etc. all resolve exactly as a normal array binding.

## Scope

Covers array parameters for free functions, instance methods, static methods, and
constructors. Referencing an earlier **nullable-scalar** parameter (`a: number |
null`) is still a clean rejection — it is stored as a boxed `{ i1, T }`
presence-flagged aggregate, whose materialization into a scratch symbol is a
separate, fiddlier change left as a narrower documented residual.

## Verification

`TestE2EDefaultParamReferencesEarlierArrayParam` — `a.length`, `a[0]`, chaining
(`total = xs.length + first`), and a class method's array-param default — matching
Node v26. The default-parameter, method, and constructor suites still pass. Built
and verified on Mac (Apple Silicon).
