# ADR-01225: A boxed object converts to a dictionary type

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-09-29

## Context

`url.format({ hostname: "h", query: { a: "1" } })` crashed once `format`
took `URL | UrlObject | string` (ADR-01221). `const r: Record<string,
string> = JSON.parse(…)` crashed as well.

## Investigation

- A union or `any` holding an object was unboxed into a dictionary type
  (an index-signature type, a map at run time) by the host-handle path:
  the payload taken as the map. For a static object or a dynamic bag,
  that pointer is not a map.
- `emitBoxedObjToDict` already converted a static object to a dictionary
  for a structural view's field. It treated every object payload as
  static, so a dictionary boxed as itself (a map has no header) came out
  empty.
- `layoutFieldKey` keyed every pointer field by its IR alone, so
  `{ hostname: string, query: string }` and `{ hostname: string, query:
  D }` interned as one layout. The second literal's row then read `query`
  as a string.

## Decision

- Unboxing into a dictionary type (`coerce` and the union narrowing) goes
  through `emitBoxedObjToDict`:
  - a headerless object payload is a dictionary, itself;
  - a static object becomes a dictionary of its present keys;
  - a dynamic bag becomes a dictionary of its own enumerable keys;
  - anything else is the host payload, as before.
- A layout field's key names its pointer kind (string, dictionary or
  dynamic object, function, promise, host handle), so layouts that store
  different kinds in one slot are distinct.

## Implementation notes

`codegen/llvm/emit_record_view.go`, `emit_exprs_coerce.go`,
`emit_narrowing.go`, `objheader.go`.

## Side effects discovered

- The static-object and bag conversions copy. A write through the
  dictionary does not reach the source object, which JavaScript's single
  object would show. That is the dictionary representation (P3.3).
- A dictionary boxed into `any` is opaque to the dynamic paths:
  `console.log` prints `[Object]`, `Object.keys` is empty and
  `JSON.stringify` throws. The box does not say how the map's values are
  stored.
