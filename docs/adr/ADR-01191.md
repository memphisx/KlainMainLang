# ADR-01191: A union's object member asserted as another shape is read by field name

- **Relations**: `Extends ADR-00929`
- **Date**: 2026-09-28

## Context

`(server.address() as { port: number }).port` read garbage (a pointer's
bits as a double) where `as AddressInfo` read the port: `address()` is
`AddressInfo | string | null`, and the assertion reinterpreted the union's
object member with the asserted layout, whose `port` sits where
`AddressInfo` keeps `address`. A test server's port computed this way made
`fetch` reject, which looked like a hang (the rejection was unhandled).

## Decision

`emitAsExpression`: when the target is a plain record whose layout differs
from the union's object member and every target field is in the member,
the member is unboxed and then copied by field name (the relayout `coerce`
already performs between two object layouts).

## Implementation notes

`codegen/llvm/emit_undefined.go`.

## Side effects discovered

None.

## Verification

Mac (Apple Silicon), against Node v24.19: `server.address() as { port:
number }` and `as AddressInfo` agree; `TestE2EFetchedResponseStatusTextAndType`.
