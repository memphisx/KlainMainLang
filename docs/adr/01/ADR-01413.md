# ADR-01413: util.inspect honours customInspect: false

- **Relations**: Extends ADR-01410
- **Date**: 2026-10-05

## Context

`util.inspect(value, { customInspect: false })` read the option but never
passed it to the native renderer, which always called an object's
`[inspect.custom]`. A custom inspector written as Node's own are, rendering
itself with `inspect(this, { ...options, customInspect: false })`
(`Timeout`, `TimersList`), recursed until the stack overflowed.

## Decision

`inspectWith` takes `customInspect`; for that one rendering the native
renderer (`dynjson.c`) skips every object's `[inspect.custom]` while it is
off, as Node's `formatValue` does.

## Verification

- Mac (M4): `TestE2EInspectCustomInspectFalse` (a class inspecting itself
  with `customInspect: false`, and `inspect(a, { customInspect: false })`,
  matching Node) and the inspect tests.
- Linux (x86-64, Ubuntu 24.04 container), with ADR-01410 to ADR-01415: the
  full test suite, the 394 examples, and Test262 in both lanes (strict 8,497,
  the one file of ADR-01412 fewer; js 10,506; no invalid IR).
