# ADR-01705: An evolving array of functions

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-18

## Context

An unannotated `[]` takes its element type from what is pushed into it (`inferEmptyArrayElemTypes`). Before this change, only numbers, booleans and strings unified. A pushed function gave the array its default `number` element type, so the array could not be called through:
- in strict TypeScript, inside a function, it was an element type mismatch;
- under `-compat=js`, `fs[0]()` was "only simple function calls are supported", and `for (var f of fs) f()` was "undefined function or closure".

## Decision

When every pushed value is a function:
- if their types are identical, the array holds that function type;
- otherwise its elements are boxed function values (`any[]`), which a call dispatches at run time.

## Verification

macOS (Apple Silicon): the probes match Node's output in both lanes. They cover calls by index, `for…of`, `forEach` and `map`, closures sharing a `var`, and mixed signatures. `TestE2EPushedFunctionArray` and `TestE2EJSPushedFunctionArray` pass.
