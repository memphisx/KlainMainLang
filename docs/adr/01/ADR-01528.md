# ADR-01528: An immediately invoked function's parameters take its arguments' types

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-10

## Context

tsc types an unannotated parameter of an immediately invoked function
expression or arrow by the widened type of its argument:
`(a => a + 1)(1)` has `a: number`. The checker gave it no context, so
the parameter was implicitly `any`, and the result `any`, where codegen
reads the number.

## Decision

`contextualParam` answers a parameter of a function literal that is a
call's callee with `iifeParam` (its argument's widened type; none past a
spread, or while that argument is itself being typed from this
parameter), where it read the call's context and found an `any`.
