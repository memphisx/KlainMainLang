# ADR-01740: Fixes from the conformance sweep — wrapper hook, void values, inline bound callbacks, literal assertions, boxed index bases, http/fs signatures, abstract sockets

- **Relations**: `Implements TDD-00230`, Extends [ADR-01739](ADR-01739.md)
- **Date**: 2026-10-19

## Context

A full conformance run (Test262, WPT, Node-core, TypeScript) over the staged tree found:

- **`Array.prototype.join/every/…​.call(new String("hi"))` looped until it ran out of memory.** The Array methods are shared library code, which is program-independent. There the wrapper redirect (`emitWrapperRecv`) was off, so the generic array-like reading saw the wrapper's raw host cell. That run aborted Test262 on its memory cap.
- **Invalid IR (js lane, 5 files):**
  - a `void` call read as a value (`new String(x).indexOf(f())`) left an empty register;
  - a bound function given inline to an Array method (`a.flatMap(fn.bind(x))`) was inferred `any` but emitted as a closure pointer, then read as a box.
- **Node-core strict lost 10 files.**
  - Four were new checker rejections that tsc does not make:
    - `http.get(url.parse(…))` and `{ port: null }` were rejected, because our `RequestOptions` typed `host`/`port`/`hostname`/`path`/`protocol`/`auth` more narrowly than `@types/node`;
    - `fs.write(fd, dataView, cb)` was rejected, because its overloads took only `Buffer`.
  - One was a runtime failure: a Linux abstract socket name (`"\0name"`) was truncated at its leading NUL. Listen bound 108 zero bytes and the old connect matched that by accident; the libuv connect then failed with `EINVAL`.
  - The other five are faithful:
    - four read internals that `@types/node` does not declare (`process._exiting`, `_eventsCount`, `timer._destroyed`, `_repeat`), which tsc rejects too;
    - one expects Node 22's webcrypto message. The corpus is pinned to v22.11.0; Node v24.19.0 prints the generic one, as we do.
- **Found while probing:**
  - `{} as { xs?: number[] }` failed with "no field 'xs'";
  - `headers.host?.split(":")[0]` on an index-signature type failed with "cannot index a non-array expression".

## Decision

- **Wrapper hook:** program-independent code redirects through a hook (`emitWrapperHookCall`). The hook pointers `__kml_wrapper_recv_hook` and `__kml_host_unwrap_hook` are weak globals initialised to null in IR. `wrapper.c`, linked when the program makes a wrapper, defines them strongly as its routines, so the redirect costs a null check in programs without wrappers.
- **`convert` from `void`** to any other type yields `undefined`.
- **The `any`-callback branch** of `resolveCallbackWithHints` boxes a value emitted as its own kind before checking it is callable.
- **Object-literal assertions:** an object literal asserted to a static object type whose fields name every key it has is built as that type, in `emitAsExpression` and in inference alike; the fields it leaves out are absent.
- **Boxed index base:** when the object of `a[i]`, inferred an array, is emitted boxed, `emitIndexBase` reports it (`dynIndexBase`). The read is then dynamic, converted to the inferred element type. A write keeps the compile error.
- **`RequestOptions`** declares `host?: string | null`, `port?: number | string | null`, `protocol`/`hostname`/`path`/`auth` `?: string | null`, and the connect options, as `@types/node` does. `ClientRequest` reads `port` through `Number()` and checks `path` and `auth` against `null`.
- **`fs.write`'s buffer overloads** take `NodeJS.ArrayBufferView`.
- **Unix socket paths:** `pipe_addr` copies the path by its byte length, the whole length-prefixed string for an abstract name (`pipe_len`), and returns the address length. `bind` and the fallback `connect` use it, and the libuv client connects with `uv_pipe_connect2` and that length.

## Verification

- **macOS (Apple Silicon), against Node:**
  - `tests/wrapper_objects_test.go` TestE2EArrayMethodOnStringWrapper and TestE2EVoidValueAndInlineBoundCallback;
  - `tests/objects_test.go` TestE2EObjectLiteralAssertionAndBoxedIndexBase;
  - the wrapper, bind, callback, index, optional-chain, assertion, HTTP client, pipe and net families pass;
  - a live `http.get` with a string port and a `url.parse()` result matches Node.
- **Linux (DeskMini `kmlbox`):**
  - `tests/net_pipe_server_test.go` TestE2EAbstractUnixSocketHTTP (Linux-only) passes, with the pipe and net families;
  - Node-core passes 317 files strict (316 before) and 714 js (683); the five fixed files pass again.
