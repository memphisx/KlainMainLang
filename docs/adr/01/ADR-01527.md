# ADR-01527: A namespace merged into a function declares its members

- **Relations**: Extends TDD-00095, TDD-00229
- **Date**: 2026-10-10

## Context

With `function N` and `namespace N` merged, a read or call of `N.h`
(a namespace member) was typed by inference as the function's own
property bag: `any`, while emission called the namespace function. The
two disagreed on the result's representation (a `void` member's call,
inside an arrow, made the arrow return a box).

## Decision

Inference resolves a member a namespace of the receiver's name declares
before the function-own-property rules (`isNamespaceMember`, in the
member read and in `funcOwnPropCall`), as emission does.

## Divergences

None.
