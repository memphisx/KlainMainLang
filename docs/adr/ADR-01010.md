# ADR-01010: AbortSignal.any live propagation

- **Relations**: Extends ADR-01004 (reason slot), ADR-00979 (background timeout fire); TDD-00081
- **Date**: 2026-09-18

## Context

The stale-caveat sweep confirmed "`AbortSignal.any(signals)` snapshots the
input signals at construction" — a source aborted *after* the composite was
built never latched it (`combined.aborted` stayed `false`, no listeners
fired). Node propagates live.

## Investigation

`emitAbortSignalAny` looped the sources once at construction. Signals are
fixed structs constructed only in `emit_abort.go`, aborts fire from
`controller.abort()` (inline emission) and the background timeout dispatcher
`__kml_abort_timeout_fire`. Listener dispatch needs the compile-time emitters
(`emitFireOnabort`/`emitDispatchToMap`), so propagation lives in a synthetic
compiled function (the `emitAbortTimeoutDispatcher` builder-swap pattern), not
hand-written IR.

## Decision

- `AbortSignalType` gains a trailing hidden `followers` field: the head of a
  `{ ptr composite, ptr next }` linked list (null-initialized at all four
  construction sites). Trailing, so the fixed indices the runtime GEP literals
  (`{ i1, i64, ptr, i64 }`) rely on are untouched.
- `emitAbortSignalAny`: a source that is non-null and not already aborted gets
  the composite pushed onto its followers list (the already-aborted snapshot
  latch is unchanged).
- `ensureAbortPropagate` emits `@__kml_abort_propagate(ptr sig)` once: for
  each not-yet-aborted follower — latch `aborted`, copy the source's boxed
  reason, fire `onabort` + the addEventListener listeners, then recurse into
  the follower (a composite can itself be another composite's source).
- Called after listener dispatch in `emitAbortControllerAbort` and at the end
  of `__kml_abort_timeout_fire` (ensured from `ensureAbortTimeoutRuntime`).

## Implementation notes

`codegen/llvm/types.go`, `codegen/llvm/emit_abort.go`,
`codegen/llvm/emitter.go` (used-flag). The already-aborted guard in the
propagate loop makes a second source's abort a no-op on an already-latched
composite (first reason wins, as in Node) and terminates any accidental
follower cycle.

## Side effects discovered

A timeout source latched only via the `__kml_signal_aborted` deadline poll
(no event-loop dispatcher run, e.g. a fetch polling the source directly)
propagates when the background dispatcher fires, not at the poll — the same
delivery point its own listeners already have (ADR-00979 posture).

## Verification

New `TestE2EAbortSignalAnyLatePropagation` (late abort latches flag/reason,
fires `onabort` + listener exactly once, second abort doesn't re-fire, nested
composites propagate) — byte-exact vs Node. `Abort|Event|Fetch|Signal|Timeout`
groups pass; `make examples` + `make conformance-node` green (macOS arm64).
Caveat deleted from `docs/status/data/events-cancellation.json`.
