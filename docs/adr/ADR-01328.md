# ADR-01328: The runtime outside HTTP in C

- **Relations**: Implements TDD-00240 (second batch), Extends ADR-01327
- **Date**: 2026-10-01

## Context

[TDD-00240](../tdd/TDD-00240.md) moves the runtime out of IR text into C.
ADR-01327 ported the microtask queues and the try-frame stack; 812 IR
definitions were still written as text. This batch ports every runtime
but HTTP, which waits on the klain:http redesign.

## Investigation

- The ported files, by IR definitions written as text: collections 54,
  task 52, dynobj 29 + dynarr 13, strheader 13, core 10, date 10, strings 8,
  regexp 8, weak 8, finalization 8, encoding 6, path 4, atomics 4, json.
- A C routine that returns `{ ptr, i64 }` by value does not match the IR
  aggregate return on Windows x64 (an sret pointer there). Such routines
  return through an out-parameter in C, behind a short IR wrapper that
  builds the pair.
- An IR call passes a bare `i1`/`i8` without `zeroext`; a C callee taking
  `_Bool` may assume the upper bits are clear. The C side takes an int and
  masks it.
- An any-heavy loop (`typeof x === "string"` over 40M elements) ran 1.8x
  slower: the IR helpers it called (`__kml_nb_tag`/`_pay`, `__kml_str_len`,
  `__kml_str_cmp`) had inlined at -O2; calls into a C object cannot. A
  ThinLTO link of the same objects did not inline `__kml_str_cmp`.

## Decision

1. **Ported to C**, same symbols and ABI, each linked when its `ensure*`
   ran: `tasksrc/task.c` (scheduler, task array, spawn, waits, the
   trampoline, await) and `tasksrc/promise.c` (allocator, the
   scheduler-free Promise.any scan); `collectionssrc/` (Map/Set engine, a
   separate unit for any-keyed maps); `dynobjsrc/` (dynamic objects,
   dynamic arrays, the JSON-tree conversion); `stringsrc/` (string header
   routines, trim/replace/split, regexp helpers); `coresrc/` (number
   parsing, pow, cbrt, RSS, JSON helpers); `datesrc/`, `encodingsrc/`,
   `pathsrc/`; `weaksrc/`, `finalizationsrc/`, `atomicssrc/`.
2. **Task layout in `kml_layout.h`**: the task struct, the fetch fields a
   parked task polls, the connection slot, and the Error tag. The ucontext
   offsets are per-platform `#if`s matching `ucontextLayout`; the GC stack
   bottom mode is a `-D` flag (part of the object cache key).
3. **Globals C reads are no longer `internal`**: the current task, the root
   async context, the connection poke, the main context, the connection
   array and index, the curl multi handle, the thrown value, the GC stack
   origin.
4. **Leaf primitives stay IR**: `__kml_nb_pack`/`_tag`/`_pay` and
   `__kml_str_alloc`/`_len`/`_free`, so every call site inlines them.
5. **Kept in IR**: what is generated per program: per-layout shape
   routines, record views, class-reference dispatchers, per-class host
   routines, `.then` runners built from callback types, the for-of-over-any
   collectors, AbortSignal readers built from the class's fields, the
   uncaught-exception reporters, the Windows spawn and fork regions; and
   the by-value wrappers of point 1.
6. **Error names referenced from C** (`Error`, `TypeError`, …) are the
   `linkonce_odr` constructor-name symbols, compared by address: C names
   them through an assembler label, and the emitter interns them so they
   are defined.
7. **String equality is emitted inline** (`emitStrEq`): equal header
   lengths, then `memcmp` over the constant operand's length, so a compare
   against a literal folds to a length test and a few loads. `===`, `!==`
   and `switch` on strings use it; orderings keep `__kml_str_cmp`.

## Implementation notes

- `__kml_task_launching` and `__kml_task_active` live in task.c; IR
  declares them `external thread_local`. A program with the HTTP loop and
  no task runtime still defines its own inert `__kml_task_active`.
- The loop's per-subsystem no-op stubs (`emitLoopTaskStubs`) are unchanged;
  they go with TDD-00230 Phase 4's loop interface.

## Side effects discovered

- Fixed in passing: `Date` parsing read a fraction's integer value as its
  milliseconds (`.5` was 5 ms; Node reads 500).
- Fixed in passing: the frozen set's header under `-mm=gc` was allocated
  8 bytes short of its iterator field.
- `__kml_json_str_str(NULL)` left its "null" unterminated; the C writes the
  terminator.
- A response header line starting with `:` looped forever in the header
  map; it is skipped.
- A connection fiber resumed from a fetch wait cleared its park fields
  through a pointer into the connection array taken before it moved; the
  slot is recomputed. The net dispatch had the same stale-array read.
- A spawn failure's Error carried an unflagged kind and no `cause`.
- `process.execPath` on macOS leaked its buffer; a child's argv leaked in
  the parent.
- Cross-language inlining is open (BACKLOG section 5).
