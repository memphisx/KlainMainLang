# ADR-01758: A conditional's `typeof` guard narrows its branches

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

`typeof name === "symbol" ? name.description : name` over `name: string | symbol` failed to compile ("'description' can't be read on an un-narrowed union"), though the same guard in an `if` worked. The narrowed-conditional path (`narrowedCondBranchTypes`) took only `instanceof`, `in` and type-guard calls, and the boxed-result path (`emitConditionalAny`) emitted both branches in the outer scope. Test262's `propertyHelper.js` uses this shape in the strict lane.

## Decision

- `narrowedCondBranchTypes` also takes a `typeof` comparison (`isTypeofGuard`).
- `emitConditionalAny` emits each branch in its own scope, narrowed by the test (`narrowUnionLocal`), as `emitNarrowedConditional` does.

## Consequences

- `TestE2ETypeofGuardConditionalMemberRead` covers both orders and both result shapes.
