# ADR-01859: Iterating a value of type never is TS2488/TS2504

- **Relations**: `Implements TDD-00230` (P3.3: found while answering the shadow report's CallExpression bucket)
- **Date**: 2026-10-21

## Context

- tsc reports TS2488 ("Type 'never' must have a '[Symbol.iterator]()' method…") for `yield*` or `for…of` over a value of type `never`, and TS2504 (the `[Symbol.asyncIterator]()` form) for `yield*` in an async generator or `for await`. Test262's `yield-star-expr-abrupt` family (`yield* abrupt()` where `abrupt` only throws) is such a program.
- The checker reported TS2488 only for a class instance without `[Symbol.iterator]`, so the strict lane compiled these programs, which tsc rejects, and left the calls on the generator they built without an answer.

## Decision

- `checkNeverIterated` reports TS2488, or TS2504 in an async generator (`inAsyncFunction`) or a `for await`, at the start of an iterated expression of type `never`, in the strict lane.

- The iterated type of `never` is then tsc's error type, `any` (`iteratedType`, `asyncIteratedType`), so the generator stays typed (`() => AsyncGenerator<any, void, unknown>`, as tsc's declaration output gives) in the JavaScript lane, where the diagnostic is not reported.

## Consequences

- `TestYieldStarNeverIsAny` holds the generator types; `TestCheck` holds tsc 5.6 `--strict`'s lines and codes for the sync and async forms.
- Verified on Apple Silicon.
