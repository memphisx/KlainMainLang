# ADR-01700: f.caller and f.arguments

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-18

## Context

`f.caller` and `f.arguments` read `undefined`. Node runs a `.ts` file as CommonJS, which is sloppy mode. There, a plain `function`'s two properties give:
- during a call: the calling function (the module wrapper for a top-level call, `null` when the caller is a strict function) and the live Arguments object;
- outside a call: `null`.

A strict function (an arrow, a class method, a generator or async function, a builtin, a bound function) throws a TypeError on either read: `'caller', 'callee', and 'arguments' properties may not be accessed on strict mode functions…`.

## Decision

1. A program that reads a `caller` or `arguments` property (a member name or a string key) records activations (`callerprops.go`).
   - Each sloppy function declaration builds its arguments object. This is the existing `arguments` machinery, enabled by an `arguments` reference added to its body.
   - Each declaration stores its own boxed value and that object in its frame record.
   - The shadow stack's frame record grows two words for this, `{ previous, descriptor, position, function, arguments }`.
   - Main's frame is marked as the module wrapper's.
2. Function metadata flags a sloppy function (`FN_SLOPPY`): a function declaration, or a function expression that is not an object method.
3. A dynamic function's `caller`/`arguments` read reaches `__kml_fn_caller_get` (`fnmeta.c`):
   - a function not flagged sloppy throws;
   - otherwise it walks the frames to the function's newest activation and answers from it;
   - with no activation, the answer is `null`.
   The module wrapper is a five-parameter function record that does nothing. It renders as `[Function (anonymous)]`.

## Consequences

- A sloppy function with a rest or destructured parameter has no recorded arguments object, so it reads `null`. The same goes for an anonymous function expression as a caller.
- Programs that read neither property are unchanged, apart from the two zeroed words in each frame record that no one reads.

## Verification

macOS (Apple Silicon): the probe matches Node's output. It covers live caller and arguments, top-level and nested calls, `null` outside a call, and the TypeError for arrows, methods, generators, async functions and builtins. `TestE2EFunctionCallerArguments` passes.
