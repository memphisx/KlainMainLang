# ADR-01338: Statics per evaluation

- **Relations**: Implements TDD-00242, Extends ADR-01336, ADR-01334, ADR-01333
- **Date**: 2026-10-03

## Context

[ADR-01336](ADR-01336.md) made a class declared in a function, used as a
value, a class per evaluation: each evaluation's record carries its
bindings. Its statics still lived in one global per field, shared by every
evaluation, and a static member, static block or static initializer that
read a local was rejected ("reads it in a static member; not supported
yet"). Node gives each evaluation's class its own statics, initialized from
that evaluation's locals:

```ts
function make(b: number) {
  class D { static base = b * 10; static count = 0; static inc() { return ++D.count + D.base } }
  return D
}
const A = make(1), B = make(2)
A.inc(); A.inc(); B.inc() // 12, 12, 21: A.count is 2, B.count 1
```

Probing Node 24 also showed `this` in a static member (the class) was a
compile error here for every class: "'this' is only valid inside a method
or constructor body".

## Decision

1. **A static area per record** (`unitregsrc/unitreg.c`):
   `__kml_classrec_statics(rec, ref, bytes)` is record `rec`'s static area,
   allocated zeroed on first use; with no record it is the class's own area.
   The layout is every static field of the class (sorted), then an own flag
   per inherited one ([ADR-01318](ADR-01318.md) §6's flags, moved into the
   area).
2. **Which record code reads** (`emit_classstatics.go`, `recordFor`):
   - in the function declaring the class, the local holding this
     evaluation's record;
   - in a static member or the static initialization, the receiver its call
     passed: a direct call (`D.inc()`) and the per-evaluation static re-run
     pass the record they name (`__kml_classrec_recv`); a dispatch through
     the class as a value passes the record whose constructor row it looked
     up (`__kml_unit_find` notes it). Each local class the static member's
     class extends reads its own record up the chain (`__kml_classrec_up`);
   - in an instance member, the record its instance was built from.
   `staticFieldReadPtr`/`WritePtr` and the static-member rows (`nstatic`,
   `sget`) take the slot through it; a class without records keeps its
   globals.
3. **Locals read by static members** become hidden static fields
   (`#__kml_scap_<name>`), set from the locals when the record is made, before
   the static initialization runs. A class with such a field is a record
   class even when it is not otherwise used as a value. Static blocks are
   accepted.
4. **`this` in a static member** (methods, accessors, static field
   initializers, static blocks) is the class's own name, rewritten after
   class hoisting (`staticThisToClass`), outside nested non-arrow
   functions. In a class per evaluation it reads that evaluation's record.
5. A class expression's evaluation makes its record before re-running its
   statics, so the initializers see the record.

## Implementation notes

- An anonymous class expression is named during hoisting; the closure
  conversion's references to it used its placeholder name, so hoisting
  renames that placeholder too.
- The receiver is a thread-local read once, at a static member's entry, into
  a local: a static member that calls another class's static members still
  reads its own record afterwards.

## Side effects discovered

- `this` in a static member of any class was unsupported (above, item 4).
- `TestE2ELocalClassStaticCaptureRejected` asserted the old rejection; it is
  replaced by `TestE2ELocalClassStaticsPerRecord`.

## Remaining

- The record table, the instance table and the static areas are never
  pruned.
- An inherited static method called on a subclass reads `this` as the class
  declaring it, not the subclass (`this` is rewritten to the declaring
  class's name).

## Verification

`TestE2ELocalClassStaticsPerRecord` (both lanes) and
`examples/classes/class_statics_per_eval.ts` match Node 24: per-evaluation
initializers, `++`/`+=` on statics, static blocks, static getters, `this` in
static members of local, expression and top-level classes, a local
subclass's inherited statics, statics read through `any`, `Object.keys`
and inspect of each evaluation's class. Mac (Apple Silicon): the class
suites pass. Linux x86-64: test-par green (Node304, 3,832 tests),
examples 387/387 and Test262 strict 8,196 / js 9,843 (DeskMini).
