# ADR-02020: Classes extending Response, Request and XMLHttpRequest

- **Date**: 2026-11-21

## Context

`class R extends Response` (likewise Request and XMLHttpRequest) was
refused: "extending the builtin 'Response' is not supported yet". These
values are host records with a header word: the value is the body after
that word, and a host box is the object itself. That is the layout a
TDD-00247 host-subclass instance already has, with its own header and the
host's body at +8. Two other problems turned up along the way:

- A plain XMLHttpRequest failed `instanceof XMLHttpRequest`, because its
  host class name read "XHR".
- `String(xhr)` did not compile.

## Decision

- `hostBaseOf` gives the record type for `@lowerType` response, request
  and xmlhttprequest. The instance's hidden body holds the record's
  words.
- The body is built by the builtin's own construction, `new
  <Base>(args)`, with the words copied in. This happens at `super(…)`, or
  at the `new` for a class with no constructor of its own (a field-only
  class's implicit `super()` does not rebuild it). Allocation leaves the
  body zeroed: an argument-less build would throw for a Request.
- Members read on the body, statically and through `any`, as for a Map
  subclass. `instanceof <Base>` holds down the class's bases.
- The XHR host flag names XMLHttpRequest. `String()` of a host object is
  `[object <Class>]`.
- Stream bases (ReadableStream, WritableStream, TransformStream,
  DecompressionStream) stay refused. A stream's controller holds the
  stream itself, so a copy would split its state; the stream must instead
  be built in place in the instance body.

## Implementation notes

- codegen/llvm/lower_type.go: `hostBaseOf`, `hostBodySize`,
  `emitHostBody`, `emitHostRecordBody`.
- codegen/llvm/emit_classes.go: the `new` and `super()` paths, and
  `instanceof`.
- codegen/llvm/emit_hostbox.go (`hostFlagJSName`),
  codegen/llvm/emit_exprs_types.go, resolver/host_bases.go.

## Verification

- `TestE2EHostRecordSubclassTS` matches Node on Linux x86 (Node304).
  `TestE2EXHRSubclassJS` matches the spec's values, since Node has no
  XMLHttpRequest.
