# ADR-01047: `String.prototype.concat`

- **Date**: 2026-09-21

## Context

Writing ADR-01045's chain-depth test, `'…'.slice(1).concat('z')` failed to compile: "a string has no method
'concat'". The method was absent from the dispatch and had no status row; `concat` was only known for arrays and
as the static `Buffer.concat`.

## Investigation

The spec'd behaviour is the receiver followed by `ToString(arg)` for each argument. `ToString` is not what `+`
applies to an object operand: `+` runs ToPrimitive with the default hint (`valueOf` first), `concat` — like a
template-literal substitution — uses the string hint (`toString` first):
`'o:'.concat({ toString() { return 'TS' }, valueOf() { return 7 } })` is `o:TS`, `'o:' + obj` is `o:7`. So
desugaring to a chain of `+` would be subtly wrong; desugaring to a template literal is exact and inherits every
conversion the template path already has (numbers, booleans, `null`/`undefined` as words, nullable scalars, user
`toString`/`@@toPrimitive`).

A spread argument contributes `ToString` of each element. `xs.join("")` is not that: `join` renders a
null/undefined element as the empty string.

## Decision

`emitStringConcatMethod` (`codegen/llvm/emit_strings.go`) builds a template literal with empty quasis whose
substitutions are the receiver and the arguments, and emits it. A spread argument `...xs` becomes the substitution
`` xs.map((c) => `${c}`).join("") ``. `emitCall` dispatches to it when the receiver infers as a plain string
(`isForOfStringTy`, the strict test — a bare `ptr` is also a Map, a RegExp, …); arrays keep `emitArrayConcat`.
`inferExprType` returns `string` for the same receiver test.

## Implementation notes

`codegen/llvm/emit_strings.go`, `emit_call.go`, `emit_exprs_types.go`. Tests:
`tests/string_concat_method_test.go` (4). Example: `examples/strings/string_concat.ts`. Status row in
`string-methods.json`; website reference entry `string.concatMethod` (`string.concat` was already the id of the `+`
entry); String coverage badge 31/32 → 32/33, strict 17/32 → 18/33.
