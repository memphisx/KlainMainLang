# ADR-01743: A box in a typed array keeps its kind

- **Relations**: `Implements TDD-00230`, Extends [ADR-01741](ADR-01741.md), Extends [ADR-01742](ADR-01742.md)
- **Date**: 2026-10-19

## Context

TypeScript lets an `any[]` stand where a `string[]` is declared, and Node's array is the same array either way, its elements keeping their kinds.

- `const ys: string[] = xs` with `xs: any[]` shared the boxed-element storage under a `string[]` type. Reading an element read a number's box as a string pointer, and `console.log(ys)` crashed with a segmentation fault.
- `len(xs)` with `len(a: string[])` had the same hazard inside the callee.
- An array literal holding a value codegen keeps as a box (`[id(anyFive)]`, `[c.n]` with `c.n` shadowed) was built as the checker's `string[]`/`number[]`, converting each element.
- A callback given to a method called on a box (`ys.map(v => typeof v)`) received boxes, but its body read `v` as the checker's contextual `string`.

## Decision

- **Bindings.** A binding annotated as an array of a checkable element kind, and initialized from or assigned an `any[]`, is held as a box of that same array (`boxesInto`), so writes through either name are seen through the other.
- **Arguments.** An `any[]` argument at a parameter whose elements are typed always runs the function's any-argument variant, with that parameter held as a box.
- **Array literals.** A literal with an element codegen holds as a box infers as `any[]` (`boxOverride`), in inference and in the type oracle alike.
- **Callbacks.** An arrow-function parameter whose hint is a box, where the checker's contextual type is another kind, is read as the box in the body, using the dynamic entry's widening.

## Implementation notes

`codegen/llvm/emit_anyarg.go` (`anyElemArray`, `boxesInto`, `anyArgMarks`, `anyAssignedDecls`), `emit_shadowread.go` (`boxOverride`), `emit_func.go` (`emitArrowFunctionWithHints`), `infer_memo.go`, `shadow_binder.go`.

## Verification

macOS (Apple Silicon), against Node, both lanes: `tests/box_container_test.go` — TestE2EAnyElementArrayIntoTypedArray, TestE2EBoxInTypedArrayLiteral; the arrow, callback, map/filter, any-argument and shadowed-field families.
