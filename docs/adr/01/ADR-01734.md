# ADR-01734: Module namespace objects, V8's messages (writes, RegExp syntax, JSON.parse), RegExp empty iterations, replacement templates, typed-array casts, js-mode literals

- **Relations**: `Implements TDD-00230`, Extends [ADR-01731](ADR-01731.md)
- **Date**: 2026-10-18

## Context

- **Namespace objects:** `console.log(ns)` printed `{ … }` where Node prints `[Module: null prototype] { … }`; the object was frozen, where Node's is sealed with writable properties whose writes are rejected.
- **Rejected writes:** every rejected write on a dynamic object named it `#<Object>`, with no object part in the read-only form; deleting a property of a frozen or sealed static object succeeded.
- **RegExp syntax errors:** a pattern error carried PCRE2's bare message (`quantifier does not follow a repeatable item`) without V8's `Invalid regular expression: /p/f:` prefix; `\p{L}` under `u` was rejected as an incomplete quantifier; a quantified lookbehind, or lookahead under `u`, compiled.
- **Replacement templates:** `` $` ``, `$'` and two-digit `$nn` were left literal, expanded by hand-emitted IR; the callback form's status caveats (a fixed `(match, offset, string)`) no longer held.
- **Match results through a type:** a function returning `str.match(r)` for a RegExp parameter returned a plain array: `RegExpMatchArray` mapped to `string[]`, dropping `index`, `input` and `groups`.
- **JSON.parse errors:** every malformed document threw `Unexpected token in JSON at position N`.
- **Empty iterations:** `/(a|)*/` on `"aa"` captured `""`: PCRE2 runs one more, empty, iteration, which ECMAScript rejects once the minimum is met. A capture inside a repeated group kept an earlier iteration's value, which ECMAScript clears.
- **`-compat=js` literals:** an object literal whose property the parameter's declared type cannot hold (`{ argv: 'foo' }` for a `string[]`) was a compile error.
- **Typed-array casts:** `u16 as unknown as Uint8Array` read the Uint16Array's bytes through the Uint8Array layout.

## Decision

- **Namespace objects:** detailed in ADR-01731's update: header bit 36, sealed, writes rejected, `[object Module]`.
- **Messages:** `__kml_dyn_set_throw` and `__kml_static_set_throw` build V8's message from the object (`#<Foo>`, `[object Object]` for a null prototype, `[object Module]`). A static object's delete checks its integrity level.
- **RegExp:** in the ES dialects `__kml_regex_syntax_message` maps PCRE2's compile error code to V8's text, prefixed with the pattern and flags (`Nothing to repeat`, `Unterminated group`, `Invalid group`, `Unmatched ')'`, `Duplicate capture group name`, `Invalid capture group name`, `Invalid property name`, …); the brackets check skips `\p{…}`/`\u{…}` braces; `quantified_lookaround` rejects V8's quantified assertions.
- **Replacement templates:** `__kml_regex_expand` (C) is the spec's GetSubstitution for one match: `$$`, `$&`, `` $` ``, `$'`, `$n`/`$nn` (two digits when that group exists), an unmatched group empty.
- **Match results:** `RegExpMatchArray` is exec's header type, marked possibly plain (`matchArrayType`), as `match` itself returns.
- **JSON.parse errors:** the parser records the first error's reason and position (`fail`); `__kml_json_syntax_message` builds V8's text: the specific message (`Expected ',' or ']' after array element`, `Bad escaped character`, `No number after minus sign`, …) with the position and its line and column, `Unexpected end of JSON input`, the four special sources (`"undefined" is not valid JSON`), or `Unexpected token 'c', "<context>" is not valid JSON` with V8's ten-character context. Positions and context count UTF-16 code units; a context edge inside a surrogate pair keeps the lone half, as V8 does.
- **Empty iterations:** in the ES dialects, a capture group under `*`, `?` or `{0,…}` whose body may match empty becomes `(?:(X)(?C255))`, and under `+` or `{1,…}` `(?Cg)(?:(X)(?C128+g))`. Every ES-mode match runs with one match context per thread whose callout fails an empty iteration (the group just closed is empty), except, under `+`, the first, at the position the start callout noted. After a match, a capture inside a repeated capture group that starts before that group's last iteration is unset. A capture inside a repeated non-capturing group has no outer span to compare with and keeps its earlier value (BACKLOG).
- **`-compat=js` literals:** such a property is stored as from `any`; a value the field cannot hold throws a TypeError at run time, as the library does in Node.
- **Casts:** `x as unknown as T`, with `x` statically a typed array of another kind than `T`, keeps the box (`keepsBoxedTypedArray`), which carries the array's own kind. An `as T` after an `instanceof` test still unboxes.

## Consequences

- A typed-array binding or parameter annotated with another kind than the `any` it receives still reads through its own layout (BACKLOG).
