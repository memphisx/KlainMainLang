# ADR-01153: A lowered rest parameter (`String.prototype.concat`); ToString of an absent string argument

- **Relations**: `Implements TDD-00230` (Phase 3, P3.2); `Extends ADR-01142`
- **Date**: 2026-09-25

## Context

`loweredCall` declined any declaration with a rest parameter or an array
argument, so `concat(...strings: string[])` stayed on its hand-written
emitter. An array crossing the boundary as an argument is the next piece
P3.2 needs: the Array methods and every rest parameter use one.

## Investigation

- **Array results already cross as the header pointer** (ADR-01142).
  An argument can cross the same way: a fresh header whose data is the
  converted arguments, 8 bytes each, which `string.c`'s `array_header`
  reads.
- **An absent string argument crashed** (HEAD too), whether lowered or
  hand-written. Under `-compat=js`, `"anull".indexOf(null)` and
  `"a".concat(undefined)` passed a null pointer into the entry point and
  segfaulted. So did a `string | null` holding null. The literals'
  types (`TypeNull`, `TypeUndefined`) are pointer types that
  `emitArgToString` took as strings, and a nullable string passed through
  unconverted.

## Decision

- **Lowering.** A rest parameter whose type lowers to an array (`string[]`
  so far), as the last parameter, is a `loweredParam` with `rest` set.
  `emitLowered` converts each remaining argument to the element's
  representation (ToString). `restArray` builds a fresh array of them,
  and the call passes its header pointer. `paramIR` gives an array
  parameter as `ptr`. A spread argument still declines to the
  hand-written path.
- **`string.c`'s `__kml_String_concat`** joins the receiver and each
  argument, with Node's RangeError past the maximum string length.
  `lib/es.d.ts` lowers `concat` to it.
- **`emitArgToString`** converts the null and undefined literals to
  `"null"` and `"undefined"`. A nullable string converts to its word when
  absent, chosen at run time.

## Verification

- **`TestE2EStringConcatLowered`** matches Node's output for:
  - no argument and several arguments;
  - multi-byte text;
  - argument evaluation order;
  - a spread;
  - absent strings in both lanes;
  - `-compat=js` numbers, booleans, `null`, `undefined`, an object's
    `toString` and an array.
- **Gates (with ADR-01148–01153):**
  - Test262: strict 7,032 and js 7,832 (the handover's were 7,034 and
    7,825), no clang failures in either lane. The two strict files lost
    call `str.slice(obj, obj2)` with objects for `number` parameters,
    which tsc rejects (TS2345).
  - Node suite: strict 61, js 63, unchanged.
  - `make examples`: 360 pass. `chained_listen` timed out once, its
    known intermittent hang, and passes 3 of 3 runs alone.
  - `make test-par`: only the four macOS `-mm=gc` failures.
