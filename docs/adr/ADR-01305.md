# ADR-01305: zlib's Brotli and Zstd codecs

- **Relations**: `Implements part of TDD-00230` (P3.1), `Extends ADR-01296`
- **Date**: 2026-09-30

## Context

`lib/node/zlib.ts` (ADR-01296) had no `BrotliCompress`/`BrotliDecompress`/
`ZstdCompress`/`ZstdDecompress` nor their one-shot and `create*` forms: they
need libbrotli and libzstd, which Node bundles.

## Investigation

Node v24's lib/zlib.js builds both on `ZlibBase` with a per-family flush
range (Brotli operations 0–3, Zstd end directives 0–2), applies `params` to
the fresh handle (a key out of range or repeated: `ERR_BROTLI_INVALID_PARAM`
/ `ERR_ZSTD_INVALID_PARAM`), and node_zlib.cc's contexts report
`Compression failed`/`ERR_BROTLI_COMPRESSION_FAILED`, `Decompression
failed` with `ERR_` plus BrotliDecoderErrorString's name and the decoder's
code as errno, `unexpected end of file`/`Z_BUF_ERROR` for a truncated Brotli
stream, and ZSTD_getErrorString with the `ZSTD_error_*` name and code for
Zstd (a truncated Zstd frame is no error). Checked against Node 24.19.

## Decision

- `klainzlib.c`: modes 8–11 in the same handle table and write path, over
  BrotliEncoder/Decoder and ZSTD_CCtx/DCtx; `zlibSetParam` and
  `zlibInitOther` (dictionary, pledged source size). The libraries load with
  `dlopen` (the system's, then Homebrew's and `/usr/local`'s) the first time
  a Brotli or Zstd stream is made, with the stable C prototypes declared in
  the unit, so a program using zlib needs neither to build or run; without
  them the stream's init fails with `ERR_ZLIB_INITIALIZATION_FAILED`. Linux
  links `-ldl`.
- `zlib.ts`: `Brotli`/`Zstd` bases, the four classes, `brotliCompress`/
  `brotliDecompress`/`zstdCompress`/`zstdDecompress` (callback and `*Sync`),
  `createBrotli*`/`createZstd*`, the per-family flush bounds.

## Verification

`tests/streams_test.go` `TestE2EZlibBrotliZstd` and
`examples/zlib/brotli_zstd.ts` print what Node 24.19 prints (byte-identical
Brotli and Zstd output at the same parameters); the zlib suites pass. macOS
(arm64), Homebrew brotli 1.2 and zstd 1.5.7.
