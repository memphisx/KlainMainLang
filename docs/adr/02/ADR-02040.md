# ADR-02040: A builtin module namespace's `default`

- **Date**: 2026-11-22

## Context

- `import * as os from 'node:os'` (and `import('node:os')`) lacked Node's
  `default`, the module's `module.exports`. The resolver reported
  `os.default` as a missing export.

## Decision

- The resolver rewrites `ns.default.x` to `ns.x` and a bare `ns.default`
  to the namespace object, for a namespace of a builtin module
  (`builtinDynamicSpec`) that exports no `default` of its own.
- That namespace object gets a `default` getter returning the object
  itself, listed with its other keys.

## Consequences

- Tests: `TestE2EBuiltinNamespaceDefaultTS`.
