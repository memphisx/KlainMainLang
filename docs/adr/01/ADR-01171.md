# ADR-01171: Compiler fixes found by the net/tls/http port

- **Relations**: `Extends [ADR-01170](ADR-01170.md)`, [ADR-01168](ADR-01168.md), [ADR-01169](ADR-01169.md)
- **Date**: 2026-09-26

## Context

Porting Node's `net`, `tls` and `http` (ADR-01170) as ordinary TypeScript hit
these gaps; a program hits them too. Each is fixed where it lives.

## Investigation and decision

**Checker**
- Assignment narrowing (`let d = this.cache; if (d === null) d = {}`)
  kept `T | null`: an object assigned to a union narrows to the members it
  is assignable to (tsc's getAssignmentReducedType), by the real relation.
- `x instanceof Error` (a constructor declared as a value, `declare var
  Error: ErrorConstructor`) narrowed nothing: the instance type is the
  construct signature's result, in both branches.
- A type predicate's false branch removed `Uint8Array` for `Buffer.isBuffer`:
  two named object types of one kind are within each other only when the
  relation says yes.
- TS2411 (a property outside the string index signature's type) is
  reported; named properties beside an index signature are allowed.
- A bare name a builtin module written in TypeScript declares (an
  unimported `IncomingMessage`) is TS2304, as tsc has it.

- `catch ({ message })` without an annotation destructures an `unknown`:
  tsc's TS2339 for each name.

**Parser**
- A destructured catch binding takes a type annotation
  (`catch ({ message }: any)`).

**Resolver**
- An interface's index signature and call signature, and an inline type's
  index signature, were not renamed with the program's other type names.

**Code generation**
- Unions: a `string[]` (and a byte array beside it) or an index-signature
  dictionary is a union member; a union narrowed by the checker (in a
  ternary, after an early return, on a property path) reads as its member,
  arrays included; `.length` on a `string | string[]`; `as` from a union to
  a member or to `any`; a union's function member unboxes through its
  adapter; a union's fallback in `??` is built as its member (`opts ?? {}`);
  a single member beside null is that member, nullable; `typeof` of a
  `T | null` scalar holding null is `"object"`.
- Dictionaries (`{ [k: string]: V }`): named properties read with their
  declared type; union values box and read back (a missing key is
  undefined); `for…in`; inspect and JSON render the plain object (they
  printed `Map(…)`); an object literal passed or assigned where one is
  expected builds the dictionary, with the target's value type; an array
  value mutates through `d[k]!.push(…)`; a dictionary boxes as its pointer;
  a missing key of a string, object or number value reads `undefined` (it
  read `null`, or 0).
- An absent object-literal field of a box type (any, a union) is
  `undefined`, not the zero word.
- Compound and logical assignment (`o.n += 1`, `o[k] ??= v`) on an `any`
  base in the strict lane (logical ones wrote unconditionally).
- A class type captured before its fields were registered (a type alias's
  function type naming it) binds as the live class.
- `removeListener` of a closure that reached the emitter through a typed
  adapter (a `(err: Error) => void` passed as `(...args: any[]) => void`)
  now finds it: records compare by the closure the adapters lead to.
- An object passed to a union's object member of another layout
  (`const o = { cert, key }` as `TlsOptions | fn`) is copied into the
  member's layout: its concrete fields box into the member's union fields,
  the fields it lacks are undefined.
- A caught value captured by a closure (a `catch (e)` whose name some
  closure in the program captures) boxes as its two-word aggregate.
- An unannotated class field initialised by a call of a function declared
  later in registration order (`server = http.createServer(…)`, `f = mk()`)
  has the function's declared return type, not the number default.
- An unannotated top-level `const` a function or class reads is a module
  global when codegen infers its initializer's type as the checker types it
  (`const crlf = Buffer.from('\r\n')`, a class instance from a call), or
  when it is a `new Map` with entries stable before `main()`.
- A caught value that is not an Error reads its Error fields (`message`,
  `name`, `code`, …) as undefined, not `""`/0; a destructured catch binding
  reads each name as that member, its default taking an undefined one.
- A binding initialised by an assertion to a union (`let c = "5" as string
  | number`) holds the union, not the operand's type.
- A class still registering keeps its placeholder type where a method's
  `this` is bound (the published info has no type yet): `this.m()` inferred
  from a sibling method.
- An `any` holding a non-string bound to a string parameter or slot is
  its ToString (a Buffer emitted to a `(chunk: string) => …` listener).
- `Timeout.unref()`, `ref()`, `hasRef()`, `close()`: an unref'd timer fires
  while something else keeps the loop but does not keep it itself.
- `ReturnType<typeof setTimeout>`; `Date.prototype.toUTCString`;
  `mustCall(fn)` passed where a function type is expected types fn's
  parameters from it; `return null` from a `T[] | null` function; object
  destructuring of any object-valued expression; an Error's fixed field set
  through `any` from a `T | undefined` value, and read back from its bag;
  `str-map[k]` declares its runtime helpers.

## Side effects discovered

- The union member's copy is a copy: writes through the parameter do not
  reach the caller's object (BACKLOG), as for any relaid-out object.

- `interface X extends Error` holds the Error representation only when its
  own members are fields every Error has.
