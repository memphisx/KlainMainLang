# ADR-00548: String.search coerces a plain-string argument to RegExp

- **Relations**: Extends ADR-00028
- **Date**: 2026-09-01

## Context

`String.prototype.search` ran a real PCRE2 search only when the argument was
already a `RegExp`; a plain-string argument fell back to `.indexOf()`-shaped
literal matching. Real JS coerces the argument to a `RegExp` (`re = new
RegExp(arg)`), so `"a.b".search(".")` is `0` (the `.` matches any character),
not `1` (the literal-dot index). This was a disclosed caveat on the
string-methods status page.

## Investigation

`emitStringSearch` (emit_strings.go) already routed a `RegExp` argument through
`emitRegexSearch`. `new RegExp(pattern)` compiles its pattern from a runtime
string via PCRE2 (emit_regexp.go `emitNewRegExpExpression`), so a plain-string
argument can reuse the exact same construction path — no new runtime needed.
`NewRegExpExpression` exposes `Pattern`/`Flags` as exported fields, so a
synthetic node wrapping the string argument can be built and handed to
`emitNewRegExpExpression`.

## Decision

In `emitStringSearch`, when the argument is a string (not already a `RegExp`),
synthesize `&ast.NewRegExpExpression{Pattern: args[0]}`, compile it via
`emitNewRegExpExpression`, and run `emitRegexSearch` against it — identical to
the `RegExp`-argument path. A `RegExp` argument still emits directly. A
genuinely non-stringy, non-RegExp argument keeps the `emitStringIndexOf`
fallback.

## Implementation notes

- Special characters are now interpreted, matching JS; an invalid pattern
  (e.g. `"("`) throws a catchable `SyntaxError`, exactly as
  `new RegExp("(")` already does.
- The synthetic node's position is the zero `Pos`; it is only used for
  construction, and any pattern error surfaces through the RegExp compiler's
  own message, so this is immaterial.

## Side effects discovered

None.

## Verification

`TestE2EStringSearchCoercesPlainStringToRegExp` (`"a.b".search(".")` → `0`,
`"[0-9]+"` and `"\\d"` cross-checked against Node) plus the existing
`.search` tests pass. Built and verified on Mac (Apple Silicon).
