# ADR-02045: A class may extend a stream class

- **Date**: 2026-11-22

## Context

- `class C extends ReadableStream` (`WritableStream`, `TransformStream`,
  `CompressionStream`, `DecompressionStream`) was refused at parse time.
  The other host bases copy the builtin's record into the instance body;
  a stream cannot move, since its controller points at the stream itself.

## Decision

- A stream base's body is one word holding the stream's pointer
  (`hostStreamBase`, `hostBodySize` 1). `super(…)`, or a `new` with no
  constructor of the class's own, builds the stream as the builtin's own
  construction, with the class's extends-clause type arguments
  (`emitHostStreamBody`, `streamBaseArgs`).
- `bindHostBody` loads the stream from the word, so the host's members
  and methods reach it. Converting an instance to the stream type loads it
  too, as do `for await`, `pipeTo`/`pipeThrough` arguments, a Response
  body and a Request/fetch init body (`streamOfInstance`,
  `streamArgExpr`). `Object.prototype.toString` names the stream class.

## Consequences

- The parse-time refusal and its diagnostic are gone.
- Tests: `TestE2EClassExtendsStreamTS`.
