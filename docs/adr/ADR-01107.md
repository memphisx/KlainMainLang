# ADR-01107: A shadow harness comparing codegen's type deciders with the new front end

- **Relations**: `Implements TDD-00230` (Phase 0, P0.2); `Extends ADR-01099`
- **Date**: 2026-09-24

## Context

Phases 2 and 3 of [TDD-00230](../tdd/TDD-00230.md) replace the places where
codegen decides a type on its own (`inferExprType` with about 545 call sites,
`resolveType`, `reliableGlobalType`, `inferUnannotatedReturnType`, and the
rest) with the checker. Switching a decider over in one step would change
every program's IR at once. P0.2 asks for a harness that runs the new pass
alongside the old deciders, records every disagreement, and ranks them over
the corpus, so each decider is switched only when it agrees everywhere, and
then deleted.

## Investigation

- **The deciders.** `inferExprType` (`codegen/llvm/infer_memo.go`) is a
  memoising wrapper over `inferExprTypeUncached` and is re-entered for every
  sub-expression. `resolveType` (`emitter.go`) recurses into nested
  annotations. `reliableGlobalType` and `inferUnannotatedReturnType` answer
  once per declaration and function body. All four return a codegen `Type`.
- **Comparing types.** `Type` has no equality and no complete string form:
  over 100 flags, nested element, key, value and field types, and a few AST
  expressions (parameter defaults). `tsTypeName` renders only a coarse name.
- **P0.1's switch.** `KML_IR_SITES` is read at start-up; with it unset the
  output is byte-identical. The same shape suits this harness.
- **Positions.** The resolver merges every module into one program, so a node
  knows its line and column but not its file. The run's entry file is known
  to whoever starts the compile.

## Decision

- **An oracle interface in codegen, `ShadowOracle`,** with one method per old
  decider: `ExprType`, `AnnotationType`, `GlobalType`, `ReturnType`. Each
  returns the new pass's answer already mapped to codegen's representation (the
  mapping is `reprOf` once P3.3 exists), or ok=false where the new pass has no
  answer yet. `llvm.NewShadowOracle` is the registration point: nil until the
  new pass registers a constructor.
- **Hooks.** Each of the four deciders becomes a thin wrapper around its
  unchanged body (`decideAnnotationType`, `inferExprTypeMemo`,
  `decideGlobalType`, `decideReturnType`). The wrapper asks the oracle only
  when one is set, and only after the decider has answered, so the old answer
  is what codegen uses. Recursive calls go through the wrapper, so nested
  expressions and annotations are compared too.
- **Switch.** `EmitProgram` turns the comparison on when `KML_SHADOW` names a
  file and an oracle is registered. `KML_SHADOW_UNIT` labels the run's
  records with its entry file.
- **Comparing.** Two types agree when their representation keys are equal: a
  canonical rendering of every non-zero exported field, nested types included,
  AST expressions and functions left out (`reprKey`). A disagreement records
  the decider, the node kind and position, both keys, and the top-level fields
  that differ (`presence` when one side had no answer).
- **A `shadow` package** holds the record (`Disagreement`), a JSON-lines
  `Recorder` that writes each decider and node once, and `Aggregate`, which
  ranks records into buckets by decider, node kind and differing fields.
- **`make shadow-report`** (`tools/shadow`) compiles the corpus with
  `-emit-llvm` (examples, tools, apps, and Test262's language tests, a `.js`
  file in both lanes, as the IR equivalence tool does), one record file per
  run, and writes the ranked report to `.shadow-out/SHADOW-REPORT.md`: totals
  per decider, the bucket table, and three examples of each of the top 30
  buckets. `.shadow-out/` is not committed until the report has rows worth
  tracking.

## Implementation notes

- **New:** `shadow/shadow.go`, `shadow/shadow_test.go`,
  `codegen/llvm/shadow.go`, `codegen/llvm/shadow_test.go`,
  `tools/shadow/main.go`.
- **Changed:** `codegen/llvm/emitter.go` (the Emitter's two fields, the
  `resolveType` wrapper, the switch in `EmitProgram`),
  `codegen/llvm/infer_memo.go`, `codegen/llvm/emit_exprs_vardecl.go`,
  `codegen/llvm/emit_func.go`, `Makefile`, `.gitignore`, `README.md`.
- **Cost when off:** one nil check per decider call.
- **Not yet hooked:** codegen's other deciders (the jsinfer pass,
  `promotedStorageAgrees`, generic concretisation, the `infer*` family beyond
  the four). Each gets a method and a hook when the checker can answer its
  question; until then a hook would compare nothing.

## Side effects discovered

- **The examples run had no per-example time limit.** One run of
  `examples/http/req_readable` (the flaky hang in BACKLOG §0 item 1) stalled
  `make examples` for nine hours until it was killed by hand. Each example
  now runs under a 300-second limit (`EXAMPLE_TIMEOUT`, through `perl`'s
  `alarm`, since macOS has no `timeout`), so a hang fails that example and the
  run continues. The hang itself stays BACKLOG §0 item 1.

- **Two package tests had gone stale** in earlier staged work: `dynjson.c`
  gained two externs (`__kml_fn_inspect_dyn`, `__kml_boxed_bigint_str`) that
  `ensureDynJSONC` already provides, but `sidecar_layout_test.go`'s extern list
  and its layout probe's stubs were not updated. `make test-par` runs only
  `./tests`, so neither gate saw it; both are updated, and every step's gate
  now also runs `go test` over the other packages.

## Verification

All on macOS arm64 (M4):

- `go test ./shadow ./codegen/llvm -run 'Shadow|ReprKey|RecordOnce'`: with a
  deliberately disagreeing oracle the emitted IR is byte-identical to a run
  without it; disagreements are recorded for `inferExprType` and
  `resolveType`, once per node; representation keys tell `Nullable` apart and
  render nested element types; aggregation ranks and counts.
- **End to end with a stand-in oracle** (a scratch build, not committed, whose
  oracle calls every call expression an `i8` and every global non-promotable):
  `tools/shadow -limit 20` recorded 495 disagreements in 15 buckets, headed by
  `inferExprType` on `CallExpression` differing in `IR` (233), with
  `reliableGlobalType`'s `presence` rows (30).
- With no oracle registered, the hooks ask nothing: the unit test above
  shows the IR is byte-identical even with a disagreeing oracle, and the
  gates below ran with recording off.
- `make examples` (with ADR-01106): 358 passed, 0 failed, and
  `make conformance`: strict 7,084, js 7,669, invalid IR strict 1, js 5, as
  recorded in ADR-01106.
- `go test` over every package but `./tests` passes.
- `make test-par` (with the other of the two): passes apart from the four
  known macOS `-mm=gc` thread-local-root failures in
  `tests/task_reclaim_gc_tls_test.go`. An earlier run hit the known flaky
  `TestE2EHTTPServerListeningEvent` hang (BACKLOG §0 item 1), which then
  passed six times of six alone; another timed a shard out while a second
  heavy job ran beside it.
