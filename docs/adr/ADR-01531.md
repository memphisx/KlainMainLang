# ADR-01531: A return type inferred through its own function is TS7023

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-10

## Context

An unannotated function whose return expressions reach itself, directly
(`return n * fact(n - 1)`) or through other functions, has its return
type inferred while it is being inferred. tsc gives it `any` and, under
noImplicitAny, reports TS7023 at each function on that cycle. The
checker gave the `any` but reported nothing, so the strict lane
accepted programs tsc rejects, and compiled their result as a box.

## Decision

- The checker keeps its symbol-resolution stack; when a function's type
  is re-entered, every unannotated function from it up the stack gets
  TS7023 (once), at its name, when one of them calls it (tsc infers a
  return type for a call; a reference to the function as a value, such
  as `return g`, does not). Not in the js lane.
- A `return f(…)` of the function itself is not typed: it returns what
  the other returns do (tsc's `never` for it), so it neither joins the
  result nor makes the cycle.
- Function declarations and expressions record their name's position
  (`NamePos`).
