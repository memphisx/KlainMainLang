# ADR-01037: Optional chaining completed — `f?.()`, `a?.[k]`, whole-chain short-circuit; mixed-kind `??` yields a union

- **Relations**: `Extends ADR-00682, ADR-00834, ADR-00652`; `Implements TDD-00180` (the `process.getuid?.()` row)
- **Date**: 2026-09-21

## Context

Node leaves `process.getuid`/`geteuid`/`getgid`/`getegid` undefined on Windows, so the portable spelling is `process.getuid?.()`. That did not parse: `?.` accepted only a property name (`parse error: expected IDENT, got (`), and `a?.[k]` failed the same way. Building the two forms surfaced three further defects in the same area, none of them new:

1. **A chain did not short-circuit as a whole.** `r?.name.length`, `r?.tags.length`, `r?.name.toUpperCase()` with a nullish `r`: only the `?.` link itself was guarded; the following `.length` / `.toUpperCase()` then ran against the absent value — a crash for a string, the zero-shaped array's `0` for an array (a test pinned that `0`). JS yields `undefined` for the whole chain.
2. **A nullable scalar lost its absence when its payload type changed.** A `{ i1, i64 }` `undefined` passed where a `number | undefined` parameter is `{ i1, double }` arrived as a *present* `0`: `coerce` demoted the aggregate to its payload and the scalar→nullable branch re-wrapped it as present. The argument-boxing path (`boxNullableScalarFromValue`) had the same flaw.
3. **`x ?? "fallback"` with a number or boolean `x` emitted invalid IR** (`store double <ptr>`): `emitNullCoalesceScalar` coerced the right operand into the left's payload slot unchecked. The string-left form (`s ?? 42`) had been made a clean rejection by ADR-00652; the scalar-left form was never covered.

## Investigation

- Parser: `parseCallMember`'s `OPTIONAL_DOT` case went straight to `expectPropertyName`.
- Codegen had three single-link emitters (`emitOptionalMember`, `emitOptionalCall` for `a?.m()`, and the nullable-scalar receiver variant). Each guards its own link and returns; nothing looked further up the chain. `emitOptionalCall`'s comment claims nested chains compose because "a nullish inner link already produces the null sentinel this guard catches" — true for a pointer, false for an array or scalar result, which have no null sentinel.
- The AST has no parenthesis node, so `(a?.b).c` and `a?.b.c` were indistinguishable.
- `emitVarDecl` runs its own per-shape pre-inference before `inferExprType`; its blind `i64` default sized `const r = cb?.(1)` for a bare number, storing a skipped call as a present zero.
- Declared unions (`number | string`) are an `IsDynamic` type with `UnionMembers`, NaN-boxed; `coerce(value, unionTy)` boxes a member. A mixed-kind ternary is still a clean rejection; `??` had no such check on the scalar path.
- The box reads a `string | undefined` pointer's static `IsUndefined` flag as the literal `undefined`, so boxing a *present* optional string produced `undefined`.

## Decision

**Syntax.** `ast.CallExpression.Optional` (`f?.(args)`), `ast.IndexExpression.Optional` (`a?.[k]`), and `ChainEnd` on member/index/call nodes, set by the parser on a parenthesised expression.

**Single optional link** (the `?.` is the chain's last link):
- `f?.(args)` — `emitOptionalCalleeCall`. The callee is classified: a function-typed variable, parameter or object/class field is evaluated once, bound to a temporary and null-guarded; a declared function, method or built-in is never nullish, so the call is ordinary and keeps its plain return type; `process.getuid`/`geteuid`/`getgid`/`getegid` are *host-dependent* — skipped on Windows, called on POSIX, and typed `number | undefined` on every host so a program's types do not change with the target. The bare `process.getuid()` stays a compile-time rejection on Windows (a `TypeError` in Node), now pointing at the optional call.
- `a?.[k]` — `emitOptionalIndex`: a pointer receiver is guarded, an array or scalar receiver uses plain access, as `a?.x` already did.
- All forms share `emitNullGuardedExpr(isNull, through)` (extracted from `emitOptionalCall`): it skips `through` entirely — call arguments, element key — and yields a real `undefined`. A guarded expression that is itself `T | undefined` passes its own aggregate through instead of being wrapped a second time.

**A chain continuing past a `?.`** — `emit_optional_chain.go`. `emitExpr` and `inferExprType` first ask `optionalChainDepth`: walking down the spine (member/index receiver, call callee, `!` operand, stopping at a `ChainEnd` child), find the leftmost `?.`. If it sits below the top node, guard once there: evaluate its base, bind it to a temporary, and emit the remainder — a copy of the spine with that link made plain and reading from the temporary — inside the guarded branch. A further `?.` to the right is the leftmost optional link of the remainder, so this composes (`r?.inner?.count`). The guard is a null check for a pointer base and the presence bit for a nullable-scalar base (`m.get(k)?.toFixed(1).length`); a base that cannot be absent makes the chain plain. Only the spine is copied; the AST is never mutated. `emitVarDecl` defers to `inferExprType` for such a chain and for an optional call.

**Nullable scalar → nullable scalar of another payload**: `coerce` converts the payload and carries the presence bit; `boxNullableScalarFromValue` routes through it.

**`a ?? b` with operands of different scalar kinds** yields their union (`nullCoalesceUnion`, shared by emission and inference): each branch boxes its value, and a `string | undefined` right operand is boxed by a run-time null test rather than its static flag. Applies to a nullable-scalar left, its narrowed-non-null form, and a string left — which replaces ADR-00652's rejection.

## Side effects discovered

Reading a member of a value that is `undefined` at run time — `s.length` for an omitted `s?: string`, or the parenthesised `(r?.name).length` — crashes (or, outside a `try` on Windows, hangs) instead of throwing `TypeError: Cannot read properties of undefined`. Independent of optional chaining and not addressed here.

A mixed-kind ternary (`c ? 1 : "a"`) is still a clean compile-time rejection.
