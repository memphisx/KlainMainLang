# ADR-01462: A -compat=js destructuring target holds any kind

- **Relations**: Extends TDD-00162
- **Date**: 2026-10-07

## Context

A shadow bucket (110 locations) was `inferExprType` of no node: the
`-compat=js` widening pre-pass (`crossTypeWidenedBindings`) records a
destructuring assignment's targets as assigned "a value of unknown kind" by
passing a nil expression, which inferred as the integer default. Probing
it: `var x = 1, y = 'a'; [x, y] = ['s', 2]` printed `NaN number number`;
Node prints `s 2 string number`.

## Investigation

A nil right-hand side inferred `i64`, a concrete kind: `x` (a number) saw
no second kind and stayed a number slot; the string stored into it read
back as `NaN`.

## Decision

The pre-pass notes a destructuring target as `any`, and an `any` value
counts as a kind of its own: a binding that also holds a number or string
widens to the any-box, as JavaScript's binding holds whatever it is given.

## Verification

- `TestE2EJSDestructuringAssignmentWidens` (against Node); the js-lane,
  dynamic, object-literal and destructuring E2E tests pass on the Mac.
