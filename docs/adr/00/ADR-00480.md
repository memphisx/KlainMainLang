# ADR-00480: caveat clearing — readonly fields, enum brackets, namespace type-member chains

- **Relations**: Extends [ADR-00447](ADR-00447.md), [ADR-00450](ADR-00450.md)/[ADR-00453](ADR-00453.md)
- **Date**: 2026-08-29

## Context

A deliberate pass over `docs/status` caveats (each cleared caveat also
moves its row toward Strict Coverage):

- "the `readonly` *field* modifier is still not parsed" (Classes row);
- "outside `X.Enum.Member` access is unsupported" (Namespaces rows,
  TDD-00148's open item);
- enums had no bracket access (`E["B"]`) and no numeric reverse mapping
  (`E[1]` → `"B"`), both real TS/JS surface.

## Decision

- **`readonly` field modifier**: contextual in the class-member modifier
  loop (a field literally named `readonly` still works, including
  `readonly = 5`); recorded-not-enforced, the ADR-00447 ctor-param
  stance. `static readonly` composes.
- **Enum bracket access**: `E["lit"]` is the member's value (unknown
  member: clean error). A numeric index is the *reverse* mapping — a
  compile-time-unrolled compare chain over the (sorted, deterministic)
  member set yielding the member-name string, `"undefined"` for an
  unmatched value (JS: `E[99] === undefined`). Numeric enums only — a
  string enum's reverse lookup is a clean rejection.
- **Namespace type-member chains**: a new `stripNSTypeQualifier` rewrites
  `ns.TypeName` → the bare desugared identifier when `ns` is a namespace,
  the property is not a value member, and it names a registered
  enum/class — matching exact and resolver-suffixed (`Color__kml_mod0`)
  forms, since the namespace root itself is never renamed. Hooked at the
  top of `emitMember` (pure AST rewrite), the static-call branch of
  `emitCall`, and inference — so `X.Color.Red`, `X.C.staticMethod()`,
  `X.C.staticField`, and `new X.C(…)` all resolve.

## Verification

Mac. New E2Es in `tests/classes_test.go` (readonly incl. the
`readonly`-named field), `tests/type_features_test.go` (bracket +
reverse mapping incl. runtime index and unmatched), and
`tests/namespaces_test.go` (all four chain shapes); enum/namespace
examples extended; parser + enum/namespace/class/static batches green.
TS oracle: **57.1% → 57.2%** (agreement 5289 → 5296). Node oracle
unchanged (40).
