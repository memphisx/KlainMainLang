# ADR-00899: Non-ASCII identifiers escaped in LLVM symbol names

- **Date**: 2026-09-12

## Context

Part of the invalid-IR (Test262 `CLANG_ERROR`) sweep. A variable whose name uses
non-ASCII letters — which JS/TS fully allow — emitted an illegal bare LLVM global
name:

```ts
var а = 1;   // Cyrillic 'а'
```

clang: `expected '=' in global variable` on `@__kml_global_а__kml_mod0`. From
`language/identifiers/vals-rus-alpha-{lower,upper}.js` and `vals-cjk.js`.

## Investigation

`llvmSafeSymbol` (`codegen/llvm/emit_classes.go`) — the shared choke-point that
builds symbol names from user identifiers — only substituted `@@` (well-known
symbol) and `#` (private name). LLVM's unquoted identifier grammar is
`[A-Za-z$._][A-Za-z0-9$._]*`; a non-ASCII rune is illegal and must be escaped or
quoted. The name flowed straight into `@__kml_global_<name>` (and function/method
symbols), which clang rejects.

## Decision

Extend `llvmSafeSymbol` to escape any rune outside the bare-identifier set
(`[A-Za-z0-9_$.]`) to `__kml_u<hex>_` — deterministic and in the reserved
namespace, so it stays injective against real identifiers. A fast-path
`isBareLLVMIdent` keeps the common all-ASCII symbol zero-alloc.

Because every global/function/method/field symbol already routes through
`llvmSafeSymbol`, one change fixes all of them consistently (definition and
reference sites share the transform).

## Implementation notes

- `isBareLLVMIdent` guards the builder so only names that actually contain an
  illegal rune allocate.
- Top-level *function* names are built from a pre-computed `llvmName` passed into
  `emitFunctionDeclAs` and do not all route through `llvmSafeSymbol`, so a
  non-ASCII top-level function name is a known remaining edge (not in the failing
  corpus, which uses non-ASCII variables); threading the escape through every
  function def+call site is deferred.

## Side effects discovered

None; all-ASCII symbols are unchanged.

## Verification

- `TestE2EUnicodeIdentifier` (new).
- The three `language/identifiers/vals-*` files now compile clean.
- `make examples` 296/296.
