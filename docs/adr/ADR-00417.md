# ADR-00417: http2 Stage 4 — constants and the settings helpers

- **Relations**: Implements [TDD-00139](../tdd/TDD-00139.md) Stage 4; Extends [ADR-00416](ADR-00416.md)
- **Date**: 2026-08-27

## Context

The http2 long tail: `http2.constants` (~23 corpus files) and
`getDefaultSettings`/`getPackedSettings`/`getUnpackedSettings` (~31). The
packing order and defaults were pinned from the corpus's own expected wire
bytes rather than assumed.

## Decision

- **`http2.constants` is a compile-time namespace** (like the class-name
  statics): a member read resolves to its literal — `HTTP2_HEADER_*` /
  `HTTP2_METHOD_*` strings, RFC 7540 §7 error codes, the nghttp2 library
  codes the corpus asserts on, and the default-settings values. A binding
  (`const constants = http2.constants` — the corpus's dominant form after
  the destructured-import rewrite) carries an `IsH2Constants`-flagged dummy
  value so reads through the alias resolve identically. Unknown members are
  a clean rejection naming the covered categories.
- **`getDefaultSettings()`** returns the typed settings record with Node's
  defaults (headerTableSize 4096, enablePush, maxConcurrentStreams 2³²−1,
  initialWindowSize 65535, maxFrameSize 16384, maxHeaderListSize 65535,
  enableConnectProtocol false).
- **`getPackedSettings(obj)`** packs 6-byte entries (identifier 2B +
  value 4B, big-endian) in identifier order 1..6, 8 — including only the
  fields the argument provides: a literal's own keys, or every known field
  of a typed object value (`getPackedSettings(getDefaultSettings())`).
  Unknown literal keys are clean rejections. Returns a Buffer.
- **`getUnpackedSettings(buf)`** is a runtime parse loop back into the
  record: unknown identifiers skipped, later entries win, absent fields stay
  zero-valued (matching Node's only-what-the-buffer-carries posture; the
  length-validation RangeErrors are not modeled).

## Implementation notes

New `codegen/llvm/emit_http2_settings.go` (table, namespace resolution,
three emitters); hooks in `emit_exprs_member.go` (member reads),
`emit_call.go` (dispatch), `emit_exprs_types.go` (inference), `types.go`
(`IsH2Constants`).

## Side effects discovered

- **Regression caught by the full suite and fixed**: the Map bracket-get
  added in ADR-00415 numerically converted number-typed map values, but the
  string-map runtime stores a double's *bit pattern* in its i64 slot — an
  index-signature read came back as `4607182418800017408` instead of `1`.
  Bracket-get now bitcasts for double-valued maps, mirroring `.get`.
- Corpus settings tests asserting `deepStrictEqual` on Buffers or exact
  `ERR_HTTP2_INVALID_SETTING_VALUE` RangeErrors keep failing honestly
  (TypedArray deep-equal is a disclosed assert gap; the validation taxonomy
  is out of scope).

## Verification

New E2E `TestE2EHTTP2ConstantsAndSettings` (constants direct + aliased,
defaults, exact packed bytes, pack→unpack round trip) passes; new example
`examples/http2/constants_settings.ts` compiled and run; index-signature
suite re-run green; Node oracle + full `make test-par` re-run (Mac).
