# ADR-00603: Object-literal getters/setters via a synthetic accessor class

- **Relations**: Implements [TDD-00153](../tdd/TDD-00153.md); reuses [TDD-00030](../tdd/TDD-00030.md)'s class accessor dispatch and [ADR-00386](ADR-00386.md)-era `this`-binding
- **Date**: 2026-09-01

## Context

Class getters/setters worked; object-literal ones (`const o = { get x() { return this._x }, set x(v) { this._x = v } }`) did not — a parse error, and deeper, no `this` on a plain object. This closes the object-literal half of the "Getters / setters" status row.

## Decision

Lower an object literal that declares at least one `get`/`set` to an instance of
a **synthesized anonymous class** `__kml_objlit_<N>`, reusing the entire proven
class-accessor subsystem rather than building a parallel object-accessor path.

- **Parser**: `parseObjectLiteral` accepts `get x()`/`set x()` (contextual
  2-token lookahead, mirroring the class-member grammar), storing each as an
  `ObjectProperty` with `AccessorKind` + a `FunctionExpression` value.
- **Registration** (`ensureObjLitClass`): builds a `ClassInfo` — data properties
  become fields; each accessor is registered under `accessorMethodName("get"|"set",
  prop)`, the exact dispatch key the class path reads. This is **metadata only**
  (no IR), so it is safe to call from the pure-inference path: `inferObjectType`
  returns the synthetic class type, keeping the variable-slot type consistent
  with the emitted value. Registration is memoized per literal (`objLitClasses`).
- **Emission** (`emitObjectLiteralWithAccessors`): emits the accessor bodies once
  via the existing `emitClassMember` (which binds `this` to the receiver), then
  constructs the instance in the literal's own scope (calloc + tag + field
  stores) — so a data initializer referencing an enclosing local works.
- **Dispatch**: because the value's `Type` is now `IsClass`, the member-read
  (`emit_exprs_member.go`) and assign (`emit_exprs_assign.go`) accessor hooks —
  already gated on `IsClass` — fire with **no change** to that codegen. `o.x`
  calls the getter; `o.x = v` / `o.x += v` route through the setter.

The rejected alternative — a parallel accessor table on the object `Type` plus a
new object `this`-binding path — duplicates the class machinery and re-solves
`this` from scratch.

### Structural-typing boundary

A synthetic class is nominal; its accessors are methods, not fields. Assigning an
accessor-bearing literal to a *different* structural object type (`const p: { x:
number } = o`) would structurally read a non-existent field. `coerciblePure`
rejects a synthetic-objlit-class → different-object/class coercion, and
`emitVarDecl` rejects the annotated-binding form with a clear message. Direct use
(`o.x`, `o.x = v`, `this` inside the accessor) — the common case — is fully
supported. The synthetic name never leaks: `console.log(o)` prints `{ ... }`.

## Verification

`TestE2EObjectLiteralGetterSetter`, `…AccessorsMixed` (multi-field getter,
local-referencing initializer, compound assign), `…UnannotatedGetter` (return
type inferred from the read field), `…GetterNoSetterRejected`, and
`…AccessorStructuralAssignRejected`. Example `examples/objects/getters_setters.ts`
matches Node v26 exactly. Object/class suites still pass. Built and verified on
Mac (Apple Silicon).
