# ADR-01591: Buffer.concat takes a list with a spread element

- **Date**: 2026-10-11

## Context

`Buffer.concat([head, ...rest])` failed to compile ("Buffer.concat's list
elements must be Buffers or byte TypedArrays").

## Investigation

The array-literal fast path of `Buffer.concat` (`emit_buffer.go`) types
each element as a Buffer. A spread element's own type is the array.

## Decision

A literal list with a spread element takes the general list path
(`emitBufferConcatList`), which evaluates the list as an array.

## Verification

`TestE2EBufferConcatSpreadList` matches Node.
