# ADR-01568: A return annotation the body cannot meet is a type error

- **Relations**: Extends ADR-01565, ADR-00814, Implements TDD-00230
- **Date**: 2026-10-10

## Context

tsc checks a function's return annotation against its body. A generator's
annotation must be an iterator type (`function* f(): number` is TS2322:
`Generator<any, any, unknown>` is not assignable to `number`). A function
whose end is reachable must have a return type that allows `undefined`:
TS2355 when the body returns no value at all, TS2366 when some path falls
off the end, and TS2534 when the type is `never`. The checker reported
none of these, so the default lane compiled programs tsc rejects. ADR-01565
recorded the gap.

## Decision

`checkReturnPaths` (in `checker/check.go`) runs for every function
declaration, function expression and block-bodied arrow that has a return
annotation, and follows tsc's `checkAllCodePathsInNonVoidFunctionReturnOrThrow`:

- a generator (sync or async) whose annotation is not iterator-like reports
  TS2322 against `Generator<any, any, unknown>` or
  `AsyncGenerator<any, any, unknown>`;
- otherwise (an async function's type is awaited first), a type that is
  `any`, includes `undefined` or `void`, or a body whose end the flow graph
  proves unreachable is accepted;
- an end-reachable body reports TS2534 for `never`, TS2355 when it has no
  `return` statement, and TS2366 when `undefined` is not assignable to the
  type.

All are reported at the annotation, as tsc does. `-compat=js` skips the
check: the annotation is only a type, and the program runs as JavaScript.

The examples and tests that annotated a generator with its element type
(113 sites) now use `Generator<T>` / `AsyncGenerator<T>`. The checker's
unwrapping of a bare element type stays for `-compat=js`.

## Verification

Positions and codes match tsc 5.9.3 on a probe covering all four codes
plus accepted forms (`number | undefined`, `void`, a body ending in
`throw`, `Generator<number>`). Unit cases in `checker/check_test.go`; E2E
`TestE2EReturnAnnotationRejectedStrict` / `…AcceptedCompatJS`. Linux
(DeskMini kmlbox) full gates.
