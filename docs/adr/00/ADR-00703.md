# ADR-00703: FinalizationRegistry Stage 5 — scope-exit finalization under -mm=auto

- **Relations**: Implements TDD-00163 (Stage 5); Extends ADR-00701, ADR-00698
- **Date**: 2026-09-04

## Context

ADR-00701 left one gap: under `-mm=auto` a registered target's cleanup only
fired at the exit flush, never at scope exit, because passing the value to
`reg.register(...)` counted as a disqualifying escape ("the callee may
retain it") — so the implicit free layer skipped it and no death signal
ever fired mid-run. TDD-00163's Stage 5 pointed at TDD-00134's escape
analysis; TDD-00173 has since shipped that analysis, so Stage 5 reduces to
one insight about the register call itself.

## Investigation

`register` *does* retain the target pointer (the global registration
list), but that retention is **free-notified**: the emitted free runs
`__kml_finreg_onfree`, which fires the cleanup callback and marks the cell
dead, and a dead cell's target field is only ever pointer-compared
(`onfree` scans), never dereferenced. `unregister` compares tokens, the
report path prints held values. So freeing a registered target at block
exit is sound — it is precisely the deterministic death point the whole
mode-dependent design wants.

The held and token argument positions are different: held is read by the
callback *after* the target dies, and a token is compared by later
`unregister` calls — both must keep counting as escapes.

## Decision

- The free planner's escape checker exempts one exact shape: a call
  `N.register(candidate, …)` where the candidate is the bare identifier in
  TARGET position (argument 0), appears nowhere else in the call, the
  receiver `N` is not the candidate, and `N` provably denotes a
  FinalizationRegistry program-wide.
- "Provably denotes": `collectFinRegNames` (emit_stackalloc.go) — `N` is
  bound exactly once, by a `new FinalizationRegistry(...)` declaration, and
  never rebound by any other binder. The scan is a reflection walk over the
  whole AST that treats ANY binder-naming struct field
  (`Name`/`VarName`/`Param`/…, `ast.Identifier` references excluded) as a
  disqualifier — over-disqualifying only loses the optimization, never
  soundness.
- The exemption is off under `-mm=gc` (the Boehm finalizer is the death
  signal there; an early free must not race it) and off in the
  `-optimize-memory` stack planner (a stack value's scope exit emits no
  free, so the registry would never be notified — registered targets stay
  heap, ADR-00702).
- The exemption serves every consumer of the free planner: `-mm=auto`'s
  implicit layer AND explicit `/** @free */` / `/** @owned */` in manual
  mode — deterministic destructors at scope exit in both.

## Implementation notes

`escape_check.go`: `escChecker.finregNames` + the `call()` exemption;
`planAutoFrees` populates it via `collectFinRegNames` when not in gc mode.
First cut had a real bug caught by testing: the generic binder rule counted
every `ast.Identifier` *reference* as a rebinding, disqualifying every
name; identifiers are now skipped explicitly.

## Side effects discovered

A freed token no longer matches later `unregister` calls (the binding is
nulled by the free) — inherent to freeing, not new here.

## Verification

Mac (Apple Silicon): E2E ordering tests prove the callback drains BEFORE a
0ms `setTimeout` tick (auto-mode implicit and manual-mode explicit @free),
where before it ran at the exit flush; negative tests prove held-position
@free still errors and a same-named non-registry `register` receiver gets
no exemption; full FinReg + Memory suites pass.
