# ADR-00912: ToPrimitive with a void/undefined-returning valueOf

- **Date**: 2026-09-12
- **Relations**: Extends TDD-00201, ADR-00859

## Context

Invalid-IR sweep. An object whose `valueOf` returns nothing, used in a numeric
context, emitted invalid IR:

```ts
const n = { valueOf: function() { /* no return */ } };
Math.max(NaN, n);   // clang: '%t8' defined with type 'ptr' but expected 'double'
```

From `built-ins/Math/{max,min}/Math.*_each-element-coerced.js`.

## Investigation

`emitObjectToPrimitive` (`emit_toprimitive.go`) skips a `valueOf`/`toString`
candidate whose declared return type is not a primitive (`resultUsableForHint` →
`isPrimitiveResultTy`). A void/undefined return is not in that primitive set, so
the candidate was skipped, the ladder found nothing, and the object `ptr` reached
the numeric op. But `undefined` IS a primitive ToPrimitive result — the method
must still be CALLED (the spec evaluates it; the test asserts `valueOf` ran
exactly once) and yields `undefined`, which `ToNumber` maps to `NaN`.

## Decision

In `emitObjectToPrimitive`, detect a `valueOf`/`toString` candidate whose return
is void or undefined: load and call the closure (preserving side effects), then
return the undefined result directly — `NaN` (a `double`) for the "number" hint,
an `undefined` value otherwise. Handling it locally keeps the general `coerce`
untouched (a separate faithfulness gap — `coerce(undefined → double)` still
yields `0`, not `NaN` — is noted but not changed here, to avoid broad fallout).

## Implementation notes

- `@@toPrimitive` is exempt (trusted to return the right kind).
- The NaN constant is `0x7FF8000000000000`.

## Side effects discovered

`Object.assign` override and `Array/Iterator reduce` coerced-element files share
the "defined with type ptr but expected double" symptom but a different root
cause (object-field store / named-callback specialization); not fixed here.
General `coerce(undefined → double) = NaN` remains a separate deferred gap.

## Verification

- Runtime: `{valueOf(){ c++ }}` in `Math.max(NaN, n)` calls valueOf once and
  returns NaN, matching Node.
- `Math.max`/`Math.min` coerced files compile clean.
- `make examples` 296/296 (re-run at delivery).
