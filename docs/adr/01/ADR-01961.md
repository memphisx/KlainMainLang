# ADR-01961: The front end drops its overload-implementation rule for top-level bindings

- **Relations**: Implements TDD-00230 (P2.3); revises [ADR-01925](ADR-01925.md)
- **Date**: 2026-10-29

## Context

ADR-01925 gave the front end a rule for a top-level binding of an overloaded function's call whose implementation returns `T | undefined` (`const st = fs.statSync(p)`): the binding held the implementation's nullable result, as codegen's top-level declaration did then. The rewrite of codegen's `decideGlobalType` since holds such a binding as the picked overload's result (`Stats`), as it already held a local one. The rule then disagreed with codegen on every such binding (`examples/fs/fs.ts:221`).

## Decision

The rule (`implementationResult`) is deleted. A top-level binding of such a call holds the overload's result, as a local one does.

## Consequences

- The examples under `examples/fs/` report no disagreement.
- `reliableGlobalType` is compared, not switched, so no compiled output changes.
