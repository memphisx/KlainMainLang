# ADR-01933: More runtime leaves IR text; the stream iterator and console.table move to TypeScript

- **Relations**: Implements TDD-00240, Implements TDD-00230, Extends ADR-01932
- **Date**: 2026-10-28

## Context

This batch continues TDD-00240, moving runtime IR text out of Go string literals. It takes the fs error constructor, the uncaught-exception entry points, the AbortSignal accessors, `process.env` and `os.networkInterfaces()`, `ToNumber`/`ToBoolean` of a box, and a set of thunks. It also rewrites two intrinsics, `console.table` and the ReadableStream async iterator, as TypeScript library code. Each port was checked against Node, and every divergence those checks found is fixed here.

## Investigation

- **The uncaught-exception handler did not keep the program running.** When a `process.on('uncaughtException')` listener handled an error thrown in a timer, the timer loop stopped. A handled throw at top level exited with code 1. In Node, both cases keep running the event loop and exit with `process.exitCode`.
- **`console.table`** handled only arrays of objects and arrays of primitives, through about 600 lines of emitted IR. It did not handle a properties filter, a plain object, a Map, a Set, or nested arrays.
- **The stream iterator.** `values()` returned a reader that only `for await` could drive. Node's iterator, read from its own `lib/internal/webstreams/readablestream.js`, behaves as follows:
  - The first read waits one microtask.
  - It has a buffered fast path that returns `{ done: false, value }` (that key order) when a chunk is already queued.
  - Each read request settles the result synchronously.
  - `return()` cancels the stream with its argument, then releases the lock.
- **Source callbacks.** Node wraps each one in an `async` arrow (`createPromiseCallback1Param`). An async `pull` therefore resolves through a thenable job, and a synchronous one settles a microtask later. The runtime reacted to the callback's own promise directly, so the next pull ran a tick early. That changed which of Node's iterator paths a read took.
- Bugs found while checking against Node:
  - A cancel reason reached `cancel(reason)` as a raw Error pointer (0 for a string).
  - `reader.cancel(r)` did not invoke the source's cancel.
  - A `tee()` cancelled its source with only the last branch's reason.
  - A tee branch's `cancel()` settled at once. Node settles it once both branches are cancelled.
  - In `exceptions.c`, `fetch.c` and `streams.c`, an Error put into `any` went through `__kml_nb_pack(KML_TAG_ERROR, …)`. Tag 13 is not a NaN-box tag, so the packed value read back as `undefined`. An Error held in `any` is its object box.
  - A typed promise converted to `Promise<any>` (`const q: Promise<any> = typed`) is one object in JavaScript. Here it was two promises, each with its own "handled" flag. Handling one side still reported the other as an unhandled rejection.
  - In a generic class, an unannotated `async` method's inferred return type was not wrapped in `Promise`. The method was also unknown to a sibling method's inference, and to a call through `new C<T>().m()` made before the class was instantiated.
  - A call argument whose union-typed parameter contains another union (`resolve` of `Promise.withResolvers<IteratorResult<T>>()`, typed `IteratorResult<T> | PromiseLike<…>`) was rejected as not a member.
  - `o.m!()` lost `this`.
  - `+x` of a BigInt held in `any` gave NaN instead of throwing a TypeError.

## Decision

- **Moved to C:**
  - `__kml_fs_error_new` → `fserror.c`.
  - `ToNumber`/`ToBoolean` of a box → `toprim.c`. A BigInt now throws Node's TypeError.
  - `throw_kind`, the null-dereference throw and the RangeError throw → `exceptions.c`.
  - AbortSignal accessors → `fetch.c`.
  - `process.env` and `os.networkInterfaces()` bags → the new `osinfo_bags.c`.
  - Per-program interned names reach C through hooks.c globals set at startup.
- **The uncaught-exception path:** `__kml_make_callback` is a setjmp frame that reports whether a listener handled a throw. The timer and immediate loops re-enter it, and a handled top-level throw runs the event loop, `beforeExit` and `exit`, then exits with `process.exitCode`.
- **Built by builder functions instead of IR text:**
  - The process and worker uncaught handlers.
  - The iterator collector and the inspect thunks.
  - The finalization trampoline.
  - The promise wrapper lookup and its dynamic attach.
  - The stream decoder.
- **Deleted:** the unused HTTP client registry and the unused stream try-read entry points.
- **`console.table`** is `lib/node/internal_console_table.ts`, a port of Node's algorithm, reached through `@lower`. `emit_console_table.go` is deleted.
- **The stream iterator** is `lib/node/internal_rs_iterator.ts`, a port of Node's `values()`. Two parts of it run in C:
  - **Read requests.** `__kml_native_rs_read_request` registers a read whose request is a callback. It is tagged with bit 2 in the pending-read FIFO and runs synchronously when the chunk, the close or the error arrives, like Node's `ReadableStreamAsyncIteratorReadRequest`.
  - **The buffered fast path.** `rsHasQueued` and `rsTakeQueued` check for and take an already-queued chunk.
  - Native parameters may now be typed `ReadableStream`. A generic function infers `T` from a `ReadableStream<T>` argument, so `values<R>` gets the stream's own chunk type and needs no `any` conversion.
- **`for await` over a stream** goes through `values()` and the dynamic iteration protocol, so an early exit calls `return()`, which cancels the stream.
- **The stream runtime:**
  - `pull` and `cancel` results go through `as_async`: an adopted or freshly fulfilled promise, as Node's async wrapper gives.
  - `cancel` returns `then(() => {})` of it.
  - The cancel reason is a boxed `any`.
  - A tee cancels its source with `[reason1, reason2]`, and both branches' `cancel()` wait on one shared promise.
  - The reader's `closed` promise is rejected already marked handled.
  - The typed→`any` stream wrapper forwards the cancel reason and releases the source's lock.
- **The promise struct gains a `TWIN` slot (64 bytes).** `__kml_promise_twin` joins a converted view to its source in a ring. `mark_handled` marks every promise in the ring, and only the view reports an unhandled rejection. A `Promise<T>` → `Promise<any>` conversion is skipped when `T` is already held boxed (a union).
- **Error boxing in C** uses the object box (`ptr | 1`), and a boxed reason is read back with the Error flag in the object header.
- **Compiler fixes:**
  - Generic class methods: the async wrap, registration before the methods' signatures with a second inference pass, and body inference for a not-yet-instantiated instance.
  - Union arguments: a union member that is itself a union is checked by its own members.
  - `o.m!()` unwraps the non-null assertion before dispatching.

## Implementation notes

- `as_async` needs `adopt.c`: `ensureStreamRuntime` links it, and the new `streams` `@link` unit points native declarations at the stream runtime.
- Builder-function code stores into the heap only through `heapStore`/`heapMallocInto`. The test-mode heap check (`heap store outside a heap primitive`) caught raw stores in `__kml_pdyn_attach` and `__kml_stream_decode`.
- An `async` method returning the result of an unannotated sibling relies on the second pass. The first pass sees only the siblings declared before it.

## Side effects discovered

- `__kml_nb_pack` has no case for tag 13, so any C caller passing `KML_TAG_ERROR` got an immediate value. All three such callers are fixed. `exceptions.c` uses the tag only on the caught-value side, where it is correct.

## Verification

- Probes against Node v24 match. They cover:
  - Iterator results, key order and timing: sequential, concurrent and async-pull reads.
  - `return()` and `preventCancel`.
  - `for await` with `break` over a typed stream and over one held in `any`.
  - An errored stream, the tee cancel reasons and promises, and a cancel's returned promise.
  - Promise conversions handled on either side, and unhandled on both.
  - `console.table` shapes.
- New E2E tests:
  - `TestE2EReadableStreamAsyncIterator`
  - `TestE2EGenericClassAsyncPrivateMethod`
  - `TestE2EWithResolversIteratorResult`
  - `TestE2ENonNullMethodCallKeepsThis`
  - `TestE2EConsoleTableNodeLayout`
  - `TestE2EAnyBigIntToNumberThrows`
  - `TestE2EProcessUncaughtExceptionLoopGoesOn`
- Targeted E2E suites and the `codegen/llvm`, `lib`, `lib/conform`, `resolver` and `checker` units were run on the Mac (Apple Silicon).
