# ADR-01194: `instanceof Promise`, and `instanceof Array`/`Promise` of a value held in `any`

- **Relations**: `Extends ADR-00162`, `Extends ADR-01182`
- **Date**: 2026-09-28

## Context

`x instanceof Promise` was "instanceof is only supported against
user-defined classes". A builtin `instanceof` is answered from the left
side's static type (ADR-00162), so a value held in `any` always answered
`false` — `(arr as any) instanceof Array` included.

## Decision

`Promise` joins the builtin `instanceof` table (static `IsPromise`). For a
left side of type `any`, `Array` checks the box tag (a static or dynamic
array) and `Promise` checks that the box is an object whose header is the
promise wrapper's layout (ADR-01182); the other builtins keep the static
answer.

## Implementation notes

`codegen/llvm/emit_classes.go` (`emitDynBuiltinInstanceOf`).

## Side effects discovered

None.
