# ADR-01795: Generator pattern-parameter defaults take their binding's name

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- `function* g({ q = () => {} })` gave `q.name` as "". The same default in an ordinary function reads "q" (ADR-01785).
- A generator's destructured parameters move into statements its start runs (`desugarGeneratorPatternParams`, recorded in `genPatternInits`). That can happen before function names are inferred, and those statements are no longer in the program tree that `inferFunctionNames` walks.

## Decision

- `inferFunctionNames` also walks the recorded `genPatternInits` statements.

## Consequences

- `TestE2EJSFileGeneratorPatternDefaultNames` compares generator methods (instance and static) and generator declarations against Node.
