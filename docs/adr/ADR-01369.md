# ADR-01369: An Error's own keys follow assignment and defineProperty's `enumerable`

- **Relations**: Extends ADR-01080's extra bag
- **Date**: 2026-10-03

## Context

Backlog 150 and part of 149:
- `e.cause = 5` left `cause` out of `Object.keys(e)` and `JSON.stringify(e)`.
  In Node it is an own enumerable property; the constructor's `{ cause }`
  option is not.
- `Object.defineProperty(e, 'cause', { enumerable: false, value })` stored
  the value only. A key defined on an Error without `enumerable` was listed,
  where Node's default for a new property is non-enumerable.

## Investigation

- `cause` is a fixed slot of the error layout. The walkers (inspect's keys,
  JSON, `Object.keys`) read an Error's own keys beyond its layout through
  `errkeys.c`: the present system fields, then its `extra` bag's keys.
- The bag's entries carry attributes (`A_ENUM`), but `errkeys.c` listed
  every entry.
- ValidateAndApplyPropertyDescriptor: an omitted attribute keeps an existing
  property's value, and is false for a new one.

## Decision

- **Assignment.** `e.cause = v`, statically or through `any`, also records
  `cause` in the extra bag (`__kml_error_own_cause`), refreshed on every
  assignment so the bag agrees with the slot.
- **Listing.** `errkeys.c` lists only enumerable bag entries.
- **defineProperty.** On an Error, the key's prior enumerability is read
  (`__kml_error_key_enumerable`) before the value is stored. After the
  store, `__kml_error_define_enum` sets it from the descriptor's
  `enumerable`, or keeps the prior state.
- **Declarations.** `emitErrorOwnKeysHooks` now declares its hooks once.

`writable`, `configurable` and `getOwnPropertyDescriptor` on an Error's
fields remain (backlog 149).

## Implementation notes

`codegen/llvm/boxsrc/errkeys.c`, `emit_inspect.go`, `emit_exprs_assign.go`,
`emit_dynobj.go`, `emit_dyndesc.go` and `emit_iter_collect.go`.

## Verification

Mac (Apple Silicon), against Node 24: an assigned cause, `enumerable: false`
over it, the constructor's cause redefined with and without `enumerable`, a
new cause and a new non-field key without it
(`TestE2EErrorCauseEnumerability`); the Error, defineProperty, child-process
and dynamic-JSON groups.
