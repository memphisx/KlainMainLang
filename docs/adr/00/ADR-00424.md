# ADR-00424: `process.<stdio>.isTTY` + zero-param `createServer` listener

- **Relations**: Extends [ADR-00423](ADR-00423.md) (histogram-driven idiom closures), [ADR-00406](ADR-00406.md)
- **Date**: 2026-08-28

## Context

Next two shapes from the Node-oracle failure histogram:

- 32 files fail "undefined variable 'process'" — the first such read is
  usually `if (process.stdout.isTTY) …` (color/TTY gating at the top of
  a test), so the whole file dies before its real content.
- `http.createServer(common.mustNotCall())` — a server that must never
  receive a request (client-abort tests) — was rejected by the
  two-param listener check (a `mustNotCall()` wrapper is `() => void`).

## Investigation

`process.stdout`/`stderr` are pseudo-namespaces handled per-shape
(`process.stdout.write` has a two-level chain check in emit_call.go);
there was no member read for them at all, so the identifier fallback
reported `process` itself undefined. `isTTY` is cheap to make *real*:
POSIX `isatty(fd)` gives Node-identical behavior (false under
pipes/redirects — the harness case — true on a terminal).

## Decision

- `process.stdin/.stdout/.stderr` `.isTTY` emits `icmp ne (isatty(fd)), 0`
  (fds 0/1/2), typed bool in both emission and call-type inference —
  the same two-level shape check as `.write`. `isatty` is declared via a
  new `ensureIsatty` (standing `ensure*` discipline).
- `emitHTTPCreateServerCore` wraps a listener whose inferred type is a
  zero-param function into a synthesized
  `(req: IncomingMessage, res: ServerResponse) => { <listener>() }`
  arrow — so `mustNotCall()`'s counting wrapper still fires (and fails
  at exit) if a request arrives. Applies to any `() => …` listener, not
  just the wrapper.

## Implementation notes

- `codegen/llvm/emit_process.go`: `ensureIsatty`,
  `emitProcessStreamIsTTY`; flag in `emitter.go`.
- `codegen/llvm/emit_exprs_member.go` / `emit_exprs_types.go`: the
  `.isTTY` chain check (emission + bool inference — without the
  inference case a `const t = process.stdout.isTTY` binding printed `0`).
- `codegen/llvm/emit_http.go`: zero-param listener wrap in
  `emitHTTPCreateServerCore`.

## Side effects discovered

None.

## Verification

- `TestE2EProcessStdioIsTTY` (pipe ⇒ `false`, bool-typed binding),
  `TestE2EHTTPCreateServerMustNotCall` (binds, closes clean, exit 0);
  manually verified the negative twin — a request against a
  `mustNotCall()` server prints the diagnostic and exits 1. Neighboring
  `TestE2EProcess*`/`TestE2EHTTPCreateServer*` suites re-run green (Mac).
