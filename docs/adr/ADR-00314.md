# ADR-00314: `Blob` — immutable binary data with a MIME type

- **Relations**: Implements [TDD-00102](../tdd/TDD-00102.md)
- **Date**: 2026-08-23

## Context

The last missing WHATWG binary primitive; its absence compile-failed conformance files that construct Blobs from mixed parts.

## Investigation

The ArrayBuffer hidden-header convention (`{i64, ptr}`, ADR-00078) extends naturally with a type-string word; fetch's `Response.arrayBuffer()` (emit_fetch.go) proved the "hand-build a header around bytes" shape, and emit_async.go's non-promise `await` identity pass-through (ADR-00241's lineage) means the promise-shaped readers can return already-resolved values.

## Decision

Per TDD-00102: `Type{IR:"ptr", IsBlob:true}` → heap header `{i64 size, ptr data, ptr type}`, data materialized eagerly (immutable ⇒ one contiguous buffer). `new Blob(parts?, {type}?)` is a general expression (`NewBlobExpression`); parts must be an inline array literal, each element dispatching on its inferred type (string/TypedArray/ArrayBuffer/Blob). `.size`/`.type` are dedicated member reads; `.slice(start?, end?, contentType?)` copies with array-slice normalization and the spec's non-inherited type; `.arrayBuffer()`/`.bytes()`/`.text()` return copies as already-resolved values. Cut: `.stream()`, type lowercasing, `endings`.

A user-declared `class Blob` shadows the builtin: the parser can't know classes, so `emitNewBlobExpression` (and its inference/vardecl mirrors) rebuilds a generic `new Blob(args)` construction when a class named `Blob` is registered — found immediately by the existing `TestE2EClassSiblingWithNoOverrideStaysDirectCall`, which declares one.

## Implementation notes

New `codegen/llvm/emit_blob.go`; `ast/nodes.go`, `parser/parser_literals.go`, `resolver/rename.go`, `emit_func.go` (scanner), `emit_exprs.go`/`emit_exprs_vardecl.go`/`emit_exprs_types.go` (dispatch/inference — `.slice`/`.text`/`.arrayBuffer`/`.bytes` gates checked before Response's claims on the same names), `emit_exprs_member.go`, `emit_call.go`, `types.go` (`IsBlob`/`BlobType`). Cross-module shadowing by an *imported* class named Blob is not detected (the codegen check sees the post-rename class table) — an accepted edge alongside every other builtin constructor name.

## Side effects discovered

None.
