# ADR-00712: Rebind-free — `-mm=auto` frees the overwritten value on owning reassignment

- **Relations**: Extends TDD-00173's implicit layer
- **Date**: 2026-09-04

## Context

The benchmark campaign's `string_churn` (30 rounds of `s += "x"` × 8000)
was MEM-KILLED at 512MB under `-mm=auto`/`-optimize-memory` while gc mode
ran in 3.5MB. Root cause: the escape analysis disqualified *any*
reassigned binding ("the block-exit free would target the wrong value"),
so a churned string binding never freed anything — every intermediate
concat buffer leaked, quadratically.

## Decision

A reassignment whose RHS provably produces a fresh owned allocation
doesn't escape the old value — it *drops* it. The implicit layer now:

- **Plan** (escape_check.go): `rebindOwningRHS` accepts `s += …`
  (concatenation on a freeable type), `s = a + b`, and an interpolating
  template as owning rebinds; the checker records the binding as
  rebind-planned instead of disqualifying it, and keeps scanning the RHS
  (reads of the binding there are copy-safe). Any other reassignment
  shape — a bare alias (`s = other`), a literal, `??`/`||` selection —
  still disqualifies. Off for explicit `@free`/`@owned` (annotation
  semantics unchanged) and the stack planner (a stack value must never
  be freed).
- **Declaration** (emit_autofree.go): a rebind-planned string binding
  whose initializer is an interned literal (`let s = ""`) gets a heap
  copy stored at registration, so the binding owns its value from the
  start and every subsequent free is unconditional — no runtime
  interned-vs-heap discrimination needed.
- **Store** (emit_exprs_assign.go): right before the identifier-slot
  store — RHS already evaluated, old value's last reachable point —
  `maybeFreeOnRebind` frees the overwritten value. Matching is by name
  AND slot pointer, so a shadowing inner binding never triggers the
  outer's free. The block-exit obligation stays and frees whichever
  value is last.

## Consequences

- `string_churn` scale 10 under auto/auto-opt: MEM-KILLED → **~0MB peak,
  0.08–0.09s** — faster than gc (0.157s) and Node (0.209s), on par with
  PerryTS (0.076s, first run with the perry engine wired into
  benchmarks/run.sh).
- E2E coverage: RSS-bounded churn (peak <30MB on ~240MB churned), all
  three rebind shapes + shadowing correctness, and the alias-rebind
  rejection case. Full auto/optimize/finalization/string lanes green;
  `make examples MM=auto` 283/283; Node oracle unchanged.
- `manual` mode still leaks the naive program by definition; the
  benchmark's `_manual.ts` variant convention remains the answer there.
- ASan-under-auto differential sweeps remain a TDD-00174 gate item, not
  rerun per-change.
