# ADR-01805: Generator calls take any argument count in JavaScript

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- In `-compat=js` a generator call with fewer or more arguments than the generator declares was a compile error ("generator expects 2 argument(s), got 3"). An omitted argument past the first optional parameter took undefined, but one before it did not. Also, an unannotated parameter defaulted to a number, so even a padded undefined read as 0. ADR-01800 fixed the same issue for class calls.

## Decision

- In the js lane, `emitGeneratorConstructionWithThis` pads missing declared arguments with undefined. Extra arguments (with no rest parameter) are evaluated in order after the declared ones, and their values are dropped.
- An unannotated generator parameter in the js lane is `any`, so an omitted argument reads as undefined.

## Consequences

- `TestE2EJSFileGeneratorArity` compares omitted and extra arguments, their evaluation order, a rest generator and a generator method against Node.
- The strict lane still reports the mismatch, as tsc does.
