# ADR-01275: typeof a generic function is "function"

- **Relations**: `Extends ADR-00607`
- **Date**: 2026-09-29

## Context

A generic function has no single signature until it is instantiated, so
`typeof g` fell through to "undefined". This included a namespace member
such as `timers.setTimeout`.

## Decision

`typeofStaticAnswer` answers "function" for a name in `genericFuncs`.

## Verification

Mac (Apple Silicon): `TestE2EGenericDefaultVoidAndTypeof`;
`TestE2ETimersPromisesSleepAndImmediate`.
