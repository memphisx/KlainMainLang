# ADR-01169: Code generation and runtime fixes found by the fs port: try/finally, value-preserving && and ||, errors, Buffer encodings

- **Relations**: `Extends [ADR-01167](ADR-01167.md)`, [ADR-01168](ADR-01168.md), [ADR-00460](ADR-00460.md), [ADR-00619](ADR-00619.md)
- **Date**: 2026-09-26

## Context

Porting Node's fs streams (ADR-01167) as ordinary TypeScript hit these in
code generation and the runtime. Several are not specific to streams:
`try`/`finally` swallowed an exception in every function kind.

## Investigation and decision

- **`try`/`finally`**: with no `catch`, a thrown exception reached the
  `finally` and was then dropped; a throw inside a `catch` skipped the
  `finally`; and a `return`/`break`/`continue` leaving a `try` never popped
  its handler, so a later throw jumped into the dead frame (a segfault).
  `emitTry` keeps the exception a `finally` must rethrow in a pending slot
  (volatile, across the setjmp), runs the `catch` under a handler of its
  own when there is a `finally`, and rethrows after the `finally` through
  `__kml_throw_any` with the original tag and payload. Every early exit
  unwinds `pendingFinallys`, now `pendingExit{popHandler, body}`: the
  try's handler is popped, then its `finally` runs.
- **`for await` closing its iterator**: a `break` (or `return`, or a throw)
  out of `for await` over an async generator left it suspended; its
  `finally` never ran. The loop now closes it with `await it.return()`
  (AsyncIteratorClose), as the sync loop does.
- **`&&` and `||` are value-preserving in the strict lane too**: they
  compiled to a boolean outside `-compat=js`, while inference answered the
  left operand's type (invalid IR where the two met). Both lanes now use
  `shortCircuitValueType`: the shared type, a scalar union, two arrays (the
  chosen header, as a ternary's), or `any` with both operands boxed.
- **`x ?? null` on a possibly-undefined number** gave 0; it is now
  `number | null`, absent where x is. An absent `T | null` scalar boxes to
  `null` (it boxed to `undefined`).
- **`x?.p` on an `any`** holding `null` threw; it is `undefined`.
- **Errors**: `class E extends TypeError` (or `RangeError`, …) is an error
  subclass whose `.name` defaults to its base's and which `instanceof` the
  base matches, statically and boxed. `NodeJS.ErrnoException` has the
  Error representation. An Error's absent `code`, `syscall`, `path`,
  `dest`, `errstr`, `address` read as `undefined` (and `errno`, `errcode`,
  `port`, stored as 0 when unset); a subclass may redeclare `code: string`
  over them. A property set on an Error held as `any` stores a fixed field
  or, for any other name, its `extra` bag (it threw "Cannot set properties
  of a non-object value"). `console.log` of a statically typed Error
  printed an empty line (or, for a subclass's instance, its tag bytes); it
  prints the boxed form, `Name: message`.
- **Buffer encodings named at run time**: `Buffer.from(s, enc)`,
  `buf.toString(enc)`, `buf.write(s, off, enc)` and `Buffer.byteLength(s,
  enc)` required a literal encoding. A non-literal one dispatches in C
  (`__kml_buf_decode_enc`/`__kml_buf_encode_enc`), case-insensitively, an
  undefined encoding being utf8 and an unknown one Node's
  `ERR_UNKNOWN_ENCODING` (a literal unknown name too, at run time).
  `Buffer.byteLength` follows Node's per-encoding formula over the UTF-16
  length (`hex` is `length >>> 1` whatever the digits). `allocUnsafeSlow`
  is `allocUnsafe`.
- **Closures**: a closure captured in one branch boxed an array local or
  array parameter at the capture site, which does not dominate later uses
  (invalid IR); array locals and parameters a closure captures are boxed at
  their declaration, as scalars are (ADR-00619). A dynamic-ABI arrow (an
  arrow passed where `any` is expected) captures lexical `this` as a typed
  arrow does (ADR-00460), types an unannotated parameter from the checker's
  contextual type (number, string, boolean, Buffer), and binds an
  array-typed parameter as the array itself. A closure cast from `any` to a
  function type with an array parameter calls through (it was treated as a
  raw pointer).
- **Calls**: a `T | undefined` argument the checker proved present fits a
  union parameter holding T; a timer or `process.nextTick` callback with
  parameters is called with none.
- **`ArrayBuffer.isView`** was missing (a codegen rejection); it answers
  from the type, or from an `any`'s box. `stream.ts` now takes any
  `ArrayBufferView` chunk as Node's `Stream._uint8ArrayToBuffer` does (it
  accepted only a Buffer), and a runtime Readable handle (`req`) pipes into
  a `stream` module class (an fs `WriteStream`) by its `'data'`/`'end'`
  events, pausing until `'drain'` when `write()` asks.

## Side effects discovered

- A class instance boxed into `any` inside a function renders as
  `[object Object]` (and at top level without its class name).
- A thrown error subclass's instance prints `Error: message` from
  `console.log`, without Node's `SE [Error]` class form or its own
  properties.
- A string with an embedded NUL still ends at it (`JSON.stringify` of
  `"\u0000cde"`).
- An unhandled rejection still exits 0 (BACKLOG, `'unhandledRejection'`).
- A value cast through `as any` into a function compiled with typed
  parameters (`(fs.close as any)('3')`) reaches the typed parameter, not
  JavaScript's untyped one.

## Verification

Mac (Apple Silicon): a `try`/`catch`/`finally` matrix (a catch that
throws, `return` in `finally`, `break`/`continue`/labelled `break` through
`finally`, nesting, async functions and generators) matches Node v24, and
the former segfault exits as Node does; `for await` with `break` over an
async generator and a `[Symbol.asyncIterator]` class runs their
`finally`; the `&&`/`||`, `??`, `?.`, Error, Buffer encoding and closure
probes match Node. `tests/fs_port_fixes_test.go` (13 programs, expected
output from Node v24), `tests/fs_stream_test.go`, `tests/node_stream_test.go`
and `tests/stream_port_fixes_test.go` pass. Three tests that asserted the
old behaviour now assert Node's: `TestE2ELogicalValuePreservingStrict`
(was `…StayBoolStrict`), `TestE2EFsErrorSyscallAndPath` (a plain Error's
`syscall`/`path` are `undefined`), `TestE2EBufferRejections` (a variable
encoding works).
