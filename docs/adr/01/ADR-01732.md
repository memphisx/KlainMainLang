# ADR-01732: Array.prototype is an Array

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-18

## Context

`Array.prototype.slice.call(arguments, 1)` and the other borrowed-method calls already matched Node. `Array.prototype` itself did not. It was an ordinary prototype object, while in JavaScript it is an Array exotic object with length 0:

- `Array.isArray(Array.prototype)` was `false`;
- its `length` read `undefined`;
- `Object.prototype.toString` gave `[object Object]`;
- `console.log` printed `{}` (Node: `Object(0) []`);
- `JSON.stringify` gave `{}` (Node: `[]`).

## Decision

- **Flag:** a dynamic object's header gains bit 35, "array exotic". `Array.prototype`'s bag sets it when first built (`__kml_dynobj_array_exotic`), together with an own `length` of 0 that is writable, not enumerable and not configurable.
- **Readers of the bit:**
  - `Array.isArray` on a value held in `any` answers true for a flagged bag;
  - `Object.prototype.toString` reports `Array`;
  - inspect prints an empty flagged bag as `Object(0) []`;
  - `JSON.stringify` writes `[]`.

## Consequences

- Index properties added to `Array.prototype` are not shown by inspect or serialized by JSON. Node shows them, but no program in the test corpora writes them.

## Verification

macOS (Apple Silicon), against Node:

- **`tests/builtin_prototype_test.go` TestE2EArrayPrototypeIsArray:** the five observables, `isArray` of `{}` and `Object.prototype`, and borrowed `slice`/`map`/`join` calls.
