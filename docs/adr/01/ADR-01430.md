# ADR-01430: Parameter types in body pre-passes, class and object reprs

- **Relations**: Implements TDD-00230 (P2.2, P3.3), Extends ADR-01429
- **Date**: 2026-10-06

## Context

The shadow comparison's largest new bucket after giving `reprOf` a class
arm was an annotated class parameter (`a: TimersList`) that codegen
answered as `i64`. The program compiled correctly, so the question was
being asked somewhere other than the emitted read.

## Investigation

- A stack at the disagreeing query: `inferEmptyArrayElemTypes`, which a
  function, arrow function or function expression runs over its body
  before its parameters are bound. An unbound name defaults to `i64`.
- The same pass decides an empty array's element type, so the default is
  observable: `const out = []; out.push(a.expiry); out.push(n / 4)` with
  `a: L` (a numeric field) was rejected as a heterogeneous array, where
  Node prints `[ 1.5, 0.75 ]`. `crossTypeWidenedBindings` and
  `inferEmptyMapKVTypes` run at the same point and read the same way.
- Shadow runs timed out on the http2 examples once class answers existed:
  `reprKey` rendered each class's whole field tree, nested classes
  included, for every compared expression (52 s for one compile against
  23 s without the comparison).

## Decision

- The body pre-passes run inside a scope binding each named parameter to
  its signature type.
- `reprOf` takes a context (`reprCtx`): the classes codegen registered,
  found by declaration node (a class published before its layout is built
  has no answer yet), and the lane. An object type is a dynamic object in
  the js lane and a fixed-layout object of its properties in order in the
  strict lane. The codegen deciders still use the context-free form,
  which answers neither (giving it the object arm made a returned
  `{ seq, inc }` take the checker's layout, and `m.seq(1)` read as a
  number).
- `reprKey` keys a class by its name.
- The shadow report's top-level-variable rows record codegen's final
  decision once per declaration, skipping a local no function reads.

## Verification

`TestE2EEmptyArrayElemFromParams` (a function, an arrow function and a
function expression, against Node). Gates on this tree (Linux, kmlbox):
test-par on Node304, examples 396/396 and Test262 strict on DeskMini,
Test262 js on Node304; both lanes pass exactly the files of the previous run
(strict 8401, js 10810), with no invalid IR. The shadow report runs 47899
compiles with none timed out (5m52s).
