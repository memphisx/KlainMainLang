# ADR-00378: Invalid-IR hardening + conformance-runner C-runtime linking

- **Relations**: Extends [ADR-00377](ADR-00377.md); Implements [TDD-00123](../tdd/TDD-00123.md), [TDD-00082](../tdd/TDD-00082.md)
- **Date**: 2026-08-26

## Context

After the `number`→double flip (ADR-00377), the Test262 in-scope count read
slightly *below* the pre-change baseline and a chunk of files failed at the
clang stage. Investigating "what are the erroring files actually testing" — to
fix the ones exercising supported features and defer the genuinely out-of-scope
ones — split the failures into two very different populations.

## Investigation

Instrumenting the conformance runner to dump each clang-failing file's path,
scope, and first line of code, then classifying the 543 in-scope failures:

- ~171 exercise **out-of-scope dynamic behavior** — `ToPrimitive`/`ToInteger`
  coercion (`String.prototype.at({valueOf(){…}})`), cross-type `===`
  (`1 === "1"`), `arguments`, `eval`, prototype mutation. These are a typed
  subset's deliberate divergences; **defer**.
- The rest were dominated by two *fixable* root causes, both hidden behind a
  generic "clang error":
  1. **The runner never linked the compiler's embedded C runtime.** The CLI
     driver (`main.go`) writes and links `dtoa.c` / bigint / crypto / JSON /
     Buffer-codecs / URLPattern / … whenever a program uses them; the
     conformance runner ran a bare `clang -O2 <ll>`. Every test that stringifies
     a number (`` `foo ${5}` ``, template literals, `"" + n`) now routes through
     `__kml_dtoa`, so it *declared* the symbol but failed to *link* it — a
     ~216-file "linker command failed" bucket of genuine, supported-feature
     tests the CLI compiles fine.
  2. **Genuine cross-type type errors emitted invalid IR** rather than a clean
     rejection — `coerce`'s `default` case returns the value unchanged for an
     incompatible pair (a number into a string field, `1 - "a"`), which then
     stored/operated with a mismatched IR type.

## Decision

**Fix (1) — shared C-runtime source of truth.** New `(*Emitter).EmbeddedCSources()`
(`codegen/llvm/embedded_c.go`) returns every embedded `.c` file the emitted IR
depends on (name, content, cflags, libs), keyed off the same `Uses*()` flags the
CLI already consulted. Both `main.go` and the conformance runner now iterate it,
so they can never drift on which runtime files get linked. This is a
conformance-*tool* correctness fix, not a compiler change: the CLI already did
the right thing.

**Fix (2) — reject cross-type mismatches cleanly.** A pure predicate
`coerciblePure(src, target)` (and `coerceChecked`) reports whether a coercion is
real vs. the silent unchanged-fallthrough; a genuine cross-kind mismatch is now
a clean compile error — TypeScript-faithful (TS rejects a cross-type `===`
too) — applied at the value-consuming sites: binary arithmetic/comparison,
object-literal field stores, variable initializers, and function/closure call
arguments. Plus structural rejections for constructs that had silently emitted
invalid IR: a void-typed initializer (`const i = arr.forEach(…)`), a
heterogeneous array literal (`[obj, 0, "s"]`), a nullable/union array element
type (`(number | null)[]`), and a void `reduce` callback.

Out-of-scope dynamic-coercion tests are left as-is (deferred by design), but they
no longer masquerade as codegen bugs.

## Results

- Test262 **in-scope 5067 → 5228 (+161)**, overall 5858 → 6021; **clang
  (invalid IR) 570 → 354 (−216)**. A net conformance *gain* over the pre-number
  baseline, not a regression.
- The remaining clang bucket is dominated by out-of-scope dynamic coercion and a
  long tail of per-builtin arg mismatches (each builtin's bespoke arg handling) —
  a separate, low-yield hardening effort, deferred.

## Verification

- `make test-par` E2E: green except the pre-existing `TestE2ESignalBoth…` flake
  (fails identically on the clean tree). The type-mismatch checks add zero
  false-positives (generics, defaults, `any`, nested objects/arrays all compile).
- `make examples`: 190/190 — the CLI's C-runtime refactor links float/bigint/
  crypto/tls/http2/Buffer/JSON/URLPattern programs unchanged.
- `go vet ./...` clean.
