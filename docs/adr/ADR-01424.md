# ADR-01424: Classes extending Map and Set

- **Relations**: Implements TDD-00247 (stages 1 and 2), Extends ADR-01423
- **Date**: 2026-10-06

## Context

TDD-00247 has a class extending a builtin host class be that host object, as
in Node. Map and Set are the first hosts (stage 2); the extends clause first
had to take a full type-argument list (stage 1): `extends Map<string,
number>` was a parse error.

## Investigation

- A Map or Set is a pointer to a 72-byte body (`collections_engine.h`) whose
  word 0 is its size; generated code reads the body's offsets at about 120
  sites. A header word at `+0` would move every one of them.
- A Map boxed into `any` was a fresh 16-byte cell `{header, handle}` per box,
  so identity through `any` came from the cell compare in `__kml_any_eq`,
  which loads both handles.
- `structuredClone` of a boxed Map passed only because each box was a fresh
  cell: the comparison of a clone with its source loaded the handles.
- Found on the way, older than this work, each fixed here:
  - the Map/Set inspectors and `Map.forEach` loaded an array key or value
    as its raw header pointer, so a Map with array values (`Map<string,
    string[]>`) was invalid IR once its host layout's routines were made;
  - the host method adapter bound an array argument as a one-word value,
    invalid IR for `a.set(k, [1, 2])` through `any`;
  - an `any` receiver's `forEach` with a callback whose index parameter is
    annotated as something else (`(v: number[], k: string) => …`, written
    for the Map it holds) compiled its array branch against the array
    callback's types: invalid IR;
  - `__kml_map_free` was IR text, and `free` of a WeakMap/WeakSet took the
    Map path, reading a 72-byte body from an 8-byte list head.

## Decision

- The extends clause parses a type-argument list; a builtin base other
  than Error, Map or Set is a clean error naming it.
- A Map or Set is allocated with a header word before its body, at
  `body - 8`; its pointer stays the body. `__kml_map_<k>_create_h(header)`
  takes the word (the host header word of its static type, computed
  without registering the layout's routines); the no-argument form, used
  for runtime-internal maps, writes 0. `__kml_map_free` (now C) frees from
  `body - 8`.
- The header of a Map or Set carries `hostInlineFlag` (bit 50): its body
  follows, where a host cell holds a handle. A Map or Set boxes as its header
  pointer, so the box is the object; unboxing is `+8`; `__kml_any_eq`
  compares two such boxes by pointer.
- A class extending Map or Set (`ClassInfo.HostBase`, `HostAnnot`):
  - its instance is `[tag][body: 9 words][vtable][fields]`: the body sits
    where a Map's does after its header, kept ahead of the vtable as Error's
    fields are, and hidden from reflection;
  - construction makes the body empty in place (`__kml_map_init_at`);
    `new C(entries)` without a constructor, `super(entries)` and the
    synthesized constructor seed it; an absent optional array seeds
    nothing;
  - a method or property the class does not declare, and `super.m()` on the
    host, run on `this + 8` typed as the host; `set`/`add` return the
    instance;
  - iteration, spread and `Array.from` use the host's default iterator
    (`entries()`, `values()`) unless the class has its own;
  - `instanceof Map` holds statically, and `x instanceof C` on a Map reads
    the tag before its body;
  - passing the instance where its host is expected passes `+8`;
  - the class's parent row is its host layout's id: the host method
    adapters accept the instance through `__kml_class_is`, and the class's
    shape getter falls back to a host getter on its body, so members work
    through `any`; `hostbox.c`'s row lookup walks a class tag's parents to
    its host layout (`instanceof Map`, the other host dispatchers);
  - `console.log` renders `C(n) [Map] { entries, own fields }`, `[C [Map]]`
    past the inspect depth, statically and through `any` (an inspect-custom
    row per class), and `[object Map]` is its tag.
