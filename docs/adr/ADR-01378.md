# ADR-01378: Class members: a later sibling's result, static name clashes, repeated accessors

- **Relations**: Extends ADR-00906
- **Date**: 2026-10-03

## Context

Three Test262 files produced invalid IR, at HEAD too:
- `private-method-shadowed-on-nested-class.js`: `method() { return
  this.#m(); }` declared before `#m() { return 'x'; }`;
- `static-field-redeclaration.js`: `static g() {}` then
  `static g = this.g();`;
- `prop-dup-set-set.js`: an object literal with two `set foo`.

## Investigation

- Class registration infers each unannotated method's result in
  declaration order. ADR-00906 published the class before the loop, so a
  call to an *earlier* sibling resolved; a call to a later one fell back to
  `i64`, while the body returned a pointer. The loop's order fixes vtable
  slots, so it cannot be reordered.
- A static method's function and a static field's global were both named
  `Class_static_name`.
- The object-literal accessor lowering kept the first accessor's signature
  and emitted every body under one name. JavaScript keeps the last
  definition.

## Decision

- Before the registration loop, every unannotated plain method's result
  is inferred into `forwardMethodRet` (keyed by class, static-ness and
  name), re-inferred until none changes (at most four rounds). Inference of
  `obj.m()` and `C.m()` reads it for a method not yet registered; the
  entries are dropped once the class is registered.
- A static method compiles to `Class_smethod_name` (`staticMethodName`),
  apart from a static field's global.
- An object literal's later accessor of the same kind and name replaces
  the earlier one; only its body is emitted.

## Implementation notes

`codegen/llvm/emit_classes.go` (`inferForwardMethodResults`,
`staticMethodName`), `emit_exprs_types.go`, `emitter.go`,
`emit_objects_accessors.go`.

## Side effects discovered

- tsc rejects a duplicate class member (TS2300); the strict lane does not.
- A setter's unannotated parameter is a `number` under `-compat=js`
  (ADR-00042's default), so `set q(b) { s.push(b); }` given `"x"` stores
  NaN.

## Verification

Mac (Apple Silicon): `TestE2EMethodCallsLaterSibling` (a three-link chain,
a private method, static methods, a class expression); the class, static
and private E2E tests; both static-field Test262 files print Node's
`test262 45`; the duplicate accessors resolve to the last.
