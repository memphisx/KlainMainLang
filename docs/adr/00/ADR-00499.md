# ADR-00499: assert.ifError + assert.doesNotThrow

- **Date**: 2026-08-29

## Context

The Node corpus calls `assert.ifError` 143 times and
`assert.doesNotThrow` 19 times; neither existed.

## Decision

`ifError(value)` inverts the truthiness check into the shared
assert-fail path. `doesNotThrow(fn[, message])` is `throws`' inverse
over the same setjmp try-frame: the caught branch fails, the clean
branch pops the frame and continues. `assert.rejects` (522 corpus
calls) is deliberately not in this batch — it needs
await-a-rejection machinery, its own change.

`TestE2EAssertIfErrorAndDoesNotThrow` passes; assert batch green;
`examples/assert/assert.ts` extended and re-run.
