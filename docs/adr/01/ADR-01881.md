# ADR-01881: instanceof a linked global's class; boxed-on-entry parameters in return inference

- **Relations**: `Implements TDD-00230` (P3.3: the shadow report's Identifier bucket)
- **Date**: 2026-10-21

## Context

- A builtin module written in TypeScript implements a global (`URL` by kml_url's class): the resolver renames the global's value references to the class, while a type annotation `URL` stays the library's interface. `filename instanceof URL` with `filename: string | URL` narrowed the true branch to `never` and the false branch not at all, since the class's instance type is unrelated to the interface; tsc has one `URL`, narrowing to it and to `string`.
- A closure parameter annotated `any` that a runtime calls with a concrete value takes the concrete type as its ABI and boxes it on entry (ADR-01080); the closure's return inference bound the parameter with the concrete type, so `errors.map((e: any) => e.message)` inferred from an Error the body never sees.

## Decision

- instanceof narrowing by a class that implements a linked global (the program's GlobalLinks) treats the library's interface of that global as an instance of the class, in both branches.
- Return inference binds a boxed-on-entry parameter as the box the body sees.

## Consequences

- The worker_threads and net rows that every program loading those modules carried leave the shadow report; `string | URL` narrows as tsc narrows it, and callback results match Node.
- Verified on Apple Silicon.
