# ADR-01517: The js parameter pre-pass types a call's result by the checker

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-09

## Context

In the js lane, `jsCollectFuncParamTypes` types an unannotated parameter
from the arguments its call sites pass, including a top-level binding's
type. It ran before any function signature exists, so a binding holding
a user-function call (`const w = s2()`) read inference's bare-number
default. A function receiving `w` then had a number parameter, and
passing the string failed to compile (shadow bucket 9, 87 rows).

## Decision

A top-level binding initialized by a call of a program function takes
the checker's result type: a string, boolean or number when the checker
gives one of those, otherwise `any`, which every argument fits.
