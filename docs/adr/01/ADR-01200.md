# ADR-01200: `WeakRef`, `FinalizationRegistry` and `Proxy` are declared

- **Relations**: `Implements TDD-00230`, `Extends ADR-01134`
- **Date**: 2026-09-28

## Context

The checker left `new WeakRef(…)`, `new FinalizationRegistry(…)` and
`new Proxy(…)` unanswered: `lib/es.d.ts` did not declare them, so nothing
about their uses was decided (a wrong argument, a misspelled member).

## Investigation

A sweep of the `new X` names across the examples, apps and tests against
the declared globals listed the implemented ones still missing; these
three are ECMAScript's own (TypeScript's `lib.es2021.weakref.d.ts` and
`lib.es2015.proxy.d.ts`). `Reflect` stays undeclared: its signatures lean
on conditional types (`P extends keyof T ? T[P] : any`) the checker does
not evaluate yet.

## Decision

`lib/es.d.ts` declares `WeakRef`, `FinalizationRegistry`, `ProxyHandler`
and `Proxy` in TypeScript's shapes, with `object` where TypeScript 5.2+
writes `WeakKey` (the checker's `WeakMap`/`WeakSet` already use
`object`), and without the `[Symbol.toStringTag]` members.

## Implementation notes

`lib/es.d.ts`.

## Side effects discovered

None.

## Verification

Mac (Apple Silicon): `tools/libconform` 0 divergences; the example/app
sweep reports no type error; the collections, dynamic-object, finalization
and memory test files pass.
