# ADR-01898: a binding of an array element read, in both lanes

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

- An unannotated binding initialized with an element read of an array of arrays (`var sub = rows[0]`) holds the read as codegen emits it: possibly absent, with an unchecked index. The oracle modelled that only in the js lane and only over a literal array, so in the strict lane it answered the checker's present `number[]` at every read of such a binding.

## Decision

- The rule applies in both lanes; the js lane keeps its literal-array condition, where a non-literal source is a box.

## Consequences

- The strict lane's rows for such bindings go away; no emission change.
