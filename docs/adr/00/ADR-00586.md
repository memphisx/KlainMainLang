# ADR-00586: Number(bigint) conversion

- **Relations**: Extends [ADR-00216](ADR-00216.md), follows [ADR-00584](ADR-00584.md)
- **Date**: 2026-09-01

## Context

`Number(x)` handled booleans, numbers, and strings but rejected a bigint
operand — a disclosed sub-caveat on the `bigint` row (`Number(bigint)`
unsupported).

## Decision

Add `__kml_bigint_to_double(ptr) -> double` to both bigint backends
(`mp_get_double` for tommath, `mpz_get_d` for GMP) and route a bigint operand of
`Number()` through it. The result is the nearest IEEE-754 double — `Infinity`
when the magnitude exceeds the double range, matching JS (`Number(10n)` is `10`,
a 30-digit bigint yields its nearest double in exponential form).

## Verification

`TestE2ENumberOfBigInt` (small, negative, a value past 2^53 that rounds like
Node, a 30-digit bigint, zero) compared byte-for-byte against Node v26 under both
bigint backends. Built and verified on Mac (Apple Silicon).
