# ADR-01588: concat spreads an `any` holding an Array

- **Date**: 2026-10-11

## Context

`[].concat(a, b)` with `a`/`b` typed `any` and holding arrays returned
`[null, null]`; `x.concat(a, b)` on an `any[]` returned `[[…], […]]`. JS
spreads an argument whose IsConcatSpreadable is true, an Array by default.
Found writing the DNS test server ([ADR-01587](ADR-01587.md)).

## Investigation

`emitArrayConcat` (`codegen/llvm/emit_arrays_transform.go`) decides
spread-or-append from the argument's static type: an `any` argument was
always appended. `[]` has element type never, so an `any` argument
coerced into it read as null.

## Decision

An `any` argument concatenated into a boxed-element array is decided at
runtime (`emitConcatAnyPart`). An Array (`emitDynIsArray`: a static or
dynamic array box, not a TypedArray) contributes its elements through
`__kml_anyarr_view`; any other value is a one-element run of the value
itself. An empty array literal receiver with an `any` argument is `any[]`.

## Verification

`TestE2EArrayConcatSpreadsAnyArrays` (with objects, scalars, null, a
nested literal array and a TypedArray) matches Node.
