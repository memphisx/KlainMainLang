# ADR-01695: Primitive wrapper objects

- **Relations**: Implements TDD-00230
- **Date**: 2026-10-18

## Context

TDD-00230 P3.3. `new Number(3)`, `new String("a")` and `new Boolean(false)` were compile errors ("unknown class"). `Object(primitive)` threw a TypeError. `(3).valueOf()` and `x.valueOf()` on an `any` holding a primitive failed too.

## Decision

**A wrapper is a headered host value** (`hostPrimWrapper`, its class in `HostTag`). The cell is `{ header, primitive, bag }`:
- the primitive is the boxed value the constructor called as a function gives (`Number(x)`, `String(x)`, `Boolean(x)`);
- the bag is the dynamic object of the properties assigned to the wrapper, null until one is.

The checker's `Number`, `String` and `Boolean` interfaces already lower to `any`, so a wrapper is only ever held boxed. That makes it:
- `typeof` "object";
- always truthy;
- an object with its own identity (`new Number(1) !== new Number(1)`).

**The host row** (`boxsrc/hostbox.c`) gives:
- ToPrimitive and `String()`: the primitive, whatever the hint;
- `[object Number]` and `instanceof Number`;
- console.log's `[Number: 3]`, `[String: 'a']`, followed by its own properties (`[Number: 4] { tag: 'x' }`).

**JSON.stringify** serializes the primitive (`dynjson.c`).

**Properties** (`wrappersrc/wrapper.c`, linked only when the program builds a wrapper — an AST prescan, `wrappersUsed`):
- A read or method call finds the bag's own property first, else the primitive's, which are the prototype's members (`__kml_wrapper_recv`).
- An assignment goes into the bag. A String's index or `length` is read-only, so assigning one throws the strict-mode TypeError.
- `Object.keys` lists a String's indices, then the bag's keys. `getOwnPropertyNames` adds `length`.
- `in` answers a String's index, `length` and the bag's keys, then the prototype's members as before.
- for-of and spread walk a String wrapper's characters.

**`Object(v)`** wraps a number, string or boolean, typed or boxed. `new Object(v)` is held as `any`.

**`valueOf`** on a primitive (`Number`/`String`/`Boolean.prototype.valueOf`, an intrinsic) is the primitive itself. On a wrapper it is the wrapper's primitive. A dynamic `x.valueOf()` returns a boxed primitive as it is.

Not covered: a bigint or a symbol has no wrapper. `Object(1n)` is a compile error for a typed value and returns the primitive for an `any`.
