# ADR-01772: Generators throw and receive any value, not only an Error

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

A generator kept its pending exceptions as Error pointers:

- The body's catch-all stored `__kml_get_thrown()`, which is null for a thrown value that is not an Error. So `function* g() { throw 42 }` finished silently, and an async generator throwing a plain object fulfilled its request instead of rejecting it.
- `.throw(v)` ran `v` through `errorPtrFromValue`, which wraps a non-Error in a new Error. `it.throw("x")` was caught in the body as `Error: x`, and a forwarding yield* passed the inner iterator an Error.

## Decision

Both fields (`__genError` for the catch-all, `__thrown` for `.throw(v)`) hold a 16-byte thrown cell: the value's tag and payload, as `throw v` throws it (`emitThrownCell`, `thrownCellOf`). Every reader takes the value back out of the cell:

- re-throwing reads it with `loadThrownCell` and `excThrowAny`;
- rejecting reads it with `emitRejectCaught`;
- forwarding to an inner iterator reads it with `thrownCellAny`.

## Consequences

- `TestE2EJSFileGeneratorThrowsAnyValue` covers both, in sync and async generators.
- Each generator throw allocates one cell.
