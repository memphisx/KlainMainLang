# ADR-00995: Numeric Map/Set keys follow SameValueZero (-0/+0, NaN)

- **Date**: 2026-09-17

## Context

Typed numeric-keyed `Map`/`Set` (and the bare `new Map()` numeric runtime)
compared keys by the raw double bit-pattern, diverging from JS SameValueZero:
`+0` and `-0` were distinct keys (`new Set([0, -0]).size` was `2`, JS: `1`), and
a `NaN` key deduped only when producing operations happened to share bit
patterns. Documented as a caveat on the `Map`/`Set` rows (type-system,
language-constructs) and on the bare-`new Map()` row (object-collections).

## Investigation

- `emit_collections.go:valueToMapKey` lowers a `Float` key by `bitcast double ->
  i64`, using the full bit-pattern as the opaque key. `+0.0` is `0x0`, `-0.0` is
  `0x8000000000000000`; distinct NaNs differ too.
- `.set`/`.get`/`.has`/seeding all route through `mapKeyRef` → `valueToMapKey`,
  so a single normalization point fixes every operation consistently.
- The any-keyed (heterogeneous) runtime already implements SameValueZero via
  `__kml_any_eq` and its box encoding (verified: `Set<any>` of `0, -0` is one
  key, `NaN` matches) — only the typed numeric path needed the fix.

## Decision

Normalize the double onto its SameValueZero representative before the bitcast:
`-0 → +0` (both signed zeros satisfy `fcmp oeq 0.0`, `select` to `+0.0`) and
every `NaN → 0x7FF8000000000000` canonical quiet NaN (`fcmp uno` detects any
NaN). Every other value passes through bit-exact, so distinct finite numbers
(`1`, `1.5`) stay distinct. Extracted as `normalizeSameValueZero(dbl)`.

## Implementation notes

- `emit_collections.go`: new `normalizeSameValueZero`; `valueToMapKey`'s `Float`
  branch calls it before `bitcast`. `valueToMapVal` (value storage) is untouched
  — only keys participate in equality.

## Side effects discovered

None. Integer-typed keys (`int32`, …) never carried a signed zero or NaN and are
unaffected.

## Verification

- New E2E `TestE2ENumericKeySameValueZero` (typed `Map`/`Set`, bare `new Map()`,
  NaN, and non-zero-distinct control); existing collection tests pass.
  Differential against `node` — all match.
- Caveats removed from 5 rows (type-system Map/Set, language-constructs Map/Set,
  object-collections bare-Map); `make status`/`status-check`/`reference-check`
  and `make examples` clean.
