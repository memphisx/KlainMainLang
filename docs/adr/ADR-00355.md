# ADR-00355: Object members in union types (usable via narrowing)

- **Relations**: Implements [TDD-00115](../tdd/TDD-00115.md); extends [TDD-00043](../tdd/TDD-00043.md) (unions), [TDD-00114](../tdd/TDD-00114.md) (narrowing); closes [TDD-00065](../tdd/TDD-00065.md) Stage 3c's object-union case
- **Date**: 2026-08-25

## Context

Union types were scalar-members-only — `string | Point` was a clean rejection.
Two pieces added since [TDD-00043](../tdd/TDD-00043.md) make an object member
tractable now: object boxing already exists (`emitBoxValue` → tag 6, with a
`"[object Object]"` toString stand-in and reference equality), and flow narrowing
([TDD-00114](../tdd/TDD-00114.md)) plus `emitUnboxBoxToType` recover a member's
static shape in a branch — the box can't carry field shape at runtime, but a
narrowed branch supplies it statically.

## Decision

Allow **at most one** object/interface/class member in a union (two would need
discriminated-union narrowing, deferred), boxed unchanged as tag 6:

- `validateUnionMembers` accepts one object member (`isUnionObjectMember`);
  a second, or an array/Map/Set member, is a clean rejection.
- `unionAllowsAssignmentFrom` matches an object value to the object member by
  structural width subtyping (`objectStructurallyAssignable`: the value carries
  every field the member declares, with a matching kind; extra fields ok).
- `unionMemberTag` classifies an object member as `"object"`, so
  `typeof x === "object"` narrows to it and `emitUnboxBoxToType` recovers the
  object pointer typed as the member — field access, destructuring, and object
  rest then ride existing machinery. Truthiness `if (x)` on `Point | null`
  narrows to the object member the same way.
- Un-narrowed: the boxed-object stand-ins stand (`String(x)` → `"[object
  Object]"`, `===` reference equality); field access on an un-narrowed object
  union is a clean rejection (no static shape without narrowing).

This closes [TDD-00065](../tdd/TDD-00065.md) Stage 3c's object-union-source rest
case — `if (v) { const { a, ...rest } = v }` over a `Rec | null` now works — so
the only Stage 3c case still deferred is a bare-`any` source (no static shape,
[TDD-00062](../tdd/TDD-00062.md)).

## Scope

- **In:** a union with scalar members plus one object member; structural
  assignment; `typeof === "object"` / truthiness narrowing; fields/destructuring/
  rest on the narrowed member; un-narrowed stand-ins.
- **Out (deferred):** two+ object members (discriminated unions); array/
  `ArrayBuffer` union members (2-slot aggregate doesn't fit the single payload);
  field access on an un-narrowed object union or bare `any`; `switch`/`in`
  discriminant narrowing.
