# ADR-02077: Unbounded async recursion throws the stack-overflow RangeError

- **Relations**: Extends TDD-00249; Implements TDD-00230
- **Date**: 2026-11-24

## Context

Node's `test-console-log-stack-overflow` recurses through
`async function test() { await test(); }` and expects the
`RangeError` to be caught. Here the program grew past 4 GB in five
seconds on Linux x86-64 (HEAD and the working tree alike) and the
guard killed it; on macOS it took the Node js lane down with it.

## Investigation

- An async function runs on its caller's stack until its first
  `await`, so in Node the recursion is synchronous and overflows the
  one stack.
- Here every async call starts a task on its own 256 KB fiber stack
  (`__kml_spawn_task_ex`, task.c). No single stack ever fills, so the
  stack guard never fires. Each level holds a task, a context, a stack
  mapping and a jmpbuf stack, and the recursion runs until memory
  runs out.

## Decision

- A thread-local `task_chain_bytes` holds the stack used by the chain
  of synchronous task starts above the current one. A spawn adds the
  current fiber's used stack (its stack top minus the frame address)
  to it. Past 984 KB (Node's default stack size, the main thread's
  limit in stackguard.c) the spawn throws `RangeError: Maximum call
  stack size exceeded` at the call site, before allocating.
- A spawn restores the chain value when the new task yields back. A
  task resumed from the event loop (`task_swap_in`) starts a chain of
  zero, as a resumed async function in Node runs on a fresh stack.
- The message is the program string stackguard.c already holds
  (`__kml_sg_message`), so it renders as any other error message. With
  the guard compiled out (sanitizer builds) there is no message, and
  the spawn does not throw.

## Implementation notes

- `codegen/llvm/tasksrc/task.c`: `TASK_CHAIN_LIMIT`,
  `task_chain_bytes`, `task_stack_used`, the check in
  `__kml_spawn_task_ex`, the reset in `task_swap_in`.
- `codegen/llvm/stackguardsrc/stackguard.c`: `__kml_sg_message`, in
  both the POSIX and Windows halves.

## Verification

- `TestE2EAsyncRecursionStackOverflow`: the recursion is caught as a
  `RangeError` with Node's message, and a 500-deep awaited recursion
  that ends still completes. Passes on Linux x86-64 and macOS arm64.
- The Node test's program peaks at 66 MB on Linux x86-64, against more
  than 4 GB before.
