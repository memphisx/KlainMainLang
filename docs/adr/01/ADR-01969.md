# ADR-01969: Generic class members, rest type parameters and other checker gaps the shadow rows named

- **Relations**: Implements TDD-00230 (P3.3); follows [ADR-01968](ADR-01968.md)
- **Date**: 2026-10-29

## Context

After ADR-01968, 323 E2E shadow rows remained. Grouping them by node and callee showed several small checker and oracle gaps, each behind a handful of rows. Two were wrong output, not only disagreements.

## Investigation

- **A function parameter typed `Error & { port?: number }` printed `Error undefined` where Node prints `x 3`.** The checker types the intersection as an object of the merged members. The oracle laid that out as a struct of those fields, so the parameter read `message` from the slot where the host `Error` keeps `name`. Codegen's own rule (`resolveType`) holds an intersection with a host or class member as `any`: no struct of the merged fields holds that value. The checker's intersection type kept no record of its members, so the oracle could not apply the same rule.
- **`NodeJS.ErrnoException & { address?: string }` was laid out as the bare `ErrnoException`.** A union or intersection annotation's head copy carries its first member's name and qualifier (TDD-00078). `qualifiedLibType` read that qualifier and ignored the member lists. `NodeJS.Timeout | number` had the same problem.
- **`o.m!()` stripped in place.** `emitCall` drops a non-null assertion on a callee by assigning `ex.Callee = nn.Arg`. When the checker had not typed the call yet, it then saw `it.return("x")` on an optional method, a possibly-undefined call, and answered `any`.
- **`setTimeout(cb, 1, a)` and `setInterval`/`setImmediate` with extra arguments were unanswered.** Inference already collected the tuple for a rest typed by a type parameter (`...args: TArgs`). `pickOverloadPass` then required `paramAt(sig, i)` for every argument, which is nil for a type-parameter rest on the uninstantiated signature, so every such overload was rejected.
- **`get<T, K extends keyof T>(o: T, k: K): T[K]` gave `string | number` for `get(m, "id")` instead of `number`.** A type parameter keeps a literal candidate when its constraint is primitive. `keyof T` over a generic `T` is a deferred type, which `primitiveConstraint` did not count.
- **`[..."a1".matchAll(r)]` was unanswered.** `iteratedType` lists the lib's iterator interfaces by name; `StringIterator`, `RegExpStringIterator` and `ReadableStreamAsyncIterator` were missing.
- **Every unannotated member of a generic class instance was unanswered** (`new Stack(1).size()`). `instanceOf` declined them on purpose: an expression's type is cached per node, and in a generic class it could depend on the type arguments. tsc infers such a member once, on the declaration, against the class's own type parameters, and instantiates the result.
- **`crypto.subtle.generateKey`/`importKey`, `stream.values()` and dynamic `import()` results** were answered by the checker but mapped to layouts codegen does not use:
  - `CryptoKey`/`CryptoKeyPair` have no tagged layout; codegen holds them boxed.
  - `ReadableStreamAsyncIterator<R>` is implemented by the lib class `StreamAsyncIterator<R>`, which is generic. The oracle's lib-class mapping handled only global links and non-generic classes.
  - An isolated module's `import()` result is an object of its exports with no presence word (`importCallResultObjectType`). The oracle laid the checker's object type out with one.
- **`function f() { const { y = "dflt" }: M.Pt = { x: 1 }; return y; }` returned `0` instead of `"dflt"`.** The resolver rewrites a declaration's annotation to the merged program's names (`rewriteType`), but not an array or object destructuring's. A destructuring annotated through an import (`M.Pt`, `crypto.KeyPairKeyObjectResult`) named nothing in the merged program, and its bindings were untyped.
- **`const p = it.next(); await p`** on an async generator: the step rule followed only an `await` of the call itself, not of a `const` holding it.
- **`const [m, n]: [number, string] = JSON.parse("[4]"); n.length` crashed (exit 139) where Node throws a TypeError.** The pattern's source is a box, so its leaves are held as boxes. `checkerNarrowed` then read the checker's `string` as a flow narrowing and unboxed the leaf as a string, which the missing element is not. The annotation is a claim nothing checked, not a narrowing.
- **`k: keyof S` and `o[k]` was unanswered.** An element access by a union of literal keys reads each key's property, joined; the checker read only a single literal key.
- **`e.once("b", (...args) => …)` typed `args` as one box.** The rule for a callback passed where an overloaded implementation takes `any` applied to a rest parameter too, which collects the boxes into an `any[]`.
- **`globalThis` had no type.** The checker typed `globalThis.setTimeout` through the global's declaration, but not `globalThis` itself, `globalThis.zz` or a binding holding it.
- **A JavaScript prototype constructor's identifier typed its plain return** (`Sum` with `Sum.prototype.tag = …` as `(a, b) => number`). Codegen gives every prototype constructor a boxed return (`jsCollectProtoCtors`). `return new P(v)` inside `P` was also unanswered: codegen records the constructors only after it first infers their bodies.
- **An object pattern over an object literal's type without the key** (`({t = arguments}) => …` called with `{k: 4}`) was unanswered. tsc reports TS2339 and types the name with its error type, which a default joins as `any`.
- **`new Map([['a', 1], ['b', 'c']])` in the JavaScript lane** typed `Map<any, any>` (the lane's lenient arity picks the zero-argument overload). Codegen reads the pairs' own key type, `string`.
- **A method with a `this: Example` parameter and no return annotation was unanswered.** `thisType` declined every narrowable explicit `this`, an instance type included, because flow narrowing does not track an explicit `this` yet.

## Decision

- **The checker:**
  - Records an intersection's members on its type (`Type.Intersects`, part of its interned key).
  - Marks a dynamic `import()`'s module object with its call (`Type.ImportCall`).
  - Binds a type-parameter rest's arguments to the inferred tuple's elements (`instantiatedParamAt`, and `paramAt` on an instantiated tuple rest).
  - Counts a deferred `keyof` constraint as primitive.
  - Reads an element access by a union of literal keys as the union of their properties.
  - Types `globalThis` as the global object: a member of it is the global of that name, else `any`.
  - Types a pattern name that an object literal's type has no property for as `any`.
  - Iterates the missing lib iterator interfaces.
  - Types a generic class's unannotated fields, methods and getters on its own instance (type arguments equal to its type parameters). Every other instantiation substitutes that answer.
  - Types an explicit `this` of a class or interface instance type as declared, unless the body tests `this` (`instanceof`, `typeof`, an equality, `in`), which could narrow it (`narrowsThis`).
- **The oracle:**
  - Maps an intersection with a host or class member to `any` (`hostIntersection`), and an `import()` module object to codegen's layout.
  - Maps a tagged lib interface to its generic implementing class, instantiated (`libInterfaceClass` with type arguments).
  - Follows an awaited `const` holding a generator step.
  - Leaves a callback's rest parameter out of the boxed-parameter rule for an `any`-taking implementation.
  - Gives a prototype constructor a boxed return, and `new F(…)` of a top-level function declaration a box, from the binder rather than codegen's late set.
  - Maps the global object to a box, and a JavaScript-lane `new Map(pairs)` typed `Map<any, any>` to codegen's `mapKVTypes`.
- **The lib:**
  - Tags `CryptoKey` and `CryptoKeyPair` `dynamic`.
  - Tags `ReadableStreamAsyncIterator` with its implementing class.
- **The resolver** rewrites an array or object destructuring's annotation, as a declaration's.
- **Codegen:**
  - `qualifiedLibType` declines a union's or intersection's head copy.
  - `emitCall` has the checker type a call before it strips the callee's non-null assertion.
  - `checkerNarrowed` keeps the box of an annotated destructuring's leaf that flow has not narrowed.

## Consequences

- `Error & { port?: number }` and `NodeJS.ErrnoException & {…}` parameters read their values as Node does (`TestE2EIntersectionErrorParam`).
- A destructuring annotated with an imported type reads its defaults and members as Node does (`TestE2EDestructuringAnnotationImportedType`).
- An annotated pattern over a short source reads undefined and throws on a property read, as Node does (`TestE2EDestructuringAnnotationShortSource`).
- Timer calls with extra arguments, `T[K]` accessors, `matchAll` spreads, generic class members, `o[k]` by a `keyof` key, `globalThis` and a missing pattern property type as tsc types them (`TestOverloadRestTypeParam`, `TestGenericDeclarations`, `TestIndexByLiteralKeyUnion`, `TestGlobalThisType`, `TestDestructuredMissingProperty`).
- Not yet closed:
  - An explicit `this` that its body tests is still unanswered: flow narrowing does not track it yet.
