# ADR-01665: Promise.withResolvers

- **Relations**: Implements TDD-00230
- **Date**: 2026-10-17

## Context

`Promise.withResolvers()` (ES2024, available in Node since 22) did not compile.

## Decision

The function is a library lowering in `lib/node/kml_promise.ts`: `__kml_Promise_withResolvers<T>` builds a `new Promise<T>` and returns its promise together with the captured `resolve` and `reject` functions. `lib/es.d.ts` declares `withResolvers<T>(): PromiseWithResolvers<T>` with `@lower`, and declares the `PromiseWithResolvers<T>` interface.

A lowered call carries the program's type arguments (`libCall` copies `ex.TypeArgs`), so the explicit form `Promise.withResolvers<number>()` instantiates the lowering. The early return in `emit_lowered.go` for calls with type arguments now applies only to the native-entry path.

## Side effects discovered

Calling it with another constructor as `this` (`Promise.withResolvers.call(MyPromise)`) still builds a plain `Promise`. This is disclosed as a caveat on the status row.

## Verification

- `TestE2EPromiseWithResolversSameAsNode` covers the explicit, contextual and `await` forms against Node.
- Example: `examples/promise/with_resolvers.ts`.
- Verified on Mac.
