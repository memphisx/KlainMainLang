# ADR-00731: `atoi`/`readlink` declared once — and the Windows delivery's suite results

- **Relations**: Extends [ADR-00719](ADR-00719.md) (recorded the unguarded declarations as a side effect); closes the 2026-09-06 Windows delivery ([ADR-00725](ADR-00725.md)–[ADR-00730](ADR-00730.md))
- **Date**: 2026-09-06

## Context

ADR-00719 noted that the cluster, fs and process runtimes each emitted their own `declare` for `readlink` (and the cluster runtime one for `atoi`) without a once-guard, so a program using two of those modules together would produce a duplicate declaration. Every other C declaration in the emitter goes through an `ensure*()` that emits exactly once.

## Decision

`ensureAtoiDecl` / `ensureReadlinkDecl` in `runtime_core.go`, with once-flags on the emitter; the four sites (`runtime_cluster.go` ×2, `runtime_fs.go`, `runtime_process.go`) call them. The declaration text is the `noundef` form; the `runtime_process.go` site had used the bare form, which the shared helper supersedes.

## Verification

- Windows 11 x86-64, `go test ./tests` (AdGuard not running): **2678 passed, 0 failed, 36 skipped**, 10.7 min. The skips: the 7 windowed webview smoke runs (gated by `KML_WEBVIEW_SMOKE` on every host; all 7 pass with it set), 12 child_process/execFileSync tests spawning POSIX tools, the 6 POSIX signal tests (their console-backed Windows variants run and pass), 3 cluster distribution tests (TDD-00177 open question 7), 4 `/proc`-reading memory-bound tests, 2 sanitizer builds, `process.getuid`, and the fs POSIX path-ops test. ADR-00719's 47 skips are down to 36 with the webview compile tier, `serve`, and — through the harness — signals, tty and tui now running. `go test .` (packaging) and `go vet ./...` pass.
- Linux x86-64 (Docker `klain-ci`, `golang:latest` + the release workflow's package list, Go 1.27.1, clang 19): `go build`, `go vet ./...` and `go test ./...` pass (the E2E package in 7.4 min). Two files first named with Go's `_windows.go` suffix (`webview_windows.go`, `packaging_windows.go`) were invisible to the Linux build and are `*_win32.go` now — the Linux lane is what caught it.
- Test262 (`tools/conformance -compat=both`, Linux): js lane **6676 / 53578** (was 6669), strict lane **6270** (was 6265) — the `var` re-declaration fix of ADR-00730 accounts for the movement; the committed reports are regenerated from this run.
