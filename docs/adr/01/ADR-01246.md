# ADR-01246: A machine integer into `any` is boxed

- **Date**: 2026-09-29

## Context

`a ?? Number.MAX_SAFE_INTEGER`, with `a: any`, read `4.17e-308`. The
constant is an `i64` (it is exact as one), and `coerce` passed a value
through unchanged whenever the source and target IR matched. `any` is also
`i64` in IR, so the integer's raw bits became the box.

## Decision

`coerce` no longer passes a non-dynamic value through into a dynamic
target when their IR matches; the value is boxed as a number
(`emitBoxValue`).

## Verification

Mac (Apple Silicon): `TestE2EIntegerConstantIntoAny`; the full test suite.
