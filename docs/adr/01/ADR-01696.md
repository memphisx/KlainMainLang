# ADR-01696: Array holes

- **Relations**: `Implements TDD-00226`; `Implements TDD-00230`; `Supersedes ADR-01040` (the gap-write throw it kept)
- **Date**: 2026-10-18

## Context

A write past the end of an array (`a[3] = 4` on `[1]`) threw `Array index out of bounds`; `new Array(n)` and an elided literal element (`[1, , 3]`) made real zero or undefined slots; `delete a[i]`, `i in a` and `a.hasOwnProperty(i)` did not compile on arrays. Node gives all of these *holes*: elements that read as `undefined`, are skipped by `forEach`/`map`/`filter`/`reduce`/`some`/`every`/`indexOf`/`lastIndexOf`/`Object.keys`/`for…in`, print as `<n empty items>`, serialize as `null` and join as `""`.

## Decision

TDD-00226's Option A, all four stages:

- **Header word.** The heap array header is `{ ptr data, i64 len, ptr holes }` (`arrayHolesOff` 16, `arrayHeaderSize` 24). `holes` is null for a packed array; the first hole points it at a bitmap `{ i64 nwords, u64 bits[] }` (`holessrc/holes.c`). The `{ptr,i64}` aggregates and the call ABI are unchanged.
- **Opt-in.** Only a program that can make a hole (`holesUsed`: an element assignment, `new Array(…)`/`Array(…)`, an elision, `delete xs[i]`) emits hole tests and links `holes.c`; any other program emits what it did before.
- **Producers.** A gap write grows the buffer and marks the gap; `new Array(n)` marks every element; an elision marks its index (after a spread, the index as written at run time); `delete xs[i]` marks an in-range element; growing `length` marks the new elements.
- **Readers.** An index read tests the bit and reads the miss value; inspect groups runs into `<n empty items>`; `JSON.stringify` writes `null`; `join`/`String()` write `""`; the skipping walkers above pass over holes; `includes` matches a hole only against `undefined`; `map`, `slice`, `concat` and `splice`'s removed array keep their source's holes; `reduce` without a seed starts at the first set element (and throws when there is none); `in`, `hasOwnProperty` and `Object.hasOwn` answer false for a hole.
- **Mutators.** `pop`, `shift`, `unshift`, `splice`, `length =` move or drop bits with the elements (`__kml_holes_splice`, `__kml_holes_setlen`); `reverse`, `fill`, `copyWithin` reverse, clear or move them; `sort` compacts the set elements to the front, sorts those and leaves the holes last, as Node does. An index write clears its bit.
- **Slot contents.** A hole's slot holds what a hole reads as where a walk loads the slot directly (for…of, spread, `find`, destructuring): the undefined box for a dynamic element, a null reference for a string or object, NaN for a float, zero for an integer.

## Consequences

- An integer element has no undefined: a walk that reads holes as values (for…of, spread, `find`/`findIndex`, destructuring) sees `0` for a hole of a `number` array compiled to `i64`, and `NaN` for a float one. This is the representation limit ADR-01040 already records for an out-of-range read; every other observation (index read, inspect, JSON, join, the skipping walkers, `in`) is faithful.
- A packed array in a program that makes holes pays one load and branch per hole test.

## Verification

macOS (Apple Silicon). Probe programs diffed against Node: producers, inspect, JSON, the walkers, the mutators, `delete`/`in`/`hasOwnProperty`, reduce without a seed, `copyWithin`, an elision after a spread — identical output. E2E: `tests/array_holes_test.go`. Example: `examples/basics/array_holes.ts`.
