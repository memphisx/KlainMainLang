# ADR-01925: oracle rows — overload implementations, boxed `this`, generic instantiations, iterator helpers

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

The oracle disagreed with codegen on:

- a call of an overloaded function whose implementation returns `T | undefined` (`statSync(p)`), which codegen holds as the implementation's nullable result;
- a property of a `this` held as a box (an object literal's method typed by a contextual `this:` parameter), which codegen reads dynamically;
- a generic class's instantiation (`new AsyncLocalStorage<RequestCtx>()`), which codegen monomorphizes to its own class;
- an iterator helper's result (`it.filter(f)`, `IteratorObject<T>`), which codegen holds boxed;
- an object literal with a member that returns a generator, which the type alone could not tell from a generator method (boxed);
- a null comparison's operand whose every store is present, which codegen reads as its payload;
- the switch fallbacks of an analysis pre-pass, which asks before its bindings are in scope.

## Decision

The oracle mirrors each codegen reading. A generic instantiation asks codegen for the class it builds, through a side-effect-free hook. Pre-pass fallbacks are not compared, matching the other hooks.

## Consequences

- The fs, call/apply, AsyncLocalStorage, iterator-helper, for-await, nullable-scalar and generic-Promise compiles lose their rows.
