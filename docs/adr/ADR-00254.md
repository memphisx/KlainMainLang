# ADR-00254: Async generator methods (`async *m()`)

- **Relations**: `Implements TDD-00085` (Stage 4, completing it); builds on [ADR-00253](ADR-00253.md) (async generators), [ADR-00182](ADR-00182.md) (sync generator methods)
- **Date**: 2026-08-20

## Context

Sync generator methods (`*m()` on a class, [ADR-00182](ADR-00182.md)) bind `this`
from a `__this` slot stored at construction and emit through the shared generator
machinery. Async generators as free functions ([ADR-00253](ADR-00253.md)) added
the fused fiber (`yield` + `await` + `.next(): Promise<{value,done}>` + throw→
reject) driven off `GeneratorInfo.IsAsync`. An `async *m()` method is the
intersection — previously a clean rejection at emit time.

## Decision

Remove the emit-time rejection; an `async *m()` rides the exact same path as a
sync generator method. It already worked out because both prerequisites were in
place:

- **Registration** already builds a `GeneratorInfo` for any generator method via
  `buildGeneratorMethodInfo` → `buildGeneratorSig`, which sets `IsAsync` from the
  method declaration and stamps `GeneratorIsAsync` onto the method's generator
  type — so `.next()` type-infers to `Promise<{value,done}>` and dispatches to the
  async `.next()` path.
- **Emission** routes a generator method through `emitGeneratorFunctionDecl`,
  which (from [ADR-00253](ADR-00253.md)) sets `hasMaySuspend` and pulls the task
  runtime when `IsAsync`, so the body's `await`s emit the scheduler-driven path.

The `__this` binding and the async fiber are orthogonal — `this` is loaded once
at body entry from the `__this` slot regardless, and the async `.next()` swap /
`for await` consumer are unchanged.

## Consequences

- An `async *m()` method works: `this` access, `await` in the body,
  `for await...of` consumption, manual `.next()`, and throw→reject — the same
  surface as a free-function async generator.
- Static and abstract generator methods stay rejected (unchanged, [ADR-00182](ADR-00182.md)),
  as do the free-function async-generator V1 scope cuts (`yield*`,
  `Symbol.asyncIterator`, `.return()`/`.throw()`, resolved-not-pending `.next()`).
