# ADR-01520: A module binding promotes by its declared type's representation

- **Relations**: Extends TDD-00093, TDD-00230
- **Date**: 2026-10-09

## Context

A top-level binding a function reads must be a module global; otherwise
the function's reference is an undefined variable. An unannotated
binding promoted only when the checker typed its initializer as a
primitive, a class instance or bytes. `let u = 0 as number | string`
(read in a function) was therefore never promoted and failed to compile.
The promotion pass also typed an `as` initializer by its operand, while
the declaration types a widening to a union by the union.

## Decision

- A binding a function reads promotes when the checker's declared type
  for it maps (`reprOf`) to the storage the declaration stores. Every
  later store coerces into it; `promotedStorageAgrees` still checks the
  declaration.
- The promotion pass and the declaration share `asBindingType`.
- `reprOf` maps the builtin `Function`, `Boolean`, `Number`, `String` and
  `Object` interfaces to `any`, as codegen holds them.
