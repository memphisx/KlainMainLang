# ADR-01653: An array keeps its identity across every boundary

- **Relations**: Implements [TDD-00230](../../tdd/TDD-00230.md) (P3.3, values and representation); builds on [TDD-00213](../../tdd/TDD-00213.md)
- **Date**: 2026-10-16

## Context

An array is one object shared by every alias (TDD-00213), but several
paths carried only its `{data, len}` pair and rebuilt a header on the far
side. The copy shared element writes, but a `push` on it did not reach the
original, and `===` was false:

- a promise's value (`Promise.resolve(a)`, `res(a)`, an async return,
  `.then`) stored data and length in its two value words;
- an async function's array parameter travelled through the task bundle
  as data and length;
- `boxArrayValue` minted a second header even for a value that carried
  its live one (`const [z] = [a]`, nested-array element stores);
- a rest argument holding an array stored the 16-byte pair into an
  8-byte slot, which is invalid IR;
- `t[0].push(x)` on a tuple element was a codegen error.

The checker also rejected `setTimeout((q: number[]) => …, 1, a)`: a rest
parameter typed by a type parameter (`...args: TArgs`) did not infer the
tuple of the arguments it collects.

`Symbol.NullableBoxed` duplicated what the symbol's type already records
(`isNullableScalar(sym.Ty)`), and the two could disagree.

## Decision

- A promise's v0 word holds the array's header pointer;
  `loadPromiseValue`, the `.then` result and argument paths, and the
  `resolve` thunk all read that header.
- The task bundle holds the caller's header, and the parameter binds a
  slot pointing at it.
- `boxArrayValue` returns a value's live header when it has one.
- Rest packers store elements through `storeArrayElem`.
- A tuple receiver of an array mutator goes through the value's header.
- `...args: A` infers `A` as the tuple of the trailing argument types,
  both at a call and when unifying one function's parameters against
  another's.
- `Symbol.NullableBoxed` is removed; the type decides.

## Consequences

- `TestE2EArrayIdentityAcrossBoundaries` matches Node.
- A generator's yielded array and `Promise.allSettled`'s values still
  lose identity: their readers carry the `{data, len}` register. The
  single array value shape in P3.3 removes that register form.
