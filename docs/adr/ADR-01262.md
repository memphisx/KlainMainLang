# ADR-01262: Rest-parameter closures convert through the box

- **Relations**: `Extends ADR-00477`
- **Date**: 2026-09-29

## Context

Assigning `(cb, ...args) => …` to `(...args: any[]) => any` passed the
closure through unchanged, and a call through the new type crashed: the
calling conventions differ, one taking `cb` and a rest array, the other
a single rest array. The reverse direction (`snapshot()`'s runner) did
the same. `funcAdapterPlan` reported these conversions as not needed.

## Decision

A conversion where one side takes fixed parameters the other passes in
its rest tail is needed but not direct: it goes through the boxed closure,
whose dynamic call spreads and packs the arguments.

## Verification

Mac (Apple Silicon): `TestE2ERestClosureConversions` matches Node.
