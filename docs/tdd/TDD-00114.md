# TDD-00114: Flow-based narrowing of union types

- **Status**: Implemented
- **Date**: 2026-08-25

## Context

General union types ship ([TDD-00043](TDD-00043.md)) as a boxed `{ i8, i64 }`
value (the `any` box plus a checked member set), but with **no flow-based
narrowing**: inside `if (typeof x === "string") { … }` the value `x` stays a
union, so it can't be used as a `string` (no method calls, no arithmetic) — the
single biggest thing that makes unions actually usable in real TypeScript. This
is the last major core-language type-system gap.

When TDD-00043 shipped it noted narrowing was deferred because "this compiler has
no flow-typing infrastructure anywhere." That is no longer quite true:
[TDD-00064](TDD-00064.md) Stage 2 added a **narrow-in-branch-scope** mechanism
for nullable scalars (`applyBranchNarrowing` / `narrowingFromCondition` /
`narrowNonNullInCurrentScope`, `emit_nullable_scalar.go`), wired into the `if`
statement (`emit_stmts.go`) for both branches. Union narrowing generalizes
exactly that precedent rather than inventing a new analysis.

## Design

### Reuse the nullable-scalar branch-narrowing seam

The nullable path already does the whole scope dance: at an `if`, it inspects the
test, and in the branch where a guard proves the binding present it shadows the
binding into the branch's own scope with a flag set; `popScope` discards the
shadow, restoring the outer view. Union narrowing adds:

1. **A target-type field on the shadow.** `Symbol` gains `NarrowedTo *Type` (nil
   = not narrowed). Where the nullable path sets `NarrowedNonNull`, the union
   path sets `NarrowedTo = &memberType`. (For a `T | null` union guarded to `T`,
   both may apply.)
2. **Guard recognition** (`narrowingFromCondition`, generalized): detect, for a
   union-typed local `x` —
   - `typeof x === "string"` / `"number"` / `"boolean"` (and `!==` for the
     opposite branch) → narrow to that scalar member;
   - `if (x)` truthiness → narrow out `null`/`undefined` (and falsy), i.e. to the
     remaining member(s); if exactly one non-nullish member remains, that concrete
     type;
   - `x === null` / `x == null` / `!==` / `!=` → the existing nullish split,
     extended so the non-null branch narrows to the remaining member(s).
   Return `(name, narrowedType, branchWhenTrue)`.
3. **Use-site unboxing.** When `emitExpr`/`inferExprType` resolves an identifier
   whose `Symbol.NarrowedTo` is set, unbox the union box to that concrete type
   (`emitUnboxTagPayload` + rebuild the scalar/string `Value`) and hand back a
   value of the narrowed `Type` — so every downstream site (method dispatch,
   arithmetic, `console.log`) sees a concrete `string`/`number`/`boolean`, not a
   union. Narrowing to a still-multi-member union (e.g. `string | number | boolean`
   guarded only by `if (x)` removing null) keeps the box but drops the nullish
   members from the static member set.

### `if` wiring

`emit_stmts.go` already calls `applyBranchNarrowing(s.Test, true)` in the then
branch and `(…, false)` in the else. Both extend to union locals with no new call
sites. `&&`-chained guards (`if (typeof x === "string" && …)`) narrow on the
left conjunct in V1; a general boolean-guard algebra is deferred.

### Scope (V1)

- **In:** narrowing a union-typed **local binding** via `typeof`, truthiness, and
  `=== null`/`== null` guards, in both an `if`/`else` branch and — via the
  existing nullable early-exit seam (`emit_stmts.go`) — after an early
  `return`/`throw`/`break`/`continue` (`if (typeof x === "string") return;`
  narrows the remainder of the scope to the complement); nested `else if`
  composes (each refines the remaining members); narrowing to a single scalar
  member makes the value fully usable (methods/arithmetic/print); the five scalar
  tags TDD-00043 already boxes.
- **Out (deferred):** narrowing a
  field/element or an arbitrary expression (locals only, matching the nullable
  precedent); discriminated-union narrowing on an object tag field (needs object
  union members, itself post-TDD-00043); `switch (typeof x)` narrowing; `&&`/`||`
  guard algebra beyond the first conjunct; `as` casts.

## Open questions

- **Reassignment inside a narrowed branch.** If `x` is reassigned to a different
  member inside the narrowed block, the narrowing must not outlive the
  assignment. The nullable path shadows per-scope; confirm an assignment
  re-widens (or re-narrows) correctly, or clear `NarrowedTo` on assignment within
  the branch.
- **Truthiness precision.** `if (x)` on `string | number` removes `null`/`""`/`0`
  at runtime but statically only `null`/`undefined` are removed from the member
  set — a `0`/`""` value still flows in as its type. Confirm this matches TS
  (it does: TS narrows by type, not value, for non-literal members).
