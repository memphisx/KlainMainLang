# ADR-01533: A boxed instance of an Array subclass is an Array

- **Relations**: Extends TDD-00247
- **Date**: 2026-10-10

## Context

`Array.isArray(x)` and `x instanceof Array` on an `any` holding an
instance of `class X extends Array<T>` walk the class's parent rows to
the Array host's id. Host ids are per element layout (`Array<string>`
and `any[]` are different hosts, so a shape getter reads the right
elements), and the check looked only for the `any[]` one: both answered
false for `extends Array<string>`, and the builtin library's
`spawnSync(cmd, args)` dropped such an `args`.

## Decision

Each Array host id a class extends is registered as a child of the
`any[]` one (a parent row, as a class's), so the unchanged check finds
it. Shared library code stays the same whatever the program extends.
