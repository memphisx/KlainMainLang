# ADR-01656: Host objects carry their header word, and convert is total

- **Relations**: Implements [TDD-00230](../../tdd/TDD-00230.md) (P3.3, host header words and a total `convert`); extends [ADR-01204](ADR-01204.md); builds on [TDD-00247](../../tdd/TDD-00247.md)
- **Date**: 2026-10-16

## Context

A probe of `Object.prototype.toString.call(x)` over every host type boxed
into `any` disagreed with Node for eight of them:

- A `Response` was `[object Error]`. Its first field is `status` as a
  double, and 200.0's bit 48 reads as the Error flag of a header word.
  Response, Request, XMLHttpRequest, the HTTP server's request and response
  and FinalizationRegistry were host layouts without a header word, boxed
  under the object tag as if they had one.
- `const r: any = new Response(...)` replaced the Response with an empty
  dynamic object: allocation-site widening copied its user fields, and it
  has none. `r.status` read `undefined`.
- A ReadableStream (its own NaN-box tag) was `[object Object]`. A reader
  and a writer were `[object StreamReader]`/`[object StreamWriter]`, from
  their flag names. AbortController, AbortSignal, EventTarget and the event
  classes had no `Symbol.toStringTag`.
- `x instanceof FinalizationRegistry` did not compile, and a boxed
  WritableStream or TransformStream failed its `instanceof`.

`coerce` returned a value unchanged for any pair of representations it had
no case for, so a missing conversion reached clang as a type mismatch or
ran as a reinterpretation.

## Decision

- The six host layouts are prefixed (`hostPrefixedObject`): the header
  word sits before the body, at -8, as a Map's, a Set's, a RegExp's and a
  Date's do (TDD-00247), so the runtime's field offsets are unchanged. The
  object allocation primitives (`emitObjAlloc`, `emitObjAllocInto`,
  `emitObjMallocInto`) place it. `fetchdrive.c` stamps a fetched
  Response's from the generated `KML_RESP_HDR`, and `__kml_finreg_create`
  takes the registry's as an argument. These types join `headeredHost`, so
  a box is the header itself, frees release the base, and unboxing,
  inspection and `instanceof` read the header id.
- The host handles get the same prefix: an ArrayBuffer's and a
  SharedArrayBuffer's `{byteLength, data}` header (every creation site
  through `emitArrayBufferHeaderAlloc`; views.c stamps `KML_AB_HDR` or
  `KML_SAB_HDR` and boxes `ta.buffer` at its header), a WeakMap's or
  WeakSet's list head (`__kml_weak_create(hdr)`), a Map, Set or array
  iterator node, a WritableStream (`KML_WS_HDR` in `__kml_ws_alloc`) and a
  TransformStream's context.
- A reader or writer is its own object, `{header, stream}`, rather than the
  stream pointer retyped, so `getReader()` after `releaseLock()` answers a
  new reader as Node does. `streamOfHandle` gives the stream to every
  receiver.
- `HostTag` names a host value's class where its flags do not: a
  CompressionStream and a DecompressionStream are TransformStreams by
  layout.
- Widening a host object into a dynamic bag boxes it as itself.
- `Object.prototype.toString` answers `ReadableStream` for the stream tag.
  The class name of a host flag comes from a table where it differs from
  the JS class (`ReadableStreamDefaultReader`, `Request`, …). The event
  classes in `kml_event_target.ts` declare their `Symbol.toStringTag`.
- `coerce` records a pair of different storage types it does not convert,
  and `EmitProgram` fails with an internal compiler error naming each one.
  The first it found: `s += n` coerced the number to a string before the
  concatenation that converts it.
- `__kml_resp_collect`'s fallback is defined after the host rows, which can
  call a Response body method.

## Consequences

- Every host type in the probe prints Node's tag, and a boxed Response
  reads its fields and passes `instanceof Response`.
- Boxing any of these allocates nothing, and identity through `any` is the
  pointer's. A stream controller still boxes as a cell over its stream: its
  identity is not observable apart from the stream's.
