# ADR-01644: Own-method check for library calls with a function-literal argument

- **Relations**: Extends [ADR-01596](ADR-01596.md)
- **Date**: 2026-10-16

## Context

Node's `test-http-agent-close` assigns `agent.createSocket` on an instance
and expects `http.request` to call it. The library calls
`this.createSocket(req, options, (err, s) => …)`, and
[ADR-01596](ADR-01596.md) left out any call with a function-literal
argument, because both arms of the own-method check would emit the
literal's closure and the second copy's environment did not dominate its
use. So the program's override never ran, and the request reported an error
of its own, not the one the override passed.

## Investigation

`emitOwnOrClassMethodCall` (`codegen/llvm/emit_classes.go`) emits the
arguments once in the own arm (as a dynamic call) and again in the class
arm. Literals are the only arguments where emitting twice is a problem:
they define a closure and its environment. Making a closure has no side
effects, so evaluating the literal ahead of the other arguments cannot be
observed.

## Decision

When a call gets the own-method check (in a library, or a program that
assigns the name), each argument that is itself an arrow or function
expression is first emitted once, typed by its parameter
(`emitExprWithObjectHint`), into an entry-block slot bound to a synthetic
local. The call then passes identifiers to both arms
(`spillFunctionLiteralArgs`). A literal nested inside another argument still
skips the check in a library, as before.

## Implementation notes

`codegen/llvm/emit_classes.go`. The synthetic name carries the slot's
register, so nested calls never shadow each other.

## Side effects discovered

`test-http-write-callbacks` timed out only under the Node runner: the
test (like Node itself) lingers for the server's 5 s keep-alive timeout,
and the runner's limit was Test262's 5 s. The node suite now defaults to
30 s unless `-timeout` is given (`tools/conformance/main.go`).

## Verification

`TestE2ELibraryOwnMethodWithFunctionLiteralArg` matches Node. The library,
stream, http agent and net suites pass on Linux x86-64 (DeskMini), and
`test-http-agent-close` and `test-http-write-callbacks` pass in the Node
runner.
