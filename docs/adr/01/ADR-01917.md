# ADR-01917: oracle rows of number-keyed maps, inherited index signatures and box member reads

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

The oracle disagreed with codegen on:

- a number index signature alone (`{ [status: number]: string }`), which codegen holds as the same map as a string-keyed one, its keys the numbers' strings;
- an interface that inherits an index signature from a plain base (`SecureServerOptions extends ServerOptions`), which codegen lays out as its members; only an interface writing its own index signature, or extending a generic dictionary, is a map;
- a boxed local of a dynamic entry the checker narrows to a string (`typeof shell === 'string'`), which codegen reads as its payload;
- a member read off a box that the checker types as a number or boolean (`opaqueData.byteLength`), which codegen reads as that primitive (a string stays boxed, as it may be absent).

## Decision

The oracle mirrors each of the four codegen readings.

## Consequences

- The cluster, child-process, klainconf and HTTP/2 compiles lose their rows.
