# ADR-01800: Class method and constructor calls take any argument count in JavaScript

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- In `-compat=js`, a call to a method, static method or constructor with fewer or more arguments than it declares was a compile error ("C.m expects 2 argument(s), got 1"). JavaScript allows both: a missing argument is `undefined`, and an extra one is evaluated and dropped. Free functions and closures already followed this.

## Decision

- In the js lane the three class call paths treat every parameter as omissible. An omitted `any` parameter receives the boxed undefined; other types receive their absent value, as an optional parameter does.
- Arguments past the declared count (with no rest parameter) are evaluated in order after the declared ones, and their values are dropped. The constructor path trims a copy of the `new` node, never the AST itself.
- The strict lane still reports the mismatch, as tsc does.

## Consequences

- `TestE2EJSFileClassMethodArity` compares omitted and extra arguments, and their evaluation order, against Node.
