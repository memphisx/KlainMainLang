## Decisions

1. **`.trim()`/`.trimStart()`/`.trimEnd()` strip the full JS whitespace set**
   — previously ASCII-only *with a zero-caveat status row* (exactly the
   status/behavior misalignment this pass hunts). A new UTF-8-aware
   `@__kml_ws_span` helper recognizes every spec WhiteSpace/LineTerminator
   (U+00A0, U+1680, U+2000–200A, U+2028/29, U+202F, U+205F, U+3000, U+FEFF)
   by byte sequence, never reading past a NUL; the three trims became
   forward end-tracking scans over it (no backwards UTF-8 decoding needed).
2. **`**`/`Math.pow`: `|±1| ** ±Infinity` is NaN** — JS deviates from IEEE
   pow (which returns 1) exactly there; both routes now call a
   `@__kml_js_pow` wrapper.
3. **A decimal integer literal too large for i64 becomes a double** (e.g.
   `92233720368620160000`) — as in JS, where every literal is a double
   anyway; previously it passed through verbatim and silently wrapped at
   the LLVM layer. Inference mirrors the rule.
4. **DataView float offsets go through ToIndex** — `getFloat32(-Infinity)`
   previously hit `fptosi` poison and could bypass the bounds check; NaN,
   ±Infinity, negatives, and > 2^53 now throw the RangeError while the
   value is still a double.
5. **Harness shim `assert.sameValue` uses SameValue semantics for NaN**
   (`actual !== actual && expected !== expected`) — upstream's does; the
   `===`-only version wrongly failed every NaN assertion corpus-wide. The
   remaining SameValue difference (`+0` vs `-0`) is not reproduced — a rare
   wrong-pass, not a wrong-fail, noted in the shim.

Checked and left as already-correctly-disclosed caveats: the `const` TDZ
cluster (Variable declarations' sound-not-complete analysis), `typeof`'s
exotic tails (`BigInt(0n)`, `Date()` as a function, `new Function`,
`Reflect`), and the valueOf-coercion comparison tests (dynamic object
model).

## Verification

- Node-diff (byte-identical): the trim battery incl. U+3000/U+FEFF/U+00A0
  mixes and trimStart/trimEnd, `(-1) ** -Infinity` / `1 ** Infinity` /
  `Math.pow` equivalents, oversized-literal comparisons against
  `getFloat64` results.
- Formerly-failing Test262 near-misses re-run PASS: the DataView
  `negative-byteoffset-throws` set, `return-nan`, `to-boolean-littleendian`,
  `return-values-custom-offset`; `String/prototype/trim/15.5.4.20-3-*`.
