# ADR-00611: Default parameter referencing an earlier nullable-scalar parameter

- **Relations**: Extends [ADR-00598](ADR-00598.md) (scalar/string) and [ADR-00610](ADR-00610.md) (array) — completes the earlier-parameter default set
- **Date**: 2026-09-01

## Context

A parameter default could reference an earlier scalar/string ([ADR-00598](ADR-00598.md))
and array ([ADR-00610](ADR-00610.md)) parameter, but an earlier
**nullable-scalar** parameter (`a: number | null`) stayed a clean rejection
(`undefined variable 'a'`) — the arg loops passed its boxed `{ i1, T }` aggregate
straight through (`emitNullableScalarArg` returns only the ready arg string) and
never materialized it into the scratch scope a later default reads.

## Decision

Materialize a nullable-scalar parameter into the scratch scope as a
`NullableBoxed` symbol, so a later default can `??`/`=== null`/narrow it exactly
like a nullable-scalar local.

- The arg loops now call `emitNullableScalarBoxedValue` (the inner half of
  `emitNullableScalarArg`) to get the `{ i1, T }` aggregate, build the arg
  string themselves, and stash the aggregate.
- Free functions (`emit_call.go`): store the aggregate into a fresh
  `{ i1, T }` alloca and bind a `Symbol{..., NullableBoxed: true}` under the
  parameter name.
- Class methods / static methods / constructors (`emit_classes.go`): a new
  `paramDefaultScratch.bindNullable(i, agg, pty)` mirrors `bind`/`bindArray`.

This closes the earlier-parameter default family: scalar, string, array, and
nullable-scalar params are all now referenceable from a later default, across
free functions, instance/static methods, and constructors.

## Verification

`TestE2EDefaultParamReferencesEarlierNullableParam` — `(a ?? 0) + 1` for a passed
value, a `null`, an explicit override, and the same on a class method — matching
Node v26. The nullable-scalar, default-parameter, method, and constructor suites
still pass (the arg-passing refactor is exercised by every existing
nullable-scalar-argument test). Built and verified on Mac (Apple Silicon).
