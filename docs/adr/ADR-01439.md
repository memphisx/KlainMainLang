# ADR-01439: Presence-narrowed reads; `||` nullability; generic layouts of classes

- **Relations**: Implements TDD-00230 (P2.2), Extends ADR-01431
- **Date**: 2026-10-07

## Context

Shadow buckets after ADR-01438:

- `const value = n === undefined ? dflt : n` (`events.ts`, `n?: number`)
  held as `number | undefined` by codegen, `number` by the checker;
- `process.env.TMPDIR || process.env.TMP || ''` (`os.ts`) held as
  possibly undefined by codegen;
- `const timerListMap = new Map<number, TimersList>()` (`internal_timers.ts`)
  and `var x = function () { throw "x"; }` with no checker answer;
- `const cb = timer._onTimeout as (...args: any[]) => void` held as
  possibly null by codegen, not by the checker.

## Investigation

- Codegen narrows a nullable-scalar local only inside an `if` whose test
  is a null comparison. A conditional branch, an `&&` operand or a
  parameter read where flow proves the value present still read the
  `{i1, T}` aggregate, and the conditional's result stayed nullable.
- `&&`/`||` over two operands of one pointer type took the left operand's
  type. A pointer's absence is falsy, so `a || b` yields a present `a` or
  `b`.
- A builtin generic layout's type arguments (`Map<K, V>`) were represented
  without the caller's classes, so a class value had no representation.
  A function returning `never` had none either.
- `as` is erased (ADR-00371): a possibly-null pointer asserted to the same
  shape stays possibly null at run time, where a call through it throws as
  in Node. The checker's answer took the asserted type.

## Decision

- A nullable scalar read where the checker's declared type holds null or
  undefined and its flow type does not is its payload, in emission and in
  inference. A declared type without the absence (an out-of-range
  destructured element) is not narrowed: the checker does not model that
  absence.
- `a || b` over one pointer type is absent only when `b` can be; `a && b`
  when either can.
- Generic layouts take the caller's representation context; a function
  returning `never` is `TypeNever`.
- The checker's answer keeps a pointer's possible absence through `as`.

## Verification

- `TestE2EPresenceNarrowedReads` (against Node) passes, with the nullable,
  optional, narrowing, conditional, short-circuit, destructuring, array,
  closure, async and class tests on the Mac. The first attempt narrowed on
  the flow type alone and failed the out-of-range destructuring tests.
- The probes' shadow rows are gone.
