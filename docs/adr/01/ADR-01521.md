# ADR-01521: A member of `never` is TS2339

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-09

## Context

tsc reports a property read on `never` (TS2339: "Property 'map' does
not exist on type 'never'"), as after `let l: number[] | null = null;
if (l) l.map(…)`. The checker skipped it, so the strict lane compiled
programs tsc rejects.

## Decision

- `checkProperty` reports TS2339 for a member read whose object type is
  `never`, except through a non-null assertion (`x!` of a `null` is
  `never`, but tsc reads its members unchecked).
- The false branch of `x instanceof C` removes the members that derive
  from C's instance type (a class's base chain, an interface's
  `extends`), as tsc does, not those merely assignable to it: an `Error`
  is no `TypeError`, so `else` after `instanceof TypeError` keeps it
  (this branch had read `never`).
