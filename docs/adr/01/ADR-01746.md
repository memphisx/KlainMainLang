# ADR-01746: A constructor function takes any number of arguments

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-19

## Context

In the js lane, `new F()` and `Base.call(this, a)` failed to compile with "constructor function 'F' expects 2 argument(s), got 0" whenever the argument count differed from the parameter count. JavaScript allows any number of arguments. A missing one is `undefined`, and an extra one is evaluated and then dropped. Test262's own harness calls `new Test262Error()` with no message.

## Decision

- `emitProtoCtorArgs` passes a missing argument as the stand-in an omitted call argument gets: the boxed `undefined` for an `any` parameter, otherwise the type's zero value.
- An extra argument is evaluated for its side effects after the declared ones, then dropped.

## Consequences

- `new F()`, `new F(1)` and `new F(1, 2, extra())` behave as in Node, through `new` and through `Base.call(this, …)`.
