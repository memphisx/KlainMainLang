# ADR-01311: The checker's return type when a function's returns disagree

- **Relations**: `Implements part of TDD-00230` (P3.3)
- **Date**: 2026-09-30

## Context

An unannotated function's return type came from its first `return`
expression alone, inferred without the narrowing around it
(`decideReturnType`). A function whose returns have different kinds of value
therefore failed with invalid IR:

```ts
function g(x: number | bigint) { if (typeof x === "bigint") return x * 2n; return x * 2; }
```

The function was declared to return the first `return`'s bigint, and the
second `ret double` failed in clang (BACKLOG 27). The same held for a
string/number split, a `string | undefined` result, and so on.

## Investigation

- The checker already infers what TypeScript does: `returnType` unions each
  return expression's type, each read under its flow narrowing, plus
  `undefined` for a reachable end.
- The shadow harness's `reprOf` maps checker types to codegen
  representations, but had no union case. A union's aggregated flags would
  also have matched its scalar cases.

## Decision

- `Checker.BodyReturnType(body)` exposes `returnType`.
- `reprOf` handles a union first (`reprOfUnion`):
  - `T | null` / `T | undefined` is T's nullable form (a reference keeps
    `IsUndefined`; a scalar becomes `{ i1, T }`).
  - Two or more primitive kinds are a NaN-boxed union naming its members.
  - A union containing an array, object or function has no answer yet.
- `decideReturnType` keeps its first-return answer unless the body's return
  expressions fall into different representation classes (`reprClass`:
  number, string, boolean, bigint, array, object, function, dynamic,
  nullish). Then it takes the checker's return type through `reprOf`.
  Numeric widths alone do not count as a disagreement, so a function
  returning `0` and `a.length` is unchanged.

## Implementation notes

The checker's union already includes `undefined` for a reachable end, so the
fall-off widening is not applied again on that path.

## Side effects discovered

A symbol held in a union read `typeof` "string" and lost its description
(BACKLOG 22). ADR-01312 fixes that.

## Verification

`TestE2EUnannotatedReturnUnion` (tests/return_type_union_test.go) matches
Node on macOS arm64. It covers number/bigint, number/string,
string/number/boolean, string/undefined, number/null and array/undefined
returns.
