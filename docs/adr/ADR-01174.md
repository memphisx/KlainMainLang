# ADR-01174: Checker fixes from the diagnostics measurement

- **Relations**: `Extends [ADR-01171](ADR-01171.md)`, [ADR-01173](ADR-01173.md); `Implements [TDD-00230](../tdd/TDD-00230.md)` (P2.5, P2.7)
- **Date**: 2026-09-26

## Context

`tools/tsdiag` measures the checker against TypeScript's error baselines.
After the checker work of ADR-01171 and ADR-01173 it reported 23
diagnostics that tsc does not make. The strict lane rejects every error the
checker reports, so each one is a valid program the compiler refuses.

## Investigation

Each false positive was traced to tsc's own rule for the case:

- An interface whose construction comes out unanswered (a base the checker
  cannot type, `extends Record<keyof any, R>`) was interned before its
  bases were read. A second lookup returned the half-built type, which has
  neither the base's index signature nor its members (TS2339).
- tsc gives spelling suggestions (TS2552) only to the first ten unresolved
  names of a program (`maximumSuggestionCount`); every later one is TS2304.
- `getNarrowedType`: a union member that is a subtype of the predicate
  type stays itself; the candidate replaces a member only when it is a
  subtype of it; two unrelated object types narrow to their intersection,
  which the checker does not model. `Crate<{}>` is not a `Crate<Sundries>`:
  two instantiations of one declaration relate only when their members do.
- `x instanceof C` narrows to the type of `C`'s `prototype` property unless
  that is `any`, and only then to what `C`'s construct signature makes.
- Assigning the library's `Object` type where it does not fit is TS2696
  (tsc's head message for it), not TS2322.
- `super.m && super.m()` narrows `super.m` as it does `this.m`.
- Cases whose first line starts with a byte-order mark had their `// @strict:
  false` directive missed by `tools/tsdiag`, so they were compared as strict.

## Decision

- `interfaceOf` remembers an interface whose construction was unanswered
  (`failedNominal`); a later lookup of the interned type is unanswered too.
- `suggestionCount` counts the unresolved names reported, value and type
  positions alike; past ten, no suggestion.
- `narrowToType` keeps a member within the candidate first, substitutes the
  candidate when it is a subtype, and is unanswered for two unrelated object
  types. `within` requires real assignability between any two distinct
  named types, one declaration's instantiations included.
- `constructedType` reads `prototype` first.
- `checkAssign` reports TS2696 for a source of the global `Object` type.
- The binder records the flow node and receiver of a `super` expression as
  of `this`; a `super.m` reference is its own narrowing reference.
- `tools/tsdiag` strips a leading byte-order mark before reading directives.

## Implementation notes

`checker/{checker,symbols,narrow,check,unresolved}.go`, `binder/{binder,flow}.go`,
`diag/messages.go` (`ObjectToFewTypes`), `tools/tsdiag/main.go`.

## Side effects discovered

None.

## Verification

Mac (Apple Silicon): `tools/tsdiag` over TypeScript 7.0.2's corpus and this
project's examples and apps: 3226 diagnostics, all matching a baseline error
(was 3157 with none spurious before ADR-01171's work, 3181 with 23 spurious
after it); this project's own programs: none. The E2E suite.
