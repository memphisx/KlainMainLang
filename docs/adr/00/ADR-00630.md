# ADR-00630: D1 Stages 6+7 — extends Error, Proxy traps, Reflect

- **Relations**: `Implements TDD-00155 (Stages 6, 7 — closes the TDD)`, `Extends ADR-00629`
- **Date**: 2026-09-02

## Context

The last two D1 stages: the static bridge's `class X extends Error` leg plus
the Stage-6 widening disposition, and the `Proxy`/`Reflect` tier. Semantics
verified diff-identical against `node` (ESM `.mjs`).

## Decision

**`class X extends Error`** (`emit_classes.go`): `Error` joins
EventEmitter/Readable/Writable as a synthetic root — never a registered
class. The subclass's inherited fields are the runtime error struct's own
fields minus its kind slot, which the class tag field occupies
byte-for-byte, so an instance is prefix-compatible with every existing
throw/catch/`.message`/`.name` reader with zero new runtime machinery.
The class TagID doubles as its error kind, allocated in a dedicated
`>= 1000` range disjoint from the built-in kinds:

- `super(msg)` stores the toString'd message; `new` pre-defaults
  `name = "Error"` (JS: inherited from `Error.prototype` unless the class
  assigns `this.name`) and `message = ""`. A constructor-less subclass
  accepts JS's optional single message argument.
- `instanceof`: a statically-typed subclass instance answers `Error` true
  and specific built-in kinds false at compile time; a *caught* error
  (`errorObjType`) against a subclass class compares the kind slot to the
  TagID at runtime — so `catch (e) { e instanceof HttpError }`
  discriminates sibling subclasses correctly.
- ToString without a user `toString()` follows `Error.prototype.toString`:
  `"name: message"`, name alone when the message is empty.
- Extending an Error *subclass* is rejected with a clear message (one
  level deep for now — the flattened-field model needs no chain, but the
  kind-slot trick doesn't compose past one level without a hierarchy map).

**Stage-6 widening disposition**: TDD-00155's provisional "allocation-site
widening" analysis is **superseded, not built**. The need it targeted —
a literal flowing into a dynamic position becoming a bag at construction —
is covered at the language-mode level: under `-compat=js` every untyped /
bare object literal *is* allocation-site-widened (it compiles as a D1 bag
from the start), which is the analysis's practical form with perfect
precision at zero analysis cost. Under `strict`, widening stays rejected
by design: silently demoting a typed struct to a bag would surrender the
static representation the mode exists to guarantee, so a Tier-S value in
a dynamic position keeps its clean rejection.

**`Proxy`** (`runtime_dynobj.go`, `emit_reflect.go`): `new Proxy(target,
handler)` builds a 40-byte header carrying the PROXY flag (`1<<33`),
target at +8, handler at +16. The four runtime entry points — `get`,
checked `setv`, `has_chain`, `delete` — test the flag and dispatch to the
handler's trap (looked up by name through the ordinary bag `get`; invoked
through the Stage-4 dynamic-function ABI with `(target, key[, value])`),
forwarding to the target when the trap is absent. The C stringify walker
forwards proxies to their target (JSON.stringify semantics).

**`Reflect`** (`emit_reflect.go`): `get`/`set`/`has`/`deleteProperty`/
`ownKeys`/`getPrototypeOf`/`setPrototypeOf`/`isExtensible`/
`preventExtensions`/`defineProperty` map 1:1 onto the `__kml_dynobj_*`
runtime; the boolean-returning forms (`set`, `deleteProperty`,
`setPrototypeOf`) return the JS success flag instead of throwing.

**In passing**:

- `catch (e) { if (e instanceof HttpError) { e.status } }` — the guard
  flow-narrows the caught binding to the subclass type (the TDD-00114
  narrowing seam), so subclass fields/methods are readable in the branch.
- A ternary with a dynamic branch (`flag ? t[key] : "fallback"`) now
  types as `any` with both branches NaN-boxed, instead of the
  incompatible-branches rejection.
- `__kml_any_eq` regained the boxed-array identity arm the NaN-box
  rewrite (ADR-00628) had dropped: two boxings of one array malloc two
  headers, so `===` compares the data pointers *inside* the headers
  (ADR-00478 semantics) — `x1 === x2` on the same array boxed twice is
  true again.

## Consequences

- TDD-00155 is fully implemented; all seven stages shipped. The
  verification programs — subclass construction, throw/catch instanceof
  discrimination, name override, toString; proxy get/set/has/delete traps,
  trap-less forwarding, stringify-through-proxy; the Reflect surface —
  are diff-identical to Node. 10 new E2E tests.
- Disclosed: Error subclass chains deeper than one level; `e.stack`;
  `Error.captureStackTrace`; Proxy traps beyond
  get/set/has/deleteProperty (ownKeys/getOwnPropertyDescriptor/apply/
  construct traps absent — those operations forward to the target);
  `Reflect.apply`/`Reflect.construct`; Proxy over non-dynamic targets.
- Verified on the Mac (arm64).
