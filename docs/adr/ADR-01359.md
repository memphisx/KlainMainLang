# ADR-01359: ArrayBufferView, BufferSource and ArrayBufferLike resolve to their members

- **Relations**: Extends ADR-01352
- **Date**: 2026-10-03

## Context

`new Blob([bytes])`, written against a parameter typed `(string |
ArrayBuffer | ArrayBufferView | Blob)[]`, failed codegen with "value's type is
not a member of the declared union type". Found while porting Blob to
TypeScript.

## Investigation

- Codegen resolves a type name it does not model to `number` (`i64`).
  `ArrayBufferView`, `BufferSource` and `AllowSharedBufferSource` were among
  those names, so a typed array matched no member, and a parameter of one of
  these types held an `i64`.
- `ArrayBufferLike` is an ArrayBuffer or a SharedArrayBuffer, which share one
  representation.

## Decision

- `ArrayBufferLike` resolves to the ArrayBuffer type.
- `ArrayBufferView`, `BufferSource` and `AllowSharedBufferSource` resolve to
  `any`: each value is held boxed, as its own class.
- A union with a dynamic member accepts any value.

## Implementation notes

`codegen/llvm/types.go` (`ResolveTypeName`) and `emit_dynamic.go`
(`unionAllowsAssignmentFrom`).

## Verification

Mac (Apple Silicon), against Node 24: a typed array and a DataView in a union
array and as an `ArrayBufferView` parameter, and an ArrayBuffer and a
SharedArrayBuffer as an `ArrayBufferLike` (`TestE2EBufferSourceTypeNames`).
