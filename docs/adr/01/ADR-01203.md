# ADR-01203: Event, EventTarget and AbortSignal are a TypeScript global module

- **Relations**: `Implements TDD-00232`, `Supersedes ADR-00978`, `Supersedes ADR-00979`
- **Date**: 2026-09-28

## Context

TDD-00232 Stage 1. `class X extends EventTarget` was "extends unknown
class" in any program; `Event` exposed `type`/`defaultPrevented`/`detail`
only; `addEventListener`'s `capture`/`passive`/`signal` were ignored; the
code generation behind them (`emit_event.go`, `emit_eventtarget.go`,
`emit_abort.go`, about 1,000 lines, with an abort-timeout registry
threaded through the timer and event loops) matched none of Node's
`lib/internal/event_target.js` or `abort_controller.js`.

## Investigation

- A global needs no import, so the builtin-module route (TDD-00231) did
  not reach it. Binding an implicit import would have the checker type
  the global from the module's class, whose internal types need not match
  TypeScript's declaration (`CustomEvent<T>` generic, `EventListener |
  EventListenerObject` unions code generation cannot represent).
- The checker runs at the end of resolution; `sema.Prepare` runs after it
  and already decides every `new X` scope-aware.
- `setTimeout(...).unref()` already gives the abort timeout's
  "fires while the loop is alive, never keeps it alive".
- Fetch's native abort check runs where no TypeScript can (the await loop,
  the event loop's resume scan).

## Decision

- **Global modules.** A `lib/node/*.ts` file starting `// kml:global`
  implements the globals its exported classes name
  (`lib.GlobalModuleNames`). A file that mentions such a name without
  declaring or importing it at top level brings the module into the
  program; `Program.GlobalLinks` maps every class of an included global
  module to its renamed class. The checker types the globals from
  `lib/node.d.ts` as before; `sema` then rewrites each free reference
  (identifier, `new`, `extends`) to the linked class, and codegen's
  `resolveType` does the same for type names (type arguments erased).
- **`lib/node/kml_event_target.ts`**: `Event`, `CustomEvent`,
  `EventTarget`, `AbortSignal`, `AbortController` after Node's own
  (listener options, `handleEvent`, duplicate suppression, a listener's
  throw reported through `process.nextTick`, trusted `abort` events,
  `onabort` keeping its slot from its first assignment, `abort`/`timeout`/
  `any`, the illegal constructor). `timeout()` is an unref'd timer and
  records a `performance.now()` deadline.
- **Native view of a signal** (`emit_signal.go`): `__kml_signal_aborted`
  (the `#aborted` flag or an elapsed `#deadline`), `__kml_signal_reason`,
  `__kml_signal_timeout`, generated from the class's layout, stubs in a
  program without it. Fetch and `pipeTo` take the class instance.
- **Deleted**: the three emitter files, the abort-timeout registry and its
  hooks in the timer and event loops, the `Event`/`CustomEvent`/
  `EventTarget`/`AbortController` AST nodes and their `new` rewrites, the
  host types and their `Is*` flags, the `typeof` entries.

## Implementation notes

`lib/lib.go`, `resolver/resolver.go`, `sema/sema.go`, `ast/nodes.go`,
`codegen/llvm/emit_signal.go`, `emitter.go`, `emit_fetch.go`,
`emit_streams_pipe.go`, `runtime_fetch.go`, `emit_timers.go`,
`runtime_http.go`; the tests' in-process `parseStrict` resolves a program
that names a global-module global.

## Side effects discovered

- Boxing a `null` closure into `any` built a callable record; it is `null`
  now (`emitBoxValue`).
- A generic class's getters, defaults and `any` arguments (ADR-01202), a
  function boxed twice (ADR-01201) and generic inference through an
  optional generic interface parameter were found on the way.
- `TestE2EAbortSignalTimeoutBackgroundDispatch` expected `onabort` before
  an earlier-registered listener; Node runs them in registration order.
- A module-level `const` holding a `Symbol` is not visible inside a
  builtin module's class members, a class is not a first-class value
  (`const C: any = AbortSignal`), and a `function | object` union does not
  narrow (BACKLOG).

## Verification

Mac (Apple Silicon), against Node v24.19: a probe of listener options,
`handleEvent`, `once`, removal, `CustomEvent.detail`, `preventDefault`,
abort/`onabort` order, `AbortSignal.abort`/`any`/`timeout`, the illegal
constructor and `class Sub extends EventTarget` prints what Node prints;
the event, abort, fetch-abort, stream-pipe-abort and module-global tests
pass.
