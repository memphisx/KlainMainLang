# ADR-01622: globalThis reaches the globals of global modules; a Date element converts to its string

- **Relations**: Extends TDD-00232, ADR-01040
- **Date**: 2026-10-14

## Context

WPT's `.any.js` files reach the global object as `self` (the harness's
`self` is now `globalThis`, ADR-01623), so `self.performance.mark(…)` must
work. Checking it found that `globalThis.performance` did not.

## Investigation

- `typeof globalThis.performance` was `"number"`; `globalThis.performance.now`
  failed to compile (undefined variable). A global a global module implements
  (`perf_hooks.ts`'s `performance`) is linked by `sema`, which renames a free
  identifier to the module's binding (`walker.link`); `globalThis.performance`
  has no identifier `performance` to rename, and the emitter's rewrite of it
  to a fresh identifier produced one nothing linked.
- `globalThis` read as a value (`internal_namespaces.ts _kmlGlobalThis`)
  listed a fixed set of globals and none of the global modules'. Node's
  carries `performance` (enumerable) and the classes (`URL`, `Blob`,
  `PerformanceObserver`, …, not enumerable); `Worker`, `self`, `Histogram`,
  `IteratorHelper`, `ErrorEvent` and `EventSource` are no property of it.
- `String(ds[0])` and `` `${ds[0]}` `` for a `Date[]` element printed the
  pointer as a string or crashed: an element read is `Date | undefined`
  (ADR-01040), and `emitValueToString`'s Date path required a non-nullable
  Date.

## Decision

- `sema` rewrites `globalThis.x`, `x` a global module's global and
  `globalThis` not shadowed, to the module's binding (`globalThisLink`) —
  whatever a local `x` shadows, as the property is the global's.
- Reading `globalThis` as a value first defines the program's global-module
  globals on it (`_kmlGlobalThisLink`, once per name, with Node's
  enumerability); the modules are only in programs that name them.
- A nullable `Date` converts as a nullable object does: `"undefined"` or
  `"null"` when absent, the date's string otherwise.

## Implementation notes

`sema/sema.go`, `codegen/llvm/emit_exprs.go`, `emit_exprs_types.go`,
`lib/node/internal_namespaces.ts`; tests `TestE2EGlobalThisModuleGlobals`,
`TestE2EDateElementToString`.

## Side effects discovered

None.
