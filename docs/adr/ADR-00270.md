# ADR-00270: A Promise is a reusable value — `await`/combinators stop consuming the slot

- **Relations**: Implements [TDD-00090](../tdd/TDD-00090.md); refines [ADR-00249](ADR-00249.md), [ADR-00265](ADR-00265.md) (task-promise model), [ADR-00073](ADR-00073.md) (combinators); corrects the strict claim on the `await` row
- **Date**: 2026-08-20

## Context

`await` and the `Promise` combinators freed the promise slot after reading it, making a promise
single-consumption. A second read — `await p` twice, `await p` after `Promise.all([p])`, or the
same promise twice in one combinator — was a use-after-free (SIGTRAP, exit 133). In ECMAScript a
promise is an ordinary value, awaitable any number of times; reads are non-destructive and
settling is idempotent. This surfaced while auditing why Async/Promise strict coverage was stuck
at 4/9: the `await` row carried **no** caveat yet `await p; await p` crashed — the exact
"zero-caveat row that is secretly broken" trap the project's status-doc discipline warns about.

## Investigation

Repro confirmed all three crashes (exit 133). The free sites: `emitAwaitTaskPromise`
(`emit_async.go`, three sites — reject/void/value), the generic `emitAwait` non-task path
(void/value), and every combinator branch in `emit_promise.go` that loaded a member slot
(`emitTaskCombinatorAwaitEach:93`, the already-resolved `.all:399`/`.race:485`/`.any:590` paths,
both `.allSettled:735/753` paths). The `.race`/`.any` **task** paths already did not free the
winner (`emit_promise.go:468`/`577`) — proof the read is non-destructive and the free alone broke
reuse.

The companion caveat "`.race` may not return the shortest-delay member" was tested and found
**stale**: `__kml_timer_fire_next` (`emit_timers.go:169`) scans for the strictly earliest fire
time and sleeps until due, and `__kml_task_await_any_of` wakes the awaiter event-driven — a
`setTimeout`-raced set returns the shortest delay (verified with 2/3/5-member races in both array
orders, and `Promise.any` over timers).

Ownership options weighed (see TDD-00090): refcounting (large surface for a 40-byte value),
escape analysis (absent, conservative), or stop-freeing-and-leak (collected under `-mm=gc`).

## Decision

Stop freeing the promise slot at every `await` and combinator read site — value/void/task **and
fetch `Promise<Response>`**. A promise becomes an ordinary reusable heap value; the small slot
leaks in manual mode — the same ambient behavior every unreclaimed allocation has — and is
collected under `-mm=gc`. ASan's leak check is already off project-wide (`detect_leaks=0`),
consistent with this.

The fetch case needed no new representation: its pending struct is never freed, `__kml_await_fetch`
already short-circuits an already-done handle, and `__kml_pending_finish` is a non-destructive read
— so removing the slot free (at `await` and in `buildPendingMembersArr`) suffices, plus one
reorder: `__kml_await_fetch` checks *done* before the abort signal, so a re-await of a completed
fetch never re-enters the abort teardown on its already-cleaned easy handle (a second
`curl_easy_cleanup` would be a double free).

## Implementation notes

- `emit_async.go`: removed the three `free`s in `emitAwaitTaskPromise` (reject path frees before
  `__kml_throw` — removed too, since a caught rejection may be re-awaited) and the void/value
  `free`s in the generic `emitAwait`. Kept the `IsResponse` branch's free.
- `emit_promise.go`: removed the member-slot `free`s in `emitTaskCombinatorAwaitEach`, the
  already-resolved `.all`/`.race`/`.any` paths, both `.allSettled` paths, **and** the fetch
  `buildPendingMembersArr` outer-slot free. Left the combinator-internal frees (the group struct /
  members array are combinator-owned temporaries).
- `runtime_fetch.go`: `__kml_await_fetch`'s `checkloop` now loads the pending struct's done flag
  first and branches to `finish` before the abort-signal check (a new `chksignal` block does the
  per-spin abort check on a still-pending transfer). Behavior-identical for a first await; makes a
  re-await of a done fetch skip the abort teardown.
- `emit_async.go`: removed the `IsResponse` branch's slot free.
- A now-unused `@free` declaration where an internal temporary still frees is harmless.

## Side effects discovered

- The `await` row was **falsely strict** — this corrects that (the row now genuinely has no
  double-await bug). With both its caveats closed (member reuse for value/task **and** fetch, plus
  the removed stale `.race` timer-ordering caveat), the `Promise.all`/`.race`/`.allSettled` row
  becomes strict — Async/Promise strict moves **4/9 → 5/9** (the LANGUAGE-CONSTRUCTS.md page header
  was also stale at `7/7`, `1/7`; corrected to `9/9`, `5/9`).
- Manual-mode long-running programs leak one small slot per awaited promise — noted in TDD-00090
  as acceptable for the target and reclaimable by a future pool/refcount without semantic change.
