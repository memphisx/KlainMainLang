# ADR-01889: a shape-record body's return inference out of the shadow report

- **Relations**: `Implements TDD-00230` (P3.3: the shadow report)
- **Date**: 2026-10-21

## Context

- A JavaScript class's method is also compiled for any receiver (its shape record), where `this` is a box and a field read a dynamic one; emission never asks the checker there, so the shadow comparison of expressions skips such a body. The comparison of return inference did not: every method returning a field read in a JavaScript class was a row, the box against the checker's field type.

## Decision

- The return-inference comparison skips a shape-record body, as the expression comparison does.

## Consequences

- Those rows leave the report; emission is unchanged.
- Verified on Apple Silicon.
