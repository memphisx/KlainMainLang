# ADR-01884: a callback parameter of an erased generic method

- **Relations**: `Implements TDD-00230` (P3.3: the shadow report's Identifier bucket)
- **Date**: 2026-10-21

## Context

- A program class's generic method is erased: its type parameters are boxes, and an arrow passed to it binds its unannotated parameters with the erased signature's types (`this.call<T>(s, (fd, done) => …)` gives `done` `(err: any, value: any) => void`). The representation oracle typed the parameter from the checker's instantiated signature, `T` the call's type argument.

## Decision

- The oracle answers such a parameter with the erased signature's hint, through a hook (erasedCallbackParam) that reads the method's codegen signature.

## Consequences

- The internal_fs row every program loading `fs` carried leaves the shadow report.
- Verified on Apple Silicon.
