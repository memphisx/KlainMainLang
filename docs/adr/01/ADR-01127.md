# ADR-01127: Operators on `any` compile in the strict lane

- **Relations**: `Implements TDD-00230` (Phase 2, P2.7); `Extends ADR-01123`, `ADR-01126`
- **Date**: 2026-09-25

## Context

P2.7 requires that a program the checker accepts compiles. tsc accepts
every arithmetic, bitwise, unary and compound-assignment operator on an
`any` operand. The strict lane rejected all of them in codegen with
"operator '…' on any/unknown is not yet supported". Only `-compat=js`
dispatched them at run time (TDD-00076 A2).

This came up when [ADR-01126](ADR-01126.md) rewrote the example
`+null` (TS18050) as `+nothing` with `nothing: any`: the strict lane
refused the valid program.

## Investigation

- **The runtime path exists and is lane-independent.** `emitAnyBinary`,
  `emitAnyToNum` and the unary `+` ToNumber ladder work on the NaN-boxed
  word the same way whichever lane compiles them. The strict guards were
  left over from the typed-subset lane that ADR-01123 replaced.
- **The rejection existed so `unknown` would not compile.** The checker now
  reports an `unknown` operand of those operators as TS18046/TS2571
  (ADR-01126). tsc rejects mixed concrete operands (`n * "4"`, TS2362/2363)
  and nullish ones (`null + 1`, TS18050), so their codegen gates stay.

## Decision

- **For an `any` operand, the strict lane now does what `-compat=js`
  does:**
  - binary operators go through `emitAnyBinary`;
  - compound assignment goes through the same dispatch;
  - unary `-` and `~` run ToNumber;
  - unary `+` runs the ToNumber ladder;
  - `inferExprType` types an arithmetic result on an unconstrained dynamic
    operand as `any`.
- **The gates on mixed concrete and nullish operands remain,** because tsc
  rejects those programs. They are clean rejections the checker reports
  first, and P2.7 deletes them once the checker's codes cover every case.

## Implementation notes

- `codegen/llvm/emit_exprs_operators.go`: the binary default arm, unary
  `-`, unary `~`, and `emitUnaryPlus`.
- `codegen/llvm/emit_exprs_assign.go`: compound assignment.
- `codegen/llvm/emit_exprs_types.go`: result typing.

## Side effects discovered

None.

## Verification

- **A strict-lane program covering the new paths** prints the same output
  as Node. It exercises `+`, `-`, `~`, arithmetic between `any` values,
  `**`, `%`, `<`, and compound `+=`/`-=`/`*=`/`**=` on numbers and on a
  string, and checks `typeof` of an `any - 1` result.
- **`examples/basics/var_hoisting.ts`** prints the same output as Node.
