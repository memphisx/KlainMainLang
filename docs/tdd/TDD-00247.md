# TDD-00247: Classes extending builtin host classes

- **Status**: Implemented
- **Date**: 2026-10-06

## Context

[TDD-00230](TDD-00230.md) P3.2 says `@lowerType` layouts support single
inheritance: a derived layout begins with its base's, so user classes extend
host classes. Error works ([ADR-01423](../adr/ADR-01423.md)): its object is a
fixed struct whose word 0 is a type id, and an Error subclass's instance is
that struct with the class's fields after it. Every other host class fails:

| Base | Today |
|---|---|
| `Map<K, V>` | parse error: the extends clause takes one type argument |
| `Set<T>` | "a generic class base is not supported yet" |
| `Uint8Array` (each typed array), `Date`, `RegExp` | "extends unknown class" |
| `Promise<T>` | a generic class cannot use `extends` |
| `Array<T>` | rejected by the checker path |

In Node an instance of `class M extends Map` is a Map: Map's methods run on
it, `m instanceof Map` holds, a function typed `(x: Map<K, V>)` takes it and
`x instanceof M` still holds there, and `===` compares one object.

## Design

### What the host values are now

- Map and Set: a pointer to a 72-byte `kml_map` header whose word 0 is the
  size; keys, values and index are separate allocations.
- WeakMap and WeakSet: a pointer to an 8-byte list head.
- Promise: a pointer to a 56-byte task struct whose word 0 is the state.
- RegExp: a headerless struct whose word 0 is the PCRE handle.
- Date: an `i64` timestamp, not a heap object; setters need a named variable.
- Arrays and typed arrays: a `{data, len}` header without a type id.
- Boxed into `any`, Map/Set/Date/RegExp/ArrayBuffer get a fresh 16-byte cell
  `{header, handle}` per box, so identity through `any` is the handle's.

### Option A: a hidden base slot (rejected)

The instance holds the host value in a field (`__kml_base`); a host method
called on the instance loads the slot. It works for every base without
touching the runtime, but passing the instance where the base is expected
passes the slot's value: the callee holds a different object, so
`x instanceof M`, `x === m` and the subclass's overrides of a Map method are
lost there. That is a divergence native compilation does not force, so the
faithfulness rule excludes it.

### Option B: the host object is the instance (chosen)

The instance is the host object, with the class's header and fields
appended, as Error's is. That needs, for each host layout:

1. **A header word before the host body.** The type id names the object's
   class: the host class, or the user subclass whose parent row reaches it.
   This is [TDD-00230](TDD-00230.md) Phase 5's uniform header, applied to
   Map, Set, WeakMap, WeakSet, Promise and RegExp first. The header sits at
   `body - 8` and a host value keeps pointing at its body, as a string
   points past its length: the body's offsets, which generated code reads at
   about 120 sites, do not move. A subclass instance's pointer is its header
   (the class's tag word, as for any class), its host body follows at `+8`,
   and its own fields after the body; a host method on it takes `this + 8`.
   A host value boxes as its header pointer, so identity holds through
   `any`, and every free goes through `body - 8`.
2. **Allocation with room for the subclass.** The runtime's `create`
   functions take a total size (`__kml_map_create(size)`); `new M()` passes
   the class's size, and the class's fields follow the host struct.
3. **Dispatch.** A host method's receiver check (`intrinsicApplies`,
   `resolveMapOrSetForCall`, the Date and RegExp gates) accepts a class
   whose layout chain reaches the host layout, with the base's key and
   value types from the extends clause's type arguments. An override in the
   class wins, through the vtable as for any method.
4. **`instanceof` and `any`.** The host's type id is a parent row of the
   subclass's (`__kml_class_is`), and a header-carrying host object boxes as
   itself, without the per-box cell, so identity through `any` holds.
5. **Date and the arrays.** Date becomes a heap object with a header and
   the time (Node's Date is an object; the value representation is what
   made setters need a variable). Arrays and typed arrays gain a header
   word in their `{data, len}` header (Phase 5 adds capacity there too). Both
   are larger changes, staged after the pointer-shaped hosts.

The parser's extends clause takes a full type-argument list
(`extends Map<string, number>`), and the checker types the class against
the base interface (TypeScript's own rule for extending a builtin).

### Stages

1. Extends-clause type arguments (parser, checker, `BaseTypeArgs` a list).
2. The header word on Map/Set/WeakMap/WeakSet; sized creation; dispatch,
   `instanceof`, boxing; `extends Map`/`Set`/`WeakMap`/`WeakSet`.
3. Promise and RegExp the same way.
4. Date as a headered heap object; `extends Date`.
5. The array header's type word; `extends Array` and the typed arrays.
