# ADR-00685: `JSON.stringify` of a non-finite number serializes as `null`

- **Date**: 2026-09-03

## Context

`JSON.stringify(1/0)` produced the literal text `Infinity` (and `NaN` for `0/0`)
— invalid JSON. Real JS serializes any non-finite number (`NaN`/`±Infinity`) as
`null`. Found in the faithfulness audit; the dynamic-`any` serialization path
already folded non-finite→`null`, but the statically-float-typed path did not.

## Decision

In `emitJSONStringifyValue`'s float branch (`emit_call_json.go`), guard
finiteness before `%g` formatting: `x - x == 0` is true only for a finite `x`
(`Inf - Inf` and `NaN - NaN` are both `NaN`), so a non-finite value emits the
interned `null` token instead. Reaches every float position — a bare number, a
`number[]` element, and a float object field — since all recurse through this
branch.

## Verification

Mac. `JSON.stringify(1/0)`/`(-1/0)`/`(0/0)` → `null`; `JSON.stringify(3.14)` →
`3.14` (finite unchanged); `[1, 1/0, 0/0, 2]` → `[1,null,null,2]`;
`{a: 1/0, b: 5}` → `{"a":null,"b":5}`. E2E test; JSON regression green.
