# ADR-00601: Named function expression shadowing a top-level function

- **Relations**: Extends [ADR-00178](ADR-00178.md) (named function expression self-capture), supersedes its shadowing rejection
- **Date**: 2026-09-01

## Context

A named function expression binds its own name inside its own body for
self-reference (ADR-00178), implemented via a synthetic self-capture whose env
cell holds the closure's own header. But when the name **shadowed a top-level
function of the same name** —

```ts
function fac(n) { return 0; }
const g = function fac(n) { return n <= 1 ? 1 : n * fac(n - 1); };
```

— the compiler rejected the collision cleanly (TDD-00060). The cause: the
resolver's rename pass (TDD-00041) rewrote the body's `fac` to the outer
function's mangled name *before* codegen saw the expression's name scope, so the
self-capture couldn't reclaim it and the recursion would have called the outer
function. Rejecting was safer than miscompiling, but the form is legal JS: inside
`g`'s body, `fac` is `g`.

## Decision

Fix it in the resolver rather than reject. In the `*ast.FunctionExpression` case
of the rename pass, bind the expression's own name in its freshly-pushed scope
**before** rewriting the body. `scope.bound` then short-circuits the rename for
that identifier, so the body's self-references stay unmangled (`fac`, not
`fac__kml_mod<N>`). Codegen's existing self-capture (`CapturedVar{IsSelf}`) fires
on the unmangled `refs[fe.Name]` exactly as it does for the non-shadowing case —
no codegen change beyond deleting the now-unreachable rejection.

Outer-scope calls to the name are unaffected: they resolve outside the
expression's scope frame and still reach the top-level function.

## Verification

`TestE2ENamedFunctionExpressionShadowingTopLevel` (resolver-backed harness, since
the shielding lives in the rename pass): `g(5)` → `120` (self-recursion),
`fac(5)` → `0` (the outer function), matching Node v26. The existing
non-shadowing recursion / capture / name-not-leaked tests still pass. Built and
verified on Mac (Apple Silicon).
