# ADR-00435: `const { subtle } = globalThis.crypto` binding

- **Relations**: Extends [ADR-00434](ADR-00434.md), TDD-00104's subtle dispatch
- **Date**: 2026-08-28

## Context

The corpus's standard WebCrypto preamble — `const { subtle } =
globalThis.crypto;` — hit the generic object-destructuring rejection
(part of a 26-file cluster): `subtle` is a compile-time pseudo-namespace,
not a bindable value.

## Decision

The exact single-key `{ subtle }` pattern over `crypto` /
`globalThis.crypto` registers the local name as a subtle alias
(consulted by `isCryptoSubtle`, guarded against real shadowing bindings)
and emits nothing. A Pass-1.8 pre-scan registers top-level aliases
before Pass 2 emits function bodies (which otherwise dispatch before the
statement is reached). `globalThis.crypto.subtle.<method>` chains
dispatch directly too.

## Implementation notes

`emit_objects.go` (`cryptoGlobalExpr`, the destructuring special case,
`registerCryptoSubtleAliases`), `emit_call_crypto.go` (`isCryptoSubtle`),
`emitter.go` (Pass 1.8 + alias map).

## Side effects discovered

None.

## Verification

`TestE2ECryptoSubtleDestructuredAlias` (alias used inside an async
function + the chained globalThis form, SHA-256 digested); webcrypto +
object-destructuring suites green (Mac).
