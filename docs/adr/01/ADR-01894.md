# ADR-01894: object spreads of primitives, falsy unions and absent sources; a redeclared `var` read

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets; the strict lane rejects what tsc rejects)
- **Date**: 2026-10-21

## Context

- tsc rejects an object-literal spread whose operand, once its definitely falsy members are removed, is not any, an object or a type parameter (TS2698, `{ ...n }` for a number, `{ ...null }`), and types the literal as its error type, any. The checker left such a literal unanswered and the strict lane accepted it. As JavaScript the spread is valid (a string spreads its indices, any other primitive nothing), but codegen refused a primitive operand outright.
- tsc spreads `false | { j: number }` (or `0 | ""` beside an object, `{ j } | undefined`) as the object with its properties optional; the checker left every such literal unanswered, and codegen refused the boxed operand. An absent source (`{ x: 1, ...undefined-valued b }`) left the source's keys present with zero values (`{"x":1,"j":0}`).
- `JSON.stringify` of a number or boolean slot holding undefined returned `"null"` rather than the value undefined.
- A `var` declared twice (`var iter = gen(); var iter = gen();`) is one global both initializers store; the oracle answered a read of it only for a single declaration, so a generator instance it holds, which the checker's type does not map, went unanswered.

## Decision

- The checker types such a literal any and the strict lane reports TS2698 at the spread, with tsc's falsy-removal rule.
- Codegen spreads a primitive through its box, as it already spreads an array or a function.
- A falsy-union operand is spread as its object's layout, or nothing where the box holds a falsy primitive; the literal takes the checker's type. An absent source marks the keys it would have copied absent, unless the literal wrote them before.
- `JSON.stringify` serializes such a scalar through its box, which keeps undefined and null apart.
- The oracle reads a redeclared `var` whose declarations are all initialized, unannotated and its only stores, held alike, as that held type.

## Consequences

- Matches tsc 5.6.3 diagnostics and positions, and Node's output, on Apple Silicon.
