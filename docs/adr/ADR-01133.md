# ADR-01133: The checker reads interfaces from their members; polymorphic `this`; aliased conditions and other tsc narrowings

- **Relations**: `Implements TDD-00230` (Phase 2, P2.4, P2.5); `Extends ADR-01126`, `ADR-01128`, `ADR-01132`
- **Date**: 2026-09-25

## Context

With [ADR-01132](ADR-01132.md), 521 more TypeScript corpus cases parse. On
them the checker's already-reported codes gave 56 false positives, each one
a gap in what the checker models. All of them trace to TypeScript features
the corpus exercises:
- the older interface shape lacks optional methods and accessor pairs;
- the polymorphic `this` type, and `this is T` guards on methods;
- aliased conditions (TypeScript 4.4);
- calls to functions declared `never`;
- namespace members;
- readonly property paths.

## Investigation

Each gap was checked against tsc 5.6.3's source and behaviour.

- **Accessors.**
  - Divergent get/set types: a read has the getter's type and a write takes
    the setter's (`divergentAccessors1.ts`).
  - Assignment narrowing reduces only a union declared type
    (`getAssignmentReducedType`); every other type reads as declared.
- **Polymorphic `this`** is instantiated with the receiver at each member
  access. Binding it to the declaring type would give a subclass's chained
  call the base type (`fluentInterfaces.ts`).
- **`this is T` / `asserts this is T`** narrow the method call's receiver;
  `this` itself narrows too.
- **Never-returning calls.** A call statement through a dotted name, to a
  function whose declared return type is `never`, ends the flow
  (`getEffectsSignature`). A function declaration must annotate it.
- **Aliased conditions** (`narrowType`, `isConstantReference`).
  - A condition that is an unannotated `const` with an initializer narrows
    as that initializer, at most 5 levels deep.
  - This applies only when the narrowed reference is constant: a `const`, a
    parameter or local `let` never assigned, or a path of `readonly`
    properties from one.
- **A class cycle.** A class whose base is still being typed, because a
  member's type named the derived class, copied the base's incomplete
  member list. It then lacked inherited methods for good
  (`typeGuardFunctionOfFormThis.ts`'s `MimicFollower`).
- **Contextual return-type inference.** A generic call in a contextual
  position can keep a literal argument's type through inference from the
  context, as `const b: Box<'a' | 'b'> = box('a')` does. The checker does
  not model that.

## Decision

- **`interfaceOf` reads `Members` and `Heritage`:**
  - property signatures, with accessor pairs made into one read/write
    property;
  - method signatures (`signatureOfNodes`: their own type parameters,
    unannotated parameters as `any`, predicates, overloads merged);
  - optional methods as `| missing`.
  - An index, call or construct signature, or a generic or qualified base,
    leaves the interface unanswered, as before.
  - A computed member name marks the type `partial`: its member list is not
    whole, so it is excluded from TS2339 and the missing-property codes
    (`nominalOpen`).
- **Type literals** merge accessor pairs, and the interner keys accessor
  write types and `readonly`.
- **`c.thisT`**, one type parameter, is `this` while a class or interface is
  typed. `withThis` instantiates it with the receiver at every member
  access.
- **A `this` predicate** has index -1, and `predicateSubject` finds the
  call's receiver. `this` is a narrowable reference. `super.m(…)` is typed
  through the base instance, and the binder records flow for it as a dotted
  call.
- **`neverReturning`** makes a flow call node unreachable.
- **Namespaces.** The binder records each namespace's scope
  (`NamespaceScope`). `ns.member` is typed as the member's symbol, and it is
  not property-checked as an object.
- **Aliased conditions** (`aliasedCondition`, `constantRef`). `Property`
  gains `Readonly`, set from type literals, interfaces, class fields and
  constructor parameter properties.
- **Cycles.** A type built on a base that is itself still being built is
  `partial`.
- **A generic call** with a literal, object-literal or array-literal
  argument, in a contextual position, is unanswered.

## Implementation notes

- `checker/symbols.go`: `interfaceOf`, `signatureOfNodes`, `predicate`,
  type literals, `readonly`.
- `checker/narrow.go`: `neverReturning`, `namespaceMember`,
  `calleeSymbol`, `predicateSubject`, `aliasedCondition`, `constantRef`,
  and `super` in `dottedType`.
- `checker/checker.go`: `withThis`, narrowing `this`, and the member access
  of a namespace.
- `binder/binder.go`: `nsScopes`, and `super` in `dottedName`.

## Side effects discovered

- **TS2454 is not reported yet** (a read of an evolving variable that some
  path leaves unassigned). Such a read is skipped, as
  [ADR-01126](ADR-01126.md) recorded.

## Verification

- **`tools/tsdiag`:** 1,360 reports over 6,576 cases, of which 1,358 match
  tsc's baselines; the two misses are the known Annex B cases. The
  project's own programs report 0.
- **Checker unit tests** pass, including `TestTypeOfWholeCorpus`'s
  memoisation check.
