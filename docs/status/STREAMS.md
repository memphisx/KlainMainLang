# Streams API

> Part of the [Implementation Status](README.md) index. `ReadableStream`, `WritableStream`, and `TransformStream` are the WHATWG (browser-standard) backbone of pipeline-style data processing. Node has its own, older, differently-shaped `stream` module — see the Node rows below — that real Node code (including `fs`/`http`/`child_process` internally) actually uses far more than the WHATWG API.

**Coverage**: 7/8 (88%) · **Strict Coverage**: 0/8 (0%).

This page follows the shared status-page format ([Status page format](README.md#status-page-format)): **Status** is a bare ✅/❌; **Caveats** lists behavioral divergences from real JS/TS (a non-empty Caveats cell is what excludes an otherwise-✅ row from Strict Coverage); **Notes** carries implementation/representation detail only. One table per index category; each category's figures above derive from its table below.

WHATWG streams are scoped and staged in [TDD-00097](../tdd/TDD-00097.md); Stages 1–3 shipped: the `ReadableStream` core with the full queue/high-water-mark/pull backpressure machinery ([ADR-00296](../adr/ADR-00296.md)), `WritableStream` with serialized sink writes and `ready` backpressure ([ADR-00297](../adr/ADR-00297.md)), and the reaction-driven pipeline — `pipeTo` with all four shutdown-propagation rules + `prevent*` + `AbortSignal`, `TransformStream<I, O>` with backpressure coupling, `pipeThrough`, `tee()` ([ADR-00298](../adr/ADR-00298.md)). The whole pipeline runs on the promise/microtask runtime alone — no fibers or libcurl for in-memory pipelines. fetch `Response.body` streaming shipped as Stage 4 ([ADR-00299](../adr/ADR-00299.md)): `await fetch` resolves at headers and the body streams as `Uint8Array` chunks with curl pause/unpause backpressure (tracked on [NETWORKING.md](NETWORKING.md)'s Response row). Stage 5's response side shipped too ([ADR-00300](../adr/ADR-00300.md)): a handler `body` that is a `ReadableStream` produces a chunked response, written reaction-driven chunk-at-a-time (tracked on [HTTP-SERVER.md](HTTP-SERVER.md)); Stage 5b shipped as well ([ADR-00301](../adr/ADR-00301.md)): `req.stream()` streams request bodies with headers-complete dispatch, lifting the 10 MiB request cap (tracked on [HTTP-SERVER.md](HTTP-SERVER.md)). Node's own `stream` module (Stage 8, [ADR-00304](../adr/ADR-00304.md)) ships as options-form `Readable`/`Writable`/`Transform` wrappers over the WHATWG internals, with the `'data'`/`'end'`/`'error'`/`'finish'` event surface, `.pipe()`, the `stream/promises` `pipeline`/`finished`, and web-stream bridges.
