# ADR-01251: The `object` type is a boxed value

- **Date**: 2026-09-29

## Context

`child.send({ hello: 'world' })` failed to compile ("argument's type is not
a member of parameter 1's declared union type"): `Serializable` is
`string | object | number | boolean | bigint`, and codegen resolved the
`object` keyword to no type at all (an `i64`), so no object matched it. A
bare `function g(x: object)` was rejected the same way.

## Decision

`object` resolves to the NaN-boxed `any`, as `unknown` does: it holds any
non-primitive, and `typeof`, `JSON.stringify` and console.log read its
box. A union with a member that is itself unconstrained (`object`, `any`,
`unknown`) is that box too.

## Verification

Mac (Apple Silicon): `TestE2EObjectKeywordType`, where object literals,
arrays and class instances pass through `object` and `string | object |
number`, matching Node's output; the fork IPC probe sends an object.
