# ADR-00993: posix path.join preserves trailing slash, skips empty segments

- **Date**: 2026-09-17

## Context

`path.join` (posix flavour) dropped a trailing separator that the last segment
carried — `path.join('foo', 'bar/')` returned `'foo/bar'` where Node returns
`'foo/bar/'` — a documented caveat. Investigating it surfaced two further,
undocumented divergences from Node in the same code path:

- `path.join('a/', '')` returned `'a'` (Node: `'a/'`).
- `path.join('foo/')` (single arg) returned `'foo'` (Node: `'foo/'`).

Node's `path.join` skips empty segments entirely, joins the rest with a single
`/`, then normalizes — and Node's `normalize` preserves a trailing slash. The
compiler's join built its raw string by concatenating *all* segments with `/`
(so an empty trailing arg manufactured a `foo/`) and then ran the IR normalizer
`__kml_path_normalize`, which strips the trailing slash.

## Investigation

- `codegen/llvm/emit_path.go:emitPathJoin` concatenated every arg with `/` and
  called `__kml_path_normalize(raw, isAbs)`.
- The same raw string must yield different results by origin — `join('foo/')`
  is `'foo/'` but `join('foo','')` is `'foo'` — so trailing preservation cannot
  live in `normalize` alone; empty segments must be skipped at raw-build time.
- `path.normalize` already routes through a C sidecar `__kml_path_posix_normalize`
  (path_win32.go) that preserves the trailing slash and matches Node on all
  tested inputs (`'a/../'`→`'./'`, `'/a/../'`→`'/'`, `''`→`'.'`, …). Reusing it
  gives join the correct normalize for free; `path.resolve` keeps the
  trailing-stripping IR `__kml_path_normalize` (Node's resolve strips).

## Decision

Rewrite the posix branch of `emitPathJoin` to: build an array of the segment
pointers, call a new runtime helper `__kml_path_join_segs(arr, n)` that skips
empty segments and joins the rest with a single `/` (empty result when none),
then normalize the raw string through `__kml_path_posix_normalize`. No separate
`is_absolute` flag is needed — the sidecar detects absoluteness from the string.

## Implementation notes

- `runtime_path.go`: new `ensurePathJoinSegs` emitting `__kml_path_join_segs`, a
  two-pass (measure, then fill) builder over a `ptr` array that allocates exactly
  the joined length via `__kml_str_alloc` (which sets the string's i64 length
  header).
- `emitter.go`: `usedPathJoinSegs` guard flag.
- `emit_path.go`: posix join now emits an `alloca ptr, i64 N` array, stores each
  coerced segment, and calls the helper + sidecar normalize. The win32 branch is
  unchanged.

## Side effects discovered

Two undocumented trailing-slash bugs (`join('a/','')`, `join('foo/')`), both
fixed by the same change.

## Verification

- New E2E `TestE2EPathJoinTrailingSlash`; existing `TestE2EPathJoin` /
  `TestE2EPathResolve` still pass. 14-case differential against `node`'s
  `path.posix.join` — all match.
- `make examples` (331 passed); `make status`/`status-check`/`reference-check`
  clean.
