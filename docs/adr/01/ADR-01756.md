# ADR-01756: A computed key into a class instance

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

`c[k]` on a class instance, with `k` a `keyof C` in TypeScript or any string under `-compat=js`, failed to compile ("'c' is not an array"): the index emission treated every non-literal key into a non-dynamic receiver as an array element. Only a string literal key worked, rewritten to the member it names.

Under `-compat=js`, `typeof c.__lookupGetter__` printed `number`. A read of an instance property that is no field, method or accessor is emitted as a dynamic read, a box, but codegen's inference gave it the `i64` default, so a binding of it was a number. The front end's shadow report had the same rows.

## Decision

- A non-literal string or boxed key into an instance of a class with no host base (`classDynIndex`) boxes the instance and reads or writes the property by name, compound assignment included. Inference gives the read the checker's primitive, else the box.
- Inference gives an instance's other properties the box their dynamic read gives.

## Consequences

- `TestE2EClassInstanceComputedKey` and `TestE2ECompatJSClassInstanceComputedKey` cover the reads and writes.
- `typeof c.__lookupGetter__` now prints `undefined`, still not Node's `function`: `Object.prototype`'s members read as values are a backlog item.
