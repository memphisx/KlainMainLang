# ADR-01094: Null-prototype objects, `Object.prototype`, and static integrity levels

- **Relations**: `Implements TDD-00229`
- **Date**: 2026-09-23

## Context

`node:ffi`'s accumulator objects are null-prototype objects, and probing that
surface showed the core could not express one:

- A dynamic-object bag's `proto` slot is null both for `Object.create(null)`
  and for an ordinary `{}` (whose `Object.prototype` link is not modeled), so
  nothing could render `[Object: null prototype]`, and
  `Object.getPrototypeOf({}) === null` was `true` (Node: `false`).
- `Object.prototype` did not compile ("undefined variable 'Object'").
- On the static-struct path `{ __proto__: null, a: 1 }` became a field
  literally named `__proto__`.
- `Object.isFrozen/isSealed/isExtensible/preventExtensions` had no arm for a
  static object; `Object.seal` was a no-op that recorded nothing, so a sealed
  object could never report `isSealed`.

## Investigation

Node's renderings, by probe: `[Object: null prototype] {}` (empty, even past
the depth cap), `[Object: null prototype] { x: 1 }`, `[Object: null
prototype]` for a non-empty one past depth 2, `{ ['__proto__']: 5 }` for an own
`__proto__` key (JSON.parse, computed key). Node's single-line rule counts the
full opening brace (`[Object: null prototype] {`, 26 columns) toward the
80-column budget — a prefix printed outside the layout helper broke lines
differently from Node.

## Decision

- **NULLPROTO flag**: bit 34 of the dynamic-object header word (next to
  non-extensible bit 32 and Proxy bit 33). `__kml_dynobj_set_proto` sets it when
  the new prototype is null and clears it otherwise, so every existing
  prototype write — `Object.create(null)` (which now calls it),
  `Object.setPrototypeOf`, the `__proto__` literal/setter — gets it for free.
- **`Object.prototype`**: a lazily created singleton bag whose own prototype is
  null (`__kml_object_prototype`). `__kml_dynobj_get_proto` answers it for a
  bag whose slot is null and which is neither NULLPROTO nor a Proxy; the
  `Object.prototype` expression yields the same singleton. Monkey-patching it is
  not linked into property lookup (ordinary bags still carry a null slot).
- **Rendering**: `inspect_obj` passes `[Object: null prototype] {` as the
  opening brace to `__kml_inspect_end`, so the width rule counts it; an own
  `__proto__` key prints as `['__proto__']`. The static inspector takes the same
  prefix from a new compile-time `Type.IsNullProtoObject` flag (used for
  runtime-built objects whose shape is static — node:ffi's `getFunctions(defs)`).
- **`__proto__` literals**: a non-computed `__proto__` key routes the literal to
  the dynamic-object literal path, which already implements the setter form
  (`hasProtoKey`, both in `emitObjectLiteralWithHint` and `inferObjectType`).
- **Integrity levels**: the per-thread frozen set now stores a level per object
  pointer (1 frozen, 2 sealed, 3 non-extensible); `Object.seal` /
  `preventExtensions` record theirs, the write guard fires only on level 1, and
  `isFrozen/isSealed/isExtensible` answer from the level — including JS's rule
  that a non-extensible object with no own properties is also sealed and frozen.

## Implementation notes

`runtime_dynobj.go` (flag, `get_proto`, singleton), `emit_dynobj.go`
(`Object.create(null)`), `dynjsonsrc/dynjson.c` (`inspect_obj`),
`emit_inspect.go`, `emit_objects.go` (`emitStaticIntegrity*`,
`emitFrozenCheck` compares the level), `emit_call.go` (static arms),
`emit_exprs_types.go` (`preventExtensions` returns its argument's type).

## Side effects discovered

`Object.getPrototypeOf` of a boxed primitive still answers null (no primitive
prototype objects) — unchanged, already disclosed.

## Verification

`tests/null_prototype_test.go` (`TestE2ENullPrototypeObjects`,
`TestE2EObjectPrototypeIdentity`, `TestE2EStaticObjectIntegrityLevels`) against
Node 24.19.0; full `make test-par` on macOS/arm64 (M4).
