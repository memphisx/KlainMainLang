# ADR-01371: Annex B block functions under -compat=js; an evolving binding keeps its any-box

- **Relations**: Extends TDD-00022's `-compat=js` lane and TDD-00162
- **Date**: 2026-10-03

## Context

Backlog 61. Under `-compat=js`, `{ function f() {} }` followed by `f()`
outside the block failed: "undefined function or closure 'f'". Annex B.3.3
binds a `var f` in the enclosing function, undefined until the block runs.

Fixing it surfaced a second bug. Inside a function body, `let x = null;
x = function () {}; x()` failed the same way, while the same code at top
level compiled.

## Investigation

- The binder already models Annex B (`AnnexB: compatJS`); codegen does not.
- **Evolving binding.** `crossTypeWidenedBindings` marks an untyped binding
  initialized with `null`/`undefined` and later assigned as an any-box, and
  `emitVarDecl` set its type to `any`. The inference from the initializer
  ran after that and reset the type to `null`. Top-level bindings take
  `decideGlobalType`, which has no such step, so only function bodies were
  affected, in both lanes.

## Decision

1. **`resolver/annexb.go`**, before binding, under `-compat=js`:
   - Each plain function declared in a block (not async, not a generator,
     not generic) becomes `name = function name(…) {…}` at the start of its
     block, and `var name = undefined` is hoisted to the enclosing function
     or program body.
   - A name a parameter, a `let`/`const`/class of the enclosing body, or an
     enclosing block's lexical declaration already binds keeps the
     block-scoped function, as the spec leaves it.
   - Blocks of `if`, the loops, `try`/`catch`/`finally`, labeled statements
     and `switch` cases are covered; nested functions are handled each in
     their own scope.
2. **`emitVarDecl`** skips the initializer's type inference for a widened
   binding.

## Implementation notes

`resolver/annexb.go`, `resolver/resolver.go` and
`codegen/llvm/emit_exprs_vardecl.go`.

## Verification

Mac (Apple Silicon), against Node 24: block, `if`, `for` and `switch`
functions, `typeof` before and after, and an evolving `null` binding called
inside a function (`TestE2ECompatJSAnnexBBlockFunctions`); the widening,
null, compat-js and hoisting groups.
