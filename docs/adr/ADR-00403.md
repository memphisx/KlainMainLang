# ADR-00403: Specific "no method" diagnostic instead of the "only simple function calls" catch-all

- **Relations**: Extends TDD-00072 (diagnostics), TDD-00121 (conformance leverage map)
- **Date**: 2026-08-27

## Context

`only simple function calls are supported` was the largest Node-oracle failure
bucket (335 files), but it was a **misleading catch-all**: it fired not just for
genuinely dynamic callees (IIFEs, computed calls) but for any *method call whose
receiver type doesn't have that method* — `buf.swap16()`, `cluster.worker.send()`,
`http.get()`, `Object.setPrototypeOf()`. Lumping all of these under one message
hid the real gaps and made the leverage map useless for that 335.

## Decision

When the call fallback is reached and the callee is a `MemberExpression`, emit
`<receiver> has no method '<name>'` instead of the generic message:

- `describeReceiverType` gives a short phrase for the common builtin/receiver
  types (Buffer, TypedArray, array, Map, a Node stream, a net.Server, class 'X',
  a string, an object, …).
- A bare namespace/global identifier receiver (`Object`/`process`/`Math`/… and
  the `*__kml_builtin` module identifiers, unless locally shadowed) is named
  explicitly, since such a receiver otherwise infers as the numeric default.

The generic message is kept only for a genuinely non-member callee.

## Consequences

The 335 catch-all split into an **honest, actionable histogram**: `http has no
method` (117 — the missing Node **HTTP client** `http.get`/`http.request`, the
single largest real lever and squarely the project's #1 REST-client priority),
`a number has no method` (131 — genuinely unmodeled member-chain receivers like
`cluster.worker.send`), `process` (28 — `process.send`/IPC), `fs` (17), a dgram
socket (11). No pass-count change (this is a diagnostic-quality fix), but the
leverage map is now truthful — which is what drives what gets built next. Also a
real improvement for ordinary users: a typo'd or unsupported method now names the
type and method instead of a cryptic "only simple function calls" error.
