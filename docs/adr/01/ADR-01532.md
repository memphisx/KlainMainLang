# ADR-01532: A named async function expression's self binding is its value

- **Relations**: Extends TDD-00060, TDD-00087
- **Date**: 2026-10-10

## Context

A named function expression binds its own name inside its body. For an
async one, that binding's type returned a plain promise while the
closure value (and every other reference to it) returns a task promise.
An `await` of a self call took the plain-promise path and read the
wrong slot: `const r = await g(n - 1)` was always 0.

## Decision

The self binding takes the closure value's type, through
`asyncClosureRetType`.

- Inferring the function's return type (its value's type, and its
  emission), the name is bound to the function the checker types, so a
  recursive call in a `return` reads that rather than the integer
  default.
