# ADR-01539: A reaction on a promise of void receives undefined

- **Relations**: Extends TDD-00087
- **Date**: 2026-10-10

## Context

A `.then` runner for a promise whose value is void called its
fulfillment callback with no argument. A callback taking a parameter
read whatever its register held: an `any` parameter compared `!==
undefined` while `typeof` said "undefined", so the Test262 harness's
`.then($DONE, $DONE)` reported a failure, and a rest parameter was
empty (Node: one `undefined`).

## Decision

- The runner passes undefined as an `any` box; a callback of no
  parameters ignores it.
- A callback whose parameter is not `any`, or a rest, is adapted from
  one `any` parameter.

## Divergences

None.
