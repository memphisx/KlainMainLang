# ADR-01720: Arrays through `any`: added properties, holes, length writes

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-18

## Context

An array held in `any` (a boxed static array or a `JSON.parse` dynamic array) behaved like a list of indices only:

- **Non-index keys:** `a.tag = 1` threw "only index assignments are supported on a dynamic array". A symbol key was dropped.
- **`length` writes:** `a.length = n` threw the same error instead of truncating or extending the array.
- **Deleting an index:** `delete a[0]` left the element in place. A dynamic array had no notion of a hole, and a write past its end filled the gap with `undefined` values that `Object.keys`, `for...in` and `in` listed.
- **Object spread:** `{ ...arr }`, `{ ...fn }` and `{ ...("ab" as any) }` were compile errors or copied nothing. Node copies each value's own enumerable properties.
- **Object.assign sources:** a primitive or array source was skipped. Through `any`, symbol keys were not copied.
- **Accessors:** a computed accessor name (`get [k]() {}`) did not parse.
- **Frozen objects:** a write to a frozen static object through `any` succeeded.

## Decision

- **Added properties:** an array's non-index keys live in the shape runtime's added-property table, keyed by the array header (the box's `hdr`, or the dynamic array record).
  - Reads, writes, `delete`, `in`/`hasOwn`, `Object.keys`, `for...in`, `Object.getOwnPropertySymbols` and Object.assign consult it.
  - Inspect renders the entries after the elements (`[ 1, 2, tag: 't' ]`), with numeric column alignment off, as util.inspect does.
- **Dynamic-array holes:** a hole is element tag 13.
  - It packs back as `undefined`, so every element reader stays correct without changes.
  - Keys, `for...in`, `in` and inspect skip it; inspect shows a run as `<n empty items>`.
  - A gap write, a `length` extension and `delete` produce holes.
- **`length` writes:** these apply ToNumber.
  - A value that is no integer in [0, 2^32) throws `RangeError: Invalid array length`.
  - A TypedArray's `length` throws Node's getter-only TypeError.
  - A static array extends with holes through the holes bitmap.
- **Deleting from a boxed static array:** the index becomes a hole. A TypedArray element throws `Cannot delete property 'i' of [object Uint8Array]`.
- **Spread and Object.assign:** both share one run-time copy of a value's own enumerable properties: string keys, then enumerable symbols.
  - An object literal that spreads an array or a function builds as a dynamic object.
- **Accessor names:** any property name is accepted, computed ones included.
- **Frozen objects:** a write through `any` to a frozen static object throws `Cannot assign to read only property 'k' of object '#<Object>'`. An absent key throws the not-extensible message instead.
  - This follows the compiler's strict-mode treatment of writes.
