# ADR-00402: Node conformance — resolve `require('../common/fixtures')` via a generated typed shim

- **Relations**: Extends TDD-00121 (Conformance V4, Node oracle)
- **Date**: 2026-08-27

## Context

`unsupported module require('../common/fixtures')` was the **single largest SKIP
bucket** in the Node `test/parallel` oracle (~305 files) — larger than any
*failure* bucket. `test/common/fixtures.js` is a tiny helper (a fixtures data
dir + `path()`/`readSync()`/`readKey()`/`readKeys()`), built entirely on `path`
and `fs`, which this compiler already supports. It was skipped only because the
runner had no way to resolve it: the original is untyped CommonJS (`module.exports`
+ `pathToFileURL`) the compiler can't ingest, and each test was written to a flat
scratch file where a relative `require` resolved to nothing.

## Decision

Mirror Node's folder tree in the scratch dir and resolve the require as a real
typed import (the compiler already desugars static `require('<literal>')` to an
import, ADR-00369):

- `runNodeSuite` generates `<workdir>/common/fixtures.ts` once — a typed shim
  exposing `fixturesDir`/`path`/`readSync`/`readKey`/`readKeys`, with the real
  `test/fixtures` **absolute** path baked in so `fs.readFileSync` finds the data.
- `frontEndSource` writes each test entry under `<workdir>/parallel/`, so
  `../common/fixtures` resolves to that shim one level up.
- `transformNodeSource` rewrites `require('../common/fixtures')` (default and
  destructured forms) to an import instead of classifying it SKIP.

Shim details: all members use **rest parameters** (accepting any arity, `enc`
args ignored) rather than optional parameters — a closure value's optional-param
default isn't applied at indirect call sites, so an optional param would
arity-mismatch. `fileURL` is omitted (needs `url.pathToFileURL`, unsupported).

## Consequences

Runnable (compiled-far-enough) files grew **1195 → 1344** (+149) and SKIP dropped
correspondingly; the `common/fixtures` bucket is gone. The pass count is
unchanged (24) because those files are heavy (crypto/tls/net) and hit their real
next blocker — but that is exactly the point: **the denominator is now honest and
the histogram attributes their true gaps** (the front-end `only simple function
calls` lever grew +53 to 335, confirming its size). ~156 files still SKIP because
they require `fixtures` *and* another unsupported module. The generated shim
lives in the gitignored `.conformance-out` scratch dir, never committed.
