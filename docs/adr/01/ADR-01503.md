# ADR-01503: A skippable `var` reads its value where every path stores one

- **Relations**: Extends ADR-01057, ADR-01488, TDD-00230
- **Date**: 2026-10-09

## Context

ADR-01057 widens a `var` declared in a nested block to `T | undefined`,
because a path that skips the block reads `undefined`. Inference kept
that widened type even where the declaration had just run:

```ts
for (...) { var uu = hex[i] + hex[j]; uu === "000A"; }
```

There, `uu` read as a possibly-undefined string marked `UncheckedIndex`.
That was bucket 9 of the shadow report (464 rows), and the checker types
it `string`.

## Investigation

- The widening goes through `indexReadType`, which also sets
  `UncheckedIndex`. `checkerPresent` refuses any type carrying that
  flag.
- `DefinitelyAssigned` only follows annotated bindings declared without
  a value, and only plain assignments.

## Decision

- The binder answers `ReachingStores(id)`: the nearest store on every
  path to the read, where each one is a declaration with an initializer
  or a plain `x = v`.
- Codegen (`storesPresent`) reads the value as present when every
  reaching store's value is never absent. A guard stops recursion
  through `x = x + …`.
- `withoutNullable` also clears `UncheckedIndex`, since the absence
  that flag qualified is gone.

## Divergences

None. A path that skips the declaration still reads `undefined`.
