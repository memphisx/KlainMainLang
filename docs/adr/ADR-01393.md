# ADR-01393: IPC child, Worker, fs.watch and signal hooks off the bridge

- **Relations**: Implements TDD-00244; Extends ADR-01392
- **Date**: 2026-10-05

## Context

After [ADR-01392](ADR-01392.md) the select bridge in `loop.c` still called
per-pass hooks for five subsystems on POSIX: the fork child's IPC reader
(`__kml_ipcc_*`), the net socket registry (`__kml_net_*`), Workers
(`__kml_worker_*`), fs.watch (`__kml_fswatch_*`) and process signals
(`__kml_signal_dispatch`).

- Nothing registers a socket in `net.c`'s registry: the sockets the HTTP
  server hands out are the handle table's (`klainpool.c`), so its hooks
  never did anything.
- A Worker's only hook work was checking, every pass, whether
  `terminate()` had been called.
- fs.watch and signals were already libuv handles whose callbacks only
  queued for the next pass's dispatch.

## Decision

- **The IPC child's channel is a `uv_poll_t`**, unreferenced as Node's
  channel is, through a small `loop.c` API (`__kml_loop_fd_watch` /
  `__kml_loop_fd_unwatch`) for descriptors a runtime file reads itself.
  The process emitter's claim of the channel stops the watcher first.
- **`net.c`'s registry and hooks are deleted**; it keeps the socket-name
  readers.
- **`terminate()` posts the worker's exit to its own loop** as a pool
  completion. The worker thread hands the pool its thread-aware exit
  (`__kml_worker_set_end`), so the pool never names a symbol only
  Worker programs link. This holds on every platform.
- **fs.watch listeners and signal watchers run from their libuv
  callbacks**, inside the wait, as Node's FSEvent and Signal callbacks
  run in the poll phase.
- On Windows the ipcc, fs.watch and signal hooks stay until Stage 6.
- The pool hooks stay: other threads change its in-flight count, and
  `uv_ref` is for the loop's own thread only. They move with Stage 1's
  persistent bridge, along with the HTTP accept and dynamic-import island
  hooks.

## Verification

- Mac (M4): the Worker, fs.watch and signal tests; codegen unit tests,
  including the IR-text ratchet (`runtime_task.go` allowance 26 → 20).
- Linux x86-64 (Ubuntu 24.04 container): test-par passes (14 shards,
  3922 tests); examples 393/393; Test262 strict 8498 and js 10506
  (unchanged), no invalid IR.
