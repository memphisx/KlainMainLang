# ADR-01508: A defaulted parameter is present in its function's body

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-09

## Context

A parameter with a default is passed as `T | undefined`. The prologue
(`emitParamDefaultPrologue`) rebinds it to `arg ?? default` before the
body runs. Inference typed the body with the call-ABI type instead. So
`(y = 2) => y * 2` was inferred to return a boxed `any`, its multiply
went through the dynamic path, and `function fn(a, b, c = 0)` had an
`any` result. That was bucket 7 of the shadow report (527 rows).

## Decision

`bodyParamType` gives a body-defaulted parameter its present type when
its default is a present value. It keeps the widening when the
parameter can also be `null` (the prologue tests only `=== undefined`),
or when the default is itself absent, `void` or dynamic. Every
return-type inference that binds parameters uses it: arrows, function
expressions, function declarations, erased and specialized generics,
and class methods.

## Divergences

None. Emission was already correct; inference now agrees with it.
