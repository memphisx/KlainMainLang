# ADR-01182: Generators, promises and the iteration protocol through `any`

- **Relations**: `Extends ADR-01181`, `Implements TDD-00230` (phase 5, P3.3 convert)
- **Date**: 2026-09-28

## Context

With static objects shaped (ADR-01181), the values Node's stream code
passes around as `any` still broke: a generator's `next()`, a promise's
`await`/`then`, `iterable[Symbol.iterator]`, `for await (x of anyValue)`
over anything but an array, an async arrow or a generator expression in a
dynamic position, `Promise.resolve(p)` of a promise held in `any`.

## Investigation

- A Promise<T> stores its value in T's representation (v0/v1 words), so a
  Promise<number> read as a Promise<any> — an erased generic method's
  `Promise<T>` returned to a caller's `Promise<number>` — decoded raw double
  bits as a box (7 read back as 3.5e-323, or 7.5).
- A first design boxed a promise as a derived Promise<any> settled by a
  reaction; it delays every reaction through `any` by one microtask
  (`r.catch(...)` then `await 7` printed in the wrong order against Node).
- `for…of` over `any` walked only arrays (ADR-01077); the parser desugars
  `[Symbol.iterator]()` members to `@@iterator` but `Symbol.iterator` was
  not a value ("undefined variable 'Symbol'").
- The generator element inference and the return-type inference did not
  bind a `for…of` variable, so `yield v + v` inside a `for await` inferred an
  integer and `return w` inside a `for…of` was invalid IR (BACKLOG 43).

## Decision

- **Generators**: box as tag-6 objects (their layout has a header); the
  layout row exposes `next`, `return`, `throw` and `@@iterator`/
  `@@asyncIterator` as dynamic functions over the typed generator entry
  points.
- **Promises**: the box is a headered wrapper `{ promise, boxer, anyElem }`
  cached in a new trailing promise slot (one promise, one box). `await` on
  `any` waits on the promise itself and boxes the value with the wrapper's
  per-T routine; `then`/`catch`/`finally` register one generic reaction
  (`@__kml_pdyn_run`) that calls the dynamic callbacks and resolves the
  result with `@__kml_promise_resolve_any`, which adopts a promise held in
  the value (NewPromiseResolveThenableJob). `Promise.resolve(anyPromise)`
  returns the promise when its elements are `any`. An `async` function
  returning `any`, a `new Promise<any>` resolver and a `.then` callback
  returning `any` resolve the same way.
- **convert(Promise<any> ↔ Promise<T>)** in `coerce`: a derived promise
  whose reaction unboxes (or boxes) the value; a rejection passes through.
- **Iteration protocol**: `for…of`/`for await…of` over `any` is one cursor:
  an array by index, anything else by its `@@iterator`/`@@asyncIterator`
  (`for await` falls back to the sync iterator and awaits values), closing
  the iterator (`return()`) on an early exit. An array held in `any` answers
  `[Symbol.iterator]` with an array-iterator layout.
- **Well-known symbols** (`Symbol.iterator`, `Symbol.asyncIterator`, …) are
  static Symbol values; as property keys the two iteration ones map to the
  `@@` member names; `obj[Symbol.iterator]()` calls the member with `obj` as
  `this`, and `obj[key](…)` on `any` passes its receiver.
- An iteration-protocol interface outside a generator's own signature
  (`Iterable<T>`, `AsyncGenerator<T>`, …) resolves to `any`.
- A generator function expression used as a value compiles as a nested
  generator whose constructor closure is the (boxed) value; an async arrow
  or function expression in a dynamic position keeps its typed coroutine
  and is boxed through the closure adapter.
- A dynamic value into a static object layout converts (P3.3 convert): the
  object when its header names the layout, else a copy read field by field
  (`@__kml_any_to_layout_<id>`).
- Smaller fixes found on the way: an erased generic method erases its type
  parameters in its body too (`new Promise<T>` inside it); the any→closure
  thunk takes a rest parameter; `errorPtrFromValue` keeps an Error held in
  `any` (a generator's `throw(err)` re-wrapped it as `Error: <msg>`); a
  literal `undefined` argument applies a class method's or constructor's
  default; a ternary joining a caught value and an Error is a caught value;
  a boxed null promise is `undefined`; inference binds `for…of` variables
  (BACKLOG 43).

## Side effects discovered

- A web `ReadableStream<T>` whose chunks take two words (a `Uint8Array`)
  passed where `ReadableStream<any>` is declared reads garbage: the stream
  analogue of the Promise conversion (BACKLOG).
- Array methods on an array held in `any` (`anyArr.push(1)`, `.map`) do not
  dispatch dynamically (BACKLOG).
- Iterating a string held in `any` is not implemented (BACKLOG).
