# ADR-01988: Library entry mode (-lib)

- **Relations**: Implements TDD-00230
- **Date**: 2026-11-19

## Context

TDD-00230 phase 4 lists a library entry mode: runtime start-up that does not
own `main()` or assume the main thread, for Android and embedding hosts. The
compiler only produced executables; the only shared libraries it built were
dynamic-import islands, which run inside a compiled program.

## Investigation

- The program's entry is one emitted function (`emitter.go`, the `@main`
  head); nothing in the runtime calls `main` by name. Start-up reads the
  calling thread's stack (`__kml_stack_guard_init`), so it already runs on
  whatever thread enters it.
- The island build (`main.go`) already links a program with `-shared
  -fPIC`, so the runtime sources compile position-independent.
- `-mm=gc` links a shim that replaces `malloc` for the whole process
  (gcshim.c). A library cannot take over its host's allocator.

## Decision

- `-lib` (`options.Library`) builds a shared library: `lib<name>.so`,
  `lib<name>.dylib` or `<name>.dll` by default (`HostSharedLibName`).
- The entry is `int kml_main(int argc, char **argv)` in place of `main`, with
  the same body: argv, the event loop run to completion, `process.exitCode`
  as the result.
- Every object is compiled `-fPIC` (the cached runtime objects key on the
  flags) and the link adds `-shared`.
- Refused up front, with the reason: `--run`, `--static`, `-mm=gc`, and a
  non-bundled `-dynamic-import`.

## Implementation notes

`main.go` (flag, refusals, output name, `-fPIC`, `-shared`),
`options/options.go`, `codegen/llvm/emitter.go` (entry name),
`codegen/llvm/hostclang.go` (`HostSharedLibName`), README's flag list.

## Side effects discovered

- `process.exit()` in a library ends the host's process, as it ends Node's.
- A library under `-mm=gc` needs the collector behind the GC interface
  instead of the malloc shim; until then `-lib` refuses it.

## Verification

`TestE2ELibraryEntryFromThread`: a C host calls `kml_main` from a second
thread; output and exit code equal Node's for `node prog.ts x` (Mac arm64,
Linux x86-64 on Node304). `TestE2ELibraryRefusesGC` covers the refusal.
