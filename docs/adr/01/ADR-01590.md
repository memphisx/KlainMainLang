# ADR-01590: A module global read from a typed Record keeps its type

- **Date**: 2026-10-11

## Context

`const recs = zone["a"]` at module scope, with `zone` typed
`{ [k: string]: [number, number, Buffer][] }`, failed to compile:
"the module-global pre-pass typed 'recs' as an any box (i64) but its
declaration stores ptr[]".

## Investigation

`decideGlobalType` (`emit_exprs_vardecl.go`) types a member or index
initializer rooted at a dynamic global as `any` (`dynamicGlobalPath`). But
the declaration unboxes into the read's static type when that type is
concrete, as a `Record` read's element type is.

## Decision

The pre-pass answers `any` only when the read's inferred type is itself
dynamic. Otherwise it falls through to the simple-type check, and failing
that leaves the global un-promoted.

## Verification

`TestE2EAnyIntoTuplesAndNestedArrays` reads a `Record` at module scope.
The fixed probe compiles and matches Node.
