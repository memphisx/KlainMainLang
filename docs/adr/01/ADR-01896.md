# ADR-01896: `yield*` over a primitive `next()` result

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets); follows ADR-01886
- **Date**: 2026-10-21

## Context

- ADR-01886 typed a `next()` that only throws as tsc's error type. A `next()` returning a primitive (`next() { return 42; }`) has no `value` either: tsc reports TS2490 (TS2547 when async) and types the value any. The checker left the delegating generator, and everything read from it, unanswered.

## Decision

- A primitive member of the `next()` result makes the iterated value any; a type parameter stays unanswered.

## Consequences

- Generator types match tsc 5.6.3's declarations; the js lane's TypeError at run time is unchanged (Node-equal on Apple Silicon).
