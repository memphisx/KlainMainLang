# ADR-01400: The HTTP server's fixed runtime in C

- **Relations**: Implements TDD-00244; Extends ADR-01399
- **Date**: 2026-10-05

## Context

[TDD-00244](../tdd/TDD-00244.md) Stage 5 moves the HTTP server onto libuv,
and with it the server runtime's IR text, which this project's own practice
moves into C ([TDD-00240](../tdd/TDD-00240.md)). Part of that IR does not
depend on the program:

- the additional listeners' table (register, keepalive, fd-set, close);
- `http.close()`;
- `http.closeAllConnections()` and its local shutdown pass.

The accept paths and the connection fibers' entry do depend on it: whether
the program serves TLS, HTTP/2, or both, and the ucontext layout.

## Decision

- **`httpsrvsrc/httpsrv.c` holds the fixed part**, linked with `loop.c`
  wherever the HTTP runtime is. The behavior is the IR's:
  - a closed listener's slot is reused;
  - `close()` sets a cluster's shared word, closes the listener and wakes
    the parked fibers once;
  - `closeAllConnections()` sets the other shared word and shuts down every
    local connection, whose fiber unwinds through its own finish path.
- The listeners' table is a C thread-local. The accept IR, which stays in
  `runtime_http.go` until the accept paths move, reads it as an external
  global.
- The IR-text ratchet for `runtime_http.go` drops from 30 to 23.

## Verification

- Mac (M4): the close, closeAllConnections, multiple-server, relisten and
  cluster tests; codegen unit tests.
- Linux (x86-64, Ubuntu 24.04 container), with [ADR-01401](ADR-01401.md):
  the full test suite (3,922 tests), the 393 examples, and Test262 in both
  lanes (strict 8,498, js 10,506, unchanged, no invalid IR).
