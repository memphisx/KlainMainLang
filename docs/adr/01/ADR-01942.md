# ADR-01942: structuredClone clones a statically typed value it cannot copy statically at run time

- **Relations**: Implements TDD-00230, Extends ADR-01266, Extends ADR-00574
- **Date**: 2026-10-28

## Context

A statically typed `structuredClone` argument was copied by code generated from its type. Any type that code could not copy was a compile error: a class instance, a function, a `Promise`, a `URL`, an `EventEmitter`, and a `Map`/`Set` whose element is an array, `Map` or `Set`. Node accepts all of these. It clones a class instance as a plain object, and it throws `DataCloneError` for a function, a `Promise` or a `URL`.

The run-time cloner in `lib/node/internal_structured_clone.ts` (ADR-01266) already handled values typed `any`, but it was missing several kinds:

- wrapper objects;
- a typed array view's byte offset;
- a Proxy;
- the host objects Node refuses to clone.

`util.types` also answered false for every boxed-primitive and Proxy predicate.

## Decision

- **Routing.** If a value's static type contains, anywhere (through array elements, object fields and `Map`/`Set` elements), a kind the static clone does not copy, the whole value goes to the run-time cloner. The result is typed `any`.
  - The intrinsic's inferred type and `inferExprType` both say `any`.
  - An unannotated binding initialized by such a call keeps the box. The checker's narrowing to the argument's type would otherwise read the plain object through the class's layout.
- **The run-time cloner:**
  - clones wrapper objects (Boolean, Number, String and BigInt) and throws for a Symbol wrapper;
  - clones a view's buffer through the memo, keeping the view's offset (DataView included);
  - passes a `SharedArrayBuffer` through unchanged;
  - throws Node's messages: `#<X> could not be cloned.` for Promise, WeakMap, WeakSet, WeakRef, FinalizationRegistry and Proxy, and `Cannot clone object of unsupported type.` for URL, URLSearchParams, Headers, Request and Response.
- **`util.types`.** The boxed-primitive predicates, `isProxy` (a native `__kml_is_proxy`) and `isModuleNamespaceObject` now answer from the value.
- **Fixed in passing.** A `Set` or `Map` keyed by a host value (`Set<Map<…>>`) or by a function read its key back as the raw box payload. That gave garbage or a segfault. `mapKeyFromSlot` now unboxes a host key as any host read does, and a function key back to its closure.
- **Fixed in passing.** A generator instance recorded the prototype it inherits only when the program named a prototype (`prototype`, `getPrototypeOf`, …). `instanceof` walks that prototype too, so `function* h() {} h() instanceof h` was false. Now `instanceof` turns the recording on as well.
- **Fixed in passing.** `console.log(Function.prototype)` now prints `[Function (anonymous)] Object`, as Node does. A new metadata flag, `fnFlagObjectProto`, marks a function whose prototype is `Object.prototype`. A function view now clears its `sloppy`, `ctor` and new flag on every path; an unregistered function used to leave them uninitialized, and `instanceof` reads `ctor`.
- **Fixed in passing.** A two-argument `structuredClone(v, options)` was inferred as `any` while it was emitted with the static type. The two now agree.

## Consequences

- A statically typed class instance, function, `Promise`, `URL` or nested collection now compiles, and its clone matches Node's output or its `DataCloneError`. The compile-time rejection caveat is gone.
- These clones run through the dynamic cloner, so they are slower than the static copy, and their result is an `any`.
- Tests: `TestE2EStructuredCloneStaticRunTime` and `TestE2ESetOfMapElements`.
