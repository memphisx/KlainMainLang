# ADR-02041: console.* with a run-time format string

- **Date**: 2026-11-22

## Context

- Only a string literal first argument was treated as util.format's
  format string. `console.log(f, x)` with `f` a variable,
  `console.log(...args)` and a console method called by value printed
  `%s` as is. Node formats any first argument that is a string at run
  time.

## Decision

- A first argument typed string or `any`, with more arguments after it,
  passes its arguments' boxes to `__kml_console_fmt` (anystr.c). It
  returns the formatted line, or NULL when the first argument is no
  string or holds no `%`. NULL takes the usual per-argument printing.
- `console.log(...arr)` over string or `any` elements calls
  `__kml_console_fmt_arr` the same way.
- The specifiers follow util.format: `%s` (inspect for objects), `%d`,
  `%i` (parseInt), `%f` (parseFloat), `%j` (`[Circular]`), `%o`/`%O`,
  `%c`, `%%`. A BigInt keeps its `n` for `%s`/`%d`/`%i`.

## Consequences

- `%o` still lacks `showHidden`, as the literal path does (BACKLOG 167).
- Tests: `TestE2EConsoleRuntimeFormatStringTS`.
