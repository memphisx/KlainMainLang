# ADR-01335: `undefined` in a `number` slot

- **Relations**: Implements TDD-00241 (in part), Extends TDD-00187
- **Date**: 2026-10-02

## Context

[TDD-00241](../tdd/TDD-00241.md) chose a signaling-NaN sentinel,
`0xFFF4000000000001`, for `undefined` held in a `double` slot. The TDD's
measurements were taken on Apple Silicon (clang 21) and x86-64 (Ubuntu
clang 18).

## Decision

1. **Producers.**
   - Unboxing a value to a `double` (`emitAnyToF64Slot`, used by the
     narrowing and by `coerce`) gives the sentinel for `undefined`. This
     covers `const n: number = o.missing`, a short dynamic call into a
     typed function, and `setTimeout` arguments. Arithmetic on a box keeps
     ToNumber (`emitAnyToNum`).
   - `x!` over an absent `{i1, double}` gives the sentinel. A local is
     reloaded as its aggregate, since `emitIdent` reads it as its payload.
2. **Consumers.**
   - Boxing (`emitNbEncodeDouble`) gives `nbUndefined`.
   - `__kml_dtoa` prints `undefined`.
   - `typeof` of a non-literal `double` is a run-time choice.
   - `=== undefined` and `== null` test the bits; `=== null` stays false
     (`emitF64UndefinedEq`, and `emitNullableScalarNullCompare` no longer
     folds the comparison).
   - Two sentinels are `===`.
   - JSON drops an object field holding one (`jsonFieldSkippable`) and
     writes `null` for an array element holding one.
   - `??`, `??=` (locals and fields) and `?.` treat the sentinel as absent.
   - A property read on a `double` holding it throws Node's TypeError
     ("Cannot read properties of undefined (reading 'toFixed')") through
     the null-dereference guard.
3. **Quieting.** `quietIdentity` turns the sentinel into NaN in the result
   of a float `+ - * / %` with a literal `0` or `1` operand, the forms LLVM
   folds to the operand. Unary `+` and `Number()` on a `double` quiet too.
   `__kml_js_pow` quiets its operands, because C's `pow(x, 1)` returns
   `x`.

## Side effects discovered

- `process.stdout.columns` stored in a `number` binding off a TTY now
  reads `undefined`, as in Node, which retires that caveat.

## Remaining (TDD-00241)

- An integer slot (the unannotated-`number` `i64` default) has no spare
  pattern and still reads `0`.
- A `float32` slot has no sentinel yet.
- An identity that only becomes one after inlining (`scale(n, 1)` with
  `x * k`) can keep the sentinel.

## Verification

`tests/undefined_number_slot_test.go` asserts Node's output in both lanes.
`examples/basics/undefined_number.ts` matches Node. Mac (Apple Silicon):
targeted suites, and the codegen unit tests including the IR-text ratchet.
Linux x86-64: the sentinel measurements in TDD-00241; full gates in the
session's gate record.
