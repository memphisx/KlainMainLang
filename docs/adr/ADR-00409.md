# ADR-00409: Node oracle — unimplemented core modules count as FAIL, not SKIP

- **Relations**: Extends ADR-00407, [TDD-00121](../tdd/TDD-00121.md)
- **Date**: 2026-08-27

## Context

Even after ADR-00407's shim reclassification, the skip table still labeled
real Node core modules — `http2` (~224 files), `vm` (~77), `https` (~54),
`async_hooks`, `domain`, `diagnostics_channel`, the `node:test` runner — as
"unsupported module … out of scope". Those are in-scope gaps: modules the
project could and should implement, just never started or never finished.
Counting them as skips understated the failure count and overstated the pass
rate's meaning.

## Decision

- `classifyUnsupportedModule`: a require of a module outside the
  supported/ambient sets counts as **FAIL — `MODULE_NOT_IMPLEMENTED: <mod>`**
  when the specifier names a real Node core module; only Node-repo-internal
  paths (`../common/*` not covered by shims, `./…`, `internal/*`) remain
  SKIP, relabeled "Node-internal harness file" to say what they actually are.
- Destructured `const { mustCall, isWindows } = require('../common')` (~68
  files) is now mapped like the `common.<member>` form: test helpers become a
  real `'test'` import, probe values destructure from the injected shim
  literal; an aliased or unknown member keeps the file skipped with the
  member named.
- `../common/countdown` (~46 files): generated typed class shim
  (`writeCountdownShim`; Node's default export becomes a named export, the
  require rewrite aliases it). The real class wraps its callback in
  `common.mustCall`; the shim calls it directly.
- Report header/skip-table wording updated to the new contract.

## Implementation notes

`tools/conformance/node.go` (+ its unit test signatures):
`transformNodeSource` now returns a fourth value, the in-scope fail reason.
Totals moved from 27 passed / 1576 failed / 1875 skipped to **27 / 2304 /
1147** — ~730 files reclassified into the failure column where they belong.
The headline "pass rate over attempted" dropped 1.7% → 1.2%; that is the
number to quote.

## Side effects discovered

- The `MODULE_NOT_IMPLEMENTED` histogram is now the direct module-level
  roadmap: `http2` 236, `vm` 77, `https` 61, `test` runner 60, `async_hooks`
  52, `domain` 35, `diagnostics_channel` 28, `v8` 18, `stream/web` 18 —
  recorded in `docs/testing/NODE-GAP-ANALYSIS.md`.
- `common.skipIfInspectorDisabled` (~117) and `common.invalidArgTypeHelper`
  (~61) remain the two largest helper-gated skip buckets; their verdicts
  (genuine skip / dynamic-error-behavior tests) are in the gap analysis.

## Verification

`go test ./tools/conformance` passes; full `-suite=node` run regenerated the
report with the new columns (Mac).
