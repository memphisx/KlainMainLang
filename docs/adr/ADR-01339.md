# ADR-01339: Builtin fall-through removed for arrays, strings, promises and `http`

- **Relations**: Implements TDD-00230 (P3.2), Extends ADR-01337, ADR-01307
- **Date**: 2026-10-03

## Context

[TDD-00230](../tdd/TDD-00230.md) P3.2 compiles builtin calls through their
declarations (`lib/*.d.ts`, `@intrinsic`/`@lower`) and deletes the by-name
blocks in `emitCall` once nothing reaches them. After
[ADR-01337](ADR-01337.md) these by-name blocks were left:

- `then`/`catch`/`finally` on a promise;
- `toString()` on a RegExp, a number or boolean, and a string;
- the Array and String method names (`push` … `flatMap`, `split`,
  `match`, `matchAll`, `concat`, …), kept as the migration fall-through for
  receivers no declaration reached;
- the code-generated `http`/`https` server, client, `Agent`,
  `ClientRequest`, `IncomingMessage` and `net` socket methods.

## Investigation

- Deleting each block one at a time showed what it was still catching.
  - **`toString` on a `boolean | number`.** The checker records no
    member declaration for a union, so the call had no route.
  - **`toString()` on an `any` (`-compat=js`).** The dynamic dispatcher
    read `toString` as a property of a boxed primitive. That read is
    `undefined`, so the call threw "toString is not a function".
  - **A Buffer narrowed by `Buffer.isBuffer(x)`.** Codegen's statement-level
    narrowing kept a two-member union (`Buffer | (string | Buffer)[]`). It
    never asked the checker, which had already narrowed `x` to `Buffer`.
  - **`match`/`matchAll`.** They were not declared on `String` at all.
  - **`s.concat(...parts)`.** A spread into a lowered rest parameter was
    rejected.
  - **`Buffer`'s `indexOf`/`includes`/`fill`/`slice`.** They had no key, and
    `slice` copied, where Node's `Buffer.prototype.slice` shares memory like
    `subarray`.
  - **`new Array<number>(n).fill(…)`.** It was inferred as a number:
    `inferExprType` had no `NewArrayExpression` case.
  - **Untyped `new Array(n)`.** It was rejected, though TypeScript types it
    `any[]`.
- **`matchAll` returned an array.** Node returns a `RegExp String Iterator`
  whose steps are exec results (`index`, `input`, `groups`): `.length` is
  `undefined`, and `Object.prototype.toString.call(it)` is
  `[object RegExp String Iterator]`. Iterators in general printed
  `[object CollIter]` there.
- **`new RegExp(re)` stringified its RegExp argument.** It gave source
  `/a(\d)/g` and no flags. Node copies the source and flags.
- **The native `http`/`https` paths were unreachable.** `http` and `https`
  resolve their members to the TypeScript companions
  (`lib/node/internal_http.ts`, `internal_https.ts`, ADR-01170) on every
  target, and `new http.Agent()` is the companion's class. `deadcode -test`
  over the tree, with the dispatch branches removed, listed the unreachable
  functions.
- **Host-object methods read as values were wrong.** `typeof m.get`,
  `typeof /x/.test` and `typeof p.then` were `number`. The host-box shape
  machinery (ADR-01204's host cells, `emit_host_shape.go`) already exposes a
  boxed host's declared methods as dynamic-function records.

## Decision

1. **Promise reactions** carry `@intrinsic Promise.prototype.then|catch|finally`
   in `lib/es.d.ts`. The intrinsic's type is `promiseThenType` (extracted
   from `inferExprType`), and `reprOwners` maps a promise to `Promise`.
2. **`toString` by-name blocks deleted.**
   - `Object.prototype.toString` takes a number held as one when the
     checker resolves the member, or when its type is a union.
   - On an `any`, `emitDynToStringCall` calls a dynamic object's own
     `toString` and ToStrings every other value; a null or undefined
     receiver's read throws.
   - A flow-narrowed union local is read as the member the checker narrows
     it to (`flowNarrowedTy`, used by `emitIdent` and `inferExprType`).
3. **The Array and String fall-through deleted.** When a call's declaration
   is a library member the lowering does not take (no key, an unresolved
   overload under `-compat=js`, a spread of an `any`), `loweredCall` falls
   back to the intrinsic of the owner codegen's representation names
   (`reprIntrinsic`). `isLibMember` limits this to the library's
   declarations, so a program's own class method keeps its dispatch.
   `reprOwners` gained Array (also for typed arrays and Buffers) and String.
4. **New declarations and intrinsics:**
   - `String.prototype.match`/`matchAll`, with `RegExpStringIterator`
     declared;
   - `String.prototype.concat` as the fallback intrinsic for a spread
     argument;
   - `Buffer.prototype.indexOf`/`lastIndexOf`/`includes`/`fill`: a string
     value searches or repeats its bytes, otherwise the typed-array path;
   - `Buffer.prototype.slice` is `TypedArray.prototype.subarray`.
   - A lowered rest parameter takes spread arguments of its element
     representation, built as an array literal.
5. **`matchAll` is a real `RegExp String Iterator`.** It runs exec on a
   clone of the RegExp (its source and flags, starting at its `lastIndex`),
   collects exec-shaped steps, and opens an Array Iterator over them,
   flagged `IterRegExp`. `collIterName` names it, and host boxes take
   their class name from `collIterName` (`[object Array Iterator]`).
6. **`new RegExp(re[, flags])`** takes re's source and, unless given, its
   flags.
7. **The native `http`/`https`/`net` paths deleted.** That covers the
   `emitCall` branches, `chainedCreateServerListen`,
   `NewHTTPAgentExpression` (AST node and sema mapping), the `IsHTTPServer`/
   `IsClientRequest`/`IsHTTPAgent`/`IsIncomingMessage`/`IsNetSocket` flags,
   and every function `deadcode -test` then reported (about 3,400 lines,
   including earlier dead code in the child-process and path runtimes).
   `klain:http` keeps the server core it shares. The IR-text ratchet's
   allowances drop accordingly.
8. **A library method read as a value** (`hostMethodValue`: a library
   member, on a host handle or a promise, not in callee position) boxes the
   receiver and reads the member through the box's shape, so it is a
   function. `hostMembers` maps iterator classes to their interfaces
   (`ArrayIterator`, …).
9. **`new Array(n)` without a type argument is an `any[]`** whose slots read
   undefined. Inference answers `new Array<T>(n)` as `T[]`.
10. **`Function.prototype.call`/`apply`/`bind`** carry
    `@intrinsic Function.prototype.*` keys (the existing
    `emitFunctionCallApply`/`emitFunctionBind`); `reprOwners` maps a
    function to `Function`. Their by-name block is deleted.
11. **`str.match(re)` with a RegExp held in a value** is exec-shaped
    whatever its flags (`ExecMaybePlain`). A non-global match carries
    `index`, `input` and `groups`. A global match's header stores index -1
    and no input, so they read `undefined` and console.log lists no extras,
    as Node prints a plain array.

## Side effects discovered

- Test programs that tsc rejects were corrected: `s.match(re)[0]` without
  `!`, and `matchAll` with a string argument (moved to the `-compat=js`
  lane). Others asserted unfaithful behaviour: `p.keys().join(",")` on a
  URLSearchParams iterator, and `matchAll(...).length`.
- `Map.prototype.get === m.get` needs builtin prototypes as values; not
  done.
- The checker reports no TS2339 for a member missing from a library
  interface, since our declarations are partial (`symbols.go`). A
  per-interface member list generated from TypeScript's library would let
  it report exactly tsc's.
