# ADR-01272: Generator parameters: nullable scalars and captured locals

- **Relations**: `Extends ADR-00172`, `Extends ADR-00619`
- **Date**: 2026-09-29

## Context

Two generator-body bugs produced invalid IR:

- A generator parameter typed `number | undefined` was stored into its
  `{ i1, T }` slot as a bare `T`.
- A local captured by a closure made inside a branch was boxed at the
  closure, in a block that does not dominate the local's later uses.
  ADR-00619 fixed this for functions, but generator bodies did not compute
  the eager-box set.

## Decision

- A nullable-scalar generator parameter keeps its presence bit end to end:
  - construction boxes the argument into the aggregate;
  - the first-class constructor thunk takes the aggregate;
  - the body binds it as a nullable-scalar local.
- A generator body computes `hoistedCaptures` like any function body, so
  captured locals are boxed where they are declared. A captured parameter
  is boxed at entry.

## Verification

`timers/promises` interval iterator.
