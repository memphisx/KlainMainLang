# ADR-01538: A function's pushes type an outer empty array

- **Relations**: Extends TDD-00205, ADR-01529
- **Date**: 2026-10-10

## Context

The usage pre-pass that types an unannotated `[]` from what is pushed to
it walked function expressions and arrows in its body, but not function
declarations. A module-level `var out = []` pushed only from a
`function` stayed `number[]`, so the pushed strings were stored as
`NaN`.

## Decision

The pre-pass walks a function declaration's body as it walks a function
expression's (its own bindings shadow the array).

None.
