# ADR-01258: Generic class statics, instance annotations, `new … .m()`

- **Date**: 2026-09-29

## Context

Three generic-class gaps blocked `class AsyncLocalStorage<T>` (ADR-01257):
- A static method on a generic class was a compile error.
- An annotation naming an instance (`function of(): Box<number>`) resolved
  through the array fallback ("expression is not an array").
- `new Box<string>('s').get()` failed ("has no method"): the call looked the
  method up before the receiver's `new` had instantiated the class.

## Decision

- A static method cannot name the class's type parameters, so the statics
  compile once, as a non-generic companion class (`<Name>__kml_statics`)
  that static calls on the generic class resolve to. Static fields and
  static blocks stay rejected.
- `Box<number>` resolves to the instance type `new Box<number>()` has.
- A method call on a `new` of a generic class instantiates the class first.

## Verification

Mac (Apple Silicon): `TestE2EGenericClassStaticMethod` matches Node.
