# ADR-00875: WPT full headless corpus — allowlist removed, capability-ladder reporting

- **Relations**: `Implements TDD-00204`, `Extends ADR-00871`
- **Date**: 2026-09-11

## Context

The WPT track (ADR-00871) ran a hand-picked 21-directory slice: 1,344 headless
multi-global files. An audit of the pinned tree's full git metadata found
**4,207** `.any.js`/`.window.js`/`.worker.js` sources repo-wide — the slice
covered 32%, and areas with implemented surface (`workers`, `eventsource`,
`webstorage`, most of `html/`, `wasm` beyond `jsapi`) were simply never
fetched, invisible in the report. Meanwhile published WPT numbers from browser
engines (Servo: "52,000+ tests, ~2M subtests"; wpt.fyi: ~56K) count *generated
test documents* — each `META: global=` variant of an `.any.js` file counts
separately, and the bulk of the corpus is testharness `.html` (needs a DOM;
jsdom-tier runners reach it) and css reftests (needs rendering; only real
engines reach those). Numbers published here will be read against those; a
curated denominator is indefensible even when each cut had a rationale.

## Decision

Denominator = the entire headless multi-global class, classification at run
time, comparability made explicit:

- **`tools/conformance/wpt.go`**: the `wptRoots` allowlist is deleted; the
  whole `.wpt-tests` checkout is walked for the three suffixes. The existing
  run-time classifiers (DOM/browser-global needle, `idlharness` include
  filter) absorb out-of-scope files into the *counted* skip histogram.
- **`fetch.sh`**: the WPT sparse checkout switches from directory names to
  pattern rules — `*.js` (META helper includes are plain sibling .js files
  anywhere; a sources-only first cut produced a ~500-file false-skip bucket),
  `*.json`, and the `**/resources/**` / `**/common/**` / `**/util/**` fixture
  dirs. Media-heavy blobs stay unfetched; a still-missing helper surfaces as
  a counted "shared helper not in fetched slice" skip. The readiness marker
  gains a slice-version suffix (`<sha>+full-headless-v3`) so
  a pattern change forces a refetch. fetch.sh also writes a corpus-stats
  manifest (`.git/kml-corpus-stats`, from `git ls-tree -r` over the full
  tree): total files, headless sources, css vs other `.html`, `-manual`,
  `crashtests/`, `webdriver/` counts.
- **Report**: opens with the **capability ladder** — rung 1 rendering engines
  (css reftests, ~35.6K docs), rung 2 DOM-without-rendering / jsdom tier
  (testharness `.html`, ~31.2K docs, reachable after the TDD-00204 Track 5
  DOM shim), rung 3 this runner (4,207 headless sources), plus the
  never-headless classes (manual/crashtests/wdspec) — so every excluded file
  is attributed to a named capability, and the published number is comparable
  to Servo/wpt.fyi instead of challengeable.
- **Variant-aware comparability count**: `META: global=` is parsed
  (`worker` = 3 scopes; default = window + dedicated worker) and the report
  states the wpt.fyi-unit document expansion of the denominator. Each source
  still runs once — this runtime has no distinct per-scope globals — stated
  outright rather than counted as coverage. `wptSummaryLane` gains a
  `documents` field; `html` now reports the full-tree `.html` count.

## Consequences

The corpus fetch is 135MB (blobless). The runnable denominator roughly triples
and the skip histogram now contains browser-hardware areas (Bluetooth, WebNN,
sensors) alongside DOM files — the headline file-pass percentage drops
accordingly, which is the point: the number is now defensible line-by-line.
The report's numbers section is regenerated by `make conformance-wpt`
(TDD-00204 Track 1); Test262/Node/TS denominator tracks are separate
deliveries under the same TDD.
