# ADR-01073: A finished coroutine's task struct is freed

- **Relations**: Extends ADR-01048 (stack reclaim), ADR-01051 (parked tasks and the loop)
- **Date**: 2026-09-22

## Context

BACKLOG §0 item 11: ADR-01048 gave a finished task its stack, context and jmpbuf stack back but deliberately kept
the 112-byte task struct, because a promise's `waiter` field could still name the task after it finished (a
`Promise.race` loser settling late writes through it). In manual mode that was one struct leaked per `await`-ing
call for the life of a server.

## Investigation

Who holds a task pointer once the task is done (`runtime_task.go`):

- the task array — dropped by `@__kml_task_compact` (ADR-01048);
- a `waiter` field — written only by `@__kml_task_await_any_of` / `@__kml_task_await_first_fulfilled`
  (`Promise.race` / `Promise.any`), which register the current task on *every* member before parking; the
  member that settles wakes it, the others keep the stale registration, and `@__kml_task_finish` /
  `@__kml_promise_settle` store through it when they settle later;
- a resume closure `{ @__kml_task_resume, task }` on a promise's reaction list or the microtask queue
  (`@__kml_task_await_ready`) — consumed exactly once, and a task in that state is not done;
- the frame that swapped into the task (`spawn`, `sched_step`, `task_resume`) — which calls
  `@__kml_task_reclaim` right after the swap returns, before anything can compact.

So the waiter registrations are the only holders that outlive the task.

## Decision

- `@__kml_task_unwait(members, count, task)`: clears every member's `waiter` that still names the task. Both
  parking waits call it immediately after their `swapcontext` returns — the wake happened, no member may name
  the task any more.
- `@__kml_task_compact` frees the struct of every done task it drops from the array. Compaction only runs from
  the outermost scheduler step (the thread-local depth counter), so no in-flight frame holds a dropped pointer.

## Implementation notes

`codegen/llvm/runtime_task.go`. Under `-mm=gc` the `free` goes through the shim (`GC_base`-guarded, ADR-00351).

## Side effects discovered

None.

## Verification

Windows, manual and `-mm=gc`: 3,000 awaited coroutine calls, 200 `Promise.race` pairs whose losers settle after
the winner's awaiter has finished, a `Promise.any` with a late loser — correct sums, RSS under 60 MB (Node 24:
same output). E2E: `TestE2ETaskStructFreedAfterRaceLoser` (`tests/task_struct_free_test.go`). Linux (Docker) in
the session's full pass.
