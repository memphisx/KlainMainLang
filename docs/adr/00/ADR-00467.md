# ADR-00467: array literal elisions

- **Date**: 2026-08-29

## Context

`unexpected token , in expression` (74 TS-oracle false-rejects) is array
elision — `[1,,3]`, `[,,]` — pervasive in the older corpus.

## Decision

A hole at an element position desugars at parse time to the same
`undefined` literal an explicit `undefined` element already uses: it
reads as the element type's zero value (this compiler's usual
`undefined` stand-in, ADR-00157 convention) and counts toward the length
— `[,,].length === 2`, trailing commas unchanged. Destructuring-pattern
holes were already supported separately.

## Verification

Mac. `tests/arrays_test.go` elision E2E and the `examples/arrays`
extension pass; array/destructuring/spread batch green. TS oracle:
**55.5% → 55.6%** (agreement 5133 → 5145). Node oracle unchanged (40).
