# ADR-00870: Faithful thrown values — the unpacked catch-value record (TDD-00202)

- **Relations**: `Implements TDD-00202`
- **Date**: 2026-09-11

## Context

The runtime assumed thrown == Error: `errorPtrFromValue` wrapped a thrown
primitive into an `errorObjType` (stringified message) and the catch variable was
always bound `errorObjType`. So `throw "x"` was caught as `Error: x`
(`typeof e === "object"`) where Node gives the string `"x"`; `throw 42` became
`Error: 42`; a thrown plain object's own fields were unreadable. TypeScript binds
`catch(e)` as `unknown` and at runtime the thrown value is any value.

## Investigation (the representation)

A catch slot must hold heterogeneous machine representations (number/string/
object/bool) from different throw sites, so it needs a uniform tagged value. The
packed NaN-box `any` cannot serve: its pointer-kind space is a full 3 bits
(kinds 0–7 all used), so a caught Error gets no distinct tag, and a generic
object box carries no runtime shape to read `.message` from. Widening the packed
encoding risks misclassifying non-16-aligned string boxes.

**Decision (with the developer): an unpacked `{ i8 tag, i64 payload }` record**
(`TypeCaught`, ≈ `unknown`). The tag reuses the logical `kmlTag*` values plus a
new `kmlTagError` (13) whose payload is the errorObjType pointer. It packs down
to a real NaN-box `any` (Error → object) when a caught value flows into a general
`any` slot; the Error shape is only reachable through the record, in catch-local
scope. Strict arithmetic is unaffected — `unknown` must be narrowed before use,
so the record is only ever a storage + narrowing vehicle, never a dynamic-operator
path.

## Decision

- **Runtime** (`runtime_exceptions.go`): the thrown value is stored as
  `@__kml_thrown_tag`/`@__kml_thrown_pay`; `@__kml_throw_any(tag, pay)` is the
  core, `@__kml_throw(ptr errObj)` a tag-13 shim kept for the ~41 internal Error
  throw sites. `@__kml_thrown` (ptr) stays set to the Error for tag 13 (the
  async/fs internal Error-only catches + the uncaught printer read it).
  `__kml_caught_unc_msg` renders an uncaught throw's message per tag (Error →
  message, string → itself, number → dtoa, bool/null/undefined → literals).
- **`emitThrow`**: a caught value re-throws its record verbatim; an Error — or a
  `class X extends Error` instance (errorObjType-compatible layout, TagID in the
  kind slot) — goes through the tag-13 shim; everything else boxes to a NaN-box
  value whose `(tag, payload)` is recorded.
- **Catch binding** (`emitTry`): `catch(e)` binds `e` as `TypeCaught`; the
  destructured form synthesizes an empty Error for a non-Error throw so a bad
  pointer is never dereferenced.
- **`emit_caught.go`**: operations on a caught value — `typeof`, `===`/`==`,
  `instanceof` (built-in kind, user error-subclass via the kind-slot TagID, or
  `Object`), member access (a known Error field returns its real type so
  `e.message.length` keeps working; `.errors` routes to the AggregateError
  accessor; otherwise the dynamic path), `toString`/console rendering, and the
  `any`-pack used by the generic paths.

A known Error field on a non-Error caught value reads the field's zero value
(empty string / 0) rather than `undefined` — a minor divergence in the rare
non-Error case, no worse than the prior errorObjType-assumed behavior, and it
keeps existing lenient `catch(e){ e.message }` code type-checking.
