# ADR-01181: Every object layout starts with a header word; a layout table serves dynamic access to static objects

- **Relations**: `Implements TDD-00230` (phase 5, first step)
- **Date**: 2026-09-28

## Context

A static object — a class instance, an object literal, a generator, a
promise — reaching `any` had no run-time shape. `(o as any).x`, a class
method called through `any`, `it.next()` on a generator held in `any`, and
`iterable[Symbol.asyncIterator]` all failed ("dynamic property access on a
statically-typed value is not supported"), and a generator or a promise
boxed into `any` was tagged as a *string*. Node's `Readable.from` reads an
iterable's protocol through exactly those operations, so the stream
operators (TDD-00231) could not be ported faithfully. BACKLOG 72 (a static
object boxed into `any` has no run-time shape) is the same gap.

## Investigation

- Class instances already carried a hidden i64 tag at field 0 (TDD-00009),
  Errors a flagged kind (TDD-00222), Symbols a flagged word (ADR-01059):
  partial headers, each its own convention.
- Object literals and host classes had none, so a tag-6 payload's field 0
  could be anything — a pointer, a double's bits.
- A negative-offset (prefix) header was considered: no field index moves,
  but every object allocation and free, and the collector's interior-pointer
  handling, would change, and C-allocated objects would read garbage before
  their start. A field-0 header matches the class and Error precedent and
  TDD-00230's design ("every boxable heap object starts with one header
  word").
- Host classes (the `Is*`-flagged runtime objects) are read at fixed offsets
  by hand-written IR and C (e.g. `__kml_signal_aborted`, the fetch abort
  path, the statfs sidecar). Moving all of them at once would touch code
  phase 4 rewrites in C anyway.

## Decision

- `ObjectType` prepends a header field (named `ClassTagField`); a class's
  tag *is* the header. `TupleType` stays headerless (value-like data).
  `hostObjectType` keeps a host class's layout headerless until that class
  moves to a declared layout; `AbortSignal`, `AbortController` and `Stats`
  move now, their fixed-offset readers updated.
- The header word: bits 0–31 a type id, bits 32–46 a magic (`0x4B4D`), bit
  47 the Symbol flag, bit 48 the Error flag. A header with neither magic nor
  flag is "no shape". Class TagIDs and object-layout ids come from one
  counter (starting at `1 << 16`, clear of error kinds and error-subclass
  tags); an object layout's id is interned by its field names and storage.
- Every object allocation goes through `emitObjAlloc`/`emitObjAllocInto`/
  `emitObjMallocInto`, which store the header (TDD-00230 P3.3a's single
  allocation primitive, for object layouts). A runtime template that
  allocates a layout loads its header from `emitLayoutHeaderGlobal`.
- `UserFields()` is a layout's fields after the header; every loop,
  emptiness check and positional access that meant "the declared fields"
  uses it (child_process/http options, interfaces, unions' discriminants,
  JSON projection, webview bindings, …).
- The layout table (`emit_shape.go`, `shapesrc/shape.c`): for each layout
  that is boxed into a dynamic value (recorded by `emitBoxValue`, a class
  with its subclasses), a get and a set routine generated from the static
  type, each field boxed/unboxed by the same conversions typed code uses; a
  class's methods and accessors as dynamic-function records with generated
  adapters (a default applies when fewer arguments are passed, a rest
  parameter gathers argv); a host class exposes only its API's members.
  `shape.c` finds a layout from a header by binary search.
- `emitDynAnyMemberGet`/`Set` fall back to the layout for a tag-6 object;
  adding an own property to a fixed layout throws Node's "Cannot add
  property x, object is not extensible".
- `{ ...o }` of a boxed static object copies its own fields
  (`__kml_shape_spread`).

## Implementation notes

`codegen/llvm/objheader.go` (new), `emit_shape.go` (new),
`shapesrc/shape.c` (new), `types.go` (`ObjectType`, `UserFields`,
`hostObjectType`, `VisibleFields`), `emit_stackalloc.go`, `emit_dynobj.go`,
`emit_dynamic.go`, `embedded_c.go`, and the fixed-offset readers in
`emit_abort.go`, `runtime_fetch.go`, `runtime_http.go`, `emit_fs.go`
(statfs), `emit_cluster.go`, `emit_dns.go`, `emit_net.go`,
`runtime_dgram.go`, `emit_worker.go`, `emit_chan.go`,
`emit_exprs_member.go`. A synthesized routine uses `beginDetachedFunc`
(`funcstate.go`), which resets every per-function field an enclosing
async/generator/loop body had set — the dynamic-function emitters now use it
too (an arrow compiled as a dynamic function inside an `async` function
inherited its coroutine return label).

## Side effects discovered

- `@value` flat arrays keep each element's header (24 bytes per two-field
  element): a boxed element view is then a valid object. Headerless value
  data is a perf follow-up.
- Host classes other than `AbortSignal`, `AbortController` and `Stats`
  are still headerless (BACKLOG: host layouts).
- An own property added to a static layout throws instead of being added
  (JS extends the object): BACKLOG.
- `x as any` stays an erasure (ADR-00371): boxing there would route host
  objects through shapes they do not have yet.
