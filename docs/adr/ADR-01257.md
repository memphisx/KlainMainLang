# ADR-01257: `async_hooks` in TypeScript

- **Relations**: `Implements TDD-00230`, `Extends ADR-00678, ADR-00679, ADR-00680, ADR-00782`
- **Date**: 2026-09-29

## Context

`AsyncLocalStorage` and `AsyncResource` were code-generated host handles:
- the context was a list of (instance id, value) frames;
- `snapshot()` was a compile error;
- `runInAsyncScope` ignored `thisArg`;
- a throwing `run` callback left its frame installed.

A TypeScript module (`diagnostics_channel`'s `bindStore`, ADR-01254) could
not call a host handle through `any`.

## Decision

`lib/node/async_hooks.ts` ports Node v24's AsyncContextFrame-based
`AsyncLocalStorage` and lib/async_hooks.js's `AsyncResource`:
- The current frame is a `Map` from each store to its value. `run` installs
  a copy with the store set and restores the prior frame in a `finally`.
  `getStore` reads the frame, else the `defaultValue` option.
- `bind`/`snapshot`/`AsyncResource.bind` capture the frame and replay it
  through `runInAsyncScope`.
- `asyncId()` numbers resources in creation order. `createHook` and
  `executionAsyncId` are not ported.

The runtime keeps the frame where it kept the old list head: the task's
context slot, inherited at spawn, and carried to a timer's fire. Promise
reactions and `queueMicrotask` callbacks now carry it too. Each is a
no-argument closure like a timer's, so the same wrapper captures the frame
where it is registered. It holds
the frame as an `any` word (`asyncContextGet`/`asyncContextSet` in
lib/native.d.ts). The native call boundary now carries `any`: a lowered
parameter or result of type `any` is the NaN-boxed word. Timer callbacks
are wrapped when the program has the module (its `AsyncLocalStorage`
export).

The code-generated handles, their methods, `new` special cases and the
resolver's virtual module are deleted.

## Side effects discovered

The port needed several compiler fixes, recorded in ADR-01258 to ADR-01262:
- generic class statics and instance annotations;
- `this` aliases;
- captured handles in branches;
- nullable collections and generic `T | undefined`;
- rest-closure conversions.

An erased generic method's `R` result is unboxed to the class instance
the checker types it as (`als.run(v, () => new AsyncResource('r'))`), as
class results already were.

`queueMicrotask` now takes the callback shape timers take: called with no
arguments, its result dropped.

## Verification

Mac (Apple Silicon), against Node v24.19:
- a probe of run/exit/enterWith/disable, name/defaultValue, bind/snapshot,
  AsyncResource, `await` and timers is identical to Node;
- the `AsyncLocalStorage` tests pass, the snapshot rejection test is replaced
  by `TestE2EAsyncLocalStorageSnapshotAndOptions`, and
  `examples/async/async_local_storage.ts` matches Node.
