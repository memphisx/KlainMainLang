# ADR-00831: `Math.max()`/`Math.min()` accept any arity (0 and 1 args)

- **Relations**: Extends [ADR-00286](ADR-00286.md) (the min/max fold)
- **Date**: 2026-09-10

## Context

A quick-fix pass found `Math.max`/`Math.min` rejecting the zero-arg and one-arg
forms with a compile error ("expects at least 2 arguments"), while Node accepts
any arity: `Math.max()` → `-Infinity`, `Math.min()` → `+Infinity` (the reduction
identities), and a single argument returns `ToNumber(arg)`. A real parity gap,
not a deliberate divergence.

## Investigation

`emitMathMinMax` (`emit_call_math.go`) guarded `len(args) < 2`. The spread path
(`emitMathMinMaxSpread`) already handled an empty fold with the right seeds
(`0xFFF0000000000000` = -Infinity for max, `0x7FF0000000000000` = +Infinity for
min), so the identity values were already established. The ≥2 fold starts from
`vals[0]` and loops over `vals[1:]`, so a single argument already returns
`vals[0]` correctly once the guard is lifted — only the 0-arg case needed an
explicit identity. `inferExprType`'s `min`/`max` case returned `TypeI64` by
default, which would mismatch the 0-arg double result.

## Decision

- `emitMathMinMax`: replace the `< 2` error with a 0-arg special case returning
  the double identity (`-Infinity` for max, `+Infinity` for min, materialized via
  `fadd <seed>, 0.0`). The existing ≥1 fold handles one argument unchanged
  (empty tail loop returns the lone coerced value: `i64` for an int arg, `double`
  for a float arg — consistent with the ≥2 behavior).
- `inferExprType`: `min`/`max` with zero args returns `TypeF64` (the ±Infinity
  identity), mirroring the emit site; ≥1 keeps the existing float-promotion rule.

## Implementation notes

`emit_call_math.go` `emitMathMinMax`; `emit_exprs_types.go` `min`/`max` case.
The Math status row drops its only caveat (arity), becoming a clean row.

## Verification

macOS (Apple Silicon M4): repro matches Node — `Math.max()`=-Infinity,
`Math.min()`=Infinity, `Math.max(5)`=5, `Math.min(42)`=42, `Math.max(3,7,2)`=7,
`Math.min(3.5,1.2)`=1.2. New `TestE2EMathMinMaxArity` + `go test -run
'TestE2EMath|TestE2ENumber'` green.
