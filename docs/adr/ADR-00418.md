# ADR-00418: Node oracle — the "dynamic require" label was mostly wrong

- **Relations**: Extends ADR-00409, [TDD-00121](../tdd/TDD-00121.md); relates to [ADR-00369](ADR-00369.md) (static CommonJS require)
- **Date**: 2026-08-28

## Context

The gap analysis carried a ~336-file skip bucket labeled "residual dynamic
require() — genuinely out of scope." A review of the actual files showed the
label was doing the classic aggregate-hiding: the transform's line-level
regexes only recognized three require shapes, and everything else — however
static — fell into one undifferentiated "dynamic" bin. Static CommonJS
require is a supported language feature (ADR-00369); calling these files out
of scope contradicted the project's own docs.

## Investigation

A form histogram over the bucket (first made possible by giving the skip
reason the offending statement text) decomposed it:

- `const spawn = require('child_process').spawn` — **member-off-require**,
  ~150 uses: fully static.
- Bare side-effect `require('worker_threads');` etc. — ~82: static, and a
  no-op for builtin modules.
- `require('…')` **inside embedded worker-source template strings** — a large
  share of the "bare" bin: string *content*, not code at all; the dynamic
  scan matched inside quotes.
- Genuinely dynamic (`require(fixtures.path(…))`, `require(m)()`, relative
  test-file loads, `util.debuglog(…)` call-bindings): the honest residue.

## Decision

- **Skip reasons must name the concrete blocker**: the residual-require skip
  now quotes the first unhandled statement (`unhandled require form: …`), so
  an aggregate label can never hide a bucket like this again. Recorded as a
  standing rule in the gap analysis.
- **Member form**: `const X = require('m').prop` → a named import (aliased
  when the binding name differs); an unknown member then fails honestly at
  the resolver's member validation. Ambient modules use a small
  member→global table (`events.EventEmitter`, `buffer.Buffer`, `url.URL`,
  the `timers` functions).
- **Bare side-effect requires** of supported/ambient/shimmed modules are
  dropped (no observable effect); of unimplemented real modules they FAIL as
  MODULE_NOT_IMPLEMENTED like every other reference (consistency with
  ADR-00409).
- **String-aware dynamic scan**: `stripQuoted` blanks quoted/template
  contents (escape-aware, the coalescer's own tokenizer rules) before the
  residual-require check, so embedded worker source can't fail the file.
- `NODE_SKIPLIST` env dump added alongside `NODE_FAILLIST` — per-file skip
  reasons for triage.

## Implementation notes

`tools/conformance/node.go` only; no compiler changes. Bucket: 353 → 157
files, each remaining reason naming its form; totals moved to
28 passed / 2439 failed / 1011 skipped (176 more files honestly attempted).

## Side effects discovered

- The remaining ~157 include a few mechanically-shimmable stragglers
  (`util.debuglog` bindings could become no-op closures; `NAME =
  require('m').prop` reassignments into pre-declared `let`s) — left with
  named reasons for a future pass.

## Verification

`go test ./tools/conformance` passes; full `-suite=node` re-run regenerated
the report; the new skip-reason table shows named forms only (Mac). No
compiler code touched, so the E2E suite is unaffected.
