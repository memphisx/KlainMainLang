# ADR-00356: Discriminated unions (tagged object unions)

- **Relations**: Implements [TDD-00116](../tdd/TDD-00116.md); extends [TDD-00115](../tdd/TDD-00115.md) (object union members), [TDD-00114](../tdd/TDD-00114.md) (narrowing)
- **Date**: 2026-08-25

## Context

[TDD-00115](../tdd/TDD-00115.md) allowed one object member in a union; two-plus
were deferred because `typeof` can't distinguish them. Discriminated unions —
`{ kind: "circle"; r } | { kind: "square"; s }` narrowed by `s.kind === "..."` —
are the idiomatic way to carry multiple object shapes, and the natural completion
of the object-union work.

## Decision

**Literal types carried into the resolved `Type`.** `resolveType` now returns a
string-literal type as `Type{IR: "ptr", IsStrLiteral: true, LitValue: v}` — still
string-shaped at runtime, with the literal as compile-time metadata for
discriminant matching (previously it collapsed to plain `string`,
[TDD-00079](../tdd/TDD-00079.md)).

**Discriminated union = ≥2 object members with a shared tag.**
`validateUnionMembers` allows ≥2 object members when `unionDiscriminant` finds a
common **first-position** field (same name, string-literal type, distinct value
per member); otherwise the one-object-member rule / rejection stands. All members
box unchanged as tag 6 + pointer.

**Discriminant read on the un-narrowed union.** `s.tag` (only the discriminant,
V1) unboxes the pointer and loads field 0 (a string) — the same offset in every
member. Any other field on an un-narrowed union is a clean rejection ("narrow it
first").

**Narrowing.** The narrowing seam ([TDD-00114](../tdd/TDD-00114.md)) gains a
`x.tag === "lit"` guard (`discriminantNarrowing`): the true branch narrows `x` to
the member whose discriminant value is `"lit"`, the opposite branch to the rest
(concrete if one remains). `emitUnboxBoxToType` recovers that member's typed
pointer, so member-specific fields work — in `if`/`else`, `else if` chains, and
after an early return.

## Scope

- **In:** ≥2 object members sharing a first-position string-literal discriminant;
  `s.tag` read; `s.tag === "lit"` narrowing (if/else + early return); member
  fields after narrowing.
- **Out (deferred):** number/boolean-literal discriminants; a discriminant not in
  first position (per-member offset lookup); `switch (s.tag)` narrowing (the
  if-chain is the V1 form); exhaustiveness (`never`) checking; mixing scalar and
  object members.
