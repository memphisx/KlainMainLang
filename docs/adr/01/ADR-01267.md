# ADR-01267: Writes and TypedArray `instanceof` on an `any` array

- **Relations**: `Extends ADR-01059`
- **Date**: 2026-09-29

## Context

Through an `any` holding a static array, `a[i] = v` threw "Cannot set
properties of a non-object value", and `x instanceof Uint8Array` was a
compile error for every TypedArray.

## Decision

- `__kml_anyarr_set_by_key` (dynjson.c) stores an indexed write into the
  boxed array's storage, converted to its element kind. Past the end a
  plain array grows, and a TypedArray ignores the write, as in JS.
- The TypedArray constructors join `instanceof`. A static TypedArray
  answers from its element kind; a boxed one asks its box
  (`__kml_anyarr_typed_is`). A Buffer is a `Uint8Array`.

A grown `number[]`'s gap reads as 0 where Node has a hole, since typed
storage has no holes.

## Verification

Mac (Apple Silicon): writes and TypedArray/Buffer `instanceof` match
Node.
