# ADR-01264: An `any` holding a static array reads as `any[]` element by element

- **Relations**: `Extends ADR-01059`
- **Date**: 2026-09-29

## Context

`const a: any = buffers; for (const c of a as any[]) …` gave empty
Buffers, where indexing `a[i]` and iterating `a` directly worked. Unboxing
an `any` to `any[]` reused the boxed array's header, so the elements were
read as NaN-boxed words. They were not: a `Buffer[]` holds array header
pointers.

## Decision

Unboxing to an `any[]` reads a boxed static array through
`__kml_anyarr_words` (dynjson.c):
- its own header when the elements already are words;
- else a fresh header whose elements are boxed as an index read boxes
  them (`kj_elem_box`), nested arrays included.

## Verification

Mac (Apple Silicon): a `Buffer[]` through `any` and `as any[]` iterates and
indexes as in Node; `dgram`'s queued sends (ADR-01263) carry their data.
