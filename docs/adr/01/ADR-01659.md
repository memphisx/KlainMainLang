# ADR-01659: Builtin constructor statics through a value, Node's Buffer fill, Array.from thisArg

- **Relations**: Implements [TDD-00230](../../tdd/TDD-00230.md) (P3.3, found while probing the builtin-constructor shadow rows of [ADR-01658](ADR-01658.md))
- **Date**: 2026-10-16

## Context

A builtin constructor held in an `any` read none of its statics:
`const A: any = Array; A.isArray([])` threw "isArray is not a function", as
did `N.isInteger` with `const N: any = Number`. `const B: any = Buffer`
failed to compile ("undefined variable 'Buffer'"). Making those statics
function values exposed three more gaps, each a compile failure of the
static's widest declared signature: `Array.from` rejected its third
argument, `thisArg`; `Buffer.from(x, a, b)` with an `any` first argument
was rejected; `Buffer.alloc` rejected `encoding`. Probing `buf.fill` then
showed it diverged from Node: an `any` string fill ignored its encoding,
`fill("")` left the buffer unchanged (Node zero-fills), a negative or
out-of-range offset was clamped (Node throws `ERR_OUT_OF_RANGE`), a string
fill with an encoding did not compile, and a filled Buffer printed as an
array, since the result was a fresh header of the element type.

## Investigation

- A builtin constructor in value position is a constructor reference
  (`kmlTagFuncRef`) whose row has a construct thunk but no static get, so
  `__kml_classref_get` answered only `length`. `Buffer` was not among the
  names boxed this way.
- `Number`, `String`, `Boolean` and `Symbol` by value are their call
  signature's intrinsic function (`ensureBuiltinFunc`), a function box whose
  property read finds only an own-property bag.
- `builtinRef` needs the checker's answer for the member expression, which a
  synthetic `Array.isArray` built at finalize does not have.
- Node's `Buffer.prototype.fill` is `_fill(buf, value, offset, end,
  encoding)`: a string value takes a string offset or end as its encoding
  and an empty string as 0, the offsets go through `validateOffset`, and the
  binding fills a view's bytes or `ToUint32(value) & 255`. `Buffer.alloc`
  calls `_fill(buf, fill, 0, length, encoding)`.

## Decision

- A library global declared as a constructor object (`declare var Buffer:
  BufferConstructor`) in value position is a constructor reference too.
- Each builtin constructor reference's row gets a static get thunk built
  from its declaration's properties: an intrinsic method is its function
  value (`intrinsicBuiltin`, split out of `builtinRef`), a property is read
  as written (`Number.MAX_SAFE_INTEGER`), and anything else reads undefined.
- A function box with no own property falls back to
  `__kml_fn_static_get` (fnmeta.c), which looks the function's identity up
  in a unit table (kind 9) of `{identity, static getter}` rows, one per
  builtin constructor used by value, and reads that constructor's statics.
- `Array.from(src, mapFn, thisArg)` maps with `mapFn.call(thisArg, v, i)`,
  each argument evaluated once in order; an `any` mapFn that is undefined
  does not map, as the spec reads a missing mapFn. `receiverTemp` now spills
  an array to a temporary like any other value (the single array shape makes
  it one register).
- `Buffer.from` with an `any` first argument and three arguments dispatches
  at run time on whether the value is an ArrayBuffer.
- `buf.fill` and `Buffer.alloc(n, fill, encoding)` go through one C routine,
  `__kml_buf_fill_any` (buffill.c, its own runtime member), over the boxed arguments with Node's
  reading and messages; codegen throws the coded error it reports. `fill`
  returns its receiver.

## Implementation notes

`emit_classref_rows.go` (`emitHostRefGetRows`, `hostStaticGetter`,
`hostStaticKeys`, `registerFnStatics`), `fnmetasrc/fnmeta.c`, `unitreg.go`, `emit_exprs.go`
(`isLibConstructorValue`, a recursion guard while a row is emitted),
`emit_intrinsics.go` (`intrinsicBuiltin`, `builtinFn.ctor`),
`emit_dynobj.go`, `emit_arrays_iter.go` (`emitArrayFromMaybeMapped`),
`emit_call.go`, `emit_buffer.go` (`emitBufferFill`, `emitBufferFillBoxes`),
`buffillsrc/buffill.c`, `buffill_c.go`, `embedded_c.go`. The getters and
the dispatch avoid IR-text definitions (the IR-text ratchet).

## Side effects discovered

`TestE2EBufferStringFill` expected `fill("")` to leave the buffer unchanged;
Node zero-fills, and the expectation is corrected.

## Verification

`TestE2EBuiltinConstructorStaticsThroughAny` and
`TestE2EBufferFillNodeArguments` (every argument form and each of the seven
error cases) compare with Node; the Buffer, typed array, builtin value,
constructor, class value and function property suites pass (Mac).
