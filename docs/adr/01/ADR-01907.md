# ADR-01907: `Response.json()` is its promise wherever it is read

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-21

## Context

- A declaration's `await r.json()` emitted its await without marking the enclosing callable as waiting, so an async arrow doing it was compiled as a plain closure and aborted ("a wait outside a coroutine").
- A declaration initialized from an un-awaited `r.json()` parsed the body synchronously into the declared type; Node gives the promise. The deep-free rule likewise took an un-awaited `r.json()` binding for a freshly parsed graph and freed the promise, so a `.then` attached later (from a timer) never ran, and in the js lane a `.then` after reading the binding never ran either.

## Decision

- The declaration's `await r.json()` marks the callable as waiting, as every await does.
- An un-awaited `r.json()` is its promise in a declaration as anywhere else, and the deep-free rule takes only the awaited form; the synchronous declaration parse is removed.

## Consequences

- `r.json()` behaves as Node's in every position.
