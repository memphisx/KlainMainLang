# ADR-01736: An `any` bag as a structural value, `this` in method shorthands, literals a hint cannot hold, sanitizer-lane fixes

- **Relations**: `Implements TDD-00230`, Extends [ADR-01735](ADR-01735.md), Extends [TDD-00233](../../tdd/TDD-00233.md)
- **Date**: 2026-10-19

## Context

- **An `any` object converted to a structural type was copied** into the type's layout. The copy lost the object's identity, its other keys and their order, and converted a member of another kind to the declared one: `{ shell: true }` read through `{ shell?: string }` answered `typeof o.shell === "string"`, and a string for an array member threw "the value is not an array". `JSON.parse` into `P[]` threw the same error when assigned to a member, and failed to compile when `P` had a function member.
- **`this` in a method shorthand** was a compile-time rejection unless the literal's contextual type gave the method a `this: T` parameter ([ADR-01158](ADR-01158.md)), where TypeScript types it as the literal and JavaScript binds the receiver.
- **`JSON.stringify` of a static object** wrote a function-valued property as `""`; one holding a `this`-taking function crashed.
- **js lane:** a literal whose property the parameter's type cannot hold (`new Worker(f, { argv: 'foo' })`) was built in the parameter's layout, which threw that bare TypeError. Node's library throws `ERR_INVALID_ARG_TYPE` for `options.argv`, which our library did not check.
- **`-optimize-memory`:** a function returning `[number, number] | null` took the by-value tuple ABI, which has no null, and `return null` failed to compile.
- **The first sanitizer-lane run:**
  - most programs failed to link: UBSan's vptr check needs the C++ runtime;
  - every sort failed under `-fsanitize=function`, which checks calls into IR-emitted comparators;
  - `atob`/`decodeURIComponent` errors overflowed the heap: `encoding.c` built a 24-byte error, and the throw path reads the frames and stack slots;
  - the localtime helper negated `INT64_MIN`;
  - the stack-overflow tests failed: the guard is off in sanitizer builds.
  - Failures printed no program stderr.

## Decision

- **A bag is a structural value.** `emitAnyToLayout` returns a dynamic bag itself for a structural target.
  - `emitRecordForeign` treats a bag header as foreign, so every member read, write and split (`emitRecordSplit`) goes by name.
  - A structural value boxes as what it is (`emitBoxRecordPtr`): tag 10 for a bag, 6 otherwise.
  - The shape runtime (`__kml_shape_get/set/nkeys/key`) answers a bag through the bag API (weak references), so the layout consumers (`Object.entries`, inspect, JSON) take bags unchanged.
  - The operations that answered from the static layout now split on a foreign object: `in`/`hasOwnProperty`, `delete` of an optional member, and `typeof` of a member (the held value answers).
  - A literal spreading a structural value builds a bag when any source is foreign or has expandos (`emitRecordSpreadLiteral`), so the source's own keys and order are copied as JavaScript copies them.
  - A dynamic array converts to an array of a structural type element by element (`emit_narrowing.go`).
- **A method shorthand reading `this`** (a `this` of its own, not a nested function's) without a `this` parameter takes an implicit `this: any` (`maybeAddThisParamExpr`). A literal's field is then a `this`-taking function, so `o.m()` passes `o`, and the body reads the receiver by name, whatever object it is. A bare call passes undefined, which a sloppy-mode file turns into `globalThis` (`emitSloppyThis`). A contextual `this: T` still types the receiver (`emitThisTakingClosure` replaces the implicit parameter).
  - Stored into an interface's method slot (a function type without `this`), the method is its boxed function behind a thunk (`emitAnyToClosure`). A member call through such a slot checks for that thunk (its env's first word `@__kml_d2s_env`) and calls the boxed function by name with the object as its receiver; any other function is called directly (`emitFuncFieldCallReceiving`). Arguments are evaluated once, before the branch.
  - A member read whose type the checker leaves `any` takes the layout's member type when the layout holds a function (`objectFuncFieldRule`).
- **`JSON.stringify`** skips a static object's function-valued properties, as it skips them in JavaScript.
- **A library unit that fails to compile** keeps its `.ll`, named in the error.
- **`JSON.parse` projection** of a member JSON cannot spell (a function, a host value) converts the parsed value as from `any`.
- **A literal a structural hint cannot hold** (an array where the slot is not one, or the reverse) keeps its own layout (`literalFitsLayout`), which the structural type reads by name. `Worker` checks `options.execArgv` and `options.argv` as Node does (a truthy non-array throws `ERR_INVALID_ARG_TYPE`).
- **A nullable tuple keeps the pointer ABI** (`tupleByValEligible`).
- **Sanitizer lane:**
  - `-fno-sanitize=vptr,function`;
  - `encoding.c` allocates a whole error (`KML_ERR_SIZE`, behind `kml_layout.h`);
  - the localtime helper floors without negating;
  - the stack-overflow tests skip under `KLAIN_TEST_SAN`;
  - a failed run prints the program's stderr (`exitStderr`).

## Verification

macOS (Apple Silicon), against Node:

- `tests/structural_view_test.go` TestE2EStructuralViewOfAnyBag;
- `tests/objects_test.go` TestE2EObjectLiteralMethodShorthandThis (replaces the rejection test): the receiver through the object, another object, `call`/`bind`, an interface slot and an array element; a bare call's TypeError; `JSON.stringify` and `Object.keys` of a literal with methods. A sloppy `.js` file's bare call reads `globalThis`;
- `tests/jsmode_test.go` TestE2EJSModeLiteralContradictsParam now compares Node's code and message;
- the structural-view, JSON, spread, `in`, `delete`, `Object.keys/values/entries`, typeof, js-mode, literal, Worker, stream, EventEmitter and `this`-parameter families pass;
- `TestE2EGenericFromCallbackReturnAndTupleAssignment` passes under `KLAIN_TEST_OPTMEM=1`.

Linux (Node304 `kmlbox`): the sort, date, `atob` and querystring sanitizer cases pass.
