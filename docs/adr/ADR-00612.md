# ADR-00612: Run pending `finally` blocks on an async `return`

- **Relations**: Completes the abrupt-completion `finally` handling of [ADR-00172](ADR-00172.md) (generator return) for async functions
- **Date**: 2026-09-01

## Context

A `finally` block runs on an early `return`/`break`/`continue` in a regular
function, and — after [ADR-00172](ADR-00172.md) — on a generator `return`. But an
early `return` inside a `try/finally` in an **async** function skipped the
finally entirely. `break`/`continue` were already correct (they go through the
shared `emitBreak`/`emitContinue`, which unwind pending finallys to the loop
depth); only the async `return` path diverged.

The cause: `emitReturn`'s `if e.isAsync` branch evaluated and stored the return
value into the coroutine's promise-result slot, then branched straight to
`coroRetLabel` — never calling `emitPendingFinallys`. Every non-async return path
in the same function called it before its `ret`.

## Decision

Call `emitPendingFinallys()` in the async return path, **after** the return value
is stored into `coroHdl` and **before** the `br` to `coroRetLabel` — matching JS:
the return value is computed at the `return`, then the enclosing `finally` blocks
run (innermost first), then the function settles.

The finally bodies are re-emitted inline by the existing
`emitPendingFinallys`/`emitFinallysToDepth` mechanism, in the same block context
the normal fall-through finally uses — so a finally containing `await` (or a
nested `try`, or its own `return` that overrides the pending one via the
`blockDone` rule) works with no new machinery.

## Verification

`TestE2EAsyncFinallyRunsOnReturn` (finally runs on an async `return`),
`TestE2EAsyncFinallyAwaitAndOverride` (the finally awaits and its own `return`
overrides), and `TestE2EAsyncNestedFinallyOnReturn` (innermost-first) — all
matching Node v26. Async `break`/`continue` with finally, and generator
`return`/`continue` with finally, were already correct and remain so. The async,
await, promise, try/finally, and generator suites still pass. Built and verified
on Mac (Apple Silicon).
