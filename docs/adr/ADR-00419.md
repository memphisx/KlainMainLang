# ADR-00419: The node:test runner — test/describe, TestContext, hooks

- **Relations**: Implements [TDD-00140](../tdd/TDD-00140.md); Extends [TDD-00122](../tdd/TDD-00122.md) (test builtin), [ADR-00412](ADR-00412.md)
- **Date**: 2026-08-28

## Context

TDD-00140: `node:test` was a 60-file oracle block and — the real motivation —
the missing piece for writing native unit tests with this compiler, portable
with Node.

## Decision

Implemented per the TDD, all V1 surface:

- **Run-at-registration** with each body inside a setjmp exception frame
  (the same structure `emitTry` emits): a thrown assertion marks the test
  failed with the error's `.message` and execution continues. Async bodies
  complete inline (the established inline-async posture).
- `test`/`it` (name?, opts?, fn — `{ skip, todo }` honored, `concurrency`/
  `timeout` accepted no-ops), `describe`/`suite` (compile-time name-prefix
  stack → `group > name` reporting), module `before` (runs now), `after`
  (closure list run by the exit sink), `beforeEach`/`afterEach` (one slot
  each, last wins — disclosed).
- **TestContext** via the contextual-typing mechanism (`__kml_test_ctx`):
  `t.test` (subtest, own context), `t.after` (runs after the body, pass or
  fail), `t.skip`/`t.todo` (mark; body continues, reported `# SKIP`/`# TODO`
  instead of pass), `t.diagnostic` (`# `-prefixed stderr note);
  `t.beforeEach`/`t.plan` accepted no-ops.
- **Reporting**: TAP-shaped lines (`ok - name` / `not ok - name: msg`), an
  exit-sink summary (`tests N, pass P, fail F, skip S`) that exits non-zero
  when any test failed — composed with the mustCall verifier in the same
  sink, node:test summary first.
- **Module identity**: the runner members join the existing `test` builtin
  (TDD-00122); and the resolver now accepts **`node:`-prefixed specifiers
  for every Node-named virtual module** (an `init()` aliasing pass), which
  the runner surfaced as a general prerequisite — `import fs from 'node:fs'`
  works everywhere now.

## Implementation notes

`runtime_nodetest.go` (counters, closure lists, summary),
`emit_nodetest.go` (runner emitters + TestContext dispatch),
`emit_testmod.go` (member routing), `types.go` (`IsTestContext`,
`__kml_test_ctx`), `runtime_process.go` (exit-sink composition),
`resolver/virtual_modules.go` (`node:` aliases + runner members),
`tools/conformance/node.go` (`test` now a supported module).
One ordering subtlety: a `describe` body's `test()` calls emit while the
closure is being *resolved*, so the name prefix pushes around resolution,
not around the call.

## Side effects discovered

- `beforeEach` also fires for subtests (Node scopes hooks per-suite) —
  disclosed as a caveat with the single-slot simplification.
- Top-level code textually after a `test()` runs after that test here,
  before it in Node — the run-at-registration divergence, disclosed.

## Verification

Four new E2E tests (`tests/nodetest_test.go`): full passing flow with
groups/subtests/`t.after`, failure → non-zero exit with subsequent tests
still running, skip/todo + hooks interplay, async bodies — all pass. New
example `examples/testing/unit_tests.ts` compiled and run. Node oracle +
full `make test-par` re-run (Mac).
