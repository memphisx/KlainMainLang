# ADR-01662: Codegen's Type carries one host class, one representation kind and one absence

- **Relations**: Implements [TDD-00230](../../tdd/TDD-00230.md) (P3.4)
- **Date**: 2026-10-16

## Context

TDD-00230 P3.4 turns codegen's `Type` into a lowering type: its `Is*` flags
go, host classes are identified by declaration rather than by a flag, and
the representation comes from one closed set. `Type` carried 42 boolean
`Is*` flags. Each named either a builtin host class (`IsDate`, `IsMap`,
`IsResponse`, … 28 of them) or a representation (`IsArray`, `IsObject`,
`IsFunc`, `IsDynamic`, …), and nothing kept two of them from being set at
once.

## Investigation

- Across every composite literal, only related flags were ever set
  together: Map with DynamicObject, ArrayBuffer with SharedArrayBuffer,
  Object with Tuple. Assignments added Buffer over TypedArray and Class
  over Object. Each pair is a derived host or kind answering its base's
  question as well (a Buffer is a Uint8Array).
- `IsUndefined` is not a kind. It is the null-vs-undefined flavour of a
  nullable type, or of the null literal's type. Every write sets it
  together with `Nullable` or on the null literal, so with `Nullable` and
  `NullAndUndef` it describes one of four absence states: none, null,
  undefined, both.
- `IsNullProtoObject` was never set; its three reads were dead.
- Two places read the flags by field name through reflection:
  `hostClassName`/`hasHandleFlag`, which try the flags in declaration
  order, and the shadow comparison's representation key.

## Decision

- `Type.Host` (a `hostKind`, `host_kind.go`) names the builtin class a
  value is an instance of, `hostNone` otherwise. The 28 host flags are
  predicates over it (`t.IsDate()`). A derived host (Buffer,
  SharedArrayBuffer, DynamicObject) answers its base's predicate as well.
  `setHost(h, on)` keeps a derived host when its base is marked again, and
  leaves the base when the derived host is unmarked.
- `Type.Kind` (a `reprKind`, `repr_kind.go`) names the representation:
  array, flat array, object (tuple and class instance derived from it),
  closure (the promise resolver derived from it), the NaN-boxed `any`,
  never, a caught value, the null literal, a string literal. Scalars and
  strings are `kindNone`, told apart by IR.
- Under `KML_KINDCHECK`, `setKind` panics on a write that would replace an
  unrelated kind, i.e. a type that would have carried two representation
  flags at once.
- Each flag's documentation moved to its constant. `typeFlagOrder` keeps
  the declaration order the reflective readers relied on, and `typeFlag`
  answers a predicate by name.
- `Type.Absent` (an `absence`, `absence.go`) replaces `Nullable`,
  `IsUndefined` and `NullAndUndef`: `absNone`, `absNull` (`T | null`),
  `absUndef` (`T | undefined`), `absBoth` (the three-state
  `T | null | undefined`). The undefined literal's type is `kindUndefined`,
  derived from `kindNull`. The three old names are predicates. Their
  setters keep the old write order's meaning, and `absenceOf` builds a
  literal's state. Under `KML_KINDCHECK` a state the old flags allowed but
  absence cannot hold (undefined on a non-nullable type, a null-only
  three-state) panics.
- `IsNullProtoObject` is deleted.

## Implementation notes

The rewrite was mechanical:

- field reads became predicate calls;
- `IsX: true` in a literal became `Host:`/`Kind:` with the most derived
  value;
- `t.IsX = v` became `setHost`/`setKind`, and the absence fields'
  writes `setNullable`/`setUndefined`/`setNullAndUndef`;
- the compiler's own errors identified the same-named fields of other
  structs (AST nodes, generic positions), which were left alone;
- multi-target assignments involving a flag were split first.

Symbol names hashed from a printed `Type` (one per program at most) change,
since the printed struct changed.

## Side effects discovered

- `a && b` / `a || b` over two pointers copied `Nullable` and `IsUndefined`
  from the chosen side but kept the left side's three-state bit. The result
  was a three-state type that was not undefined, a state no other code
  produces. The result now holds the chosen side's absence; a three-state
  left side makes it three-state only under `&&`, which can yield that
  falsy side (`||` yields the left side only when present). The one
  library site this touched (`destroyError || error` in `node:stream`'s
  `pipeline`) keeps boxing its null as null.

## Verification

- IR byte-identical on the 68-file corpus after each stage, apart from
  the hashed symbol names; no `KML_KINDCHECK` panic on the corpus or the
  E2E suite.
- `go test` of every unit package; test-par on the Linux boxes.
