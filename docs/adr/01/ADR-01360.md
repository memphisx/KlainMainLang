# ADR-01360: A typed array's `constructor` is its builtin

- **Relations**: Extends TDD-00018
- **Date**: 2026-10-03

## Context

`u.constructor.name` for a `Uint8Array` failed codegen with "field access on
non-object". Found while porting Blob to TypeScript.

## Investigation

A class instance's `constructor` is handled (`emitConstructorOf`); a typed
array, an array aggregate, reached no such case. A builtin constructor used as
a value is a constructor reference: a `kmlTagFuncRef` box of its interned
name, which `===`, `.name` and `new` already understand.

## Decision

A typed array's `constructor` is the constructor reference of its builtin
(`typedArrayConstructorName`), and `Buffer` for a Buffer. Its type is `any`.

## Implementation notes

`codegen/llvm/emit_exprs_member.go` and `emit_exprs_types.go`.

## Verification

Mac (Apple Silicon), against Node 24: `.name`, `=== Uint8Array`, a Float64Array
and a Buffer, and `new` through the reference
(`TestE2ETypedArrayConstructorProperty`).
