# ADR-01252: A function-typed top-level binding is a module global

- **Relations**: `Extends ADR-01059`
- **Date**: 2026-09-29

## Context

`let sink: ((w: any) => void) | null = null`, read from a named function,
failed with "undefined variable 'sink__kml_mod0'". The module-global
pre-pass (`decideGlobalType`) promoted annotated scalars, strings, objects
and `any`, but not function types, so the binding stayed a `main()` local
that a named function's fresh scope cannot see. It came up in the
`emitWarning` port.

## Decision

An annotated function-typed binding (nullable or not) is a module global:
one closure-header pointer slot, which the declaration and every
assignment store into.

## Verification

Mac (Apple Silicon): `TestE2EFunctionTypedTopLevelLet`, for nullable and
non-null function globals, reassignment, and reads from a named function.
