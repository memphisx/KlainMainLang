# ADR-01540: An async function's signature returns a task promise

- **Relations**: Extends TDD-00084, TDD-00230
- **Date**: 2026-10-10

## Context

Both async epilogues return a task promise, and a call to an async
function is typed as one, as is an async closure's result. A named async
function's own signature was not: read as a value (`fn`, passed or
stored), its result type lacked the task flag the call carries, and
disagreed with the checker's.

## Decision

A named async function's signature result is a task promise.

None.
