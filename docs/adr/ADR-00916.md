# ADR-00916: Captured-default polish — async, object/array slots, and `.bind` mask threading (TDD-00206 Stage 2)

- **Relations**: Extends [ADR-00915](ADR-00915.md); Implements [TDD-00206](../tdd/TDD-00206.md) Stage 2
- **Date**: 2026-09-12

## Context

[ADR-00915](ADR-00915.md) evaluates a parameter default that references a
captured variable in the closure **body prologue**, gated by a hidden
argument-presence mask. It shipped with three documented clean rejections, each
narrower than the mechanism needed to be:

- a body default on an **async** closure (`async (x, y = base) => …`);
- a body default on an **object** or **array** parameter (only a single scalar
  alloca was filled);
- `Function.prototype.bind` on a closure that carries the presence mask.

Each is an everyday shape (`const f = make(n)` returning an async or
array-defaulting closure, a bound partial application), not a Test262 exotic.

## Investigation

- The async prologue (`emitSettledAsyncPrologue`, `emit_async.go:84`) ends at the
  `async.body` label with the block open; parameter allocas and captured-variable
  cells are bound *after* it (`emit_func.go` arrow path), and the body-default
  prologue already ran after both. So the ordering the `isAsync` guard feared was
  in fact already correct — the prologue's branch/label machinery composes with
  the inline async body block. Removing the guard and compiling
  `make(base)` → `async (x, y = base)` produced correct, distinct per-closure
  results.
- An **object** parameter is bound to a single `%v_<name>` pointer alloca
  (`emit_func.go` generic param path), identical to the scalar slot — so the
  existing scalar store already fit; only the rejection predicate blocked it. A
  **tuple** parameter lands on the same pointer path.
- An **array** parameter uses the object-reference model (TDD-00127,
  `bindArrayParam`, `emit_arrays_core.go:238`): its stable slot `%v_<name>_ptr`
  holds a pointer to the `{data, len}` header, and length lives in the header, not
  a separate mutable slot. Filling it means storing a fresh header
  (`arrayArgFromAggregate`) — not a scalar store. Capturing an array *variable* is
  itself an unrelated, pre-existing rejection (`gatherCaptures`), so a reachable
  array body default references a **module global**, not a closure capture.
- `.bind` builds a forwarding trampoline (`emitBindTrampoline`) whose signature is
  `<ret>(ptr env, remaining params)`. A mask closure's original expects a trailing
  `i32` mask the trampoline neither took nor forwarded — hence the rejection. The
  reduced bound value's type is produced in two places that must agree: the
  returned `Value.Ty` (`emitFunctionBind`) and `inferExprType`'s `.bind` case
  (`emit_exprs_types.go:1499`) — a `const bf = f.bind(…)` binding's call-site type
  comes from the latter.

## Decision

Extend the Stage-2 mechanism to all three cases; keep only the genuinely
slot-less rejections.

- **Async**: drop the `isAsync` guard in `emitBodyDefaultPrologue`. The prologue
  runs unchanged inside the inline async body block.
- **Object / tuple**: allow the single-pointer `%v_<name>` slot through the
  existing scalar store path.
- **Array**: fill the object-reference header slot — store a fresh header
  (`arrayArgFromAggregate`) into `%v_<name>_ptr`. The call site already supplies
  the two `(ptr, i64)` slots for an omitted array (the empty-array default arm),
  with the mask bit left clear, so the body overwrite lands correctly.
- **`.bind`**: the bound value retains `FuncHasDefaultMask`; its parameter names
  and both default slices shift down by the bound-parameter count
  (`shiftExprOrNameSlice` / `shiftDefaultSlice`). The trampoline gains a trailing
  `i32 %dmask`, and forwards the full mask `((1<<boundCount)-1) | (dmask << boundCount)`
  to the original — bound positions are always present, remaining positions carry
  the caller's mask. The same reduced type is mirrored in `inferExprType`'s `.bind`
  case so the call-site ABI matches.

Still a clean rejection (no single overwrite slot): a **nullable-scalar** body
default (its boxed `{i1,T}` aggregate is set up separately) and a **destructured**
(`{a}` / `[a]`) body-default parameter.

## Implementation notes

- Files: `codegen/llvm/emit_func.go` (`emitBodyDefaultPrologue` rewrite, async
  guard removed, `emitFunctionBind` / `emitBindTrampoline` mask threading, two
  `shift*` helpers), `codegen/llvm/emit_exprs_types.go` (`.bind` inferred type).
- The `isAsync` parameter of `emitBodyDefaultPrologue` is gone; both call sites
  updated.
- The two-site agreement gotcha (ADR-00915) applies again: the `.bind` reduced
  type is built identically in `emitFunctionBind` and `inferExprType` — the first
  `bf(7)` repro returned the default (not the argument) until `inferExprType`
  carried the mask too.
- Array capture remains rejected by `gatherCaptures`; an array body default is
  therefore reachable only via a module global, which the prologue evaluates
  directly (not through the env).
