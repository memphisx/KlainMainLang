# ADR-00690: console/util formatting fidelity — format specifiers, undefined, Map/Set, Buffer

- **Date**: 2026-09-04

## Context

Four console/util rendering mismatches against Node.js v26 surfaced while
exercising ordinary logging:

1. **Format specifiers were not interpreted.** `console.log("%s!", "hi")`
   printed `%s! hi` instead of Node's `hi!`. The whole `%s %d %i %f %j %o %O
   %c %%` family was ignored — the format string and its arguments were just
   space-joined.
2. **`undefined` rendered as a blank.** `console.log(undefined)` printed an
   empty line (Node: `undefined`), and `console.log(null, undefined)` printed
   `null null` instead of `null undefined`.
3. **`Map`/`Set` were not inspected.** `console.log(new Map([["a",1]]))`
   printed a blank line; Node prints `Map(1) { 'a' => 1 }`, and likewise
   `Set(2) { 1, 2 }`.
4. **Buffer used the array form.** `console.log(Buffer.from("hi"))` printed
   `[ 104, 105 ]`; Node prints `<Buffer 68 69>`.

## Investigation

`emit_util.go` already implemented `util.format`'s specifier substitution for
an explicit `util.format(...)` call, but `console.log` never routed through it:
`emitConsolePrint` (`emit_call_console.go`) space-joined its arguments token by
token with no format-string awareness.

For (2), `TypeUndefined` (`types.go:2285`) is `{IR:"ptr", IsNull:true,
IsUndefined:true}`; its value is a non-null pointer to an empty interned
string, so it fell through `emitConsolePrintValueToken` to the raw `%s` ptr
path and printed blank. `null` happened to render because its pointer is
NULL and the ptr path already guards NULL → `"null"`.

For (3)/(4), `Map`/`Set` are `IsObject` but excluded from
`isInspectableObject` (`emit_inspect.go`), so they hit the default ptr branch
(garbage/blank). A Buffer is structurally a `Uint8Array` (IsArray also set —
`BufferType`, `types.go:1646`) so it went through `emitInspectArray`, which
excludes Buffer from its typed-array prefix and so produced the bare
`[ 104, 105 ]`.

`emitValueToString` (`emit_exprs_types.go:50`) already renders `IsNull` values
as `null`/`undefined` correctly, distinguishing via `IsUndefined`; the Map/Set
keys()/vals() parallel-array walk already existed for `map.forEach`/`entries`
(`mapKeysAndVals`, `emit_collections.go`).

## Decision

- **Format specifiers.** When a `console.*` call's first argument is a string
  *literal*, route through a new `emitConsoleFormatLine`: substitute
  `%s/%d/%i/%f/%j/%o/%O` from the following arguments (reusing
  `emitUtilFormatArg`), collapse `%%` to a literal `%`, treat `%c` as consuming
  its argument and emitting nothing, and leave an unmatched specifier literal.
  Arguments left unconsumed are appended space-separated with the ordinary
  per-token rendering, so object/array/Map arguments still inspect. A runtime
  (non-literal) format string keeps the plain per-token path.
- **undefined.** `emitConsolePrintValueToken` gains an early `IsNull` branch
  that renders via `emitValueToString` (which already yields `undefined` vs
  `null`).
- **Map/Set/Buffer.** New inspector routines `emitInspectMap`/`emitInspectSet`
  (`Map(N) { k => v, … }` / `Set(N) { v, … }`, empty → `Map(0) {}`) and
  `emitInspectBuffer` (`<Buffer 68 69>`, empty → `<Buffer >`), wired into both
  `emitConsolePrintValueToken` (top-level) and `emitInspectField` (nested).
  The Buffer branch is checked before the array branch since a Buffer is also
  IsArray.

## Implementation notes

- Files touched: `codegen/llvm/emit_call_console.go` (format-line path +
  IsNull/Buffer/Map/Set token branches), `codegen/llvm/emit_inspect.go`
  (`emitInspectBuffer`, `emitInspectMap`, `emitInspectSet`, and a shared
  `emitInspectCollection` body-builder + nested-field branches).
- `emitInspectBuffer` builds each hex pair with `sprintf(" %02x")` into a raw
  `malloc` buffer; that buffer is a bare C string with no length header, so it
  must be wrapped with `__kml_str_from_cstr` (via `ensureStrHeaderRuntime`)
  before `emitStringConcat`, which reads the 8-byte length prefix — passing the
  raw buffer segfaults in `__kml_str_len`. This was found the hard way in the
  first draft.
- The empty-buffer `<Buffer >` (trailing space) vs non-empty `<Buffer 68 69>`
  (no trailing space) split is a runtime `select` on the length being zero.

## Side effects discovered

None beyond the four fixed. The format path deliberately triggers only on a
string-*literal* first argument; a runtime format string is left on the plain
per-token path (a possible future extension), matching what the pre-existing
`util.format` also required. `%o`/`%O` and unconsumed inspected arguments reuse
the object/array inspector, so they inherit its existing depth cap.

## Verification

- `tests/console_format_fidelity_test.go` — five E2E cases covering specifiers,
  `%c`/`%o`, undefined, Map/Set, and the Buffer form. Pass on macOS (Apple
  Silicon).
- `examples/console/format.ts` added; output matches the annotated Node
  expectations.
- `go test ./tests/ -run 'Inspect|Console|Util|Map|Set|Buffer'` — no
  regressions (macOS).
