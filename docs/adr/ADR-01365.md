# ADR-01365: Buffer.from(arrayBuffer) is a view

- **Relations**: Builds on ADR-01351; refines TDD-00103
- **Date**: 2026-10-03

## Context

`Buffer.from(arrayBuffer[, byteOffset, length])` copied the bytes. Node
returns a view that shares them. This was a caveat on the Buffer row, kept
because typed arrays could not name their buffer.

## Investigation

A typed array's data pointer already aliases its buffer's bytes for
`new Uint8Array(buffer, …)`. With the view registry (ADR-01351), a Buffer
pointing at the buffer's data also answers `.buffer` and `.byteOffset`.

## Decision

The one-argument form, the range form and the dynamic (`any`) form point the
Buffer at the buffer's bytes, at the offset, and register the view. A
SharedArrayBuffer is registered as shared.

## Implementation notes

`codegen/llvm/emit_buffer.go`; `emitRegisterView`/`emitRegisterViewDyn` in
`emit_arraybuffer.go`.

## Verification

Mac (Apple Silicon), against Node 24: writes visible through the buffer,
`.buffer` identity, offset and length for all three forms, and a
SharedArrayBuffer's buffer (`TestE2EBufferFromArrayBufferIsAView`); the
Buffer group.
