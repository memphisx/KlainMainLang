# ADR-00415: http2 Stage 2 — core streams API + Map bracket access

- **Relations**: Implements [TDD-00139](../tdd/TDD-00139.md) Stage 2; Extends [ADR-00414](ADR-00414.md), [ADR-00357](ADR-00357.md)
- **Date**: 2026-08-27

## Context

Stage 1 left the http2 corpus failing on its dominant server shape:
`server.on('stream', (stream, headers) => …)` (~45 files' first blocker,
156 files total use it). The TDD's premise held: the synchronous
handler-in/response-out bridge to the nghttp2 driver means the streams API is
mostly an emitter-level dispatch variant, not new session machinery.

## Decision

- **Stream mode dispatcher**: `server.on('stream', cb)` (on the shared server
  handle, filling the same pending-handler slot as `'request'`) builds the
  dispatcher in a new `httpStreamMode`: the request's headers map gains the
  pseudo-headers (`:method`, `:path`, `:scheme`), a fresh
  `Http2ServerStreamType` object is allocated — its first three fields
  deliberately mirror ServerResponse (status/body/headers) so the existing
  response-writing tail reads it unchanged, with the request body appended —
  and the handler is called as `(stream, headers[, flags])` — Node's third
  `flags` parameter is accepted (passed as 0). Contextual typing through
  `mustCall` wrappers applies via internal annotation names, now typing up to
  the handler's own arity.
- **Http2Stream surface**: `.respond({ ':status': n, name: value })` (object
  literal; `:status` → status field, other names → response headers map,
  other pseudo-headers rejected), `.write(chunk)`/`.end(chunk?)` (body
  accumulation), `.on('data'|'end')` (request body as one chunk, delivered
  synchronously at registration — the body is complete before the handler
  runs), `.close()`/`.setEncoding`/`.resume`/`.pause` accepted no-ops.
- **Response headers over h2**: the C submit path sent only `:status`.
  Three new bridge getters (`__kml_h2_resp_hdr_count/name/val`, indexed
  straight off the string-map layout, compiled to constants when the response
  shape has no headers field) let `http2src/http2.c` build the full nv list —
  which also fixes a latent Stage-1/compat gap: **`res.setHeader`/`writeHead`
  headers were silently dropped on the h2c path** for every server form.
- **Map bracket access**: `headers[':path']` — the corpus's universal header
  read — is now sugar for `.get` on any string-keyed `Map` (value or null),
  in both the emitter and inference. Generally useful (`req.headers['host']`
  works too), surfaced here.

Two same-delivery arity fixes from the freed files' next blockers: a
**handler-less server** (`http.createServer()` + `listen` with no
`'request'`/`'stream'` listener — legitimate Node, used by client-behavior
tests) synthesizes an empty handler answering 200/empty (a disclosed
divergence from Node's hang-until-timeout); and **`createServer({}, cb)`**
accepts an empty options literal (any actual option stays a clean rejection).

## Implementation notes

`codegen/llvm/emit_http.go` (stream mode branch in `emitHTTPCallHandler`,
`emitNewH2ServerStream`, `emitHTTPStreamHandlerCore`, `emitH2StreamMethod`,
bridge getters), `emit_call.go` (dispatch), `emit_exprs_member.go` +
`emit_exprs_types.go` (Map bracket get), `types.go`
(`Http2ServerStreamType`, internal annotation names),
`http2src/http2.c` (nv list from the getters). `server.on`/`stream.on` also
accept `once` (the corpus uses `server.once('request')`).

## Side effects discovered

- The silent header-drop on h2c responses (above) predated this work and
  affected the compat path too; fixed here rather than tracked.
- The streams corpus's next blockers are `http2.connect` client sessions
  (Stage 3) and multi-server files (single-server V1).

## Verification

New E2E tests `TestE2EHTTP2StreamsAPI` (pseudo-header reads, `:status` 201,
custom response header asserted via curl `%header{}`) and
`TestE2EHTTP2StreamsRequestBody` (POST body through `on('data'/'end')`) —
both over real HTTP/2 (curl `--http2-prior-knowledge`, `http_version=2`);
new example `examples/http2/streams_server.ts` compiled and run; full
`make test-par` + Node oracle re-run (Mac).
