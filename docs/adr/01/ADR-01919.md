# ADR-01919: subtype reduction where an instanceof branch joins

- **Relations**: `Implements TDD-00230` (strict lane is tsc)
- **Date**: 2026-10-21

## Context

After `if (a || this instanceof Sub) {}`, tsc types `this` as the class again: a branch type that is not a subset of the declared type (one `instanceof` or a type predicate injected) makes the join reduce subtypes. The checker kept `S | Sub`, so a call of an inherited overloaded method (`this.once(…)` on a Duplex subclass) became a union of overload sets and was left unanswered.

## Decision

Where a branch's type is not a subset of the declared type, the join drops a member that is an instance of a class deriving from another member's class.

## Consequences

- `this.once(…)` after such a guard is typed as in tsc; the HTTP/2 stream's row goes.
