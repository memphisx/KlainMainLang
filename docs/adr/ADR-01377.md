# ADR-01377: coerce takes ToNumber and ToBoolean, never a reinterpretation

- **Relations**: Supersedes the class-call branches of ADR-01372 and ADR-01374; Implements part of TDD-00230 P3.3 (`convert`)
- **Date**: 2026-10-03

## Context

ADR-01372 and ADR-01374 converted a string, array or object argument of a
class method's number or boolean parameter inside `emitClassCall`. The
same values still reached other conversion sites unconverted:
`new DataView(ab, 0, "")` passed a pointer where the optional
`byteLength`'s `{ i1, double }` expected a double (invalid IR), because the
nullable-scalar path calls `coerce`, which returned a pointer unchanged
for a double target.

## Investigation

TDD-00230 P3.3 requires one total conversion function: "A pair it does
not define is a compiler bug reported at the call, never a raw
reinterpretation." `coerce` returned a string, array, function or object
unchanged for a `double` or `i1` target, and every caller inherited that.

## Decision

- Under `-compat=js`, `coerce` converts a non-boxed string, array, function or object into a
  `double` target by ToNumber (`emitUnaryPlus`: ToPrimitive for an object),
  and into an `i1` target by ToBoolean (`toBool`). Integer targets are left
  alone: a pointer converted to `i64` on purpose elsewhere must not become
  ToNumber. The strict lane keeps its clean rejections (tsc rejects these
  programs); a first version converting in both lanes made five rejection
  tests compile.
- The class-call branches of ADR-01372 and ADR-01374 are deleted: the
  conversion is `coerce`'s.
- DataView's `byteLength` parameter is `any` in the TypeScript class, so
  ToIndex sees `null` (0) apart from `undefined` (the rest of the buffer),
  which a `number | undefined` slot cannot hold apart; ToIndex maps -0 to
  +0.

## Implementation notes

`codegen/llvm/emit_exprs_coerce.go`, `codegen/llvm/emit_classes.go`,
`lib/node/kml_dataview.ts`. The user-facing declaration in `lib/es.d.ts`
is unchanged, so the strict lane still rejects a non-number argument.

## Verification

Mac (Apple Silicon): `new DataView(ab, 0, x)` for the 14 values of
Test262's `toindex-bytelength` matches Node; `TestE2ECompatJSClassCallToNumber`,
`TestE2ECompatJSClassCallToBoolean`, `TestE2EAnyToNumberToPrimitive` and the
DataView E2E tests pass.
