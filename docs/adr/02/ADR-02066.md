# ADR-02066: Host-record subclass chains, stream collectors, runtime hooks

- **Date**: 2026-11-22

## Context

The Linux x86-64 test gate found four faults in this batch's work:

- `class D extends M`, `class M extends Response`, neither with a
  constructor: `new D(...)` took the Map/Set seeding path, and the compiler
  panicked. With one level, `Object.prototype.toString` named the instance
  `[object Set]`: the host-tag fallback was `"Set"` for every host it did
  not list, host records included.
- A `Response` reached only through `any` (`const R: any = Response`,
  `new R(...).clone()`) defines the stream collector, whose read awaits,
  in a program classified as never waiting. The `clone` adapter compiled
  to a thrown internal error, and the module failed to compile.
- `__kml_any_iter_collect_map`, generated only when a program needs it,
  sat in the same shared unit as the always-present collectors, so that
  unit differed between programs.
- The loop and task runtimes named two program-generated symbols
  (`__kml_process_versions`, `__kml_promise_proto_ctor_read`) as weak
  externs, not through hooks.c.

## Decision

- The conformance runners (Test262 and Node) start clang's deadline once
  the memory budget admits the compile. The wait in that queue counted
  toward the 30 s budget, so a large program queued behind others was
  reported `CLANG_TIMEOUT` with clang itself fast.

- A class whose chain down to a host record has no constructor builds
  the record from the root builtin, as that builtin's `new` does. The host
  tag names Set only for a Set, and asks the host's class name otherwise.
- Defining either stream collector marks the program as one that may wait
  (it supersedes the Request-only rule of ADR-02064).
- The map collector has a shared unit of its own.
- hooks.c defines both symbols weakly: an empty version table and a no-op
  `constructor` read. The program's own definitions replace them.

## Consequences

- `TestE2EHostRecordSubclassNoCtorChainTS` covers the chain.
- `TestE2EBuiltinConstructedThroughValue`, `TestE2EHostRecordSubclassTS`,
  `TestLibUnitsSameAcrossPrograms` and
  `TestRuntimeSymbolsResolveWithinRuntime` pass.
- Verified on Node304 (Linux x86-64).
