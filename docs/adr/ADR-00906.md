# ADR-00906: Sibling- and super-method return-type inference

- **Date**: 2026-09-12

## Context

Invalid-IR sweep. A method whose body returns another method's result got the
wrong return type, emitting invalid IR:

```ts
class C { #m() { return "test262"; } method() { return this.#m(); } }
// clang: ret ptr %t1 — in an i64 function (method() inferred i64)
```

From the `regular-definitions-private-method-{usage,getter-usage}` files (×4) and
`super-access-inside-a-private-getter.js`.

## Investigation

Two gaps in unannotated-return inference during `registerClasses`
(`emit_classes.go`):

1. `e.classes[cd.Name]` was only stored *after* the per-method loop, so while
   inferring `method()`'s return type, `this.#m()` resolved against an absent
   class — `inferExprType`'s instance-method-call case
   (`emit_exprs_types.go:1408`) fell through to the i64 default.
2. `inferExprType` had no `SuperExpression` case, and the inference temp scope
   bound only `this`, not `super` — so `return super.method()` also defaulted to
   i64.

## Decision

1. Publish the (still-populating) `ClassInfo` into `e.classes[cd.Name]` *before*
   the method loop. `MethodSigs` is a map, shared by reference, so a method
   calling an earlier-declared sibling now resolves its return type.
2. Add a `SuperExpression` case to `inferExprType` that reads the scope `super`
   symbol, and bind `super` (typed as the base class) in the inference temp
   scope — mirroring `emitClassMember`'s own `super` binding.

## Implementation notes

- Only earlier-declared siblings resolve (forward references still default) — an
  acceptable limitation matching source-order inference elsewhere.
- `info` scalar fields read during inference (`HasEventEmitter`, …) are all set
  at construction, before the early publish; the final store re-publishes the
  completed struct (same maps).

## Side effects discovered

`staging/sm/Function/regress-528082.js` (a named-function-expression referencing
its own name as an upvalue) remains invalid IR — a separate function-value
return-inference gap, deferred.
