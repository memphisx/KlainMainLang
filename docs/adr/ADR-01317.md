# ADR-01317: A class's static side, TS2344, and tsc's flow shortcuts past calls and conditions

- **Relations**: `Implements TDD-00230` (P3.2); `Extends ADR-01315`
- **Date**: 2026-09-30

## Context

- ADR-01315 left `emitCall`'s by-name Map/Set/RegExp dispatch as a fallback
  for receivers the checker gave no declaration. Deleting it showed which
  receivers those were:
  - `target.#listeners.get(k)` in a static method (`EventTarget._dispatch`):
    `target` read as `any`;
  - `this._kmlStreams.get(a)` in http2's event loop: `this` read as `any`;
  - `frame.set(…)` after `prior.forEach((v, k) => { frame.set(k, v) })`;
  - `memos.set.delete(…)` in the assert comparisons, which tsc narrows to
    `never`;
  - Headers' `entries`/`keys`/`values`/`forEach`, and klain:http's
    `req.query.has(…)`.
- `new WeakMap<string, number>()` compiled to a codegen error instead of
  tsc's TS2344.

## Investigation

- The checker never typed a class's value (`typeof C`): `computeSymbolType`
  had no `ClassDeclaration` case, so `C.x` and `C.m(…)` were unanswered. A
  call with an unanswered callee whose arguments mention a reference counts
  as a possible `asserts` function (`unknownGuard`), which makes the
  reference unanswered after it. `Ev.b(target)` turned `target` into `any`.
- `unknownGuard`'s `mentions` also matched a reference inside a closure
  argument, and any argument rooted at the same symbol (`this.x` against
  `this.y`).
- `dottedType` read no member through an apparent type (`arr.forEach`) or a
  union. `Array.from` was not declared in `lib/es.d.ts`.
- The flow walk recursed at every call, condition and switch clause.
  `narrowByEquality` and `narrowByDiscriminant` typed the other side of a
  comparison before checking that narrowing applies. Inside a loop, two
  comparisons typing each other recursed without end. The flow budget
  caught this, and the answer became `any`.
- A first cycle cut through the assignment mechanism (`assigning`/`cuts`)
  made those answers provisional, so they were never cached, and
  `TestFlowCost` ran out of memory. It was replaced by a plain in-progress
  set.

## Decision

- **`typeof C`** (`classObject`): the class's static fields, methods and
  accessors, its base class's statics, `prototype` (a non-generic class's
  instance), and its construct signature. A builtin base's statics are not
  modelled (the type is partial).
- **Flow**, as tsc's `getTypeAtFlowNode`:
  - a call, condition or switch clause that cannot narrow the reference is
    walked past without recursing (`callMayNarrow`, `condMayNarrow` through
    aliased conditions, `switchMayNarrow` through case tests);
  - a receiver narrows only through a declared `asserts this` predicate, or
    a callee the checker cannot type;
  - `mentions` skips function arguments, and matches only paths that
    overlap the reference;
  - `dottedType` reads members through apparent types and unions. A member
    nothing declares is no guard. So is an unmodelled library method whose
    declarations have no type predicate (`declaredNoGuard`);
  - `narrowByDiscriminant` types the other side only for a discriminant;
  - `comparedType` breaks a comparison cycle: the re-entered comparison
    narrows nothing.
- **TS2344**: explicit type arguments are checked against their parameters'
  constraints, instantiated by the arguments given. This covers calls,
  `new` (`newCtor`), and type references in annotations
  (`checkRefTypeArgs`: interfaces, aliases, classes). A literal source is
  named by its base type when the constraint has no literal (`1` as
  `number`), as tsc names it.
- `lib/es.d.ts` declares tsc's four `Array.from` overloads.
- `lib/node/internal_util_comparisons.ts` reads `memos.set` through an
  unnarrowed local, since `objEquiv` may create it.
- **Name dispatch**:
  - the RegExp `exec`/`test` fallback is deleted;
  - Headers' `forEach`/`entries`/`keys`/`values` go through Headers' own
    branch;
  - the Map/Set fallback remains only for klain: modules' compiler-typed
    values (`HttpRequest.query`), which TDD-00230 declares last.
- Host-shape methods (a Date or collection held in `any`) call their
  intrinsic directly: the synthesized call has no declaration.
- A Set or weak collection method ensures its runtime, for a program that
  calls one it never constructs.
- Unary `-` and `~` on a `number | undefined` local take ToNumber first.

## Side effects discovered

Fixed here:
- `const f = C.m` (a static method as a value) was a codegen error. It is now
  the method's function object (`emitNamedFuncValue` on
  `<Implementor>_static_<m>`), typed as such by `inferExprType`.
- A method's unannotated defaulted parameter (`p = '!'`) was typed as a
  number in `buildParamSig`, so `c.greet('b', '?')` printed a pointer. It now
  takes the default's type, as a function's does.
- A named function taken by value (`const k = h; k('x')`) left an omitted
  defaulted argument `null`. The value's inferred type now carries the
  defaults (`funcValueType`), as `emitNamedFuncValue`'s does.
- `const K = C; new K(…)` was "unknown class" (BACKLOG 81), and `K` held
  0. A constant bound to a class (through further constants) now constructs
  and reads statics as the class (`constClassAlias`, `identClassAlias`,
  `dealiasNew`), and holds the constructor reference.
- A class had no `name` or `length`: `C.name` is its source name, and
  `C.length` its constructor's parameters before the first optional one.
- util.inspect showed a class as `[Function: C]`. It is now `[class C]`, or
  `[class B extends A]`, followed by its own public static fields' current
  values (`[class C] { s: 5 }`). The runtime reads them through accessors
  code generation defines (`__kml_classref_shown`/`nstatic`/`skey`/`sget`),
  and lays them out as an object's. The class-reference finalize now runs
  before the shape table, which the boxed statics' layouts join.
- Linux only: a program that seeds `Math.random` and formats an HTTP date
  declared `@time` twice (invalid IR). Both now go through `ensureTime`.
- Linux only: `String.fromCharCode`'s ToUint16 in `casemap.c` called
  `fmod`, and no libm is linked. It is now `t - 65536·floor(t / 65536)`,
  exact for an integral `t`.
- Left in BACKLOG 81: a class held in a `let`, a parameter or `any`
  constructed with `new`, and a host class (`Map`) as a value.

## Verification

On macOS arm64:
- Each repro was compared with Node, and each TS2344 case with `tsc
  --strict`: positions and messages match.
- `TestE2EWeakMapPrimitiveKeyRejected` now expects TS2344.
- `TestE2EStaticMethodUnionParamNullMember` passes `undefined` where tsc
  rejects it (TS2345), so it moves to `-compat=js`.
- `TestE2EClassConstAliasAndInspect` compares the alias, `name`/`length`
  and the inspect forms with Node.
- `TestE2EStaticMethodValueAndDefaultParams` compares the static method
  value, method defaults and a function value's default with Node.
- The checker, binder, lib, resolver and diag unit tests pass under a
  memory guard, `TestFlowCost` included.
- Full test-par passes on macOS arm64 (60m shards: the first run's 20m
  shards timed out under a post-reboot load average of 43, with no test
  failure). `make examples`: 373/373.
- Test262: js lane 9001 → 9141, strict lane 7620 → 7713 of 53578.
- Linux (Docker `golang:latest`, arm64): the checker, binder, resolver, diag
  and lib tests, and the E2E tests of every touched area, pass. This
  includes the GC-mode and worker suites.
