# ADR-01336: A class per evaluation as a value

- **Relations**: Implements TDD-00242 (in part), Extends ADR-01334, ADR-01318
- **Date**: 2026-10-02

## Context

[ADR-01334](ADR-01334.md) closure-converts a class declared in a function
that reads the function's locals, but rejected one used as a value
(`return D`), whose `new` happens where the locals are out of scope.
[TDD-00242](../tdd/TDD-00242.md) gives each evaluation a record. Node, the
reference: `make(1) !== make(1)`, an instance of one evaluation's class is
not `instanceof` another's, and each evaluation's instances see their own
bindings.

## Investigation

- A dispatcher keyed by a constructor reference looks the payload up in the
  unit registry (`__kml_unit_find`, unitregsrc). A record registered as an
  alias of its class's row is answered for like the class, so `.name`,
  inspect, statics and construction need no new IR.
- The construction arm (`i64 (ptr argv, i64 argc)`) has no access to the
  reference it was reached through.
- The dynamic `.name` read of a constructor reference returned the payload
  as the name's characters.
- `new z1.Dog()` with `z1` a module binding failed with "unknown class":
  the resolver renamed the member (`Dog`) as if it were the binding, and
  left the qualifier unrenamed.
- A block subclass of a closure-converted class captured nothing itself,
  so its construction arm could not supply the base's bindings. The arm's
  codegen failed, and the dispatcher fell back to `undefined`.

## Decision

1. **Records** (`codegen/llvm/unitregsrc/unitreg.c`):
   `__kml_classrec_new(ref, base, n, stride)` allocates
   `{ ref, base, caps[n] }`, records it, and registers a copy of `ref`'s
   constructor row keyed by the record.
2. **The class value.** A closure-converted class used as a value makes
   its record where its declaration is evaluated
   (`emitClassRecord`). The record holds the captured bindings, boxed, or
   their cells, and links to the record of the local class it extends.
   Its name in value position reads that record, boxed as a constructor
   reference.
3. **Construction through a value.** The call site calls
   `__kml_classrec_enter(payload)` before `__kml_dyn_construct`. The
   class's arm reads `__kml_classrec_current(ref)` and fills the hidden
   fields from it (`__kml_classrec_cap`, undefined without a record).
4. **Identity.** Every construction binds the instance to its record:
   the local record at a direct `new`, the arm's record, or the record of
   `this` for a `new` inside the class (`__kml_classrec_bind`/`_of`).
   `instanceof` against a record also requires the instance's record chain
   to contain it (`__kml_classrec_is`). `__kml_classref_name` maps a record
   to its class's name.
5. **Local subclasses.** A block class extending a closure-converted one
   takes its captures, and is a record class when its base is.
6. **Class expressions.** A class expression that reads a local is
   closure-converted and hoisted like a block class. It is always a value,
   so each evaluation of the expression makes its record.
7. `new obj.K()` with `obj` a value reads `K` as a property of `obj`. The
   resolver renames the qualifier and never the member, and codegen
   accepts a function as the qualifier (`new assert.Assert()`, a
   function carrying the class as a property). The member had been
   renamed whenever a top-level class shared its name, so
   `new registry.Square()` constructed the top-level `Square`.

## Side effects discovered

- `bindParams`' position parameter had been dead since the reserved-name
  checks were deleted (ADR-01333). It is removed, with a stale comment in
  `emitter.go` that still described those checks.
- The Linux x86-64 gate turned up three defects:
  - `Math.max(n, 1)` with an undefined `n` printed `undefined`:
    `llvm.maximum`/`llvm.minimum` return a NaN operand unchanged on
    x86-64, so the sentinel came back. Their result is now quieted.
  - An optional field held as a plain `double` (`Partial<{ x: number }>`)
    took the pointer null test in `emitFieldPresentAt`, which clang
    rejects. It now tests for the sentinel.
  - `TestE2EWorkerNested` hung about once in a hundred runs under load,
    already at HEAD. The reactor checked a worker's terminate flag before
    draining completions, so a `terminate()` that landed in between lost
    its wakeup and the worker slept in `select()`. The check now follows
    the drain (`runtime_http.go`); 640 loaded runs on Node304 pass, where
    7 hung before.

## Remaining (TDD-00242)

- A static member, static block or static initializer that reads a local
  is still rejected. Statics live in one storage per class, where each
  evaluation needs its own.
- `extends <expression>` (a mixin over a parameter) is out of scope, as
  for any class.
- The record table and the instance table are never pruned.
