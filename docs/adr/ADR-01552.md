# ADR-01552: Inference from index signatures; `this` from the checker alone

- **Relations**: Extends ADR-01548, ADR-01469, TDD-00230
- **Date**: 2026-10-10

## Context

- Type-argument inference matched an interface target's properties
  against the source, never its index signatures. `ArrayLike<T>` against
  a `Uint8Array` (`[index: number]: number`) inferred nothing: `function
  g<T>(x: ArrayLike<T>): T` called with one gave `unknown`, and
  `Array.from(bytes, b => …)` typed `b` as `any` where TypeScript has
  `number`.
- `.length` on an instance of a class extending Array or a typed array is
  read off the instance's array body and converted to a number, but the
  inference of the read only knew array and typed-array receivers: the
  class receiver fell through to an integer.
- `this` was answered by the checker for ordinary nodes and by the old
  inference otherwise (a synthesized field initializer, a function
  expression's own `this`, which the checker leaves unanswered).
- The checker-side mapping held a module `var` declared without a value
  and later assigned (`var ref; ref = function () {…}`) as `any` only in
  -compat=js, and `JSON.stringify` of an `any` as a string; codegen
  holds the first as `any` in both lanes, and the second as `any`
  (it may be `undefined`).

## Decision

- Inference pairs index signatures (TypeScript's inferFromIndexTypes): a
  target's number index from the source's number index, else its string
  index; a target's string index from the source's string index.
- `.length` on an instance of a class extending Array or a typed array is
  a number.
- `this` is decided without the old inference: the checker's answer, else
  the binding the function's calling convention gives `this`, else (a
  pre-pass before it is bound) `any`. Its old arm is deleted.
- The checker-side mapping follows codegen for both the untyped module
  `var` and `JSON.stringify` of an `any`.
- The checker-side mapping also holds a binding annotated with a plain
  number, boolean or string as codegen stores it when it may be
  undefined (declared without a value, or initialized from a read that
  may be absent): `T | undefined`, its read the payload only where every
  reaching store is present or (no absent initializer) flow proves it
  assigned; a conditional between that slot and its scalar keeps the
  slot.

## Verification

- Mac (Apple Silicon): checker unit test for the inferred types;
  `examples/classes/extends_array.ts` and a typed-array/Array subclass
  `.length` probe print as Node with no shadow disagreement.
- Linux (Node304, x86-64): targeted E2E run over the promise, class,
  method, arguments, function, array, union, literal, async, JSON and
  private-member tests passes.
