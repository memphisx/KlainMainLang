# ADR-01374: ToNumber runs ToPrimitive everywhere; a boolean parameter takes ToBoolean

- **Relations**: Extends ADR-01372, TDD-00201; the class-call branch Superseded by ADR-01377
- **Date**: 2026-10-03

## Context

After ADR-01372, the DataView `to-boolean-littleendian` Test262 files still
produced invalid IR under `-compat=js`, and `getInt16(0, "s")` read
big-endian where Node reads little-endian. A related probe showed
`Number`-typed positions reading NaN for `{ valueOf() { return 1 } }` held
in `any`.

## Investigation

- `emitClassCall` (`codegen/llvm/emit_classes.go`) passed a string or an
  object unconverted to an `i1` parameter: invalid IR.
- ADR-01372's ToNumber branch also matched an `i1` parameter
  (`Type.IsInteger` counts booleans), so `"s"` went ToNumber → NaN → false.
- `__kml_any_tonum` returned NaN for every heap value that is not a
  string. Only operator sites ran ToPrimitive first (TDD-00201 Stage 4), so
  every other ToNumber of an object held in `any` (an argument, a number
  slot) skipped `valueOf`/`toString`.

## Decision

- A class method's boolean parameter takes ToBoolean (`toBool`) of any
  argument; ADR-01372's ToNumber branch excludes `i1`.
- `__kml_any_tonum` sends a heap value that is neither a string nor a
  Symbol to `__kml_obj_tonum` (`boxsrc/toprim.c`): ToPrimitive with the
  number hint, then ToNumber of the primitive, NaN when there is none. That
  is the spec's ToNumber, so every site agrees.

## Implementation notes

`codegen/llvm/emit_classes.go`, `codegen/llvm/emit_anyops.go`,
`codegen/llvm/boxsrc/toprim.c`. `ensureAnyOps` now pulls in the ToPrimitive
runtime; a binary using `any` arithmetic grew by 160 bytes on the Mac.

## Side effects discovered

A `number` parameter or binding holds a double, so an object passed where
JavaScript would keep the object (`function f(n: number) { return n }`
called with one) is converted at the boundary. That divergence predates
this change and is unchanged.

## Verification

Mac (Apple Silicon): `TestE2ECompatJSClassCallToBoolean`,
`TestE2EAnyToNumberToPrimitive`, `TestE2ECompatJSClassCallToNumber`; the
DataView Test262 category has no invalid IR left.
