# ADR-00500: http.get/request method + headers options

- **Date**: 2026-08-29

## Context

The client's options object accepted `{ port, path, host, agent }` only
— `method` and `headers` were rejections (27 Node-corpus files hit the
options message).

## Decision

Thread both through the existing transfer: the ClientRequest handle
grows 24→40 bytes to carry `method`/`headers` pointers, and
`__kml_httpc_begin` takes them and hands them to `__kml_fetch_async`'s
already-existing method/header slots (null method → "GET").
`headers` must be an object literal — its pairs fill a string map, then
the same curl_slist builder `fetch(url, init)` uses. The variable-bound
options form gains a string `method` field; literal-only `headers`
stays its documented narrowing. No request body yet (`req.write()` is
the remaining Stage-2 piece).

## Verification

Mac. `tests/http_test.go` `TestE2EHTTPClientMethodAndHeaders` (DELETE +
custom header echoed by the server) passes; full HTTP batch green;
`examples/http/client_server.ts` extended (HEAD + header) and re-run.
