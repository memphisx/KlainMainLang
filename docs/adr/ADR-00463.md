# ADR-00463: N-ary array concat; zero-arg Array constructor

- **Date**: 2026-08-29

## Context

The TS oracle's `arrayConcat2` shape: `new Array<string>()` (zero-arg)
was a parse error (the `Array<T>(n)` form required a size), and
`.concat("a", "b")` rejected — concat took exactly one array argument.

## Decision

- `new Array<T>()` parses with the size defaulting to 0 — an empty array.
- `arr.concat(...)` takes any number of arguments; each is an array
  (flattened one level, JS semantics) or a plain value coerced to the
  element type and appended; zero arguments copy the receiver. Emission
  sums part lengths into one allocation with a running write offset.

## Verification

Mac. `tests/arrays_test.go` additions (mixed arrays+scalars incl. string
elements, zero-arg copy, zero-arg constructor) and a new
`examples/arrays/arrays.ts` pass; full array E2E batch green. TS oracle
agreement 5131 → 5135; Node oracle unchanged (40).
