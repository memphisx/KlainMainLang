# ADR-00289: Built-in error constructors as first-class values (boxed funcrefs)

- **Relations**: Extends the `any` box (TDD-00062) with a new tag; picked from the [ADR-00288](ADR-00288.md) blocked-by histogram (`TypeError` 1042 + `ReferenceError` 335 + `SyntaxError` 258 files gated)
- **Date**: 2026-08-22

## Context

`assert.throws(TypeError, fn)` — Test262's single most common assertion
shape after `sameValue` — passes a built-in error constructor as a *value*.
`new TypeError(...)` and `e instanceof TypeError` both worked (the fixed
error-kind enum, TDD-00013), but the bare identifier in value position was
"undefined variable".

## Decision

A new `any`-box tag, `kmlTagFuncRef` (8): the payload is the constructor's
*interned name string* (`ptrtoint`'d). Interned strings are deduplicated per
module — one global per name — so `__kml_any_eq`'s same-tag payload compare
gives exact identity (`TypeError === TypeError` true, `=== RangeError`
false) with no new runtime code. `emitIdent` produces the box for any
`errorKinds` name after every other resolution misses (locals and named
functions still shadow); `inferExprType` mirrors it as `TypeAny`.

Tag-dispatch additions: `typeof` → `"function"`; stringification →
`function <name>() { [native code] }` (real JS's native-function rendering).
`__kml_any_eq` groups tag 8 with the reference-equality tags.

## Verification

Node-diff (byte-identical): `typeof TypeError` through an `any` param,
`x === TypeError` / `=== RangeError` discrimination, `TypeError ===
TypeError`. E2E: `TestE2EErrorConstructorAsValue`. Full suite green.
