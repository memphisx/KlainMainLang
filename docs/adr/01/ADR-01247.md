# ADR-01247: `RegExpExecArray` and `RegExpMatchArray` annotations

- **Date**: 2026-09-29

## Context

`let m: RegExpExecArray | null; m = re.exec(s)` was a compile error ("cannot
assign a array value to 'm' (a object)"): code generation had no type for
the name, although tsc code uses it all the time.

## Decision

Both names resolve to the type `exec`/`match` return (a string array, `|
null` as its nullable form).

## Side effects discovered

The result's `index`/`input`/`groups` are still missing; that is an
existing caveat on `str.match`/`exec`.

## Verification

Mac (Apple Silicon): `TestE2ERegExpExecArrayAnnotation`.
