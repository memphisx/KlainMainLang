# ADR-01638: A var redeclared with another object-literal type is TS2403

- **Relations**: Extends ADR-01470
- **Date**: 2026-10-15

## Context

`built-ins/String/S9.1_A1_T2.js` passed on Linux AMD64 and failed on
Windows, where it printed `6.95e-310` for `String(object)`:

```ts
var object = { valueOf: function() { return 0 }, toString: function() { return 1 } }
var object = { valueOf: function() { return 0 }, toString: function() { return {} } }
String(object)
```

tsc rejects the second declaration (TS2403). The strict lane compiled it.

## Investigation

- The variable's storage takes the first declaration's type, so
  `toString` sat in a slot typed `() => number`. The redeclaration stored a
  closure returning an object there, and the call read a `double` the
  function never set. That register held 0 on Linux and a leftover pointer
  on Windows, so the Linux pass was luck.
- A plain assignment of the same value is already rejected (TS2322), because
  `assignableTo` answers a definite no.
- `checkVarRedeclared` (`checker/check.go`) got the same definite no, then
  stayed silent for any object type. That guard is for types this checker
  cannot compare exactly, such as a mapped `Required<T>` or an intersection.
  It also covered plain object literals, which the checker models fully.

## Decision

A definite no in either direction is never identity. When both types are
anonymous object types (object or type literals), the redeclaration is
reported as TS2403. Other object types keep the guard. The `-compat=js`
lane compiles the program as JavaScript, as before.

## Implementation notes

`checker/check.go`, `checkVarRedeclared`.

## Verification

Windows 11: the checker tests add three cases: a method returning an object
where it returned a number (TS2403), a string where it returned a number
(TS2403), and the same shape again (no error). The Test262 file and the
reduced programs are rejected with tsc's message, and `-compat=js` prints
Node's output for them. The TypeScript conformance suite on both platforms
compares the checker with tsc.
