# ADR-01522: A generator's value is one function, under its own name

- **Relations**: Extends TDD-00096, TDD-00129
- **Date**: 2026-10-10

## Context

Each reference to a generator function built a new constructor closure,
so `G === G` and `G().next().value === G` were false. A top-level
`var G = function* g() {}` was rewritten into a declaration named `G`;
the body's references to its own name `g` were then undefined variables
(or the outer `g`), and `G.name` printed `G`.

## Decision

- A generator capturing nothing keeps its value in a module global, made
  on first reference; every reference reads it. Its constructor thunk is
  emitted once per generator.
- The rewrite of a named generator expression renames its own name in
  its body to the binding (unless a parameter shadows it) and records the
  expression's name as the value's display name.
