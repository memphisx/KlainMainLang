# ADR-01407: A hint-less `[Symbol.toPrimitive]()` ignores the hint

- **Relations**: Extends ADR-00912
- **Date**: 2026-10-05

## Context

`emitObjectToPrimitive` calls `[Symbol.toPrimitive]` with the hint string
(`"string"`, `"number"` or `"default"`). A method declared without a
parameter, `[Symbol.toPrimitive](): number { return this.id }`, failed to
compile wherever a string hint applied: a template literal `${t}` gave
"T.@@toPrimitive expects 0 argument(s), got 1". JS passes the hint and the
method ignores it, as any function ignores an extra argument.

## Decision

The ladder passes the hint only when the method declares a parameter, for
a class's method and for an object literal's function-valued member alike.

## Verification

- Mac (M4): `TestE2EToPrimitiveWithoutHintParam` (class and object-literal
  methods with and without the hint, under `+`, a template literal and
  `+ ''`, against Node) and the other toPrimitive tests.
- Linux (x86-64, Ubuntu 24.04 container), with ADR-01406 to ADR-01409: the
  full test suite (3,927 tests), the 393 examples, and Test262 in both lanes
  (strict 8,498, js 10,506, unchanged, no invalid IR).
