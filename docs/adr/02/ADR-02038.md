# ADR-02038: Object.defineProperties links the added-property hooks

- **Date**: 2026-11-22

## Context

- A typed object given a property only by `Object.defineProperties` logged
  without it, though reads, keys and JSON saw it. The inspect split
  (`emitExtraSplit`) asks `__kml_obj_has_extra`. Only a program that
  sets `usedObjExtensible` links objextra.c's answer; otherwise hooks.c's
  weak default says no extras. `defineProperties` never set it.

## Decision

- `Object.defineProperties` and `Object.defineProperty` set
  `usedObjExtensible`: a static object they define on carries the
  property beside its layout.

## Consequences

- Tests: `TestE2EDefinePropertiesInspectTS`.
