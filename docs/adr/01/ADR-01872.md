# ADR-01872: `x ?? {}` reduction, dictionary interfaces, array union members

- **Relations**: `Implements TDD-00230` (P3.3: the shadow report's Identifier, MemberExpression and IndexExpression buckets)
- **Date**: 2026-10-21

## Context

- `opts ?? {}` and `opts || {}` gave `O | {}`; tsc reduces the result by subtype to `O`, and `xs ?? []` to `string[]`. Node's http Agent reads every option off `options ?? {}`, so each read was unanswered.
- The shadow oracle refused a union with one plain array beside a Buffer (`string | Buffer | (string | Buffer)[]`, the TLS `ca`/`cert`/`key`), which codegen boxes; and an index-signature interface naming optional members (`IncomingHttpHeaders`), which codegen holds as a dictionary with named fields.
- The oracle refused scalars beside one object (`number | Error`, the HTTP parser's `finish()`), which codegen boxes member by member.
- A boxed union narrowed to its array or interface member (`OutgoingHttpHeader` after the string and number tests) read as the box, where codegen reads the array.

## Decision

- `??`/`||` reduce a right-hand object literal the left's non-nullish (truthy) part covers to that part, and `[]` beside an array to the array, as tsc does.
- The oracle maps one plain array and one byte array in a box (validateUnionMembers' rule), an interface of a string index and optional members to the dictionary view with its named fields (withDictFields), scalars beside one object to a box of each, and a boxed union narrowed to its array or interface member to that member.

## Consequences

- `TestNullishLiteralReduction` holds tsc 5.6's declaration output.
- Verified on Apple Silicon.
