# ADR-00581: dgram socket.setBroadcast

- **Relations**: Extends [ADR-00327](ADR-00327.md)
- **Date**: 2026-09-01

## Context

`dgram` UDP sockets had no `setBroadcast()` — a datagram sent to a broadcast
address needs `SO_BROADCAST` enabled first, so broadcast senders were
unreachable. (The row's `.address()` was already implemented; this ADR also
corrects the stale "no `.address()`" caveat.)

## Decision

Add `socket.setBroadcast(flag: boolean)` — a real
`setsockopt(SOL_SOCKET, SO_BROADCAST, &flag, 4)` on the socket fd, mirroring the
pattern `net`'s `setNoDelay`/`setKeepAlive` already use. `SO_BROADCAST` is
`0x0020` on Darwin and `6` on Linux (host-only, no cross-compile). Returns the
socket for chaining.

## Verification

`TestE2EDgramSetBroadcast` (enable, bind, confirm the socket is still usable,
disable). Built and verified on Mac (Apple Silicon).
