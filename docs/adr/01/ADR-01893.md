# ADR-01893: a declared function's implicit `arguments` rest in the oracle

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

- Where a program reads `.arguments` or `.caller`, emission gives every sloppy function declaration the implicit rest parameter that collects its overflow arguments. The oracle added that parameter to a function expression's type but not to a declaration read by name, so it disagreed on every such name (a Test262 harness function in each forbidden-extension test).

## Decision

- A name resolving to one function declaration (a merged namespace aside) that emission has given the implicit rest parameter carries it in its function type, as a function expression's does.

## Consequences

- About 200 shadow rows go away; no emission change.
