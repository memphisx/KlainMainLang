# ADR-01856: Hand-built iterables, self-returning literals, static rewrites, pattern defaults and string indexes are typed

- **Relations**: `Implements TDD-00230` (P3.3: the checker answers what inferExprType did)
- **Date**: 2026-10-21

## Context

- `yield*` and `for await` over a hand-built iterable (an object whose `[Symbol.asyncIterator]()` returns `{ next() { return Promise.resolve({ value, done }) } }`) left the element unanswered: the checker followed an own `[Symbol.iterator]` only into a lib iterator type, and never `[Symbol.asyncIterator]`. The async generator delegating to it, its calls and every `.next().then(...)` on the result fell back; Test262's async-generator `yield*` tests are built this way, and the pattern led the shadow report's largest bucket (10,010 rows in all).
- A callback parameter whose contextual type has no representation (`v => …` over `IteratorYieldResult<T> | IteratorReturnResult<R>`, a union of two object types) kept the oracle from answering the literal, though emission types such a parameter as a box.

- A destructured parameter with an empty default (`([[x, y] = [4, 5]] = []) => …`, `({ a = 1 } = {}) => …`) was unanswered; the object form failed to compile ("object has no field 'a'"): codegen typed the parameter from the empty literal.
- The oracle mapped a `key?: T` property to a plain `T` field, which cannot hold absence; a destructuring default on it was dropped as unreachable.

- A string's number index (`"lol"[1]`, a `string` read at `s[i]`) was unanswered: the checker's element access had no string arm.

- An object literal whose method returns its own `this` (`[Symbol.iterator]() { return this; }`) is, in tsc, a recursive literal type. The checker builds no cyclic anonymous types (its printing and widening walk types without a cycle guard), so the method, the literal and every read of it fell back.
- A loop variable over a boxed-element array (`for (var r of [0, 0n, true])`) and any literal holding it were unanswered: the union of element kinds has no representation.
- A for-of over such a literal called `[Symbol.iterator]()` without its receiver: the program compiled and threw "Cannot read properties of undefined (reading 'next')" where Node iterates.

- The checker binds the program before codegen's static-member rewrites (`staticThisToClass`, `staticPrivateBrand`, `liftStaticGenerators`) run, and types lazily: a class's value first asked for after them was typed from the rewritten class (a lifted generator method no longer a generator), and the nodes a rewrite built (`(brand check, C.#p)` for a static `this.#p`) were never bound. Every read of such a class's static private generator fell back — the second- and seventh-largest buckets.

- A js-lane function literal a member is read off (`(function (obj) {…}.apply(null, args))`) was unanswered: its call sites are out of sight, and only methods, returned, field-initializing and assigned literals took checkJs's `any` for that.

- A builtin function an intrinsic implements, held in a variable (`var __defineProperty = Object.defineProperty`, Test262's property helpers), was answered by its library signature (a box for the generic `defineProperty`), while emission builds a closure of `any` parameters (`emitBuiltinValue`); every call through it disagreed.
- A union or `any` variable a `typeof x === "symbol"` test narrows stayed a box in the oracle, while emission unboxes it to the symbol object.

- A union of class instances (`Array<Readable | Writable | null>`, `node:child_process`'s stdio) did not map: the oracle's union rejected every object member, though `resolveType` boxes such a union naming each class. And codegen's own narrowing of such a box (`checkerNarrowedUnion`) never matched a module's class: the checker's symbol keeps its mangled name, which `objectMemberNamed` compared against the member's unmangled one.

- A conditional between instances of two classes (`enc ? createCipheriv(…) : createDecipheriv(…)`) took the consequent's class and called its methods on either instance (a `TypeError` at run time for the alternate); once the union mapped, the box it became had no method dispatch at all, since only a box of scalars counted as self-describing.

## Decision

- An iterator-protocol object (one with a `next` method) yields the `value` of what `next()` returns, the members' values joined for a union of results. `asyncIteratedType` prefers an own `[Symbol.asyncIterator]`, awaiting `next()`'s result, and serves `yield*` in an async generator and `for await`.
- `literalFromReturns` boxes any unannotated, non-rest parameter without a default whose type has no representation, not only a destructured one, as emission does (checkerContextualParam takes only primitives and `any`); and a defaulted pattern parameter (`([[,] = g()] = []) =>`) likewise, since `patternDefaultType` falls back to `any` there.

- An empty array or object literal default is typed by its pattern, each element taking its own default's type (tsc's contextual typing by a binding pattern); codegen takes a pattern parameter's type from the checker, mapped as the oracle maps it, falling back to the literal.
- `reprCtx.object` widens an optional property's field with `optionalFieldType`, as `resolveType` does.

- A number-typed index on a string reads `string`, as the String interface's `[index: number]: string` does.

- The oracle mirrors emission for a `this`-returning literal method: its result, and its body's return type, are a box, while the checker leaves the literal unanswered (no recursive type, no diagnostic lost). A literal whose checker type has no representation is built from its fields' representations, as `inferObjectType` builds it.
- A sync for-of loop variable over an array of boxed elements is a box.
- `emitForOfObjectSymbolIterable` passes the object as `this` to a method taking one, held under a hidden name so the iterable is evaluated once.

- `warmStatics` has the checker type each class's value and its static members' bodies before those rewrites, keeping each answer (`frontWarm`: the checker's own memo drops an answer reached inside the class-value cycle). `staticPrivateBrand` links every node it builds to the expression it stands for (`originate`); the oracle answers such a node by its original's kept checker type, a sequence by its last expression, and a `C.#m` the rewrite named by the static member codegen registered.

- Such a literal's parameters are `any` (`isMemberReceiver`), as checkJs types them.

- Such a member read, the variable's global type and a read of a variable whose only store it is are the closure `builtinRefValueType` names.
- A narrowed symbol reads as the symbol object, as a narrowed boolean, number or string reads unboxed.

- A union whose object members are class instances maps to the box naming them; a read the checker narrows to one of them (`x instanceof A`) is that instance, and `objectMemberNamed` unmangles both names.

- Such a conditional is the union's box, or the common base class when the checker's type is that; a method call on a box of class instances (`isClassUnionBox`) is the dynamic dispatch on the instance's own class.

## Consequences

- `TestYieldStarOverProtocolObject` covers the async and sync delegations.
- `TestE2EPatternParameterEmptyDefault` matches Node; `TestStringNumberIndex` covers the string index; `TestE2ESelfIteratorLiteral` matches Node in both lanes; `TestJSMemberReceiverParams` covers the receiver case; `TestE2EClassUnionInstanceofNarrowing` and `TestE2EConditionalClassUnionMethod` match Node.
- A `yield*`/`then` chain over a hand-built async iterable prints what Node prints.
- Verified on Apple Silicon (checker package; the Test262 file named in the report reports no rows).
