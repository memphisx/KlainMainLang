# ADR-01376: A value is used in the representation it was emitted in

- **Relations**: Extends ADR-01373, TDD-00230 P3.3
- **Date**: 2026-10-03

## Context

Conformance of the tree through ADR-01375 measured 56 strict and 80 js
files of invalid IR, against 39 at HEAD, and test-par failed 233 tests
(zlib, child_process, workers, performance) with
`select i1 %c, ptr %v, ptr null` on an `i64`. Most of the invalid IR came
from one pattern: a site decided a value's representation from
`inferExprType`, emitted the value, and then used the emitted register as
the inferred representation, while the two disagreed.

## Investigation

- **Collection iterator result.** `emitCollIterNext` built the `value`
  of a done step as `select …, ptr …, ptr null` for every element type. A
  boxed (`any`) element is an `i64`. ADR-01373's fixed-point layout
  generation now emits host `next` adapters this previously skipped,
  which is what reached 233 tests.
- **typeof.** `typeof Math.E` (inferred `any` under `-compat=js`, emitted
  a double) and `typeof Function.prototype.length` (inferred a number,
  emitted a box) used the inferred branch's code on the emitted value.
- **Dynamic member access.** `emitDynAnyMethodCall`, the dynamic get and
  the dynamic set are contracted to a boxed receiver; a well-known Symbol
  or a numeric constant reached them unboxed
  (`Symbol.toPrimitive[Symbol.toPrimitive]()`,
  `(Number.NEGATIVE_INFINITY).toLowerCase()`).
- **Equality.** `===` between a `number` parameter and a function compared
  the two registers (`icmp eq i64 …, ptr …`).
- **Operators.** A function operand of `*`, `-`, `<` … reached the integer
  instruction as a pointer; a Promise or host operand of a string `+`
  reached `add ptr`.
- **Property keys.** `dynAnyKeyRef` formatted every non-string,
  non-float key with `%lld`, so a function key was a pointer passed as an
  integer; `obj[null] = v` passed a null key pointer and crashed at run
  time (HEAD too).
- **Map/Set keys.** A function key used the numeric key runtime.
- **Date.parse as a value.** Its wrapper takes `any`; the intrinsic passed
  the box to a `ptr` parameter.
- **Atomics.** A Symbol index threw (ending the block) and the code after
  it still used a register defined in the dropped instructions; a string
  `count` was coerced to `i64` unconverted.
- **An all-nullish literal** (`[, , ,]`) under `-compat=js` was
  `undefined[]`, so `indexOf(10)` compared a double with `strcmp`.

## Decision

- `emitCollIterNext` selects the absent value by representation: null for
  a pointer, the undefined word for a box, the zero otherwise.
- `typeof` answers from the emitted value (`typeofValue`) whenever the
  emitted representation differs from the inferred one.
- The three dynamic entry points box a non-boxed receiver themselves.
- An equality between a pointer and a number/boolean register
  (`reprMismatch`) compares boxed values: `emitAnyEquals` for `===`,
  `emitAnyLooseEquals` for `==`.
- A function operand of an arithmetic, bitwise, shift or relational
  operator is boxed, so it takes ToPrimitive then ToNumber; a Promise or
  host operand of string `+` is boxed, so it renders as `[object X]`.
- `dynAnyKeyRef` formats only integers with `%lld`; `null`/`undefined`
  literals key as `"null"`/`"undefined"`, a nullable string that is null
  as `"null"`, and every other value by its ToString.
- `isReferenceKeyTy` includes functions: they key Maps and Sets by
  identity through the boxed runtime.
- `Date.parse` takes ToString of its argument.
- Atomics continues in a fresh (unreachable) block after a throwing
  ToNumber, and `notify`'s count is ToIntegerOrInfinity(ToNumber(count)),
  at least 0, `undefined` meaning every waiter.
- Under `-compat=js` a literal of only holes, `undefined` and `null` is
  `any[]`, as TypeScript infers it in a JavaScript file.
- A conversion that throws (ToNumber of a Symbol or a BigInt) continues in
  a fresh, unreachable block, so its caller's later instructions are not
  dropped while a later block uses them (DataView with a Symbol argument);
  ToBoolean of a Symbol is `true`.
- The runtime ToPrimitive (`boxsrc/toprim.c`) throws "Cannot convert object
  to primitive value" when an object's own `toString` returned an object and
  no method gave a primitive, and, for a dynamic object without its own
  `toString`, stops at the inherited `Object.prototype.toString`
  (`String({ valueOf() { return 1 } })` is `"[object Object]"`).

## Side effects discovered

These no longer produce invalid IR but still differ from Node; each is a
missing feature:
- `Function.prototype` reads `undefined`; `Array.prototype.reduce.call`
  and `Object.getOwnPropertyDescriptor(Date, "parse")` are unsupported.
- `Symbol.prototype`'s methods are not readable through a boxed symbol
  (only `description` is).
- A method assigned to a primitive's prototype
  (`Number.prototype.toLowerCase = …`) is not seen by a typed number
  receiver.
- `[, , ,].indexOf(undefined)` is 0, not -1: a hole is an `undefined`
  element (TDD-00226).
- An async generator's `yield` does not await its operand, and
  `yield*` over a sync iterator does not await each value.
