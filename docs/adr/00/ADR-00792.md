# ADR-00792: console.group variadic labels + console.groupCollapsed alias

- **Relations**: `Extends ADR-00029`, `Implements TDD-00024`
- **Date**: 2026-09-08

## Context

Two edges of the `console` grouping API diverged from Node:

- `console.group(...)` rejected more than one argument, but Node accepts a
  variadic label list and formats it exactly like `console.log`
  (`console.group('a', 'b')` prints `a b`).
- `console.groupCollapsed(...)` was unimplemented and hit the generic "no
  method" rejection. In a terminal it is identical to `console.group` — only a
  browser devtools console renders the group collapsed — so Node's Node-side
  behaviour is a plain alias.

## Investigation

- `emit_call.go`'s console dispatch had `case "group"` only; `emit_call_console.go`'s
  `emitConsoleGroup` had a `len(args) > 1` hard error and printed only when
  `len(args) == 1`, passing the whole `args` slice to `emitConsolePrint` (which
  already applies the group indent and space-joins arguments like `console.log`).
- `console.dir` already routes through `emitConsolePrint`, so it is already
  group-indent-aware — no change needed there; its only caveat (`colors`
  ignored, no ANSI) is a genuine, disclosed one and stays.
- Node parity confirmed: `console.group('label', 1, true)` → `label 1 true`;
  `console.groupCollapsed('c')` indents exactly as `console.group('c')`.

## Decision

- `emitConsoleGroup`: drop the arg-count restriction; when any args are
  present, print them all via `emitConsolePrint` (variadic, format-aware, at the
  current pre-increment indent), then increment the depth. Zero args still just
  increments, as before.
- Dispatch: `case "group", "groupCollapsed"` both route to `emitConsoleGroup`.

## Implementation notes

- Files: `codegen/llvm/emit_call.go` (dispatch), `codegen/llvm/emit_call_console.go`
  (`emitConsoleGroup`). No new runtime — the existing indent/print path is reused.
- A stale comment in `examples/console/console.ts` claimed `console.log`
  prints one argument per line "unlike real Node"; the shipped behaviour
  space-joins arguments on one line (matching Node, as its own passing test
  asserts), so the comment was corrected in passing.

## Side effects discovered

None. `groupEnd` and the depth flooring are unchanged.

## Verification

macOS (Apple Silicon M4). New tests `TestE2EConsoleGroupVariadicLabel` and
`TestE2EConsoleGroupCollapsedAliasesGroup` pass; the existing
`TestE2EConsoleGroup*`/`TestE2EConsoleDir*` suite stays green; a combined
group/groupCollapsed/dir program is byte-identical to Node's output;
`make examples` runs `console.ts` clean.
