# ADR-01243: `readline` is a TypeScript module

- **Relations**: `Implements TDD-00235`, `Extends ADR-01238, ADR-01239`
- **Date**: 2026-09-29

## Context

`readline` was code-generated (`emit_readline.go`, `runtime_readline.go`):
input was always stdin and output always stdout, with one interface at a
time and one listener per event. It had no terminal line editing, history,
completer, `prompt`, `for await` or `readline/promises`, and couldn't read
a file or a child's stdout line by line. TDD-00235 stage 1 (ADR-01239) made
`process.stdin` a real stream, so readline can run over it.

## Decision

- **Port.** Node v24's `lib/readline.js`, `lib/readline/promises.js` and
  `lib/internal/readline/*.js` become four files:
  - `lib/node/readline.ts`;
  - `lib/node/readline_promises.ts`;
  - `internal_readline_interface.ts` (the Interface, `emitKeypressEvents`,
    the in-memory part of `internal/repl/history`);
  - `internal_readline_utils.ts` (`emitKeys`, the character widths,
    `getStringWidth`/`stripVTControlCharacters` from `internal/util/inspect`).
- **How Node's structure maps:**
  - symbol-keyed state becomes `#private` fields;
  - the legacy underscore members (`_ttyWrite`, `_refreshLine`, `_prompt`,
    …) are ordinary members;
  - the hooks `readline/promises` needs are `_kml`-prefixed methods.
- **`events.on`** (the line iterator) gets Node's `highWaterMark`/
  `lowWaterMark` backpressure: it pauses the emitter above the high mark
  and resumes it below the low mark. It also gets the internal
  first-argument mode Node's `kFirstEventParam` selects, here an
  `_kmlFirstEventParam` option key.
- **Deleted:** the code-generated readline, its event-loop hooks
  (keepalive, fd set, dispatch) and its handle type. `readline` is no
  longer a virtual module.
- **Compiler support the port needed:**
  - `[Symbol.dispose]`/`[Symbol.asyncDispose]` as class member names;
  - `for await` over a class whose `[Symbol.asyncIterator]()` returns
    `any` drives that iterator through the dynamic protocol.

## Implementation notes

- **Line endings.** A RegExp match result has no `index` yet, so
  `_normalWrite` and `_ttyWrite` find line endings with a scanner. It
  matches the same endings as Node's `lineEnding` regex (`\r\n`, `\n`, `\r`
  not before `\n`, U+2028, U+2029).
- **Ctrl+Z.** `process.once('SIGCONT')` doesn't exist yet (`process` is
  code-generated until P3.2), so Ctrl+Z's resume work runs right after
  `process.kill(process.pid, 'SIGTSTP')`. A signal a process sends itself
  is delivered before `kill` returns: the process stops there and
  continues when SIGCONT arrives, which is where Node's listener runs.
- **`TERM=dumb`** applies to the legacy Interface only, as in Node.

## Side effects discovered

- **Not reachable yet:**
  - `readline.promises` holds only `createInterface` (a class is not a
    value, BACKLOG 81);
  - `util.promisify(rl.question)` isn't the promise form (a class's
    `prototype` is not reachable);
  - `String.prototype.normalize` is missing, so widths skip Node's NFC step
    (combining marks are zero-width either way).
- **Compiler gaps worked around in the port:**
  - a function returning a tuple typed `[a, b] | null` emits invalid IR;
  - an `any` object converted to a declared interface drops the properties
    the interface doesn't declare;
  - `super(message, options)` on `Error` is rejected.
- **Old tests asserted non-Node behaviour:**
  - `TestE2EReadlineExplicitClose`: Node still emits the lines already read
    in the same chunk after `close()`;
  - a multi-character chunk inserts a tab literally (completion only runs
    on a chunk's last character).

## Verification

Mac (Apple Silicon), against Node v24.19, all identical to Node:

- **E2E tests:**
  - `TestE2EReadlineFileStreamAndPromises` (a file stream with
    `crlfDelay: Infinity`, `readline/promises` question);
  - `TestE2EReadlineTerminalEditing` (arrows, Ctrl-A/E, backspace,
    history, completion);
  - `TestE2EEventsOnWatermarksAndClose`;
  - the existing readline and stdin tests.
- **Manual comparisons:**
  - question + prompt + pause/resume;
  - `readline/promises` + `for await` over piped stdin;
  - a child's stdout.
