# ADR-01910: an overloaded function's closure result; an empty array branch under context

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

- A call of an overloaded function runs its implementation, so one whose implementation declares a function return (`promisify(f)`, `(...args: any[]) => Promise<any>`) returns that closure. The oracle answered the picked overload's signature (`(arg1: number) => Promise<string>`) at the call, its binding and each read of it.
- The checker typed a conditional's empty array branch as `never[]` only without a contextual type, so `ds = c ? [] : xs` under `ds: string[]` was unanswered; tsc types the empty literal `never[]` either way and reduces it away beside the other branch.

## Decision

- The oracle answers such a call, and an unannotated binding of one, with the implementation's declared return.
- The checker's empty branch is `never[]` with or without a contextual type.

## Consequences

- The util module's promisify and debug rows go away.
