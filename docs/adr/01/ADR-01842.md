# ADR-01842: ArrayLiteral and NewExpression switched to the checker

- **Relations**: `Implements TDD-00230` (P3.3: the checker answers what inferExprType did)
- **Date**: 2026-10-20

## Context

The previous full shadow run left 4 ArrayLiteral and 9 NewExpression disagreements:

- `new (await Array)`, `new (await Map)`: emission constructs through the value a computed callee holds (`emitDynNew`). The instance is a program class the checker resolves, otherwise a box (`checkerInstanceType`). The oracle named the builtin.
- `new Proxy(target, handler)` is held boxed. The oracle answered with the target's type.
- `[never, seen]`: a nullable string and a nullable number form no union emission joins, so their elements are boxed. The oracle gave a union box.
- `[...headers]` over a Map: emission builds `[key, value]` tuples. The oracle mapped the checker's tuple to an array.
- `[this.#currentTarget]`: emission builds an array of the element as held (a nullable class). The oracle used the checker's narrowed element.

## Decision

- The oracle mirrors each case:
  - a computed callee gives the resolved program class, else a box;
  - a builtin `Proxy` gives a box;
  - a literal whose answer is a union of elements is re-joined as emission joins it;
  - a spread Map gives the checker's tuple type, with tuples kept;
  - a one-element literal of an object or class gives that element as held.
- The mixed-literal join is shared with the old inference rather than copied. `inferMixedArrayElem` and the kinds check became `mixedArrayElem` and `mixedKindsBoxed`, each over a function that types the elements. Emission passes `inferExprType`; the oracle passes its own answers, and uses the result only when it answers every element.
- A literal spreading a box, or holding one beside other elements, is `any[]`, as `inferArrayTypeOf` makes it.
- ArrayLiteral and NewExpression join the switched kinds. A node the checker has no answer for falls back to the old inference and is logged as `switchFallback`.

## Consequences

- No disagreements remain in the files behind the 13 rows.
- Verified on Apple Silicon (targeted array/spread/literal/tuple/new/proxy/class/collection tests) and with the gate on Linux x86-64 (DeskMini): examples 417/417, E2E green. The unit test that named ArrayLiteral as an unswitched kind now names ArrowFunction.
