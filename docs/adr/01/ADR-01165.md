# ADR-01165: The web APIs declared: fetch, URL, text encoding, events and abort

- **Relations**: `Implements TDD-00230` (P3.1); `Extends ADR-01164`
- **Date**: 2026-09-25

## Context

The REST client is this project's first priority, and its surface —
`fetch`, `Request`, `Response`, `Headers` — was undeclared: the checker
left every `fetch(…)` and every read of a response unanswered, so a
`const n: number = res.statusText` reached code generation's own rejection
instead of tsc's TS2322.

## Investigation

- `@types/node` declares these in `web-globals/fetch.d.ts` through
  conditional types (`typeof globalThis extends { onmessage: any } ? {} :
  undici.Response`), selecting undici-types' classes when the DOM library
  is absent. The checker does not model those conditionals.
- undici's and TypeScript's DOM declarations differ in shape: undici
  declares classes with function-valued readonly properties, and
  `json(): Promise<unknown>`; `lib.dom.d.ts` declares interfaces with
  methods, `declare var Response: { prototype; new(…); error(); … }`, and
  `json(): Promise<any>`. `tools/libconform` checks against TypeScript's.

## Decision

- **`lib/node.d.ts`** declares `fetch`, `Request`, `Response`, `Headers`,
  `RequestInit`, `ResponseInit`, `Body` and the init and enum types in
  TypeScript's `lib.dom.d.ts` shapes, which is what tsc checks a program
  against by default. `json()` is `Promise<any>` accordingly.
- **`URL` and `URLSearchParams`** have their constructors and TypeScript's
  members (`URL` was a type without `searchParams`; `URLSearchParams`
  was undeclared).
- **`TextEncoder` and `TextDecoder`**, with `BufferSource` and
  `AllowSharedBufferSource`, as TypeScript declares them.
- **`EventTarget`, `Event`, `CustomEvent`, `AbortController` and
  `AbortSignal`**, with their init and listener types. `AbortSignal`'s
  `addEventListener<K extends keyof AbortSignalEventMap>` overload names an
  indexed event-map type the checker does not model, which leaves a call of
  `signal.addEventListener` unanswered (one unanswered overload leaves the
  set unanswered, ADR-01148).
- **Node's `duplex` option** stays in `RequestInit` (undici's streaming
  upload option, absent from the DOM library): an allowlisted divergence
  (`tools/libconform/allow.txt`).
- Names not declared yet (`ReadableStream`, `Blob`, `FormData`,
  `MediaSource`, the `Headers` and `URLSearchParams`
  iterators) leave the members that name them unanswered.

## Verification

- **tools/libconform:** 0 divergences not allowlisted.
- **tsdiag, TS 7.0.2 corpus:** 3,157 diagnostics, 0 false positives.
- **Checker:** `const n: number = (await fetch(u)).statusText` is TS2322.
- **Tests:** the fetch, Request, Response, Headers, URL, text-encoding, event and abort groups.
