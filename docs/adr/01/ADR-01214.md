# ADR-01214: An unannotated mixed array literal is an array of a union

- **Relations**: `Implements TDD-00200`
- **Date**: 2026-09-28

## Context

`const a = [new P(), 2]` type-checks in TypeScript as `(P | number)[]`.
The strict lane rejected it as a heterogeneous array; only an annotation
(`(P | number)[]`) or `-compat=js` compiled it.

## Investigation

`inferArrayType` took the first element's type unless `-compat=js`
boxed the literal to `any[]`. Annotated union arrays already store boxed
elements, and a class instance or plain object in a union now renders and
serializes from its layout row (ADR-01213).

## Decision

- `inferMixedArrayElem`: a literal whose elements are of two or more kinds
  is an array of their union. The allowed kinds are number, string,
  boolean, an array (by storage), a class instance with a header word and
  a plain object type; a `null`/`undefined` element makes the union
  nullable.
- The literal stays uniform-inferred (and rejected) when it has a spread,
  a promise, a function, a Map/Set, a stream, a bigint, an `any`, or two
  object members (a union of objects needs a discriminant, BACKLOG 71).
- `JSON.stringify` serializes a union element whose members render from
  their box the way console.log does (`inspectsByTag`).

## Implementation notes

`codegen/llvm/emit_exprs_types.go`, `emit_call_json.go`.

## Side effects discovered

`Promise.all([p, 4])` (a promise among values) stays rejected in the
strict lane.

## Verification

Mac (Apple Silicon), against Node v24.19: `TestE2EMixedArrayLiteralInfersUnion`.
