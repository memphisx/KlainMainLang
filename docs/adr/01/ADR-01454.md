# ADR-01454: A generator's TReturn shares its value slot

- **Relations**: Extends ADR-00172
- **Date**: 2026-10-07

## Context

`function* adder(): Generator<undefined, number, number> { …; return a + b }`
returned `undefined` from its last `.next()`; Node returns the sum.
`examples/generators/generator_sent_value.ts` needs this annotation now
that the strict lane reports TS7057, as tsc does, for its unannotated
`yield` results.

## Investigation

A generator object holds one value slot for what it yields and what it
returns, typed by the annotation's first type argument; TReturn was ignored.

## Decision

When the annotation's TReturn has a representation other than T's (and is
not void or undefined), the slot is `any`, so both fit.

## Verification

- `TestE2EGeneratorReturnTypeArgument` (against Node); the example passes
  and tsc 5.9 accepts it.
