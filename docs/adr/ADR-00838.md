# ADR-00838: `f(undefined)` triggers a defaulted parameter's default

- **Relations**: Extends [ADR-00164](ADR-00164.md) (default/optional parameters)
- **Date**: 2026-09-10

## Context

Calling a function with an explicit `undefined` argument for a **defaulted**
parameter did not trigger the default: `f(undefined)` for `f(x: number = 5)`
returned `0` (the `undefined` coerced to the param's zero) instead of `5`. In
JS/TS, an explicit `undefined` argument is treated as *omitted* for the purpose
of default substitution — `f(undefined)` is equivalent to `f()`.

## Investigation

`emitCall`'s argument loop (`emit_call.go`) chose the provided-arg path whenever
`i < len(args)`, evaluating `args[i]` and coercing it to the parameter type — so
a literal `undefined` became the param's zero value, and the default branch
(`sig.Defaults[i]`) was never reached. The default only applied to a genuinely
omitted argument.

## Decision

Before dispatching, if a provided argument is a literal `undefined` (a
`NullLiteral` with `IsUndefined`) and the parameter has a default, treat the
argument as **not provided** (`argProvided = false`), so control falls into the
existing default-evaluation branch. Everything else — non-`undefined` args,
`undefined` for a param with no default (still the `T | undefined` / zero path),
rest parameters — is unchanged.

## Implementation notes

`emit_call.go`: the loop's `i < len(args) && …` condition is lifted into an
`argProvided` variable, cleared for the literal-`undefined`-with-default case.
Scoped to the compile-time literal `undefined`; a *runtime* `T | undefined`
value that happens to be `undefined` passed to a defaulted param is not covered
(it would need a per-argument runtime presence check + default) — rare, and left
for a follow-on if it ever matters.

## Verification

macOS (Apple Silicon M4): `f(undefined)` → `5` (the default), `f()` → `5`,
`f(10)` → `10`; a string default `g('x', undefined)` → `x-def`. New
`TestE2EDefaultParamExplicitUndefined` + the func/default/call/param/optional
suites green.
