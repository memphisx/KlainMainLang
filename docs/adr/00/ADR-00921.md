# ADR-00921: Non-callable `.then`/`.catch` handlers are treated as undefined (invalid-IR sweep)

- **Date**: 2026-09-13

## Context

`p.then(3, 5)` and `p.catch(42)` emitted the raw handler argument into the
callback closure's `ptr` slot. A numeric literal lowered to a `double` constant
(`store ptr 0x4008000000000000, ...`) stored into a `ptr` field — clang rejected
it ("floating point constant invalid for type"). Surfaced in the Test262
CLANG_ERROR sweep (`built-ins/Promise/prototype/then/S25.4.5.3_A4.2_T{1,2}.js`,
which pass non-callable `then` arguments deliberately).

Only a literal `null` was previously recognised as "no callback"
(`isAbsentCallback`); a non-callable *value* fell through to the store path.

## Decision

Per PerformPromiseThen / `Promise.prototype.catch`, a non-callable handler is
treated as `undefined` — the fulfilment value (or rejection) passes through
unhandled. Recognise a statically non-callable argument and lower it to a null
callback slot rather than storing the value as a callback pointer.

`isNonCallableThenArg(arg)` returns true for a literal `null`/`undefined` or an
argument whose inferred type is a concrete non-function (`!IsFunc && !IsDynamic`).
`any`/`unknown` arguments may hold a function at runtime, so they are never
statically dropped. Wired into both `then` arguments and the `catch` argument.

## Implementation notes

- `codegen/llvm/emit_promise_then.go`: added `isNonCallableThenArg`; the `then`
  onFulfilled/onRejected sites and the `catch` site now use it. A non-callable
  `catch` handler takes the pass-through path (rejection propagates), keeping the
  returned promise's value type.

## Verification

- `TestE2ENonCallableThenCatchHandlers` (new): `g().then(3,5)` /  `g().catch(42)`
  compile and pass the resolved value through, matching Node (`v 7` / `c 7`).
- The two `then/S25.4.5.3_A4.2_T*` files no longer emit invalid IR (they now
  reach runtime; residual object-identity-through-promise mismatch is the
  pre-existing static-object gap, unrelated).
- Promise/async/then/catch/reject test lane green; macOS arm64.
