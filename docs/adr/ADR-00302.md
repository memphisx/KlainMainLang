# ADR-00302: `CompressionStream` / `DecompressionStream` over zlib

- **Relations**: Implements [TDD-00097](../tdd/TDD-00097.md) Stage 6; extends [ADR-00298](ADR-00298.md)
- **Date**: 2026-08-22

## Context

TDD-00097 Stage 6: gzip/deflate as WHATWG transform streams, completing the
pipeline's standard codec pair. `-lz` is linked only when one of the two
constructors is actually used — the same used-only discipline libcurl has.

## Investigation / Decision

- Each instance is an ordinary `%kml.ts` TransformStream context (ADR-00298),
  so `.readable`/`.writable`/`pipeThrough`/`pipeTo` ride the existing
  machinery untouched — the only new pieces are native transform/flush
  closures over a zlib `z_stream` (`runtime_streams_zlib.go`):
  `__kml_zs_transform` points `next_in` at the chunk and pumps
  deflate/inflate into 64 KiB output blocks enqueued on the readable side;
  `__kml_zs_flush` drives `Z_FINISH` to `Z_STREAM_END` (deflate) or ends the
  inflate state. `Z_BUF_ERROR` is treated as "no progress right now"; any
  other error errors the readable side.
- `z_stream` is an opaque 112-byte calloc — the size is verified against
  zlib.h on this machine and re-checked at runtime by the `*Init2_` entry
  points (they reject a mismatched `sizeof`). Formats map to windowBits:
  gzip 31, deflate (zlib-wrapped) 15, deflate-raw −15; inflate uses 15+32
  auto-detection for the wrapped formats.
- The format argument must be a string literal (compile-time windowBits
  selection); chunks are `Uint8Array` in and out (text goes through
  `TextEncoder`/`TextDecoder`, as in the spec).

## Fixed in passing — bare-return closures crashed

Wiring pull-driven sources into the codec pipeline hit a **pre-existing
crash** (verified present in the pre-streams compiler): an unannotated
closure whose only `return` is a bare `return;` inferred the scalar default
return type, so the bare return emitted `ret i64 0` and the fall-through end
emitted a runtime-reachable `unreachable` — `brk` at the first fall-through
exit. Every earlier stream test happened to use if/else rather than
early-return callbacks, masking it. Both closure emitters (arrow + function
expression) now infer `void` when a block's returns are all bare.

## Verification

- `tests/streams_test.go` Stage 6 block: a gzip round-trip through
  `tee()` (magic bytes `1f 8b`, compression ratio, byte-exact recovery);
  `deflate` and `deflate-raw` round-trips; **cross-implementation interop
  both ways** — Go's `compress/gzip` output decoded through fetch's
  streaming `Response.body` piped into `DecompressionStream`, and a
  compiled server's `CompressionStream`-compressed chunked response decoded
  by Go's gzip reader. Plus the bare-return regression test.
- `examples/streams/gzip.ts` (4200 → 90 bytes, round-trip intact).
- Full `go test ./...` green, `go vet` clean (Mac); Linux verification via
  an arm64 Debian container (clang 19, GnuTLS libcurl, zlib) — see the
  platform note in [TDD-00097](../tdd/TDD-00097.md)'s status trail.
