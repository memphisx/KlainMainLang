# ADR-01260: A captured Map/Set is boxed at its declaration

- **Relations**: `Extends ADR-00619`
- **Date**: 2026-09-29

## Context

`const frame = new Map(); if (p) { p.forEach((v, k) => frame.set(k, v)) }
frame.set(…)` emitted invalid IR ("Instruction does not dominate all
uses"). A local a nested closure captures is boxed at its declaration
(`hoistedCaptures`). The Map/Set declaration path and the handle
declaration path did not consult that set, so the local was boxed at the
closure, inside the branch.

## Decision

The declaration's slot is the heap cell for a captured Map/Set or handle
local (and the forward cell for one captured before its declaration), as
for arrays and scalars.

## Verification

Mac (Apple Silicon): `TestE2ECollectionOrUndefinedAndBranchCapture`.
