# ADR-01888: a conditional of a derived class's instance and its base's

- **Relations**: `Implements TDD-00230` (the strict lane is tsc)
- **Date**: 2026-10-21

## Context

- tsc types a conditional expression by subtype reduction of its two branches: `c ? new B() : new A()` with `B extends A` is `A`, so reading `b` off it is TS2339. The checker reduced only object-literal branches and kept `B | A`.

## Decision

- A conditional whose branches are two class instances, one deriving from and assignable to the other, is the base's instance. Interfaces keep the union: tsc's strict subtype relation compares them member by member (a Buffer beside a Uint8Array stays `Uint8Array | Buffer`), which assignability does not mirror.

## Consequences

- The strict lane rejects a derived member read off the reduced type as tsc does; the value keeps its own class at run time.
- Verified on Apple Silicon against tsc 5.6.3.
