# TDD-00246: Class members keyed by a declared symbol

- **Status**: Implemented
- **Date**: 2026-10-05

## Context

A class can declare a member under a literal computed name (`['a-b']`) or a
well-known symbol (`[Symbol.iterator]`, `[inspect.custom]`), each resolved
to a name at parse time. A member keyed by a symbol the program declares,

```ts
const kRefed = Symbol('refed');
class Timeout {
    [kRefed]: boolean | null = true;
    hasRef() { return this[kRefed]; }
}
```

is rejected ("a computed class member name must be a constant string or
number literal"). Node's own classes key their internal state this way, and
so does code ported from them. The timers port (ADR-01411) works around it
by setting the keys as run-time properties, `(this as any)[kRefed]`, which
live in the per-object expando table: about 1 KB a timer, kept for the
program's life under the default memory mode and retained under `-mm=gc`.

## Design

- **Which keys.** A computed member name that is an identifier bound to a
  top-level `const` initialized with `Symbol(<string literal>)` (or
  `Symbol()`), the form TypeScript types as `unique symbol`. Any other
  identifier, call or expression stays the rejection it is now.
- **Parsing and resolution.** The parser keeps the key expression on the
  member. After the resolver has renamed the program's bindings, the member
  is named by the const's final (mangled) name in a reserved form, so two
  symbols with the same description stay apart:
  `"\x01@@symf:" + description + "\x00" + mangledName`. The member then
  behaves as any field or method of the class: stored in the instance's
  layout, inherited, overridden.
- **Access.** `obj[k]` (read, write, compound assignment, `in`, call) whose
  key is such a const and whose receiver is a class instance with that
  member lowers to the member's static access; any other `obj[k]` keeps the
  dynamic path, which also finds the member through the shape's getter (the
  shape's `get` compares the key's run-time `"\x01@@sym:%p"` form against
  the symbol the const holds).
- **Checker.** A `const` initialized by `Symbol(...)` gets a `unique symbol`
  type carrying its declaration, so a class member keyed by it is a named
  member for lookup: `this[kRefed]` types as the member's declared type.
  A computed class member name of plain `symbol` type is TS1166, as in tsc.
- **Reflection.** `util.inspect` shows the member as `Symbol(description)`
  after the string keys; `Object.keys`, `for…in` and `JSON.stringify` skip
  it; `Object.getOwnPropertySymbols` lists the const's symbol.
- **Then** `lib/node/internal_timers.ts` declares its five symbol-keyed
  members and drops the expandos.
