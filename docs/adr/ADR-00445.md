# ADR-00445: statusgen importer retained as on-demand tooling (TDD-00145 Phase 5)

- **Relations**: Implements [TDD-00145](../tdd/TDD-00145.md) Phase 5; Extends [ADR-00444](ADR-00444.md)
- **Date**: 2026-08-29

## Context

[TDD-00145](../tdd/TDD-00145.md)'s final phase: "retire the importer once the
forward gate is proven; keep as an on-demand re-derivation tool if cheap." The
forward gate is proven: since the flip ([ADR-00444](ADR-00444.md)),
`make status-check` holds all 33 pages in sync with `docs/status/data/`, and a
fresh `make status-roundtrip` re-verified the full corpus byte-identical.

## Decision

The importer is **retained**, not deleted — it meets the TDD's "if cheap" bar
squarely:

- It is ~350 lines with zero routine footprint: CI runs only `check`; nothing
  in the everyday `make status` path touches it.
- Two genuinely useful on-demand commands depend on it and would die with it:
  `export` (Markdown → data re-derivation, the recovery path after a deliberate
  hand-edit of a page) and `roundtrip` (the standing fuzz check that the schema
  still loses nothing in either direction).
- Its strictness doubles as a corpus lint — it is what surfaced the stale
  numbers and malformed rows during the flip.

"Retired" therefore means retired **from any routine role**, which was already
true at the flip: the JSON→Markdown direction is the only one exercised
routinely; `import`/`export`/`roundtrip` are documented as one-time /
re-derivation tools in `cmd/statusgen/main.go` and stay available for the day a
page is hand-edited or the schema is evolved.

With this, Phases 1–5 of the TDD are closed. The one item still open on it is
outside the phasing list: the website reference projection deriving
`badge`/`differences[]` from the status source (the TDD's Reconciliation
section), deliberately deferred pending an editorial review of the reference
`differences[]` content ([ADR-00444](ADR-00444.md)).

## Implementation notes

One code addition beyond the TDD's scope, delivered alongside the closure:
every generated page now opens with a do-not-edit HTML-comment banner naming
its JSON source (`<!-- GENERATED FILE — do not edit. Source of truth:
docs/status/data/<file>; edit the JSON, then run \`make status\`. -->`). The
banner is fully derived from the page's file name, so the round-trip stays
bijective: the generator emits it (`banner()` in `cmd/statusgen/gen.go`), the
importer requires and discards it (`stripBanner`). The repo README and the
Status-page-format spec now also state that the JSON is the source of truth.

Otherwise documentation-only: no code changes — the tool already had the shape this
decision keeps. TDD-00145's Status line, the TDD index row, and the README's
TDD-backlog row (authored in `docs/status/data/_index.json`, pages regenerated
via `make status`) now record Phases 1–5 as shipped with only the
reconciliation item remaining.

## Verification

On the Mac: `make status-check` green (33 pages) and `make status-roundtrip`
byte-identical across the corpus before the decision; `make status` +
`make status-check` green again after the `_index.json` ripple; with the
banner, all 33 pages regenerate, `check` and `roundtrip` stay green, `go vet`
is clean, and the website reference guard still passes (32 surfaces,
0 warnings) against the bannered pages.
