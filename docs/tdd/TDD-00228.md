# TDD-00228: Runtime handles in an `any` — a type-id word for Map/Set/Weak*/channel/Promise/Date

- **Status**: Superseded
- **Notes**: Superseded by [TDD-00230](TDD-00230.md) phase 5: every boxable object carries a header whose type id identifies it exactly. The bit-46 flag probe designed below is unsound on macOS arm64 (heap addresses exceed 2^46) and is not to be built.
- **Date**: 2026-09-22

## Context

`const m: any = new Map()` is a clean compile rejection (ADR-01060; before that it was invalid IR): a Map, Set,
WeakMap, WeakSet, WeakRef, channel or Promise value is `IR: "ptr"` without `IsObject`, so `emitBoxValue`
(`emit_dynamic.go:432-495`) would box it as a **kind-0 string pointer** and every consumer of the box would
misread it. `Date` is a bare `i64` and boxes as a number — its identity is lost rather than misread. Only
`RegExp`, which is an `ObjectType`, boxes correctly (as `kmlTagObject`). BACKLOG §0 item 14.

The NaN box (`runtime_nanbox.go`) has **no free pointer kind**: all eight low-3-bit kinds are assigned (string,
static object, array box, funcRef, stream, dynobj, dynarr, dynfunc). Errors and Symbols are told apart from a
plain static object by a hidden *field-0 type-id word* — `errorTypeIDFlag = 1<<48`, `symbolTypeIDFlag = 1<<47` —
which works because a user-space heap pointer (any real field-0 pointer in a plain object) is `< 2^47`.

Map/Set cannot reuse that as is: their 56-byte header (`runtime_collections.go:518-539`) has **`i64 size`
(the entry count) at offset 0**, read raw by 18 runtime sites and 2 emitter sites and written by 10 more, and the
same header backs Headers, EventEmitter, EventTarget, AbortSignal, the HTTP header/query maps, XHR, the Symbol
registry and two C sidecars (`http2.c`, `urlpattern.c`). WeakMap/WeakSet's field 0 is a list head pointer,
WeakRef's is the bare referent (and under `-mm=gc` a registered disappearing link — it must stay a bare pointer
word), a channel's is a `pthread_mutex_t`, a Promise's is the `i64` state word.

## Design

### Option A (recommended): a leading type-id word on every boxable handle

Prepend one hidden `i64` to each handle: `{ i64 typeid, …existing fields… }`, with `typeid = handleTypeIDFlag |
kind` and a new `handleTypeIDFlag = 1<<46` (bits 47/48 stay Error/Symbol; a plain object's field 0 is `< 2^46`).
`kind` enumerates Map, Set, WeakMap, WeakSet, WeakRef, channel, Promise, Date (boxed Date becomes a heap cell
`{ typeid, i64 ms }` only when boxed — statically it stays the bare `i64`). Every existing field offset shifts by
8; the change is mechanical but wide:

- Map/Set: 30 raw field-0 sites in `runtime_collections.go` / `emit_exprs_member.go` (`.size`) plus the group-map
  header; the sites *already* address fields by `getelementptr i8, ptr %map, i64 <offset>`, so the edit is a
  constant bump — best done by naming the offsets once (`mapOffSize = 8`, …) and replacing the literals.
  `http2.c`/`urlpattern.c` only call `create`/`set` — unaffected. A layout test in the style of
  `sidecar_layout_test.go` pins the offsets.
- WeakMap/WeakSet (`runtime_weak.go`): the head box grows to 16 bytes; `__kml_weak_delete`'s "prev may be the
  head" write moves to offset 8.
- WeakRef: `{ typeid, ptr referent }`; the disappearing link registers `&cell[1]`.
- channel (`klainsync.c` `ks_chan`): `int64_t typeid` as the first struct member.
- Promise (`runtime_task.go` `promiseStructIR`): field 0 becomes typeid, state moves to field 1 — every
  `i32 0, i32 0` promise access (~40 sites across `runtime_task.go`, `emit_async*.go`, `emit_promise_*.go`,
  `runtime_promise_adopt.go`) shifts; the Go constants `promise*Slot` already exist for most.

Then `emitBoxValue` boxes any of these as `kmlTagObject` (kind 1) and the `kmlTagObject` arms — `typeof`
(`"object"` for all of them, `"function"` never), `util.inspect` (`Map(2) { … }`, `Set(1) { … }`, `WeakMap {
<items unknown> }`, `WeakRef { <target> }`, `Promise { <pending> }`, a Date's ISO form), `JSON.stringify`
(`{}` for Map/Set/Weak*/Promise, the ISO string for Date), member-get/method-call (`size`, `get`, `set`, `has`,
`delete`, `add`, `then`, `deref`, `getTime`…), `instanceof Map/Set/WeakMap/WeakSet/WeakRef/Promise/Date` on an
`any` — probe the typeid word first, before the Error and Symbol probes. The `-compat=js` dynamic dispatch
(`emitDynAnyMemberGetNamed`, `emitDynAnyMethodCall`) gains one arm per kind that unboxes and calls the statically
typed implementation with the key/value family read from the header (a `kind` sub-field records the
str/num/any family so `get`/`set` through `any` pick the right hash).

### Option B (rejected): a ninth pointer kind

Would need a fourth tag bit; pointers are only 8-byte aligned, so no spare bit exists without changing the box
encoding (TDD-00156) and its C mirror in `dynjson.c`.

### Option C (rejected): a side table from handle pointer to kind

A global hash from pointer to kind consulted at every box/unbox — an allocation and a lookup per box, a leak per
handle in manual mode (nothing removes the entry), and a second source of truth for what the header already knows.

### Stages

1. Offsets named as constants + layout test (no behaviour change).
2. Map/Set typeid word; `emitBoxValue` + `typeof`/`inspect`/`JSON`/`instanceof` through `any`; the ADR-01060
   rejection lifted for Map/Set.
3. Member-get/method-call through `any` for Map/Set (`-compat=js` and strict where `any` is already allowed).
4. WeakMap/WeakSet/WeakRef/channel.
5. Promise + Date.

## Open questions

- Whether `Date` should become heap-allocated *always* (one representation) or only when boxed (two). The bare
  `i64` is a deliberate no-allocation design (`emit_date.go`); boxing-time allocation keeps that and costs one
  cell per boxed Date.
- Whether the typeid word should also carry the Map's key family or a separate byte is cleaner.
