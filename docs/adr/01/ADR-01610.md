# ADR-01610: Windows --static is self-contained; the webview pump on libuv

- **Relations**: Implements TDD-00253 (Windows), Extends ADR-00771, ADR-00772, ADR-01602
- **Date**: 2026-10-13

## Context

A `--static` Windows build of a program using `node:sqlite` and `BigInt`
imported `libsqlite3-0.dll` and `libtommath-1.dll`; Brotli and Zstd load
their DLLs at run time. Such a binary fails on a clean machine
(TDD-00253). Checking the webview build for the same property showed it
no longer linked at all since ADR-01602: its Windows page-tick pump called
`__kml_timers_run_due`/`__kml_timers_check`, the select loop's functions.

## Investigation

- Every needed archive is in the ucrt64 sysroot: `libsqlite3.a`,
  `libtommath.a`, `libz.a`, `libbrotlienc.a`, `libbrotlidec.a`,
  `libbrotlicommon.a`, `libzstd.a`.
- A static webview program imports no `WebView2Loader.dll`: the bundled
  webview library finds the WebView2 runtime itself, so TDD-00253's open
  question 4 does not arise for it.

## Decision

- Under `--static` on Windows (`winSelfContained`) sqlite3, zlib, Brotli and
  Zstd join pcre2 and c-ares as archives, and tommath (or gmp) links as
  `-l:lib<name>.a`.
- `klainzlib.c` built with `KZ_STATIC` takes Brotli's and Zstd's entry
  points from the link through a name table, instead of `LoadLibraryA`;
  without `--static` they stay optional and loaded on first use.
- The Windows webview pump runs one non-blocking pass of the loop
  (`__kml_loop_run_once`) per page tick: timers, I/O, tasks and microtasks.
- `--static`'s help and README say "self-contained" with each OS's meaning;
  the README's stale "known gaps" (cluster sharing, `--static` out of
  scope) go.

## Verification

Windows 11: `TestE2EStaticBinaryImportsOnlyWindows` (HTTP server, fetch,
zlib with Brotli and Zstd, sqlite, BigInt, RegExp, crypto: only Windows
DLLs imported, and it runs with only Windows' directories on `PATH`),
`TestE2ETuiBinaryIsSelfContained` and `TestE2EWebviewBinaryIsSelfContained`
with the same allow-list. macOS: TDD-00253 (Mac work).
