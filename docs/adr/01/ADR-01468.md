# ADR-01468: Date as a heap object; classes extending Date

- **Relations**: Implements TDD-00247 (stage 4), Extends ADR-01463, ADR-01466
- **Date**: 2026-10-08

## Context

A Date was its `i64` time value. Node's Date is an object, and the value
representation showed:

- `a === b` on two Dates compared their times, so two Dates made from the
  same time were equal;
- a setter needed a named variable (`b.when.setFullYear(…)` was a compile
  error), since only a variable's own slot could be written back;
- a Date key in a `Map` or `Set`, and `includes`/`indexOf` on a `Date[]`,
  went by time value;
- `class D extends Date {}` was a compile error (TDD-00247 stage 4).

## Investigation

- About fifty codegen sites read a Date's register as its time value:
  operators, `String`, `JSON.stringify`, inspect, the host box (a cell
  carrying the `i64`), `@lowerType date`, the `Date | undefined` slot (a
  `{ i1, i64 }` pair).
- `isStringTy` is true for every `ptr` without an object flag. Once a Date is
  a pointer, the Map/Set runtime choice (`mapRuntime`) and array search
  (`emitElemEq`, `searchKind`) took it for a string: content-hashed and
  `strcmp`'d. Map, Set and the other handle types had the same bug as
  keys and as `includes`/`indexOf` elements.
- `isHostHandle` excludes a type with `IsUndefined`, so a possibly
  undefined host value (`Date | undefined`, and every unchecked `dates[i]`
  read, which is typed so) boxed into `any` as a string.
- The checker leaves `a?.m()` untyped (`case e.Optional`), so an optional
  call on a pointer receiver, rebound to a synthesized local, found no
  intrinsic.
- The checker typed `new D(…)` for a class without a constructor only when
  its base is a class; a builtin base (`Date`, `Map`) left it unanswered.
- The checker did not check a compound assignment's result against its
  target (tsc's `checkAssignmentOperator`): `n += "x"` on a number reached
  codegen, and `d += 1` on a Date compiled, though tsc reports TS2322 and
  TS2365.
- `Date.now()` was typed as a Date, so `typeof Date.now()` was "object".

## Decision

- A Date is a pointer to a one-word body holding the time value, with a
  host header word at `body - 8` (`emitDateObject`), a headered host like
  Map, Set and RegExp: it boxes as its header, frees through `body - 8`,
  and a `Date | undefined` is a nullable pointer.
- The time value is read at each use (`emitDateTimeValue`); the formatting
  and calendar helpers keep taking it. A setter evaluates its receiver as
  any expression and stores the new time value into the body; the time
  value is read before the arguments are converted, as ECMA-262 orders it.
- Operators: two Dates compare by identity under `==`/`===`; a Date
  against a primitive is unequal strictly and compares its date string
  loosely; `-`, `*`, `/`, `%`, `**` and the relational operators take the
  time value as a number (NaN for Invalid Date); unary `+` and `Number(d)`
  too, NaN for an absent Date.
- A handle-typed (`hasHandleFlag`) Map/Set key rides the reference-keyed
  runtime; array search compares handles by identity.
- A possibly absent host handle boxes through a branch: absent is its
  keyword, present its box.
- An optional call keeps the intrinsic the written call resolves to; a
  Date receiver's method resolves by its representation when the checker
  gives none.
- `class D extends Date`: the instance is `[tag][time value][vtable]
  [fields]`. Without a constructor, `new D(…)` takes Date's arguments (an
  implicit constructor running field initializers then runs without them);
  `super(…)` sets the time value as `new Date(…)` would. Date's methods
  dispatch on the body (`emitHostBaseCall`), an override in the class wins,
  `String(d)`, `JSON.stringify` and inspect use Date's unless the class
  declares its own.
- The checker gives a class without a constructor, extending a value with
  construct signatures, those signatures making its instance
  (`inheritedConstructs`), and checks a compound assignment's result type
  against its target, sharing `checkOperator`'s operand rules
  (`checkArithmetic`).
- `Date.now()` is a number.

## Verification

- Found on the way, older than this work, each fixed here: a class field
  initialized from an earlier one (`n = this.s`) took the number type; a
  generic constraint naming another type parameter (`B extends A`) was
  matched as an unknown name. Both passed by accident while a Date was an
  `i64`.

`TestE2EClassExtendsDate`, the Date suite; each program the same output as
Node; `examples/classes/extends_date.ts`.
