# ADR-01862: A JavaScript function literal in an array takes any parameters

- **Relations**: `Implements TDD-00230` (P3.3: found while answering the shadow report's IndexExpression bucket)
- **Date**: 2026-10-21

## Context

- Under `-compat=js` an unannotated parameter takes its call sites' types where every call is in sight, and `any` where some position decides the call (a method, a returned function, a field, an assigned value). A function literal written as an array element (`var a = [function *(a) { yield a+1; }]`, Test262's `generators/no-name.js`) was in neither group: its parameter, the function, the array and every read of it (`a[0]`) had no type. checkJs gives `((a: any) => Generator<any, void, unknown>)[]`.
- Mapped, an array of functions whose signature has no closure representation (a generator's) had no representation either, though emission holds each such element boxed.

## Decision

- `isArrayElement` joins the positions whose function literal takes `any` for its parameters.
- An array whose element is a function type without a representation maps to an array of boxed elements.

## Consequences

- `TestJSArrayElementFunction` holds tsc 5.6's declaration types.
- Verified on Apple Silicon.
