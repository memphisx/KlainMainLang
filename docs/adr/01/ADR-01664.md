# ADR-01664: Builtin-name dispatch through per-owner tables

- **Relations**: Implements TDD-00230
- **Date**: 2026-10-17

## Context

Builtin calls dispatched by long `switch` statements keyed on a method or function name (`case "slice":`). Each statement listed the same names again: once to emit the call, again to infer its result type (`inferMethodNameType`), and again in `typeof` and in variable-declaration typing. A name added to one switch but not another produced a call that compiled one way and typed another way.

## Investigation

A census of string `case` arms in `codegen/llvm` counted 966. The result-type switch in `infer_structural.go` matched names before the receiver, so it answered for receivers it was never meant for. A trace of every lookup that reached its last fallback showed that only `toString` on an `any` receiver ever arrived there.

## Decision

Every builtin owner registers its names once, in a table that maps each name to an emitter and a result type:

- Result types: `stringMethodTypes`, `bodyMethodTypes`, `bufferMethodTypes` and `arrayMethodTypes` (`intrinsic_types.go`), and `objectStaticTypes`.
- Emitters: one per name for Math, Reflect, Date readers, `Object` statics, Map/Set and WeakMap/WeakSet.

`inferMethodNameType` and its fallback are deleted; `toString` on `any` is typed `any`, as `emitDynToStringCall` already produces. `typeof` on a member of a library global reads the checker's declared type, so the three hand-kept maps of "function" names are deleted. A variable declaration initialized by any other lowered call takes `inferExprType(init)` and no longer matches the callee's name.

## Implementation notes

- Math registers itself from the `init` of `emit_call_math.go`. Registering it from another file's `init` depended on file order.
- The generated Reflect `ownKeys` emitter is named `emitReflectOwnKeysCall`, because `emitReflectOwnKeys` was already taken.
- Buffer statics (`bufferStatics`), stream, reader and controller methods (`readableStreamMethods`, `streamReaderMethods`, `rsControllerMethods`, `streamMethodTypes`) and Map/Set result types (`mapMethodTypes`, `setMethodTypes`) are tables too. The Number predicates register their emitters directly; the `emitNumberStaticCall` switch and its unreachable `parseInt`/`parseFloat` arms are gone.
- `streamMethodTypes` is assigned in `init`: as a package-level initializer it formed an initialization cycle through `inferExprType`.
- `TestStringCaseArmsOnlyShrink` (`switch_ratchet_test.go`) holds the package's string case values at an allowance, currently 989. A new arm fails the test, and removing arms requires lowering the allowance.

## Side effects discovered

A local function named `fetch` failed to compile, because declaration typing matched the global's name. This was fixed by the generic path; the test is `TestE2EShadowedGlobalLocalFetchFunction`.

## Verification

- The emitted IR is byte-identical for the 68-file IR list after every step.
- Stage test-par passed with KML_KINDCHECK: 4162 tests on Linux (Node304).
- Test262 strict is unchanged at 8566/53578, with no invalid IR (Linux, DeskMini).
