# ADR-01284: `Object.is`; `Object.keys` of a boxed array

- **Relations**: `Implements part of TDD-00230` (P3.2)
- **Date**: 2026-09-29

## Context

Two gaps, found while porting `assert`:

- `Object.is` did not exist: "Object has no method 'is'".
- `Object.keys` of an array or TypedArray held in `any` returned `[]`
  where Node returns its index keys.

## Decision

- `Object.is` is declared with `@lower __kml_Object_is`, an IR runtime
  function over two boxed values:
  - two numbers are the same when their bits are, or when both are NaN,
    so `+0` is not `-0`;
  - anything else compares as `===`.
- `Object.keys` of a boxed static array or TypedArray lists `"0"` to
  `"len-1"`, from the box's live length (`__kml_anyarr_len`). The index
  keys come from one runtime function (`__kml_index_keys`), which the
  dynamic array's keys now use too.
- Still open (TDD-00230 P3.3) through `any`:
  - a `Date` boxes as a number;
  - a `RegExp` is a static object that `instanceof RegExp` and member
    reads do not reach;
  - a boxed `Map` or `Set` is not iterable.

## Verification

Mac (Apple Silicon): `TestE2EObjectIsAndKeysOfBoxedArrays` prints what
Node v24.19.0 prints.
