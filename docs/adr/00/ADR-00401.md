# ADR-00401: `assert.deepStrictEqual` and `process.on('warning')`

- **Relations**: Implements TDD-00131 (per-module Node API fidelity); Extends ADR-00395 (`process.emitWarning`)
- **Date**: 2026-08-27

## Context

Two concrete per-module gaps from the Node-oracle histogram: `assert.deepStrictEqual`
(9 files) and `process.on('warning')` (13 files, `got "warning"`).

## `assert.deepStrictEqual` / `deepEqual` (+ `not*`)

A recursive structural equality over the shared static type of the two operands
(this compiler's `==` is already strict, so `deepEqual`/`deepStrictEqual` are
aliases, as `equal`/`strictEqual` already are):

- Scalars (`icmp`/`fcmp`), strings (`strcmp`), booleans — direct.
- Arrays — equal length, then a runtime loop AND-ing element-wise deep-equality.
- Objects — AND of each visible field's deep-equality, recursing.

The recursion is compile-time (types are static), generating the comparison
inline, so nested shapes (`{ a: "hi", b: [1, 2] }`) work. Map/Set/class
instances, nullable-scalar members, and TypedArrays are a clean compile error
(V1). NaN uses `fcmp oeq` (not `Object.is`), a documented edge.

## `process.on('warning', handler)`

A `'warning'` listener slot (`@__kml_process_warning_handler`); `process.emitWarning`
still prints `(node:<pid>) <type>: <message>` to stderr (matching Node's always-on
default printer) **and**, if a listener is registered, additionally invokes it
with the warning as an `Error` object (`name` = the warning type, `message` = the
text) — verified to match Node's dual print-and-dispatch behavior exactly.

## Consequences

Both verified byte-identical to Node v26. `deepStrictEqual` is a common test-suite
primitive, so it unblocks assertion-heavy files; the `'warning'` event completes
the `emitWarning` surface (ADR-00395). Broad assert/process suites green.
