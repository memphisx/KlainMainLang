# ADR-01202: Generic classes — defaults, `any` arguments, accessors, `T` in bodies

- **Relations**: `Implements TDD-00230`, `Extends TDD-00010`
- **Date**: 2026-09-28

## Context

Writing `CustomEvent<T = any>` for TDD-00232 hit five gaps, each one also
reachable from user code:

- The checker inferred `unknown` for `new C({ detail: 5 })` when the
  constructor's parameter is an optional generic interface
  (`o?: Init<T>`); tsc infers `number`.
- Type-parameter defaults (`class C<T = string>`) were parsed and dropped:
  the checker gave `new C()` the type `C<unknown>` (tsc: `C<string>`), and
  codegen rejected a `new` without every type argument.
- Codegen refused `any` as a generic type argument.
- A getter or setter of a generic class was "no field": the instantiation
  registered it as a plain method.
- `x as T` inside a generic class member resolved `T` without the
  instantiation's type arguments (`new C<any>(5).d` was `undefined`).

## Investigation

- `hasTypeParam` (`checker/generics.go`) did not look into an interface or
  instance reference's type arguments, so `unify`'s union case found no
  generic member in `Init<T> | undefined`.
- `parseTypeParamList` parsed a default and discarded it; the checker's
  type parameters (`typeParamType`, `classTypeParam`) carried no default,
  and `classTypeParam` no constraint either.
- `mangleTypeArg` listed `IsDynamic` among the unsupported kinds.
- `instantiateGenericClass` keyed members by `m.Name`; `registerClasses`
  keys accessors by `accessorMethodName`.
- Generic functions emit their bodies under `withTypeParamScope`; class
  instantiations did not.

## Decision

- The parser returns the defaults, stored as `TypeParamDefaults` on
  function and class declarations. The checker's type parameters carry
  `Default` (and class ones their `Constraint`); inference with nothing to
  infer from takes the default, else `unknown` (tsc's `getInferredType`).
- `hasTypeParam` looks through interface/instance type arguments.
- Codegen completes a `new`'s type arguments from the defaults
  (`classTypeArgs`) at every generic-construction site; `any` mangles as
  `any`; instantiation members are keyed by `genericMethodKey` (accessors
  as `registerClasses` keys them, a setter's result discarded); a class
  instantiation's members are emitted under `withTypeParamScope`.

`parser/parser.go`, `parser_classes.go`, `parser_stmts.go`, `ast/nodes.go`,

## Side effects discovered

None beyond the five.
