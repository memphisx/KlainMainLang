# ADR-00799: node:ffi Stage C — registerCallback via static per-signature trampoline families

- **Relations**: Extends ADR-00797, ADR-00798; Implements TDD-00164 (Stage C)
- **Date**: 2026-09-09

## Context

Stage C is the piece TDD-00164 (and TDD-00032/TDD-00150 before it) named as
the one genuinely new codegen capability: `library.registerCallback` hands a
KlainMainLang closure to C as a raw C-callable function pointer. A closure is
two words (`{fn, env}`); a C function pointer is one word with no env, so the
env must be recoverable from the pointer alone. Every callback-driven C API —
`qsort` comparators, GUI event loops, `opentui` render callbacks — needs this.

## Decision

**Env recovery: the TDD's option (a) — static wrapper families + a
registration table.** No runtime code generation, no executable-memory/W^X
concerns (option (b) rejected), and no reliance on a `user_data` parameter
(option (c) — right for a future `klain:ffi` surface, but `registerCallback`'s
contract is exactly the no-`user_data` case).

Per **(FFI signature × closure KML ABI)** pair, the compiler emits once
(`emit_ffi_callback.go`):

- a 16-slot registration table (`[16 x {ptr fn, ptr env}]`, internal global,
  zero-initialized),
- 16 wrapper functions with the exact C-ABI prototype the signature
  describes, wrapper *i* hard-wired to slot *i*: load `{fn, env}`, marshal
  the C arguments to KML values, call the closure (`fn(env, args...)`), and
  marshal the return back to the C type. A cleared slot (fn == null) makes
  the wrapper return a zero value instead of crashing — Node's
  collected-callback semantics,
- a constant wrapper-address table and a small IR `register` helper that
  claims the first free slot and returns its wrapper's address.

The family key includes the closure-side ABI (number-vs-bigint per slot),
because the wrapper is shared: two closures of the same C signature but
different declared KML types get distinct families. Argument/return
compatibility is validated at the registration site with clear errors (64-bit
and pointer values must be `bigint` parameters, `string` must be `string`,
numerics may be declared as `number` in either int or float form — the
wrapper converts).

**Surface semantics:**

- `registerCallback([sig,] cb) → bigint` (the wrapper address; sig defaults
  to `void ()`). Arrow functions, function expressions, named functions, and
  function-typed variables all work (the standard `resolveCallback` path).
  All 16 slots taken → a catchable `Error`.
- `unregisterCallback(ptr)` clears the owning slot. The generic definition
  scans every family's address table, and is *defined at the end of
  EmitProgram* — the only point where the full set of families is known —
  with call sites forward-referencing it.
- `refCallback`/`unrefCallback` are validated no-ops: the registration table
  is scanned global data in every memory mode, so a registered callback is
  always strongly referenced and can never be collected — a safe superset of
  Node's semantics (the zero-return path exists only via explicit
  unregister).

## Consequences

- The callback-driven C API cluster (GUI loops, `opentui`, ncurses,
  comparator-style APIs) is unblocked; TDD-00164's three stages are all
  shipped.
- The cap: at most **16 concurrently-live callbacks per signature shape**
  (per family). Exceeding it throws with a clear message; the constant is
  one line to raise. Unregistered slots recycle.
- Node's runtime restrictions (same-thread invocation, no throwing, no
  promise returns) are not enforced — a throwing callback unwinds through C
  with undefined behavior, matching the module's overall unsafe posture.
- `library.close()` does not invalidate the library's callbacks (Node
  invalidates them) — documented caveat; unregister explicitly.

## Verification

- `tests/ffi_test.go` (macOS M4): libc `qsort` driven by a KML comparator
  closure (captured-variable mutation observed across C→KML calls),
  unregister + slot-reuse (the second registration returns the same wrapper
  address), a custom C library invoking int32/float64/string callbacks
  through stored function pointers, slot exhaustion throwing after 15 with
  one slot already live, and the compile-time bigint-parameter validation
  rejection.
- `examples/ffi/ffi.ts` extended with the qsort-comparator block. Node
  oracle re-run byte-identical.
