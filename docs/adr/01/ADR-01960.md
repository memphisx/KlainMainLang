# ADR-01960: A binding initialized `null` is null where it is compared

- **Relations**: Implements TDD-00230 (P2.3)
- **Date**: 2026-10-29

## Context

`let untouched = null`, never given another value, is held as `null`. The front end answered a read of it compared against `null` (`untouched === null`) with a box. The checker's storage type for the evolving `let` is `null | undefined`, and the representation step maps that union to a box, which keeps which of the two it holds. The rule that gives such a binding its `null` only recognised a storage already mapped to a nullable pointer, never the box, so it did not apply.

## Decision

The rule also applies when the storage type is exactly `null | undefined`: an unannotated binding whose initializer is the `null` literal is held as `null`.

## Consequences

- `examples/nullish/evolving_any.ts` reports no disagreement.
