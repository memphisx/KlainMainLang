# ADR-00431: worker_threads re-exports MessageChannel/MessagePort/BroadcastChannel

- **Relations**: Extends [ADR-00369](ADR-00369.md) (TDD-00099 channels), member-gap item from [NODE-GAP-ANALYSIS](../testing/NODE-GAP-ANALYSIS.md)
- **Date**: 2026-08-28

## Context

~13 oracle files import `MessageChannel` from `worker_threads`. The
constructor has existed as an ambient global since TDD-00099 — only the
Node module-named export was missing.

## Decision

`MessageChannel`/`MessagePort`/`BroadcastChannel` join
`virtualModuleMembers["worker_threads"]`; the module's identity binding
(same as `Worker`) makes the import resolve to the existing parse-time
constructors with zero codegen changes.

## Verification

`TestE2EMessageChannelWorkerThreadsImport` (same-thread roundtrip
through the named import); `TestE2EMessageChannel*` green (Mac).
