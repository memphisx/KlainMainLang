# ADR-01897: a guarded array binding of an index read the declared type says may be absent

- **Relations**: `Implements TDD-00230` (P3.3 shadow buckets)
- **Date**: 2026-10-21

## Context

- A binding that stores an index read is not narrowed to present by the checker's answer: without noUncheckedIndexedAccess the checker types a key read present although it is absent on a miss. When the declared type itself says the value may be absent (`const sc = headers['set-cookie']` over an index signature of `string | string[] | undefined`), a guard's narrowing (`sc !== undefined`) is flow's; codegen reads such an array binding present there, and the oracle kept it absent, in every program linking the http module.

## Decision

- The oracle narrows a guarded array binding of an index read when its declared storage type holds null or undefined, as codegen does.

## Consequences

- About 100 shadow rows go away; no emission change.
