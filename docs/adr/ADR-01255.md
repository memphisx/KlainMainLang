# ADR-01255: An omitted optional parameter before a rest parameter

- **Date**: 2026-09-29

## Context

`channel.runStores(ctx, fn)` (declared `runStores(context, fn, thisArg?,
...args)`) crashed the compiler: `slice bounds out of range [3:2]` in
emitClassCall. The rest arguments were sliced from the index after the
regular parameters, which is past the end when an optional one is omitted.

## Decision

The rest is empty when there are no more arguments than regular
parameters. The fix covers the class method, static method and
function-value call paths (emit_classes.go, emit_func.go).

## Verification

Mac (Apple Silicon): the `diagnostics_channel` tracing tests call
`runStores(context, fn)` (ADR-01254).
