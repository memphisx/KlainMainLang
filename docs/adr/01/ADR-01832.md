# ADR-01832: A method read as a value and a getter read, on the checker's side

- **Relations**: `Implements TDD-00230` (P3.3: inferExprType's kinds switch to the checker)
- **Date**: 2026-10-20

## Context

- The full shadow report (47,923 compile runs) ranked a `MemberExpression` fallback second (3,859 rows), and the unannotated return of the getter holding it fourth (1,714). Both came from the Test262 class pattern `get method() { return this.#method; }`.
- A class method read as a value, private (`this.#m`) or public (`this.m`), is emitted as the method's boxed function record (`emitMember`). The checker's side gave a function type for a plain method, and nothing for a generator or async generator method. So `MemberExpression`, a switched kind, could answer a type the emitted value did not have.
- A getter read is typed by the getter's emitted signature: its body's return when unannotated. The checker's side gave the checker's type of the property instead.

## Decision

- The oracle answers a program class instance's method read as a value with `any`. The emitter decides whether a read is one (`classMethodValue`): a class without a host base, whose layout has no such field, declaring or inheriting the name as a method that is not optional.
- The oracle answers an unannotated getter's read with its own `ReturnType` of the getter's body. The emitter finds the getter declaration, the class's own or an inherited one (`classGetterDecl`), and the oracle computes the answer itself, not from the old inference. An annotated getter stays the checker's.

## Consequences

- The example file's disagreements go from 10 to 0, public and private, plain and generator.
- Applying the getter rule only where the checker's type could not be named produced invalid IR: `get m() { return this.#m }` is emitted returning a box while the read was typed as a function. So the rule applies to every unannotated getter read.
- Verified on Apple Silicon (64 getter, accessor, private-method and method-value E2E tests), and with the gate on Linux x86-64 (DeskMini).
