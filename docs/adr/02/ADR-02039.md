# ADR-02039: A proxy read returned through an inferred return

- **Date**: 2026-11-22

## Context

- `function f() { return p.a }` over `p = new Proxy(target, h)` took the
  target's declared type. A trap's result of another kind was coerced
  (`"str"` became NaN). A function also read the module's `p` as the
  target's record, since a global that functions read is stored as the
  checker's type (`Proxy<T>` is `T`).

## Decision

- A `new Proxy(…)` binding is held boxed (`anyHeldDecl`), and so is its
  promoted global.
- An unannotated function or arrow whose body returns a read through a
  proxy (`returnsProxyRead`) returns `any`. Its call holds the box
  (`exprHoldsBox`, `callReturnsProxyRead`), and so does a binding of it.

## Consequences

- Tests: `TestE2EProxyReadThroughReturnTS`.
