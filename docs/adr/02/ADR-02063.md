# ADR-02063: Map.groupBy; groupBy's selector TypeError

- **Date**: 2026-11-22

## Context

- `Map.groupBy` (ES2024) was neither declared nor implemented, so a call was
  a type error.

## Decision

- `lib/es.d.ts` declares it on `MapConstructor` with `@lower
  __kml_Map_groupBy`, and `lib/node/kml_map.ts` implements it in
  TypeScript: it groups with a `Map`, so keys compare by SameValueZero, and
  it maps `-0` to `0`.
- Node's TypeErrors are kept: `Map.groupBy called on null or undefined`, and
  `5 is not a function`. The selector parameter is `any` so that a
  non-function reaches that check.

- V8 names a non-function selector by value alone: `5`, `null`, `[object
  Array]`, `#<Object>`. Array methods use the typed form, `number 5`.
  `Object.groupBy` printed that typed form; it now uses the value form
  (`__kml_require_callable_plain`), and `Map.groupBy` writes it in
  TypeScript.

## Consequences

- `TestE2EMapGroupBy` and `TestE2EGroupBySelectorNotFunction` match Node.
- Verified on Node304 (Linux x86-64).
