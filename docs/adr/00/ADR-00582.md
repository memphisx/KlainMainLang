# ADR-00582: process.hrtime diff-from-previous form

- **Relations**: Extends [ADR-00332](ADR-00332.md)
- **Date**: 2026-09-01

## Context

`process.hrtime()` returned the monotonic `[seconds, nanoseconds]` tuple but
rejected the legacy `process.hrtime(prev)` diff form — the row's only caveat.
`prev` is itself a prior `[seconds, nanoseconds]` reading.

## Decision

Accept an optional tuple argument. When present, read the current reading and
`prev`'s two `i64` fields, compute `curSec - prevSec` and `curNsec - prevNsec`,
and apply Node's borrow: if the nanosecond diff is negative, subtract 1 from the
second field and add 1e9 to the nanosecond field (branchless `select`). Return a
fresh malloc'd `{i64, i64}` tuple. The no-argument form is unchanged.

## Verification

`TestE2EProcessHrtimeDiff` (elapsed diff has a non-negative second field and a
nanosecond field in `[0, 1e9)`; a self-diff `hrtime(hrtime())` normalizes).
Built and verified on Mac (Apple Silicon).
