# ADR-01871: `await` of a program's thenable

- **Relations**: `Implements TDD-00230` (P3.3: the shadow report's AwaitExpression bucket)
- **Date**: 2026-10-21

## Context

- The checker awaited only the library's Promise; any other object with a `then` was unanswered. tsc's getPromisedTypeOfPromise reads the first parameter of `then`'s onfulfilled callback: `{ then(resolve: (v: string) => void) }` awaits to string. An `any` callback (every untyped JavaScript thenable) awaits to any and is TS1320 ("Type of 'await' operand must either be a valid promise or must not contain a callable 'then' member").
- The strict lane accepted `await { then(r: any) { … } }`, which tsc rejects.

## Decision

- A program thenable (not a library type, one non-overloaded `then`) awaits to its onfulfilled callback's first parameter, awaited: `never` for a callback with no parameter, any for an any callback.
- The strict lane reports TS1320 for an any callback.

## Consequences

- `TestAwaitThenable` holds tsc 5.6's codes. Test262's `expression-await-thenable-as-yield-operand.js` leaves the shadow report, passes in the js lane and is rejected in the strict lane, as tsc rejects it.
- Verified on Apple Silicon.
