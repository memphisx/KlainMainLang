# ADR-01676: process.nextTick is a TypeScript function

- **Relations**: Implements TDD-00230
- **Date**: 2026-10-17

## Context

`process.nextTick` was one of the last builtins still compiled directly. An `@intrinsic` emitted the tick-queue push inline. That left four divergences from Node:

- `nextTick(5)` was a compile error, not Node's `ERR_INVALID_ARG_TYPE`;
- the callback did not run in the async context it was queued in (`AsyncLocalStorage`);
- the `process` object held as a value had no `nextTick`;
- `const p = process; p.nextTick(cb)` passed the receiver as the callback.

## Decision

- **In TypeScript.** `lib/node/internal_process_tick.ts` is Node's lib/internal/process/task_queues.js. It validates the callback, captures the async context frame, and queues a closure that runs the callback with its arguments under that frame. The declaration lowers to it (`@lower __kml_process_nextTick`), and the process object holds the same function, so identity holds. The validator is local, because a module that queues ticks itself would import this one back.
- **Native queue.** `__kml_native.nextTick` (microtask.c) pushes an `(invoke, closure)` callback onto the existing tick queue. The intrinsic and `emitProcessNextTick` are deleted.
- **Receiver.** A library function that takes exactly the method's declared parameters does not get the receiver as an argument. The receiver is still evaluated, ahead of the arguments (`dropRecv`).
- **Name.** A library function a builtin lowers to is named for the builtin's last path element, so `process.nextTick.name` is `nextTick`.

## Side effects discovered

A builtin method lowered to a TypeScript function could not be read as a value through its owner: `process.nextTick` alone was an undefined `process`, and `String.raw.length` did not compile. Such a read is now the library function itself, so the value and the call are one function, and a function value answers `.length` from its metadata. The tick native links the microtask unit itself, since a program may only read the value.

The union of a function and an object type (`fn | Handler`) was boxed as `any` by ADR-01675, which broke `typeof`-narrowed calls on it. Only a union made entirely of functions is boxed now.

## Verification

- Ordering against promise jobs, arguments, `AsyncLocalStorage`, the validation error, aliasing, identity and `.name` all match Node in a side-by-side probe.
- Timer, tick, cluster, dgram and interface-method tests pass on Mac.
