# ADR-01750: `object` has Object's members; the front end follows codegen's boxes

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-19

## Context

The shadow report showed four more patterns where the front end disagreed with codegen.

1. The checker narrowed a caught value to `object` (`typeof thrown === 'object' && thrown !== null`) but found no `thrown.constructor`. Its apparent type had no case for `object`, which tsc reads through the global `Object` interface.
2. The front end answered with the checker's precise type where codegen holds a box:
   - a member read off a builtin constructor's prototype object (`Array.prototype.map`);
   - a member read off a caught value, beyond its typed error fields;
   - a conditional with one boxed branch (`… ? JSON.stringify(v) : '"' + v + '"'`);
   - `new F()` of a js prototype constructor;
   - a js-lane object-literal binding, which codegen always holds as a dynamic object, accessors or not.
3. A literal with both a computed key and an accessor was taken as a synthetic class, though codegen checks the computed key first.
4. A binding reported `T | undefined` after flow had narrowed it, in two cases:
   - an array of boxes copied from `T[] | undefined` read only the declared type;
   - an element destructured from a fixed-length tuple was given the "may be past the end" slot, which only an array source has.

## Decision

- `apparentType(object)` is the global `Object` interface.
- The front end applies each of codegen's rules above: a member of a builtin prototype object or of a caught value is a box, a conditional with a boxed branch is a box, `new` of a prototype constructor is a box, a js-lane object-literal binding is a box, and a computed key wins over accessors.
- A binding whose initializer is `T[] | undefined` keeps flow's narrowing, compared on the non-nullable part. A tuple source's direct pattern elements bind as the tuple's elements.

## Consequences

- `thrown.constructor.name` type-checks as tsc has it.
- The Test262 harness (`assert.js`, `sta.js`) leaves almost no disagreements, which removes rows from nearly every Test262 compile in the report.
