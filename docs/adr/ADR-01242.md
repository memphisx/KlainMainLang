# ADR-01242: Duplicate function implementations are TS2393

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-09-29

## Context

`function f() {}` declared twice in one scope compiled in the strict lane,
and the later one won. tsc reports TS2393 (duplicate function
implementation); Node rejects the module with a SyntaxError.

## Decision

The binder's clash rules (`binder/symbol.go`) classify two function
declarations of one name, each with a body the program wrote, as
`DuplicateImplementation`, reported as TS2393 at the later one. Overload
signatures have no body and still merge. With Annex B (sloppy scripts,
`-compat=js`) two plain function declarations still merge, as in a script.

## Side effects discovered

Two examples declared a function twice (`generics/generics.ts`,
`nullable_scalars/nullable_scalars.ts`); they are renamed or removed.

## Verification

Mac (Apple Silicon): `TestE2ETypeErrorDuplicateFunctionImplementation`
(also an overload set followed by one implementation); the full test suite.
