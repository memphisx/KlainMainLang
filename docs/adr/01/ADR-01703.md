# ADR-01703: A foreign-receiver method body ignores the checker's types

- **Relations**: `Fixes ADR-01699`
- **Date**: 2026-10-18

## Context

A class method value called on a receiver that is not an instance of the class runs the method's body with that receiver as `this` (ADR-01699). To do this, the body is compiled a second time as `function (this: any, …)`.

That second compile reuses the method's AST nodes, which the checker had typed with `this` as the class. As a result, `this.describeBalance()` was emitted as a typed call on an `i64` box, which is invalid IR. Seven examples failed to compile this way, among them `classes.ts`, `extends_array.ts` and `eventemitter.ts`.

## Decision

While that body compiles (`foreignThisBody`), `reprOracle` answers nothing. Expressions are then typed from their bindings instead, so `this` is the `any` parameter and everything read through it is `any`.

## Verification

macOS (Apple Silicon): the seven failing examples compile, and their output matches Node's.
