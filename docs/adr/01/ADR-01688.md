# ADR-01688: A string's null is nullRef

- **Relations**: Implements TDD-00257
- **Date**: 2026-10-17

## Context

TDD-00257 Stage 1. A `string` slot's only absent value was the null pointer, and readers disagreed about what it meant:
- `f(a[5])` into `t: string` printed `null`, `t === undefined` was false, and `typeof t` was "object".
- An Invalid Date's `toJSON()` relied on the opposite reading.
- `JSON.parse` turned both a JSON null and a missing key into `""`.

## Decision

A `string` or `string | undefined` pointer (`triStr`; host handles excluded) has two absent values: the null pointer is undefined, and `nullRef` is null.

**Producers of null give `nullRef`:**
- unboxing a null `any`;
- projecting a JSON null;
- `Date.prototype.toJSON` on an Invalid Date.

A missing key projects to the null pointer.

**Into `string | null`.** That type's null is still the null pointer (Stage 2 is left), so converting a string into it turns `nullRef` into the null pointer.

**Readers test both:**
- strict `===` against `null` or `undefined`, and loose `==`, which takes either;
- `typeof`: "undefined" or "object";
- `??`, `?.` and the property-access TypeError, which names `null` or `undefined`;
- boxing into `any`, so `[s]` and `{ s }` print `null` or `undefined`;
- concatenation, templates and `String()`;
- `console.log` and inspect;
- `JSON.stringify`: `null` inside an array, the key omitted for undefined, and `undefined` itself for a top-level undefined.

`asTriStr` retypes such a value as a three-state pointer for the renderers. `fromThreeState`'s result is never `nullRef`, and the emitter records its registers so that a renderer does not retype it again.

**Freeing.** The deep-free walk skips `nullRef` as it skips the null pointer.

**Deep-free helpers.** The deep-free walk's helper functions no longer inherit the enclosing function's shadow frame. Before this, a helper's `ret` popped the caller's frame through a register of the caller's, and the IR was invalid once that register held something other than a pointer.
