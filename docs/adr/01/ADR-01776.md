# ADR-01776: JavaScript default parameters take null, and methods report length

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- In the js lane, an unannotated parameter with a literal default was typed by that default (`paramDefaultType`), as TypeScript types it. A `null` argument had no place in that type:
  - `function f(a = 5)` called as `f(null)` gave 5;
  - the function-expression form failed with an internal "no conversion" error.
- The default prologue filled an `any` parameter through `??`, so an explicit null took the default too.
- A class method's dynamic adapter reported `length` as its whole parameter count. Node stops at the first defaulted parameter.

## Decision

- `paramDefaultType` applies only outside the js lane. JavaScript's parameter takes what is passed, and the call sites decide its type.
- `emitParamDefaultPrologue` tests an `any` parameter with `=== undefined`.
- The shape adapter's arity stops at the first entry of `sig.Optional`.

## Consequences

- `TestE2EJSFileDefaultParamsTakeNull` covers functions, function expressions, arrows, generator methods and method `length`.
