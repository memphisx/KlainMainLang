# ADR-01320: `URL` and `URLSearchParams` are TypeScript, on the URL Standard's parser

- **Relations**: Implements TDD-00237 (Stages 1 and 2), Extends ADR-01203, ADR-01318, ADR-01319, Supersedes ADR-00572
- **Date**: 2026-10-01

## Context

TDD-00237 Stages 1 and 2. `URL` was a codegen host object over libcurl's
`CURLU` (`emit_url.go`), and `URLSearchParams` a native list
(`urlsearchparamssrc/urlsearchparams.c`). Both had their own `Type` flags
(`IsURL`, `IsURLSearchParams`) and their own `new` nodes from sema. Neither
could be subclassed or used as a value, and libcurl's parser disagrees with
the URL Standard's parser on opaque paths, IPv4 number forms, host
validation, backslashes and the percent-encode sets.

## Investigation

- `whatwg-url`'s `url-state-machine.js` follows the standard's prose state
  by state. Porting it step by step keeps every state override the setters
  need.
- casemap.c's IDNA code covered only part of UTS #46. A TypeScript Punycode
  coder over the existing case mapping makes `domainToASCII` and
  `domainToUnicode` pure TypeScript, so the native IDNA entry point that
  TDD-00237 lists as a prerequisite is not needed.
- Writing the module showed several general compiler gaps, which are fixed
  here instead of being worked around in the library:
  - `inspect.custom` as a computed method key.
  - `this.constructor`.
  - `Object.assign({}, a, b)` adding properties.
  - An annotated module-level `Map` initialized with entries, used from
    inside functions.
  - Spreading a class iterable.
  - `x as any` keeping the value's kind.
  - A class getter read through a `string | URL` union.

## Decision

1. **`lib/node/kml_url.ts`** is a global module (ADR-01203). It holds `URL`,
   `URLSearchParams`, the URL Standard's basic URL parser (with its host
   parser, IPv4/IPv6 forms, percent-encode sets, and the setters as state
   overrides), the form-urlencoded parser and serializer, Punycode, and
   `domainToASCII`/`domainToUnicode`. A `URL`'s `searchParams` holds the
   URL and writes the query back on each mutation; the `search` setter
   re-parses the list. An invalid URL throws Node's `TypeError` with
   `code: 'ERR_INVALID_URL'` and `input`.
2. **`lib/node/url.ts`** (renamed from `internal_url.ts`) re-exports them
   and has `fileURLToPath`, `pathToFileURL` and `urlToHttpOptions`, as
   Node's `lib/internal/url.js` has them. `kml:default-namespace` makes
   `import url from 'url'` bind the module namespace.
3. **`lib/node/internal_errors.ts`** holds Node's coded errors
   (`NodeError`, `NodeTypeError`, `NodeRangeError`) and `ERR_MISSING_ARGS`.
4. **`[inspect.custom]`** methods desugar to a protocol method,
   `@@inspectCustom`. util.inspect, and `console.log` of a class instance,
   call it through `__kml_obj_inspect_custom`. `Event`, `EventTarget`,
   `AbortSignal` and `AbortController` use it to print as Node prints them.
5. **Native consumers** take a URL's `href`. That covers fetch,
   `new Request`, `http.request` and `Response.redirect`, which parses its
   argument with the `URL` class. Each consumer finds the class through the
   global links. `lib.NativeGlobalUses` names the global-module classes
   that a native global's codegen builds itself, so a program naming
   `Response` brings in `URL`.
6. **General fixes.**
   - `Object.assign` widens its target.
   - A module-level annotated `Map` with entries is promoted like an
     unannotated one.
   - Spreading a class iterable yields `any[]`.
   - `as any` boxes the value by its own type.
   - `emitUnionSoleObjectMemberRead` reads a class getter through the
     accessor.
   - Compound assignment to a URL component works, because it is now an
     ordinary accessor.

Deleted: `emit_url.go`, `emit_usp.go`, `emit_usp_runtime.go`,
`runtime_url.go`, `urlsearchparamssrc/`, the `IsURL`/`IsURLSearchParams`
flags and every site testing them, `URLType`, `URLSearchParamsType`,
`HttpOptionsType`, `emitInspectURL`, the `NewURL*` AST nodes and their sema
builders, the `url` virtual-module entries, and casemap.c's IDNA code.
libcurl no longer parses URLs.

## Implementation notes

- `parser`: `isInspectCustomKey`, `parseNewOfExpression`.
- `binder`/`checker`: `typeQueryScopes` resolves a `typeof x` in a type
  position through its own scope.
- `resolver`: `RenameInClass` and `typeof` renaming for mangled module
  names; `NativeGlobalUses` in the global-module trigger.
- `codegen/llvm`:
  - `emit_classexpr.go` hoists class expressions.
  - `emit_classref.go` adds `emitAnyInstanceOfClass`.
  - `emit_signal.go` adds `globalClass` and `isGlobalClassInstance`.
  - `emit_response_new.go`, `emit_fetch*.go` and
    `emit_structured_clone.go` are the URL consumers.
  - `emit_exprs_member.go` reads the union getter.
  - `emit_strings.go` now has `emitStrBranch`, which used to live in
    `emit_url.go`.
- `tests/compiler_test.go`: `namesGlobalModule` also resolves a program
  naming a `NativeGlobalUses` global.

## Side effects discovered

- `TestE2EExtendsErrorSubSubclassRejected` asserted the rejection that
  ADR-01319 removed. It is deleted; `TestE2EErrorSubclassOfSubclass` covers
  the behaviour.
- `child_process.ts` narrows a `string | URL` with `instanceof`, which hit
  the union-getter gap above.

## Verification

- A 46-case parser stress test (IPv4 number forms, IPv6 compression, opaque
  paths, special-scheme backslashes, every setter) gives output
  byte-identical to Node's.
- `tests/url_test.go` and the fetch, Request, Response, structuredClone,
  `child_process`, cluster, Error and class E2E suites are checked against
  Node.
- `TestE2EURLComponentCompoundAssignment` replaces the rejection test.
- Verified on macOS (Apple Silicon).
