# ADR-01463: Classes extending RegExp

- **Relations**: Implements TDD-00247 (stage 3, RegExp), Extends ADR-01424
- **Date**: 2026-10-07

## Context

TDD-00247 has a class extending a builtin host class be that host object, as
in Node. Map and Set came first (ADR-01424). Stage 3 names Promise and
RegExp; this record covers RegExp. `class R extends RegExp {}` was a clean
compile error.

## Investigation

- A RegExp was a headerless 40-byte struct (`RegExpType`, five words: the
  PCRE2 handle, `source`, `flags`, the five flag booleans, `lastIndex`),
  allocated in one place (`emitNewRegExpExpression`) and boxed into `any`
  as a fresh `{header, handle}` cell per box. No C runtime reads the struct.
- RegExp's `test`/`exec` reach their emitters only as intrinsics named by
  the checker's declaration of the member; a receiver the checker never saw
  (the body name a host call binds) found no declaration and failed with
  "a RegExp has no method 'test'".
- The string methods that take a RegExp (`replace`, `replaceAll`, `split`,
  `match`, `matchAll`, `search`) dispatch on the argument's static type
  being a RegExp.
- Found on the way, older than this work, each fixed here:
  - `s.replace(x, r)` / `s.replaceAll(x, r)` with `x` a RegExp held as
    `any` or `string | RegExp` searched for the text `/b/g`;
  - `c ? "a" : /a/` (and `c ? "a" : [1]`, a Map, any other reference)
    typed the result as a string: a RegExp in a `string | RegExp` binding
    read back as garbage, and the array arm was invalid IR;
  - `new RegExp(p, flags)` with `flags` an optional `string` parameter
    dropped the flags at compile time (the optional type carries
    `IsUndefined`);
  - `new RegExp(x)` with `x` held as `any` used `String(x)` as the pattern
    (`//q+/i/`), and an `undefined` one gave `/undefined/`;
  - the `override` member modifier was a parse error (ADR-01464).
  - a Map or Set narrowed to a class extending it (`if (m instanceof
    Counter) m.bump()`, ADR-01424's stage) read the host's body as the
    instance: "field access on non-object"; the checker narrowed
    `Map<string, number>` by `instanceof Counter` to `never`, keeping only
    members on the class's own chain, where tsc narrows any supertype to
    the class;
  - an instance of such a class stored into a host-typed binding
    (`const m: Map<string, number> = new Counter()`, a field, an object
    literal's member) kept the instance pointer where the host's body was
    expected.

## Decision

- A RegExp is allocated with a header word before its body, at `body - 8`,
  as a Map's is; its pointer stays the body. `headeredHost` includes it, so
  it boxes as its header pointer (identity through `any`), unboxes at `+8`,
  and `Memory.free` frees from `body - 8`. `emitNewRegExpInto` builds the
  body at a given pointer, or allocates.
- A class extending RegExp (`ClassInfo.HostBase` = `RegExpType()`):
  - its instance is `[tag][body: 5 words][vtable][fields]`; the body size
    is now per host (`hostBodySize`), and the hidden-field prefix is counted
    by name rather than assumed to be nine words;
  - construction compiles the pattern into the body in place: `new R(p,
    f)` without a constructor, `super(p, f)`, and the synthesized
    `(pattern?: any, flags?: string)` constructor;
  - RegExp's members on the instance and through `super` run on `this +
    8`; a property write the class does not declare (`r.lastIndex = 0`)
    does too;
  - `RegExp.prototype` intrinsics also apply by representation
    (`reprOwners`), so a host call on the body finds `test`/`exec`;
  - a string method's RegExp argument that is such an instance is passed
    as its body (`hostRegExpArgs`); `new RegExp(r)` copies its source and
    flags;
  - `String(r)` and template literals give `/a+b/g`, `[object RegExp]` is
    its tag, and `console.log` renders `R /a+b/g { tag: 'x' }`;
  - through `any`: the RegExp host row gains a primitive conversion (its
    toString for every hint), the class's parent row is emitted whenever a
    boxed program has a class extending a host, and unboxing to a headered
    host accepts an instance whose class reaches it (the runtime's row
    lookup), at `+8`.
- The older bugs:
  - `x instanceof C` narrows a host-typed reference to C in the branch:
    an `if` rebinds it to `x - 8`, and a read the checker narrows (an early
    return) takes the instance the same way (`checkerHostSubclass`); the
    checker narrows a member C's instance is assignable to (a builtin
    interface) to C;
  - an object-typed declaration converts a host-subclass instance to the
    host's body;
  - replace/replaceAll with a boxed search branches at run time on whether
    the box holds a RegExp (`emitStringReplaceMethod`);
  - a ternary of a plain string and another reference is boxed into `any`
    (`stringVsReference`);
  - only a non-string undefined/null flags value is the empty flags;
  - a boxed pattern that holds a RegExp gives its source and flags, a boxed
    `undefined` the empty pattern, anything else its ToString.
