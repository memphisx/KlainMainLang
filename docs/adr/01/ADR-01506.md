# ADR-01506: A JS call may omit any argument of a named function

- **Relations**: Extends ADR-00963, TDD-00230
- **Date**: 2026-10-09

## Context

Under `-compat=js`,
`const fe = function (a, b) { … }; fe()` failed to compile with
"missing argument 1 with no default". JavaScript passes `undefined`.

## Investigation

The closure call path already lets untyped JavaScript omit any
argument. The named-function call path (`emit_call.go`) only allowed
omitting an optional or `any` parameter.

## Decision

Under `-compat=js` an omitted argument of a named function is filled
like an optional one.

## Divergences

None. The parameter reads `undefined`, as in Node.

## Files

codegen/llvm/emit_call.go, tests/func_test.go
