# ADR-01332: Timer arguments, `await` placement, and four strict-lane regressions

- **Relations**: Extends ADR-00031, ADR-00332, ADR-01331
- **Date**: 2026-10-02

## Context

The strict Test262 lane after [ADR-01331](ADR-01331.md) passed 7,975 files
against 7,355 at the last commit: 634 gained, 14 lost. Twelve of the lost
are tsc rejections the declared signatures now report (`isNaN` of an
object, a non-`PropertyKey` key to `Reflect.has`, `bind()` with no
arguments). Two were not: `Array/length/15.4.5.1-3.d-3.js` timed out, and
`staging/sm/fields/await-identifier-module-3.js` compiled where it must be
a parse error. Probing the second found that `.then(console.log)` printed
nothing, and that `setTimeout(console.log, 0, "t")` was rejected.

## Investigation

- `a.length = 4294967295` on an empty array grows it by `realloc` and a
  `memset` of the new tail, 32 GB. The last commit ran it in 1 ms only
  because clang removed the stores nothing read; the array guard
  ADR-01331 added passes the header to an external call, so the work now
  ran (16 s, 14 s of it the kernel zeroing pages).
- No pass checked where `await` may appear. The Test262 file passed before
  only because a class expression nested there was a codegen error, which
  the runner counts as the expected rejection. Node 24.19 rejects both
  `function f() { return await 1 }` and
  `async () => class { x = await 1 }` with "Unexpected reserved word".
- `console.log` used by value went nowhere: `builtinRef`
  (`emit_intrinsics.go`) filtered member references by a fixed list of
  owners that predates the `console` declarations.
- `emitSetTimeout`/`emitSetInterval`/`emitSetImmediate` and
  `emitProcessNextTick` took the callback alone; Node passes every
  argument after the delay (after the callback for `setImmediate` and
  `nextTick`) to it.
- `setTimeout(inner, 1)` with `function inner(x?: number)` was invalid IR
  at the last commit too: `emitCBCall` padded the missing optional
  argument with `0.0` where the parameter is a `{ i1, double }` aggregate.

## Decision

1. Growing an empty array's length takes `calloc` storage, which the
   kernel zeroes lazily; a non-empty array keeps `realloc` and clears the
   tail.
2. The parser reports TS1308 ("'await' expressions are only allowed
   within async functions and at the top levels of modules") for an
   `await` outside an async body, in both lanes: a module's top level
   allows it, each function sets the context by being async or not, and a
   class field initializer or static block never allows it. A method's
   decorators belong to the enclosing context.
3. The timers and `process.nextTick` evaluate their extra arguments when
   called, box them, and keep them in a closure environment beside the
   callback; the thunk the queue fires calls the callback with them,
   dropping any past its arity unless it takes a rest parameter.
4. A missing optional scalar callback argument is the absent aggregate
   (`zeroinitializer`).
5. Extra arguments containing a spread are gathered into one `any[]` at
   the schedule; the thunk fills each fixed parameter from it (undefined
   past its end) and hands a rest parameter the remainder
   (`Callback.restArray`). A callback held in `any` (every callback a
   timer used as a value receives) is called through the dynamic ABI
   with that array. A builtin function value takes the widest overload,
   so `const st = setTimeout` keeps `...args`.
6. A function compiled for a dynamic context binds a typed `?` parameter
   as `T | undefined`, as every other function does; it read an omitted
   `b?: number` as `0`.

## Implementation notes

- `codegen/llvm/emit_arrays_mutate.go`: the length-grow branch splits on an
  empty array and joins with a phi.
- `parser/parser.go`: `awaitOutsideAsync`, beside `yieldOutsideGenerator`;
  `diag/messages.go`: `AwaitOutsideAsync`.
- `codegen/llvm/emit_timers.go`: `timerCallbackPtr` takes the extra
  arguments; `emitBoundArgsAdapter`; `codegen/llvm/emit_process.go`.
- `codegen/llvm/emit_func.go`: the nullable-scalar case in `emitCBCall`.

## Side effects discovered

- A class declared inside a function body is "unknown class"; tracked in
  `docs/BACKLOG.md`.
- `globalThis`, `Math`, `JSON` and `console` are not values (`const m =
  Math`); members are. TDD-00230 P3.3 gives them a representation;
  tracked in `docs/BACKLOG.md`.
- `.bind` on a rest-parameter function, `Math.max.bind` among them, is
  still a compile error (documented).
- A required `number` parameter passed `undefined` (a spread shorter
  than the parameter list) reads `NaN`; tracked in `docs/BACKLOG.md`.
- Node shows the slots `length` adds as holes; this compiler shows `0` or
  `undefined` ([TDD-00226](../tdd/TDD-00226.md)).
