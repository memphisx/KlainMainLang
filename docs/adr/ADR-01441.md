# ADR-01441: Contextual callback parameters of builtin layouts

- **Relations**: Implements TDD-00230 (P2.2)
- **Date**: 2026-10-07

## Context

A shadow bucket after ADR-01439 (808 rows; `kml_blob.ts`, `internal_fs.ts`)
was an unannotated arrow parameter typed by its context:
`this.arrayBuffer().then((ab) => new Uint8Array(ab))`. Codegen inferred the
arrow's type with `ab: any`; the checker types `ab` as `ArrayBuffer`.

## Investigation

- Emission takes the parameter's type from the caller's hint (the promise's
  value type), but inference of the arrow before emission has no hint and
  asks the checker for the contextual type, which it accepted only for a
  string, number or boolean.

## Decision

The contextual parameter type also accepts a builtin with a native layout
(`ArrayBuffer`, typed arrays, `Date`), in inference and in emission
without a hint.

## Verification

- `TestE2EContextualNativeLayoutParam` (against Node) and the callback,
  `then`, Blob, Date, `forEach` and arrow tests pass on the Mac; the full
  test lane and the examples pass on Linux x86-64.
- The probe's shadow rows are gone.
