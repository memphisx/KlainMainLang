# ADR-01254: `diagnostics_channel` in TypeScript

- **Relations**: `Implements TDD-00230`, `Supersedes ADR-00420`
- **Date**: 2026-09-29

## Context

`diagnostics_channel` was code-generated (ADR-00420):
- messages were strings;
- subscribers had to be string-typed;
- `tracingChannel` and the store bindings were compile errors;
- a Channel was a host handle.

TDD-00230 P3.1 moves the Node surface to TypeScript modules, and this one
is pure JavaScript in Node.

## Decision

`lib/node/diagnostics_channel.ts` ports Node v24's
lib/diagnostics_channel.js:
- `channel`, `subscribe`, `unsubscribe`, `hasSubscribers`, `tracingChannel`;
- `Channel`: `publish` of any value, subscribe/unsubscribe, bindStore,
  unbindStore, runStores;
- `TracingChannel`: traceSync, tracePromise, traceCallback, and
  subscribe/unsubscribe of the five events.

Node swaps an inactive channel's prototype; here an `active` flag reads the
same. Node keeps channels in a weak-reference map; here a plain map holds
them, which only changes memory. A subscriber's throw is reported on the
next tick as Node's `triggerUncaughtException` does: to the process
`uncaughtException` listeners when there are any, else fatal.

The codegen module is deleted (emit_diagch.go, runtime_diagch.go, the
Channel host type, and the resolver's virtual module).

## Side effects discovered

Two compiler bugs, fixed in ADR-01255 and ADR-01256:
- a class method call omitting the optional parameter before a rest
  parameter panicked;
- a closure's `return` of a local declared inside `try { }` was inferred
  without that local.

`bindStore` with an `AsyncLocalStorage` needed `async_hooks` ported too
(ADR-01257): a codegen host handle cannot be called through `any`.

## Verification

Mac (Apple Silicon), against Node v24.19:
- `TestE2EDiagnosticsChannelPubSub` and `TestE2EDiagnosticsChannelTracing`.
  Their output matches Node's, including the order of events around
  promises and callbacks.
- The rejection test for untyped subscribers is gone.
- `examples/process/diagnostics_channel.ts` matches Node.
