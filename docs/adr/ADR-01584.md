# ADR-01584: A throwing uncaughtException listener exits 7

- **Date**: 2026-10-11

## Context

The macOS node conformance run was killed by the memory guard twice: a
test binary reached 6 to 9 GB in seconds. A sampler that killed any test
binary over 2 GB and saved its sources caught
`test-stream-writable-end-cb-uncaught.js`. Its `uncaughtException`
listener asserts on the error's message. The assertion failed, and the
listener's own throw went back to the same listener, without end.

## Investigation

A minimal program reproduces it on macOS:

```ts
process.on('uncaughtException', (err) => { throw new Error('inside') })
setTimeout(() => { throw new Error('first') }, 0)
```

Node calls the listener once, prints the listener's error and exits with
code 7. Compiled, the listener ran again for each throw, recursing until
the process crashed (SIGILL) or, with allocations in the listener, ran out
of memory.

`__kml_throw_any` (`codegen/llvm/exceptionssrc/exceptions.c`) handles a
throw with no try frame by calling `__kml_process_uncaught`, which runs
the listeners. A throw from a listener has no try frame either, so it took
the same path.

## Decision

The listeners run through `__kml_process_uncaught_guarded`
(`exceptions.c`), which sets a thread-local flag while they run. Both
callers use it: `__kml_throw_any` for a throw, and the unhandled-rejection
report (`emit_unhandled.go`). A throw that reaches `__kml_throw_any` with no
try frame while the flag is set prints `Uncaught: <message>` and exits 7,
without calling the listeners again.

## Side effects discovered

- The stream test still fails, but cleanly: the program assigns
  `writable._write`, and library code calls the class's `_write`, which
  throws "not implemented" (BACKLOG, ADR-01580).

## Verification

- New test `TestE2EProcessUncaughtExceptionListenerThrows`: the listener
  runs once, and the exit code is 7 (macOS).
- The same through an unhandled rejection: listener once, exit 7 (macOS).
- `TestE2EProcessUncaughtException` passes (macOS).
- The stream test exits 7 in under a second instead of growing past 3 GB
  (macOS).
