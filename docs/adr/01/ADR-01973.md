# ADR-01973: Global object links only the globals a program can read

- **Relations**: Implements TDD-00230; follows [ADR-01970](ADR-01970.md)
- **Date**: 2026-11-06

## Context

Reading `globalThis` (or `Math`, `JSON`, `console`, `Reflect`, `Atomics`)
as a value compiled one library module that made every namespace object
and the whole global object. The global object stored `process`, `Buffer`,
`fetch`, `crypto`, `Request`, `Response`, the stream classes and the rest,
so every one of them, and everything they import (crypto, stream, net,
os, worker_threads), was linked. `const g: any = globalThis` gave a 10 MB
binary and `const m: any = Math` 8.9 MB, against 53 KB for
`console.log(1)`.

## Decision

- Each namespace object has its own module (`internal_namespaces.ts` for
  Math; `internal_ns_json.ts`, `internal_ns_reflect.ts`,
  `internal_ns_atomics.ts`, `internal_ns_console.ts`) and the global
  object its own (`internal_global_object.ts`).
  `resolver.NamespaceValueNames` maps each name to `module:maker`, and the
  resolver includes only the modules of the names the program reads as
  values.
- The heavy natives (`resolver.GlobalObjectNatives`) are no longer set by
  the maker. They are linked onto the object with `_kmlGlobalThisLink`, as
  the global-module classes already were, when the program names them.
  `fetch` goes through a small `internal_global_fetch.ts` getter, since
  the native intrinsic has no library declaration to reference.
- When the program uses the global object in a way no name shows, the
  resolver treats it as naming every native and every global module's
  globals, so the object carries them all, as Node's does.
  `globalObjectEscapes` checks for this. Escapes are: an alias of
  `globalThis`/`global` used other than as a member read or write by
  name, a string-literal index, or another const alias; an
  Object.prototype member read off it; a sloppy script's `this`; and a
  plain function called with `new`.
- Links are emitted in Node's own property order, so `Object.keys` and
  `getOwnPropertyNames` match Node's.
- The link command drops earlier copies of a repeated `-l` flag, which
  appeared once the crypto and TLS units both linked libcrypto.

## Consequences

- `const m: any = Math`: 1.1 MB. `const j: any = JSON`: 1.6 MB.
  `const g: any = globalThis` reading named members: 4.5 MB. Verified on
  the Mac.
- The remaining 4.5 MB is what Node's global object always carries as data
  properties: the timers, `structuredClone`, `atob`/`btoa`, the typed
  arrays, `Atomics` and `console`. Making those lazy would need accessor
  properties, which `Object.getOwnPropertyDescriptor` would reveal, so
  they stay eager.
- A program that enumerates the object pays the full size, as before.
