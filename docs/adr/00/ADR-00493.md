# ADR-00493: new Duplex(options)

- **Date**: 2026-08-29

## Context

`new Duplex(...)` was rejected — `duplexPair()` was the only Duplex
producer, a caveat on the stream-constructors row.

## Decision

A `"duplex"` constructor kind: exactly the Readable wiring (an rstream
whose optional `read` callback pushes) plus the Writable wiring (a
wstream with optional `write`/`final` callbacks) on one ns handle — two
independent sides, matching Node's contract, unlike Transform where the
writable side feeds the readable one. Types as
`NodeTransformType(in, out)` (both stream flags), so every existing
readable and writable method/event dispatches unchanged. String chunks
by default, `<T>` overrides, shared `highWaterMark`/`objectMode`
options. `class X extends Duplex` stays rejected (TDD-00132 Stage C).
