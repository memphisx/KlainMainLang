# ADR-01524: The shadow report compiles Test262 files with their harness

- **Relations**: Extends TDD-00230
- **Date**: 2026-10-10

## Context

`make shadow-report` compiled each Test262 file on its own. Without the
harness (`assert`, `Test262Error`, includes) every such compile failed,
and the rows it left described a program Test262 never runs: about a
thousand rows were about the unresolved harness names.

## Decision

The shadow tool assembles a Test262 file as the conformance runner does
(shim `sta.js`/`assert.js`, the async reporter, includes, `onlyStrict`),
moves the recorded rows back onto the test file's lines, and drops the
harness's own rows. Only the rows of compile runs that succeed are
ranked; a failed run has no decider to switch over, and its rows are
counted apart.

None.
