# ADR-00251: Promise.any over raw fetches, and destructured/nullable params in a suspending fn (TDD-00084 Part C)

- **Relations**: `Implements TDD-00084` (Part C, completing it); builds on [ADR-00248](ADR-00248.md), [ADR-00073](ADR-00073.md), [ADR-00199](ADR-00199.md)
- **Date**: 2026-08-19

## Context

Two smaller gaps remained after TDD-00084 Parts A/B:

1. **`Promise.any` over `Array<Promise<Response>>` (raw fetches)** was a clean
   rejection — the group machinery ([ADR-00073](ADR-00073.md)) only had mode 0
   (all) and mode 1 (race), no "first successful, else AggregateError."
2. **A destructured or nullable-scalar parameter of a genuinely-suspending async
   fn** was a clean rejection — `bindTaskParamsFromBundle` (emit_task_emit.go)
   only marshalled plain scalar and whole-array parameters through the coroutine
   task's heap args bundle.

## Decision

**`Promise.any` over fetches (runtime_fetch.go / emit_promise.go).** A new group
**mode 2**: `__kml_group_satisfied` is satisfied as soon as any member is *done
and transport-succeeded* (the pending struct's `result == 0`), or once every
member is done (all failed). `__kml_first_success_index` returns the first
transport-successful member; if it returns -1, `__kml_group_throw_aggregate`
builds an `AggregateError` whose `.errors` are one `Error` per member carrying
that fetch's `curl_easy_strerror` message, and throws it. `emitPromiseAny`'s
`IsResponse` branch drives this and, on success, builds the winning `Response`.
Per the WHATWG model an HTTP error status (404/500) is a *fulfilled* fetch, so it
counts as a success — only a transport failure (unreachable host, etc.) is a
rejection here.

**Suspending-fn parameter marshalling (emit_task_emit.go).** The task args bundle
gains two shapes:

- A **nullable-scalar** parameter travels as two 8-byte slots — the presence bit
  (zero-extended to `i64`) and the payload bits — so every bundle field stays 8
  bytes; `bindTaskParamsFromBundle` reassembles the `{ i1, T }` aggregate
  ([ADR-00199](ADR-00199.md)) and binds it like the non-suspending path.
- A **destructured** parameter reuses the value already carried for its
  underlying type — an object pattern rides the existing single-`ptr` field, an
  array pattern the existing `(ptr, len)` fields — and `bindTaskParamsFromBundle`
  runs `unpackObjectPatternInto` / `unpackArrayPatternInto` against it, exactly as
  the non-suspending binding does.

## Consequences

- `Promise.any([fetch(a), fetch(b)])` resolves to the first transport-successful
  response and throws an `AggregateError` (with `.errors`) only when every fetch
  fails at the transport level.
- A suspending async fn can take a `number | null` (etc.) parameter and an
  object/array-destructured parameter.
- **TDD-00084 is complete** (Parts A, B, C). The async model is unified: every
  async fn returns a real promise, one task-aware event loop drives everything,
  and all combinators/param shapes work across the fiber boundary. A rest
  parameter in a suspending fn stays a clean rejection (unchanged, separate).
