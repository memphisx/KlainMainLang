# ADR-01784: An unannotated destructured parameter is `any` in the js lane

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-20

## Context

- The checker gave no answer for a signature containing an unannotated `[a]` or `{a}` parameter. A method read as a value (`var f = c.pub`, `get m() { return this.#m; }`) then fell back to the default number type. Calling it failed to compile ("undefined function or closure") or threw "is not a function" at run time.

## Decision

- In the js lane the checker types such a parameter as `any`, as it does other unannotated parameters with no context. The strict lane is unchanged: tsc reports the implicit any there.

## Consequences

- `TestE2EJSFilePatternParamMethodValues` calls a private method through a getter and a public method read as a value.
