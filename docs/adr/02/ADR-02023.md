# ADR-02023: util.format `%s` and a builtin toString

- **Date**: 2026-11-21

## Context

`util.format("%s", new P())` for a class without a toString of its own
gave `[object Object]`, and Node gives `P { x: 1 }`. Our
`hasBuiltInToString` treated a class instance's inherited
Object.prototype.toString as the program's own, unless it was
Array.prototype's.

## Decision

`hasBuiltInToString` follows Node's rule:

- An object with no toString function counts as builtin.
- An own toString is the program's.
- Otherwise, find the object on the prototype chain that owns toString.
  It is builtin when its `constructor` is one of the builtin globals
  (Node's builtInObjects).
- A `Symbol.toPrimitive` method still makes `%s` call it.

## Implementation notes

- lib/node/util.ts (`hasBuiltInToString`, `builtInObjectNames`).

## Verification

- `TestE2EUtilFormatStringObjectJS` matches Node on Linux x86 (Node304).
