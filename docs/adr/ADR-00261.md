# ADR-00261: `yield*` delegation over an async generator

- **Relations**: extends [ADR-00259](ADR-00259.md) (sync `yield*`) and [ADR-00260](ADR-00260.md) (async `.throw()`/`.return()`), which scoped async `yield*` out. Part of [TDD-00086](../tdd/TDD-00086.md)
- **Date**: 2026-08-20

## Context

Sync `yield*` ([ADR-00259](ADR-00259.md)) lowers `yield* inner` to a loop that
drives the inner generator, re-yields each value, forwards each
`.next(v)`/`.throw()`/`.return()`, and evaluates to the inner's return value. Its
inner-step calls used the *sync* generator cores, which return a `{value,done}`
result object directly. An async inner's `.next()` instead returns a settled
`Promise<{value,done}>`, so delegating to it requires awaiting each step —
possible only inside an async generator body.

## Decision

Generalize `emitYieldStar` over the inner's sync/async-ness with three small step
closures (`stepNext`/`stepThrow`/`stepReturn`) that each return the `{value,done}`
result object pointer:

- **Sync inner** — call the existing sync cores
  (`emitSyncGeneratorNextCore` / `emitGeneratorThrowByValue` /
  `emitGeneratorReturnByValue`), which return the result object directly.
- **Async inner** — call the async cores
  (`emitAsyncGeneratorNextCore` / `emitAsyncGeneratorThrowByValue` /
  `emitAsyncGeneratorReturnByValue`), then `emitAwaitSettledResult` on the
  returned promise: it `__kml_task_await_ready`s the (already-settled) promise,
  re-throws on the caller side if it rejected, and unwraps the `{value,done}`
  object — mirroring `emitAwait`'s task-promise branch.

The rest of the loop is unchanged: the outer's `yield` of each inner value, the
resume-mode switch that forwards the caller's action into the inner, and the
inner-return-value result. An **async inner is allowed only inside an async
outer** (awaiting a step needs an async context) — an async inner in a sync outer
is a clean rejection. `emitAsyncGeneratorNextByValue` was split so its promise-
producing core (`emitAsyncGeneratorNextCore`, taking an already-evaluated sent
value) is reusable here, matching the sync `emitSyncGeneratorNextCore` split from
ADR-00259.

## Consequences

- `yield* innerAsyncGen()` inside an `async function*` works: delegation,
  sent-value forwarding, `.throw()`/`.return()` forwarding, and the inner's return
  value — the same surface sync `yield*` has, with each inner step awaited.
- Element types must still match between inner and outer (V1); a general async
  iterable needs `Symbol.asyncIterator` ([TDD-00044](../tdd/TDD-00044.md)), out of
  scope.
- The generator/async-generator protocol is now complete for this compiler's
  model: `.next()`/`.throw()`/`.return()`/`yield*` across both sync and async
  generators.
