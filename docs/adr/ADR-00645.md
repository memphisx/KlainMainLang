# ADR-00645: Decorators Stage 4b/5 — class-replacement divergence and the standard (TC39) dialect

- **Relations**: `Implements TDD-00161` (Stages 4b, 5), `Extends ADR-00644`
- **Date**: 2026-09-02

## Context

The last two TDD-00161 stages: 4b (a class decorator that *returns a replacement
constructor*, observed by every construction/static-reference site) and 5 (the
TC39 **standard** decorator dialect — `(value, context)` — that TypeScript 5.0
defaults to, alongside the experimental dialect of Stages 1-4).

## Decision

### Class-decorator replacement is a documented divergence (Stage 4b)

Faithful arbitrary class-decorator replacement is a **genuine impossibility** in
the strict static-class model, per this project's divergence rule:

- The only type-safe replacement in TS is `return class extends target {}` — a
  **runtime-created anonymous subclass**. The static-native model has no runtime
  class creation and no first-class constructor objects.
- Even a "wrap" replacement needs `target` to be the **callable constructor** so
  the decorator can invoke it, but our decorator `target` must be a
  **metadata-bearing data bag** (for `Reflect.getMetadata`). A single value
  cannot be both a callable constructor and a property object here; TS's
  constructor is a function-with-properties, which this model has neither of.

Disposition: a class decorator that returns a genuine replacement is **refused
at runtime** with a clear throw (both dialects), never silently dropped;
observe-only class decorators (the registration majority) run faithfully. True
replacement is deferred — the intended future home is the `-compat=js` lane,
where classes are already dynamic prototype objects, possibly with first-class
constructors; no separate TDD is opened now, mid-implementation. Recorded as a
caveat on the decorators status row.

### The standard (TC39) dialect (Stage 5)

- **Selection**: `-decorators=experimental|standard` (`SetDecoratorDialect`),
  defaulting to **experimental** — the dialect this compiler shipped first. This
  diverges from TypeScript 5.0's standard default; documented, and chosen to
  avoid reinterpreting every existing decorator. The two dialects have
  incompatible call shapes and are never mixed in one compilation.
- **Emission** (`emit_decorators_standard.go`, dispatched from
  `emitClassDecoratorApplications`): each decorator is called `(value, context)`
  where `context` is `{ kind, name, static, private }`. **Method** decorators
  receive the method as a callable `value`; a returned callable replaces it and
  re-routes the method's calls through the same per-method slot Stage 2 built
  (the return threads through multiple decorators; identity/`undefined` keeps
  the current value). **Class** decorators receive the class value and run
  observe-only (a genuine replacement hits the divergence above; returning the
  same value or `undefined` is fine).
- **Scoped out (a standard-dialect sub-stage)**: field decorators (return an
  initializer run during construction), `accessor` auto-accessor decorators,
  getter/setter decorators, and `context.addInitializer` — all need
  construction-time injection into the already-emitted constructor. Each is a
  clean compile-time rejection with a specific message, not a silent no-op.
  Parameter decorators do not exist in TC39 and are rejected outright.

## Side effects discovered

- The standard dialect does not move the acceptance oracle either (same as
  Stages 2-4): dialect is a runtime-semantics choice the accept/reject oracle
  cannot see. The remaining oracle lever stays **factory decorators**
  (`@dec(...)`), tracked next.

## Verification

- `tests/decorators_test.go`: standard class + method observe (identity return
  keeps the member; context kind/name), standard method replacement, and the
  parameter/field rejections. Experimental Stages 1-4 tests unchanged (still the
  default).
- `examples/decorators/standard_decorators.ts` runs under `-decorators=standard`
  (a Makefile carve-out, like the `-compat=js` jsmode examples).
- `go vet`, full `make test-par`, decorator/class/reflect suites, node oracle,
  `status-check`/`reference-check` pass. Mac (Apple Silicon).
