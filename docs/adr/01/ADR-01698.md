# ADR-01698: Builtin prototypes as values

- **Relations**: `Implements TDD-00230`
- **Date**: 2026-10-18

## Context

`Map.prototype`, `Array.prototype.map` and `"s".slice` as values did not compile, or they read `undefined`. A builtin method could only be called, never read as a value. So none of these worked: `Map.prototype.get === m.get`, `Array.prototype.slice.call(arguments)`, `Object.getPrototypeOf(m) === Map.prototype`, `const sl = s.slice; sl.call(t, 1)`.

## Decision

1. **One record per class and method.** `@__kml_proto_m_<Class>_<m>_rec` is the method's function value. Every read of it returns that same record, so the reads are identical.
   - A host class's adapter (Map, Set, WeakMap, WeakSet, WeakRef, FinalizationRegistry, Promise, DataView, ArrayBuffer, SharedArrayBuffer, Date, RegExp) calls `__kml_proto_call` in `shape.c`.
     - It finds the receiver's own method through the shape getter's hidden key.
     - A receiver of the wrong class throws Node's TypeError: `Method Map.prototype.get called on incompatible receiver #<Set>`.
   - Promise reuses the record its boxed wrapper already has.
2. **Array and String values are not host boxes.** For them the adapter calls the method directly on the receiver, converted as the spec's generic methods convert it:
   - an array-like goes through `Array.from`;
   - a non-string goes through `String`;
   - `null` or `undefined` throws Node's `called on null or undefined`.
   It has one branch per count of fixed arguments passed. A count the typed method does not take is fitted: an ignored argument, such as `thisArg`, is dropped, and a missing one is `undefined`.
   - `push`, `unshift` and `concat` take their rest arguments one call each.
   - `splice` inserts its items one splice each, at the start position normalized against the length.
3. **The prototype object.** `X.prototype` is a bag built once per class in `@__kml_proto_obj_<Class>`. It holds:
   - the method records;
   - `constructor`, which is the class's own value (`String.prototype.constructor === String`);
   - `@@toStringTag`, where Node has one.
   None of these properties are enumerable.
4. **Reads that reach the prototype:**
   - `Object.getPrototypeOf` of a host instance, an array or a string returns its class's prototype. For a TypedArray it is `null`, which is not modelled.
   - An `any` array's or string's property read of a method name asks the generated `__kml_array_proto_get` or `__kml_string_proto_get`. A weak default returning `undefined` stands in when the program reads no such method as a value.
   - A typed array's or string's method read as a value infers as `any`. A binding of it therefore keeps the dynamic function, and `.call(thisArg)` passes the receiver.

Bugs found along the way:
- An `any` callback to an array HOF was converted to a `void`-returning signature, so `map` and `reduce` rejected it. It now returns `any`.
- The dynamic `.call` passed a typed `thisArg`, such as a string literal, unboxed.
- `Object.getPrototypeOf` refused a typed array or string value.

## Consequences

Still not values:
- accessors (`Map.prototype.size`);
- the prototypes of web classes (URL, Headers);
- the prototypes of the other primitives (Number, Boolean, Symbol, BigInt) and of TypedArrays.

A mutation made through a non-array receiver (`Array.prototype.push.call(arrayLike, x)`) is not written back.

## Verification

macOS (Apple Silicon): the probes for host classes, Array (each method with each arity, array-likes, `arguments`), String and `getPrototypeOf` match Node's output. These tests pass: `TestE2EBuiltinPrototypeValues`, `TestE2EArrayPrototypeValues`, `TestE2EStringPrototypeValues` and `TestE2EAnyCallbackToArrayHOF`.

Linux (Node304 box): the targeted host, array, HOF, dynamic and Promise suites pass.
