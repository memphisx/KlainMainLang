# ADR-01172: `util.promisify`, and calling a function held in `any` with an argument list

- **Relations**: `Extends [ADR-00325](ADR-00325.md)`, [ADR-01170](ADR-01170.md)
- **Date**: 2026-09-26

## Context

`util.promisify` did not exist: importing it failed. Porting Node's
implementation (`lib/internal/util.js`) needs what that code does with the
function it wraps. It checks `typeof original` at run time, then calls it
with the caller's arguments plus a callback (`original(...args, cb)`). Neither
worked on a function held in an `any`: a spread call on a dynamic callee was
rejected, `fn.apply`/`fn.call` read an absent property ("apply is not a
function"), and `Reflect.apply` did not exist.

## Investigation

- Node v24's `promisify` validates with `validateFunction`
  (`ERR_INVALID_ARG_TYPE`, `The "original" argument must be of type
  function. Received …`), pushes a callback `(err, ...values)` onto the
  arguments, rejects on `err`, and resolves with `values[0]`.
- A typed parameter (`original: (...args: any[]) => void`) folds `typeof
  original` to `"function"` at compile time and unboxes any value passed as
  one, so the check could never fail. The parameter is `any`, as Node's is.
- The dynamic call ABI is `fn(env, receiver, argc, argv)` with `argv` a run of
  NaN boxes, which is exactly an `any[]`'s elements. An argument list with a
  spread is built as an `any[]` and passed as `argv`.
- Building that `any[]` from `[...nums]` copied a `number[]`'s raw doubles
  into box slots (`[...[7, 8]]` as `any[]` printed `[6.5, 7.5]`): a spread
  into box elements now boxes each element.
- Loose equality on a box holding a bigint (`b == 10` with `b: bigint |
  number`) ToPrimitive'd the bigint's cell and compared `NaN`; it now compares
  a bigint against a bigint, a number or a string by value.

## Decision

- `lib/node/internal_util.ts` (the `util` module's part in TypeScript):
  `promisify`, typed with @types/node's overloads, implemented as Node's.
- A call on an `any` callee takes spread arguments (`f(...args, cb)`):
  `emitDynArgv` builds the argument list as an `any[]` when a spread is in
  it; the dispatcher takes a run-time count.
- `f.apply(thisArg, args)` and `f.call(thisArg, …)` on an `any` are
  Function.prototype's when `f` holds a function at run time, else `f`'s own
  method of that name. `Reflect.apply(f, thisArg, args)`.
- `[...xs]` into `any` elements boxes each element.
- `x as T[]` with a box element type types an array literal (`[5, "s",
  null] as any[]`); a binding initialised by a call of a call's function
  result (`mk()()`) has that function's return type.
- `__kml_any_loose_eq` compares a boxed bigint by value
  (`__kml_boxed_bigint_eq_num`, beside the existing cell hooks).

## Implementation notes

`lib/node/internal_util.ts`; `codegen/llvm/emit_dynfunc.go` (`emitDynArgv`,
`emitDynApplyOrCall`, `emitDynFnBoxCallN`), `emit_reflect.go`,
`emit_arrays_core.go` (`emitSpreadBoxLoop`), `emit_undefined.go`
(`emitAsExpression`), `emit_exprs_types.go`, `emit_bigint_box.go`,
`emit_toprimitive_dyn.go` (`__kml_bigint_cell`).

## Side effects discovered

- A code-generated builtin (`fs.readFile`, `zlib.gzip`, `Math.max`) is not a
  function value, so `promisify(fs.readFile)` and `Reflect.apply(Math.max,
  …)` are compile errors; the builtins written in TypeScript are values.
- `promisify.custom` is not read.
